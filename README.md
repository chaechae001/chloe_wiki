# Chloe Wiki

A personal learning wiki for organizing lecture materials and study notes.

This repository restructures class materials, practice exercises, and personal notes into Markdown documents for easier review and long-term reference.

<br/>

## Repository Structure

```text id="ic26fc"
chloe_wiki/
├── 01_lecture-notes/
│   └── {month}/
│       └── {date}_{lecture-topic}/
│           ├── OVERVIEW.md
│           ├── 01-topic.md
│           ├── 02-topic.md
│           └── GLOSSARY.md
│
└── README.md
```

<br/>

## Directory Rule

Lecture notes are organized using the following structure:

```text id="111g5r"
01_lecture-notes/{month}/{date}_{lecture-topic}/
```

Example:

```text id="5e3j78"
01_lecture-notes/06월/0602_python-intermediate/
```

<br/>

## File Guide

| File                 | Description                                       |
| -------------------- | ------------------------------------------------- |
| `OVERVIEW.md`        | Summary of the lecture flow and table of contents |
| `01-*.md`, `02-*.md` | Topic-based study notes                           |
| `GLOSSARY.md`        | Key terms and definitions                         |

<br/>

## How to Read

1. Start with `OVERVIEW.md` in each lecture folder.
2. Read the topic-based Markdown files in order.
3. Check `GLOSSARY.md` for unfamiliar or confusing terms.

<br/>

## Note

This repository is maintained for personal study and review.
The content may be updated or refined as learning continues.
