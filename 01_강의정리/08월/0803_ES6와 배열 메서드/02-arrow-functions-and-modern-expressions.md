# 화살표 함수와 간결한 ES6 표현

> 짧은 문법의 목적은 글자 수를 줄이는 것이 아니라 데이터 흐름을 한눈에 보이게 만드는 것입니다.

`arrow function` · `template literal` · `optional chaining` · `property shorthand` · `method shorthand`

## 핵심요약

- 화살표 함수는 짧은 콜백과 단일 표현식 함수에 유용합니다.
- 중괄호를 생략하면 표현식의 결과가 자동 반환됩니다.
- 템플릿 리터럴은 문자열 안에 값과 계산식을 삽입합니다.
- 옵셔널 체이닝은 중간 값이 없을 때 안전하게 접근을 멈춥니다.
- 객체 축약 문법은 변수 이름과 프로퍼티 이름이 같을 때 중복을 줄입니다.

## 1. 화살표 함수

### 1) 정의

화살표 함수는 `=>`로 함수 표현식을 간결하게 작성하는 문법입니다.

### 2) 왜 필요한가

배열 메서드와 이벤트 처리에서는 짧은 동작을 함수로 자주 전달합니다. 화살표 함수를 쓰면 입력과 반환 관계가 가까워져 변환 규칙을 읽기 쉽습니다.

### 3) 핵심 흐름 재구성

```javascript
function double(value) {
  return value * 2;
}

const doubleArrow = (value) => value * 2;
```

매개변수가 하나면 괄호를 생략할 수 있지만, 일관성을 위해 괄호를 유지하기도 합니다. 여러 문장을 실행할 때는 중괄호와 `return`을 직접 작성합니다.

### 4) 쉬운 예시

“숫자를 받아 두 배로 돌려준다”처럼 입력과 결과가 한 문장인 작업은 화살표 함수로 읽기 좋습니다.

### 5) 코드 예시

```javascript
const prices = [1000, 2500, 4000];
const discounted = prices.map((price) => price * 0.9);

console.log(discounted); // [900, 2250, 3600]
```

### 6) 헷갈리는 점

객체 리터럴을 바로 반환할 때는 소괄호로 감싸야 합니다.

```javascript
const toUser = (name) => ({ name, active: true });
```

### 7) 한 줄 정리

> 화살표 함수는 짧은 입력→출력 관계를 콜백 가까이에 표현합니다.

## 2. 템플릿 리터럴과 객체 축약

### 1) 정의

템플릿 리터럴은 백틱으로 문자열을 만들고 `${표현식}`으로 값을 삽입합니다. 객체 축약은 프로퍼티 이름과 변수 이름이 같을 때 한 번만 적는 문법입니다.

### 2) 왜 필요한가

문자열 연결과 객체 생성에서 반복되는 이름을 줄이면 실제 데이터가 어디에 들어가는지 더 분명해집니다.

### 3) 핵심 흐름 재구성

```javascript
const name = "Mina";
const score = 92;

const message = `${name}님의 점수는 ${score}점입니다.`;
const result = { name, score };
```

### 4) 쉬운 예시

영수증 문구처럼 고정된 문장 사이에 상품명과 가격이 들어갈 때 템플릿 리터럴을 사용하면 구조가 그대로 보입니다.

### 5) 코드 예시

```javascript
const cart = {
  total: 30000,
  describe() {
    return `결제 금액: ${this.total}원`;
  }
};
```

### 6) 헷갈리는 점

`${}`는 일반 따옴표 문자열에서는 평가되지 않습니다. 반드시 백틱을 사용해야 합니다.

### 7) 한 줄 정리

> 템플릿과 축약 문법은 값이 문장과 객체의 어느 위치에 들어가는지 선명하게 만듭니다.

## 3. 옵셔널 체이닝

### 1) 정의

`?.`는 왼쪽 값이 `null` 또는 `undefined`일 때 더 깊이 접근하지 않고 `undefined`를 반환합니다.

### 2) 왜 필요한가

API 응답처럼 일부 중첩 정보가 없을 수 있는 데이터에서 안전하게 값을 읽을 수 있습니다.

### 3) 핵심 흐름 재구성

```javascript
const user = { profile: { nickname: "mimi" } };

console.log(user.profile?.nickname); // mimi
console.log(user.contact?.email);    // undefined
```

### 4) 쉬운 예시

주소록에 연락처 카드가 있을 때만 이메일 칸을 확인하는 과정과 같습니다. 카드 자체가 없으면 확인을 멈춥니다.

### 5) 코드 예시

```javascript
const firstTag = article.tags?.[0];
const label = firstTag ?? "태그 없음";
```

### 6) 헷갈리는 점

옵셔널 체이닝은 모든 오류를 숨기는 문법이 아닙니다. 반드시 있어야 하는 값까지 무조건 `?.`로 처리하면 데이터 문제를 놓칠 수 있습니다.

### 7) 한 줄 정리

> 옵셔널 체이닝은 선택적인 중첩 데이터 접근을 안전하게 멈추는 문법입니다.

## 코드로 보기 — 사용자 카드 만들기

```javascript
const user = {
  name: "Mina",
  profile: { city: "Seoul" }
};

const makeCard = ({ name, profile }) => ({
  title: `${name}님의 프로필`,
  city: profile?.city ?? "미등록"
});

console.log(makeCard(user));
// { title: "Mina님의 프로필", city: "Seoul" }
```

### 코드 목적

화살표 함수, 구조 분해 매개변수, 템플릿 리터럴, 옵셔널 체이닝을 한 데이터 변환에 연결합니다.

### 코드 흐름

1. 사용자 객체를 함수에 전달합니다.
2. 필요한 프로퍼티를 매개변수에서 꺼냅니다.
3. 제목 문자열을 조합합니다.
4. 도시가 없을 때 기본 문구를 사용합니다.

### 실행 결과 해석

입력 객체를 변경하지 않고 화면 표시용 새 객체를 반환합니다.

### 실무 연결

API 응답을 카드·목록·테이블 같은 UI 모델로 변환할 때 자주 쓰는 형태입니다.

## 헷갈리기 쉬운 포인트

| 헷갈리는 개념 | 차이 |
|---|---|
| 표현식 본문 vs 블록 본문 | 표현식은 자동 반환되고, 중괄호 블록은 `return`이 필요합니다. |
| 일반 문자열 vs 템플릿 리터럴 | `${}` 평가와 여러 줄 문자열 지원 여부가 다릅니다. |
| `?.` vs `??` | 안전한 접근과 nullish 기본값 선택은 서로 다른 역할입니다. |

**Q1. 화살표 함수에서 중괄호를 쓰면 자동 반환되나요?**

<details>
<summary>답</summary>

**Q2. 템플릿 리터럴은 어떤 문자로 감싸나요?**

<details>
<summary>답</summary>

</details>

**Q3. 반드시 존재해야 하는 값에도 옵셔널 체이닝을 남용하면 왜 좋지 않나요?**

<details>
<summary>답</summary>

</details>
