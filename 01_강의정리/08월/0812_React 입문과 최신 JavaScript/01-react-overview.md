# React의 역할과 학습 방향

React는 화면을 직접 고치는 명령을 나열하기보다, 현재 데이터로 어떤 UI가 보여야 하는지를 컴포넌트로 선언하게 해 주는 JavaScript 라이브러리입니다.

## 핵심 키워드

`React` · `UI` · `component` · `JSX` · `reusability`

## 핵심 요약

- React는 사용자 인터페이스를 만들기 위한 JavaScript 라이브러리입니다.
- 컴포넌트는 독립적으로 재사용하고 조립할 수 있는 UI 단위입니다.
- JSX는 JavaScript 안에서 UI 구조를 표현하는 문법입니다.
- React 학습에는 최신 JavaScript 문법과 상태 기반 사고가 필요합니다.

## 1. React가 해결하려는 문제

화면이 단순할 때는 DOM 요소를 직접 선택하고 수정해도 충분합니다. 기능이 많아지면 데이터와 화면이 어긋나지 않도록 모든 변경 지점을 관리하기 어려워집니다. React는 UI를 작은 컴포넌트로 나누고, 데이터가 달라질 때 화면이 다시 계산되도록 구성합니다.

```jsx
function Greeting({ name }) {
  return <h1>안녕하세요, {name}</h1>;
}
```

`Greeting`은 이름을 받아 화면 조각을 반환하는 컴포넌트입니다. HTML처럼 보이는 JSX 안에서 중괄호로 JavaScript 표현식을 사용합니다.

## 2. 컴포넌트와 재사용

컴포넌트는 구조, 표현, 동작을 한 단위로 묶습니다. 같은 컴포넌트를 다른 데이터와 함께 반복 사용할 수 있고, 큰 화면을 작은 책임으로 분해할 수 있습니다.

| 관점 | 질문 |
|---|---|
| 책임 | 이 컴포넌트가 보여 주거나 처리할 일은 무엇인가? |
| 입력 | 외부에서 어떤 데이터를 받아야 하는가? |
| 상태 | 내부에서 시간에 따라 변하는 값이 있는가? |
| 조합 | 어떤 하위 컴포넌트로 나눌 수 있는가? |

## 3. React의 활용 범위

React는 브라우저 웹 UI에 사용되며, 같은 컴포넌트 사고방식은 다른 렌더링 환경으로도 확장할 수 있습니다. 중요한 것은 특정 문법 암기보다 데이터 → UI 변환과 단방향 흐름을 이해하는 것입니다.

## 대표 코드: 작은 화면 조립하기

### 목적

여러 컴포넌트를 조립해 하나의 화면을 구성합니다.

```jsx
function Badge({ text }) {
  return <span className="badge">{text}</span>;
}

function ProfileCard({ user }) {
  return (
    <article>
      <h2>{user.name}</h2>
      <Badge text={user.role} />
    </article>
  );
}
```

### 코드 흐름과 결과

1. `Badge`가 작은 표현 단위를 담당합니다.
2. `ProfileCard`가 사용자 정보를 받아 제목과 배지를 조합합니다.
3. 같은 배지를 다른 카드에서도 재사용할 수 있습니다.
4. 데이터가 바뀌면 같은 구조로 다른 화면 결과를 만듭니다.

### 실무 연결

버튼, 입력창, 카드, 목록을 컴포넌트화하면 디자인 일관성과 변경 범위를 관리하기 쉬워집니다.

## 헷갈리기 쉬운 포인트

| 비교 | 차이 |
|---|---|
| React vs JavaScript | React는 JavaScript 위에서 UI 구성을 돕는 라이브러리입니다. |
| 컴포넌트 vs HTML 태그 | 태그는 기본 UI 요소이고 컴포넌트는 여러 요소와 동작을 묶은 사용자 정의 단위입니다. |
| JSX vs HTML | JSX는 JavaScript 안에서 UI를 표현하며 속성명과 표현식 규칙이 HTML과 일부 다릅니다. |
