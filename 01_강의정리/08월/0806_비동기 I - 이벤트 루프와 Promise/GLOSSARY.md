# 용어집

## 비동기 실행

작업의 완료를 기다리는 동안 현재 실행 흐름을 막지 않고 다음 코드를 진행하는 방식입니다. 완료된 작업의 후속 처리는 콜백이나 Promise로 이어집니다.

## 동기 실행

앞선 작업이 끝나야 다음 작업을 시작하는 방식입니다. 오래 걸리는 동기 작업은 사용자 입력과 화면 갱신까지 지연시킬 수 있습니다.

## 호출 스택(Call Stack)

현재 실행 중인 함수와 복귀 위치를 쌓아 두는 LIFO 구조입니다. 자바스크립트 코드는 호출 스택에서 한 번에 하나씩 실행됩니다.

## 실행 환경(Runtime)

자바스크립트 엔진과 함께 타이머, 네트워크 요청, 이벤트 처리 같은 기능을 제공하는 브라우저 또는 Node.js 환경입니다.

## 이벤트 루프(Event Loop)

호출 스택과 큐의 상태를 확인해 실행 가능한 콜백을 호출 스택으로 옮기는 조정 메커니즘입니다.

## 태스크 큐(Task Queue)

타이머나 사용자 이벤트처럼 태스크로 분류된 콜백이 실행을 기다리는 큐입니다. 매 이벤트 루프 회차에서 보통 하나의 태스크가 선택됩니다.

## 마이크로태스크 큐(Microtask Queue)

Promise의 `then`, `catch`, `finally` 콜백 등이 대기하는 큐입니다. 현재 태스크가 끝나고 호출 스택이 비면 다음 태스크보다 먼저 모두 처리됩니다.

## 콜백(Callback)

다른 함수에 인자로 전달되어 특정 시점에 호출되는 함수입니다. 비동기 완료 알림뿐 아니라 배열 메서드와 이벤트 처리에도 사용됩니다.

## 타이머 ID

`setTimeout`이나 `setInterval`이 반환하는 예약 식별자입니다. 예약을 취소할 때 `clearTimeout` 또는 `clearInterval`에 전달합니다.

## 블로킹(Blocking)

한 작업이 실행 흐름을 점유해 다른 작업이 진행되지 못하는 상태입니다. 긴 반복문이나 무거운 계산이 대표적입니다.

## Promise

아직 끝나지 않은 비동기 작업의 미래 결과를 표현하는 객체입니다. 대기, 이행, 거부 중 하나의 상태를 가집니다.

## pending

Promise가 아직 성공도 실패도 결정되지 않은 대기 상태입니다.

## fulfilled

`resolve`가 호출되어 Promise가 성공한 상태입니다. 성공값은 `then`으로 전달됩니다.

## rejected

`reject`가 호출되거나 처리 중 오류가 발생해 Promise가 실패한 상태입니다. 실패 이유는 `catch`로 전달할 수 있습니다.

## 정착(Settled)

Promise가 fulfilled 또는 rejected가 되어 결과가 결정된 상태입니다. 한 번 정착된 Promise의 상태는 다시 바뀌지 않습니다.

## Promise 체이닝

`then`, `catch`, `finally`가 새 Promise를 반환한다는 성질을 이용해 후속 작업을 연속으로 연결하는 패턴입니다.

## async 함수

항상 Promise를 반환하는 함수입니다. 일반 값을 반환하면 이행된 Promise로 감싸지고, 예외를 던지면 거부된 Promise가 됩니다.

## await

Promise가 정착될 때까지 해당 `async` 함수 내부의 다음 실행을 미루는 문법입니다. 자바스크립트 전체 스레드를 막지는 않습니다.

## Promise.all

여러 Promise를 함께 시작하고 모두 성공했을 때 입력 순서대로 결과 배열을 만드는 정적 메서드입니다. 하나라도 실패하면 전체 결과가 즉시 거부됩니다.

## 최소 지연 시간

타이머에 지정한 시간은 콜백이 실행될 수 있는 가장 이른 시점입니다. 호출 스택과 앞선 큐 작업 때문에 실제 실행은 더 늦을 수 있습니다.
