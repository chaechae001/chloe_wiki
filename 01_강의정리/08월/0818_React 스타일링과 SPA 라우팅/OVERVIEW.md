# React 스타일링과 SPA 라우팅 개요

이 묶음은 React 화면을 안정적으로 스타일링하고, SPA의 URL을 React Router v6로 설계하는 흐름을 다룹니다.

## 학습 순서

1. [React 스타일링 전략](01-react-styling-strategies.md)에서 전역 CSS, CSS Module, CSS-in-JS의 책임을 나눕니다.
2. [CSS 레이아웃 기초](02-css-layout-foundations.md)에서 박스 크기와 위치 기준을 익힙니다.
3. [Flexbox 반응형 레이아웃](03-flexbox-responsive-layout.md)에서 한 축 배치와 유동 크기를 설계합니다.
4. [Sass와 styled-components](04-sass-and-styled-components.md)에서 스타일 작성 도구를 확장합니다.
5. [SPA와 클라이언트 라우팅](05-spa-and-client-side-routing.md)에서 주소와 화면 전환 원리를 이해합니다.
6. [React Router v6 기초](06-react-router-v6-basics.md)에서 기본 경로와 이동을 구현합니다.
7. [동적 경로, 쿼리와 접근 제어](07-dynamic-routes-query-and-guards.md)에서 실무 URL과 보호 경로를 완성합니다.

용어가 낯설면 [용어집](GLOSSARY.md)을 함께 확인하세요.

## 완성할 수 있는 것

- 스타일 충돌을 줄이는 컴포넌트 스타일 구조
- 박스 모델과 Flexbox를 이용한 반응형 화면
- React Router v6 기반 기본·동적·보호 경로
- 새로고침, 404, 쿼리, 로그인 이동을 고려한 SPA 탐색 흐름

## 전체 점검

- [ ] 전역 스타일과 컴포넌트 스타일의 책임을 나눴다.
- [ ] 박스 모델과 Flexbox 축을 설명할 수 있다.
- [ ] v5 예제를 v6 문법으로 바꿀 수 있다.
- [ ] params와 query를 목적에 맞게 구분한다.
- [ ] 클라이언트 라우팅과 서버 fallback을 함께 설정한다.
