# 용어집

| 용어 | 뜻 |
|---|---|
| Box model | content, padding, border, margin으로 이루어진 CSS 요소의 공간 모델 |
| CSS Module | 클래스 이름을 파일 단위로 고유하게 변환하는 CSS 방식 |
| CSS-in-JS | JavaScript에서 스타일을 선언하고 컴포넌트와 결합하는 방식 |
| Flex container | `display: flex`가 적용되어 자식 배치를 제어하는 부모 |
| Main axis | `flex-direction`이 결정하는 Flexbox의 주된 배치 축 |
| Cross axis | 주축과 직각인 Flexbox의 보조 축 |
| Sass | 변수, 중첩, mixin 등을 제공하고 CSS로 변환되는 전처리 언어 |
| SPA | 하나의 앱 문서 안에서 클라이언트가 화면을 교체하는 애플리케이션 구조 |
| Client-side routing | 브라우저에서 URL과 렌더링 컴포넌트를 연결하는 방식 |
| History API | 새 문서 로드 없이 주소와 방문 기록을 제어하는 브라우저 API |
| Route parameter | `/items/:id`처럼 경로 일부에서 추출하는 값 |
| Query string | `?page=2`처럼 선택 조건을 표현하는 URL 부분 |
| BrowserRouter | History API 기반 React Router 문맥을 제공하는 컴포넌트 |
| Routes | v6에서 자식 Route 중 현재 URL에 맞는 경로를 선택하는 컴포넌트 |
| Navigate | 렌더링 과정에서 다른 경로로 이동시키는 v6 컴포넌트 |
| Outlet | 중첩 Route에서 선택된 자식 화면이 렌더링되는 자리 |
