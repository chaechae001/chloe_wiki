# 지도 위에 데이터 그리기 — folium으로 위치를 보여주기

> "경기도에 요소수가 많다"는 표는 머리로 이해되지만, 지도 위에 점으로 찍히면 한눈에 들어옵니다. 위도·경도가 있는 데이터는 지도로 그릴 때 비로소 진짜 힘을 발휘합니다. `folium`이 그 다리를 놓아줍니다.

`folium` `지도시각화` `CircleMarker` `위도경도` `색상인코딩` `팝업` `공간데이터`

## 핵심요약

- 위도·경도가 있는 데이터는 `folium`으로 인터랙티브 지도에 올릴 수 있다.
- `folium.Map`으로 중심 좌표와 확대 수준을 정해 빈 지도를 만든다.
- `CircleMarker`로 각 지점에 원형 마커를 찍고, **색·크기로 추가 정보(재고·가격·혼잡도)**를 표현한다.
- `Popup`으로 마커를 클릭하면 상세 정보(이름·주소·재고)가 뜨게 한다.
- 요소수: 재고·가격을 색으로, 지하철: 혼잡도를 원 크기로 인코딩했다.
- 지도는 "수도권 쏠림" 같은 **공간 패턴**을 글이나 표보다 즉각적으로 드러낸다.

## 개념별 정리

### 지도의 뼈대 — folium.Map

**1. 정의**
`folium.Map`은 빈 지도(배경)를 만드는 출발점입니다. 어디를 중심으로, 얼마나 확대해 보여줄지를 정합니다.

**2. 왜 필요한가?**
점을 찍으려면 먼저 종이(지도)가 있어야 합니다. 중심 좌표와 확대 수준을 잘 잡아야 보고 싶은 지역이 화면에 알맞게 들어옵니다.

**3. 예시**
```python
import folium

# 서울 중심(중구) 좌표를 가운데로, 확대 수준 10으로 지도 생성
map_osm = folium.Map(location=[37.557945, 126.99419], zoom_start=10)
map_osm
```
전국을 보려면 한반도 중앙쯤(`[36.35, 127.38]`)을 중심으로 잡고 `zoom_start`를 7 정도로 낮춥니다.

**4. 헷갈리기 쉬운 점**
좌표 순서가 헷갈립니다. `folium`은 `[위도(latitude), 경도(longitude)]` 순입니다. 위도·경도를 바꿔 넣으면 마커가 엉뚱한 바다 한가운데에 찍힙니다.

**5. 한 줄 정리**
`folium.Map`은 중심 좌표와 확대 수준을 정해 빈 지도를 만든다.

> 비유: 그림을 그리기 전에 도화지의 크기와 어느 부분을 그릴지 정하는 것과 같습니다.

### 점 찍기 — CircleMarker

**1. 정의**
지도 위 특정 좌표에 원형 마커를 찍는 도구입니다. 위치, 크기(`radius`), 색(`color`)을 지정할 수 있습니다.

**2. 왜 필요한가?**
각 주유소·지하철역을 지도에 표시해야 "어디에 무엇이 있는지"가 보입니다. 게다가 **크기와 색에 정보를 담아** 한 점이 여러 사실(위치+재고+가격)을 동시에 말하게 할 수 있습니다.

**3. 예시**
```python
marker = folium.CircleMarker(
    [위도, 경도],          # 위치
    radius=5,             # 원 크기
    color=색상코드,        # 테두리 색
    fill=True,            # 채우기
    fill_opacity=1.0,
    popup=팝업            # 클릭 시 뜰 정보
)
marker.add_to(map_osm)    # 지도에 추가
```
여러 지점을 찍을 땐 데이터를 반복문으로 돌며 마커를 하나씩 `add_to`로 더합니다.

**4. 헷갈리기 쉬운 점**
마커를 만들기만 하고 `add_to(map_osm)`를 빠뜨리면 지도에 아무것도 안 나타납니다. "만들기"와 "지도에 붙이기"는 별개의 동작입니다.

**5. 한 줄 정리**
`CircleMarker`로 점을 찍고, 반드시 `add_to`로 지도에 붙인다.

> 비유: 스티커를 산다고 끝이 아니라, 종이에 붙여야 보입니다.

### 색·크기로 정보 담기 — 시각적 인코딩

**1. 정의**
마커의 색이나 크기에 데이터 값을 대응시켜, 한눈에 의미를 읽히게 하는 기법입니다.

**2. 왜 필요한가?**
점이 모두 똑같으면 "어디가 재고가 많고 적은지"를 알 수 없습니다. 색·크기에 값을 담으면 지도가 곧 정보판이 됩니다.

**3. 예시 — 요소수 재고를 색으로**
```python
color = i[2].upper()                    # 재고 레벨 (GREEN/YELLOW/RED/GRAY)
if color == 'GREEN':   color_code = '#9ACD32'  # 여유
elif color == 'YELLOW':color_code = '#FFFF00'  # 보통
elif color == 'RED':   color_code = '#DC143C'  # 부족
elif color == 'GRAY':  color_code = '#696969'  # 품절
```
초록·노랑·빨강·회색으로 재고 상태가 한눈에 보입니다. 가격 지도에서는 가격대를 노랑→주황→빨강으로 인코딩했습니다(쌀수록 노랑, 비쌀수록 빨강).

**예시 — 지하철 혼잡도를 크기로**
```python
marker = folium.CircleMarker(
    [위도, 경도],
    radius=(df['평균 승차 인원 수'][i] + 1) / 3000,  # 인원 많을수록 원이 큼
    color='blue', fill_color='blue'
)
```
승차 인원이 많은 역일수록 원이 커져, 강남·잠실 같은 혼잡 역이 큰 원으로 두드러집니다. (`+1`은 인원이 0일 때 계산 오류를 막는 작은 보정입니다.)

**4. 헷갈리기 쉬운 점**
색을 너무 많이 쓰거나 의미 없이 쓰면 오히려 헷갈립니다. **신호등처럼 직관적인 색**(초록=좋음, 빨강=나쁨)을 쓰면 설명 없이도 읽힙니다.

**5. 한 줄 정리**
색은 "상태", 크기는 "양"을 담는 데 자주 쓴다.

> 비유: 일기예보 지도에서 비 오는 곳이 파랑, 더운 곳이 빨강인 것과 같은 약속입니다.

### 팝업 — 클릭하면 뜨는 상세 정보

**1. 정의**
마커를 클릭했을 때 나타나는 작은 정보창입니다. 이름·주소·재고 같은 세부 내용을 담습니다.

**2. 왜 필요한가?**
지도에 모든 글자를 다 띄우면 지저분합니다. 평소엔 점만 보여주고, 궁금한 점을 클릭하면 상세 정보가 뜨게 하면 깔끔하면서도 정보가 풍부합니다.

**3. 예시**
```python
iframe = (f"<b>명칭: </b>{이름}<br>"
          f"<b>주소: </b>{주소}<br>"
          f"<b>재고량: </b>{재고}<br>"
          f"<b>전화번호: </b>{전화}")
popup = folium.Popup(iframe, min_width=300, max_width=800)
```
HTML로 내용을 꾸며 줄바꿈(`<br>`)과 굵은 글씨(`<b>`)까지 넣을 수 있습니다.

**4. 헷갈리기 쉬운 점**
팝업 내용은 HTML이라, 숫자를 문자와 이을 때 형 변환(`str(...)`)을 빠뜨리면 오류가 납니다.

**5. 한 줄 정리**
`Popup`으로 평소엔 숨기고, 클릭하면 상세 정보를 보여준다.

> 비유: 박물관 전시물 옆 "자세히 보기" 버튼처럼, 필요할 때만 설명이 펼쳐집니다.

## 코드로 보기 — 요소수 재고 지도 한 번에

```python
# 경기도 데이터만 추리기
target_region = '경기'
df_target = df[df['addr'].str.contains(target_region)]

map_osm = folium.Map(location=[37.557945, 126.99419], zoom_start=9)

for i in df_target.values:
    # 팝업 내용 구성
    iframe = (f"<b>명칭: </b>{i[6]}<br><b>주소: </b>{i[0]}<br>"
              f"<b>재고량: </b>{i[3]}<br><b>전화번호: </b>{i[8]}")
    popup = folium.Popup(iframe, min_width=300, max_width=800)

    # 재고 레벨에 따라 색 결정
    color = i[2].upper()
    color_code = {'GREEN':'#9ACD32','YELLOW':'#FFFF00',
                  'RED':'#DC143C','GRAY':'#696969'}.get(color, '#000000')

    # 마커 생성 후 지도에 추가
    folium.CircleMarker([i[4], i[5]], radius=5, color=color_code,
                        fill=True, fill_opacity=1.0, popup=popup).add_to(map_osm)
map_osm
```

**코드목적**
경기도 요소수 유통 주유소를 지도에 색깔 점으로 찍어, 재고가 여유로운 곳·부족한 곳의 분포를 한눈에 보이게 합니다.

**해석**
경기도 전역에 초록(여유)·노랑(보통) 점이 고르게 퍼져 있어 재고가 비교적 넉넉함을 알 수 있습니다. 다만 일부 빨강·회색 점(부족·품절)도 섞여 있습니다. 전국 지도로 넓혀 보면 **마커 대부분이 수도권에 몰려** 있는데, 이는 앞서 표로 확인한 "지방 주유소가 적다"는 사실과 정확히 일치합니다. 표가 말한 것을 지도가 눈으로 증명해 줍니다.

**실무 연결**
배달 수요 히트맵, 매장 입지 분석, 코로나 확진자 분포, 물류 거점 최적화 등 "어디에"가 중요한 모든 분석에서 지도 시각화가 핵심입니다. 위치 데이터는 표로 보면 막막하지만 지도로 보면 의사결정이 빨라집니다.

## 헷갈리기 쉬운 포인트

- **`[위도, 경도]` 순서**: folium은 위도가 먼저. 바꾸면 엉뚱한 곳에 찍힘.
- **마커 만들기 vs `add_to`**: 만들기만 하면 안 보임. 반드시 지도에 붙여야 함.
- **색 인코딩 vs 크기 인코딩**: 색은 "상태(범주)", 크기는 "양(수치)"에 적합.
- **`zoom_start` 값**: 클수록 확대(좁은 지역), 작을수록 축소(넓은 지역).

## 셀프 체크

- [ ] `folium.Map`에서 중심 좌표와 `zoom_start`의 역할을 안다.
- [ ] `folium`의 좌표 순서(위도, 경도)를 안다.
- [ ] `CircleMarker`를 만들고 `add_to`로 붙이는 흐름을 안다.
- [ ] 색과 크기에 데이터를 담는 인코딩을 설명할 수 있다.
- [ ] 팝업이 왜 유용한지 안다.
- [ ] 지도 시각화가 표보다 나은 상황을 예로 들 수 있다.

**복습 질문 및 답변**

*기본:* `folium`에서 좌표를 적는 순서는 무엇인가요?
→ `[위도, 경도]` 순입니다.

*이해 확인:* 마커를 만들었는데 지도에 안 보이면 무엇을 빠뜨린 걸까요?
→ `marker.add_to(map_osm)`으로 지도에 붙이는 단계를 빠뜨린 것입니다.

*응용:* 지하철 역마다 혼잡도를 표현하려면 마커의 어떤 속성을 인원 수에 비례시키면 될까요?
→ `radius`(원의 크기)를 평균 승차 인원에 비례하게 하면 붐비는 역이 큰 원으로 보입니다.

## 한 줄 정리

> 위도·경도가 있다면 표 대신 지도로 보여줘라. `folium`의 마커에 색과 크기로 정보를 담으면, 한 장의 지도가 표 열 개보다 빠르게 패턴을 말해 준다.
