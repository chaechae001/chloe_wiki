# 전처리를 함수로, 데이터를 하나로 — 반복을 줄이고 표를 합치기

> 데이터가 한 해만 있으면 손으로 청소해도 됩니다. 하지만 2018·2019·2020·2021 네 해라면? 같은 청소를 네 번 복붙하는 대신, **한 번 만들어 네 번 쓰는** 방법이 필요합니다. 그리고 흩어진 표들을 하나로 합쳐야 비로소 "변화"가 보입니다.

`함수화` `반복적용` `merge` `outer join` `groupby` `agg` `집합연산` `개폐업분석`

## 핵심요약

- 같은 전처리를 여러 번 할 땐 **함수로 묶어** 한 번 정의하고 여러 번 호출한다.
- `merge`로 여러 해의 표를 **하나의 큰 표로 결합**한다. `how='outer'`는 한쪽에만 있는 데이터도 버리지 않는다.
- `groupby`+`agg`로 흩어진 행을 "주유소당 한 줄"로 요약한다.
- 집합(`set`)의 **차집합**으로 "작년엔 있었는데 올해 사라진 것(폐업) / 새로 생긴 것(개업)"을 찾는다.
- 분석 결과: 매년 **폐업이 개업보다 많아** 주유소 수가 꾸준히 줄었다.
- 결합 기준(key)을 무엇으로 잡느냐에 따라 결과가 달라진다 — 도메인 지식으로 신중히 정한다.

## 개념별 정리

### 전처리 함수화

**1. 정의**
앞 글에서 손으로 했던 청소 과정을 하나의 함수(`def preprocess`)로 묶어, 어떤 해의 데이터든 그 함수에 넣기만 하면 정제되도록 만드는 것입니다.

**2. 왜 필요한가?**
4개년 데이터를 똑같이 청소해야 하는데, 코드를 네 번 복붙하면 (1) 길어지고 (2) 한 군데 고치면 네 군데 다 고쳐야 하고 (3) 실수가 생깁니다. 함수로 묶으면 **수정도 한 번, 재사용도 자유**입니다.

**3. 예시**
```python
def preprocess(df):
    df = df.drop(0)                                       # 메타 헤더 행 제거
    df['기간'] = df['기간'].apply(lambda x: pd.to_datetime(str(int(x))))
    df['지역2'] = df['지역'].apply(lambda x: x.split()[0])
    df = df.loc[df['휘발유'] != 0, :]                      # 0원 제거
    uc = df.groupby('번호')[['번호','지역','상표','셀프여부']].nunique()
    target = uc.loc[(uc != 1).sum(axis=1) != 0, :]        # 정합성 위반 주유소
    df = df.loc[~df['번호'].isin(target.index), :]
    df = (df.groupby('번호')
            .agg({'지역':'first','지역2':'first','상표':'first',
                  '셀프여부':'first','휘발유':'mean'})       # 주유소당 1행으로 요약
            .reset_index())
    return df

# 2018~2021 네 해에 같은 함수를 반복 적용
f_dict = {}
for year in range(2018, 2022):
    df = pd.read_csv(f'./data/gas_price_{year}.csv')
    f_dict[year] = preprocess(df)
```

**4. 헷갈리기 쉬운 점**
함수 안에서 원본을 바꾸면 바깥 데이터까지 영향받을 수 있습니다. 안전하게 하려면 `df.copy()`로 복사본을 만들어 다루는 습관이 좋습니다.

**5. 한 줄 정리**
같은 작업을 두 번 이상 한다면, 함수로 묶을 신호다.

> 비유: 붕어빵 틀입니다. 틀(함수)을 한 번 만들면 반죽(데이터)만 바꿔 넣어 똑같은 붕어빵을 몇 개든 찍어낼 수 있습니다.

### groupby + agg — 흩어진 행을 한 줄로 요약

**1. 정의**
`groupby`는 같은 항목끼리 묶고, `agg`(aggregate)는 그 묶음을 하나의 대표값으로 요약합니다. "주유소별로 7일치 가격을 평균 하나로" 줄이는 식입니다.

**2. 왜 필요한가?**
원본은 한 주유소가 7행(7일치)입니다. 하지만 "주유소 시장"을 분석하려면 **주유소당 한 줄**이 편합니다. `groupby`+`agg`가 그 요약을 해줍니다.

**3. 예시**
```python
df.groupby('번호').agg({
    '지역':'first',     # 지역은 어차피 같으니 첫 값
    '상표':'first',
    '셀프여부':'first',
    '휘발유':'mean'      # 가격은 7일 평균
}).reset_index()
```
지역·브랜드처럼 변하지 않는 정보는 `first`(첫 값), 가격처럼 변하는 정보는 `mean`(평균)으로 요약합니다.

**4. 헷갈리기 쉬운 점**
`agg`에서 컬럼마다 다른 요약법을 줄 수 있다는 걸 놓치기 쉽습니다. 모두 평균을 내버리면 "브랜드의 평균" 같은 말이 안 되는 결과가 나옵니다. **컬럼 성격에 맞는 요약**을 골라야 합니다.

**5. 한 줄 정리**
`groupby`로 묶고 `agg`로 줄여 "한 묶음 = 한 줄"로 만든다.

> 비유: 반별 시험지를 모아 "반 평균 점수" 한 줄로 요약하는 것과 같습니다.

### merge — 여러 표를 하나로 결합(Join)

**1. 정의**
공통 열(key)을 기준으로 두 표를 옆으로 이어 붙이는 작업입니다. 엑셀의 VLOOKUP을 떠올리면 됩니다.

**2. 왜 필요한가?**
2018·2019·2020·2021 가격이 각각 다른 표에 있으면 "4년간 가격이 어떻게 변했나"를 볼 수 없습니다. 같은 주유소를 기준으로 네 표를 합쳐야 비로소 **변화**가 한 줄에 모입니다.

**3. 예시**
```python
key = ['번호', '지역', '지역2', '셀프여부']   # 결합 기준
m1 = pd.merge(f_dict[2018], f_dict[2019], on=key, how='outer',
              suffixes=('_2018', '_2019'))
m2 = pd.merge(f_dict[2020], f_dict[2021], on=key, how='outer',
              suffixes=('_2020', '_2021'))
m  = pd.merge(m1, m2, on=key, how='outer')
```

`how='outer'`는 **어느 한 해에만 있는 주유소도 버리지 않고** 모두 남깁니다. 그래야 "2018엔 없다가 2019에 생긴 주유소(개업)"를 잡아낼 수 있습니다. 빠진 해의 가격은 비어 있는 값(`NaN`)으로 채워집니다.

**4. 헷갈리기 쉬운 점**
`how`의 종류가 헷갈립니다.
- `inner`: 양쪽에 **모두 있는** 것만 남김 (교집합)
- `outer`: 한쪽에만 있어도 **모두** 남김 (합집합)
개폐업 분석에는 사라진/새로 생긴 주유소가 핵심이므로 `outer`를 써야 합니다. `inner`를 쓰면 정작 보고 싶은 변화가 사라집니다.

또 하나: 결합 기준(key)에 '상표'를 넣었더니, **폐업 후 다른 브랜드로 재개업한 주유소**가 같은 번호인데도 두 줄로 갈라졌습니다. 그래서 key에서 '상표'를 빼 같은 번호로 묶이게 했습니다. **key 선택이 결과를 좌우**하는 좋은 예입니다.

**5. 한 줄 정리**
`merge`로 표를 합치되, `outer`로 "사라진 것·새로 생긴 것"까지 남긴다.

> 비유: 여러 해의 반 명단을 학번 기준으로 한 표에 합치면, "작년엔 있다가 올해 없는 학생(전학)"이 빈칸으로 드러납니다.

### 집합 연산으로 개폐업 분석

**1. 정의**
`set`(집합)의 차집합(`difference`)을 이용해 "A 해에는 있었는데 B 해에는 없는" 주유소를 찾는 기법입니다.

**2. 왜 필요한가?**
"올해 몇 곳이 새로 생기고 몇 곳이 문을 닫았나"는 시장의 활력을 보여주는 핵심 지표입니다. 집합 연산이면 단 몇 줄로 셀 수 있습니다.

**3. 예시**
```python
# 각 해에 영업한 주유소 번호의 집합
id_dict = {}
for year in range(2018, 2022):
    id_dict[year] = set(m.loc[~m[f'상표_{year}'].isna()]['번호'].unique())

# 차집합으로 개업(새로 등장)·폐업(사라짐) 계산
for year in range(2018, 2021):
    opened = len(id_dict[year+1].difference(id_dict[year]))  # 올해 새로 생김
    closed = len(id_dict[year].difference(id_dict[year+1]))  # 올해 사라짐
```

실제 결과:

| 구간 | 개업(OPENED) | 폐업(CLOSED) |
|------|:---:|:---:|
| 2018→2019 | 291 | 436 |
| 2019→2020 | 268 | 344 |
| 2020→2021 | 223 | 383 |

**매년 폐업이 개업을 앞질러**, 전국 주유소 수가 꾸준히 줄어드는 추세가 확인됩니다.

**4. 헷갈리기 쉬운 점**
차집합은 방향이 중요합니다. `A.difference(B)`는 "A에는 있고 B에는 없는" 것입니다. 개업과 폐업은 방향만 반대일 뿐이라, 순서를 바꾸면 의미가 정반대가 됩니다.

**5. 한 줄 정리**
집합의 차집합으로 "사라진 것"과 "새로 생긴 것"을 센다.

> 비유: 작년 친구 목록과 올해 친구 목록을 비교해, 새로 사귄 친구와 멀어진 친구를 찾는 것과 같습니다.

## 코드로 보기 — 개폐업 추이 한눈에

```python
diff_df = pd.DataFrame(
    {'2018_2019':[291,436], '2019_2020':[268,344], '2020_2021':[223,383]},
    index=['OPENED','CLOSED']
)
diff_df.T.plot(color=['r','b'])   # 개업(빨강)·폐업(파랑) 추이
```

![개폐업 추이](../images/gas_01.png)

**코드목적**
연도 구간별 개업·폐업 수를 표로 만들고, 추이를 선그래프로 그려 "주유소 시장이 늘고 있나 줄고 있나"를 한눈에 보이게 합니다.

**해석**
모든 구간에서 폐업 선(파랑)이 개업 선(빨강)보다 위에 있습니다. 즉 **매년 닫는 곳이 여는 곳보다 많습니다.** 4년 동안 시장이 완만히 축소되었다는 신호입니다.

**실무 연결**
이런 "들어오고 나가는 수" 분석은 주유소뿐 아니라 회원 가입·탈퇴(이탈률), 입사·퇴사, 신규·해지 고객 등 거의 모든 비즈니스에서 똑같이 쓰입니다. 차집합 한 줄이면 "이탈 고객 명단"도 뽑을 수 있습니다.

3. `set([1,2,3]).difference(set([2,3,4]))`를 실행해 결과를 예측하고 확인해 보세요. 방향을 바꾸면?

## 헷갈리기 쉬운 포인트

- **`inner` vs `outer`**: 교집합(공통만)이냐 합집합(전부)이냐. 변화를 보려면 `outer`.
- **`first` vs `mean`**: 안 변하는 정보는 `first`, 변하는 수치는 `mean`.
- **`A.difference(B)` vs `B.difference(A)`**: 방향이 반대 → 개업과 폐업.
- **key에 무엇을 넣나**: 결합 기준이 결과를 바꾼다. '상표'를 넣고 빼는 것만으로 묶이는 방식이 달라진다.

## 셀프 체크

- [ ] 같은 전처리를 반복할 때 함수로 묶는 이유를 안다.
- [ ] `groupby`+`agg`로 "한 묶음 = 한 줄"을 만들 수 있다.
- [ ] `merge`의 `inner`와 `outer` 차이를 설명할 수 있다.
- [ ] `outer join`을 써야 개폐업을 잡을 수 있는 이유를 안다.
- [ ] 집합 차집합으로 개업·폐업을 세는 원리를 안다.

**복습 질문 및 답변**

*기본:* 여러 해 데이터를 하나로 합칠 때 쓰는 함수는 무엇인가요?
→ `pd.merge`(또는 `pd.concat`)입니다.

*이해 확인:* 개폐업 분석에 `inner`가 아니라 `outer`를 쓰는 이유는?
→ `inner`는 모든 해에 공통으로 있는 주유소만 남겨, 정작 보고 싶은 "사라진·새로 생긴" 주유소가 빠지기 때문입니다.

*응용:* "작년 회원 중 올해 탈퇴한 사람 수"를 집합으로 구하려면?
→ `set(작년회원).difference(set(올해회원))`의 크기를 구하면 됩니다.

## 한 줄 정리

> 반복은 함수로 줄이고, 흩어진 표는 `merge`로 합친다. 그렇게 모은 데이터에 집합 연산을 더하면 "무엇이 사라지고 무엇이 생겼는지"가 숫자로 드러난다.
