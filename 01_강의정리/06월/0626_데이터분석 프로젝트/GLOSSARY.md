# 용어집 (GLOSSARY)

이번 강의에서 등장한 핵심 용어를 비전공자 눈높이로 정리했습니다.

| 용어 | 쉬운 설명 | 관련 강의명 | 함께 보면 좋은 개념 |
| ---- | --------- | ----------- | ----------- |
| 데이터 분석 워크플로우 | 불러오기 → 전처리 → 분석 → 시각화의 표준 4단계 흐름 | 01. 분석 프로젝트 흐름 | EDA, 데이터 파이프라인 |
| DataFrame | 행과 열로 된 표 형태의 데이터. pandas의 기본 단위 | 01·02 | pandas, Series |
| 라이브러리 | 미리 만들어진 기능 묶음(pandas, folium 등) | 01 | 함수, 패키지 |
| `read_csv` | CSV 파일을 표(DataFrame)로 읽어 들이는 함수 | 02 | DataFrame, 인코딩 |
| `info()` | 각 열의 자료형과 비어 있지 않은 값 개수를 보여주는 진단 도구 | 02 | describe, 결측치 |
| `describe()` | 숫자 열의 평균·최소·최대·사분위 등 요약 통계를 보여줌 | 02 | 기술통계, IQR |
| 결측치(Missing) | 값이 비어 있는 칸(NaN) | 02 | dropna, fillna |
| 이상치(Outlier) | 음수·0원처럼 말이 안 되는 극단값 | 02 | sort_values, 박스플롯 |
| 형 변환(Type Conversion) | 잘못 인식된 자료형을 올바르게 바꾸는 일(숫자↔날짜 등) | 02 | to_datetime, to_numeric |
| 데이터 정합성 | "당연히 이래야 한다"는 규칙이 지켜졌는지 점검하는 것 | 02 | nunique, groupby |
| `axis` | 방향 지정. 0=행(가로줄), 1=열(세로줄) | 02 | drop, 집계 |
| Feature Engineering | 원본에서 분석에 쓸 새 컬럼을 만드는 작업(예: 주소→시도) | 03 | apply, split |
| 함수화 | 반복 작업을 `def`로 묶어 재사용하는 것 | 03 | DRY 원칙, 반복문 |
| `groupby` | 같은 항목끼리 묶는 기능 | 03·04 | agg, pivot_table |
| `agg`(집계) | 묶음을 평균·합계 등 대표값 하나로 줄이는 것 | 03 | groupby, mean |
| `merge`(조인) | 공통 열을 기준으로 두 표를 옆으로 합치는 것 | 03 | concat, key |
| inner / outer join | 교집합만 남기기 / 한쪽에만 있어도 모두 남기기 | 03 | merge, NaN |
| 집합(set)·차집합 | 중복 없는 모음, 그리고 "A엔 있고 B엔 없는" 것 찾기 | 03 | 개폐업 분석, 이탈률 |
| EDA(탐색적 데이터 분석) | 그래프로 데이터를 살펴보며 질문을 만드는 단계 | 04 | 히스토그램, 박스플롯 |
| 히스토그램 | 값을 구간으로 나눠 개수를 막대로 그린 분포 그래프 | 04 | bins, 분포 |
| 박스플롯 | 중앙값·사분위·이상치를 한 번에 보여주는 그래프 | 04·05 | IQR, 이상치 |
| 산점도(scatter) | 두 값을 점으로 찍어 관계 모양을 보는 그래프 | 04 | 상관계수 |
| 상관계수 | 두 값이 함께 움직이는 정도(-1~1) | 04·05 | pearson, 인과관계 |
| `value_counts()` | 각 항목이 몇 번 나오는지 세는 기능 | 04 | groupby, 막대그래프 |
| `str.contains()` | 텍스트에 특정 단어가 들어 있는지 확인 | 04 | 문자열 패턴, 필터링 |
| 기술통계 | 데이터를 평균·중앙값·표준편차 등 숫자로 요약 | 05 | describe, 왜도 |
| 중앙값(Median) | 크기순으로 딱 가운데 있는 값. 극단값에 강함 | 05 | 평균, 왜도 |
| IQR | 가운데 50%의 폭(Q3−Q1). 퍼짐의 정도 | 05 | 박스플롯, 사분위 |
| 왜도(Skewness) | 분포가 한쪽으로 치우친 정도. 양수면 오른쪽 꼬리 | 05 | 평균, 중앙값 |
| ANOVA | 셋 이상 집단의 평균이 정말 다른지 검정 | 05 | F값, p값 |
| t검정 | 두 집단의 평균이 정말 다른지 검정 | 05 | p값, 효과크기 |
| p값 | 차이가 우연일 확률. 작을수록 "우연 아님" | 05 | 가설검정, 유의성 |
| 효과 크기(Cohen's d, η²) | 차이가 "얼마나 큰가"를 재는 값 | 05 | p값, 실용적 유의성 |
| 변동계수(CV) | 표준편차÷평균. 수준이 다른 집단의 흔들림을 공정 비교 | 05 | 표준편차, 안정성 |
| SCQA | 상황→복잡성→질문→답 순서의 분석 전달 구조 | 05 | 피라미드 원리 |
| 피라미드 원리 | 결론을 먼저, 근거를 그 아래 받치는 전달 방식 | 05 | SCQA |
| 정직한 시각화 | 축 조작·과장 없이 데이터를 솔직히 보여주는 원칙 | 05 | 불확실성 표시 |
| folium | 위도·경도를 인터랙티브 지도에 그리는 라이브러리 | 06 | CircleMarker, 좌표 |
| `CircleMarker` | 지도 위 좌표에 원형 점을 찍는 도구 | 06 | add_to, 인코딩 |
| 시각적 인코딩 | 색·크기에 데이터 값을 담아 한눈에 읽히게 하는 것 | 06 | 색상, 혼잡도 |
| 팝업(Popup) | 마커를 클릭하면 뜨는 상세 정보창(HTML) | 06 | CircleMarker |
| `zoom_start` | 지도 처음 확대 수준. 클수록 좁게, 작을수록 넓게 | 06 | folium.Map |
