# 인공지능과 머신러닝의 큰 그림
> 머신러닝을 배우기 전에 먼저 “AI가 무엇을 학습하고, 어떤 문제를 풀 수 있는지”를 구분해야 한다.

`인공지능` · `머신러닝` · `딥러닝` · `지도학습` · `비지도학습` · `강화학습` · `분류` · `회귀`

## 핵심요약

- 인공지능은 사람이 하던 판단, 인식, 추천, 검색 같은 지능적 작업을 수행하는 시스템이다.
- 머신러닝은 인공지능의 한 분야로, 사람이 모든 규칙을 직접 작성하지 않고 컴퓨터가 데이터에서 규칙을 학습하게 하는 방법이다.
- 딥러닝은 머신러닝 안에 포함되는 방법으로, 복잡한 패턴을 여러 층의 신경망으로 학습한다.
- 머신러닝은 크게 지도학습, 비지도학습, 강화학습으로 나눌 수 있다.
- 지도학습은 정답이 있는 데이터로 학습하며, 대표 문제는 분류와 회귀다.
- 비지도학습은 정답 없이 데이터의 구조를 찾는 방식이며, 군집화나 차원 축소가 대표적이다.
- 강화학습은 행동의 결과로 얻는 보상을 기준으로 더 나은 선택을 학습하는 방식이다.

## 인공지능

### 개념명

**1. 정의**  
인공지능은 사람이 지능적으로 처리한다고 여기는 문제를 컴퓨터가 수행하게 만드는 기술이다. 예를 들어 스팸 필터, 음성 검색, 얼굴 인식, 추천 시스템처럼 판단이나 분류가 필요한 작업에 사용된다.

**2. 왜 필요한가?**  
모든 경우의 수를 사람이 직접 규칙으로 만들기 어려운 문제가 많기 때문이다. 고객 추천, 이미지 판별, 이상 탐지처럼 패턴이 복잡한 문제는 데이터 기반 접근이 더 효과적이다.

**3. 예시**

```python
# 사람이라면 "이 고객은 구매 가능성이 높다"고 판단할 수 있다.
# 인공지능 시스템은 데이터를 이용해 이런 판단을 자동화한다.
customer = {
    "visit_count": 12,
    "cart_items": 3,
    "previous_purchase": 1
}
```

**4. 헷갈리기 쉬운 점**  
인공지능은 하나의 특정 알고리즘 이름이 아니다. 머신러닝, 딥러닝, 규칙 기반 시스템 등을 모두 포함할 수 있는 큰 범위의 개념이다.

**5. 한 줄 정리**  
인공지능은 사람이 하던 지능적 판단을 컴퓨터가 수행하게 만드는 큰 영역이다.

## 머신러닝

### 개념명

**1. 정의**  
머신러닝은 데이터를 학습해서 새로운 데이터에 대한 예측이나 판단을 하도록 만드는 기술이다. 기존 프로그래밍이 `Case1이면 Action1`처럼 규칙을 직접 쓰는 방식이라면, 머신러닝은 데이터에서 규칙을 찾아낸다.

**2. 왜 필요한가?**  
규칙을 사람이 일일이 정하기 어려운 문제에서 필요하다. 예를 들어 “이 문장이 스팸인지 아닌지”, “이 사용자가 어떤 콘텐츠를 좋아할지”, “이 승객이 생존했을지” 같은 문제는 데이터 패턴을 학습하는 방식이 적합하다.

**3. 예시**

```python
# 전통적 프로그래밍: 사람이 규칙을 직접 작성
if "무료" in message and "클릭" in message:
    result = "spam"

# 머신러닝: 여러 메시지와 정답을 보고 모델이 규칙을 학습
# 입력 데이터: 메일 제목, 발신자, 단어 빈도
# 정답 데이터: 스팸 여부
```

**4. 헷갈리기 쉬운 점**  
머신러닝은 무조건 정답을 만들어내는 마법이 아니다. 데이터가 편향되어 있거나 잘못 정리되어 있으면 모델도 잘못된 패턴을 학습한다.

**5. 한 줄 정리**  
머신러닝은 사람이 규칙을 직접 만드는 대신, 데이터로부터 규칙을 학습하는 방식이다.

## 머신러닝 문제 유형

### 지도학습

**1. 정의**  
정답이 있는 데이터로 학습하는 방식이다. 입력 데이터와 정답 레이블을 함께 제공해 모델이 둘 사이의 관계를 익힌다.

**2. 왜 필요한가?**  
예측하고 싶은 결과가 명확할 때 사용한다. 예를 들어 타이타닉 승객의 생존 여부, 고객 이탈 여부, 집값 같은 결과가 정해져 있으면 지도학습으로 접근할 수 있다.

**3. 예시**

```python
# 특성 데이터: 예측에 사용할 정보
X = [[3, 0, 22, 1, 0, 7.25],
     [1, 1, 38, 1, 0, 71.28]]

# 레이블 데이터: 정답
# 0 = 사망, 1 = 생존
y = [0, 1]
```

**4. 헷갈리기 쉬운 점**  
지도학습에서 “정답”은 사람이 보기에 절대 진리라는 뜻이 아니라, 모델이 학습할 기준값이라는 뜻이다.

**5. 한 줄 정리**  
지도학습은 문제집과 정답지를 같이 주고 공부시키는 방식이다.

### 분류와 회귀

**1. 정의**  
분류는 예측 결과가 범주일 때 사용한다. 생존/사망, 스팸/정상, 합격/불합격처럼 결과가 끊어진 값이다. 회귀는 예측 결과가 숫자일 때 사용한다. 가격, 매출, 온도처럼 연속적인 값을 예측한다.

**2. 왜 필요한가?**  
문제 유형에 따라 모델과 평가 방법이 달라지기 때문이다. 타이타닉 생존 여부는 분류 문제이고, 면적에 따른 땅 가격 예측은 회귀 문제다.

**3. 예시**

```python
# 분류 예시: 생존 여부 예측
survived = 1  # 생존

# 회귀 예시: 가격 예측
predicted_price = 23500.0
```

**4. 헷갈리기 쉬운 점**  
숫자로 표현되어도 범주일 수 있다. `survived = 0 또는 1`은 숫자처럼 보이지만, 실제 의미는 사망/생존이라는 범주다.

**5. 한 줄 정리**  
결과가 종류면 분류, 크기나 양이면 회귀다.

### 비지도학습과 강화학습

**1. 정의**  
비지도학습은 정답 없이 데이터의 구조나 묶음을 찾는 방식이다. 강화학습은 행동을 하고 보상을 받으며 더 좋은 행동 전략을 학습하는 방식이다.

**2. 왜 필요한가?**  
정답 레이블을 만들기 어려운 데이터도 많기 때문이다. 고객을 비슷한 그룹으로 나누거나, 사용자의 행동 패턴을 탐색할 때 비지도학습을 사용할 수 있다. 강화학습은 게임, 로봇 제어, 추천 정책처럼 행동의 선택이 중요한 문제에 사용된다.

**3. 예시**

```python
# 비지도학습 예시: 정답 없이 고객을 비슷한 그룹으로 나누기
customers = [
    [10, 2, 30000],
    [12, 3, 35000],
    [1, 0, 5000]
]

# 강화학습 예시: 행동과 보상
action = "recommend_coupon"
reward = 1  # 쿠폰 추천 후 구매 발생
```

**4. 헷갈리기 쉬운 점**  
비지도학습은 정답이 없다고 해서 아무 결과나 내는 것이 아니다. 데이터 안의 거리, 유사도, 밀도 같은 구조를 기준으로 패턴을 찾는다.

**5. 한 줄 정리**  
비지도학습은 정답 없는 데이터에서 구조를 찾고, 강화학습은 보상을 통해 행동 전략을 배운다.

## 코드로 보기 — 지도학습 데이터 구조

```python
import pandas as pd

train_data = pd.DataFrame({
    "pclass": [3, 1, 3],
    "sex": [0, 1, 1],
    "age": [22, 38, 26],
    "fare": [7.25, 71.2833, 7.9250],
    "survived": [0, 1, 1]
})

X = train_data[["pclass", "sex", "age", "fare"]]
y = train_data["survived"]

print(X)
print(y)
```

**코드목적**  
모델에 넣을 입력 데이터 `X`와 정답 데이터 `y`를 분리한다.

**해석**  
`X`는 승객 등급, 성별, 나이, 요금 같은 설명변수이고, `y`는 생존 여부라는 목표변수다.

**실무 연결**  
AI 서비스 기획에서도 “무엇을 보고 무엇을 예측할 것인가?”를 먼저 정의해야 한다. 이때 `X`와 `y`를 명확히 나누는 사고가 필요하다.
