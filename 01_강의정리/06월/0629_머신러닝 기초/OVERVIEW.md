# 머신러닝 기초 Overview
> 머신러닝은 “데이터를 보고 규칙을 학습한 뒤, 새로운 상황을 예측하거나 분류하는 과정”이다. 이번 정리는 머신러닝의 큰 그림부터 데이터 처리, 시각화, 타이타닉 생존 예측 모델까지 한 번에 이어지는 학습 로드맵이다.

## 학습 로드맵

```text
인공지능과 머신러닝 이해
        ↓
머신러닝 문제 유형 구분
지도학습 · 비지도학습 · 강화학습
        ↓
데이터를 다루는 기본 도구
NumPy · Pandas
        ↓
데이터를 눈으로 확인하는 도구
Matplotlib · Seaborn
        ↓
분류 모델 만들기
타이타닉 생존 분석 · 로지스틱 회귀
        ↓
모델 결과 해석
확률 · 임계값 · 정확도 · 혼동 행렬 · 오즈비
```

## 다루는 핵심 개념

- 인공지능, 머신러닝, 딥러닝의 포함 관계
- 지도학습, 비지도학습, 강화학습
- 분류와 회귀의 차이
- NumPy 배열, shape, size, dtype, reshape, slicing, concatenate
- Pandas Series, DataFrame, index, columns, loc, iloc, drop, sort_values
- Matplotlib 기본 그래프와 figure/subplot 구조
- Seaborn의 regplot, countplot, jointplot
- 타이타닉 데이터셋의 EDA와 전처리
- 로지스틱 회귀, 시그모이드 함수, 예측 확률, 임계값
- 정확도, 혼동 행렬, 정밀도, 재현율, F1-score
- 회귀계수, 오즈비, 모델 계수 저장

## 이번 학습의 핵심 흐름

머신러닝을 처음 배울 때 가장 중요한 것은 알고리즘 이름을 많이 외우는 것이 아니라, “데이터가 어떤 형태로 들어오고, 어떤 문제를 풀며, 결과를 어떻게 해석하는지”를 이해하는 것이다. 이번 흐름은 이론 → 라이브러리 → 시각화 → 모델링 → 평가 순서로 구성되어 있어, 하나의 작은 분석 프로젝트를 완성하는 방식으로 머신러닝 기초를 익힐 수 있다.

## 학습 후 할 수 있어야 하는 것

- AI, 머신러닝, 딥러닝의 차이를 설명할 수 있다.
- 지도학습 문제를 분류와 회귀로 나눌 수 있다.
- NumPy 배열과 Pandas DataFrame의 역할 차이를 설명할 수 있다.
- 데이터의 분포와 관계를 그래프로 확인할 수 있다.
- 타이타닉 데이터에서 결측치 처리와 범주형 인코딩을 할 수 있다.
- 로지스틱 회귀 모델이 “0 또는 1”을 바로 예측하는 것이 아니라 “1일 확률”을 예측한다는 점을 설명할 수 있다.
- 정확도뿐 아니라 혼동 행렬, 정밀도, 재현율로 모델 결과를 해석할 수 있다.
