# 함수와 메서드 — 코드를 기능 단위로 묶는 첫걸음

> 같은 일을 하는 코드를 매번 복사하고 있나요? 그럴 때 등장하는 게 '함수'입니다. 그리고 `len(x)`와 `x.append()`는 비슷해 보이지만 사실 다른 종류라는 것, 알고 계셨나요?

`함수` `메서드` `def` `return` `매개변수` `내장함수` `사용자정의함수`

## 핵심요약

- 함수는 **특정 기능을 수행하는 코드들의 모임**이다. 라면 끓이는 여러 단계를 "라면 끓이기" 하나로 묶는 것과 같다.
- 프로그래밍의 기본 틀은 **입력 → 작용(기능) → 출력**이고, 함수가 바로 이 "작용" 덩어리다.
- 함수는 크게 두 종류: 파이썬이 미리 만들어 둔 **내장 함수**(`len`, `int`, `str`, `max`, `sum` 등)와 내가 직접 만드는 **사용자 정의 함수**.
- 함수는 `def`로 정의하고, **매개변수로 값을 받아**, **`return`으로 값을 돌려준다.**
- `return`이 없으면 함수 밖에서는 결과를 알 수 없다. 출력(`print`)과 반환(`return`)은 전혀 다른 동작이다.
- **메서드**는 함수의 친척이지만, **특정 자료 뒤에 점(`.`)을 찍어 그 자료에 대해 작동**하는 코드다.

---

## 개념별 정리

### 함수(Function)

**1. 정의**
특정 기능을 수행하는 코드(들)의 모임이다. 여러 줄짜리 작업을 이름 하나로 묶어 두고, 필요할 때마다 그 이름을 불러 쓴다.

**2. 왜 필요한가?**
같은 코드를 반복해서 쓰지 않기 위해서다. 한 번 잘 만들어 두면 어디서든 호출해 재사용할 수 있고, 코드를 고칠 때도 한 곳만 고치면 된다. 실무에서는 "데이터 전처리", "매출 합계 계산"처럼 반복되는 작업을 함수로 묶어 둔다.

**3. 예시**

```python
def plusDouble(a, b):
    c = a + b
    return 2 * c

print(plusDouble(3, 4))   # (3+4) * 2
```

실행 결과:
```
14
```

**4. 헷갈리기 쉬운 점**
함수를 "정의"하는 것과 "호출"하는 것은 다르다. `def plusDouble(...)`는 레시피를 적어 둔 것일 뿐, 실제로 요리(실행)되는 건 `plusDouble(3, 4)`처럼 불렀을 때다.

**5. 한 줄 정리**
함수는 반복되는 작업에 이름을 붙여 재사용하는 "코드 묶음"이다.

> 비유: 함수는 **라면 레시피**다. "냄비 올리기 → 불 켜기 → 물 550mL 붓기 …"를 매번 설명하는 대신 "라면 끓이기"라고만 하면 된다.

### 내장 함수(Built-in Function)

**1. 정의**
파이썬 개발자들이 미리 만들어 둔, 바로 가져다 쓸 수 있는 함수들이다.

**2. 왜 필요한가?**
자주 쓰는 기능을 매번 직접 구현할 필요가 없게 해 준다.

**3. 예시**

```python
my_list = ["a", "b", "c"]
print(len(my_list))        # 자료의 길이

print(max((1, 2, 3, 4, 5)))  # 최댓값
print(min([1, 2, 3, 4, 5]))  # 최솟값
print(sum((1, 2, 3, 4, 5)))  # 합계
print(len("Hello World!!"))  # 문자열 길이
```

실행 결과:
```
3
5
1
15
13
```

`int()`, `str()`처럼 자료형을 바꿔 주는 변환 함수도 내장 함수다.

```python
my_data = "1234"
print(type(int(my_data)))   # 문자열 "1234" → 정수 1234
my_number = 5678
print(type(str(my_number))) # 정수 5678 → 문자열 "5678"
```

실행 결과:
```
<class 'int'>
<class 'str'>
```

**4. 헷갈리기 쉬운 점**
`int("1234")`는 새 값을 만들어 돌려줄 뿐, 원래 변수 `my_data`를 바꾸지는 않는다.

**5. 한 줄 정리**
내장 함수는 "이미 만들어진 도구상자"라서 `import` 없이 바로 쓸 수 있다.

### 사용자 정의 함수와 `return`

**1. 정의**
내가 여러 코드를 묶어 새로 만든 함수다. `def 함수이름(매개변수):` 형태로 정의하고, 내부 명령은 같은 들여쓰기로 작성하며, `return`으로 결과를 밖으로 내보낸다.

**2. 왜 필요한가?**
함수 내부에서 일어난 일은 함수 밖에서 알 수 없다. 계산 결과를 함수 밖에서 쓰려면 반드시 `return`으로 "전달"해야 한다.

**3. 예시 — `return`이 있을 때와 없을 때**

```python
# return이 없는 버전
def formula(a, b):
    c = (a**2) + (b**2)
    print("return :", c)

result = formula(2, 4)
print("result :", result)
```

실행 결과:
```
return : 20
result : None
```

```python
# return이 있는 버전
def formula(a, b):
    c = (a**2) + (b**2)
    return c

result = formula(2, 4)
print("result :", result)
```

실행 결과:
```
result : 20
```

**4. 헷갈리기 쉬운 점**
`print`는 화면에 보여 줄 뿐이고, `return`은 값을 "들고 나가는" 것이다. `print`만 한 함수는 밖에서 받으면 `None`이 된다. 초보자가 가장 많이 헷갈리는 지점이다.

**5. 한 줄 정리**
함수의 결과를 밖에서 쓰려면 `print`가 아니라 `return`이 필요하다.

> 비유: `print`는 "혼잣말로 답을 말하는 것", `return`은 "답을 적은 쪽지를 건네주는 것". 쪽지를 받아야 다음 사람이 그 값을 쓸 수 있다.

### 메서드(Method)

**1. 정의**
특정 자료에 대해 특정 기능을 하는 코드다. `자료.기능()` 형태로, 자료 뒤에 점을 찍어 사용한다.

**2. 왜 필요한가?**
어떤 기능은 특정 자료와 떼어놓고 생각할 수 없다. "리스트에 값 추가하기"는 그 리스트가 있어야 의미가 있다. 그래서 자료에 붙여 쓰는 형태가 자연스럽다.

**3. 예시**

```python
my_list = [1, 2, 3]
my_list.append(4)   # 리스트 끝에 4 추가
my_list.count(2)    # 2가 몇 번 나오는지 세기
my_list.pop()       # 마지막 원소 꺼내기
```

**4. 헷갈리기 쉬운 점**
`len(my_list)`(함수)와 `my_list.append(4)`(메서드)의 차이. 함수는 자료를 **괄호 안에 넣어 전달**하고, 메서드는 자료 **뒤에 점을 찍어** 호출한다.

**5. 한 줄 정리**
메서드는 "그 자료 전용 기능"이라서 자료에 점을 찍어 부른다.

## 코드로 보기 — 함수 vs 메서드

```python
my_list = [1, 2, 3]

# 함수: 자료를 괄호 안에 전달
len(my_list)
sum(my_list)
min(my_list)

# 메서드: 자료 뒤에 .을 찍어 사용
my_list.append(4)
my_list.count(2)
my_list.pop()
```

**코드목적**
같은 리스트를 두 가지 방식으로 다루며, 함수 호출과 메서드 호출의 생김새 차이를 비교한다.

**해석**
`len(my_list)`는 "이 자료를 도구에 넣어 처리"하는 모양이고, `my_list.append(4)`는 "이 자료에게 기능을 시키는" 모양이다. 결과적으로 둘 다 자료를 다루지만, 호출 형태(괄호 vs 점)가 다르다.

**실무 연결**
데이터 분석에서 `df.head()`, `df.groupby()` 같은 건 전부 메서드다. 판다스(pandas) 같은 라이브러리를 다룰 때 "이건 함수일까 메서드일까?"를 구분하면 문서를 읽고 코드를 짜기가 훨씬 수월해진다.

## 헷갈리기 쉬운 포인트

- **함수 vs 메서드**: `함수(자료)` vs `자료.메서드()`. 괄호 안에 넣으면 함수, 점 찍고 부르면 메서드.
- **print vs return**: 화면 출력 vs 값 전달. `return` 없는 함수의 결과를 받으면 `None`.
- **정의 vs 호출**: `def`로 적어 두는 것(정의)과 이름을 불러 실행하는 것(호출)은 별개.

**복습 질문 및 답변**

- (기본) 함수란 무엇인가?
  → 특정 기능을 수행하는 코드들의 모임으로, 이름을 붙여 재사용한다.
- (이해 확인) `return`이 없는 함수의 결과를 변수에 담으면 무엇이 들어가나?
  → `None`이 들어간다. 함수가 값을 밖으로 전달하지 않았기 때문이다.
- (응용) `my_list.sort()`는 함수일까 메서드일까? 그 이유는?
  → 메서드다. `my_list`라는 자료 뒤에 점을 찍어 그 리스트에 대해 작동하기 때문이다.

## 한 줄 정리

> 함수는 기능을 묶어 재사용하는 코드 덩어리이고, 그 결과를 밖에서 쓰려면 `return`이 필요하며, 메서드는 특정 자료에 점을 찍어 부르는 "그 자료 전용 함수"다.
