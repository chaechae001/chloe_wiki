# 모듈과 패키지 — 코드를 파일과 폴더로 나누어 관리하기

> 코드가 수백 줄이 되면 한 파일에 다 넣기가 힘들어집니다. 그리고 남이 만들어 둔 좋은 기능을 굳이 다시 만들 필요도 없죠. 이때 등장하는 게 모듈입니다.

`모듈` `module` `import` `from import` `패키지` `package` `random` `math` `__name__` `__main__`

## 핵심요약

- **모듈**은 특정 목적을 가진 함수와 자료(변수)들의 모임으로, 보통 하나의 `.py` 파일이다.
- `import 모듈명`으로 불러오고, `모듈명.함수()`처럼 점을 찍어 그 안의 기능을 쓴다.
- 표준 모듈 예: `math`(수학 연산), `random`(난수). 모듈 사용법은 공식 문서·검색·생성형 AI로 확인하되 **결과는 반드시 검증**한다.
- 내가 만든 `.py` 파일도 모듈이 된다(`import cal` → `cal.plus(...)`).
- **패키지**는 모듈을 폴더(디렉터리)로 묶어 관리하는 것이다. `import 폴더.모듈` 또는 `from 폴더.모듈 import 함수`로 쓴다.
- 파이썬은 파일 실행 시 **모든 코드를 위에서부터** 실행한다. 그래서 "직접 실행할 때만 동작할 코드"는 `if __name__ == "__main__":` 안에 둔다.

---

## 개념별 정리

### 모듈(Module)

**1. 정의**
특정 목적을 가진 함수와 자료의 모임이다. 보통 `.py` 파일 하나가 모듈 하나다.

**2. 왜 필요한가?**
코드가 길어지면 모든 함수·변수를 직접 구현하기 어렵다. 누군가 잘 만들어 둔 기능을 가져다 쓰면 빠르고 안정적이다.

**3. 예시**

```python
import random
# random이라는 모듈 불러오기

print(random.randrange(0, 2))   # 0 이상 2 미만의 무작위 정수
```

실행 결과(매번 달라질 수 있음):
```
1
```

> 비유: 모듈은 "라면 끓이기" 같은 기능 묶음이다. 스프 양(`5`), 물의 양(`550`), 끓이는 함수(`ku_ramen()`, `sok_ramen()`)처럼 관련된 자료와 함수를 한 묶음으로 담는다.

**4. 헷갈리기 쉬운 점**
`import random` 후 그냥 `randrange(...)`라고 쓰면 안 되고 `random.randrange(...)`처럼 모듈명을 앞에 붙여야 한다(아래 `from ~ import`는 예외).

**5. 한 줄 정리**
모듈은 관련 함수·자료를 담은 `.py` 묶음이고, `import`로 불러 점을 찍어 쓴다.

### 모듈 사용법 — 표준 모듈 예

**1. 정의**
파이썬이 기본 제공하는 모듈들이다. 대표적으로 `math`, `random`.

**2. 왜 필요한가?**
수학 상수·연산, 난수 생성처럼 자주 쓰는 기능을 직접 만들 필요가 없다.

**3. 예시**

```python
import math
print(math.pi)   # 원주율
print(math.e)    # 자연상수
```

실행 결과:
```
3.141592...
2.718281...
```

```python
import random
print(random.randrange(1, 11))   # 1 이상 11 미만 중 무작위 하나
```

실행 결과(매번 달라질 수 있음):
```
8
```

**4. 헷갈리기 쉬운 점**
`random.randrange(1, 11)`은 11을 **포함하지 않는다**(1~10). "a 이상 b 미만"이 기본이다.

**5. 한 줄 정리**
사용법이 헷갈리면 공식 문서·검색·생성형 AI로 확인하되, 답은 직접 실행해 검증한다.

### 모듈 만들기 — 내 파일을 import 하기

**1. 정의**
내가 만든 `.py` 파일도 모듈로 불러 쓸 수 있다.

**2. 왜 필요한가?**
프로젝트가 커지면 기능별로 파일을 나누고 서로 불러 쓰는 게 관리에 유리하다.

**3. 예시**

```python
# cal.py
def plus(a, b):
    c = a + b
    return c
```

```python
# main.py
import cal
print(cal.plus(3, 4))
```

실행 결과:
```
7
```

**4. 헷갈리기 쉬운 점**
`import cal`에서 `cal`은 파일명(`cal.py`)이지 함수명이 아니다. 함수는 `cal.plus(...)`로 모듈명을 통해 접근한다.

**5. 한 줄 정리**
내 `.py` 파일도 `import`로 불러 그 안의 함수를 재사용할 수 있다.

### 패키지(Package)

**1. 정의**
모듈을 폴더(디렉터리)로 구분해 관리하는 것이다.

**2. 왜 필요한가?**
모듈이 많아지면 한 폴더에 쏟아 두기보다 `script`, `sound`, `audio`처럼 성격별 폴더로 나누는 게 관리하기 좋다.

**3. 예시 — 두 가지 import 방법**

폴더 구조: `user/` 안에 `cal.py`, 그 안에 함수 `plus()`.

```python
# 방법 1: 폴더.모듈을 불러와서 모듈명으로 호출
import user.cal
print(cal.plus(3, 4))   # 7
```

```python
# 방법 2: from ~ import → 함수 사용 시 점(.) 불필요
from user.cal import plus
print(plus(3, 4))       # 7
```

**4. 헷갈리기 쉬운 점**
`import`는 "어디까지 불러왔느냐"에 따라 호출 형태가 달라진다. `from ~ import 함수`로 가져오면 함수를 점 없이 바로 쓸 수 있다.

**5. 한 줄 정리**
패키지는 모듈을 폴더로 묶은 것이고, `from 폴더.모듈 import 함수`로 가져오면 점 없이 함수를 쓸 수 있다.

> 비유: 모듈이 '서류 파일'이라면, 패키지는 그 파일들을 종류별로 넣어 둔 '서랍/캐비닛'이다.

### `if __name__ == "__main__"` — 실행 시작점 지정

**1. 정의**
"이 파일을 직접 실행할 때만 이 코드를 동작시켜라"라고 지정하는 구문이다.

**2. 왜 필요한가?**
C·Java 같은 언어는 `main` 함수에서 시작해 시작점이 분명하지만, 파이썬은 파일을 실행하면 **들여쓰기 안 된 모든 코드를 위에서부터** 실행한다. 그래서 다른 파일에서 `import`만 해도 의도치 않은 코드(예: 테스트용 `print`)가 실행될 수 있다.

**3. 예시 — 문제 상황과 해결**

```python
# cal.py
def plus(a, b):
    c = a + b
    return c

def sub(a, b):
    c = a - b
    return c

print(plus(1, 5))   # 이게 import만 해도 실행됨
print(sub(5, 1))
```

```python
# main.py
import cal
```

`main.py`를 실행하면 `cal.py`의 `print`들이 실행되어 `6`, `4`가 출력된다. 의도치 않은 결과다. 해결:

```python
# cal.py
def plus(a, b):
    c = a + b
    return c

def sub(a, b):
    c = a - b
    return c

if __name__ == "__main__":   # cal.py를 '직접' 실행할 때만 동작
    print(plus(1, 5))
    print(sub(5, 1))
```

이제 `main.py`에서 `import cal`만 하면 **아무것도 출력되지 않는다.** `print`들이 "직접 실행 전용" 블록 안으로 들어갔기 때문이다.

**4. 헷갈리기 쉬운 점**
`__name__`은 파일을 직접 실행하면 `"__main__"`이 되고, 다른 곳에서 import되면 모듈 이름이 된다. 그래서 이 조건이 "직접 실행했는지"를 가른다.

**5. 한 줄 정리**
`if __name__ == "__main__":`은 "이 파일을 직접 돌릴 때만 실행할 코드"를 담는 시작점 표시다.

## 코드로 보기 — 실행 순서 따라가기

```python
import sys

def sum(a, b):
    c = a + b
    return c

def main():
    print("3 더하기 6은?")
    result = sum(3, 6)
    print(result)

if __name__ == "__main__":
    sys.exit(main())
```

**코드목적**
프로그램의 시작점을 `if __name__ == "__main__":`으로 명확히 하고, `main()`에서 흐름을 시작해 `sum()`을 호출한다. (`sys.exit()`는 프로그램을 종료하며 오류 발생 여부를 알려 주는 함수다.)

**해석**
실행 순서는 ① `main` 함수 호출 → ② `main` 실행("3 더하기 6은?" 출력) → ③ `sum(3, 6)` 호출·계산 후 9 반환 → 출력. 즉 함수는 **호출되어야** 실행된다. 결과:
```
3 더하기 6은?
9
```

**실무 연결**
스크립트를 "직접 실행용"과 "import해서 가져다 쓰는 용"으로 동시에 만들 때 필수다. 라이브러리 코드와 실행 코드를 분리해 두면, 같은 파일을 다른 프로젝트에서 안전하게 재사용할 수 있다.

## 헷갈리기 쉬운 포인트

- **import vs from import**: `import m` 후엔 `m.func()`, `from m import func` 후엔 `func()`로 점 없이 사용.
- **파일 실행 = 전체 실행**: 파이썬은 들여쓰기 안 된 코드를 모두 실행하므로, 직접 실행 전용 코드는 `if __name__ == "__main__":`으로 분리.
- **randrange 범위**: `randrange(a, b)`는 b 미만(b 불포함)이다.

- [ ] 모듈을 `import`하고 그 안의 함수를 호출할 수 있다.
- [ ] `import`와 `from ~ import`의 호출 형태 차이를 안다.
- [ ] 패키지가 무엇인지(폴더로 묶은 모듈) 설명할 수 있다.
- [ ] 파이썬이 파일 실행 시 전체 코드를 실행한다는 점을 안다.
- [ ] `if __name__ == "__main__":`을 왜 쓰는지 설명할 수 있다.

## 한 줄 정리

> 모듈은 함수·자료를 담은 `.py` 묶음이고 패키지는 그 모듈들을 폴더로 묶은 것이며, 파이썬은 파일을 통째로 실행하므로 직접 실행 전용 코드는 `if __name__ == "__main__":`으로 분리한다.
