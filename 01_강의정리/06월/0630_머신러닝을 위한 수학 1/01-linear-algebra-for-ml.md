# 선형대수학, 머신러닝의 언어

> 추천 시스템은 어떻게 "이 영화 별점 4.6점 줄 것 같아요"를 맞출까요? 고화질 이미지는 어떻게 화질을 거의 잃지 않고 절반 크기로 줄어들까요? 그 비밀은 모두 **벡터와 행렬의 곱셈** 한 줄에 있습니다.

`선형대수학` · `벡터` · `행렬` · `차원축소` · `PCA` · `SVD` · `추천시스템` · `신경망`

## 핵심요약

- 머신러닝/딥러닝이 다루는 데이터는 결국 **벡터(숫자의 나열)** 와 **행렬(숫자의 표)** 로 표현된다.
- 문장은 단어 등장 여부를 0/1로 적은 벡터(Bag-of-Words)로, 이미지는 픽셀 밝기를 담은 행렬로 바꿀 수 있다.
- 신경망의 한 층은 `u = Wx + b` 라는 **행렬-벡터 곱 + 덧셈** 한 줄로 표현된다.
- 추천 시스템은 "사용자 성향 행렬 × 콘텐츠 성분 행렬"의 곱으로 예상 선호도를 계산한다.
- 변수가 수백 개로 늘어나면(고차원) 저장·연산 비용이 폭증하는데, **PCA/SVD** 로 핵심만 남겨 차원을 줄인다.
- 차원 축소는 단순한 수학 기교가 아니라 **저장 비용 절감·연산 속도 향상**이라는 비즈니스 효과로 직결된다.
- 그래서 선형대수는 외워야 할 공식 모음이 아니라, **데이터를 다루는 공통 언어**다.

---

## 개념별 정리

### 데이터를 벡터로 표현하기 (Bag-of-Words)

**1. 정의**
문장이나 데이터를 "고정된 길이의 숫자 나열"로 바꾼 것이 벡터입니다. 가장 단순한 방법은 전체 단어 목록을 정해두고, 각 단어가 문장에 있으면 1, 없으면 0을 적는 것입니다.

**2. 왜 필요한가?**
컴퓨터는 "사랑"이라는 글자를 직접 이해하지 못합니다. 모든 것을 숫자로 바꿔야 계산할 수 있죠. 텍스트를 숫자 벡터로 바꿔야 검색·분류·유사도 비교 같은 작업이 가능해집니다. 자연어 처리(NLP)의 출발점입니다.

**3. 예시**
"I love machine learning"과 "I love deep learning"을 같은 단어 목록 `[I, love, machine, learning]` 기준으로 표현하면:

```python
import numpy as np

vocab = ['"I"', '"love"', '"machine"', '"learning"']
sent1 = np.array([1, 1, 1, 1])   # "I love machine learning"
sent2 = np.array([1, 1, 0, 1])   # "I love deep learning" → machine만 0
```

두 문장은 'machine' 자리에서만 값이 다릅니다(1 vs 0). 이렇게 숫자로 바꾸면 "두 문장이 얼마나 비슷한가"를 계산으로 따질 수 있습니다.

**4. 헷갈리기 쉬운 점**
벡터의 "차원"은 어렵고 추상적인 개념이 아니라, 그냥 **숫자의 개수**입니다. 단어가 4개면 4차원 벡터(`R⁴`)입니다. 단어가 만 개면 만 차원이 되는 것뿐입니다.

**5. 한 줄 정리**
벡터는 "데이터를 숫자 줄로 바꾼 것"이고, 차원은 그 줄의 길이다.
> 🍞 비유: 설문지의 객관식 답안을 0/1 체크박스로 적은 한 줄 — 그게 벡터입니다.

---

### 데이터를 행렬로 표현하기 (이미지)

**1. 정의**
행렬은 숫자를 직사각형(행 × 열)으로 배열한 표입니다. 이미지는 각 픽셀의 밝기 값을 담은 행렬로 표현됩니다.

**2. 왜 필요한가?**
컬러 이미지 한 장은 빨강(R)·초록(G)·파랑(B) 세 장의 밝기 표(행렬)가 겹쳐진 것입니다. 이걸 행렬로 다뤄야 압축·필터·딥러닝 입력이 가능합니다.

**3. 예시**
45×40 크기의 RGB 이미지는 `(45, 40, 3)` 모양이고, 1차원으로 펼치면(flatten) 45×40×3 = 5400개의 숫자가 됩니다.

```python
np.random.seed(42)
img_rgb = np.random.randint(80, 256, (45, 40, 3), dtype=np.uint8)  # 45×40 RGB

print(f'이미지 shape: {img_rgb.shape}')               # (45, 40, 3)
print(f'Flatten 벡터 크기: {img_rgb.flatten().shape[0]}')  # 5400
```

**4. 헷갈리기 쉬운 점**
벡터(1차원), 행렬(2차원), 텐서(3차원 이상)는 "차원의 개수"가 다를 뿐 본질은 같은 숫자 묶음입니다. 컬러 이미지는 (높이×너비×채널) 3차원이라 정확히는 **텐서**입니다.

**5. 한 줄 정리**
이미지·표·이미지묶음은 모두 행렬(또는 텐서)이라는 같은 그릇에 담긴다.
> 🍞 비유: 엑셀 시트 한 장이 행렬, 여러 시트가 겹쳐진 통합 문서가 텐서입니다.

---

### 모델을 행렬로 표현하기 (신경망 한 층)

**1. 정의**
신경망의 한 층은 입력 벡터 `x`에 가중치 행렬 `W`를 곱하고 편향 `b`를 더한 뒤, 활성화 함수 `f`를 통과시키는 계산입니다.

$$\mathbf{u} = W\mathbf{x} + \mathbf{b}, \qquad \mathbf{y} = f(\mathbf{u})$$

**2. 왜 필요한가?**
수백 개의 뉴런 계산을 일일이 쓰면 끝이 없습니다. 행렬-벡터 곱 한 줄로 묶으면 코드도 짧아지고, GPU가 한 번에 빠르게 계산할 수 있습니다.

**3. 예시**
입력 3개 → 출력 4개인 층을 계산하고, 음수를 0으로 만드는 ReLU를 적용합니다.

```python
np.random.seed(0)
x_input = np.array([[1.0], [0.5], [-0.3]])      # 입력 (3×1)
W = np.random.randn(4, 3).round(2)              # 가중치 (4×3)
b = np.random.randn(4, 1).round(2)              # 편향 (4×1)

u = W @ x_input + b          # 선형 결합 Wx + b
y_relu = np.maximum(0, u)    # ReLU: 음수는 0, 양수는 그대로
```

**4. 헷갈리기 쉬운 점**
`W @ x`(행렬 곱)와 `W * x`(성분별 곱)는 완전히 다릅니다. 신경망에서 쓰는 건 `@`(행렬 곱)입니다. 활성화 함수(ReLU 등)는 "비선형성"을 넣어 모델이 복잡한 패턴도 배우게 해주는 장치입니다.

**5. 한 줄 정리**
신경망 한 층 = `Wx + b` 라는 행렬 연산 한 줄 + 활성화 함수.
> 🍞 비유: 여러 재료(입력)에 각자 다른 가중치를 곱해 섞고(`Wx`), 기본 간(`b`)을 더한 뒤, 맛을 보정(활성화)하는 요리 과정입니다.

### 차원 축소 (PCA·SVD)

**1. 정의**
수백 개의 변수(차원)를 핵심 정보는 최대한 지키면서 몇 개로 줄이는 기술입니다. 대표적으로 **PCA(주성분 분석)** 와 **SVD(특이값 분해)** 가 있습니다.

**2. 왜 필요한가?**
변수가 많아질수록 저장 공간과 연산 시간이 폭증합니다(고차원의 저주). 또 변수가 너무 많으면 시각화도 분석도 어렵습니다. PCA/SVD는 "정보가 가장 많이 담긴 방향"만 골라 차원을 줄여, 비용은 낮추고 본질은 지킵니다.

**3. 예시 — 이미지 압축의 비즈니스 효과**
고해상도 이미지에 SVD를 적용해 상위 50개 성분만 남기면, 화질은 거의 그대로인데 저장 용량은 절반 가까이 줄어듭니다. 실제 실행 결과 요약:

```text
[1] 분산 보존율(정보량): 98.43% 유지 (화질 손상 거의 없음)
[2] 저장 용량: 786,432 Bytes → 358,600 Bytes  (약 54.4% 절감)
[3] 연산 속도: 78.62 ms → 38.54 ms  (약 2.0배 향상)
[4] 통계 검정(Wilcoxon): p-value 2.22e-14, 효과크기 r = 0.75
```

정보의 98%를 지키면서 저장 비용은 절반, 연산 속도는 2배 — 이것이 차원 축소가 "수학"이 아니라 "비즈니스 의사결정"인 이유입니다.

**4. 헷갈리기 쉬운 점**
차원 축소는 데이터를 "버리는" 게 아니라 "겹치거나 덜 중요한 정보를 압축"하는 것입니다. PCA는 보통 데이터를 표준화(평균 0, 분산 1)한 뒤 적용하며, 이를 건너뛰면 결과가 왜곡됩니다.

**5. 한 줄 정리**
PCA/SVD는 "정보는 지키고 크기는 줄이는" 압축 도구다.
> 🍞 비유: 1시간짜리 회의를 핵심 5줄 요약으로 줄이는 것 — 다 적지 않아도 중요한 내용은 남습니다.

## 코드로 보기 — 추천 시스템의 별점 예측

영화 추천이 어떻게 작동하는지, 행렬 곱셈 단 한 줄로 직접 확인해 봅니다.

```python
import numpy as np

# 유저 성향 행렬 U (행: 사람, 열: [액션 선호, 로맨스 선호])
U = np.array([
    [5, 1],   # 철수: 액션 5, 로맨스 1
    [1, 5],   # 영희: 액션 1, 로맨스 5
    [4, 4],   # 민수: 액션 4, 로맨스 4
])

# 영화 성분 행렬 V_T (행: [액션 성분, 로맨스 성분], 열: 영화)
V_T = np.array([
    [1.0, 0.0, 0.9],   # 액션 성분 비중
    [0.0, 1.0, 0.1],   # 로맨스 성분 비중
])

predicted_ratings = U @ V_T   # 선형대수 행렬 곱
print(predicted_ratings)
```

실행 결과:

```text
[[5.  1.  4.6]
 [1.  5.  1.4]
 [4.  4.  4. ]]
```

**코드목적**
"누가(유저 성향)"와 "무엇이(영화 성분)"를 각각 행렬로 표현한 뒤, 둘을 곱해 **모든 사람 × 모든 영화의 예상 별점**을 한 번에 계산합니다.

**해석**
결과 행렬의 (행, 열)은 "그 사람이 그 영화에 줄 예상 별점"입니다. 액션을 좋아하는 철수(첫 행)는 액션 영화 'Die Hard'에 5점, 액션+약간 로맨스인 'Terminator'에 4.6점을 줍니다. 로맨스를 좋아하는 영희(둘째 행)는 'Titanic'에 5점을 줍니다. 사람의 취향과 콘텐츠의 성분이 잘 맞을수록 점수가 높게 나옵니다.

**실무 연결**
넷플릭스·유튜브·쇼핑몰의 추천 엔진이 바로 이 구조입니다. 실제로는 사용자의 클릭·시청·구매 기록에서 성향 행렬과 성분 행렬을 자동으로 학습(SVD/행렬 분해)한 뒤, 곱셈으로 "아직 안 본 콘텐츠의 예상 선호도"를 계산해 추천 목록을 만듭니다.

2. 새로운 사용자 "지수"가 액션 0, 로맨스 5라면, 세 영화에 대한 예상 별점은 각각 얼마일까요? 손으로 계산해 보세요.

<details>
<summary>정답 보기</summary>

1. 행렬 곱 `(m×r) @ (r×n) = (m×n)`. `U`는 3×2, `V_T`는 2×3이므로 가운데 2가 맞아떨어지고 결과는 3×3.

3. 단어 목록 `[I, love, machine, learning]` 기준이라면 'machine' 자리 1개가 다릅니다(1 vs 0).

## 헷갈리기 쉬운 포인트

- **벡터 vs 행렬 vs 텐서**: 1차원 줄(벡터) / 2차원 표(행렬) / 3차원 이상 묶음(텐서). 본질은 모두 숫자 묶음.
- **`@` vs `*`**: `@`는 행렬 곱(내적 규칙), `*`는 같은 위치끼리 성분별 곱. 신경망·추천은 `@`.
- **차원 = 어려운 개념 vs 차원 = 숫자 개수**: 후자가 맞습니다. 100차원은 그냥 숫자 100개짜리 줄.

## 한 줄 정리

> 선형대수는 데이터를 벡터·행렬로 바꿔 곱하고 분해하는 머신러닝의 공통 언어이며, 추천·압축·신경망이 모두 이 언어로 쓰여 있다.
