# 연립방정식과 가우스 소거법

> "예산은 9백만 원, 가용 시간은 80시간. 광고 채널 A와 B에 각각 몇 번씩 집행해야 둘 다 정확히 소진할까?" 이런 **제약 속 최적 배분** 문제는 결국 연립방정식 하나로 정리되고, 행렬로 깔끔하게 풀립니다.

`연립방정식` · `Ax=b` · `가우스소거법` · `가우스조던소거법` · `첨가행렬` · `후진대입` · `자원배분` · `최적해`

## 핵심요약

- 연립 일차 방정식은 행렬 형태 `Ax = b` 로 표현할 수 있다.
- 계수행렬 `A` 와 상수 `b` 를 한데 붙인 것을 **첨가행렬 `[A|b]`** 라 한다.
- **가우스 소거법**: 첨가행렬을 상삼각행렬로 만든 뒤 **후진 대입**으로 해를 구한다.
- **가우스-조던 소거법**: 단위행렬(RREF)까지 만들어 해를 **직접 읽어낸다**.
- 두 직선(또는 평면)이 만나는 **교점**이 곧 연립방정식의 해다.
- 비즈니스에서 연립방정식을 푸는 것은 "여러 제약 속 최적 자원 배분(황금비율)을 찾는 일"이다.
- `numpy.linalg.solve(A, b)` 한 줄로도 해를 구할 수 있다.

---

## 개념별 정리

### 연립방정식을 행렬로 — Ax = b

**1. 정의**
여러 개의 일차 방정식을 동시에 만족하는 해를 찾는 것이 연립방정식입니다. 미지수의 계수를 모아 행렬 `A`, 미지수를 벡터 `x`, 우변 상수를 벡터 `b` 로 두면 `Ax = b` 한 줄로 표현됩니다.

**2. 왜 필요한가?**
현실의 문제는 대부분 "여러 조건을 동시에 만족"해야 합니다. 예산·시간·인력 같은 제약을 식으로 적으면 연립방정식이 되고, 이를 풀면 모든 조건을 만족하는 최적의 배분이 나옵니다.

**3. 예시**

$$\begin{cases} 3x + y = 9 \\ x + 2y = 8 \end{cases} \quad\Rightarrow\quad A = \begin{pmatrix} 3 & 1 \\ 1 & 2 \end{pmatrix},\ b = \begin{pmatrix} 9 \\ 8 \end{pmatrix}$$

```python
import numpy as np

A = np.array([[3, 1], [1, 2]])
b = np.array([9, 8])

solution = np.linalg.solve(A, b)
print(solution)   # [2. 3.]
```

**4. 헷갈리기 쉬운 점**
`Ax = b` 에서 `A` 는 "미지수의 계수"만 모은 것이고, 미지수 `x` 자체는 들어가지 않습니다. 우변 `b` 는 등호 오른쪽 상수입니다.

**5. 한 줄 정리**
연립방정식은 `Ax = b` 라는 행렬 한 줄로 압축된다.
> 🍞 비유: 여러 조건이 적힌 주문서(방정식)를 한 장의 표(`A`, `b`)로 정리하는 것입니다.

### 첨가행렬과 가우스 소거법

**1. 정의**
계수행렬 `A` 오른쪽에 상수 `b` 를 붙인 `[A|b]` 가 첨가행렬입니다. **가우스 소거법**은 행 연산(한 행을 다른 행에 더하거나 빼기)으로 첨가행렬을 **상삼각행렬**(왼쪽 아래가 0)로 만든 뒤, 맨 아래부터 값을 차례로 대입(후진 대입)해 해를 구합니다.

**2. 왜 필요한가?**
미지수가 많아지면 손으로 풀기 어렵습니다. 가우스 소거법은 "미지수를 하나씩 규칙적으로 지워가는" 체계적인 절차라, 컴퓨터가 그대로 따라 할 수 있습니다.

**3. 예시**

$$\begin{cases} x + 2y - 4z = 2 \\ x + 3y - 6z = 1 \\ x + 2y - 3z = 4 \end{cases}$$

첨가행렬에서 `R2 ← R2 − R1`, `R3 ← R3 − R1` 을 적용하면 상삼각행렬이 됩니다:

```text
[ 1  2  -4 |  2 ]
[ 0  1  -2 | -1 ]
[ 0  0   1 |  2 ]
```

맨 아래에서 `z = 2`, 위로 올라가며 `y = 3`, `x = 4` 를 차례로 얻습니다(후진 대입).

```python
A = np.array([[1, 2, -4], [1, 3, -6], [1, 2, -3]])
b = np.array([2, 1, 4])
print(np.linalg.solve(A, b))   # [4. 3. 2.]
```

**4. 헷갈리기 쉬운 점**
"행 연산"은 한 행을 통째로 더하거나 빼는 것이지, 성분 하나만 바꾸는 게 아닙니다. 상삼각행렬을 만든 뒤에는 반드시 **아래에서 위로** 대입해야 합니다(z → y → x 순서).

**5. 한 줄 정리**
가우스 소거법은 "미지수를 아래쪽부터 하나씩 지워 계단 모양을 만든 뒤 거꾸로 대입"하는 풀이법이다.
> 🍞 비유: 복잡하게 얽힌 매듭을 끝에서부터 하나씩 풀어가는 과정과 같습니다.

---

### 가우스-조던 소거법

**1. 정의**
가우스 소거법을 한 걸음 더 진행해, 왼쪽을 **단위행렬(RREF, 기약행 사다리꼴)** 까지 만드는 방법입니다. 이렇게 하면 후진 대입 없이 오른쪽 열에서 **해를 바로 읽어낼** 수 있습니다.

**2. 왜 필요한가?**
후진 대입 단계를 생략하고 싶을 때, 또는 역행렬을 구하거나 해를 한눈에 확인하고 싶을 때 유용합니다.

**3. 예시**
위 상삼각행렬에서 위쪽 성분까지 0으로 마저 소거하면:

```text
[ 1  0  0 | 4 ]
[ 0  1  0 | 3 ]
[ 0  0  1 | 2 ]
```

왼쪽이 단위행렬이므로 `x = 4, y = 3, z = 2` 를 그대로 읽습니다.

**4. 헷갈리기 쉬운 점**
가우스 소거법은 **아래쪽만** 0으로 만들지만, 가우스-조던은 **위아래 모두** 0으로 만듭니다. 그만큼 행 연산이 많지만, 대신 대입 과정이 사라집니다.

**5. 한 줄 정리**
가우스-조던은 끝까지 정리해 "해를 표에서 바로 읽게" 만든다.

| 구분 | 가우스 소거법 | 가우스-조던 소거법 |
|------|--------------|-------------------|
| 목표 형태 | 상삼각행렬 | 단위행렬(RREF) |
| 해 구하기 | 후진 대입 필요 | 직접 읽어냄 |
| 연산량 | 적음 | 많음 |

## 코드로 보기 — 제약 속 최적 자원 배분

비즈니스 관점에서 연립방정식을 푼다는 것은 "여러 제약 조건을 동시에 만족하는 최적 비율(황금비율)을 찾는 일"입니다. 광고 채널 A·B의 최적 집행 횟수를 구해 봅니다.

```python
import numpy as np

# 제약 1 (예산): 3x + 1y = 9   (예산 9백만 원 소진)
# 제약 2 (시간): 1x + 2y = 8   (가용 시간 80시간 소진)
A_matrix = np.array([[3, 1],
                     [1, 2]])
b_vector = np.array([9, 8])

solution = np.linalg.solve(A_matrix, b_vector)
x_sol, y_sol = solution
print(x_sol, y_sol)   # 2.0 3.0
```

실행 결과:

```text
2.0 3.0
```

**코드목적**
예산과 시간이라는 두 제약을 각각 방정식으로 적고, 둘을 **동시에** 만족하는 집행 횟수 `(x, y)` 를 한 번에 계산합니다.

**해석**
해는 `채널 A = 2회, 채널 B = 3회`. 이 조합이 예산 9와 시간 8을 정확히 둘 다 소진합니다. 기하학적으로는 두 제약 직선이 만나는 **교점**이 곧 이 최적해입니다. 제약이 바뀌면(예: 예산 12, 시간 7) 교점도 이동해 새로운 최적 배분이 나옵니다.

**실무 연결**
마케팅 예산 배분, 생산 계획(어떤 제품을 몇 개씩), 포트폴리오 구성 등 "한정된 자원을 여러 곳에 최적으로 나누는" 문제가 모두 이 형태입니다. 제약을 식으로 옮기고 `Ax=b` 를 풀면, 감이 아니라 근거 있는 배분이 나옵니다.

## 헷갈리기 쉬운 포인트

- **가우스 vs 가우스-조던**: 전자는 상삼각행렬 + 후진 대입, 후자는 단위행렬 + 직접 읽기.
- **계수행렬 A vs 첨가행렬 [A|b]**: A는 계수만, 첨가행렬은 우변 상수 b까지 붙인 것.
- **행 연산 vs 성분 변경**: 행 연산은 한 행 전체를 더하거나 빼는 것(해는 그대로 보존됨).
- **유일해 vs 무수히 많은 해**: `det(A) ≠ 0` 이면 유일한 교점(해), `det = 0` 이면 평행하거나 겹쳐 해가 없거나 무수히 많음.
