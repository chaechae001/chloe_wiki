# 행렬과 행렬 연산

> 벡터가 화살표 하나라면, 행렬은 화살표를 잔뜩 모아 둔 표입니다. 그런데 이 표는 단순한 데이터 저장소가 아니라, **데이터를 회전·확대·변형하는 '변환 장치'** 이기도 합니다.

`행렬` · `행렬곱` · `전치` · `대칭행렬` · `단위행렬` · `역행렬` · `행렬식` · `선형변환`

## 핵심요약

- 행렬은 수를 직사각형(m행 × n열)으로 배열한 것이며, 행과 열의 수가 같으면 정방행렬이다.
- 덧셈·뺄셈은 **같은 크기**일 때만, 성분끼리 더하고 뺀다.
- 행렬 곱은 "앞 행렬의 행 × 뒤 행렬의 열" 내적으로 계산하며, **앞의 열 수 = 뒤의 행 수** 일 때만 가능하다.
- 행렬 곱은 **교환법칙이 성립하지 않는다**(`AB ≠ BA`).
- 전치(`Aᵀ`)는 행과 열을 맞바꾸며, `A = Aᵀ` 이면 대칭행렬이다.
- 단위행렬 `I` 는 곱셈의 1 역할을 하고, 역행렬 `A⁻¹` 은 `AA⁻¹ = I` 를 만족한다.
- 역행렬은 **행렬식 `det(A) ≠ 0`** 일 때만 존재한다.

---

## 개념별 정리

### 행렬의 정의

**1. 정의**
행렬은 수나 식을 직사각형 모양으로 배열한 것입니다. **m×n 행렬**은 행이 m개, 열이 n개입니다. 행과 열의 수가 같으면 **정방행렬**, 1행짜리는 **행벡터**, 1열짜리는 **열벡터**입니다.

**2. 왜 필요한가?**
여러 데이터를 한 덩어리로 다루려면 표가 필요합니다. 고객 100명 × 특성 5개는 100×5 행렬, 이미지는 픽셀 행렬입니다. 행렬은 데이터를 담는 기본 그릇입니다.

**3. 예시**

```python
import numpy as np

A = np.array([[1, 2, -1],
              [3, 2, -1]])     # 2×3 행렬 (비정방)
print(A.shape)                  # (2, 3) → 2행 3열
print(A[0, 0], A[1, 2])         # 1, -1  (a_11, a_23)
```

**4. 헷갈리기 쉬운 점**
파이썬 인덱스는 0부터 시작합니다. 수학에서 `a₁₁`(1행 1열)은 코드에서 `A[0, 0]`입니다. `A.shape`은 `(행 수, 열 수)` 순서입니다.

**5. 한 줄 정리**
행렬은 "행과 열로 정리된 숫자 표"다.
> 🍞 비유: 출석부처럼 가로(학생)·세로(과목)로 점수를 적은 표가 행렬입니다.

---

### 행렬의 곱셈

**1. 정의**
`AB` 의 (i, j) 성분은 **A의 i번째 행과 B의 j번째 열의 내적**입니다. 곱이 성립하려면 A의 열 수와 B의 행 수가 같아야 합니다.

$$A_{(m \times r)} \, B_{(r \times n)} = C_{(m \times n)}, \qquad c_{ij} = \sum_k a_{ik} b_{kj}$$

**2. 왜 필요한가?**
행렬 곱은 단순 계산이 아니라 "데이터에 변환을 적용"하는 연산입니다. 신경망의 한 층, 좌표 회전, 추천 점수 계산이 전부 행렬 곱입니다.

**3. 예시**

```python
A = np.array([[5, 6], [7, 8]])
B = np.array([[1, 2], [3, 4]])

print(A @ B)   # [[23 34] [31 46]]
print(B @ A)   # [[19 22] [43 50]]  ← AB와 다름!
print(np.allclose(A @ B, B @ A))   # False
```

**4. 헷갈리기 쉬운 점**
행렬 곱은 **교환법칙이 성립하지 않습니다**. `AB`와 `BA`는 대개 다르고, 심지어 크기가 안 맞아 한쪽은 계산조차 안 될 수 있습니다. "앞 열 = 뒤 행"만 외우면 크기 판단은 끝입니다.

**5. 한 줄 정리**
행렬 곱은 "행 × 열 내적"이고, 순서를 바꾸면 결과가 달라진다.
> 🍞 비유: '양말 신고 신발 신기'와 '신발 신고 양말 신기'가 다르듯, 행렬 곱도 순서가 중요합니다.

---

### 전치행렬과 대칭행렬

**1. 정의**
전치(`Aᵀ`)는 행과 열을 맞바꾸는 연산입니다(`(Aᵀ)ᵢⱼ = Aⱼᵢ`). 전치해도 자기 자신과 같은 행렬(`A = Aᵀ`)을 **대칭행렬**이라 합니다.

**2. 왜 필요한가?**
데이터의 "행 기준 ↔ 열 기준"을 바꾸거나, 내적·공분산 계산에서 모양을 맞출 때 전치가 필수입니다. 공분산 행렬·상관 행렬은 대칭행렬이라 분석에서 자주 등장합니다.

**3. 예시**

```python
A = np.array([[1, 2, 3], [4, 5, 6]])   # 2×3
print(A.T)        # 3×2 로 행↔열 교환

S = np.array([[2, 4, 0],
              [4, 1, 6],
              [0, 6, 3]])
print(np.allclose(S, S.T))   # True → 대칭행렬
```

**4. 헷갈리기 쉬운 점**
전치는 크기도 바뀝니다(2×3 → 3×2). 대칭행렬은 반드시 정방행렬(n×n)이어야 하며, 대각선을 기준으로 위아래가 거울처럼 같습니다.

**5. 한 줄 정리**
전치는 표를 대각선 기준으로 뒤집는 것, 대칭행렬은 뒤집어도 똑같은 표다.
> 🍞 비유: 전치는 사진을 대각선 축으로 뒤집기, 대칭행렬은 좌우 대칭인 나비처럼 뒤집어도 같은 모양입니다.

---

### 단위행렬과 역행렬

**1. 정의**
**단위행렬 `I`** 는 대각선이 모두 1, 나머지는 0인 정방행렬로, 곱셈의 1 역할을 합니다(`AI = IA = A`). **역행렬 `A⁻¹`** 은 곱했을 때 단위행렬이 되는 행렬입니다(`AA⁻¹ = I`).

**2. 왜 필요한가?**
역행렬은 "나눗셈"에 해당합니다. 방정식 `Ax = b` 를 `x = A⁻¹b` 로 풀 수 있게 해줍니다. 변환을 되돌리는(원상복구) 역할도 합니다.

**3. 예시**

```python
A = np.array([[2., 5.], [-3., -7.]])
A_inv = np.linalg.inv(A)

print(np.round(A @ A_inv, 10))   # [[1. 0.] [0. 1.]] → 단위행렬
```

**4. 헷갈리기 쉬운 점**
모든 행렬에 역행렬이 있는 것은 아닙니다. `det(A) = 0` 이면(특이행렬) 역행렬이 없습니다. 예를 들어 한 행이 다른 행의 배수인 행렬은 역행렬이 없습니다.

**5. 한 줄 정리**
단위행렬은 곱셈의 1, 역행렬은 행렬의 "되돌리기" 버튼이다.
> 🍞 비유: 숫자 5의 역수가 1/5(곱하면 1)이듯, 행렬의 역행렬은 곱하면 단위행렬(I)이 됩니다.

---

### 행렬식(Determinant)

**1. 정의**
정방행렬에 대응하는 하나의 숫자로, 2×2 행렬에서는 `ad − bc` 입니다. 역행렬 존재 여부를 판가름합니다.

$$\det\begin{pmatrix} a & b \\ c & d \end{pmatrix} = ad - bc$$

**2. 왜 필요한가?**
"이 방정식이 유일한 해를 갖는가?", "이 변환이 되돌릴 수 있는가?"를 행렬식 한 숫자로 즉시 알 수 있습니다. `det ≠ 0` 이면 역행렬이 있고 해가 유일합니다.

**3. 예시**

```python
M = np.array([[3., 1.], [2., 4.]])
print(np.linalg.det(M))   # 10.0  → 역행렬 존재

S = np.array([[1., 2.], [2., 4.]])   # 2행이 1행의 2배
print(np.linalg.det(S))   # 0.0   → 역행렬 없음(특이행렬)
```

**4. 헷갈리기 쉬운 점**
행렬식은 정방행렬에만 정의됩니다. `det = 0` 은 "행/열이 서로 종속(겹침)"이라는 신호이며, 이때 역행렬이 없고 방정식의 해가 유일하지 않습니다.

**5. 한 줄 정리**
행렬식은 "역행렬이 있는가"를 0이냐 아니냐로 알려주는 숫자다.
> 🍞 비유: 행렬식은 자물쇠의 "열림/잠김" 표시등 — 0이면 잠김(역행렬 없음), 0이 아니면 열림입니다.

## 코드로 보기 — 행렬 곱셈 직접 계산

행렬 곱셈을 손 계산과 코드로 함께 확인해 봅니다. 두 행렬을 곱해 결과가 단위행렬이 나오는 경우(서로 역행렬 관계)입니다.

```python
import numpy as np

A = np.array([[3, 1], [2, 1]])
B = np.array([[1, -1], [-2, 3]])

print(A @ B)
```

실행 결과:

```text
[[1 0]
 [0 1]]
```

**코드목적**
`A`의 각 행과 `B`의 각 열을 내적해 곱 행렬을 만듭니다. 결과가 단위행렬이면 두 행렬은 서로 **역행렬 관계**입니다.

**해석**
(1행 1열) = `3×1 + 1×(-2) = 1`, (1행 2열) = `3×(-1) + 1×3 = 0`, (2행 1열) = `2×1 + 1×(-2) = 0`, (2행 2열) = `2×(-1) + 1×3 = 1`. 결과가 단위행렬이므로 `B = A⁻¹` 입니다. 이처럼 영행렬이 아닌 두 행렬의 곱이 단위행렬이 되면 서로 역행렬입니다.

**실무 연결**
역행렬은 연립방정식 풀이([다음 글](04-linear-equations-gauss.md)), 회귀 분석의 정규방정식, 좌표 변환의 원상복구에 쓰입니다. 다만 실무에서는 역행렬을 직접 구하기보다 수치적으로 더 안정적인 방법(소거법 등)을 선호합니다.

3. `det = 1×4 − 2×2 = 0`. 행렬식이 0이므로 **역행렬이 없습니다**(2행이 1행의 2배라 종속).

## 헷갈리기 쉬운 포인트

- **`AB` vs `BA`**: 행렬 곱은 교환법칙 불성립. 순서가 바뀌면 결과도, 때로는 가능 여부도 달라집니다.
- **덧셈 vs 곱셈의 크기 조건**: 덧셈은 "완전히 같은 크기", 곱셈은 "앞의 열 = 뒤의 행".
- **전치 vs 역행렬**: 전치는 단순히 행↔열 교환(항상 가능), 역행렬은 곱하면 I가 되는 행렬(`det ≠ 0` 일 때만 존재).
- **`det = 0` vs `det ≠ 0`**: 0이면 역행렬 없음·해 유일하지 않음, 0이 아니면 역행렬 있음·해 유일.
