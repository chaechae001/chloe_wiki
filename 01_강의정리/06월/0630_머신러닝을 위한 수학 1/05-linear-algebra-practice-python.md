# Python으로 푸는 선형대수 기초 문제

> 손으로 푼 내적, 노름, 행렬 곱셈, 연립방정식을 NumPy로 다시 계산하면 수식이 실제 코드와 연결된다.

`NumPy` · `내적` · `노름` · `행렬곱` · `단위행렬` · `np.dot` · `np.linalg.norm` · `np.linalg.solve` · `Gauss-Jordan`

## 핵심요약

- 선형대수 문제는 손풀이로 원리를 이해하고, NumPy로 계산 결과를 검증하면 가장 빠르게 익숙해진다.
- 내적은 같은 위치의 성분끼리 곱한 뒤 더하는 연산이며, 결과는 벡터가 아니라 하나의 숫자다.
- `np.linalg.norm(x)`는 기본적으로 L2 노름을 반환한다. 노름의 제곱을 출력하면 성분 제곱합이 나온다.
- 내적의 선형성은 복잡한 벡터식의 내적을 이미 알고 있는 내적값의 조합으로 계산하게 해준다.
- 행렬 곱셈은 왼쪽 행렬의 행과 오른쪽 행렬의 열을 내적하는 방식이며, 결과 크기는 바깥쪽 차원으로 결정된다.
- 두 행렬의 곱이 단위행렬이 되면 서로 역행렬 관계로 볼 수 있다.
- 연립방정식은 `Ax=b` 형태로 바꾼 뒤 `np.linalg.solve(A, b)`로 풀고, `A @ x`가 `b`와 같은지 검증한다.
- 비즈니스 관점에서 선형방정식은 예산·시간·인력 같은 제약조건이 동시에 만나는 지점을 찾는 도구다.

## 1. 벡터의 내적과 노름

### 1) 정의

내적은 두 벡터의 같은 위치 성분끼리 곱한 뒤 모두 더하는 연산이다. 예를 들어 $x=(x_1,x_2,\dots,x_n)$, $y=(y_1,y_2,\dots,y_n)$라면 내적은 다음과 같다.

$$
\langle x,y\rangle=x_1y_1+x_2y_2+\cdots+x_ny_n
$$

노름은 벡터의 크기, 즉 길이다. 가장 자주 쓰는 L2 노름은 각 성분을 제곱해서 더한 뒤 제곱근을 씌운다.

$$
\|x\|=\sqrt{x_1^2+x_2^2+\cdots+x_n^2}
$$

### 2) 왜 필요한가

내적과 노름은 코사인 유사도, 거리 계산, 추천 시스템, 문서 검색, 신경망의 가중합 계산까지 연결된다. 두 벡터가 얼마나 같은 방향을 바라보는지, 얼마나 큰지, 얼마나 가까운지 판단하려면 이 두 연산이 필요하다.

### 3) 원본 강의 기준 설명

실습에서는 다음 두 벡터가 주어졌고, 내적과 노름을 직접 계산한 뒤 NumPy로 검증했다.

$$
x=(1,-1,0,2,4), \quad y=(2,1,1,3,0)
$$

손으로 계산하면 내적은 다음과 같다.

$$
\langle x,y\rangle=(1)(2)+(-1)(1)+(0)(1)+(2)(3)+(4)(0)=7
$$

노름의 제곱은 각각 다음과 같다.

$$
\|x\|^2=1^2+(-1)^2+0^2+2^2+4^2=22
$$

$$
\|y\|^2=2^2+1^2+1^2+3^2+0^2=15
$$

### 4) 쉬운 예시

고객 A와 고객 B를 `[액션 시청량, 로맨스 시청량, SF 시청량]`처럼 벡터로 표현했다고 생각하면, 내적은 두 고객의 장르별 선호가 얼마나 겹치는지 계산하는 궁합 점수처럼 볼 수 있다. 노름은 그 고객의 전체 활동량 또는 벡터 크기를 나타낸다.

### 5) 코드 예시

```python
import numpy as np

x = np.array([1, -1, 0, 2, 4])
y = np.array([2, 1, 1, 3, 0])

inner = np.dot(x, y)
print(f"(1) <x, y> = {inner}")

norm_x = np.linalg.norm(x)
print(f"(2) ||x||^2 = {norm_x ** 2}")

norm_y = np.linalg.norm(y)
print(f"(3) ||y||^2 = {norm_y ** 2}")
```

실행 결과:

```text
(1) <x, y> = 7
(2) ||x||^2 = 22.0
(3) ||y||^2 = 15.000000000000002
```

### 6) 헷갈리는 점

`np.linalg.norm(x)`는 $\sqrt{22}$를 반환한다. 위 코드에서 `norm_x ** 2`를 출력했기 때문에 22가 나온 것이다. 실제 노름은 $\sqrt{22}$이고, 노름의 제곱이 22다.

### 7) 한 줄 정리

> 내적은 두 벡터의 방향 일치도를 숫자로 압축하고, 노름은 벡터 자체의 크기를 알려준다.

## 2. 내적의 선형성

### 1) 정의

내적은 덧셈과 스칼라곱에 대해 선형성을 가진다. 즉, 벡터를 더하거나 숫자를 곱한 뒤 내적해도, 내적값을 먼저 계산한 뒤 같은 방식으로 조합할 수 있다.

$$
\langle av_1+bv_2,w\rangle=a\langle v_1,w\rangle+b\langle v_2,w\rangle
$$

### 2) 왜 필요한가

복잡한 벡터식을 직접 계산하지 않고, 이미 알고 있는 내적값을 이용해 빠르게 결과를 구할 수 있다. 선형대수에서 “선형”이라는 말이 실제 계산에서 어떻게 작동하는지 보여주는 핵심 성질이다.

### 3) 원본 강의 기준 설명

실습 문제에서는 다음 조건이 주어졌다.

$$
\langle v_1,w\rangle=3, \quad \langle v_2,w\rangle=-2
$$

구해야 하는 값은 다음이다.

$$
\langle 2v_1-3v_2,w\rangle
$$

내적의 선형성을 적용하면 다음처럼 계산된다.

$$
\langle 2v_1-3v_2,w\rangle=2\langle v_1,w\rangle-3\langle v_2,w\rangle
$$

$$
=2\times3-3\times(-2)=12
$$

### 4) 쉬운 예시

두 과목 점수의 가중합을 생각하면 쉽다. 국어 점수를 2배, 영어 점수를 -3배 해서 총점을 만든 뒤 평가하는 것과, 국어 평가점수와 영어 평가점수를 따로 계산한 뒤 같은 가중치로 합치는 것은 같은 결과를 낸다.

### 5) 코드 예시

```python
import numpy as np

v1 = np.array([1, 0, 0])
v2 = np.array([0, 1, 0])
w = np.array([3, -2, 0])

print(f"<v1, w> = {np.dot(v1, w)}")
print(f"<v2, w> = {np.dot(v2, w)}")

result = np.dot(2 * v1 - 3 * v2, w)
print(f"<2v1 - 3v2, w> = {result}")

result_dist = 2 * np.dot(v1, w) - 3 * np.dot(v2, w)
print(f"2<v1,w> - 3<v2,w> = {result_dist}")
```

실행 결과:

```text
<v1, w> = 3
<v2, w> = -2
<2v1 - 3v2, w> = 12
2<v1,w> - 3<v2,w> = 12
```

### 6) 헷갈리는 점

`2v1 - 3v2`를 먼저 만든 뒤 `w`와 내적해도 되고, `v1`, `v2`와 `w`의 내적값을 먼저 구한 뒤 `2`, `-3`을 곱해도 된다. 이 두 방식이 같은 이유가 바로 내적의 선형성이다.

### 7) 한 줄 정리

> 내적의 선형성은 복잡한 벡터식을 이미 알고 있는 내적값의 조합으로 바꾸는 계산 규칙이다.

## 3. 행렬 곱셈과 단위행렬

### 1) 정의

행렬 곱셈은 왼쪽 행렬의 행과 오른쪽 행렬의 열을 내적해서 새 행렬의 성분을 만드는 연산이다.

$$
C_{ij}=\sum_k A_{ik}B_{kj}
$$

### 2) 왜 필요한가

행렬 곱셈은 선형 변환, 신경망 계산, 추천 시스템, 연립방정식 풀이에 모두 쓰인다. 특히 머신러닝 모델에서 입력 데이터 행렬과 가중치 행렬을 곱하는 계산은 모델 예측의 핵심이다.

### 3) 원본 강의 기준 설명

실습에서는 다음 두 행렬의 곱을 계산했다.

$$
A=\begin{pmatrix}3&1\\2&1\end{pmatrix}, \quad
B=\begin{pmatrix}1&-1\\-2&3\end{pmatrix}
$$

곱하면 다음 결과가 나온다.

$$
AB=\begin{pmatrix}1&0\\0&1\end{pmatrix}
$$

이 결과는 단위행렬이다. 따라서 두 행렬은 서로 역행렬 관계로 볼 수 있다.

### 4) 쉬운 예시

단위행렬은 숫자에서 1과 비슷하다. 어떤 행렬에 단위행렬을 곱해도 원래 행렬이 유지된다. 두 행렬을 곱했더니 단위행렬이 나왔다는 것은, 두 변환이 서로를 원래 상태로 되돌리는 관계라는 뜻이다.

### 5) 코드 예시

```python
import numpy as np

A = np.array([[3, 1], [2, 1]])
B = np.array([[1, -1], [-2, 3]])

result = np.dot(A, B)
print(f"C = {result}")
```

실행 결과:

```text
C = [[1 0]
 [0 1]]
```

### 6) 헷갈리는 점

행렬 곱셈은 일반적으로 순서를 바꾸면 결과가 달라진다. 다만 서로 역행렬 관계인 특별한 경우에는 `AB = BA = I`가 성립할 수 있다. 따라서 “이번 문제에서 같았다”를 “모든 행렬에서 순서를 바꿔도 된다”로 일반화하면 안 된다.

### 7) 한 줄 정리

> 행렬 곱셈은 행과 열의 내적이며, 결과가 단위행렬이면 두 행렬은 서로 되돌리는 관계다.

## 4. 행렬 곱셈의 결과 크기

### 1) 정의

행렬 곱셈이 가능하려면 앞 행렬의 열 수와 뒤 행렬의 행 수가 같아야 한다.

$$
(m\times r)(r\times n)=(m\times n)
$$

### 2) 왜 필요한가

코드에서 행렬 곱셈 오류가 나는 가장 흔한 이유는 차원이 맞지 않기 때문이다. 모델 입력 `X`와 가중치 `W`를 곱할 때도 이 크기 규칙이 맞아야 한다.

### 3) 원본 강의 기준 설명

실습에서는 $3\times2$ 행렬과 $2\times3$ 행렬을 곱해 $3\times3$ 행렬을 만들었다.

### 4) 쉬운 예시

앞 행렬의 열 수와 뒤 행렬의 행 수는 “연결고리”다. 이 연결고리가 맞아야 곱셈이 가능하고, 결과의 모양은 바깥쪽 숫자인 앞 행렬의 행 수와 뒤 행렬의 열 수로 결정된다.

### 5) 코드 예시

```python
import numpy as np

B = np.array([
    [-1, 2],
    [-2, 1],
    [3, 4]
])

C = np.array([
    [1, 0, 2],
    [2, -3, 1]
])

A = B @ C
print(A)
```

실행 결과:

```text
[[  3  -6   0]
 [  0  -3  -3]
 [ 11 -12  10]]
```

### 6) 헷갈리는 점

`B`는 $3\times2$, `C`는 $2\times3$이므로 `B @ C`는 가능하고 결과는 $3\times3$이다. 반대로 `C @ B`도 이 경우에는 가능하지만 결과 크기는 $2\times2$가 된다. 순서를 바꾸면 크기와 값이 모두 달라진다.

### 7) 한 줄 정리

> 행렬 곱셈은 가운데 차원이 맞아야 가능하고, 결과 크기는 바깥쪽 차원으로 정해진다.

## 5. 연립 일차 방정식과 `np.linalg.solve`

### 1) 정의

연립 일차 방정식은 여러 개의 일차식을 동시에 만족하는 미지수 값을 찾는 문제다. 계수행렬 `A`, 미지수 벡터 `x`, 상수 벡터 `b`로 정리하면 다음처럼 쓸 수 있다.

$$
Ax=b
$$

### 2) 왜 필요한가

현실의 문제는 하나의 조건만 만족하면 끝나지 않는 경우가 많다. 예산, 시간, 인력, 재고처럼 여러 제약조건을 동시에 만족하는 조합을 찾을 때 연립방정식이 필요하다.

### 3) 원본 강의 기준 설명

실습에서는 다음 연립방정식을 풀었다.

$$
\begin{cases}
x+2y-4z=2 \\
x+3y-6z=1 \\
x+2y-3z=4
\end{cases}
$$

이를 행렬로 나타내면 다음과 같다.

$$
A=\begin{pmatrix}1&2&-4\\1&3&-6\\1&2&-3\end{pmatrix}, \quad b=\begin{pmatrix}2\\1\\4\end{pmatrix}
$$

### 4) 쉬운 예시

세 개의 조건을 동시에 만족해야 하는 비밀번호를 푸는 것과 비슷하다. 첫 번째 조건만 만족하는 값은 많을 수 있지만, 세 조건을 모두 만족하는 값은 하나로 좁혀질 수 있다.

### 5) 코드 예시

```python
import numpy as np

A = np.array([
    [1, 2, -4],
    [1, 3, -6],
    [1, 2, -3]
])

b = np.array([2, 1, 4])

x = np.linalg.solve(A, b)
print(x)

print(f"검증 : A @ x = {A @ x}")
print(f"정답 b = {b}")
```

실행 결과:

```text
[4. 3. 2.]
검증 : A @ x = [2. 1. 4.]
정답 b = [2 1 4]
```

### 6) 헷갈리는 점

`np.linalg.solve(A, b)`로 해를 구한 뒤에는 반드시 `A @ x`가 원래의 `b`와 같은지 검증하는 습관이 좋다. 해를 구하는 것과 해가 맞는지 확인하는 것은 다른 단계다.

### 7) 한 줄 정리

> 연립방정식은 `Ax=b`로 정리하고, `np.linalg.solve`로 푼 뒤 `A @ x`로 검증한다.

## 코드로 보기 — 제약조건이 바뀌면 해는 어떻게 이동할까?

```python
import numpy as np

A_matrix = np.array([
    [3, 1],
    [1, 2]
])

b_old = np.array([9, 8])
sol_old = np.linalg.solve(A_matrix, b_old)

b_new = np.array([12, 7])
sol_new = np.linalg.solve(A_matrix, b_new)

print(sol_old)
print(sol_new)
```

### 코드 목적

같은 구조의 비즈니스 문제에서 제약조건이 바뀌면 최적 조합이 어떻게 이동하는지 확인한다.

### 코드 흐름

1. 예산과 시간 제약을 나타내는 계수행렬 `A_matrix`를 만든다.
2. 기존 조건 `b_old = [9, 8]`에 대한 해를 구한다.
3. 변경된 조건 `b_new = [12, 7]`에 대한 해를 구한다.
4. 두 해를 비교한다.

### 실행 결과 해석

기존 조건의 해는 `[2, 3]`이다. 이는 채널 A를 2회, 채널 B를 3회 선택하면 예산과 시간이 동시에 맞는다는 뜻이다. 조건이 `[12, 7]`로 바뀌면 해가 `[3.4, 1.8]`로 이동한다. 즉, 같은 계산 구조에서 우변의 제약값만 바꿔 새로운 의사결정 조합을 빠르게 구할 수 있다.

### 실무 연결

마케팅 예산이 늘거나 가용 시간이 줄어드는 상황에서 각 채널에 얼마를 배분해야 하는지 시뮬레이션할 수 있다. 생산계획, 인력 배치, 재고 배분에서도 같은 구조를 사용할 수 있다.

2. `B @ C`는 $3\times3$ 행렬이고, `C @ B`는 $2\times2$ 행렬이다. 두 곱은 모두 계산 가능하지만 결과 크기와 값이 다르다. 따라서 행렬 곱셈에서는 순서가 중요하다.

3. 다음처럼 계산할 수 있다.

```python
b_changed = np.array([15, 10])
print(np.linalg.solve(A_matrix, b_changed))
```

해는 `[4, 3]`이다. 이는 변경된 예산과 시간 조건에서는 채널 A 4회, 채널 B 3회 조합이 두 조건을 동시에 만족한다는 뜻이다.

</details>

## 헷갈리기 쉬운 포인트

| 헷갈리는 개념 | 차이 |
|---|---|
| `np.dot(x, y)` vs `x @ y` | 1차원 벡터끼리는 둘 다 내적처럼 사용할 수 있다. 2차원 행렬에서는 둘 다 행렬 곱에 사용할 수 있다. |
| `np.linalg.norm(x)` vs `np.linalg.norm(x) ** 2` | 전자는 실제 노름, 후자는 성분 제곱합이다. |
| 행렬 곱 `@` vs 성분별 곱 `*` | `@`는 행과 열의 내적, `*`는 같은 위치 성분끼리 곱이다. |
| 해 구하기 vs 해 검증하기 | 해는 `solve`로 구하고, 검증은 `A @ x`가 `b`와 같은지 확인한다. |
| Gauss 소거법 vs Gauss-Jordan 소거법 | Gauss는 상삼각행렬 후 후진대입, Gauss-Jordan은 단위행렬까지 만들어 해를 직접 읽는다. |
