# 벡터와 벡터공간

> "두 고객이 얼마나 비슷한가?", "이 단어와 저 단어의 의미가 가까운가?" — 이런 질문은 전부 **벡터 사이의 거리와 각도** 문제로 바뀝니다. 그 계산의 기본기를 한 번에 익혀봅니다.

`벡터` · `벡터공간` · `내적` · `노름` · `거리` · `코사인유사도` · `직교` · `삼각부등식`

## 핵심요약

- 벡터는 **크기(magnitude)** 와 **방향(direction)** 을 동시에 가진 양이다.
- 벡터공간 `Rⁿ` 은 "n개의 실수 묶음 + 덧셈·스칼라곱"이 정의된 공간이다.
- **내적(inner product)** 은 두 벡터의 성분별 곱을 모두 더한 값으로, 결과는 하나의 숫자(스칼라)다.
- **노름(norm)** 은 벡터의 크기(길이)이며, 가장 흔한 L2 노름은 피타고라스 정리와 같다.
- 두 벡터 사이의 **거리**는 차 벡터의 노름 `‖x − y‖` 로 구한다.
- 두 벡터 사이의 **각도**는 내적과 노름으로 계산하며, 내적이 0이면 두 벡터는 **직교(수직)** 다.
- **코사인 유사도**는 크기를 무시하고 방향(취향의 비율)만 비교해 "얼마나 비슷한가"를 잰다.

## 개념별 정리

### 벡터란 무엇인가

**1. 정의**
벡터는 크기와 방향을 동시에 표현하는 수단입니다. 화살표 하나로 그릴 수 있고, 시작점이 달라도 **크기와 방향이 같으면 같은 벡터**입니다(평행이동으로 겹치면 동일).

**2. 왜 필요한가?**
"3만큼 이동"은 방향이 없어 모호하지만, "오른쪽으로 3, 위로 2 이동"은 명확합니다. 움직임·힘·데이터의 특성을 한꺼번에 표현하려면 방향과 크기를 함께 담는 벡터가 필요합니다.

**3. 예시**
온라인/오프라인 고객 행동을 각각 벡터로 보고, 더하면 통합 프로파일이, 스칼라를 곱하면 규모만 키운 시뮬레이션이 됩니다.

```python
import numpy as np

online_behavior  = np.array([4, 2])   # (구매횟수, 체류시간) 온라인
offline_behavior = np.array([1, 4])   # 오프라인 행동
scalar_growth    = 1.5

integrated_v = online_behavior + offline_behavior   # 옴니채널 통합
scaled_v     = scalar_growth * integrated_v         # 규모 1.5배 스케일업

print(integrated_v)   # [5 6]
print(scaled_v)       # [7.5 9. ]
```

**4. 헷갈리기 쉬운 점**
회전시켜야 겹치는 두 벡터는 **같지 않습니다**(방향이 다르므로). 평행이동만으로 겹쳐야 같은 벡터입니다.

**5. 한 줄 정리**
벡터는 "어느 방향으로 얼마나"를 담은 화살표다.
> 🍞 비유: 내비게이션의 "북동쪽으로 3km" — 방향(북동)과 크기(3km)를 함께 가진 벡터입니다.

---

### 벡터공간 Rⁿ

**1. 정의**
`Rⁿ` 은 n개의 실수 순서쌍 전체의 집합이며, 여기에 **벡터 덧셈**과 **스칼라 곱** 두 연산이 정의되어 있습니다.

$$(x_1, \cdots, x_n) + (y_1, \cdots, y_n) = (x_1+y_1, \cdots, x_n+y_n)$$
$$\lambda \cdot (x_1, \cdots, x_n) = (\lambda x_1, \cdots, \lambda x_n)$$

**2. 왜 필요한가?**
분석가가 고객을 바라보는 "렌즈(변수)"를 늘릴수록 차원이 커집니다. 나이·구매액(2차원) → 방문횟수 추가(3차원) → 클릭·체류·반품 등 수백 개(`R¹⁰⁰`). 이 모든 데이터를 같은 규칙으로 다루는 무대가 벡터공간입니다.

**3. 예시**

```python
# R^2, R^3, R^4 에서 동일한 규칙으로 연산
a = np.array([1, 2]);   b = np.array([3, -1])
print(a + b)            # [4 1]   (성분별 덧셈)
print(3 * a)            # [3 6]   (스칼라 곱)

x = np.array([1, 0, -1, 2]);  y = np.array([1, 0, -1, -2])
print(x + y)            # [ 2  0 -2  0]
```

**4. 헷갈리기 쉬운 점**
벡터공간에서는 교환법칙·결합법칙·분배법칙이 모두 성립합니다. 다만 이는 **덧셈과 스칼라 곱**에 대한 것이고, 뒤에 나올 "내적"이나 "행렬 곱"의 성질과는 구별해야 합니다.

**5. 한 줄 정리**
`Rⁿ` 은 숫자 n개짜리 벡터들이 덧셈·스칼라곱 규칙대로 노는 무대다.
> 🍞 비유: 변수 하나하나가 고객을 보는 렌즈입니다. 렌즈가 많을수록(차원이 높을수록) 고객을 더 입체적으로 봅니다.

---

### 내적(Inner Product)

**1. 정의**
두 벡터의 같은 위치 성분을 곱해서 모두 더한 값입니다. 결과는 벡터가 아니라 **하나의 숫자(스칼라)** 입니다.

$$\langle x, y \rangle = x_1 y_1 + x_2 y_2 + \cdots + x_n y_n$$

**2. 왜 필요한가?**
내적은 "두 벡터가 같은 방향을 얼마나 향하는가"를 숫자로 알려줍니다. 거리·각도·유사도·신경망 계산이 모두 내적 위에 세워져 있습니다.

**3. 예시**

```python
x = np.array([1, -1, 2])
y = np.array([-1, 0, 2])

print(np.dot(x, y))   # 1×(-1) + (-1)×0 + 2×2 = 3
print(x @ y)          # 3  (1차원끼리 @ 는 내적)
```

**4. 헷갈리기 쉬운 점**
내적의 결과는 **숫자**입니다. 성분별 곱 `x * y`(결과가 벡터)와 헷갈리지 마세요. `np.dot(x, y)`나 `x @ y`가 내적, `x * y`는 성분별 곱입니다.

**5. 한 줄 정리**
내적은 두 벡터를 곱해 "방향이 얼마나 일치하는지"를 숫자 하나로 압축한다.
> 🍞 비유: 두 사람의 취향 점수표를 항목별로 곱해 더한 "궁합 점수"입니다.

---

### 노름(Norm)과 거리(Distance)

**1. 정의**
노름은 벡터의 크기(길이)입니다. 가장 흔한 **L2 노름**은 각 성분을 제곱해 더한 뒤 제곱근을 씌운 값입니다.

$$\|v\|_2 = \sqrt{x_1^2 + \cdots + x_n^2}, \qquad d(x, y) = \|x - y\|$$

거리는 두 벡터의 차 벡터의 노름입니다.

**2. 왜 필요한가?**
"두 데이터가 얼마나 떨어져 있나"를 재려면 거리가 필요합니다. 군집화·이상치 탐지·추천이 모두 거리 계산에 기반합니다.

**3. 예시 — 거리의 여러 종류**

```python
x = np.array([1.0, -1.0, 2.0])
y = np.array([-1.0, 0.0, 2.0])

# L1(맨해튼): 성분 차이의 절댓값 합
print(np.linalg.norm(x - y, ord=1))    # 3.0
# L2(유클리디안): 직선 거리
print(np.linalg.norm(x - y, ord=2))    # 2.2361
# L∞: 가장 큰 성분 차이
print(np.linalg.norm(x - y, ord=np.inf))  # 2.0
```

L1은 바둑판 길처럼 가로·세로로만 움직인 거리(맨해튼 거리), L2는 자로 잰 직선 거리, L∞는 가장 크게 벌어진 한 성분의 차이입니다.

**4. 헷갈리기 쉬운 점**
노름은 "한 벡터의 크기", 거리는 "두 벡터 사이의 떨어짐"입니다. 거리 `d(x,y) = ‖x − y‖` 처럼 거리는 차 벡터의 노름으로 정의됩니다.

**5. 한 줄 정리**
노름은 벡터의 길이, 거리는 두 벡터를 잇는 길이다.
> 🍞 비유: L2는 새가 직선으로 나는 거리, L1은 택시가 도로를 따라 가는 거리입니다.

---

### 코사인 유사도(Cosine Similarity)

**1. 정의**
두 벡터의 내적을 각자의 노름 곱으로 나눈 값으로, 두 벡터가 이루는 각도의 코사인입니다. **−1 ~ 1** 범위이며, 1에 가까울수록 방향(취향)이 비슷합니다.

$$\cos\theta = \frac{\langle v, w \rangle}{\|v\| \, \|w\|}$$

**2. 왜 필요한가?**
절대적인 양(크기)이 달라도 "비율(방향)"이 같으면 비슷하다고 봐야 할 때가 많습니다. 헤비 유저와 라이트 유저는 시청 총량은 크게 다르지만 장르 비율이 같다면 취향은 동일합니다. 코사인 유사도는 크기를 무시하고 방향만 비교합니다.

**3. 예시**

```python
from sklearn.metrics.pairwise import cosine_similarity

customer_A = np.array([100, 10, 50])   # 헤비 유저
customer_B = np.array([10, 1, 5])      # 라이트 유저 (정확히 1/10)

# 직접 공식
dot = np.dot(customer_A, customer_B)
cos_sim = dot / (np.linalg.norm(customer_A) * np.linalg.norm(customer_B))
print(cos_sim)   # 1.0

# scikit-learn (2차원 배열 입력 필요)
A_2d = customer_A.reshape(1, -1)
B_2d = customer_B.reshape(1, -1)
print(cosine_similarity(A_2d, B_2d)[0][0])   # 0.9999999999999999
```

시청 총량은 10배 차이지만 장르 비율이 같으므로 유사도는 **1**(완전히 같은 방향)로 나옵니다.

**4. 헷갈리기 쉬운 점**
거리(유클리디안)는 "절대량 차이"를 보고, 코사인 유사도는 "방향 차이"를 봅니다. 헤비/라이트 유저는 거리로는 멀지만 코사인으로는 똑같습니다. 목적에 맞게 골라야 합니다. 또 `scikit-learn`의 `cosine_similarity`는 입력으로 2차원 배열을 요구하므로 `reshape(1, -1)`로 모양을 바꿔야 합니다.

**5. 한 줄 정리**
코사인 유사도는 "크기는 빼고 방향만" 비교해 취향의 닮음을 잰다.
> 🍞 비유: 라면을 100그릇 먹는 사람과 10그릇 먹는 사람도, "매운맛만 골라 먹는 비율"이 같으면 입맛은 똑같습니다.

## 코드로 보기 — 단어 임베딩의 의미 유사도

단어를 벡터로 표현하면(임베딩), 코사인 유사도로 "의미가 가까운 단어"를 찾을 수 있습니다.

```python
import numpy as np

def cosine_similarity(a, b):
    return np.dot(a, b) / (np.linalg.norm(a) * np.linalg.norm(b))

cat = np.array([0.9, 0.1, 0.7, 0.2])   # 고양이
dog = np.array([0.8, 0.2, 0.6, 0.3])   # 개
car = np.array([0.1, 0.9, 0.1, 0.8])   # 자동차

print(cosine_similarity(cat, dog))   # 0.97...  (비슷한 개념)
print(cosine_similarity(cat, car))   # 0.42...  (다른 개념)
```

**코드목적**
'고양이·개·자동차'를 4차원 벡터로 표현하고, 코사인 유사도로 어떤 단어들이 의미상 가까운지 측정합니다.

**해석**
고양이-개는 유사도가 1에 가깝고(둘 다 동물), 고양이-자동차는 낮습니다(개념이 다름). 벡터의 "방향"이 의미를 담고 있어, 비슷한 뜻일수록 방향이 가깝습니다.

**실무 연결**
검색 엔진, 챗봇, 추천 시스템의 핵심입니다. 질문과 문서를 벡터로 바꾼 뒤 코사인 유사도가 높은 문서를 찾아주는 것이 "의미 기반 검색(semantic search)"이며, 최근 LLM 기반 서비스의 검색·RAG도 같은 원리입니다.

## 헷갈리기 쉬운 포인트

- **내적 `np.dot(x, y)` vs 성분별 곱 `x * y`**: 앞은 숫자 하나, 뒤는 벡터.
- **노름 vs 거리**: 노름은 한 벡터의 길이, 거리는 두 벡터 사이의 떨어짐(`‖x − y‖`).
- **유클리디안 거리 vs 코사인 유사도**: 거리는 절대량 차이, 코사인은 방향 차이. 헤비/라이트 유저 구분에 결정적 차이.
- **직교 vs 평행**: 내적이 0이면 직교(90도), 한 벡터가 다른 벡터의 배수면 평행(코시-슈바르츠 등호).

- (응용) 시청 총량이 크게 다른 두 사용자의 "취향"이 같은지 보려면 거리와 코사인 유사도 중 무엇이 더 적절한가요? 이유는?
  <details><summary>답</summary>코사인 유사도. 거리는 시청량(크기) 차이 때문에 멀게 나오지만, 코사인 유사도는 크기를 무시하고 장르 비율(방향)만 보므로 "취향이 같다"를 제대로 잡아냅니다.</details>

## 한 줄 정리

> 벡터는 데이터를 화살표로 표현하고, 내적·노름·거리·코사인 유사도는 그 화살표들이 "얼마나 가깝고 닮았는지"를 숫자로 알려준다.
