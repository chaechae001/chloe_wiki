# 용어집 (GLOSSARY)

SQL 입문에서 자주 만나는 용어를 쉬운 말로 정리했습니다. '관련 글'의 번호는 [OVERVIEW](OVERVIEW.md)의 목차와 같습니다.

| 용어 | 쉬운 설명 | 관련 글 | 함께 보면 좋은 개념 |
| --- | --- | --- | --- |
| 데이터베이스(Database) | 여러 사람이 공유하려고 통합·관리하는 데이터 창고 | 1. 기초 개념 | 관계형 데이터베이스, SQL |
| 관계형 데이터베이스(RDB) | 서로 연결된 여러 개의 표(테이블)로 이루어진 데이터베이스 | 1. 기초 개념 | 테이블, 기본키, 외래키 |
| SQL | 데이터베이스에 접근·조작하는 표준 명령 언어 (Structured Query Language) | 1. 기초 개념 | 쿼리, DML |
| 쿼리(Query) | 데이터베이스에 내리는 SQL 명령 한 덩어리 | 1. 기초 개념 | SELECT, WHERE |
| 테이블(Table) | 컬럼과 레코드로 이루어진 표. 고유한 이름으로 구분 | 1. 기초 개념 | 컬럼, 레코드 |
| 컬럼(Column) | 표의 세로 항목 (예: 이름, 점수) | 1. 기초 개념 | 레코드, 데이터 타입 |
| 레코드(Record) | 표의 가로 한 줄, 즉 한 건의 데이터 | 1. 기초 개념 | 컬럼, 행(Row) |
| DESC(구조 보기) | 테이블이 어떤 컬럼으로 생겼는지 보여 주는 명령 | 1. 기초 개념 | DESC(내림차순)와 구분 |
| SELECT | 테이블에서 원하는 컬럼을 꺼내 보는 조회 명령 | 2. SELECT 기본 | FROM, WHERE |
| FROM | 어느 테이블에서 가져올지 지정하는 키워드 | 2. SELECT 기본 | SELECT |
| 와일드카드 `*` | 컬럼 자리에 쓰면 '모든 컬럼'을 뜻함 | 2. SELECT 기본 | SELECT |
| DISTINCT | 뒤따르는 컬럼의 중복을 제거하고 종류만 보여 줌 | 2. SELECT 기본 | GROUP BY |
| LIMIT | 결과를 위에서 n개까지만 보여 줌 | 2. SELECT 기본 / 4. 정렬 | ORDER BY, OFFSET |
| WHERE | 검색할 데이터의 조건을 정하는 명령 | 3. 조건 검색 | 비교 연산자, 논리 연산자 |
| 비교 연산자 | 크기·같음을 따지는 기호 (`>`, `<`, `>=`, `<=`, `=`, `!=`) | 3. 조건 검색 | WHERE |
| 이상/이하 vs 초과/미만 | `>=`/`<=`는 경계값 포함, `>`/`<`는 경계값 제외 | 3. 조건 검색 | 비교 연산자 |
| AND | 여러 조건을 '모두' 만족 (교집합) | 3. 조건 검색 | OR, NOT |
| OR | 여러 조건 중 '하나라도' 만족 (합집합) | 3. 조건 검색 | AND, IN |
| NOT | 조건에 해당하지 '않는' 값 | 3. 조건 검색 | NOT IN |
| BETWEEN | 범위 조건. `A BETWEEN 10 AND 20`은 양 끝값 포함 | 3. 조건 검색 | 비교 연산자 |
| IN | 나열한 값들 중 하나에 해당 | 3. 조건 검색 | OR, NOT IN |
| NOT IN | 나열한 값들 중 어디에도 해당하지 않음 | 3. 조건 검색 | IN |
| LIKE | 특정 문자가 포함/시작/끝나는 값을 찾는 패턴 검색 | 4. 유사 검색·정렬 | 와일드카드 `%` |
| 와일드카드 `%` | '아무 문자나 0개 이상'. 위치로 시작·끝·포함을 표현 | 4. 유사 검색·정렬 | LIKE |
| ORDER BY | 검색 결과를 특정 컬럼 기준으로 정렬 | 4. 유사 검색·정렬 | ASC, DESC |
| ASC | 오름차순 정렬 (작은 값부터) | 4. 유사 검색·정렬 | DESC |
| DESC(내림차순) | 내림차순 정렬 (큰 값부터). 구조 보기 DESC와 다름 | 4. 유사 검색·정렬 | ASC, ORDER BY |
| DML | 데이터를 직접 바꾸는 명령들 (INSERT/UPDATE/DELETE) | 5. 데이터 변경 | CRUD |
| INSERT | 테이블에 새 데이터를 추가하는 명령 | 5. 데이터 변경 | VALUES |
| VALUES | INSERT에서 넣을 값을 적는 부분 | 5. 데이터 변경 | INSERT |
| UPDATE | 이미 저장된 값을 수정하는 명령 | 5. 데이터 변경 | SET, WHERE |
| SET | UPDATE에서 '어떤 값으로 바꿀지'를 적는 부분 | 5. 데이터 변경 | UPDATE |
| DELETE | 테이블에 저장된 데이터를 삭제하는 명령 | 5. 데이터 변경 | WHERE |
| CRUD | 데이터 다루기의 4대 동작 (Create/Read/Update/Delete) | 5. 데이터 변경 | DML, SELECT |
