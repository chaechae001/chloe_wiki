# 반복문 — 코드의 반복 줄이기

> 별 100개를 출력해야 한다면 `print`를 100번 쓸 건가요? "같은 일을 여러 번"을 컴퓨터에게 한 줄로 시키는 방법이 반복문입니다.

`for문` · `range` · `while문` · `break` · `들여쓰기` · `누적변수`

## 핵심요약

- 반복문은 "어떤 범위나 조건 안에서 같은 명령을 반복 수행"하는 도구다.
- `for`는 리스트 같은 **시퀀스의 원소를 하나씩 꺼내** 반복한다.
- `range(a, b)`는 **a 이상 b 미만**의 연속된 숫자를 만들어 준다(끝값 미포함).
- `for ... in range(...)`는 "정해진 횟수만큼" 반복할 때 쓴다.
- `while`은 **조건이 참인 동안** 계속 반복하며, 조건을 바꿔 줘야 멈춘다.
- 조건을 바꾸지 않으면 영원히 도는 **무한루프**가 되므로 `break`로 빠져나온다.
- 반복문 안에 들어갈 명령은 모두 **같은 들여쓰기**로 묶는다.
- 합계·개수 세기처럼 "값을 쌓아 가는" 작업은 누적 변수를 0(또는 빈 값)으로 두고 시작한다.

## 개념 정리

### for 문

**1. 정의**
시퀀스(리스트·문자열 등 순서 있는 자료)에서 원소를 하나씩 꺼내 변수에 담고, 그 변수로 같은 명령을 반복 실행하는 문법이다.

**2. 왜 필요한가?**
"고객 명단 전체에게 메일 보내기", "점수 리스트의 합 구하기"처럼 목록의 각 항목에 똑같은 처리를 해야 할 때가 데이터 작업의 대부분이다. for는 그 반복을 한 묶음으로 표현한다.

**3. 예시**
```python
sum_val = 0
for i in [1, 3, 5]:
    sum_val = sum_val + i   # i 에 1, 3, 5 가 순서대로 들어옴
print("합계:", sum_val)
# 합계: 9
```

**4. 헷갈리기 쉬운 점**
`for i in [1, 3, 5]:` 다음 줄은 반드시 들여써야 하며, 들여쓴 줄들만 반복 대상이다. 들여쓰기를 풀면 그 줄은 반복이 끝난 뒤 한 번만 실행된다(`print`가 반복 안에 있는지 밖에 있는지로 결과가 완전히 달라진다).

**5. 한 줄 정리**
for는 "목록의 원소를 하나씩 꺼내 같은 일을 시키는" 반복이다.

> 비유: 택배 상자(시퀀스)에서 물건을 하나씩 꺼내(`for`) 똑같이 포장(명령)하는 컨베이어 벨트.

### range

**1. 정의**
연속된 숫자를 만들어 주는 도구. `range(a, b)`는 a부터 시작해 b 바로 앞(b-1)까지의 숫자를 생성한다.

**2. 왜 필요한가?**
`[1, 2, 3, ... , 100]`을 손으로 타이핑하는 건 비효율적이다. "1부터 100까지"처럼 규칙적인 숫자 범위를 한 줄로 만들고 싶을 때 쓴다.

**3. 예시**
```python
print(range(1, 9))             # range 객체 그 자체
print(list(range(1, 9)))       # [1, 2, 3, 4, 5, 6, 7, 8]  ← b-1 까지!
print(list(range(5)))          # [0, 1, 2, 3, 4]
# range(1, 9)
# [1, 2, 3, 4, 5, 6, 7, 8]
# [0, 1, 2, 3, 4]
```

**4. 헷갈리기 쉬운 점**
끝값은 포함되지 않는다. `range(1, 9)`는 9가 아니라 8까지다. 또 `print(range(1, 9))`만 하면 숫자가 펼쳐지지 않고 `range(1, 9)`라고 나오므로, 내용을 눈으로 확인할 때는 `list()`로 감싼다. 인자를 하나만 주면(`range(5)`) 0부터 시작한다.

**5. 한 줄 정리**
range는 "시작~(끝-1)까지의 숫자 줄자"다.

### while 문

**1. 정의**
주어진 조건이 참(True)인 동안 명령을 계속 반복하고, 조건이 거짓이 되면 멈추는 문법이다.

**2. 왜 필요한가?**
"몇 번 반복할지 미리 모르고, 어떤 조건이 만족될 때까지" 반복해야 할 때 쓴다. 예를 들어 "사용자가 올바른 값을 넣을 때까지" 또는 "잔액이 0이 될 때까지" 같은 상황이다.

**3. 예시**
```python
i = 5
while i > 0:
    print(i)
    i = i - 1      # i 를 1씩 줄여야 종료 조건에 도달!
print("Launch! ")
# 5
# 4
# 3
# 2
# 1
# Launch!
```

**4. 헷갈리기 쉬운 점**
반복 안에서 조건에 쓰인 값(여기선 `i`)을 변화시키지 않으면 조건이 영원히 참이라 멈추지 않는다. while을 쓸 때는 "이 조건을 언젠가 거짓으로 만드는 줄"이 반드시 있어야 한다.

**5. 한 줄 정리**
while은 "조건이 참인 동안 계속"이고, 조건을 바꿔 줘야 끝난다.

> 비유: "신호가 빨간불인 동안(조건) 기다린다(명령)". 불이 바뀌어야 출발한다.

### break 문

**1. 정의**
반복문 안에서 만나는 즉시 그 반복문을 빠져나오게 하는 명령이다. 보통 `if`로 조건을 건 다음 실행한다.

**2. 왜 필요한가?**
"찾던 값을 발견하면 더 볼 필요 없이 멈추기", "무한루프를 특정 시점에 끊기"처럼, 끝까지 돌지 않고 중간에 탈출해야 할 때 쓴다.

**3. 예시**
```python
i = 1
while i > 0:
    print(i)
    if i >= 5:     # i가 5 이상이 되면 반복 탈출
        break
    i = i + 1
print("종료!")
# 1
# 2
# 3
# 4
# 5
# 종료!
```

**4. 헷갈리기 쉬운 점**
`break`는 자기를 감싼 가장 가까운 반복문 하나만 빠져나온다. 반복이 두 겹이면 안쪽 반복만 탈출한다.

**5. 한 줄 정리**
break는 "여기서 그만!"하고 반복을 즉시 끝내는 비상구다.

## 코드로 보기 — for-range로 "1~20의 짝수 합" 구하기

```python
even_sum = 0

for i in range(1, 21):
    if i % 2 == 0:          # 2로 나누어 떨어지면 짝수
        even_sum += i

print("1~20 짝수 합:", even_sum)
# 1~20 짝수 합: 110
```

**코드목적**
1부터 20까지 숫자를 차례로 보면서, 짝수일 때만 골라 합계에 더해 최종 합을 구한다.

**해석**
`range(1, 21)`이 1~20을 만들고, `i % 2 == 0`(2로 나눈 나머지가 0)이 짝수 판별이다. 짝수일 때만 `even_sum`에 더해서 2+4+6+...+20 = 110이 나온다. "범위 만들기(range) → 조건으로 거르기(if) → 누적하기(+=)"라는 데이터 처리의 기본 3박자가 한 자리에 모인 예제다.

**실무 연결**
"전체 주문 중 환불 건만 합산", "센서 측정값 중 기준치 초과한 횟수만 집계"처럼 데이터 분석·업무 자동화에서 "조건에 맞는 것만 골라 누적"하는 패턴이 그대로 반복문+조건문 조합으로 구현된다.

## 헷갈리기 쉬운 포인트

- **for vs while**: 반복 횟수나 대상 목록이 정해져 있으면 `for`(데이터 분석에서 주로 사용), 끝나는 시점을 조건으로만 판단해야 하면 `while`. 데이터는 보통 범위가 정해져 있어 for가 더 자연스럽다.
- **`range(1, 9)` vs `range(9)`**: 앞은 1~8, 뒤는 0~8. 인자가 하나면 0부터 시작하고, 둘이면 첫 값부터 시작한다. 둘 다 끝값은 미포함.
- **반복 안의 `print` vs 반복 밖의 `print`**: 들여쓰기로 구분된다. 안에 있으면 매 반복마다, 밖에 있으면 반복이 끝난 뒤 한 번만 출력된다.

## 셀프 체크

- [ ] `for i in [1, 3, 5]:`에서 i에 차례로 어떤 값이 들어가는지 말할 수 있다.
- [ ] `range(2, 5)`가 만드는 숫자를 정확히 안다.
- [ ] while 문이 무한루프에 빠지는 이유와 막는 방법을 설명할 수 있다.
- [ ] `break`가 어떤 상황에서 유용한지 예를 들 수 있다.
- [ ] 들여쓰기에 따라 반복 대상이 어떻게 달라지는지 구분할 수 있다.

**복습 질문 및 답변**

- (기본) `range(1, 5)`를 리스트로 만들면? → `[1, 2, 3, 4]`. 끝값 5는 포함되지 않는다.
- (이해 확인) `while i > 0:` 안에서 `i`를 줄이지 않으면 어떻게 되나요? → 조건이 항상 참이라 멈추지 않는 무한루프가 된다.
- (응용) 1부터 100까지의 수 중 3의 배수만 더하려면 어떤 조건과 누적 변수를 써야 할까요? → 누적 변수를 0으로 시작하고 `for i in range(1, 101): if i % 3 == 0: total += i`.

## 한 줄 정리

> 반복문은 "같은 일을 사람이 손으로 반복하는 수고"를 컴퓨터에게 넘기는 도구이며, for는 목록·횟수, while은 조건으로 반복하고 break로 빠져나온다.
