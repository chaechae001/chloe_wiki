# 리스트와 시퀀스 자료형 다루기

> 값 하나에 변수 하나씩 만들다 보면 변수가 수백 개가 됩니다. "여러 값을 순서대로 한 묶음에" 담는 그릇이 리스트이고, 리스트·문자열이 공유하는 공통 규칙이 시퀀스입니다.

`리스트` · `시퀀스` · `인덱싱` · `슬라이싱` · `append` · `split` · `join` · `pop`

## 핵심요약

- 리스트는 여러 값을 **순서대로** 담는 그릇으로, 대괄호 `[]`로 만든다.
- 리스트·문자열처럼 **순서(인덱스)가 있는 자료형**을 통틀어 시퀀스라 한다.
- 시퀀스는 공통적으로 인덱싱·슬라이싱·`in`·`len`·`+`·`*`를 지원한다.
- 인덱스는 0부터 시작하고, 음수 인덱스로 뒤에서부터 셀 수 있다.
- 리스트 메서드: `append`(끝에 추가), `insert`(위치 지정 추가), `remove`(값 제거), `sort`(정렬), `pop`(꺼내며 반환).
- `split`은 문자열을 리스트로 쪼개고, `join`은 리스트를 문자열로 합친다(서로 반대).
- 같은 종류의 시퀀스끼리 `+`로 이어 붙이고, `*`로 반복할 수 있다.
- `count`는 특정 값이 시퀀스 안에 몇 개 있는지 세어 준다.

## 개념 정리

### 리스트 추가·삭제·정렬 (append / insert / remove / sort)

**1. 정의**
리스트의 내용을 바꾸는 대표 동작들이다. `append(d)`는 맨 뒤에 하나 추가, `insert(i, d)`는 i번째 자리에 하나 끼워 넣기, `remove(d)`는 처음 나오는 값 하나 제거, `sort()`는 오름차순(문자열은 사전순) 정렬이다.

**2. 왜 필요한가?**
데이터는 고정돼 있지 않다. 새 주문이 들어오면 추가하고, 취소되면 빼고, 점수를 정렬해 순위를 매기는 일이 끊임없이 일어난다. 리스트가 "변경 가능(mutable)"하기 때문에 이런 작업이 가능하다.

**3. 예시**
```python
a = []
b = ["a", "b", "c"]
a.append(10)
b.append("d")
print(a, b)          # [10] ['a', 'b', 'c', 'd']

c = [1, 2, 4, 5]
c.insert(2, 3)       # 인덱스 2 자리에 3을 끼워 넣음
print(c)             # [1, 2, 3, 4, 5]

e = [6, 2, 4, 1]
e.sort()
print(e)             # [1, 2, 4, 6]
```

**4. 헷갈리기 쉬운 점**
`append`와 `sort`는 리스트 자체를 바꾸고 아무것도 돌려주지 않는다(반환값은 None). 그래서 `b = b.append("d")`처럼 다시 대입하면 b가 None이 되어 버린다. 그냥 `b.append("d")`만 쓰면 된다. 또 `remove`는 값으로 지우고(처음 하나만), 인덱스로 지우는 게 아니다.

**5. 한 줄 정리**
리스트는 추가·삽입·삭제·정렬로 자유롭게 내용을 바꿀 수 있는 그릇이다.

> 비유: 칸이 줄지어 있는 사물함. 끝 칸에 넣기(append), 중간에 끼우기(insert), 빼기(remove), 번호순 정리(sort).

### 인덱싱과 슬라이싱

**1. 정의**
인덱싱은 `자료[번호]`로 한 원소를 꺼내는 것, 슬라이싱은 `자료[시작:끝]`으로 일부 구간을 잘라 내는 것이다. 둘 다 순서가 있어야 가능하므로 시퀀스의 공통 기능이다.

**2. 왜 필요한가?**
"세 번째 값만", "앞 다섯 글자만", "뒤에서 두 번째"처럼 묶음의 일부만 꺼내 쓰는 일이 잦다. CSV 한 줄을 쪼갠 뒤 특정 칸만 읽을 때 핵심적으로 쓴다.

**3. 예시**
```python
a = "Hello"
b = ["e", "l", "i", "c", "e"]

print(a[1])     # e        (인덱스는 0부터)
print(b[2:4])   # ['i', 'c'] (2번째~3번째, 끝 4는 미포함)
print(a[-1])    # o        (뒤에서 첫 번째)
print(b[:4])    # ['e', 'l', 'i', 'c']  (처음~3번째)
print(b[2:])    # ['i', 'c', 'e']       (2번째~끝)
```

**4. 헷갈리기 쉬운 점**
인덱스는 1이 아니라 0부터 센다. 슬라이싱의 끝 번호는 포함되지 않는다(`b[2:4]`는 2와 3만). 자리를 비우면 "처음부터"(`[:4]`) 또는 "끝까지"(`[2:]`)라는 뜻이 된다.

**5. 한 줄 정리**
인덱싱은 한 칸, 슬라이싱은 구간을 꺼내며, 끝값은 포함하지 않는다.

### split과 join

**1. 정의**
`split(c)`은 문자열을 특정 문자 c 기준으로 쪼개 리스트로 만들고, `join(list)`은 리스트의 원소들을 특정 문자로 이어 붙여 문자열로 만든다. 정확히 반대 동작이다.

**2. 왜 필요한가?**
실제 데이터는 `"홍길동,25,서울"` 같은 한 덩어리 문자열로 들어오는 경우가 많다. split으로 쪼개 분석하고, 처리한 결과를 join으로 다시 하나의 문자열로 합쳐 저장·출력한다.

**3. 예시**
```python
my_str = "1 2 3 4 5"
print(my_str.split())          # ['1', '2', '3', '4', '5'] (괄호 비우면 공백 기준)

elements = "Na,Mg,Al,Si"
print(elements.split(","))     # ['Na', 'Mg', 'Al', 'Si']

stations = ["서울", "대전", "대구"]
print("→".join(stations))      # 서울→대전→대구
```

**4. 헷갈리기 쉬운 점**
`split`은 문자열만 가능하고, `join`은 "이어 붙일 기준 문자"가 앞에 오고 리스트가 괄호 안에 온다(`"→".join(리스트)`). 순서를 `리스트.join("→")`로 헷갈리기 쉽다. 또 `append`는 리스트만, `split`은 문자열만 되는 등 자료형마다 쓸 수 있는 기능이 다르다.

**5. 한 줄 정리**
split은 "문자열 → 리스트", join은 "리스트 → 문자열"이다.

> 비유: split은 김밥을 한 입 크기로 써는 것, join은 그 조각들을 꼬치에 다시 꿰는 것.

### pop과 count

**1. 정의**
`pop(i)`는 i번째 원소를 **제거하면서 그 값을 돌려준다**(괄호를 비우면 마지막 원소). `count(d)`는 시퀀스 안에 값 d가 몇 개 있는지 센다.

**2. 왜 필요한가?**
pop은 "대기열에서 한 명 꺼내 처리"처럼 빼면서 그 값을 바로 써야 할 때 유용하다. count는 "장바구니에 같은 상품이 몇 개 담겼나"처럼 빈도를 셀 때 쓴다.

**3. 예시**
```python
my_list = [2, 3, 5, 7, 11]
print(my_list.pop(0))   # 2  (맨 앞을 빼면서 반환)
print(my_list.pop())    # 11 (마지막을 빼면서 반환)
print(my_list)          # [3, 5, 7]

my_str = "elice and alice"
print(my_str.count("e"))  # 3
```

**4. 헷갈리기 쉬운 점**
`remove`는 값을 지우기만 하고 돌려주지 않지만, `pop`은 지운 값을 돌려준다는 점이 다르다. pop은 인덱스로, remove는 값으로 지운다.

**5. 한 줄 정리**
pop은 "빼면서 돌려주기", count는 "개수 세기"다.

## 코드로 보기 — split + 반복 + join으로 단어 꾸미기

```python
sentence = "파이썬 공부 열심히 하자"

words = sentence.split()        # 1단계: 문자열을 단어 리스트로
print("단어 리스트:", words)

new_words = []                  # 2단계: 가공 결과를 담을 빈 리스트
for w in words:
    new_words.append("★" + w + "★")

result = " ".join(new_words)    # 3단계: 다시 하나의 문자열로
print("결과:", result)
# 단어 리스트: ['파이썬', '공부', '열심히', '하자']
# 결과: ★파이썬★ ★공부★ ★열심히★ ★하자★
```

**코드목적**
문장을 단어 단위로 나눈 뒤, 각 단어를 별표로 감싸고, 다시 한 문장으로 합친다.

**해석**
"쪼개기(split) → 반복하며 가공(for + append) → 합치기(join)"라는 3단계 흐름이 핵심이다. 중간 결과를 바로 문자열로 붙이지 않고 일단 리스트(`new_words`)에 모은 뒤 마지막에 한 번 join하는 것이 깔끔하다. 얻는 것은 "원본 → 가공된 문자열"이다.

**실무 연결**
검색어에 형광펜 태그 붙이기, 로그 한 줄을 항목별로 분해해 다시 포맷 맞춰 저장하기, 사용자 입력 문장 정제하기 등 텍스트를 다루는 거의 모든 전처리 작업이 이 패턴을 따른다.

## 헷갈리기 쉬운 포인트

- **append vs insert**: append는 무조건 끝에, insert는 원하는 위치에. insert는 자리 번호를 함께 줘야 한다.
- **remove vs pop**: remove는 "값"으로 지우고 안 돌려준다. pop은 "인덱스"로 지우면서 그 값을 돌려준다.
- **sort vs sorted**: `리스트.sort()`는 원본을 직접 바꾸고 None을 반환한다. `sorted(리스트)`는 원본은 두고 정렬된 새 리스트를 돌려준다(이 글의 예제는 sort).
- **split vs join**: split은 문자열→리스트, join은 리스트→문자열. join은 `"구분자".join(리스트)` 순서에 주의.

## 셀프 체크

- [ ] 리스트와 문자열이 둘 다 시퀀스인 이유(공통 기능)를 말할 수 있다.
- [ ] `b[2:4]`가 어떤 원소를 반환하는지, 왜 끝값이 빠지는지 안다.
- [ ] `append`가 반환값으로 None을 준다는 사실과 그 함정을 안다.
- [ ] split과 join이 서로 반대 동작임을 설명할 수 있다.
- [ ] pop과 remove의 차이를 한 문장으로 구분할 수 있다.

**복습 질문 및 답변**

- (기본) `["a","b","c"].append("d")`의 결과는? → `['a', 'b', 'c', 'd']`. 맨 뒤에 하나가 추가된다.
- (이해 확인) `"a,b,c".split(",")`와 `"-".join(["a","b","c"])`의 결과를 각각 말해 보세요. → `['a', 'b', 'c']`와 `"a-b-c"`.
- (응용) 리스트 `[6, 2, 4, 1]`을 정렬하면서 원본은 그대로 두고 싶다면 `sort()`와 `sorted()` 중 무엇을 써야 할까요? → `sorted()`. 새 리스트를 돌려주므로 원본이 보존된다.

## 한 줄 정리

> 리스트는 순서 있는 값들을 자유롭게 추가·삭제·정렬하는 그릇이고, 시퀀스 공통 기능(인덱싱·슬라이싱·split·join)으로 문자열과도 자연스럽게 오갈 수 있다.
