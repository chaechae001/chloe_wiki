# 함수와 메서드

> 똑같은 계산을 코드 여기저기에 복붙해 두면, 고칠 일이 생겼을 때 전부 찾아 바꿔야 합니다. "자주 쓰는 동작에 이름을 붙여 한 번만 정의하고 계속 불러 쓰는" 것이 함수입니다.

`함수` · `return` · `매개변수` · `내장함수` · `메서드` · `변수범위` · `docstring`

## 핵심요약

- 함수는 "입력 → 처리 → 출력"의 한 덩어리를 이름 붙여 재사용하는 도구다.
- `int`·`str`·`max`·`min`·`sum`·`len` 등 파이썬이 미리 준 것이 **내장 함수**다.
- `def 함수명(매개변수):` + 들여쓰기 + `return`으로 **사용자 정의 함수**를 만든다.
- `return`이 있으면 결과를 밖에서 받아 쓸 수 있고, 없으면 반환값은 `None`이다.
- 매개변수가 모자라거나 많으면 에러가 나며, 에러 메시지로 원인을 읽을 수 있다.
- **함수**는 `함수(자료)`로, **메서드**는 `자료.동작()`으로 호출한다.
- 함수 안에서 만든 변수(지역 변수)는 함수 밖에서 쓸 수 없다(변수 범위).
- 타입 힌트와 docstring을 달면 함수의 입출력과 역할이 명확해진다.

## 개념 정리

### 내장 함수

**1. 정의**
파이썬이 기본으로 제공하는 함수들. `len`(길이), `int`/`str`/`float`(형 변환), `max`/`min`(최대·최소), `sum`(합계) 등이 대표적이다.

**2. 왜 필요한가?**
자주 쓰는 계산을 매번 직접 짜지 않아도 되도록 미리 만들어 둔 것이다. 평균·합계·최댓값 같은 건 내장 함수로 단번에 처리한다.

**3. 예시**
```python
scores = [85, 92, 78, 95, 88, 76, 90]
print(sum(scores))            # 604
print(len(scores))            # 7
print(sum(scores) / len(scores))  # 86.28...

data = (3, 1, 4, 1, 5, 9, 2, 6)
print(max(data))   # 9
print(min(data))   # 1
```

**4. 헷갈리기 쉬운 점**
`sum`, `min`, `list` 같은 내장 함수 이름을 변수명으로 쓰면 안 된다. 예를 들어 `sum = 10`이라고 하면 그 뒤로 `sum(...)` 함수가 덮어써져 못 쓰게 된다.

**5. 한 줄 정리**
내장 함수는 "이미 준비된 만능 도구 상자"다.

### 사용자 정의 함수와 return

**1. 정의**
`def`로 직접 만드는 함수. 매개변수로 입력을 받고, 처리한 결과를 `return`으로 돌려준다.

**2. 왜 필요한가?**
같은 처리를 여러 번 해야 할 때, 한 번 정의해 두고 이름만 불러 재사용한다. 고칠 일이 생기면 그 한 곳만 수정하면 된다.

**3. 예시**
```python
def plusDouble(a, b):
    c = a + b       # 두 수를 더함
    return 2 * c    # 합의 2배를 반환

result = plusDouble(3, 4)
print(result)       # (3+4)*2 = 14
```

`return`의 유무가 만드는 결정적 차이:
```python
def formula_no_return(a, b):
    c = (a**2) + (b**2)
    print("함수 안:", c)     # 출력은 되지만...

result = formula_no_return(2, 4)
print("함수 밖:", result)    # None ← 반환값이 없으면 None!

def formula_with_return(a, b):
    return (a**2) + (b**2)   # 값을 반환!

result = formula_with_return(2, 4)
print("함수 밖:", result)    # 20 ← 정상적으로 값을 받음
# 함수 안: 20
# 함수 밖: None
#
# 함수 밖: 20
```

**4. 헷갈리기 쉬운 점**
함수 안에서 `print`만 했다고 그 값을 밖에서 쓸 수 있는 게 아니다. `print`는 화면에 보여 줄 뿐이고, 결과를 변수에 담아 다른 계산에 쓰려면 반드시 `return`이 필요하다. return이 없으면 반환값은 `None`이다.

**5. 한 줄 정리**
`print`는 "보여 주기", `return`은 "넘겨 주기"다. 재사용하려면 return.

> 비유: 자판기에서 음료가 "나오는 것(return)"과 화면에 "준비 중이라고 표시되는 것(print)"은 다르다. 손에 쥐려면 음료가 나와야 한다.

### 매개변수 설계

**1. 정의**
함수가 입력으로 받는 값을 매개변수라 한다. 개수가 정해져 있고, 기본값을 줄 수도 있다.

**2. 왜 필요한가?**
같은 함수라도 다른 값을 넣어 다양한 상황에 쓰려면 입력을 받아야 한다. 또 "꼭 필요한 입력은 최소화하고 나머지는 기본값으로" 설계하면 쓰는 사람이 편하다.

**3. 예시**
```python
def greet(name, age):
    return f"안녕하세요! {name}님, {age}살이시군요."

print(greet("Alice", 25))   # 안녕하세요! Alice님, 25살이시군요.
print(greet("Bob",   30))   # 안녕하세요! Bob님, 30살이시군요.
```

**4. 헷갈리기 쉬운 점**
매개변수가 부족하면 `missing required positional argument`, 너무 많으면 `takes N positional arguments but M were given` 같은 에러가 난다. 에러 메시지는 "몇 개를 기대했는데 몇 개가 왔다"를 알려 주는 힌트다. 좋은 함수는 필수 입력을 적게 두고 나머지는 기본값으로 옵션화한다(예: 데이터 분석 라이브러리의 파일 읽기 함수는 경로 1개만 필수이고 나머지는 기본값).

**5. 한 줄 정리**
매개변수는 함수의 입력 창구이며, 필수는 적게·옵션은 기본값으로 설계한다.

### 함수 vs 메서드

**1. 정의**
함수는 `함수(자료)` 형태로 자료를 괄호 안에 넣어 부른다. 메서드는 `자료.동작()`처럼 자료 뒤에 점을 찍어 부른다.

**2. 왜 필요한가?**
둘 다 어떤 동작을 실행하지만 호출 모양이 다르다. 이 차이를 알아야 `len(my_list)`와 `my_list.append(9)`를 헷갈리지 않는다.

**3. 예시**
```python
my_list = [3, 1, 4, 1, 5]

# 함수: 자료를 괄호 안에 전달
print(len(my_list))   # 5
print(sum(my_list))   # 14
print(min(my_list))   # 1

# 메서드: 자료 뒤에 .을 찍어 사용
my_list.append(9)
my_list.sort()
print(my_list)            # [1, 1, 3, 4, 5, 9]
print(my_list.count(1))   # 2
```

**4. 헷갈리기 쉬운 점**
같은 일을 함수로도 메서드로도 할 수 있을 것 같지만, 자료형마다 쓸 수 있는 메서드가 정해져 있다. 문자열에는 `.upper()`가 있지만 리스트엔 없는 식이다.

**5. 한 줄 정리**
함수는 `도구(재료)`, 메서드는 `재료.도구()` 형태다.

### 변수 범위 (지역 변수 vs 전역 변수)

**1. 정의**
함수 안에서 만든 변수는 지역 변수로 그 함수 안에서만 살아 있고, 함수 밖에서 만든 변수는 전역 변수로 함수 안에서도 읽을 수 있다.

**2. 왜 필요한가?**
변수 이름이 겹쳐도 서로 간섭하지 않도록 "구역"을 나누기 위해서다. 이걸 모르면 "함수 안에서 바꿨는데 밖에선 안 바뀐다"는 혼란을 겪는다.

**3. 예시**
```python
def my_func(a):
    x = "Hi"       # 지역 변수: my_func 안에서만 존재
    print(a)

a = 3
my_func(a)         # 3

try:
    print(x)       # 함수 밖에서 x 접근 → NameError!
except NameError as e:
    print("에러:", e)
# 3
# 에러: name 'x' is not defined
```

이름이 같아도 지역과 전역은 별개다.
```python
score = 100   # 전역 변수

def update_score(new_score):
    score = new_score   # 지역 변수 (전역과 이름만 같음)
    print("함수 안 score:", score)

update_score(200)
print("함수 밖 score:", score)
# 함수 안 score: 200
# 함수 밖 score: 100
```

**4. 헷갈리기 쉬운 점**
함수 안에서 `score = 200`을 해도 그건 같은 이름의 새 지역 변수일 뿐, 전역 `score`는 그대로 100이다. 이름이 같다고 같은 변수가 아니다.

**5. 한 줄 정리**
함수 안 변수는 함수 안에서만 산다. 이름이 같아도 안과 밖은 별개다.

> 비유: 회의실(함수) 안에서 쓴 화이트보드 메모는 회의가 끝나면 지워진다. 복도(전역)의 게시판과는 다른 공간이다.

### 타입 힌트와 docstring

**1. 정의**
타입 힌트는 매개변수와 반환값의 자료형을 표기하는 것(`def add(a: int, b: int) -> int:`), docstring은 함수 바로 아래 삼중따옴표로 함수의 역할·인자·반환을 설명하는 문서다.

**2. 왜 필요한가?**
함수가 "무엇을 받아 무엇을 돌려주는지"를 코드만 봐도 알 수 있게 한다. 협업·재사용·유지보수에서 시간을 크게 아낀다. `help(함수)`로 docstring을 바로 확인할 수 있다.

**3. 예시**
```python
def celsius_to_fahrenheit(celsius: float) -> float:
    """섭씨 온도를 화씨 온도로 변환합니다.

    Args:
        celsius (float): 변환할 섭씨 온도 값

    Returns:
        float: 변환된 화씨 온도 값

    Example:
        >>> celsius_to_fahrenheit(100)
        212.0
    """
    return celsius * 9 / 5 + 32

help(celsius_to_fahrenheit)   # docstring 내용이 출력됨
```

**4. 헷갈리기 쉬운 점**
타입 힌트는 "이런 자료형을 의도했다"는 안내일 뿐, 다른 자료형을 넣어도 파이썬이 강제로 막지는 않는다(문서·도구 지원 목적). 그래도 의도를 분명히 해 주므로 다는 습관이 좋다.

**5. 한 줄 정리**
타입 힌트·docstring은 "이 함수 사용 설명서"를 코드에 붙이는 일이다.

## 코드로 보기 — 점수 리스트를 분석하는 함수

```python
def analyze_scores(score_list):
    """점수 리스트를 분석해 딕셔너리로 반환하는 함수"""
    return {
        "최고": max(score_list),
        "최저": min(score_list),
        "평균": round(sum(score_list) / len(score_list), 1),
        "합격(60+)": sum(1 for s in score_list if s >= 60)
    }

test_scores = [95, 82, 71, 58, 90, 65, 88, 44, 77, 93]
print("분석 결과:", analyze_scores(test_scores))
# 분석 결과: {'최고': 95, '최저': 44, '평균': 76.3, '합격(60+)': 8}
```

**코드목적**
점수 리스트 하나를 받아 최고·최저·평균·합격자 수를 한꺼번에 계산해 딕셔너리로 돌려준다.

**해석**
내장 함수(`max`, `min`, `sum`, `len`, `round`)를 조합해 여러 통계를 한 번에 만들고, 그 결과를 딕셔너리로 묶어 `return`한다. 함수로 만들었기 때문에 어떤 점수 리스트를 넣어도 같은 분석을 즉시 적용할 수 있다. "재사용 가능한 분석 단위"가 만들어진 셈이다.

**실무 연결**
설문 점수 요약, 매출 데이터의 핵심 지표 산출 등 "데이터를 넣으면 요약 지표를 돌려주는" 함수는 분석 업무의 기본 단위다. 같은 함수를 부서별·기간별 데이터에 반복 적용하면 일관된 리포트를 자동으로 뽑을 수 있다.

## 헷갈리기 쉬운 포인트

- **print vs return**: print는 화면 표시(반환값은 None), return은 값 넘기기. 결과를 변수에 담아 쓰려면 return.
- **함수 vs 메서드**: `len(x)`(함수)와 `x.append(9)`(메서드). 점(`.`)이 붙는지로 구분.
- **지역 변수 vs 전역 변수**: 함수 안에서 만든/대입한 변수는 기본적으로 지역. 이름이 같아도 밖의 전역과 별개.
- **내장 함수 이름 vs 내 변수 이름**: `sum`, `list`, `str` 등을 변수명으로 쓰면 원래 함수를 덮어써 못 쓰게 되니 피한다.

## 연결되는 개념

- 먼저 알면 좋은 것: [반복문](01-loops.md), [리스트와 시퀀스](02-sequence-list.md), [딕셔너리](04-dictionary.md). 함수는 이 도구들을 한 덩어리로 묶어 재사용한다.
- 다음으로 이어지는 것: 클래스(여러 함수와 데이터를 하나의 설계도로 묶기), 모듈·패키지(함수들을 파일로 모아 배포하기).
- 더 찾아볼 키워드: 기본값 매개변수(`def f(a, b=10)`), `*args`/`**kwargs`, 람다(lambda), PEP 8 스타일 가이드.

## 셀프 체크

- [ ] `def`로 함수를 만들고 `return`으로 값을 돌려받을 수 있다.
- [ ] return이 없는 함수의 반환값이 None임을 안다.
- [ ] 함수 호출과 메서드 호출의 형태 차이를 구분한다.
- [ ] 지역 변수와 전역 변수가 어떻게 다른지 예로 설명할 수 있다.
- [ ] 매개변수 부족·초과 시 에러 메시지의 의미를 읽을 수 있다.
- [ ] docstring을 달고 `help()`로 확인할 수 있다.

**복습 질문 및 답변**

- (기본) 함수에서 결과를 밖으로 넘기는 키워드는? → `return`. 없으면 반환값은 `None`이다.
- (이해 확인) `len(my_list)`와 `my_list.sort()`는 호출 방식이 어떻게 다른가요? → 앞은 함수(자료를 괄호에), 뒤는 메서드(자료 뒤에 점을 찍어 호출).
- (응용) 전역 변수 `score = 100`이 있을 때 함수 안에서 `score = 200`을 하면 함수 밖 `score`는 얼마이고 왜 그런가요? → 100. 함수 안 대입은 같은 이름의 새 지역 변수를 만들 뿐, 전역에는 영향이 없다.

## 한 줄 정리

> 함수는 자주 쓰는 동작을 이름 붙여 재사용하는 도구이며, `return`으로 결과를 넘기고 매개변수로 입력을 받으며, 지역/전역 변수 범위와 docstring까지 챙기면 신뢰할 수 있는 코드 단위가 된다.
