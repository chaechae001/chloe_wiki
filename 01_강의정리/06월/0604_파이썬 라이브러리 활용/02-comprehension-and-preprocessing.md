# 컴프리헨션과 데이터 전처리

> 빈 리스트를 만들고, for문을 돌리고, `append`로 하나씩 담는 세 줄짜리 작업. 이걸 한 줄로 줄일 수 있다면 어떨까요? 그리고 그 한 줄로 지저분한 데이터까지 청소할 수 있다면?

`리스트 컴프리헨션` `딕셔너리 컴프리헨션` `조건 필터링` `strip` `전처리` `리팩터링`

## 핵심요약

- 컴프리헨션은 반복문으로 리스트나 딕셔너리를 만드는 작업을 한 줄로 압축한 표현이다.
- 기본 형태는 `[표현식 for 항목 in 반복대상]`이다.
- 뒤에 `if 조건`을 붙이면 조건에 맞는 항목만 골라 담는 필터링이 된다.
- 딕셔너리도 같은 방식으로 `{키: 값 for ...}` 꼴로 만들 수 있다.
- `strip()`으로 공백을 없애고 빈 문자열을 걸러내는 등, 데이터 전처리에 자주 쓰인다.
- 처음에는 for문으로 정답을 만든 뒤 컴프리헨션으로 바꾸는(리팩터링) 순서를 추천한다.

## 개념별 정리

### 리스트 컴프리헨션 (List Comprehension)

**1. 정의**
`[표현식 for 항목 in 반복대상]` 한 줄로 새 리스트를 만드는 문법입니다.

**2. 왜 필요한가?**
"기존 데이터를 하나씩 가공해 새 리스트로 만드는" 작업은 정말 자주 일어납니다. for문으로 쓰면 서너 줄이 되는데, 컴프리헨션은 의도를 한 줄에 담아 코드가 짧고 읽기 좋아집니다.

**3. 예시**

```python
# 1부터 10까지의 제곱
squares = [x ** 2 for x in range(1, 11)]
print(squares)
# [1, 4, 9, 16, 25, 36, 49, 64, 81, 100]
```

같은 일을 for문으로 쓰면 이렇게 됩니다.

```python
squares = []
for x in range(1, 11):
    squares.append(x ** 2)
```

**4. 헷갈리기 쉬운 점**
컴프리헨션은 "값을 모아 새 리스트를 만드는" 용도입니다. 단순히 출력만 하거나 부수적인 동작만 하려고 컴프리헨션을 쓰면 오히려 읽기 어렵습니다. 그럴 땐 그냥 for문이 낫습니다.

**5. 한 줄 정리**
리스트 컴프리헨션은 "반복해서 가공한 결과를 한 줄로 모아 담는" 표현입니다.

> 비유: 컨베이어 벨트예요. 원재료(반복 대상)가 지나가면서 가공(표현식)되어 상자(새 리스트)에 차곡차곡 담깁니다.

### 조건 필터링 (if 포함)

**1. 정의**
`[표현식 for 항목 in 반복대상 if 조건]`처럼 뒤에 `if`를 붙여 조건에 맞는 항목만 담는 형태입니다.

**2. 왜 필요한가?**
전체가 아니라 "조건을 만족하는 일부"만 추리는 일은 데이터 작업의 절반입니다. 연봉 일정액 이상인 사람, 특정 카테고리 상품 등을 뽑을 때 씁니다.

**3. 예시**

```python
members = [
    {"name": "Alice", "team": "A", "salary": 5200},
    {"name": "Bob",   "team": "B", "salary": 4800},
    {"name": "Carol", "team": "A", "salary": 6100},
    {"name": "Dave",  "team": "B", "salary": 5500},
]

# 연봉 5000 이상인 멤버의 이름만 추출
high = [m["name"] for m in members if m["salary"] >= 5000]
print(high)
# ['Alice', 'Carol', 'Dave']
```

**4. 헷갈리기 쉬운 점**
`if`의 위치에 따라 의미가 다릅니다. 뒤에 오는 `... for ... in ... if 조건`은 **걸러내기(필터)**이고, 앞에 오는 `값A if 조건 else 값B for ...`는 **조건에 따라 값을 바꾸기**입니다. 후자(if-else)는 한 줄이 복잡해지므로 처음엔 for문으로 먼저 만들어 보는 게 안전합니다.

**5. 한 줄 정리**
뒤에 붙는 `if`는 "통과시킬 항목을 고르는 체"입니다.

### 딕셔너리 컴프리헨션 (Dictionary Comprehension)

**1. 정의**
`{키: 값 for 항목 in 반복대상}` 꼴로 딕셔너리를 만드는 문법입니다.

**2. 왜 필요한가?**
"이름 → 연봉"처럼 짝지어진 표(매핑)를 즉석에서 만들 때 유용합니다. 리스트를 빠르게 조회용 사전으로 바꿀 수 있습니다.

**3. 예시**

```python
name_to_salary = {m["name"]: m["salary"] for m in members}
print(name_to_salary)
# {'Alice': 5200, 'Bob': 4800, 'Carol': 6100, 'Dave': 5500}
```

**4. 헷갈리기 쉬운 점**
리스트 컴프리헨션은 대괄호 `[]`, 딕셔너리 컴프리헨션은 중괄호 `{}`에 **콜론(`:`)으로 키와 값을 구분**합니다. 중괄호인데 콜론이 없으면 딕셔너리가 아니라 집합(set)이 만들어집니다.

**5. 한 줄 정리**
딕셔너리 컴프리헨션은 "키-값 짝을 한 줄로 엮어 사전을 만드는" 표현입니다.

## 코드로 보기 — 지저분한 기술 목록 청소하기

```python
raw_skills = [" Python ", "", " SQL", "   ", "Excel "]

cleaned = [s.strip() for s in raw_skills if s.strip()]
print(cleaned)
# ['Python', 'SQL', 'Excel']
```

**코드목적**
양옆에 공백이 묻어 있고 중간에 빈 값까지 섞인 원시 데이터를, 사용할 수 있는 깔끔한 목록으로 정리하는 것이 목적입니다.

**해석**
한 줄 안에서 두 가지 일이 동시에 일어납니다. ① `s.strip()`이 각 항목의 양옆 공백을 제거하고(표현식), ② `if s.strip()`이 공백을 지운 결과가 비어 있지 않은 항목만 통과시킵니다(필터). 빈 문자열 `""`과 공백뿐인 `"   "`는 strip 후 빈 값이 되어 `if`에서 걸러집니다.

**실무 연결**
설문 응답, 엑셀에서 복사한 텍스트, 웹에서 수집한 데이터에는 거의 항상 공백과 빈 칸이 섞여 있습니다. 분석이나 저장 전에 이런 전처리를 거쳐야 결과가 깨지지 않습니다. 데이터 분석 파이프라인의 가장 첫 단계가 바로 이 청소 작업입니다.

## 헷갈리기 쉬운 포인트

- **뒤 `if`(필터) vs 앞 `if-else`(값 변환):** 전자는 항목을 걸러내고, 후자는 모든 항목을 남기되 값만 바꿉니다.
- **`[]`(리스트) vs `{}`(딕셔너리/집합):** 중괄호에 콜론이 있으면 딕셔너리, 없으면 집합입니다.
- **컴프리헨션 vs for문:** 결과를 모아 담을 땐 컴프리헨션, 복잡한 분기·여러 동작이 필요하면 for문이 읽기 좋습니다.

## 셀프 체크

- [ ] 리스트 컴프리헨션의 기본 형태를 쓸 수 있다.
- [ ] 뒤에 붙는 `if`가 필터 역할이라는 걸 안다.
- [ ] 딕셔너리 컴프리헨션과 집합의 차이(콜론 유무)를 안다.
- [ ] `strip()`으로 공백을 제거할 수 있다.
- [ ] 빈 문자열을 걸러내는 전처리 한 줄을 작성할 수 있다.
- [ ] for문 먼저 → 컴프리헨션 리팩터링 순서를 이해한다.

**복습 질문 및 답변**

- (기본) 컴프리헨션의 기본 골격은? → `[표현식 for 항목 in 반복대상]`.
- (이해 확인) `[s.strip() for s in raw if s.strip()]`에서 `if s.strip()`은 무엇을 하나요? → 공백을 지운 결과가 비어 있지 않은 항목만 남깁니다.
- (응용) `{}` 안에 콜론을 빼면 무엇이 만들어지나요? → 딕셔너리가 아니라 집합(set)이 만들어집니다.

## 한 줄 정리

> 컴프리헨션은 반복·조건·가공을 한 줄로 압축하는 표현이며, 공백 제거와 빈 값 필터링 같은 데이터 전처리에 특히 잘 맞습니다.
