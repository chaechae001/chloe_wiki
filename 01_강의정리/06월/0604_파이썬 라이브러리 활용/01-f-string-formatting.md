# f-string으로 문자열 예쁘게 만들기

> "점수: " + str(score) + "점" 이렇게 더하기로 문장을 잇다 보면 따옴표와 +가 뒤엉켜 금방 지저분해집니다. 변수를 문장 안에 그냥 끼워 넣을 수는 없을까요?

`f-string` `문자열 포맷` `format spec` `소수점` `천 단위` `퍼센트` `정렬`

## 핵심요약

- f-string은 문자열 앞에 `f`를 붙이고, 중괄호 `{}` 안에 변수나 식을 직접 넣는 방식이다.
- `+`로 문자열을 잇는 방식보다 읽기 쉽고, 숫자를 문자열로 바꾸는 `str()`도 필요 없다.
- 중괄호 안에는 변수뿐 아니라 `{a + b}` 같은 계산식도 넣을 수 있다.
- 콜론(`:`) 뒤에 형식을 지정하면 소수점 자리수, 천 단위 구분, 퍼센트 표기를 자동으로 처리한다.
- 폭과 정렬을 지정하면 표처럼 줄을 맞춰 출력할 수 있어 로그·표 출력의 가독성이 크게 좋아진다.
- 외울 필요는 없고, "이런 게 가능하다"만 알고 필요할 때 찾아 쓰면 충분하다.

## 개념별 정리

### f-string 기본 형태

**1. 정의**
문자열 앞에 `f`를 붙인 문자열입니다. 중괄호 안에 변수 이름을 적으면 그 자리에 변수의 값이 들어갑니다.

**2. 왜 필요한가?**
사람이 읽는 출력(보고서 문장, 로그, 안내 메시지)을 만들 때, 고정된 글자와 변하는 값을 섞어야 합니다. f-string은 그 둘을 한 문장 안에서 자연스럽게 합쳐 줍니다.

**3. 예시**

```python
name = "Alice"
score = 92.5
print(f"{name}님의 점수는 {score}점입니다.")
# Alice님의 점수는 92.5점입니다.

a, b = 3, 5
print(f"{a} + {b} = {a + b}")
# 3 + 5 = 8
```

**4. 헷갈리기 쉬운 점**
맨 앞의 `f`를 빠뜨리면 `{name}`이 값으로 바뀌지 않고 글자 그대로 출력됩니다. 중괄호를 글자로 그대로 쓰고 싶다면 `{{`, `}}`처럼 두 번 적습니다.

**5. 한 줄 정리**
f-string은 "문장 안 빈칸에 변수를 끼워 넣는" 가장 깔끔한 방법입니다.

> 비유: 빈칸 채우기 안내문 같은 거예요. "( )님 환영합니다"의 괄호 안에 이름을 그때그때 넣는 것과 같습니다.

### 숫자 포맷 지정 (format spec)

**1. 정의**
중괄호 안에서 `값:형식` 꼴로 콜론 뒤에 표기 방식을 지정하는 기능입니다.

**2. 왜 필요한가?**
돈(1,234,567원), 비율(87.50%), 소수점 둘째 자리(3.14)처럼 같은 숫자라도 보여 주는 형태가 달라야 할 때가 많습니다. 매번 손으로 자르고 붙이는 대신 형식만 지정하면 됩니다.

**3. 예시**

```python
pi = 3.14159
print(f"{pi:.2f}")    # 3.14   (소수점 둘째 자리)
print(f"{pi:.0f}")    # 3      (소수점 없이 정수처럼)

price = 1234567
print(f"{price:,}원")  # 1,234,567원  (천 단위 구분)

rate = 0.875
print(f"{rate:.2%}")  # 87.50%  (소수를 100배 해 % 표기)
```

**4. 헷갈리기 쉬운 점**
`:.2%`는 0.875를 그대로 0.875%로 쓰는 게 아니라, **100을 곱한 뒤** 87.50%로 표기합니다. 이미 87.5라는 값을 가지고 있다면 `%`를 쓰지 말고 `f"{rate}%"`처럼 직접 붙여야 합니다.

**5. 한 줄 정리**
콜론 뒤 형식 지정으로 "같은 숫자, 다른 옷차림"을 손쉽게 만듭니다.

### 폭과 정렬

**1. 정의**
`{값:<10}`(왼쪽 정렬), `{값:>10}`(오른쪽 정렬)처럼 출력 폭과 방향을 지정하는 기능입니다.

**2. 왜 필요한가?**
여러 줄을 출력할 때 칸을 맞추면 표처럼 보여 한눈에 들어옵니다. 로그나 간단한 목록 출력에서 특히 유용합니다.

**3. 예시**

```python
rows = [("Alice", 92), ("Bob", 7)]
for name, score in rows:
    print(f"{name:<8}|{score:>4}")
# Alice   |  92
# Bob     |   7
```

**4. 헷갈리기 쉬운 점**
폭은 "최소 폭"입니다. 값이 폭보다 길면 잘리지 않고 그대로 다 나옵니다. 칸을 맞추려는 거지 글자를 자르려는 게 아닙니다.

**5. 한 줄 정리**
폭·정렬 지정은 출력을 "표처럼 줄 세우는" 도구입니다.

## 코드로 보기 — 한 줄 매출 요약 만들기

```python
product = "노트북"
sales = 1234567
share = 0.213

print(f"[{product:<6}] 매출 {sales:,}원 (점유율 {share:.1%})")
# [노트북   ] 매출 1,234,567원 (점유율 21.3%)
```

**코드목적**
제품명, 매출, 점유율이라는 서로 다른 종류의 값을 사람이 읽기 좋은 한 문장으로 합치는 것이 목적입니다.

**해석**
`{product:<6}`은 제품명을 왼쪽 정렬로 6칸 확보해 줄을 맞추고, `{sales:,}`는 큰 숫자에 천 단위 쉼표를 넣고, `{share:.1%}`는 0.213을 21.3%로 바꿉니다. 세 가지 변환이 출력 시점에 한꺼번에 일어납니다.

**실무 연결**
데이터 분석 결과를 요약 메시지로 뽑거나, 자동화 스크립트가 슬랙·메일로 보낼 알림 문구를 만들 때 그대로 쓰입니다. 표 형태 로그를 남길 때도 정렬 지정이 빛을 발합니다.

## 헷갈리기 쉬운 포인트

- **`f` 붙임 vs 안 붙임:** `f"{x}"`는 x의 값으로, `"{x}"`는 글자 그대로 출력됩니다.
- **`:.2f` vs `:.2%`:** 둘 다 소수 둘째 자리지만, `%`는 100을 곱한 뒤 퍼센트 기호를 붙입니다.
- **`+` 연결 vs f-string:** `+`는 숫자를 `str()`로 변환해야 하지만, f-string은 알아서 처리합니다.

## 셀프 체크

- [ ] f-string 앞에 `f`를 붙이는 이유를 설명할 수 있다.
- [ ] 중괄호 안에 계산식을 넣을 수 있다는 걸 안다.
- [ ] `:.2f`, `:,`, `:.2%`가 각각 무엇을 하는지 구분할 수 있다.
- [ ] `:.2%`가 값에 100을 곱한다는 점을 기억한다.
- [ ] 폭·정렬 지정으로 출력을 줄 맞춤할 수 있다.

**복습 질문 및 답변**

- (기본) f-string은 어떻게 시작하나요? → 문자열 따옴표 앞에 `f`를 붙입니다.
- (이해 확인) `f"{0.5:.2%}"`의 결과는? → `50.00%`. 0.5에 100을 곱하고 소수 둘째 자리까지 표기합니다.
- (응용) 매출 `980000`을 `98만 원` 단위로 보여 주려면? → 직접 나눠서 `f"{sales // 10000}만 원"`처럼 계산식을 넣으면 됩니다.

## 한 줄 정리

> f-string은 변하는 값과 고정된 글자를 한 문장에 섞고, 콜론 뒤 형식으로 숫자의 표기까지 단번에 정돈해 주는 도구입니다.
