# 용어집 (Glossary)

이번 강의에서 나온 핵심 용어를 학습 흐름 순서로 정리했습니다. "쉬운 설명"은 비전공자 눈높이의 한 줄 요약이고, "관련 강의명"은 그 용어를 자세히 다루는 글입니다. 더 깊이 알고 싶다면 "함께 보면 좋은 개념"을 따라가 보세요.

## 중급 문법

| 용어 | 쉬운 설명 | 관련 강의명 | 함께 보면 좋은 개념 |
| --- | --- | --- | --- |
| f-string | 문자열 앞에 `f`를 붙이고 중괄호 `{}` 안에 변수나 식을 직접 끼워 넣어 문장을 만드는 방식 | 01 f-string으로 문자열 예쁘게 만들기 | format spec, 문자열 메서드 |
| format spec | 중괄호 안 콜론(`:`) 뒤에 적어 소수점·천 단위·퍼센트·정렬 등 숫자 표기 방식을 정하는 형식 | 01 f-string으로 문자열 예쁘게 만들기 | f-string, 반올림 |
| 컴프리헨션(comprehension) | 반복문으로 리스트·딕셔너리를 만드는 작업을 한 줄로 압축한 표현 | 02 컴프리헨션과 데이터 전처리 | 조건 필터링, map/filter |
| 리스트 컴프리헨션 | `[표현식 for 항목 in 반복대상]` 한 줄로 새 리스트를 만드는 문법 | 02 컴프리헨션과 데이터 전처리 | 딕셔너리 컴프리헨션, for문 |
| 딕셔너리 컴프리헨션 | `{키: 값 for ...}` 꼴로 사전(매핑)을 한 줄로 만드는 문법 | 02 컴프리헨션과 데이터 전처리 | 집합(set), 매핑 |
| strip() | 문자열 양옆의 공백을 제거하는 메서드, 데이터 청소에 자주 쓰임 | 02 컴프리헨션과 데이터 전처리 | 전처리, 조건 필터링 |
| sort / sorted | `sort()`는 원본 리스트를 직접 정렬(반환값 없음), `sorted()`는 정렬된 새 리스트를 반환 | 03 정렬·람다·enumerate | key, reverse |
| key | 정렬할 때 "무엇을 기준으로 비교할지"를 정하는 함수 자리 | 03 정렬·람다·enumerate | lambda, 다중 정렬 |
| lambda | 이름 없이 그 자리에서 쓰고 버리는 일회용 함수 | 03 정렬·람다·enumerate | key, map/filter |
| enumerate | 반복할 때 순번(인덱스)과 값을 함께 꺼내 주는 함수 | 03 정렬·람다·enumerate | for문, start 옵션 |
| map / filter | `map`은 모든 항목에 같은 변환을 적용, `filter`는 조건을 통과한 항목만 남김(보통 람다와 함께) | 03 정렬·람다·enumerate | 컴프리헨션, 지연 객체 |

| 외부 라이브러리 | 별도 설치가 필요하며 보통 PyPI로 배포되는 라이브러리(`pandas` 등) | 04 라이브러리·모듈·패키지·프레임워크 기초 | PyPI, pip |
