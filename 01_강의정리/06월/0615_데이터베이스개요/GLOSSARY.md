# 용어집 (GLOSSARY)

| 용어 | 쉬운 설명 | 관련 강의명 | 함께 보면 좋은 개념 |
| --- | --- | --- | --- |
| 데이터(Data) | 가공되지 않은 사실과 값의 모음 (재료) | 데이터베이스 개요 | 정보, 데이터베이스 |
| 정보(Information) | 데이터를 목적에 맞게 가공·해석한 결과 (요리) | 데이터베이스 개요 | 데이터, 데이터 분석 |
| 데이터베이스(Database) | 여러 사용자가 공동으로 쓰기 위해 통합·저장·운영하는 데이터의 묶음 | 데이터베이스 개요 | DBMS, 무결성 |
| DBMS | 데이터베이스를 관리하는 소프트웨어 | 데이터베이스 개요 | RDB, NoSQL |
| 무결성(Integrity) | 데이터가 정확하고 일관된 형태로 유지되는 성질 | 데이터베이스 개요 | 제약 조건, 키 |
| 데이터 종속 | 데이터 구조가 바뀌면 프로그램 구조도 바꿔야 하는 문제 | 데이터베이스 개요 | 파일 처리 시스템 |
| 데이터 중복 | 같은 데이터가 여러 곳에 따로 저장되는 문제 | 데이터베이스 개요 | 관계, 정규화 |
| RDB(관계형 DB) | 행과 열의 테이블로 데이터를 관리하는 DB | 데이터베이스 개요 | SQL, NoSQL |
| NoSQL | 관계를 엄격히 정의하지 않는 유연한 DB | 데이터베이스 개요 | RDB, 빅데이터 |
| RDBMS | 관계형 DB를 관리하는 시스템 (MySQL, PostgreSQL 등) | 데이터베이스 개요 | RDB |
| 테이블(Table) | 행과 열로 구성된 데이터의 표 | 관계형 DB 구조와 SQL 기본 | 속성, 튜플 |
| 속성(Attribute)/열 | 데이터의 특성을 나타내는 가장 작은 논리 단위 (세로) | 관계형 DB 구조와 SQL 기본 | 튜플, 도메인 |
| 튜플(Tuple)/행 | 속성이 모여 이룬 하나의 행 (가로) | 관계형 DB 구조와 SQL 기본 | 속성, 기본키 |
| 도메인(Domain) | 한 속성이 가질 수 있는 값의 범위 | 관계형 DB 구조와 SQL 기본 | 속성, 데이터 타입 |
| SQL | 관계형 DB를 다루는 표준 언어 | 관계형 DB 구조와 SQL 기본 | DDL, DML, DCL |
| DDL | 데이터 구조를 정의하는 SQL (CREATE/ALTER/DROP) | 관계형 DB 구조와 SQL 기본 | CREATE TABLE |
| DML | 데이터를 조회·조작하는 SQL (INSERT/SELECT) | 관계형 DB 구조와 SQL 기본 | SELECT |
| DCL | DB 접근 권한을 관리하는 SQL | 관계형 DB 구조와 SQL 기본 | 권한 관리 |
| VARCHAR(n) | 가변 길이 문자열 데이터 타입 | 관계형 DB 구조와 SQL 기본 | INT, DATETIME |
| INT / FLOAT | 정수 / 부동 소수점 숫자 데이터 타입 | 관계형 DB 구조와 SQL 기본 | 데이터 타입 |
| DATETIME | 날짜와 시간 형태의 데이터 타입 | 관계형 DB 구조와 SQL 기본 | 데이터 타입 |
| NULL | 비어 있는 값 (↔ NOT NULL) | 제약 조건 | NOT NULL, UNIQUE |
| 제약 조건(Constraint) | 잘못된 데이터 입력을 막는 규칙 | 제약 조건 | 무결성 |
| NOT NULL | 빈 값을 허용하지 않는 제약 조건 (필수 입력) | 제약 조건 | NULL, DEFAULT |
| UNIQUE | 중복 값을 허용하지 않는 제약 조건 | 제약 조건 | 기본키, NULL |
| DEFAULT | 값 미입력 시 자동으로 채울 기본값 | 제약 조건 | NOT NULL |
| CHECK | 값의 범위를 제한하는 제약 조건 | 제약 조건 | 비즈니스 규칙 |
| CONSTRAINT | 제약 조건에 이름을 붙여 관리하는 키워드 | 제약 조건 | ALTER TABLE |
| 기본키(Primary Key) | 행을 유일하게 식별하는 속성 (중복·NULL 불가) | 키와 무결성 | 외래키, 개체 무결성 |
| 외래키(Foreign Key) | 다른 테이블의 기본키를 참조해 관계를 잇는 속성 | 키와 무결성 | 참조 무결성, 관계 |
| 후보키 | 유일성·최소성을 모두 만족하는 키 | 키와 무결성 | 대체키, 슈퍼키 |
| 대체키 | 후보키 중 기본키가 아닌 키 | 키와 무결성 | 후보키 |
| 슈퍼키 | 유일성은 만족하나 최소성은 만족하지 않는 키 | 키와 무결성 | 후보키 |
| 복합 기본키 | 두 개 이상의 컬럼을 묶어 만든 기본키 | 키와 무결성 | 연결 테이블, N:M |
| 개체 무결성 | 기본키는 NULL·중복 값을 가질 수 없다는 규칙 | 키와 무결성 | 기본키 |
| 참조 무결성 | 외래키는 부모 기본키에 존재하는 값이어야 한다는 규칙 | 키와 무결성 | 외래키 |
| 데이터 모델링 | 현실 데이터를 DB 구조로 옮기는 설계 과정 | 데이터 모델링과 ERD | 개체, 속성, 관계 |
| 개체(Entity) | 데이터로 표현할 현실의 개념·정보 단위 | 데이터 모델링과 ERD | 속성, 관계 |
| 관계(Relationship) | 개체 간의 연관성 (예: 대여한다) | 데이터 모델링과 ERD | 카디널리티 |
| ERD | 데이터를 개체·관계 형태로 그린 다이어그램 | 데이터 모델링과 ERD | Peter Chen, IE |
| Peter Chen 표기법 | 도형(사각형·타원·마름모)으로 개념을 그리는 ERD 표기법 | 데이터 모델링과 ERD | IE 표기법 |
| IE 표기법 | 키·타입·제약까지 상세히 그리는 ERD 표기법 | 데이터 모델링과 ERD | 까마귀발 |
| 까마귀발(crow's foot) | 관계 참여 수(0/1/다수)를 나타내는 IE 기호 | 데이터 모델링과 ERD | 카디널리티 |
| 카디널리티 | 한 데이터가 다른 데이터 몇 개와 관계를 맺는지 (1:1/1:N/N:M) | 데이터 모델링과 ERD | 관계, 복합 기본키 |
