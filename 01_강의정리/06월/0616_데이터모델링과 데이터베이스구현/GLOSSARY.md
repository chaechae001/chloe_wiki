# 용어집 (GLOSSARY)

이번 강의에 등장한 핵심 용어를 쉬운 말로 정리했습니다.

| 용어 | 쉬운 설명 | 관련 강의명 | 함께 보면 좋은 개념 |
| ---- | --------- | ----------- | ----------- |
| 이상 현상(Anomaly) | 잘못된 설계 때문에 데이터를 넣고·고치고·지울 때 생기는 부작용 | 데이터 모델링 | 삽입/갱신/삭제 이상, 정규화 |
| 삽입 이상 | 다른 정보가 없으면 필요한 데이터를 넣을 수 없거나 의미가 불명확해지는 문제 | 데이터 모델링 | 함수 종속, 2NF |
| 갱신 이상 | 중복 저장된 값 중 일부만 고쳐서 데이터가 어긋나는 문제 | 데이터 모델링 | 중복, 무결성 |
| 삭제 이상 | 어떤 데이터를 지울 때 함께 저장된 다른 정보까지 사라지는 문제 | 데이터 모델링 | 테이블 분리, 외래키 |
| 함수 종속(Functional Dependency) | A 값을 알면 B 값이 하나로 정해지는 관계(A → B) | 데이터 모델링 | 결정자, 종속자 |
| 결정자 | 다른 속성의 값을 정하는 쪽(A → B에서 A) | 데이터 모델링 | 종속자, 후보키 |
| 종속자 | 결정자에 의해 값이 정해지는 쪽(A → B에서 B) | 데이터 모델링 | 결정자 |
| 완전 함수 종속 | 복합키 전체가 있어야 결정되는 종속 | 데이터 모델링 | 부분 함수 종속, 2NF |
| 부분 함수 종속 | 복합키의 일부만으로 결정되는 종속 | 데이터 모델링 | 2NF, 복합키 |
| 이행 함수 종속 | A→B, B→Z라서 결국 A→Z가 성립하는, 한 다리 건넌 종속 | 데이터 모델링 | 3NF |
| 정규화(Normalization) | 종속·중복을 분석해 테이블을 나눠 이상 현상을 없애는 과정 | 데이터 모델링 | 1NF~5NF, 무결성 |
| 원자값(Atomic Value) | 더 이상 나눌 수 없는 하나의 값 | 데이터 모델링 | 1NF |
| 1차 정규화(1NF) | 모든 컬럼이 원자값(값 하나)을 갖게 하는 단계 | 데이터 모델링 | 원자값, 다중값 |
| 2차 정규화(2NF) | 부분 함수 종속을 제거해 완전 함수 종속만 남기는 단계 | 데이터 모델링 | 복합키, 외래키 |
| 3차 정규화(3NF) | 이행 함수 종속을 제거하는 단계 | 데이터 모델링 | 이행 종속, 마스터 테이블 |
| BCNF | 모든 결정자가 후보키가 되도록 만든, 더 엄격한 3NF | 데이터 모델링 | 후보키, 결정자 |
| 4차 정규화(4NF) | 서로 독립적인 다중값(다치 종속)을 제거하는 단계 | 데이터 모델링 | 다치 종속 |
| 5차 정규화(5NF) | 분해 후 재결합 시 가짜 행이 생기는 조인 종속을 제거하는 단계 | 데이터 모델링 | 조인 종속, 손실 없는 분해 |
| 다치 종속 | 한 키에 서로 독립적인 여러 값이 따라붙는 관계 | 데이터 모델링 | 4NF |
| 조인 종속 | 테이블을 나눴다 합칠 때 원본에 없던 행이 생기는 관계 | 데이터 모델링 | 5NF, JOIN |
| 역정규화(Denormalization) | 성능을 위해 정규화된 테이블을 의도적으로 다시 합치는 것 | 데이터 모델링 | 트레이드오프, 성능 |
| 복합키 | 두 개 이상의 컬럼을 합쳐 만든 기본키 | 데이터 모델링 | 기본키, 부분 종속 |
| 기본키(Primary Key) | 테이블에서 행을 유일하게 구분하는 열쇠 | 데이터베이스 구현 | 외래키, 후보키 |
| 외래키(Foreign Key) | 다른 테이블의 기본키를 가리키는 연결 고리 | 데이터베이스 구현 | 기본키, 참조 무결성 |
| 후보키 | 행을 유일하게 식별할 수 있는 속성(집합) 후보 | 데이터 모델링 | 기본키, BCNF |
| ERD | 테이블과 그 관계를 그림으로 나타낸 설계도 | 데이터 모델링 | 기본키, 외래키 |
| RDBMS | 데이터를 테이블 형태로 저장·관리하는 시스템(예: MySQL) | 데이터베이스 구현 | 데이터베이스, 테이블 |
| 데이터베이스 | 여러 테이블을 담는 가장 큰 단위의 그릇 | 데이터베이스 구현 | CREATE DATABASE, 테이블 |
| CREATE DATABASE | 데이터베이스를 새로 만드는 명령 | 데이터베이스 구현 | USE, DROP DATABASE |
| USE | 작업 대상 데이터베이스를 지정하는 명령 | 데이터베이스 구현 | CREATE DATABASE |
| DCL(데이터 제어어) | 데이터베이스 접근 권한을 관리하는 명령 그룹 | 데이터베이스 구현 | GRANT, REVOKE |
| GRANT | 사용자에게 권한을 부여하는 명령 | 데이터베이스 구현 | REVOKE, FLUSH PRIVILEGES |
| REVOKE | 사용자의 권한을 회수하는 명령 | 데이터베이스 구현 | GRANT |
| FLUSH PRIVILEGES | 변경한 권한 설정을 즉시 적용하는 명령 | 데이터베이스 구현 | GRANT, REVOKE |
| TCL(트랜잭션 제어어) | 작업 묶음을 저장·취소하는 명령 그룹 | 데이터베이스 구현 | COMMIT, ROLLBACK |
| COMMIT | 트랜잭션 작업을 확정해 저장하는 명령 | 데이터베이스 구현 | ROLLBACK, 트랜잭션 |
| ROLLBACK | 트랜잭션 작업을 취소해 이전 상태로 되돌리는 명령 | 데이터베이스 구현 | COMMIT |
| 트랜잭션 | 함께 성공하거나 함께 실패해야 하는 작업의 묶음 단위 | 데이터베이스 구현 | COMMIT, ROLLBACK |
| 인덱스(Index) | 검색 속도를 높이기 위한 색인 같은 자료구조 | 데이터베이스 구현 | WHERE, JOIN, 중복도 |
