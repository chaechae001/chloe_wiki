# 확률분포와 랜덤 샘플링
> 확률분포는 데이터가 어떤 모양으로 발생할지 미리 그려보는 지도다.

`확률분포` · `베르누이분포` · `이항분포` · `초기하분포` · `포아송분포` · `균일분포` · `정규분포` · `PMF` · `PDF` · `CDF`

## 핵심요약

- 확률분포는 확률변수가 가질 수 있는 값과 그 값이 나올 가능성을 함께 나타낸다.
- 이산 확률분포는 셀 수 있는 값에 대한 분포이고, 연속 확률분포는 구간 안에서 연속적인 값을 갖는 분포다.
- 베르누이분포는 성공/실패처럼 결과가 2개인 한 번의 시행을 다룬다.
- 이항분포는 같은 성공확률을 가진 베르누이 시행을 여러 번 반복했을 때 성공 횟수를 다룬다.
- 초기하분포는 비복원 추출에서 관심 있는 항목이 몇 개 뽑히는지 다룬다.
- 포아송분포는 단위 시간 또는 단위 공간 안에서 드물게 발생하는 사건의 횟수를 다룬다.
- 균일분포는 특정 구간 안의 값이 같은 가능성으로 나타나는 연속분포다.
- 정규분포는 평균을 중심으로 좌우가 대칭인 종 모양 분포이며 많은 통계검정의 출발점이다.

## 확률분포의 큰 분류

### 이산 확률분포

**1. 정의**  
확률변수의 값이 정수처럼 셀 수 있는 경우의 분포다. 예를 들어 성공 횟수, 불량품 개수, 방문 고객 수처럼 개수로 세는 값이 여기에 해당한다.

**2. 왜 필요한가?**  
비즈니스에서는 “몇 명이 구매했는가”, “몇 건의 오류가 발생했는가”, “몇 개가 불량인가”처럼 개수를 분석하는 일이 많다.

**3. 예시**

```python
# 성공 횟수처럼 정수 값이 나오는 경우
x_values = [0, 1, 2, 3]
```

**4. 헷갈리기 쉬운 점**  
이산분포에서는 특정 값의 확률 `P(X=x)`를 직접 계산할 수 있다. 그래서 PMF, 즉 확률질량함수를 사용한다.

**5. 한 줄 정리**  
이산분포는 셀 수 있는 결과의 확률을 다룬다.

### 연속 확률분포

**1. 정의**  
확률변수의 값이 실수처럼 연속적인 경우의 분포다. 키, 몸무게, 시간, 매출액처럼 구간 안에서 매우 많은 값을 가질 수 있는 경우가 여기에 해당한다.

**2. 왜 필요한가?**  
실무 데이터에는 측정값이 많다. 고객 체류시간, 주문금액, 전환율처럼 연속적인 값의 패턴을 이해하려면 연속분포가 필요하다.

**3. 예시**

```python
# 0부터 1 사이의 실수값
x_values = [0.1, 0.35, 0.72]
```

**4. 헷갈리기 쉬운 점**  
연속분포에서는 정확히 `X=0.5`가 될 확률은 거의 0으로 본다. 대신 `0.4 <= X <= 0.6`처럼 구간 확률을 계산한다.

**5. 한 줄 정리**  
연속분포는 값 하나보다 구간의 가능성을 다룬다.

## 이산 확률분포

### 베르누이분포

**1. 정의**  
한 번의 시행 결과가 성공 또는 실패 두 가지뿐일 때 사용하는 분포다. 성공확률은 `p`, 실패확률은 `1-p`다.

**2. 왜 필요한가?**  
클릭 여부, 합격 여부, 구매 여부처럼 0/1로 표현되는 데이터를 이해하는 출발점이다.

**3. 예시**

```python
import scipy.stats as stats

p = 0.7
x = [0, 1]
prob = stats.bernoulli(p).pmf(x)
print(prob)
```

**4. 헷갈리기 쉬운 점**  
베르누이분포는 한 번의 시행만 다룬다. 여러 번 반복했을 때 성공 횟수를 보고 싶다면 이항분포를 사용한다.

**5. 한 줄 정리**  
베르누이분포는 한 번의 성공/실패 실험이다.

### 이항분포

**1. 정의**  
성공확률이 같은 베르누이 시행을 독립적으로 n번 반복했을 때 성공 횟수 X의 분포다. 보통 `X ~ B(n, p)`로 표현한다.

**2. 왜 필요한가?**  
광고 100회 노출 중 클릭 수, 지원자 50명 중 합격자 수처럼 반복 시행에서 성공 횟수를 알고 싶을 때 사용한다.

**3. 예시**

```python
import scipy.stats as stats

n = 10
p = 0.3
x = 3

stat_bin = stats.binom(n, p)
print(stat_bin.pmf(x))   # 정확히 3번 성공할 확률
print(stat_bin.cdf(x))   # 3번 이하 성공할 누적확률
```

**4. 헷갈리기 쉬운 점**  
이항분포는 각 시행이 서로 독립이고 성공확률이 같다는 가정이 중요하다. 뽑은 것을 다시 넣지 않는 상황이라면 초기하분포가 더 적절하다.

**5. 한 줄 정리**  
이항분포는 같은 조건의 성공/실패 시행을 여러 번 반복한 결과다.

### 초기하분포

**1. 정의**  
유한한 모집단에서 비복원 추출할 때, 관심 있는 범주에 속하는 구성원이 몇 개 뽑히는지 나타내는 분포다.

**2. 왜 필요한가?**  
상자에서 공을 뽑고 다시 넣지 않는 경우, 표본검사에서 불량품 개수를 세는 경우처럼 한 번 뽑은 결과가 다음 추출에 영향을 주는 상황에 필요하다.

**3. 예시**

```python
import scipy.stats as stats

# 전체 10개 중 관심 항목 6개, 표본 5개를 뽑을 때 관심 항목이 3개 나올 확률
M = 10      # 모집단 크기
n = 6       # 관심 항목 수
N = 5       # 표본 크기
x = 3

stat_hyp = stats.hypergeom(M, n, N)
print(stat_hyp.pmf(x))
```

**4. 헷갈리기 쉬운 점**  
이항분포는 복원 또는 독립 반복에 가깝고, 초기하분포는 비복원 추출이다. “뽑은 뒤 다시 넣는가?”를 먼저 확인해야 한다.

**5. 한 줄 정리**  
초기하분포는 뽑은 것을 다시 넣지 않는 상황의 성공 개수 분포다.

### 포아송분포

**1. 정의**  
단위 시간이나 단위 공간에서 드물게 발생하는 사건의 횟수를 설명하는 분포다. 평균 발생 횟수는 `λ`로 표현한다.

**2. 왜 필요한가?**  
일정 시간 동안 발생하는 불량품 수, 톨게이트 통과 차량 수, 페이지 작성 중 발생하는 오타 수처럼 횟수 데이터를 다룰 때 사용된다.

**3. 예시**

```python
import scipy.stats as stats

lam = 2
x = 3

stat_poi = stats.poisson(lam)
print(stat_poi.pmf(x))   # 평균 2회 발생할 때 정확히 3회 발생할 확률
print(stat_poi.cdf(x))   # 3회 이하 발생할 확률
```

**4. 헷갈리기 쉬운 점**  
포아송분포는 “횟수”를 다루지만 아무 횟수나 해당하지 않는다. 특정 단위 안에서 드물고 독립적으로 발생하는 사건에 잘 맞는다.

**5. 한 줄 정리**  
포아송분포는 정해진 구간에서 드물게 일어나는 사건 수를 설명한다.

## 연속 확률분포

### 균일분포

**1. 정의**  
구간 `[a, b]`에 속하는 값이 같은 가능성으로 나타나는 분포다. `X ~ U(a, b)`로 표현한다.

**2. 왜 필요한가?**  
랜덤 샘플을 만들거나, 특정 범위 안에서 편향 없이 값을 뽑는 시뮬레이션에 사용된다.

**3. 예시**

```python
import numpy as np

samples = np.random.uniform(0, 1, 5)
print(samples)
```

**4. 헷갈리기 쉬운 점**  
균일분포는 모든 값이 정확히 같은 확률로 나온다는 뜻이 아니라, 같은 길이의 구간들이 같은 확률을 가진다는 뜻이다.

**5. 한 줄 정리**  
균일분포는 특정 구간 안에서 치우침 없이 값이 나오는 분포다.

### 정규분포

**1. 정의**  
평균을 중심으로 좌우가 대칭인 종 모양의 연속분포다. 평균과 표준편차로 모양이 정해진다.

**2. 왜 필요한가?**  
t-검정, ANOVA, 회귀분석 등 많은 모수 검정은 정규분포를 전제로 한다. 중심극한정리도 정규분포를 이해하는 데 핵심이다.

**3. 예시**

```python
import scipy.stats as stats

mu = 0
sigma = 1
x = 1.96

stat_norm = stats.norm(mu, sigma)
print(stat_norm.cdf(x))
```

**4. 헷갈리기 쉬운 점**  
원 데이터가 반드시 정규분포여야 하는 경우와 표본평균의 분포가 정규분포에 가까워지는 경우를 구분해야 한다.

**5. 한 줄 정리**  
정규분포는 많은 통계검정의 기준이 되는 대표적인 연속분포다.

## 코드로 보기 — scipy.stats로 확률값 계산하기

```python
import scipy.stats as stats
import numpy as np

# 이항분포: 10번 중 3번 성공할 확률
stat_bin = stats.binom(10, 0.3)
print(stat_bin.pmf(3))

# 초기하분포: 전체 10개, 관심 항목 6개, 5개 추출 중 3개 성공
stat_hyp = stats.hypergeom(10, 6, 5)
print(stat_hyp.pmf(3))

# 포아송분포: 평균 2회 발생할 때 3회 발생
stat_poi = stats.poisson(2)
print(stat_poi.pmf(3))

# 정규분포: 표준정규분포에서 1.96 이하 누적확률
stat_norm = stats.norm(0, 1)
print(stat_norm.cdf(1.96))
```

**코드목적**  
분포 객체를 만든 뒤 특정 값의 확률 또는 누적확률을 계산한다.

**해석**  
`pmf()`는 이산분포에서 특정 값이 나올 확률, `cdf()`는 특정 값 이하가 나올 누적확률이다. 연속분포에서는 `pdf()`로 밀도를 보고, 실제 확률은 구간의 넓이로 해석한다.

**실무 연결**  
품질검사에서 불량품 개수, 광고 캠페인에서 클릭 수, 서비스 장애 발생 횟수, 고객 지표의 분포를 해석할 때 사용된다.

## 직접 해보기

1. 성공확률이 0.2인 광고를 20번 노출했을 때 클릭이 정확히 5번 발생할 확률을 계산해보기.
2. 평균 3회 발생하는 오류가 하루에 0회 발생할 확률을 포아송분포로 계산해보기.
3. 표준정규분포에서 `-1.96`부터 `1.96` 사이에 들어올 확률을 계산해보기.

## 헷갈리기 쉬운 포인트

| 구분 | 핵심 차이 | 판단 질문 |
| --- | --- | --- |
| 베르누이 vs 이항 | 한 번 시행 vs 여러 번 시행 | 시행을 몇 번 하는가? |
| 이항 vs 초기하 | 독립 반복 vs 비복원 추출 | 뽑은 것을 다시 넣는가? |
| 이항 vs 포아송 | 정해진 시행 횟수의 성공 수 vs 단위 구간의 발생 횟수 | 전체 시행 횟수가 명확한가? |
| PMF vs PDF | 특정 값의 확률 vs 밀도 | 이산형인가, 연속형인가? |
| CDF vs PMF/PDF | 누적확률 vs 한 값의 확률/밀도 | 이하 또는 이상 확률을 보는가? |

Q. 클릭 여부는 어떤 분포로 볼 수 있는가?  
A. 한 번의 클릭 여부라면 베르누이분포로 볼 수 있다.

Q. 광고 100번 노출 중 클릭 수는 어떤 분포로 볼 수 있는가?

Q. 비복원 추출에서 관심 항목 개수를 세는 분포는 무엇인가?  
A. 초기하분포다.
