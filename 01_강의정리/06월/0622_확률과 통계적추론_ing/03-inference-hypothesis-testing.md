# 통계적 추론과 가설검정
> 가설검정은 “내 주장이 맞다”를 증명하는 과정이 아니라, 우연으로 보기 어려운 근거가 있는지 확인하는 과정이다.

`통계적 추론` · `모집단` · `표본` · `중심극한정리` · `귀무가설` · `대립가설` · `p-value` · `유의수준` · `제1종 오류` · `제2종 오류`

## 핵심요약

- 통계적 추론은 표본 데이터를 이용해 모집단의 특성을 판단하는 과정이다.
- 전수조사는 가장 확실하지만 현실적으로 어렵기 때문에 표본조사를 사용한다.
- 표본조사는 항상 오차 가능성이 있으므로 샘플링 방식이 중요하다.
- 중심극한정리는 표본평균들의 분포가 정규분포에 가까워진다는 통계검정의 핵심 이론이다.
- 귀무가설은 보통 “차이 없음, 변화 없음, 연관 없음”을 뜻한다.
- 대립가설은 분석자가 표본을 통해 근거를 가지고 주장하고 싶은 가설이다.
- p-value가 유의수준보다 작으면 귀무가설을 기각하고, 작지 않으면 귀무가설을 기각하지 못한다.
- 모든 통계적 의사결정에는 제1종 오류와 제2종 오류 가능성이 있다.

## 통계적 추론

### 모집단과 표본

**1. 정의**  
모집단은 알고 싶은 전체 대상이고, 표본은 모집단에서 일부만 뽑은 데이터다.

**2. 왜 필요한가?**  
전체 고객, 전체 지원자, 전체 제품을 모두 조사하는 것은 대부분 어렵다. 그래서 일부 표본을 통해 전체를 추정한다.

**3. 예시**

```python
import pandas as pd

# 전체 고객 중 일부 표본을 뽑는 상황
sample_df = df.sample(n=100, random_state=42)
print(sample_df.shape)
```

**4. 헷갈리기 쉬운 점**  
데이터가 많다고 항상 좋은 표본은 아니다. 특정 그룹에 치우친 데이터는 큰 표본이어도 편향될 수 있다.

**5. 한 줄 정리**  
표본은 모집단을 대신 보는 창문이다.

### 샘플링과 편향

**1. 정의**  
샘플링은 모집단에서 표본을 뽑는 과정이다. 편향은 표본이 모집단을 제대로 대표하지 못하는 상태다.

**2. 왜 필요한가?**  
표본이 왜곡되면 통계검정 결과도 왜곡된다. 분석에서 중요한 것은 단순한 데이터 양이 아니라 대표성이다.

**3. 예시**

```python
# 그룹 비율을 유지하며 표본 추출하는 간단한 예시
sample_df = (
    df.groupby("group", group_keys=False)
      .apply(lambda x: x.sample(frac=0.1, random_state=42))
)
```

**4. 헷갈리기 쉬운 점**  
무작위 추출도 표본 수가 작거나 특정 집단이 누락되면 불안정할 수 있다. 그룹별 비율이 중요할 때는 층화추출을 고려한다.

**5. 한 줄 정리**  
좋은 표본은 큰 표본이 아니라 모집단을 잘 닮은 표본이다.

### 중심극한정리

**1. 정의**  
원래 데이터가 정규분포가 아니더라도, 충분히 큰 표본을 반복해서 뽑아 표본평균들의 분포를 만들면 정규분포에 가까워진다는 정리다.

**2. 왜 필요한가?**  
t-검정, ANOVA, 회귀분석 같은 모수 검정은 정규분포 아이디어 위에서 작동한다. 중심극한정리는 표본으로 모집단을 추론할 수 있게 해주는 핵심 근거다.

**3. 예시**

```python
import numpy as np

population = np.random.exponential(scale=2, size=10000)
sample_means = []

for _ in range(1000):
    sample = np.random.choice(population, size=30, replace=True)
    sample_means.append(sample.mean())

print(round(np.mean(sample_means), 3))
```

**4. 헷갈리기 쉬운 점**  
중심극한정리는 원 데이터 자체가 정규분포로 바뀐다는 뜻이 아니다. 표본평균들의 분포가 정규분포에 가까워진다는 뜻이다.

**5. 한 줄 정리**  
중심극한정리는 표본평균을 믿고 추론할 수 있게 해주는 다리다.

## 가설검정의 기본 구조

### 귀무가설과 대립가설

**1. 정의**  
귀무가설은 기존 상태 또는 차이가 없다는 가설이다. 대립가설은 표본을 통해 근거를 가지고 입증하고 싶은 가설이다.

**2. 왜 필요한가?**  
가설이 명확하지 않으면 분석 결과를 해석할 수 없다. 평균 차이를 보려는지, 연관성을 보려는지, 효과를 보려는지에 따라 검정 방법이 달라진다.

**3. 예시**

```text
H0: 온라인 채널과 오프라인 채널의 월매출 평균은 같다.
H1: 온라인 채널과 오프라인 채널의 월매출 평균은 다르다.
```

**4. 헷갈리기 쉬운 점**  
통계검정에서 관심 있는 것은 보통 대립가설이다. 하지만 출발은 귀무가설이 맞다고 가정한 뒤, 이를 기각할 만큼 강한 증거가 있는지 확인한다.

**5. 한 줄 정리**  
가설검정은 귀무가설을 기준점으로 삼아 대립가설의 근거를 확인하는 절차다.

### p-value와 유의수준

**1. 정의**  
p-value는 귀무가설이 참이라고 가정했을 때, 현재 표본 결과처럼 극단적인 결과가 나올 확률이다. 유의수준 `α`는 귀무가설을 기각할지 판단하는 기준이다.

**2. 왜 필요한가?**  
분석 결과가 우연인지 의미 있는 차이인지 판단하려면 기준이 필요하다. 보통 `α = 0.05`를 많이 사용하지만, 분야에 따라 0.01 또는 0.1을 사용하기도 한다.

**3. 예시**

```python
alpha = 0.05
p_value = 0.03

if p_value < alpha:
    print("귀무가설 기각")
else:
    print("귀무가설을 기각하지 못함")
```

**4. 헷갈리기 쉬운 점**  
p-value가 0.03이라는 말은 “대립가설이 97% 확률로 맞다”는 뜻이 아니다. 귀무가설이 맞다고 가정했을 때 현재 결과가 얼마나 드문지를 나타낸다.

**5. 한 줄 정리**  
p-value는 우연으로 보기 어려운 정도를 나타내는 지표다.

### 제1종 오류와 제2종 오류

**1. 정의**  
제1종 오류는 실제로 귀무가설이 참인데 잘못 기각하는 오류다. 제2종 오류는 실제로 귀무가설이 거짓인데 기각하지 못하는 오류다.

**2. 왜 필요한가?**  
통계적 판단은 항상 틀릴 가능성이 있다. 특히 제1종 오류는 “차이가 없는데 차이가 있다고 말하는 것”이므로 보수적인 분야에서는 유의수준을 낮게 잡는다.

**3. 예시**

```text
제1종 오류: 효과가 없는데 효과가 있다고 결론냄
제2종 오류: 효과가 있는데 효과가 없다고 결론냄
```

**4. 헷갈리기 쉬운 점**  
유의수준을 낮추면 제1종 오류 가능성은 줄지만, 반대로 진짜 효과를 놓칠 가능성은 커질 수 있다.

**5. 한 줄 정리**  
가설검정은 항상 오류 가능성을 관리하는 의사결정이다.

## 주요 가설검정 기법

### 단일표본 t-검정

**1. 정의**  
하나의 표본평균이 알려진 모집단 평균과 같은지 비교하는 검정이다.

**2. 왜 필요한가?**  
예를 들어 어떤 집단의 평균 키가 기준값 75와 다른지 확인할 때 사용한다.

**3. 예시**

```python
from scipy import stats

t_score, p_value = stats.ttest_1samp(df["Height"], popmean=75)
print(round(t_score, 2), round(p_value, 2))
```

**4. 헷갈리기 쉬운 점**  
비교 대상은 두 그룹이 아니라 “하나의 표본”과 “기준 평균”이다.

**5. 한 줄 정리**  
단일표본 t-검정은 표본평균이 기준값과 다른지 보는 검정이다.

### 독립표본 t-검정

**1. 정의**  
서로 독립인 두 집단의 평균이 같은지 비교하는 검정이다.

**2. 왜 필요한가?**  
온라인 채널과 오프라인 채널, 남성과 여성, A상품 구매자와 B상품 구매자처럼 서로 다른 두 그룹의 평균을 비교할 때 사용한다.

**3. 예시**

```python
from scipy import stats

levene_stat, levene_p = stats.levene(group_a, group_b)
equal_var = levene_p >= 0.05

t_stat, p_value = stats.ttest_ind(group_a, group_b, equal_var=equal_var)
print(t_stat, p_value)
```

**4. 헷갈리기 쉬운 점**  
독립표본 t-검정 전에는 정규성과 등분산성을 확인한다. 등분산성이 깨지면 Welch t-test를 사용한다.

**5. 한 줄 정리**  
독립표본 t-검정은 서로 다른 두 그룹의 평균 차이를 검정한다.

### 대응표본 t-검정

**1. 정의**  
같은 대상의 전후 변화처럼 서로 짝이 있는 두 측정값의 평균 차이를 검정한다.

**2. 왜 필요한가?**  
교육 전후 점수, 캠페인 전후 전환율, 임상실험 전후 지표처럼 같은 대상의 변화량을 보고 싶을 때 사용한다.

**3. 예시**

```python
from scipy import stats

t_stat, p_value = stats.ttest_rel(post, pre, alternative="greater")
print(t_stat, p_value)
```

**4. 헷갈리기 쉬운 점**  
전후 데이터는 독립된 두 그룹이 아니다. 같은 대상이 두 번 측정된 것이므로 대응표본 t-검정을 사용해야 한다.

**5. 한 줄 정리**  
대응표본 t-검정은 같은 대상의 변화가 유의한지 확인한다.

### ANOVA와 카이제곱 검정

**1. 정의**  
ANOVA는 3개 이상 집단의 평균 차이를 동시에 검정한다. 카이제곱 검정은 범주형 변수 간 독립성 또는 관측도수가 기대도수와 맞는지 검정한다.

**2. 왜 필요한가?**  
직군이 4개 이상일 때 평균 점수를 비교하거나, 채용 전형 유형과 합격 여부처럼 두 범주형 변수가 연관되어 있는지 확인할 때 사용한다.

**3. 예시**

```python
from scipy import stats
from scipy.stats import chi2_contingency
import pandas as pd

# ANOVA
f_stat, p_value = stats.f_oneway(group1, group2, group3)

# 카이제곱 독립성 검정
ct = pd.crosstab(df["category"], df["result"])
chi2, p, dof, expected = chi2_contingency(ct)
```

**4. 헷갈리기 쉬운 점**  
ANOVA에서 귀무가설을 기각해도 “어떤 그룹끼리 다른지”는 바로 알 수 없다. 이때 사후검정이 필요하다.

**5. 한 줄 정리**  
ANOVA는 여러 평균 비교, 카이제곱은 범주형 변수 관계 확인에 사용한다.

## 코드로 보기 — 가설검정 의사결정 흐름

```python
alpha = 0.05

if p_value < alpha:
    decision = "귀무가설 기각"
    interpretation = "통계적으로 유의한 차이 또는 관계가 있음"
else:
    decision = "귀무가설을 기각하지 못함"
    interpretation = "통계적으로 유의하다고 보기 어려움"

print(decision)
print(interpretation)
```

**코드목적**  
p-value와 유의수준을 비교해 검정 결과를 일관되게 해석한다.

**해석**  
p-value가 0.05보다 작으면 귀무가설을 기각한다. 크거나 같으면 귀무가설을 기각할 충분한 근거가 없다고 해석한다.

**실무 연결**  
분석 보고서에서 “평균 차이가 있다”, “연관성이 있다”, “효과가 있다”는 결론을 낼 때 사용되는 기본 판단 구조다.

## 헷갈리기 쉬운 포인트

| 구분 | 핵심 차이 | 예시 |
| --- | --- | --- |
| 귀무가설 vs 대립가설 | 기준 상태 vs 입증하고 싶은 주장 | 차이 없음 vs 차이 있음 |
| p-value vs 유의수준 | 관측 결과의 드묾 vs 판단 기준 | 0.03 vs 0.05 |
| 독립표본 vs 대응표본 | 서로 다른 대상 vs 같은 대상의 전후 | 남녀 평균 비교 vs 캠페인 전후 비교 |
| ANOVA vs t-검정 | 3개 이상 평균 비교 vs 1~2개 평균 비교 | 직군 4개 비교 vs 두 채널 비교 |
| 제1종 오류 vs 제2종 오류 | 없는 효과를 있다고 함 vs 있는 효과를 놓침 | 과대판단 vs 과소판단 |

> 가설검정은 표본에서 나온 차이나 관계가 우연으로 보기 어려운지 판단하는 절차이며, 결론은 항상 오류 가능성과 함께 해석해야 한다.
