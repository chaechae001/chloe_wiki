# 용어집

| 용어 | 쉬운 설명 | 관련 강의명 | 함께 보면 좋은 개념 |
| ---- | --------- | ----------- | ----------- |
| 확률 | 어떤 사건이 일어날 가능성을 0과 1 사이 숫자로 표현한 값 | 확률의 기본 언어와 경우의 수 | 사건, 표본공간 |
| 실험 | 가능한 결과가 여러 개인 행위 | 확률의 기본 언어와 경우의 수 | 표본공간 |
| 표본공간 | 실험에서 나올 수 있는 모든 결과의 집합 | 확률의 기본 언어와 경우의 수 | 사건 |
| 사건 | 표본공간 중 관심 있는 일부 결과 | 확률의 기본 언어와 경우의 수 | 여사건, 합사건 |
| 여사건 | 사건 A가 일어나지 않는 모든 경우 | 확률의 기본 언어와 경우의 수 | `1 - P(A)` |
| 합사건 | A 또는 B가 일어나는 사건 | 확률의 기본 언어와 경우의 수 | 합의 법칙 |
| 곱사건 | A와 B가 동시에 일어나는 사건 | 확률의 기본 언어와 경우의 수 | 조건부 확률 |
| 배반사건 | 동시에 일어날 수 없는 사건 | 확률의 기본 언어와 경우의 수 | 합사건 |
| 팩토리얼 | 1부터 n까지 모두 곱한 값 | 확률의 기본 언어와 경우의 수 | 순열 |
| 순열 | 순서를 고려해 뽑는 방법 | 확률의 기본 언어와 경우의 수 | 팩토리얼, 곱의 법칙 |
| 조합 | 순서를 고려하지 않고 뽑는 방법 | 확률의 기본 언어와 경우의 수 | 순열 |
| 중복순열 | 중복을 허용하고 순서도 고려해 뽑는 방법 | 확률의 기본 언어와 경우의 수 | `product` |
| 중복조합 | 중복은 허용하지만 순서는 고려하지 않는 방법 | 확률의 기본 언어와 경우의 수 | `combinations_with_replacement` |
| 확률변수 | 사건의 결과를 숫자로 나타낸 변수 | 확률분포와 랜덤 샘플링 | 확률분포 |
| 확률분포 | 확률변수가 가질 수 있는 값과 확률을 나타낸 것 | 확률분포와 랜덤 샘플링 | PMF, PDF, CDF |
| 이산 확률분포 | 셀 수 있는 값의 확률분포 | 확률분포와 랜덤 샘플링 | 베르누이분포, 이항분포 |
| 연속 확률분포 | 실수처럼 연속적인 값의 확률분포 | 확률분포와 랜덤 샘플링 | 균일분포, 정규분포 |
| 베르누이분포 | 성공/실패 한 번의 시행을 설명하는 분포 | 확률분포와 랜덤 샘플링 | 이항분포 |
| 이항분포 | 베르누이 시행을 여러 번 반복했을 때 성공 횟수의 분포 | 확률분포와 랜덤 샘플링 | 베르누이분포 |
| 초기하분포 | 비복원 추출에서 관심 항목 개수의 분포 | 확률분포와 랜덤 샘플링 | 이항분포 |
| 포아송분포 | 단위 시간/공간에서 드물게 발생하는 사건 횟수의 분포 | 확률분포와 랜덤 샘플링 | 발생 횟수 |
| 균일분포 | 특정 구간에서 값이 치우침 없이 나타나는 분포 | 확률분포와 랜덤 샘플링 | 연속분포 |
| 정규분포 | 평균을 중심으로 좌우 대칭인 종 모양 분포 | 확률분포와 랜덤 샘플링 | 중심극한정리 |
| PMF | 이산분포에서 특정 값의 확률을 주는 함수 | 확률분포와 랜덤 샘플링 | 이산 확률분포 |
| PDF | 연속분포에서 특정 지점의 밀도를 주는 함수 | 확률분포와 랜덤 샘플링 | 연속 확률분포 |
| CDF | 특정 값 이하가 나올 누적확률을 주는 함수 | 확률분포와 랜덤 샘플링 | 누적확률 |
| 모집단 | 알고 싶은 전체 대상 | 통계적 추론과 가설검정 | 표본 |
| 표본 | 모집단에서 일부만 뽑은 데이터 | 통계적 추론과 가설검정 | 샘플링 |
| 샘플링 | 모집단에서 표본을 뽑는 과정 | 통계적 추론과 가설검정 | 편향, 층화추출 |
| 층화추출 | 그룹 비율을 유지하며 표본을 뽑는 방식 | 통계적 추론과 가설검정 | 편향 |
| 중심극한정리 | 표본평균들의 분포가 정규분포에 가까워진다는 정리 | 통계적 추론과 가설검정 | 표본분포 |
| 귀무가설 | 차이 없음, 변화 없음, 연관 없음처럼 기준이 되는 가설 | 통계적 추론과 가설검정 | 대립가설 |
| 대립가설 | 표본을 통해 입증하고 싶은 가설 | 통계적 추론과 가설검정 | 귀무가설 |
| 검정통계량 | 가설검정에서 p-value 계산의 기준이 되는 표본 통계량 | 통계적 추론과 가설검정 | t값, F값, chi2값 |
| p-value | 귀무가설이 참일 때 현재 결과처럼 극단적인 결과가 나올 확률 | 통계적 추론과 가설검정 | 유의수준 |
| 유의수준 | 귀무가설 기각 여부를 판단하는 기준 | 통계적 추론과 가설검정 | 제1종 오류 |
| 제1종 오류 | 실제로 차이가 없는데 있다고 판단하는 오류 | 통계적 추론과 가설검정 | 유의수준 |
| 제2종 오류 | 실제로 차이가 있는데 없다고 판단하는 오류 | 통계적 추론과 가설검정 | 검정력 |
| 단일표본 t-검정 | 하나의 표본평균을 기준 평균과 비교하는 검정 | 통계적 추론과 가설검정 | t-검정 |
| 독립표본 t-검정 | 서로 다른 두 집단의 평균을 비교하는 검정 | 통계분석 실습과 회귀·분류 모델 | 등분산성 |
| 대응표본 t-검정 | 같은 대상의 전후 평균 차이를 비교하는 검정 | 통계분석 실습과 회귀·분류 모델 | 변화량 |
| ANOVA | 3개 이상 집단의 평균 차이를 비교하는 검정 | 통계분석 실습과 회귀·분류 모델 | 사후검정 |
| Tukey HSD | ANOVA 이후 어떤 집단끼리 차이가 있는지 확인하는 사후검정 | 통계분석 실습과 회귀·분류 모델 | ANOVA |
| 카이제곱 검정 | 범주형 변수 간 독립성 또는 기대도수 적합성을 검정하는 방법 | 통계분석 실습과 회귀·분류 모델 | 교차표 |
| 다중회귀분석 | 여러 독립변수로 연속형 종속변수를 예측하는 분석 | 통계분석 실습과 회귀·분류 모델 | R², 회귀계수 |
| 로지스틱 회귀분석 | 0/1 결과의 발생 확률을 예측하는 분석 | 통계분석 실습과 회귀·분류 모델 | 오즈, 로짓 |
| 오즈 | 사건이 일어날 확률을 일어나지 않을 확률로 나눈 값 | 통계분석 실습과 회귀·분류 모델 | 로짓 |
| 로짓 | 오즈에 로그를 취한 값 | 통계분석 실습과 회귀·분류 모델 | 로지스틱 함수 |
| 로지스틱 함수 | 어떤 실수 입력도 0과 1 사이 확률로 바꾸는 함수 | 통계분석 실습과 회귀·분류 모델 | 시그모이드 |
| 정확도 | 전체 예측 중 맞힌 비율 | 통계분석 실습과 회귀·분류 모델 | 분류모델 평가 |
