# 확률의 기본 언어와 경우의 수
> 확률 문제는 계산보다 먼저 “무엇을 사건으로 볼 것인가”를 정하는 일이 중요하다.

`확률` · `표본공간` · `사건` · `여사건` · `합사건` · `곱사건` · `배반사건` · `순열` · `조합`

## 핵심요약

- 확률은 여러 가능한 결과 중 특정 사건이 발생할 가능성을 0과 1 사이 숫자로 표현한 값이다.
- 표본공간은 실험에서 나올 수 있는 모든 결과의 집합이고, 사건은 그중 관심 있는 일부 결과의 집합이다.
- 사건의 확률은 `사건에 속하는 결과 수 / 전체 가능한 결과 수`로 계산한다.
- 여사건은 “그 사건이 일어나지 않는 경우”이며, `P(Aᶜ) = 1 - P(A)`로 계산한다.
- 합사건은 A 또는 B가 일어나는 경우, 곱사건은 A와 B가 동시에 일어나는 경우다.
- 순열은 순서를 고려해 뽑는 방법이고, 조합은 순서를 고려하지 않고 뽑는 방법이다.
- 중복을 허용하는지, 순서를 고려하는지에 따라 순열·조합·중복순열·중복조합을 구분한다.

## 확률의 기본 개념

### 확률

**1. 정의**  
확률은 어떤 사건이 일어날 가능성을 숫자로 표현한 값이다. 0은 절대 일어나지 않음, 1은 반드시 일어남을 의미한다.

**2. 왜 필요한가?**  
데이터 분석에서는 대부분 “확실한 답”이 아니라 “그럴 가능성이 높은 답”을 다룬다. 예를 들어 고객이 이탈할 확률, 광고를 클릭할 확률, 합격할 확률처럼 결과가 불확실할 때 확률이 필요하다.

**3. 예시**

```python
# 동전 한 번 던지기
sample_space = ["H", "T"]
event_head = ["H"]

p_head = len(event_head) / len(sample_space)
print(p_head)
```

실행 결과는 `0.5`다. 가능한 결과가 앞면과 뒷면 두 가지이고, 앞면은 그중 하나이기 때문이다.

**4. 헷갈리기 쉬운 점**  
확률은 “정답을 맞히는 능력”이 아니라 “가능성을 수치화하는 언어”다. 0.8이라고 해서 반드시 일어난다는 뜻은 아니고, 같은 조건을 반복했을 때 자주 일어날 가능성이 높다는 뜻이다.

**5. 한 줄 정리**  
확률은 불확실한 사건을 계산 가능한 숫자로 바꾸는 방법이다.

### 실험, 표본공간, 사건

**1. 정의**  
실험은 결과가 여러 가지로 나올 수 있는 행위다. 표본공간은 가능한 모든 결과의 모음이고, 사건은 그중 관심 있는 결과의 모음이다.

**2. 왜 필요한가?**  
확률을 계산하려면 먼저 전체 가능한 결과와 관심 있는 결과를 분리해야 한다. 이 작업을 하지 않으면 분모와 분자를 잘못 세게 된다.

**3. 예시**

```python
# 주사위 한 번 던지기
sample_space = [1, 2, 3, 4, 5, 6]
event_even = [2, 4, 6]

p_even = len(event_even) / len(sample_space)
print(p_even)
```

**4. 헷갈리기 쉬운 점**  
표본공간은 항상 “이번 실험에서 가능한 모든 결과”다. 주사위를 한 번 던지는지, 두 번 던지는지에 따라 표본공간이 달라진다.

**5. 한 줄 정리**  
표본공간은 전체 메뉴판, 사건은 그중 내가 고른 메뉴라고 보면 된다.

## 사건의 기본 연산

### 여사건

**1. 정의**  
여사건은 사건 A가 일어나지 않는 모든 경우다. `Aᶜ`로 표현한다.

**2. 왜 필요한가?**  
직접 사건 A를 세기보다 A가 아닌 경우를 세는 것이 더 쉬울 때가 많다.

**3. 예시**

```python
p_pass = 0.7
p_fail = 1 - p_pass
print(p_fail)
```

**4. 헷갈리기 쉬운 점**  
여사건은 “반대 느낌의 사건”이 아니라 표본공간 전체에서 A를 제외한 모든 경우다.

**5. 한 줄 정리**  
여사건은 전체에서 내가 관심 있는 사건을 뺀 나머지다.

### 합사건과 곱사건

**1. 정의**  
합사건은 A 또는 B가 일어나는 경우이고, 곱사건은 A와 B가 동시에 일어나는 경우다.

**2. 왜 필요한가?**  
현실 분석에서는 조건이 하나만 있는 경우보다 여러 조건을 함께 보는 경우가 많다. 예를 들어 “여성이거나 1등석인 승객”, “여성이면서 생존한 승객”처럼 조건을 결합해야 한다.

**3. 예시**

```python
A = {1, 2, 3}      # 3 이하
B = {2, 4, 6}      # 짝수

union = A | B       # 합사건
intersection = A & B # 곱사건

print(union)
print(intersection)
```

**4. 헷갈리기 쉬운 점**  
합사건은 단순히 두 사건의 개수를 더하면 중복이 생길 수 있다. A와 B가 겹치는 부분은 한 번 빼야 한다.

**5. 한 줄 정리**  
합사건은 “또는”, 곱사건은 “그리고”다.

### 배반사건

**1. 정의**  
배반사건은 동시에 일어날 수 없는 두 사건이다. 즉 `A ∩ B = ∅`이다.

**2. 왜 필요한가?**  
두 사건이 배반이면 합사건의 확률을 계산할 때 겹치는 부분을 빼지 않아도 된다.

**3. 예시**

```python
# 주사위 한 번 던질 때 1이 나오는 사건과 2가 나오는 사건은 동시에 일어날 수 없다.
A = {1}
B = {2}
print(A & B)
```

**4. 헷갈리기 쉬운 점**  
서로 달라 보이는 사건이 항상 배반은 아니다. 예를 들어 “짝수”와 “3 이하”는 서로 다른 조건이지만 2가 겹치므로 배반이 아니다.

**5. 한 줄 정리**  
배반사건은 한 번의 실험에서 동시에 선택될 수 없는 사건이다.

## 경우의 수 계산

### 합의 법칙과 곱의 법칙

**1. 정의**  
합의 법칙은 두 사건이 동시에 일어나지 않을 때 경우의 수를 더하는 방법이다. 곱의 법칙은 여러 단계를 연속해서 선택할 때 경우의 수를 곱하는 방법이다.

**2. 왜 필요한가?**  
확률의 분모와 분자를 세려면 경우의 수를 정확히 계산해야 한다. 특히 순열과 조합은 곱의 법칙에서 출발한다.

**3. 예시**

```python
# 상의 3개, 하의 2개를 조합하는 경우
shirts = 3
pants = 2
print(shirts * pants)
```

**4. 헷갈리기 쉬운 점**  
“둘 중 하나를 고르는가”는 더하기, “첫 번째를 고른 뒤 두 번째를 또 고르는가”는 곱하기에 가깝다.

**5. 한 줄 정리**  
선택지가 갈라지면 더하고, 선택 단계가 이어지면 곱한다.

### 팩토리얼

**1. 정의**  
팩토리얼은 1부터 n까지의 정수를 모두 곱한 값이다. `n!`로 표현한다.

**2. 왜 필요한가?**  
서로 다른 n개를 줄 세우는 순서의 수를 계산할 때 사용한다.

**3. 예시**

```python
def fac(n):
    if n == 0:
        return 1
    if n == 1:
        return 1
    else:
        return n * fac(n - 1)

print(fac(4))
```

4명의 학생을 순서대로 세우는 경우의 수는 `4! = 24`다.

**4. 헷갈리기 쉬운 점**  
`0!`은 1이다. 아무것도 선택하지 않는 경우도 하나의 경우로 보기 때문이다.

**5. 한 줄 정리**  
팩토리얼은 “모두 줄 세우기”의 경우의 수다.

### 순열과 조합

**1. 정의**  
순열은 서로 다른 n개 중 k개를 순서를 고려해 뽑는 방법이다. 조합은 순서를 고려하지 않고 k개를 뽑는 방법이다.

**2. 왜 필요한가?**  
대표를 뽑는 문제와 순위를 정하는 문제는 다르다. 대표 2명을 뽑을 때는 조합, 반장과 부반장을 뽑을 때는 순열이다.

**3. 예시**

```python
from itertools import permutations, combinations

items = ["A", "B", "C"]

print(list(permutations(items, 2)))
print(list(combinations(items, 2)))
```

**4. 헷갈리기 쉬운 점**  
`("A", "B")`와 `("B", "A")`를 다르게 보면 순열, 같게 보면 조합이다.

**5. 한 줄 정리**  
순서가 의미 있으면 순열, 순서가 의미 없으면 조합이다.

### 중복순열과 중복조합

**1. 정의**  
중복순열은 같은 원소를 여러 번 뽑을 수 있고 순서도 고려한다. 중복조합은 같은 원소를 여러 번 뽑을 수 있지만 순서는 고려하지 않는다.

**2. 왜 필요한가?**  
비밀번호처럼 같은 숫자가 반복될 수 있고 순서가 중요한 경우는 중복순열이다. 아이스크림 맛 3개를 고르는데 같은 맛을 여러 번 고를 수 있고 순서는 중요하지 않다면 중복조합이다.

**3. 예시**

```python
from itertools import product, combinations_with_replacement

items = ["A", "B"]

print(list(product(items, repeat=3)))
print(list(combinations_with_replacement(items, 3)))
```

**4. 헷갈리기 쉬운 점**  
중복 허용 여부와 순서 고려 여부를 따로 판단해야 한다. 두 질문은 서로 다른 기준이다.

**5. 한 줄 정리**  
“다시 뽑을 수 있는가?”와 “순서가 중요한가?”를 따로 확인하면 된다.

## 코드로 보기 — 순열과 조합 비교

```python
from itertools import permutations, combinations, product, combinations_with_replacement

items = ["A", "B", "C"]

print("순열:", list(permutations(items, 2)))
print("조합:", list(combinations(items, 2)))
print("중복순열:", list(product(items, repeat=2)))
print("중복조합:", list(combinations_with_replacement(items, 2)))
```

**코드목적**  
같은 원소를 두고 순서와 중복 허용 여부에 따라 결과가 어떻게 달라지는지 비교한다.

**해석**  
순열은 `A-B`와 `B-A`를 다른 경우로 보고, 조합은 같은 경우로 본다. 중복순열과 중복조합은 `A-A`처럼 같은 원소가 반복되는 경우를 포함한다.

**실무 연결**  
추천 시스템의 조합 후보 생성, A/B 테스트 조건 조합, 마케팅 캠페인 옵션 설계처럼 가능한 경우를 만들 때 사용된다.

## 헷갈리기 쉬운 포인트

| 구분 | 의미 | 예시 |
| --- | --- | --- |
| 순열 vs 조합 | 순서를 고려하는가 | 반장/부반장 선출 vs 대표 2명 선발 |
| 합사건 vs 곱사건 | 또는인가, 동시에인가 | A 또는 B vs A와 B 모두 |
| 여사건 vs 배반사건 | 전체에서 뺀 나머지인가, 둘이 동시에 불가능한가 | 합격하지 않음 vs 주사위 1과 2 |
| 중복순열 vs 중복조합 | 반복 허용 후 순서를 보는가 | 비밀번호 vs 아이스크림 맛 선택 |

## 한 줄 정리

> 확률의 출발점은 가능한 전체 결과와 관심 있는 사건을 정확히 나누는 것이고, 경우의 수는 그 사건을 세기 위한 도구다.
