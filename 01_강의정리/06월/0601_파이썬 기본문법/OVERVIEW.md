# 파이썬 기본 문법 2 — 반복·자료구조·함수 한 번에 정리하기

> 별을 100번 출력해야 한다면, `print`를 100줄 쓰시겠어요? 데이터를 다루는 거의 모든 코드는 "같은 일을 반복하고, 여러 값을 한 묶음으로 보관하고, 자주 쓰는 동작을 함수로 떼어내는" 세 가지 위에서 돌아갑니다. 이 강의는 비전공자가 그 세 축을 처음부터 끝까지 손으로 익히도록 구성했습니다.

이 묶음은 파이썬의 **반복문 → 자료구조(리스트·튜플·딕셔너리) → 함수**로 이어지는 흐름을 다룹니다. 문법을 외우기보다 "이 도구가 어떤 귀찮음을 없애주는가"를 기준으로 정리했고, 모든 예제는 실제로 실행해 본 코드와 결과를 그대로 담았습니다.

## 학습 로드맵

```text
[1] 반복문                같은 일을 자동으로 반복
      │   for · for-range · while · break
      ▼
[2] 리스트 & 시퀀스       여러 값을 순서대로 보관·가공
      │   append/insert/remove/sort · 인덱싱/슬라이싱 · split/join · pop/count
      ▼
[3] 튜플                  바뀌면 안 되는 값을 안전하게 묶기
      │   불변(immutable) · (1,) 쉼표 규칙
      ▼
[4] 딕셔너리 & 반복 활용   "이름표(Key)–값(Value)" 짝으로 보관·집계
      │   keys/values/items · zip · 단어 빈도 세기
      ▼
[5] 함수와 메서드         자주 쓰는 동작을 이름 붙여 재사용
          내장 함수 · 사용자 정의 함수 · return · 매개변수 · 변수 범위 · docstring
```

핵심 흐름은 "반복으로 처리하고, 자료구조에 담고, 함수로 묶는다"입니다. 뒤로 갈수록 앞 단계가 도구로 다시 등장하므로(예: 딕셔너리를 for로 순회, 함수 안에서 반복문 사용) 순서대로 읽는 것을 추천합니다.

## 다루는 핵심 개념

반복문에서는 `for`, `for-range`, `while`, `break`와 들여쓰기로 묶는 코드 블록을 다룹니다. 자료구조에서는 리스트 메서드(`append`, `insert`, `remove`, `sort`, `pop`, `count`), 시퀀스 공통 기능(인덱싱·슬라이싱·`in`·`len`·`+`·`*`), 문자열-리스트 변환(`split`, `join`), 튜플의 불변성, 딕셔너리의 `keys`/`values`/`items`와 `zip`을 살펴봅니다. 함수 파트에서는 내장 함수와 사용자 정의 함수, `return`의 유무 차이, 매개변수 설계, 변수의 범위(지역/전역), 타입 힌트와 docstring까지 정리합니다.
