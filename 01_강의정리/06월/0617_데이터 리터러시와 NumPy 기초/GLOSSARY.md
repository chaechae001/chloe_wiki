# 용어집 (GLOSSARY)

이번 강의에서 등장한 핵심 용어를 비전공자도 이해할 수 있게 정리했습니다.

| 용어 | 쉬운 설명 | 관련 강의명 | 함께 보면 좋은 개념 |
| --- | --- | --- | --- |
| 데이터(Data) | 현실을 관찰·측정해 얻은 객관적 자료. "주어진 것"이라는 라틴어 Datum의 복수형 | 데이터, 세상을 보는 새로운 눈 | 정보, 데이터 마이닝 |
| 정보(Information) | 데이터를 가공해 얻는 의미 있는 결과 | 데이터, 세상을 보는 새로운 눈 | 데이터, DIKW |
| 데이터 마이닝 | 데이터 속에서 의미 있는 정보를 캐내는 작업 | 데이터, 세상을 보는 새로운 눈 | 정보, 패턴 |
| DIKW 피라미드 | 데이터→정보→지식→지혜로 가치가 더해지는 단계 | 데이터, 세상을 보는 새로운 눈 | 지식, 지혜 |
| 빅데이터 | (좁게) 방대한 양의 데이터, (넓게) 그 데이터를 다루는 모든 기술 | 데이터, 세상을 보는 새로운 눈 | 3V, 인공지능 |
| 데이터 문해력(리터러시) | 데이터를 읽고 의심하고 목적에 맞게 활용하는 능력 | 데이터, 세상을 보는 새로운 눈 | 목적 사고력 |
| 데이터 3법 | 2020년 통과된 개인정보 보호 관련 3개 법률(데이터 활용과 보호의 균형) | 데이터, 세상을 보는 새로운 눈 | 개인정보 보호 |
| 목적 사고력 | "이 데이터로 무엇을 밝힐 것인가"를 먼저 정의하는 능력 | 데이터로 문제를 푸는 법 | 문제 정의, SCQA |
| 문제 정의 | 데이터로 풀 문제를 정확히 진단·정의하는 첫 단계 | 데이터로 문제를 푸는 법 | SCQA, 분석 프로세스 |
| SCQA | 상황-전개-질문-답으로 문제를 정의·전달하는 프레임 | 데이터로 문제를 푸는 법 | 문제 정의 |
| 데이터 전처리 | 결측·이상치를 정리해 분석 가능한 형태로 가공하는 단계 | 데이터로 문제를 푸는 법 | 결측치, 데이터 정제 |
| 결과 확인 vs 결과 검증 | 확인은 수치로 정리, 검증은 새 실험으로 재현 점검 | 데이터로 문제를 푸는 법 | A/B 테스트 |
| 분석 신뢰도 | 이 데이터를 믿고 분석해도 되는가에 대한 판단 | 믿을 수 있는 데이터 | 편향, 오류, 결측 |
| 데이터 품질 | 데이터가 목적에 부합하고 믿을 만한 정도(정확성·완전성·일관성·적합성·최신성) | 믿을 수 있는 데이터 | 분석 신뢰도 |
| 데이터 편향 | 데이터가 전체(모집단)를 대표하지 못하는 경우 | 믿을 수 있는 데이터 | 표본, 대표성 |
| 데이터 오류 | 데이터가 사실이 아닌 정보를 담은 경우(오타·디폴트값 등) | 믿을 수 있는 데이터 | 이상치 |
| 결측 데이터 | 값이 누락되어 비어 있는 데이터 | 믿을 수 있는 데이터 | 결측치 대체(Imputation) |
| 상관관계 | 요인들이 함께 변하는 경향 | 믿을 수 있는 데이터 | 인과관계 |
| 인과관계 | 한 요인이 다른 요인의 원인이 되는 관계 | 믿을 수 있는 데이터 | 상관관계 |
| 모집단 | 알고 싶은 전체 집단 | 믿을 수 있는 데이터 | 표본 |
| 표본 | 모집단에서 뽑은 일부 | 믿을 수 있는 데이터 | 대표성 |
| 대표성 | 표본이 모집단의 특성을 잘 반영하는 정도 | 믿을 수 있는 데이터 | 표본 추출 |
| 정형 데이터 | 정해진 형식·구조가 있어 고정 자리에 저장된 데이터(표 형태) | 데이터를 모으고 연결하기 | 비정형, 반정형 |
| 비정형 데이터 | 정의된 구조가 없는 데이터(텍스트·이미지·영상) | 데이터를 모으고 연결하기 | 정형, 딥러닝 |
| 반정형 데이터 | 구조가 일부 있는 데이터(JSON·딕셔너리) | 데이터를 모으고 연결하기 | 정형, 비정형 |
| 변수의 척도 | 변수의 성질(명목·서열·등간·비율)에 따른 분류 | 데이터를 모으고 연결하기 | 범주형, 수치형 |
| 명목 척도 | 구분만 하는 범주(예: 성별 1·2) — 사칙연산 불가 | 데이터를 모으고 연결하기 | 서열 척도 |
| 서열 척도 | 순서만 있는 범주(예: 등수) | 데이터를 모으고 연결하기 | 명목 척도 |
| 등간 척도 | 크기 비교가 되는 수치(절대영점 없음, 예: 온도) | 데이터를 모으고 연결하기 | 비율 척도 |
| 비율 척도 | 절대영점(0)이 있는 수치(예: 키·몸무게) | 데이터를 모으고 연결하기 | 등간 척도 |
| 관계형 데이터베이스(RDB) | 행·열 테이블로 저장하고 관계를 관리하는 DB | 데이터를 모으고 연결하기 | 키, 무결성 |
| 키(Key) | 데이터를 식별할 수 있는 속성(열) | 데이터를 모으고 연결하기 | 유일성, 무결성 |
| 유일성 | 하나의 키가 하나의 데이터를 정확히 식별하는 성질 | 데이터를 모으고 연결하기 | 키 |
| 무결성 | 키 값이 비거나 중복되지 않아야 하는 성질(개체·참조 무결성) | 데이터를 모으고 연결하기 | 키, 유일성 |
| 3V | 빅데이터 특성: Velocity(속도)·Volume(양)·Variety(다양성) | 데이터를 모으고 연결하기 | 빅데이터 |
| Concat | 데이터를 축(axis) 기준으로 이어 붙이는 결합 | 데이터를 모으고 연결하기 | Merge, axis |
| Merge / Join | 공통 키를 기준으로 데이터를 병합(inner/outer/left/right) | 데이터를 모으고 연결하기 | 키, Concat |
| 메타 데이터 | 데이터를 설명하는 데이터(의미·출처·형식 등) | 데이터를 모으고 연결하기 | Open API |
| 데이터 엔지니어 | 데이터를 수집·저장·처리해 활용 가능하게 만드는 개발자형 직무 | 데이터를 모으고 연결하기 | 데이터 파이프라인 |
| 데이터 파이프라인 | 수집→저장→처리·정제→활용으로 이어지는 데이터 처리 흐름 | 데이터를 모으고 연결하기 | 데이터 엔지니어 |
| 로우(raw) 데이터 | 가공 전 원자료. 집계 데이터보다 분석 여지가 큼 | 데이터를 모으고 연결하기 | 집계 데이터 |
| NumPy | 파이썬에서 대규모 다차원 배열을 다루는 라이브러리 | NumPy 기초 | 배열, pandas |
| 배열(array) | 같은 자료형의 숫자를 모아 둔 NumPy의 기본 자료구조 | NumPy 기초 | dtype, shape |
| dtype | 배열 원소의 자료형(int64, float 등) | NumPy 기초 | 배열 |
| shape | 배열의 모양(행·열 구조) | NumPy 기초 | reshape, ndim |
| 인덱싱 | 인덱스로 특정 값을 찾는 것 | NumPy 기초 | 슬라이싱 |
| 슬라이싱 | 인덱스 범위로 부분 배열을 가져오는 것 | NumPy 기초 | view, copy |
| 뷰(view) | 원본과 메모리를 공유하는 슬라이스(원본도 함께 바뀔 수 있음) | NumPy 기초 | copy, 슬라이싱 |
| copy | 원본과 독립된 복제본을 만드는 것 | NumPy 기초 | view |
| reshape | 원소 수를 유지한 채 배열 모양을 바꾸는 것 | NumPy 기초 | shape |
| axis | 연산·집계의 기준이 되는 축(0=행 방향, 1=열 방향) | NumPy 기초 | 집계, split |
| 브로드캐스팅 | shape가 다른 배열끼리 연산되게 자동으로 늘려 맞추는 원리 | NumPy 기초 | 배열 연산 |
| 집계 함수 | sum·min·max·mean 등 요약 통계를 내는 함수 | NumPy 기초 | axis |
| 마스킹 연산 | True/False 배열로 조건에 맞는 값을 골라내는 방법 | NumPy 기초 | 조건 필터링, pandas |
| np.where | 조건이 참이면 A, 거짓이면 B를 고르는 함수(조건부 치환) | NumPy 기초 | 마스킹 연산 |
| np.unique | 고유값을 구하고 정수 라벨 등으로 변환하는 함수 | NumPy 기초 | 범주형 |
