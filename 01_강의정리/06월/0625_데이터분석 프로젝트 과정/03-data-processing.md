# 데이터 처리 — pandas로 불러오고, 고치고, 다듬기

> 분석은 "예쁜 데이터"가 아니라 "지저분한 데이터"에서 시작한다. 빠진 칸, 엉뚱하게 튀는 값, 따로 노는 표 두 개… 이 글은 실제 데이터셋(타이타닉)을 가지고 **불러오기 → 변환 → 요약 → 이상치·결측치 처리 → 병합 → 기초 통계**까지, 전처리의 전 과정을 한 번에 따라간다.

`데이터로드` · `read_csv` · `데이터변환` · `필터링` · `이상치` · `결측치` · `fillna` · `dropna` · `merge` · `기초통계`

## 핵심요약

- 데이터는 형식에 따라 **정형·반정형·비정형**으로 나뉘며, 분석은 대개 표 형태의 정형 데이터로 한다.
- CSV는 쉼표로 값을 구분한 텍스트 파일이고, pandas의 `read_csv()`는 이를 곧장 DataFrame으로 불러온다.
- 기존 열로 **새 열을 만들고**(`df['새열'] = ...`), 참/거짓을 1/0으로 바꾸고(`np.where`), 이름을 바꾸고(`rename`), 조건으로 행을 **필터링**한다.
- `head()`·`describe()`·`info()`·`shape`·`value_counts()`로 데이터의 모습을 빠르게 진단한다.
- **이상치**는 박스플롯·IQR로 찾아 최댓값으로 대체(capping)하고, **결측치**는 `fillna`로 채우거나 `dropna`로 행을 제거한다.
- 두 표를 위아래/좌우로 잇는 `concat`, 공통 key로 합치는 `merge`(inner·outer·left·right)로 데이터를 **병합**한다.
- 통계는 **기술 통계**(평균·분산 등으로 요약)와 **추론 통계**(표본으로 모집단 추정)로 나뉘며, 변수는 질적(명목·순서)·양적(이산·연속)으로 구분한다.

## 개념별 정리

### 1. 데이터의 종류 — 정형·반정형·비정형

**1. 정의**
데이터는 정보를 전달하는 값의 모음으로, 구조화 정도에 따라 세 가지로 나뉜다. 정형(표 형태로 명확히 정의됨), 반정형(어느 정도 구조가 있으나 유연함), 비정형(정해진 형식이 없음)이다.

**2. 왜 필요한가?**
다루려는 데이터가 어느 종류인지에 따라 도구가 달라진다. 표 데이터는 pandas로 바로 다루지만, 사진·텍스트 같은 비정형은 먼저 수치로 바꾸는 과정이 필요하다.

**3. 예시**
- 정형 데이터: 직원 데이터베이스, 판매 기록처럼 행과 열로 정리된 표
- 반정형 데이터: JSON, XML처럼 키-값 구조가 있는 데이터
- 비정형 데이터: 사진, 소셜 미디어 게시물처럼 형식이 없는 데이터

**4. 헷갈리기 쉬운 점**
"파일이 .json이면 비정형"이 아니다. JSON·XML은 구조(키-값)가 있으므로 **반정형**으로 분류한다. 완전한 표(정형)와 형식 없음(비정형)의 *중간*이라고 기억하면 쉽다.

**5. 한 줄 정리**
데이터는 구조화 정도에 따라 정형(표) · 반정형(JSON/XML) · 비정형(사진/텍스트)으로 나뉜다.

> 비유: 정형은 *서랍별로 정리된 옷장*, 반정형은 *라벨만 붙은 수납 박스*, 비정형은 *그냥 쌓아 둔 옷더미*다.

(데이터의 종류는 빅데이터 편에서도 다뤘다 → [빅데이터와 파이썬](02-bigdata-and-pandas.md))

### 2. 데이터 로드 — CSV를 DataFrame으로

**1. 정의**
CSV(Comma-Separated Values)는 쉼표로 값을 구분한 텍스트 파일이다. 저장 용량이 작고 거의 모든 프로그램이 지원해 데이터 교환에 널리 쓰인다.

**2. 왜 필요한가?**
분석의 첫 단계는 "데이터를 코드 안으로 불러오기"다. 파이썬 기본 `csv` 모듈로도 읽을 수 있지만, pandas의 `read_csv()`는 한 줄로 표(DataFrame)를 만들어 줘 훨씬 편하다.

**3. 예시**
기본 `csv` 모듈은 각 행을 리스트로 읽는다.

```python
import csv

with open('data.csv', 'r') as file:
    csv_reader = csv.reader(file)
    for row in csv_reader:
        print(row)   # 각 행이 리스트로 나옴
# [Name, Age, Occupation]
# [John, 30, Engineer]
# [Sarah, 25, Doctor]
# [Michael, 28, Teacher]
```

pandas는 같은 파일을 표 한 번에 불러온다.

```python
import pandas as pd

df = pd.read_csv('data.csv')
print(df)
#       Name  Age Occupation
# 0     John   30   Engineer
# 1    Sarah   25     Doctor
# 2  Michael   28    Teacher
```

**4. 헷갈리기 쉬운 점**
`csv.reader`는 데이터를 "리스트들의 묶음"으로 줄 뿐, 열 이름·자료형을 자동으로 정리하지 않는다. 반면 `read_csv()`는 첫 줄을 자동으로 열 이름으로 잡고 숫자/문자를 구분해 준다 — 그래서 실무에서는 거의 pandas를 쓴다.

**5. 한 줄 정리**
CSV는 쉼표로 구분된 텍스트 파일이고, `pd.read_csv()`는 그것을 분석 가능한 표(DataFrame)로 바로 만들어 준다.

> 비유: `csv` 모듈이 *재료를 봉지째 건네는 것*이라면, `read_csv()`는 *손질해서 그릇에 담아 주는 것*이다.

### 3. 데이터 변환 — 열 추가·형 변환·이름 변경·필터링

**1. 정의**
원본 데이터를 분석 목적에 맞게 바꾸는 작업이다. 새 열 만들기, 범주형을 수치형으로 바꾸기, 열·인덱스 이름 바꾸기, 조건으로 행 거르기가 대표적이다.

**2. 왜 필요한가?**
원본 그대로는 분석이 어렵다. "성인 여부", "출생연도" 같은 파생 변수를 만들고, 모델이 이해할 수 있게 True/False를 1/0으로 바꾸는 가공이 분석 품질을 좌우한다.

**3. 예시**
기존 열을 이용해 새 열을 만든다.

```python
# 나이로 '성인 여부' 열 만들기
df['Adult'] = df['Age'] >= 18          # 18 이상이면 True

# 나이로 '출생연도' 열 만들기
df['Birth(years)'] = 2023 - df['Age']  # 예: Age 31 → 1992
```

참/거짓(범주형)을 1/0(수치형)으로 바꾼다.

```python
import numpy as np
df['Adult'] = np.where(df['Adult'] == True, 1, 0)  # True→1, False→0
```

열·인덱스 이름을 바꾸고, 조건으로 행을 거른다.

```python
df = df.rename(columns={'Age': 'Age(나이)'})   # 열 이름 변경
df = df.rename(index={1: 'one'})               # 인덱스 이름 변경

# 한 가지 조건
filtered_df = df[df['Age(나이)'] >= 27]

# 두 가지 조건 (and는 &, 각 조건은 괄호로 묶기)
filtered_two_df = df[(df['Age(나이)'] >= 27) & (df['Occupation'] == 'Engineer')]
```

**4. 헷갈리기 쉬운 점**
여러 조건을 묶을 때 파이썬의 `and`/`or`가 아니라 **`&`/`|`**를 쓰고, **각 조건을 괄호로 감싸야** 한다(`(A) & (B)`). 괄호를 빠뜨리면 연산 순서 때문에 에러가 난다. 또 `np.where(조건, 참일값, 거짓일값)`의 인자 순서를 헷갈리지 말자.

**5. 한 줄 정리**
데이터 변환은 "새 열 만들기 · 형 바꾸기 · 이름 바꾸기 · 조건으로 거르기"로 원본을 분석하기 좋은 모양으로 다듬는 일이다.

> 비유: 데이터 변환은 *요리 전 손질*이다. 당근을 채 썰고(파생 열), 단위를 g으로 통일하고(형 변환), 상한 건 골라낸다(필터링).

### 4. 데이터 요약 — 한눈에 진단하기

**1. 정의**
DataFrame에 요약용 메서드를 적용해 데이터의 분포와 주요 경향을 빠르게 파악하는 단계다.

**2. 왜 필요한가?**
큰 데이터를 통째로 눈으로 볼 수는 없다. "몇 행 몇 열인지, 결측치가 있는지, 어떤 값이 몇 번 나오는지"를 먼저 알아야 다음 처리를 정할 수 있다. 이 글에서는 891명의 승객 정보를 담은 타이타닉 데이터셋으로 살펴본다.

**3. 예시**
```python
import pandas as pd
df = pd.read_csv('./train.csv')

print(df.head())     # 첫 5줄 미리보기 (5줄 미만이면 전부)
print(df.shape)      # (891, 12)  → 891행 12열

print(df['Survived'].value_counts())   # 값별 개수
# 0    549   (사망)
# 1    342   (생존)

print(df['Pclass'].value_counts())
# 3    491
# 1    216
# 2    184
```

`info()`는 열별 자료형과 결측 현황을, `describe()`는 통계 요약을 보여 준다.

```python
print(df.info(verbose=True))
# Age       714 non-null   float64   ← 891 중 714만 채워짐 (결측 존재)
# Cabin     204 non-null   object    ← 결측이 많음
# Embarked  889 non-null   object

print(df.describe())   # count·mean·std·min·25%·50%·75%·max를 열별로
```

**4. 헷갈리기 쉬운 점**
`describe()`는 기본적으로 **숫자 열만** 요약하고, **NaN은 제외**하고 계산한다(그래서 Age의 count가 891이 아니라 714다). `info()`의 "non-null count"가 전체 행 수보다 작으면 그 열에 결측치가 있다는 신호다.

**5. 한 줄 정리**
`head`·`shape`·`value_counts`·`info`·`describe`는 데이터를 처음 만났을 때 "건강검진"처럼 먼저 돌려 보는 진단 도구다.

> 비유: 데이터 요약은 *새 집에 이사 와서 방 개수·창문·고장 난 곳을 먼저 둘러보는 것*이다.

(이 메서드들은 빅데이터 편에서도 다뤘다 → [빅데이터와 파이썬](02-bigdata-and-pandas.md))

### 5. 이상치 처리 — 튀는 값 다루기

**1. 정의**
이상치(outlier)는 데이터 범위에서 크게 벗어난 값으로, 평균 등을 왜곡해 잘못된 분석을 부를 수 있다.

**2. 왜 필요한가?**
나이 열에 200이 섞여 있으면 평균이 엉망이 된다. 이상치를 시각화로 찾아내고, 제거하거나 합리적인 값으로 바꿔 줘야 통계가 신뢰를 얻는다.

**3. 예시**
박스플롯으로 이상치를 눈으로 찾는다.

```python
import matplotlib.pyplot as plt
import seaborn as sns

sns.boxplot(y=df['Age'])   # 위아래로 동떨어진 점이 이상치
plt.show()
```

IQR(사분위 범위)로 이상치 경계를 계산한다.

```python
Q1 = df['Age'].quantile(q=0.25)   # 하위 25% 지점
Q3 = df['Age'].quantile(q=0.75)   # 상위 25% 지점
IQR = Q3 - Q1                     # 가운데 50%의 폭

M = Q3 + 1.5 * IQR                # 이 값을 넘으면 이상치로 본다
print(M)                          # 64.8125
```

경계를 넘는 값을 최댓값으로 바꾼다(capping).

```python
df.loc[df['Age'] > 64, 'Age'] = 64   # 64를 넘는 나이를 64로 대체
sns.boxplot(y=df['Age'])             # 다시 그리면 위쪽 이상치가 사라짐
plt.show()
```

**4. 헷갈리기 쉬운 점**
이상치 경계는 보통 `Q1 - 1.5*IQR`(아래)과 `Q3 + 1.5*IQR`(위)로 잡는다. 1.5는 관례적인 기준일 뿐 절대 규칙이 아니다. 또 이상치를 *무조건 제거*하면 안 된다 — 진짜 의미 있는 신호일 수도 있어, 제거할지 대체할지는 맥락을 보고 정한다.

**5. 한 줄 정리**
이상치는 박스플롯·IQR로 찾아내고, 경계를 넘는 값은 제거하거나 최댓값 등으로 대체한다.

> 비유: IQR은 *데이터의 "정상 체온 범위"*다. 이 범위를 한참 벗어난 값에 빨간불이 켜진다.

### 6. 결측치 처리 — 빈 칸 다루기

**1. 정의**
결측치(missing value, NaN)는 값이 누락된 칸이다. 그대로 두면 계산이 막히거나 결과가 왜곡된다.

**2. 왜 필요한가?**
현실 데이터에는 빈 칸이 늘 있다(타이타닉의 Age·Cabin처럼). 어디에 몇 개 있는지 진단하고, 채울지(`fillna`) 버릴지(`dropna`/`drop`)를 정해야 분석이 가능해진다.

**3. 예시**
먼저 결측치가 어디에 몇 개 있는지 센다.

```python
print(df.notnull().sum())   # 열별 '비어 있지 않은' 칸 수
# Age       714   ← 891 중 714만 있음 → 177개 결측
# Cabin     204   ← 결측이 많음
# Embarked  889
```

빈 칸을 특정 값으로 채운다.

```python
print('Age mean:', df['Age'].mean())          # 29.6101...
df['Age'] = df['Age'].fillna(df['Age'].mean()) # Age 결측을 평균으로 채움
print(df.notnull().sum())                      # Age가 891로 늘어남
```

결측이 너무 많은 열은 통째로 버리고, 남은 결측 행은 제거한다.

```python
df = df.drop(['Cabin'], axis=1)   # 'Cabin' 열 전체 삭제 (axis=1 = 열)
df = df.dropna()                  # NaN이 하나라도 있는 행 삭제
print(df.notnull().sum())         # 모든 열의 개수가 같아짐
```

**4. 헷갈리기 쉬운 점**
`drop`과 `dropna`는 다르다. `drop(['열'], axis=1)`은 **지정한 열·행을 직접** 지우고, `dropna()`는 **NaN이 들어 있는 행(또는 열)을** 자동으로 지운다. 또 `fillna`로 채울 값은 신중히 골라야 한다 — 평균은 무난하지만, 분포가 치우쳤다면 중앙값이 더 안전할 수 있다.

**5. 한 줄 정리**
결측치는 `notnull().sum()`으로 진단하고, `fillna`로 채우거나 `drop`/`dropna`로 제거한다.

> 비유: 결측치 처리는 *시험 답안지의 빈칸 처리*다. 평균 점수로 채울지(`fillna`), 아예 그 답안지를 빼고 셀지(`dropna`)를 정하는 것과 같다.

### 7. 데이터 병합 — 표 두 개 합치기

**1. 정의**
여러 DataFrame을 하나로 합치는 작업이다. 단순히 잇는 `concat`과, 공통 key를 기준으로 맞춰 합치는 `merge`가 있다.

**2. 왜 필요한가?**
데이터는 보통 여러 파일에 흩어져 있다(월별 거래 내역, 사람별 기본정보와 주소…). 이를 하나로 합쳐야 통합 분석이 가능하다.

**3. 예시**
`concat`은 같은 구조의 표를 위아래(기본) 또는 좌우(`axis=1`)로 잇는다.

```python
import pandas as pd

# 두 표를 위아래로 잇고 인덱스를 새로 매김
jul_aug_df = pd.concat([jul_df, aug_df]).reset_index(drop=True)

# 좌우로 잇기
side_df = pd.concat([jul_df, aug_df], axis=1)
```

`merge`는 공통 열(key)을 기준으로 짝을 맞춰 합친다. `how`로 합치는 방식을 정한다.

```python
# 이름(key)을 기준으로 두 표 병합
merge_data = pd.merge(age_sex_df, add_df, on='이름')          # 기본 inner

merge_data = pd.merge(age_sex_df, add_df, how='outer', on='이름')  # 한쪽만 있어도 모두
merge_data = pd.merge(age_sex_df, add_df, how='left',  on='이름')  # 왼쪽 표 기준
merge_data = pd.merge(age_sex_df, add_df, how='right', on='이름')  # 오른쪽 표 기준
```

`how`에 따라 결과가 달라진다:
- `inner`(기본): 양쪽에 **모두 있는** key만 남김
- `outer`: 한쪽에만 있어도 모두 남기고, 없는 값은 NaN
- `left` / `right`: 왼쪽 / 오른쪽 표를 기준으로 맞춤

**4. 헷갈리기 쉬운 점**
`concat`은 "그냥 이어 붙이기"(구조가 같아야 깔끔), `merge`는 "key로 짝 맞춰 붙이기"다. 특히 `merge`의 기본값은 `inner`라서, 한쪽에만 있는 데이터는 **소리 없이 사라진다** — 데이터가 줄었다면 `how`를 의심하자.

**5. 한 줄 정리**
`concat`은 표를 잇고, `merge`는 공통 key로 짝을 맞춰 합치며, `how`로 어느 쪽을 살릴지 정한다.

> 비유: `concat`은 *종이를 위아래로 풀칠해 잇는 것*, `merge`는 *학번을 기준으로 성적표와 출석부를 맞춰 붙이는 것*이다.

### 8. 기초 통계 — 데이터를 숫자로 요약하기

**1. 정의**
통계 분석은 데이터에서 유용한 정보를 끌어내는 방법으로, 크게 **기술 통계**(데이터를 요약)와 **추론 통계**(표본으로 전체를 추정)로 나뉜다.

**2. 왜 필요한가?**
"이 데이터는 평균적으로 어떤가, 얼마나 퍼져 있는가"를 숫자 하나로 말할 수 있어야 비교와 판단이 가능하다. 또 전수 조사가 어려울 때 표본으로 전체를 추정하는 추론 통계가 현실 분석의 토대가 된다.

**3. 예시**
변수는 종류에 따라 다루는 통계가 다르다.

- 질적 변수: 명목형(순서 없음, 예: 성별)·순서형(순서 있음, 예: 등급)
- 양적 변수: 이산형(셀 수 있음, 예: 자녀 수)·연속형(잴 수 있음, 예: 키)

양적 변수 열에 대해 평균·중앙값·분산·표준편차를 구한다.

```python
import pandas as pd
df = pd.read_csv('./train.csv')

print(df.mean())     # 평균   (Age 29.699118 ...)
print(df.median())   # 중앙값 (Age 28.0 ...)
print(df.var())      # 분산   (Age 211.019125 ...)
print(df.std())      # 표준편차 (Age 14.526497 ...)
```

**4. 헷갈리기 쉬운 점**
`mean()` 등은 **숫자 열에 대해서만** 계산된다(최신 pandas에서는 `df.mean(numeric_only=True)` 형태를 권장). 또 분산(`var`)과 표준편차(`std`)는 같은 "퍼짐"을 재지만, 표준편차는 분산에 제곱근을 씌운 값이라 **원래 데이터와 단위가 같아** 해석이 쉽다.

**5. 한 줄 정리**
기초 통계는 평균·중앙값으로 "중심"을, 분산·표준편차로 "퍼짐"을 요약해 데이터를 숫자 몇 개로 압축한다.

> 비유: 평균이 *반의 대표 점수*라면, 표준편차는 *그 반이 우등생·열등생으로 갈리는 정도*다.

(통계 메서드의 동작 원리는 Numpy 편에서도 다뤘다 → [파이썬 데이터 분석의 기초](01-python-data-analysis.md))

## 코드로 보기 — 타이타닉 데이터 전처리 미니 파이프라인

```python
import pandas as pd

# 1) 불러오기
df = pd.read_csv('./train.csv')
print(df.shape)            # (891, 12)

# 2) 진단 — 어디에 결측이 있나?
print(df.notnull().sum())
# Age       714   (177개 결측)
# Cabin     204   (대부분 결측)
# Embarked  889

# 3) 이상치 다루기 — 나이의 위쪽 이상치를 64로 capping
Q1 = df['Age'].quantile(0.25)
Q3 = df['Age'].quantile(0.75)
IQR = Q3 - Q1
upper = Q3 + 1.5 * IQR
df.loc[df['Age'] > upper, 'Age'] = upper

# 4) 결측치 다루기 — Age는 평균으로 채우고, Cabin은 통째로 버리고, 남은 결측 행은 제거
df['Age'] = df['Age'].fillna(df['Age'].mean())
df = df.drop(['Cabin'], axis=1)
df = df.dropna()

# 5) 다시 진단 — 결측이 사라졌는지 확인
print(df.notnull().sum())  # 모든 열의 개수가 동일해짐
```

**코드목적**
실제 데이터셋 하나를 두고 "불러오기 → 진단 → 이상치 처리 → 결측치 처리 → 재진단"이라는 전처리의 한 사이클을 끝까지 돌려 본다.

**해석**
`notnull().sum()`으로 결측의 위치를 먼저 파악한 뒤, 나이의 위쪽 이상치는 IQR 기준으로 잘라 내고(capping), 채울 수 있는 결측(Age)은 평균으로 메우고, 채우기 어려운 열(Cabin)은 버리고, 남은 소수의 결측 행은 제거했다. 마지막 진단에서 모든 열의 개수가 같아지면 분석 가능한 깨끗한 표가 된 것이다.

**실무 연결**
이 흐름은 거의 모든 데이터 분석 프로젝트의 첫 단계와 똑같다. 설문·로그·거래 데이터를 받으면 가장 먼저 결측·이상치를 이렇게 정리한 뒤에야 시각화·모델링으로 넘어간다. 전처리의 품질이 곧 분석 결과의 품질이다.

## 헷갈리기 쉬운 포인트

- **정형 vs 반정형 vs 비정형** — 표 / JSON·XML / 사진·텍스트.
- **csv 모듈 vs read_csv** — 리스트로 읽기 / 표(DataFrame)로 한 번에.
- **조건 결합** — `and`/`or`가 아니라 `&`/`|`, 각 조건은 괄호로.
- **이상치 vs 결측치** — 튀는 값(범위 밖) / 빈 값(NaN).
- **fillna vs dropna vs drop** — 채우기 / NaN 행 제거 / 지정 열·행 삭제.
- **concat vs merge** — 단순히 잇기 / key로 짝 맞춰 합치기.
- **merge의 how** — inner(교집합)·outer(합집합)·left·right.
- **분산 vs 표준편차** — 같은 퍼짐이지만 표준편차는 원래 단위와 같음.

**복습 질문 및 답변**

*기본* — `df.dropna()`와 `df.drop(['Cabin'], axis=1)`은 각각 무엇을 지우나?
> `dropna()`는 NaN(결측치)이 들어 있는 *행*을 자동으로 지운다. `drop(['Cabin'], axis=1)`은 이름으로 지정한 *열*('Cabin')을 통째로 지운다(`axis=1`이 열을 뜻함).

*이해 확인* — `pd.merge(a, b, on='이름')`을 했더니 행 수가 줄었다. 왜 그럴 수 있나?
> `merge`의 기본 방식이 `inner`라서, 두 표 모두에 있는 '이름'만 남기기 때문이다. 한쪽에만 있는 이름은 결과에서 빠진다. 모두 살리려면 `how='outer'`를, 왼쪽 표를 기준으로 하려면 `how='left'`를 쓴다.

*응용* — 나이 열에 결측치와 위쪽 이상치가 모두 있을 때, 어떤 순서로 처리하는 게 자연스러운가?
> 보통 이상치를 먼저 capping(또는 처리)한 뒤 결측치를 채운다. 이상치가 남아 있으면 평균이 왜곡되어, 그 왜곡된 평균으로 결측을 채우게 되기 때문이다. 즉 `IQR로 이상치 capping → df['Age'].fillna(df['Age'].mean())` 순서가 안전하다.
