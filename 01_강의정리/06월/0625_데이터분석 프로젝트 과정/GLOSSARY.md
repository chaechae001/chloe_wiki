# 용어집 (GLOSSARY)

네 편의 글에 나오는 핵심 용어를 한곳에 모았다. 처음 보는 단어가 나오면 여기서 찾아보고, "함께 보면 좋은 개념"을 따라가며 연결해서 이해해 보자. 주제별로 묶어 두었으니 필요한 묶음만 펼쳐 봐도 좋다.

---

## 1. 파이썬 기초 — 자료형 · 제어문 · 함수

| 용어 | 쉬운 설명 | 관련 강의명 | 함께 보면 좋은 개념 |
| --- | --- | --- | --- |
| 변수 | 값을 담아 두는 이름표. `x = 10`은 x라는 이름에 10을 붙이는 것 | 파이썬 데이터 분석 | 자료형, 대입(=) |
| 자료형 | 변수에 담긴 값의 종류(정수·실수·문자열 등). 종류에 따라 가능한 계산이 다름 | 파이썬 데이터 분석 | int, float, 형변환 |
| int / float | 정수형 / 실수형. `int(3.7)`은 3(버림), `float(3)`은 3.0 | 파이썬 데이터 분석 | 형변환, 수치 연산 |
| 형변환 | 한 자료형을 다른 자료형으로 바꾸기(`int()`, `float()`, `str()` 등) | 파이썬 데이터 분석 | int/float, 자료형 |
| 문자열(string) | 글자·단어·문장을 담는 자료형. 따옴표 안에 넣어 선언 | 파이썬 데이터 분석 | 인덱싱, 슬라이싱 |
| 인덱싱 | 위치 번호로 한 글자/원소를 꺼내기. `a[0]`은 첫 번째 | 파이썬 데이터 분석 | 슬라이싱, 리스트 |
| 슬라이싱 | 구간으로 잘라내기. `a[0:3]`은 0~2번(끝 번호 제외) | 파이썬 데이터 분석 | 인덱싱, 리스트 |
| 리스트(list) | 대괄호 `[]`로 묶은, 순서가 있고 바꿀 수 있는 묶음 | 파이썬 데이터 분석 | 튜플, append/extend |
| 튜플(tuple) | 소괄호 `()`로 묶은, 순서는 있지만 바꿀 수 없는 묶음 | 파이썬 데이터 분석 | 리스트, 형변환 |
| 딕셔너리(dict) | `{key: value}` 형태로 이름표(key)로 값을 찾는 자료형 | 파이썬 데이터 분석 | 집합, Series |
| 집합(set) | 중괄호 `{}`로 묶되 중복을 허용하지 않는 묶음 | 파이썬 데이터 분석 | 교집합·합집합·차집합 |
| 교집합·합집합·차집합 | 집합 연산. `&`(둘 다), `\|`(둘 합쳐), `-`(한쪽에만) | 파이썬 데이터 분석 | 집합 |
| 조건문(if/elif/else) | 조건의 참/거짓에 따라 다른 코드를 실행 | 파이썬 데이터 분석 | 비교 연산(==), 필터링 |
| 반복문(for/while) | 같은 코드를 여러 번 실행. for는 횟수/순회, while는 조건이 참인 동안 | 파이썬 데이터 분석 | range, enumerate, break |
| range | 연속된 정수를 만드는 함수. `range(5)`는 0~4 | 파이썬 데이터 분석 | 반복문, arange |
| enumerate | 반복하면서 인덱스와 값을 동시에 꺼내기 | 파이썬 데이터 분석 | 반복문, 리스트 |
| break | 반복문을 도중에 멈추고 빠져나오기 | 파이썬 데이터 분석 | 반복문, 조건문 |
| 함수(def) | 자주 쓰는 코드 묶음에 이름을 붙여 재사용. `def 이름():` | 파이썬 데이터 분석 | return, 파라미터 |
| return | 함수가 결과 값을 밖으로 돌려주기. 없으면 None | 파이썬 데이터 분석 | 함수, 파라미터 |
| 파라미터(매개변수) | 함수가 호출될 때 받는 입력 값 | 파이썬 데이터 분석 | 디폴트 파라미터, 함수 |
| 디폴트 파라미터 | 값을 안 넘기면 쓰이는 기본값 | 파이썬 데이터 분석 | 파라미터, 함수 |
| 전역변수 / 지역변수 | 코드 전체에서 사는 변수 / 함수 안에서만 사는 변수 | 파이썬 데이터 분석 | 함수, 변수 |

## 2. Numpy — 숫자 데이터를 행렬로

| 용어 | 쉬운 설명 | 관련 강의명 | 함께 보면 좋은 개념 |
| --- | --- | --- | --- |
| Numpy | 숫자 데이터를 행렬로 빠르게 계산하는 파이썬 패키지. `import numpy as np` | 파이썬 데이터 분석 | 배열, 브로드캐스팅 |
| 배열(ndarray) | Numpy의 기본 자료구조. 원소끼리 한 번에 계산됨 | 파이썬 데이터 분석 | 리스트, Series |
| 차원(ndim) / shape | 배열이 몇 차원인지 / 행·열 모양을 튜플로 알려줌 | 파이썬 데이터 분석 | reshape, 배열 |
| reshape | 배열의 모양을 바꾸기. 원소 개수가 맞아야 함 | 파이썬 데이터 분석 | shape, 배열 |
| 브로드캐스팅 | 배열 전체에 같은 수를 한 번에 더하거나 곱하는 동작 | 파이썬 데이터 분석 / 빅데이터와 파이썬 | 배열, Series |
| 필터링 | 조건에 맞는 값만 골라내기. `na[na > 5]` | 파이썬 데이터 분석 | 비교 연산, 조건문 |
| axis | 연산 방향. `axis=0`은 열 방향(세로), `axis=1`은 행 방향(가로) | 파이썬 데이터 분석 | sum, 배열 |
| argmin / argmax | 최솟값·최댓값의 "위치(인덱스)"를 돌려줌 (값은 min/max) | 파이썬 데이터 분석 / 데이터 처리 | min/max, 통계 |
| all / any | 모두 참인지(all) / 하나라도 참인지(any) 확인 | 파이썬 데이터 분석 | 필터링, 비교 연산 |

## 3. AI · 빅데이터 개념

| 용어 | 쉬운 설명 | 관련 강의명 | 함께 보면 좋은 개념 |
| --- | --- | --- | --- |
| 인공지능(AI) | 컴퓨터가 인간과 유사한 지능을 갖도록 하는 기술의 큰 우산 | 빅데이터와 파이썬 | 머신러닝, 딥러닝 |
| 머신러닝 | 데이터로 스스로 학습하는 AI의 한 분야 | 빅데이터와 파이썬 | 지도/비지도학습, 딥러닝 |
| 딥러닝 | 인공 신경망을 기반으로 하는 머신러닝의 한 종류 | 빅데이터와 파이썬 | 머신러닝 |
| 지도학습 / 비지도학습 | 정답(label)이 있는 데이터로 학습 / 정답 없이 학습 | 빅데이터와 파이썬 | 머신러닝, 분류 |
| 빅데이터 | 전통적 방법으로는 다루기 어려운 크고 빠르게 늘어나는 데이터 | 빅데이터와 파이썬 | 3V/5V, 데이터 종류 |
| 3V / 5V | 빅데이터의 특징. 규모·다양성·속도(+가치·진실성) | 빅데이터와 파이썬 | 빅데이터 |
| 정형 / 반정형 / 비정형 데이터 | 표 형태 / JSON·XML 등 / 사진·텍스트 등 | 빅데이터와 파이썬 / 데이터 처리 | 데이터 종류 |
| 데이터 분석 | 데이터에서 인사이트를 찾는 전 과정(수집~해석) | 빅데이터와 파이썬 | CDA, EDA |
| CDA / EDA | 가설을 세워 검증하는 분석 / 데이터를 탐색하며 패턴을 찾는 분석 | 빅데이터와 파이썬 / EDA | 데이터 분석, 시각화 |
| 이상치(outlier) | 데이터 범위에서 크게 벗어난 값 | 빅데이터와 파이썬 / 데이터 처리 | IQR, 박스플롯 |
| 결측치(NaN) | 값이 누락된 칸 | 빅데이터와 파이썬 / 데이터 처리 | fillna, dropna, isnull |

## 4. pandas — 표 데이터 다루기

| 용어 | 쉬운 설명 | 관련 강의명 | 함께 보면 좋은 개념 |
| --- | --- | --- | --- |
| pandas | Numpy 기반으로 표 데이터를 다루는 라이브러리. `import pandas as pd` | 빅데이터와 파이썬 | Series, DataFrame |
| Series | 인덱스(이름표)가 붙은 1차원 데이터 | 빅데이터와 파이썬 | DataFrame, 인덱스 정렬 |
| DataFrame | 여러 Series가 모인 2차원 표 | 빅데이터와 파이썬 | Series, iloc/loc |
| 인덱스 정렬 | Series 연산 시 같은 인덱스끼리 계산, 짝 없으면 NaN | 빅데이터와 파이썬 | Series, 결측치 |
| iloc / loc | 정수 위치로 접근(iloc, 끝 미포함) / 이름으로 접근(loc, 끝 포함) | 빅데이터와 파이썬 | DataFrame, 인덱싱 |
| describe | count·평균·표준편차·사분위 등 통계를 한 표로 요약 | 빅데이터와 파이썬 / 데이터 처리 | info, 기초통계 |
| info | 행 수·열 이름·자료형·결측 현황을 보여줌 | 빅데이터와 파이썬 / 데이터 처리 | describe, isnull |
| isnull | 각 칸이 결측치인지 True/False로 표시. `.sum()`으로 개수 세기 | 빅데이터와 파이썬 / 데이터 처리 | 결측치, fillna |
| value_counts | 값별로 몇 번 나오는지 세기 | 빅데이터와 파이썬 / 데이터 처리 | count, unique |
| sort_values | 값을 기준으로 정렬(NaN은 맨 뒤) | 빅데이터와 파이썬 | rank, describe |
| rank | 값에 순위를 매기기 | 빅데이터와 파이썬 | sort_values |
| unique | 한 열의 고유값(중복 없는 목록) 출력 | 빅데이터와 파이썬 | value_counts, 집합 |
| concat | 표를 위아래(기본) 또는 좌우(axis=1)로 잇기 | 빅데이터와 파이썬 / 데이터 처리 | merge, DataFrame |

## 5. 데이터 처리 — 전처리 · 통계

| 용어 | 쉬운 설명 | 관련 강의명 | 함께 보면 좋은 개념 |
| --- | --- | --- | --- |
| CSV | 쉼표로 값을 구분한 텍스트 파일 | 데이터 처리 | read_csv |
| read_csv | CSV 파일을 DataFrame으로 불러오는 pandas 함수 | 데이터 처리 | CSV, DataFrame |
| np.where | 조건에 따라 값을 정하기. `np.where(조건, 참값, 거짓값)` | 데이터 처리 / EDA | 필터링, 인코딩 |
| rename | DataFrame의 열·인덱스 이름 바꾸기 | 데이터 처리 | DataFrame |
| IQR | 사분위 범위(Q3 − Q1). 이상치 경계 계산에 사용 | 데이터 처리 / EDA | 이상치, 박스플롯 |
| capping | 경계를 넘는 이상치를 최댓값 등으로 바꾸기 | 데이터 처리 | IQR, 이상치 |
| fillna | 결측치를 특정 값(평균 등)으로 채우기 | 데이터 처리 / EDA | 결측치, interpolate |
| dropna / drop | NaN이 있는 행을 제거 / 지정한 열·행을 제거 | 데이터 처리 / EDA | 결측치, DataFrame |
| merge | 공통 key를 기준으로 두 표를 합치기 | 데이터 처리 | concat, how 옵션 |
| how (inner/outer/left/right) | merge 방식. 교집합 / 합집합 / 왼쪽 기준 / 오른쪽 기준 | 데이터 처리 | merge |
| 기술통계 / 추론통계 | 데이터를 요약하는 통계 / 표본으로 모집단을 추정하는 통계 | 데이터 처리 | 평균·분산, EDA |
| 질적변수 / 양적변수 | 범주(명목·순서) / 수치(이산·연속) 변수 | 데이터 처리 | 데이터 비교 |
| 평균·중앙값·분산·표준편차 | 중심(평균·중앙값)과 퍼짐(분산·표준편차)을 나타내는 기초 통계 | 데이터 처리 / 파이썬 데이터 분석 | describe, 공분산 |

## 6. 시각화 · EDA

| 용어 | 쉬운 설명 | 관련 강의명 | 함께 보면 좋은 개념 |
| --- | --- | --- | --- |
| 히스토그램 | 단일 수치 변수의 분포를 막대로 표현(구간별 도수) | EDA | 박스플롯, 막대 차트 |
| 박스플롯 | 사분위·중앙값으로 퍼짐과 이상치를 보여주는 그래프 | EDA / 데이터 처리 | IQR, 이상치 |
| 산점도 | 두 수치 변수의 관계를 점으로 표현 | EDA | 상관계수, pairplot |
| 막대 차트 | 범주별 값을 비교하는 그래프 | EDA | 히스토그램, palette |
| 히트맵 | 변수 간 상관관계를 색으로 표현 | EDA | 상관계수, pairplot |
| Matplotlib | 파이썬 기본 시각화 라이브러리. `import matplotlib.pyplot as plt` | EDA | Seaborn |
| Seaborn | Matplotlib 기반의 더 세련·간결한 시각화 라이브러리 | EDA | Matplotlib, hue |
| hue | Seaborn에서 색으로 한 변수를 더 구분해 표현하는 옵션 | EDA | Seaborn, 산점도 |
| palette | 그래프의 색 묶음. 특정 대상 강조에 활용 | EDA | 막대 차트, 데이터 비교 |
| 공분산 | 두 변수가 함께 변하는 정도. 단위에 영향을 받음 | EDA | 상관계수 |
| 상관계수 | 관계의 강도를 −1~1로 표준화한 값. 단위에 휘둘리지 않음 | EDA | 공분산, 히트맵 |
| pairplot | 여러 변수의 모든 짝을 한 번에 산점도로 그리기 | EDA | 산점도, 히트맵 |
| 스케일링 | 서로 다른 변수의 값 범위를 맞추는 작업 | EDA | Min-Max, 표준화, 로버스트 |
| Min-Max / 표준화 / 로버스트 | 0~1로 / 평균0·표준편차1로 / 중앙값0·IQR1로(이상치에 강함) 변환 | EDA | 스케일링, fit/transform |
| fit / transform | 변환 기준을 학습(fit) / 그 기준으로 변환(transform) | EDA | 스케일링 |
| interpolate | 앞뒤 값을 잇는 직선 위의 값으로 결측치를 채우는 선형보간 | EDA | fillna, 결측치 |
| 특성 엔지니어링 | 기존 특성에서 새로운 특성을 만들어 모델 성능을 높이는 과정 | EDA | 인코딩, np.where |
| 인코딩 | 범주형 값(yes/no 등)을 수치(1/0)로 바꾸기 | EDA | np.where, 특성 엔지니어링 |
