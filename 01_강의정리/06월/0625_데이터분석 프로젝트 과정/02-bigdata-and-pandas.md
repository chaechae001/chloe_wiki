## 핵심요약

- **AI ⊃ 머신러닝 ⊃ 딥러닝**의 포함 관계를 가지며, 머신러닝은 데이터로 스스로 학습하는 기술, 딥러닝은 인공 신경망을 쓰는 머신러닝의 한 종류다.
- **빅데이터의 특징**은 3V(규모·다양성·속도)에서 시작해 가치(Value)·진실성(Veracity)을 더한 5V로 확장되며, 데이터는 정형·반정형·비정형으로 나뉜다.
- **데이터 분석**은 "문제 정의 → 데이터 수집 → 전처리 → 모델링 → 결과 분석·시각화"의 순서로 진행되는, 인사이트를 찾는 전 과정이다.
- 전처리의 핵심은 **이상치(범위를 크게 벗어난 값)**와 **결측치(누락된 값)**를 찾아 제거하거나 대체하는 일이다.
- **pandas**는 Numpy를 기반으로 표 형태 데이터를 다루는 라이브러리로, 1차원 **Series**와 2차원 **DataFrame**이 두 축이다.
- pandas는 같은 인덱스끼리 연산을 맞추고(없으면 NaN), 조건 필터링·정렬·순위·고유값 확인을 메서드 한 줄로 처리한다.
- `describe()`, `info()`, `isnull().sum()` 같은 메서드로 데이터의 상태를 빠르게 진단하고, CSV·엑셀로 읽고 쓸 수 있다.

## 개념별 정리

### 1. AI · 머신러닝 · 딥러닝의 관계

**1. 정의**
인공지능(AI)은 컴퓨터가 인간과 유사한 지능(학습·추론·인식·계획)을 갖도록 하는 기술의 큰 우산이다. 머신러닝은 그 한 분야로 데이터를 통해 스스로 학습하는 능력을 가리키고, 딥러닝은 사람의 신경망을 모사한 인공 신경망을 기반으로 하는 머신러닝의 한 종류다.

**2. 왜 필요한가?**
세 단어가 뉴스에서 섞여 쓰이지만 실제로는 포함 관계다. 이 위계를 알아야 "이 문제는 규칙 기반 AI로 충분한지, 머신러닝이 필요한지, 딥러닝까지 가야 하는지"를 판단할 수 있다.

**3. 예시 (개념 관계)**
머신러닝은 정답(label)이 있는지에 따라 두 갈래로 나뉜다.

- 지도학습(Supervised Learning): 정답이 있는 데이터로 학습 — 예: label이 붙은 강아지·고양이 사진 분류
- 비지도학습(Unsupervised Learning): 정답이 없는 데이터로 학습 — 예: label 없는 데이터의 군집화(클러스터링)

```text
[ 인공지능 (AI) ]
   └─ [ 머신러닝 (Machine Learning) ]
          └─ [ 딥러닝 (Deep Learning) ]
```

**4. 헷갈리기 쉬운 점**
"딥러닝 = AI의 최신 버전"이 아니다. 딥러닝은 머신러닝의 *부분집합*이며, 머신러닝 역시 AI의 *부분집합*이다. 셋은 경쟁 개념이 아니라 포함 관계다.

**5. 한 줄 정리**
AI라는 큰 우산 아래 머신러닝이 있고, 그 안에 신경망을 쓰는 딥러닝이 있다.

> 비유: 인공지능이 *교통수단 전체*라면, 머신러닝은 *자동차*, 딥러닝은 *전기차*다. 전기차도 결국 자동차이고, 자동차도 결국 교통수단이다.

### 2. 빅데이터와 그 특징 (3V → 5V)

**1. 정의**
빅데이터는 일반적인 수집·관리·처리 소프트웨어의 한계를 넘어서는 크기의 데이터로, 양이 방대하고 계속 증가해 전통적 방법으로는 분석하기 어려운 데이터를 말한다.

**2. 왜 필요한가?**
"데이터가 크다"는 막연한 표현을 분석가들은 V로 시작하는 특징으로 정리한다. 이 기준을 알면 우리가 다루는 데이터가 왜 어렵고 무엇을 조심해야 하는지 한눈에 잡힌다.

**3. 예시 (3V → 5V)**
- **Volume(규모)**: 테라바이트 수준의 큰 규모
- **Variety(다양성)**: 정형·비정형 등 다양한 형태
- **Velocity(속도)**: 실시간으로 생산·처리·유통되는 빠른 흐름
- **Value(가치)**: 데이터 속에 함축된 가치를 찾아냄
- **Veracity(진실성)**: 신뢰성과 타당성이 있는 데이터

데이터는 구조에 따라 세 종류로 나뉜다.

- 정형 데이터: 열과 행으로 이루어진 테이블 형식(구조화됨)
- 비정형 데이터: 비디오·오디오·텍스트처럼 특정 구조가 없는 데이터
- 반정형 데이터: 완전한 정형은 아니지만 어느 정도 구조가 있는 데이터(XML, HTML, JSON)

**4. 헷갈리기 쉬운 점**
3V·4V·5V는 "서로 다른 정의"가 아니라 *기존 V에 새 V를 누적해 가는 확장*이다. 또 엑셀처럼 보인다고 다 정형은 아니다 — JSON처럼 키-값 구조가 있으면 반정형으로 분류한다.

**5. 한 줄 정리**
빅데이터는 크고(Volume)·다양하고(Variety)·빠른(Velocity) 데이터에서 출발해, 가치(Value)와 진실성(Veracity)까지 따지는 데이터다.

> 비유: 빅데이터는 *쉴 새 없이 쏟아지는 거대한 폭포*다. 양도 많고(Volume), 물·나뭇잎·돌이 섞여 있고(Variety), 멈추지 않는다(Velocity).

### 3. 데이터 분석의 과정

**1. 정의**
데이터 분석은 유용한 인사이트(패턴·트렌드)를 발견하기 위해 데이터를 수집·정리·조작·분석하는 전 과정이다. 통계 분석·머신러닝·데이터 마이닝 등의 방법을 사용한다.

**2. 왜 필요한가?**
무작정 코드를 돌리는 게 아니라 *순서대로* 진행해야 시간 낭비와 잘못된 결론을 피한다. 분석은 효율적 의사결정, 타깃 이해, 마케팅 최적화, 리스크 관리에 직접 쓰인다.

**3. 예시 (분석 순서)**
1. **문제 정의**: 가치 있는 문제를 찾아 분석 대상과 목적을 구체적으로 설정
2. **데이터 수집**: 크롤링, open API 등으로 필요한 데이터 확보
3. **데이터 전처리**: raw data의 이상치·중복값·결측값 처리
4. **데이터 모델링**: 전처리된 데이터로 목적에 맞는 모델 생성(통계·머신러닝·딥러닝)
5. **결과 분석 및 시각화**: 시각화하고 결과를 해석해 인사이트 도출

분석 방식은 크게 두 갈래다 — 가설을 세우고 통계로 검증하는 **확증적 데이터 분석(CDA)**, 그리고 데이터를 먼저 탐색하며 패턴을 찾는 **탐색적 데이터 분석(EDA)**.

**4. 헷갈리기 쉬운 점**
전처리(3단계)를 건너뛰고 바로 모델링으로 가는 실수가 잦다. "양질의 데이터를 얼마나 확보하느냐"가 결과를 좌우하므로, 전처리는 선택이 아니라 필수다.

**5. 한 줄 정리**
데이터 분석은 "문제 정의 → 수집 → 전처리 → 모델링 → 해석·시각화"로 이어지는 일련의 과정이다.

> 비유: 데이터 분석은 *요리*다. 메뉴를 정하고(문제 정의), 장을 보고(수집), 재료를 다듬고(전처리), 조리하고(모델링), 접시에 담아낸다(시각화).

### 4. 빅데이터 활용 기술

**1. 정의**
빅데이터에서 의미를 끌어내는 대표적인 분석 기법들이다. 각 기법은 "어떤 질문에 답하려는가"에 따라 골라 쓴다.

**2. 왜 필요한가?**
같은 데이터라도 묻는 질문이 다르면 도구가 달라진다. 어떤 기법이 어떤 상황에 맞는지를 알아야 분석의 첫 삽을 제대로 뜬다.

**3. 예시 (대표 기법)**
- **연관 규칙 학습**: 변수들 사이의 관계 발견 — "(감자, 양파)를 산 사람은 햄버거도 산다" 같은 장바구니 규칙
- **유형 분석(분류 트리)**: 사건이 속할 범주를 찾음 — "이 사용자는 어떤 특성의 집단인가?" (문서·조직 분류)
- **유전 알고리즘**: 자연 선택·돌연변이를 모사해 최적해를 점진적으로 진화 — "응급실 의사 배치를 어떻게 해야 가장 효과적인가?"
- **기계 학습**: 학습된 특성으로 예측 — 영화·영상 추천 시스템
- **회귀 분석**: 독립 변수를 바꿔 종속 변수 변화를 파악 — "나이가 구매 차량 타입에 미치는 영향"
- **감정 분석**: 자연어에서 감정 시그널 추출 — 신제품 리뷰·댓글 분석
- **소셜 네트워크 분석**: 사회 관계망에서 영향력 있는 사람·관계 파악

**4. 헷갈리기 쉬운 점**
이름이 비슷한 "유형 분석(분류)"과 "회귀 분석"은 목적이 다르다. 분류는 *범주(어느 집단인가)*를, 회귀는 *연속적인 값의 변화(얼마나 변하는가)*를 다룬다.

**5. 한 줄 정리**
분석 기법은 "무엇을 묻는가"에 따라 고르는 도구 상자이며, 분류·회귀·연관·감정 분석이 대표 선수다.

> 비유: 분석 기법은 *공구함*이다. 못을 박을 땐 망치(분류), 나사를 조일 땐 드라이버(회귀)를 꺼내듯, 질문에 맞는 도구를 골라야 한다.

### 5. 데이터 변환 — 이상치와 결측치

**1. 정의**
이상치(outlier)는 데이터 범위에서 크게 벗어나 잘못된 분석을 부를 수 있는 값이고, 결측치(missing value)는 값이 누락된 데이터다.

**2. 왜 필요한가?**
이상치 하나가 평균을 크게 흔들고, 결측치가 있으면 계산 자체가 막히거나 왜곡된다. 전처리에서 이 둘을 다루는 게 분석 신뢰도의 출발점이다.

**3. 예시 (발견과 처리)**
이상치를 *발견*하는 방법:
- Box-plot(상자 수염 그림): 사분위 범위를 벗어난 점으로 확인
- Histogram(히스토그램): 분포에서 동떨어진 막대로 확인
- Scatter plot(산점도): 점들의 무리에서 멀리 떨어진 점으로 확인

이상치를 *처리*하는 방법:
- 제거: 해당 값을 빼기
- 대체: 평균값·중앙값으로, 또는 정해 둔 최댓값·최솟값으로 바꾸기

결측치 *처리*도 비슷하다 — 제거하거나, 평균값 등으로 대체한다.

**4. 헷갈리기 쉬운 점**
이상치를 무조건 지우면 안 된다. 진짜 중요한 신호(예: 사기 거래)가 이상치 모습으로 나타날 수도 있어, "제거 vs 대체"는 데이터 맥락을 보고 정해야 한다.

**5. 한 줄 정리**
이상치는 "튀는 값", 결측치는 "빈 값"이며, 둘 다 발견하고 적절히 제거·대체하는 게 전처리의 핵심이다.

> 비유: 전처리는 *과일 손질*이다. 멍든 부분(이상치)은 도려내고, 빠진 자리(결측치)는 채워 넣어야 깔끔한 한 접시가 된다.

### 6. pandas Series — 1차원 데이터 다루기

**1. 정의**
pandas는 Numpy를 기반으로 한 데이터 조작·분석 라이브러리로, 관례상 `import pandas as pd`로 불러온다. Series는 1차원 데이터를 담는 pandas의 기본 자료구조이며, 하나의 Series는 동일한 데이터 타입의 값을 가진다.

**2. 왜 필요한가?**
Numpy 배열이 "값만 있는 줄"이라면, Series는 각 값에 **인덱스(이름표)**가 붙은 줄이다. 'A', 'B' 같은 라벨로 값을 찾고, 라벨을 기준으로 자동 정렬해 주기 때문에 실제 데이터 분석에 훨씬 편하다.

**3. 예시**
Series를 만들고, 인덱스를 직접 지정하고, 값과 인덱스를 확인한다.

```python
import pandas as pd
import numpy as np

s = pd.Series([1, 3, 5, np.nan, 6, 8])
print(s)
# 0    1.0
# 1    3.0
# 2    5.0
# 3    NaN      ← 비어 있는 값은 NaN
# 4    6.0
# 5    8.0
# dtype: float64

s = pd.Series(np.random.randint(10, size=5), index=["A","B","C","D","E"])
print(s.index)    # Index(['A', 'B', 'C', 'D', 'E'], dtype='object')
print(s.values)   # [2 8 3 0 2]   (실행마다 값은 달라짐)
print(s.A)        # 2  (라벨로 값 접근)
```

인덱싱·슬라이싱과 조건 추출, 그리고 브로드캐스팅이 핵심이다.

```python
print(s['C'])            # 특정 라벨의 값
print(s[['B','C','E']])  # 여러 라벨을 한 번에
print(s[1::2])           # 위치 기반 슬라이싱
print(s[s > 5])          # 조건에 맞는 값만 (필터링)
print(s * 10)            # 모든 값에 10 곱하기 (브로드캐스팅)
```

Series끼리 연산하면 **같은 인덱스끼리** 계산되고, 짝이 없으면 NaN이 된다.

```python
s1 = pd.Series([1, 2, 3, 4, 5], index=["A","B","C","D","E"])
s2 = pd.Series([10, 20, 30], index=["A","C","E"])
result = s1 + s2
print(result)
# A    11.0
# B     NaN     ← s2에 B가 없어서 NaN
# C    23.0
# D     NaN
# E    35.0
# dtype: float64

print(result[result.notnull()])   # NaN을 뺀 값만 남기기
# A    11.0
# C    23.0
# E    35.0
```

**4. 헷갈리기 쉬운 점**
Series의 `+`는 위치가 아니라 **인덱스(라벨)를 맞춰** 더한다. 그래서 인덱스가 어긋나면 값이 있어도 NaN이 생긴다 — "왜 합쳤더니 NaN이 늘었지?"의 대부분은 이 인덱스 불일치 때문이다.

**5. 한 줄 정리**
Series는 "이름표(인덱스)가 붙은 1차원 데이터"로, 라벨로 찾고 인덱스를 맞춰 연산하는 게 핵심이다.

> 비유: Series는 *번호표가 붙은 사물함 한 줄*이다. 'A칸', 'C칸'처럼 이름으로 물건을 꺼낼 수 있고, 두 줄을 합칠 땐 같은 이름칸끼리 합쳐진다.

### 7. pandas DataFrame — 표 데이터 다루기

**1. 정의**
DataFrame은 여러 Series가 모여 이루어진 2차원 표 형태의 자료구조다. 행(row)과 열(column), 그리고 각각의 인덱스를 가진다.

**2. 왜 필요한가?**
현실의 데이터는 거의 다 "여러 열을 가진 표"다(이름·이메일·나이…). DataFrame은 엑셀 시트를 코드로 다루는 것과 같아서, 데이터 분석의 사실상 기본 단위가 된다.

**3. 예시**
DataFrame은 딕셔너리나 열 단위 대입으로 만든다.

```python
import pandas as pd

name = ["doori", "minsu"]
email = ["dr@example.com", "ms@example.com"]
df = pd.DataFrame({"Name": name, "Email": email})
print(df)
#     Name           Email
# 0  doori  dr@example.com
# 1  minsu  ms@example.com
```

행과 열을 선택할 땐 `iloc`(정수 위치 기반)과 `loc`(이름 기반)을 쓴다.

```python
# 5명짜리 df (doori, minsu, hana, hisu, hyun)라고 가정

# iloc: 정수 '위치'로 접근
print(df.iloc[0, 1])        # 0번 행, 1번 열의 값
print(df.iloc[0:2, :2])     # 0~1번 행, 0~1번 열

# loc: '이름'으로 접근 (끝 라벨 포함)
print(df.loc[0, "Name"])    # 0번 인덱스의 Name
print(df.loc[0:2, :"Name"]) # 0~2번 행, Name 열까지
```

조건 추출, 행·열 추가, 합치기(concat), 전치(T)도 자주 쓴다.

```python
print(df[df['Name'] == 'doori'])             # 조건에 맞는 행만

df.loc[5] = {"Email": "boo@example.com", "Name": "boo", "Age": 21}  # 행 추가
df["Address"] = ["Seoul", "Busan", "Jeju", "Deagu", "Seoul"]        # 열 추가
print(df.shape)                              # (행, 열) 개수 → 예: (5, 3)

df3 = pd.concat([df1, df2]).reset_index(drop=True)  # 위아래로 합치기
df3 = pd.concat([df1, df2], axis=1)                 # 좌우로 합치기
print(df.T)                                  # 행과 열을 바꾸기(전치)
```

**4. 헷갈리기 쉬운 점**
`iloc`과 `loc`의 차이가 가장 큰 함정이다. `iloc`은 **정수 위치**(0,1,2…)로 접근하고 끝을 *포함하지 않는다*(`iloc[0:2]`는 0,1). `loc`은 **이름(라벨)**으로 접근하고 끝 라벨을 *포함한다*(`loc[0:2]`는 0,1,2). 라벨이 숫자일 때 둘이 헷갈리기 쉽다.

**5. 한 줄 정리**
DataFrame은 "여러 Series가 모인 2차원 표"이며, `iloc`(위치)과 `loc`(이름)으로 원하는 행·열을 꺼낸다.

> 비유: DataFrame은 *엑셀 시트*, Series는 *그 시트의 한 열*이다. `iloc`은 "둘째 줄 첫째 칸"처럼 좌표로 찾기, `loc`은 "doori 행의 Age 칸"처럼 이름으로 찾기다.

### 8. 데이터 집계와 요약

**1. 정의**
DataFrame에 통계·정렬·확인용 메서드를 적용해 데이터의 전체 모습을 빠르게 파악하는 단계다.

**2. 왜 필요한가?**
분석의 첫걸음은 "이 데이터가 어떻게 생겼지?"를 아는 것이다. 합계·평균은 물론, 결측치가 몇 개인지, 어떤 값이 몇 번 나오는지를 한 줄로 확인해야 다음 단계를 정할 수 있다.

**3. 예시**
앞서 본 결측치(NaN) 개념을 실제 데이터로 다뤄 보자.

```python
import pandas as pd

names = ["apple", "pear", "banana", "strawberry", "mango", "cherry", "melon"]
quantity = [3, 5, 1, None, 1, 5, 5]   # strawberry의 값이 비어 있음(None → NaN)
fruit_df = pd.DataFrame({'Name': names, 'Quantity': quantity})
```

기초 통계는 NaN을 자동으로 건너뛰고 계산한다.

```python
print(fruit_df.Quantity.sum())    # 20.0   (NaN 제외 합)
print(fruit_df.Quantity.mean())   # 3.3333333333333335
print(fruit_df.Quantity.std())    # 1.9663841605003503
print(fruit_df.Quantity.min())    # 1.0
print(fruit_df.Quantity.argmin()) # 2   (최솟값의 '위치')
```

`describe()`는 주요 통계를 한 표로 요약한다.

```python
print(fruit_df.describe())
#        Quantity
# count  6.000000     ← NaN 제외 6개
# mean   3.333333
# std    1.966384
# min    1.000000
# 25%    1.500000
# 50%    4.000000     ← 중앙값
# 75%    5.000000
# max    5.000000
```

정렬·순위·고유값·빈도도 한 줄이다.

```python
print(fruit_df.sort_values(by='Quantity'))          # 값 기준 정렬(NaN은 맨 뒤)
print(fruit_df.Quantity.rank(ascending=False))      # 순위 매기기
print(fruit_df['Quantity'].value_counts())          # 값별 등장 횟수
print(fruit_df['Name'].unique())                    # 고유값 목록
```

데이터의 구조와 결측 현황은 `info()`, `isnull()`로 진단한다.

```python
print(fruit_df.info())
# RangeIndex: 7 entries, 0 to 6
# 0  Name      7 non-null   object
# 1  Quantity  6 non-null   float64   ← 1개가 비어 있음을 알 수 있음

print(fruit_df.isnull().sum())
# Name        0
# Quantity    1     ← 결측치가 Quantity에 1개
# dtype: int64
```

마지막으로 분석 결과는 CSV·엑셀로 저장하고 다시 읽어 들일 수 있다.

```python
fruit_df.to_csv('./fruit.csv', index=False)
df = pd.read_csv('./fruit.csv')

fruit_df.to_excel('./fruit.xlsx', sheet_name='Sheet1', index=False)
df = pd.read_excel('./fruit.xlsx', sheet_name='Sheet1')
```

**4. 헷갈리기 쉬운 점**
`value_counts()`(값별 등장 횟수)와 `count()`(결측치를 뺀 개수)를 혼동하기 쉽다. 또 `argmin()`은 최솟값의 *위치(인덱스)*를, `min()`은 최솟값 *그 자체*를 돌려준다 — 이름이 비슷한 짝이 많으니 "값이냐 위치냐"를 늘 의식하자.

**5. 한 줄 정리**
`describe()`·`info()`·`isnull().sum()`은 데이터의 분포와 결측 현황을 한눈에 보여 주는 "데이터 건강검진" 도구다.

> 비유: 이 메서드들은 *입국 심사대*다. 들어온 데이터의 개수·평균·빠진 곳을 빠르게 훑어, 통과시킬지 손볼지를 먼저 가린다.

## 코드로 보기 — 결측치를 진단하고 다루는 한 사이클

```python
import pandas as pd

# 1) 비어 있는 값(None)이 섞인 데이터 만들기
names = ["apple", "pear", "banana", "strawberry", "mango", "cherry", "melon"]
quantity = [3, 5, 1, None, 1, 5, 5]
fruit_df = pd.DataFrame({'Name': names, 'Quantity': quantity})

# 2) 결측치가 어디에 몇 개 있는지 진단
print(fruit_df.isnull().sum())
# Name        0
# Quantity    1
# dtype: int64

# 3) 통계는 결측치를 자동으로 건너뛴다
print(fruit_df['Quantity'].mean())   # 3.3333333333333335

# 4) 결측치를 평균값으로 대체 (전처리 이론을 코드로)
mean_value = fruit_df['Quantity'].mean()
fruit_df['Quantity'] = fruit_df['Quantity'].fillna(mean_value)
print(fruit_df.isnull().sum())
# Name        0
# Quantity    0     ← 결측치가 사라짐
```

**코드목적**
앞부분 이론(이상치·결측치)에서 배운 "결측치를 제거하거나 평균값으로 대체한다"를 실제 pandas 코드로 한 사이클 돌려 본다.

**해석**
`isnull().sum()`이 "어느 열에 결측치가 몇 개인지"를 알려 준다. 평균(`mean()`)은 NaN을 무시하고 계산되므로, 그 평균값으로 빈자리를 채우면(`fillna`) 데이터가 분석 가능한 상태가 된다. 채운 뒤 다시 `isnull().sum()`이 0이 되는 것으로 처리가 끝났음을 확인한다.

**실무 연결**
설문 응답 누락, 센서 결측, 거래 누락처럼 현실 데이터는 늘 빈칸이 있다. "진단 → 통계 확인 → 대체 → 재확인"의 이 짧은 루프가 모든 데이터 전처리의 기본형이며, 이후 모델링·시각화의 품질을 좌우한다.

## 헷갈리기 쉬운 포인트

- **AI vs 머신러닝 vs 딥러닝** — 경쟁 관계가 아니라 포함 관계(AI ⊃ 머신러닝 ⊃ 딥러닝).
- **지도학습 vs 비지도학습** — 정답(label)이 있으면 지도학습, 없으면 비지도학습.
- **분류 vs 회귀** — 분류는 범주(어느 집단), 회귀는 연속값의 변화(얼마나).
- **이상치 vs 결측치** — 이상치는 "튀는 값", 결측치는 "빈 값(NaN)".
- **Series `+`** — 위치가 아니라 인덱스(라벨)를 맞춰 더하며, 짝이 없으면 NaN.
- **iloc vs loc** — iloc은 정수 위치(끝 미포함), loc은 이름/라벨(끝 포함).
- **min vs argmin** — min은 최솟값(값), argmin은 그 위치(인덱스).
- **count vs value_counts** — count는 결측치 뺀 개수, value_counts는 값별 등장 횟수.

**복습 질문 및 답변**

*기본* — 딥러닝과 머신러닝은 어떤 관계인가?
> 딥러닝은 머신러닝의 한 종류다. 머신러닝 중에서도 사람의 신경망을 모사한 인공 신경망을 기반으로 하는 방법이 딥러닝이며, 머신러닝은 다시 AI의 한 분야다.

*이해 확인* — `pd.Series([1,2,3], index=['A','B','C'])`와 `pd.Series([10,20], index=['A','C'])`를 더하면 결과가 어떻게 되고, 왜 그런가?
> `A 11.0 / B NaN / C 23.0`이 된다. pandas Series의 연산은 같은 인덱스끼리 짝지어 계산하는데, 두 번째 Series에는 'B'가 없어 짝을 못 찾기 때문에 B는 NaN이 된다.

*응용* — Quantity 열에 결측치가 있는 과일 데이터에서, 결측치를 그 열의 평균값으로 채우려면 어떤 순서로 처리하나?
> 먼저 `df['Quantity'].mean()`으로 결측치를 제외한 평균을 구하고, `df['Quantity'] = df['Quantity'].fillna(평균값)`으로 빈자리를 채운 뒤, `df.isnull().sum()`이 0이 되는지 확인한다. mean이 NaN을 자동으로 무시하므로 평균값 자체는 결측치의 영향을 받지 않는다.
