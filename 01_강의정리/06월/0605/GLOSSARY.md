# 용어집 (GLOSSARY)

생성형 AI 개론에서 나온 핵심 용어를 비전공자 눈높이로 정리했습니다. "관련 글"은 그 용어를 자세히 다루는 글을, "함께 보면 좋은 개념"은 같이 알아 두면 이해가 깊어지는 짝 개념을 가리킵니다.

| 용어 | 쉬운 설명 | 관련 글 | 함께 보면 좋은 개념 |
| ---- | --------- | ------- | ------------------- |
| 생성형 AI | 학습한 패턴으로 글·이미지·코드 등 "없던 콘텐츠"를 만들어 내는 AI | ① AI란 무엇인가 | 전통적 AI, 자기회귀 |
| 전통적 AI | 데이터를 학습해 "예측·분류"에 집중하는 AI(정답 맞히기) | ① AI란 무엇인가 | 생성형 AI |
| 규칙 기반 AI | 사람이 입력한 규칙(if 조건)대로 동작하는 초기 방식 | ① AI란 무엇인가 | 머신러닝 |
| 머신러닝 | 사람이 규칙을 주는 대신, 데이터에서 패턴을 스스로 학습 | ① AI란 무엇인가 | 딥러닝, 규칙 기반 AI |
| 딥러닝 | 대규모 데이터로 이미지·음성·언어를 인식하는 학습 방식 | ① AI란 무엇인가 | 머신러닝, LLM |
| AI 모델 | AI의 "두뇌". 텍스트·이미지 생성, 추론 등 핵심 능력을 결정 | ② 모델과 서비스 | AI 서비스 |
| AI 서비스 | 모델을 담아 쓰게 해주는 "창구". 사용 환경·기능·요금을 제공 | ② 모델과 서비스 | AI 모델 |
| 서비스 접속형 | 로그인만 하면 바로 쓰는 가장 쉬운 활용법(기능은 서비스 범위 내) | ② 모델과 서비스 | API, 로컬 모델 |
| API | 키를 발급받아 내 프로그램에 AI를 끼워 넣는 방식(사용량 과금) | ② 모델과 서비스 | API 키, 토큰 |
| API 키 | API 사용을 인증하는 비밀번호 같은 문자열(유출 주의) | ② 모델과 서비스 / ⑦ 책임 있는 활용 | API, AI 보안 |
| 로컬 모델 | 모델을 내 컴퓨터·사내 서버에 직접 설치해 쓰는 방식(보안 유리, 장비 부담) | ② 모델과 서비스 | 오픈소스 모델, GPU |
| 오픈소스 모델 | 무료로 공개돼 다운로드·튜닝이 가능한 모델 | ② 모델과 서비스 | 로컬 모델 |
| GPU | 대규모 계산을 빠르게 처리하는 장치. AI 학습·구동의 핵심 인프라 | ② 모델과 서비스 | 컴퓨팅 성능 |
| 자기지도학습 | 정답을 사람이 달지 않고, 데이터 스스로가 문제·정답이 되어 학습 | ③ 작동 원리 | 자기회귀, 확산 모델 |
| 자기회귀 | "다음에 올 단어"를 예측해 하나씩 이어 붙여 문장을 만드는 방식 | ③ 작동 원리 | 자기지도학습, 환각 |
| LLM(거대 언어 모델) | 방대한 텍스트로 학습해 단어 예측 원리를 거대한 규모로 수행하는 모델 | ③ 작동 원리 | 자기회귀, 추론 모델 |
| 추론 모델 | 바로 답하지 않고 중간 사고 과정을 거쳐 답하는 모델(정확하지만 느리고 비쌈) | ③ 작동 원리 | Chain of Thought, LLM |
| Chain of Thought | 단계별로 생각을 적어 가며 푸는 추론 전략(생각의 사슬) | ③ 작동 원리 | 추론 모델 |
| 멀티모달 | 텍스트·이미지·소리·영상 등 여러 형태를 함께 다루는 모델 | ③ 작동 원리 | 확산 모델 |
| 확산 모델 | 노이즈를 더했다가 거꾸로 걷어내며 새 이미지를 만드는 방식 | ③ 작동 원리 | 자기지도학습, 자기회귀 |
| 심볼릭 AI(모델+지식) | 모델에 관련 지식을 결합해, 근거 있는 답을 만들게 하는 활용 구조 | ④ 모델 + 지식 | 지식 기반 활용 |
| 지식 기반 활용 | 질문과 함께 관련 자료를 줘서 답의 정확도·구체성을 높이는 활용법 | ④ 모델 + 지식 / ⑥ 산업 사례 | 컨텍스트, 내부 지식검색 |
| AI 에이전트 | 목표를 받아 스스로 여러 단계를 계획·실행하는 AI(목표지향·자율성·상태인식·행동수행) | ④ 모델 + 지식 / ⑥ 산업 사례 | 챗봇, Human in the Loop |
| 피지컬 AI | AI 지능을 로봇·기계 등 물리적 몸에 실어 현실에서 움직이게 한 것 | ④ 모델 + 지식 | 휴머노이드, 산업용 로봇 |
| SCQA | 도입을 짜는 틀: 상황(S)→전개·위기(C)→질문(Q)→답(A) | ⑤ 논리적 글쓰기 | 피라미드 원칙, MECE |
| 피라미드 원칙 | 결론을 맨 위에 두고 근거를 아래로 받치는 탑다운 구조 | ⑤ 논리적 글쓰기 | SCQA, MECE |
| MECE | 항목을 "겹치지 않게·빠뜨리지 않게" 나누는 정리 원칙 | ⑤ 논리적 글쓰기 | 피라미드 원칙 |
| 스마트팩토리 | 공정·설비 데이터를 AI로 분석해 생산성·품질을 높인 공장 | ⑥ 산업 사례 | 디지털 트윈 |
| 디지털 트윈 | 현실의 설비·공정을 디지털로 복제해 시뮬레이션·최적화하는 기술 | ⑥ 산업 사례 | 스마트팩토리 |
| 내부 지식검색 | 사내 비공개 자료를 근거로 답하게 만든 검색·질의 도구 | ⑥ 산업 사례 | 지식 기반 활용 |
| 환각(Hallucination) | AI가 사실이 아닌 내용을 사실처럼 그럴듯하게 만들어 내는 현상 | ⑦ 책임 있는 활용 / ③ 작동 원리 | 자기회귀, 결과 검증 |
| 아첨(Sycophancy) | AI가 사용자 의견에 동조하는 경향(듣기 좋은 답 ≠ 맞는 답) | ⑦ 책임 있는 활용 | 환각, 결과 검증 |
| Human in the Loop | 중요한 결정은 사람이 최종 검증·승인하게 두는 안전장치 | ⑦ 책임 있는 활용 | AI 에이전트, 결과 검증 |
| 프롬프트 비식별화 | 입력 자료에서 이름·번호 등 민감 정보를 가려서 넣는 보안 습관 | ⑦ 책임 있는 활용 | AI 보안, API 키 |
| 딥페이크 | AI로 만든 가짜 영상·음성. 명예훼손·사기 등에 악용될 위험 | ⑦ 책임 있는 활용 | 혐오표현, 투명한 소통 |
| 토큰 | AI가 텍스트를 다루는 처리 단위. API 비용·추론 비용의 기준 | ② 모델과 서비스 / ③ 작동 원리 | API, 추론 모델 |
| 트랜스포머 | 현대 LLM의 바탕이 되는 신경망 구조 | ① AI란 무엇인가 / ③ 작동 원리 | LLM, 딥러닝 |
