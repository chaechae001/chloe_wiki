# 용어집 (GLOSSARY)

이번 강의에 등장한 핵심 용어를 쉬운 말로 정리했습니다. "관련 강의명"은 그 용어를 자세히 다룬 글 제목이고, "함께 보면 좋은 개념"은 짝지어 이해하면 좋은 용어입니다.

| 용어 | 쉬운 설명 | 관련 강의명 | 함께 보면 좋은 개념 |
| ---- | --------- | ----------- | ----------- |
| 데이터 시각화 | 데이터를 그림으로 바꿔 메시지를 전달하고 의사결정을 돕는 작업 | 시각화는 왜 중요한가 | 삭제·분리·강조·배열, 독자 중심 보고 |
| 앤스컴 콰르텟 | 요약 수치는 거의 같은데 분포 모양은 전혀 다른 네 데이터 묶음 | 시각화는 왜 중요한가 | 기술통계량, 산점도 |
| 기술통계량 | 평균·분산 등 데이터를 수치로 압축한 요약값 | 숫자로 한 변수 요약하기 | 시각화, 분포 |
| 삭제·분리·강조·배열 | 좋은 차트를 만드는 네 단계 원리 | 시각화는 왜 중요한가 | 데이터 잉크 비율 |
| 로그 스케일 | 값의 범위가 매우 클 때 축을 압축해 패턴을 보이게 하는 방법 | 시각화는 왜 중요한가 | 축 눈금, 색상 접근성 |
| 색상 접근성 | 색각이상 사용자도 구분할 수 있도록 색·라벨·패턴을 함께 쓰는 것 | 시각화는 왜 중요한가 | 독자 중심 보고 |
| Matplotlib | 파이썬의 대표 시각화 라이브러리(계층 구조를 가짐) | Matplotlib & Seaborn 기본 문법 | Seaborn, fig/ax |
| Seaborn | Matplotlib 기반으로 더 적은 코드로 완성도 높은 그래프를 그리는 라이브러리 | Matplotlib & Seaborn 기본 문법 | Matplotlib, hue |
| fig / ax | fig는 전체 캔버스(종이), ax는 그래프가 그려지는 칸(좌표축) | Matplotlib & Seaborn 기본 문법 | 서브플롯, 객체지향 시각화 |
| 서브플롯(subplot) | 한 캔버스를 여러 칸으로 나눠 각각 다른 그래프를 그리는 것 | Matplotlib & Seaborn 기본 문법 | fig/ax, constrained_layout |
| 자료의 형태 | 자료를 수치형(연속·이산)과 범주형(명목·순위)으로 나누는 분류 | 그림으로 한 변수 요약하기 | 도수분포표, 척도 |
| 도수 / 상대도수 | 도수는 범주별 개수, 상대도수는 전체 대비 비율 | 그림으로 한 변수 요약하기 | value_counts, 도수분포표 |
| 도수분포표 | 자료를 범주(또는 구간)별 도수·상대도수로 정리한 표 | 그림으로 한 변수 요약하기 | 히스토그램, 계급 |
| value_counts | 한 범주형 변수의 도수(개수)를 세는 pandas 메서드 | 그림으로 한 변수 요약하기 | 상대도수, crosstab |
| 원형그래프 | 비율을 원의 조각으로 표현(범주 적을 때만 권장) | 그림으로 한 변수 요약하기 | 막대그래프 |
| 막대그래프 | 범주별 크기를 막대 높이로 비교하는 그래프 | 그림으로 한 변수 요약하기 | 원형그래프, 히스토그램 |
| 히스토그램 | 연속형 자료를 구간별 빈도 막대로 그린 그래프 | 그림으로 한 변수 요약하기 | 도수분포표, 도수다각형 |
| 도수다각형 | 계급 중앙점을 선으로 이어 여러 그룹 분포를 비교하는 그래프 | 그림으로 한 변수 요약하기 | 히스토그램 |
| 상자그림 | 최솟값·Q1·중앙값·Q3·최댓값을 한 그림에 담아 분포·이상치를 보이는 그래프 | 그림으로 한 변수 요약하기 | 사분위수, IQR, 이상치 |
| 평균(mean) | 모든 값의 합을 개수로 나눈 대표값(이상값에 민감) | 숫자로 한 변수 요약하기 | 중앙값, 최빈값 |
| 중앙값(median) | 정렬했을 때 가운데 값(이상값에 강건) | 숫자로 한 변수 요약하기 | 평균, 사분위수 |
| 최빈값(mode) | 가장 자주 나오는 값(단봉형 분포에서 유의미) | 숫자로 한 변수 요약하기 | 평균, 중앙값 |
| 분산 / 표준편차 | 평균에서 떨어진 정도(분산은 제곱 단위, 표준편차는 원래 단위) | 숫자로 한 변수 요약하기 | 편차, 변동계수 |
| 범위(range) | 최댓값 − 최솟값(가장 단순하지만 극단값에 민감) | 숫자로 한 변수 요약하기 | IQR |
| IQR(사분위수 범위) | Q3 − Q1, 중간 50% 데이터의 폭(극단값 영향 없음) | 숫자로 한 변수 요약하기 | 사분위수, 상자그림 |
| 백분위수 / 사분위수 | 정렬된 자료에서 특정 백분율 위치의 값(사분위수는 25·50·75%) | 숫자로 한 변수 요약하기 | IQR, 중앙값 |
| 변동계수(CV) | 표준편차 ÷ 평균 ×100(%), 단위가 없어 다른 변수끼리 비교 가능 | 숫자로 한 변수 요약하기 | 표준편차 |
| 분할표(crosstab) | 두 범주형 변수의 조합별 빈도를 담은 2차원 표 | 두 변수의 관계 요약하기 | 도수분포표, 상대도수 |
| 산점도 | 두 연속형 변수의 값 쌍을 점으로 찍어 관계를 보는 그래프 | 두 변수의 관계 요약하기 | 상관계수, 공분산 |
| 공분산(covariance) | 두 변수가 함께 변하는 방향·크기(단위 있음) | 두 변수의 관계 요약하기 | 상관계수 |
| 상관계수(correlation) | 공분산을 정규화해 −1~+1로 나타낸 직선관계의 방향·강도 | 두 변수의 관계 요약하기 | 공분산, 히트맵, 인과관계 |
| 히트맵 | 값(주로 상관계수)의 크기를 색으로 표현한 그림 | 두 변수의 관계 요약하기 | 상관계수 |
| 허위 상관 | 제3의 공통 원인 때문에 두 변수가 함께 움직이는 현상 | 두 변수의 관계 요약하기 | 상관계수, 인과관계 |
| 결측치(NaN) | 값이 비어 있는 칸 | 데이터 가공 실무 | isna, fillna |
| isna / notnull | 칸이 결측인지(isna) 아닌지(notnull) True/False로 표시 | 데이터 가공 실무 | sum, any |
| fillna | 결측치를 특정 값으로 채우는 메서드(dtype에 따라 동작 다름) | 데이터 가공 실무 | category 타입, 평균/중앙값 |
| category 타입 | 허용된 범주 목록을 갖는 pandas 자료형(새 값은 변환 필요) | 데이터 가공 실무 | astype, fillna |
| index=False | 저장 시 인덱스를 파일에 포함하지 않는 옵션(Unnamed 컬럼 방지) | 데이터 가공 실무 | to_csv, read_csv |
| 파생변수 | 기존 컬럼을 조합해 만든 새 컬럼 | 데이터 가공 실무 | pd.cut, drop |
| pd.cut | 연속형 값을 구간으로 나눠 범주로 만드는 함수 | 데이터 가공 실무 | 구간화, 도수분포표 |
| 문자열 접근자(.str) | 시리즈의 문자열에 문자열 메서드를 적용하는 통로 | 데이터 가공 실무 | contains, len |
