# 그림으로 한 변수 요약하기 — 범주형과 수치형 자료

> 데이터 한 컬럼을 받았습니다. 첫 질문은 "이건 어떤 종류의 자료인가?"입니다. 자료의 형태가 정해지면, 어떤 표와 어떤 그래프로 요약해야 할지가 자동으로 따라옵니다.

`자료의형태` `범주형` `수치형` `도수분포표` `valuecounts` `히스토그램` `도수다각형` `상자그림`

## 핵심요약

- 자료는 크게 **수치형(연속형·이산형)**과 **범주형(명목형·순위형)**으로 나뉜다.
- 자료의 형태가 정해지면 알맞은 **요약 방법과 그래프**가 정해진다.
- 범주형은 `value_counts()`로 도수·상대도수를, `pd.crosstab()`으로 교차표를 만든다. 그래프는 막대그래프가 기본, 원형그래프는 제한적으로 쓴다.
- 수치형(연속형)은 구간(계급)으로 나눠 **도수분포표 → 히스토그램**으로 요약한다.
- **도수다각형**은 계급 중앙점을 선으로 이어, 여러 그룹의 분포를 겹쳐 비교할 때 히스토그램보다 적합하다.
- **상자그림**은 다섯 요약 수치를 한 그림에 담아 분포·이상치를 한눈에 보여 준다(자세한 통계는 [4편](04-summarize-one-variable-numbers.md)).

---

## 개념별 정리

### 자료의 형태 — 수치형과 범주형

**1. 정의**
- **수치형(Numerical)**: 숫자로 측정되는 자료. 연속적으로 잴 수 있으면 **연속형**(예: 금액, 키), 셀 수 있는 정수면 **이산형**(예: 인원 수).
- **범주형(Categorical)**: 분류로 표현되는 자료. 순서가 없으면 **명목형**(예: 성별, 혈액형), 순서가 있으면 **순위형**(예: 학점 A+/A/A-).

**2. 왜 필요한가?**
자료형에 따라 쓸 수 있는 요약법과 그래프가 다릅니다. 범주형에 평균을 구하거나(예: 혈액형 평균?), 연속형을 원형그래프로 그리면 의미가 무너집니다.

**3. 예시**
식당 팁(tips) 데이터로 보면:
```python
# 연속형: total_bill(청구금액), tip(팁)
# 이산형: size(인원 수)
# 명목형: sex, smoker, day, time

df["sex"].unique()     # ['Female', 'Male']
df["smoker"].unique()  # ['No', 'Yes']
df["day"].unique()     # ['Sun', 'Sat', 'Thur', 'Fri']
df["time"].unique()    # ['Dinner', 'Lunch']
```

**4. 헷갈리기 쉬운 점**
숫자처럼 보여도 범주형일 수 있습니다. 예를 들어 "1=남, 0=여"로 코딩된 값은 숫자지만 명목형입니다. 자료가 "잴 수 있는 양"인지, "분류 표시"인지로 판단하세요.

**5. 한 줄 정리**
요약의 첫걸음은 **이 자료가 수치형인지 범주형인지** 가르는 것.

---

### 범주형 자료 요약 — 도수분포표와 교차표

**1. 정의**
- **도수**: 각 범주에 속한 관측값의 개수.
- **상대도수**: 도수를 전체 개수로 나눈 비율.
- **도수분포표**: 범주와 그 도수·상대도수를 나란히 정리한 표.
- **교차표(분할표)**: 두 범주형 변수의 조합별 빈도를 정리한 2차원 표.

**2. 왜 필요한가?**
범주형은 "어떤 범주가 얼마나 많은가", "전체에서 차지하는 비율은 얼마인가"가 핵심 질문입니다. 이를 표로 압축하면 비교가 쉬워집니다.

**3. 예시**
```python
# 도수 (범주별 개수)
df["day"].value_counts()

# 상대도수 (전체 대비 비율)
df["day"].value_counts(normalize=True).round(3)

# 한 범주 도수분포표
pd.crosstab(index=df["sex"], columns="count")

# 두 범주 교차표 (요일 × 흡연 여부)
pd.crosstab(index=df["day"], columns=df["smoker"])
```
막대그래프 해석 예로, 식당 데이터에서 **토요일 방문 수가 가장 많다**는 점이 한눈에 드러납니다.

**4. 헷갈리기 쉬운 점**
`value_counts()`는 한 변수의 도수, `pd.crosstab()`은 두 변수의 조합 빈도입니다. `crosstab`에서 `index`는 행 기준, `columns`는 열 기준 변수입니다.

**5. 한 줄 정리**
한 변수는 `value_counts()`, 두 변수의 조합은 `crosstab()`.

### 범주형 시각화 — 원형그래프 vs 막대그래프

**1. 정의**
- **원형그래프(Pie Chart)**: 원을 범주 비율로 나눠 조각낸 그림.
- **막대그래프(Bar Chart)**: 범주별 도수 크기를 막대 높이로 표현한 그림.

**2. 왜 필요한가?**
원형그래프는 **전체 대비 비율**을 직관적으로 보여 주지만, 범주가 많아지면 조각 크기 비교가 어려워집니다. 막대그래프는 **범주 간 크기 차이**를 비교하기에 가장 쉽습니다.

**3. 예시**
```python
labels = data_2019.index.tolist()    # ['어른', '청소년', '어린이']
data   = data_2019.tolist()          # [103125.0, 3817.0, 15209.0]

plt.pie(x=data, labels=labels, autopct="%1.1f%%")  # 비율(소수 첫째자리 + %) 표시
plt.legend(loc="lower left")
plt.show()

plt.bar(x=labels, height=data)        # 막대그래프
```

**4. 헷갈리기 쉬운 점**
원형그래프는 "예뻐 보여서" 자주 쓰이지만, 범주가 많거나 비율 차이가 작으면 오히려 해석을 방해합니다. 비율 비교가 핵심이고 범주가 적을 때만 제한적으로 쓰는 것이 안전합니다.

**5. 한 줄 정리**
비율은 원형(범주 적을 때만), 크기 비교는 막대.

> 비유: 원형그래프는 피자 한 판의 조각 비율, 막대그래프는 키 재기 줄 세우기.

### 수치형 시각화 — 도수분포표·히스토그램·도수다각형

**1. 정의**
- **도수분포표**: 연속형 자료를 구간(계급)으로 나눠 각 구간의 도수를 센 표.
- **히스토그램**: 계급×빈도를 막대로 그린 그림. 단일 분포의 형태를 본다.
- **도수다각형**: 각 계급의 중앙점을 선으로 이은 그림. 여러 그룹 비교에 유리하다.

**2. 왜 필요한가?**
연속형 자료는 값이 다 달라서 그대로는 도수를 셀 수 없습니다. 구간으로 묶어야 "어디에 몰려 있는지(분포)"가 보입니다.

**3. 예시**
```python
data = df["total_bill"].dropna()

# 구간 만들기 (Sturges 공식: 계급 수 k = 1 + log2(n))
n_class     = int(np.ceil(1 + np.log2(len(data))))
class_width = np.ceil((data.max() - data.min()) / n_class)
bins        = np.arange(data.min() - 0.5, data.max() + class_width, class_width)

# 히스토그램은 Seaborn이 아니라 Matplotlib의 hist
df["total_bill"].hist()                # 빠른 확인
plt.hist(data, bins=bins)              # 구간을 직접 지정
```

**4. 헷갈리기 쉬운 점**
강의에서 강조된 부분: 여기서 `hist`는 Seaborn의 `histplot`이 아니라 **Matplotlib의 `hist`**입니다. 또 `bins`(계급 수)를 어떻게 잡느냐에 따라 같은 데이터도 다른 인상을 줄 수 있습니다.

**5. 한 줄 정리**
연속형은 구간으로 묶어 히스토그램으로, 여러 그룹 비교는 도수다각형으로.

> 비유: 히스토그램은 한 반의 키 분포 막대, 도수다각형은 여러 반의 키 분포를 겹쳐 그린 꺾은선.

---

### 상자그림 — 분포와 이상치를 한 그림에

**1. 정의**
**상자그림(Box-Whisker Plot)**은 최솟값·Q1·Q2(중앙값)·Q3·최댓값의 다섯 요약 수치를 한 그림으로 표현합니다. 상자는 Q1~Q3(IQR), 상자 안 선은 중앙값, 수염 밖의 점은 이상치입니다.

**2. 왜 필요한가?**
단순히 평균만 보면 알 수 없는 **중앙값·이상치·퍼진 정도**를 한눈에 보여 줍니다. 여러 그룹을 나란히 그리면 분포 비교가 쉽습니다.

**3. 예시**
```python
day_order = ["Thur", "Fri", "Sat", "Sun"]
plt.boxplot(
    [df[df["day"] == d]["total_bill"].values for d in day_order],
    tick_labels=day_order
)
plt.title("요일별 청구금액 분포")
plt.show()

# Seaborn 버전
sns.boxplot(data=df, x="day", y="total_bill")
```

**4. 헷갈리기 쉬운 점**
상자그림은 봉우리가 **하나인 분포**에서 효과적입니다. 봉우리가 여러 개면 모양을 제대로 못 보여 주므로, 상자그림 전에 **히스토그램으로 분포 형태를 먼저 확인**하는 것이 좋습니다.

**5. 한 줄 정리**
상자그림은 다섯 수치를 한 그림에 담아 분포와 이상치를 동시에 보여 준다.

## 코드로 보기 — 연속형 자료의 도수분포표 만들기

연속형 자료를 구간으로 묶어 도수분포표를 만드는 전체 흐름입니다. ① 범위 → ② 계급 수·폭 → ③ 구간 → ④ 도수 → ⑤ 상대도수·누적도수 순서로 진행합니다.

```python
col  = "total_bill"
data = df[col].dropna()

# ① 자료의 범위
d_min, d_max = data.min(), data.max()
d_range      = d_max - d_min

# ② 계급 수·폭 (Sturges 공식)
n_class     = int(np.ceil(1 + np.log2(len(data))))
class_width = np.ceil(d_range / n_class)

# ③ 계급구간 경계점과 라벨
bins   = np.arange(d_min - 0.5, d_max + class_width, class_width)
labels = [f"{b:.0f}~{b+class_width:.0f}" for b in bins[:-1]]

# ④⑤ 도수 & 상대도수 & 누적도수
freq, edges = np.histogram(data, bins=bins)
rel_freq    = freq / freq.sum()

freq_table = pd.DataFrame({
    "계급구간": labels[:len(freq)],
    "도수":     freq,
    "상대도수": rel_freq.round(3),
    "누적도수": freq.cumsum(),
})
print(freq_table.to_string(index=False))
```

**코드목적**
값이 제각각인 연속형 자료를 "구간별 빈도"로 묶어, 분포를 표로 요약하기 위한 코드입니다.

**해석**
출력된 표의 각 행은 한 구간(계급)을 뜻하고, 도수는 그 구간에 들어온 데이터 개수, 상대도수는 전체 대비 비율, 누적도수는 위에서부터 더한 합입니다. 이 표를 그대로 막대로 세우면 히스토그램이 됩니다. 즉 **도수분포표와 히스토그램은 표/그림이라는 형태만 다른 같은 정보**입니다.

**실무 연결**
설문 점수, 응답 시간, 구매 금액처럼 연속형 데이터를 다룰 때, 도수분포표는 "어느 구간에 고객이 몰려 있는가"를 빠르게 보여 줍니다. 계급 구간을 잘 잡는 것은 직접 알고리즘이나 수식 계산을 할 때 NumPy의 배열 연산이 중요한 이유이기도 합니다.

## 헷갈리기 쉬운 포인트

- **`value_counts()` vs `crosstab()`**: 전자는 한 변수의 도수, 후자는 두 변수 조합의 빈도.
- **히스토그램 vs 막대그래프**: 히스토그램은 연속형 구간(막대 사이 빈틈 없음), 막대그래프는 범주형(막대 사이 간격 있음).
- **히스토그램 vs 도수다각형**: 단일 분포는 히스토그램, 여러 그룹 겹쳐 비교는 도수다각형.
- **원형그래프 vs 막대그래프**: 비율 강조는 원형(범주 적을 때), 크기 비교는 막대.

## 한 줄 정리

> 자료의 형태(범주형/수치형)가 정해지면 알맞은 표와 그래프가 따라오며, 도수분포표와 히스토그램은 같은 정보의 표/그림 버전이다.
