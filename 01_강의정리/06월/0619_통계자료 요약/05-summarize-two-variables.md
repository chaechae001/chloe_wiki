# 두 변수의 관계 요약하기 — 분할표·상관계수·히트맵

> 여름이면 상어 사고도, 아이스크림 판매도 함께 늘어납니다. 그렇다면 아이스크림이 상어 사고를 부르는 걸까요? "함께 움직인다"와 "원인이 된다"는 전혀 다른 이야기입니다.

`분할표` `산점도` `공분산` `상관계수` `히트맵` `인과관계` `허위상관` `crosstab`

## 핵심요약

- 한 변수 요약에서 나아가, 이제 **두 변수의 관계**를 본다.
- 범주형 × 범주형은 **분할표(crosstab)**, 연속형 × 연속형은 **산점도·공분산·상관계수**로 요약한다.
- **산점도**는 두 변수 관계를 보는 가장 기본 그림이며, 상관계수를 계산하기 전에 반드시 먼저 그려 봐야 한다.
- **공분산**은 함께 변하는 방향·크기를 보여주지만 단위가 있어 비교가 어렵다. **상관계수**는 단위를 없애 −1~+1로 정규화한 값이다.
- **히트맵**은 여러 변수의 상관계수 행렬을 색으로 표현해 한눈에 보여 준다.
- 가장 중요한 경고: **상관계수가 높다 ≠ 인과관계가 있다.**

---

## 개념별 정리

### 두 변수 요약의 분류

**1. 정의**
두 변수의 자료형 조합에 따라 요약 방법이 갈립니다.

| 자료 유형 | 요약 방법 |
|-----------|-----------|
| 범주형 × 범주형 | 분할표(contingency table) |
| 연속형 × 연속형 | 산점도, 공분산, 상관계수 |

**2. 왜 필요한가?**
"성별에 따라 흡연 여부가 다른가?"(범주×범주)와 "청구금액이 클수록 팁도 큰가?"(연속×연속)는 묻는 질문이 다르고, 따라서 도구도 다릅니다.

**3. 예시**
범주형 조합이면 빈도표(분할표), 연속형 조합이면 점 찍기(산점도)로 시작합니다.

**5. 한 줄 정리**
범주형 짝은 분할표, 연속형 짝은 산점도·상관계수.

---

### 분할표 — 두 범주형 변수의 결합 분포

**1. 정의**
**분할표**는 두 범주형 변수를 2차원 도수분포표로 나타낸 것입니다. 도수분포표를 2차원으로 확장한 형태라고 보면 됩니다. 각 셀에는 두 범주가 동시에 갖는 관측값의 수가 들어갑니다.

**2. 왜 필요한가?**
"어떤 요일에 어떤 식사시간이 많은가"처럼 두 분류가 어떻게 맞물리는지 봐야 할 때 씁니다. 비율로 바꾸면 조건부 분포까지 비교할 수 있습니다.

**3. 예시**
```python
# 도수 분할표 (요일 × 식사시간)
pd.crosstab(df["day"], df["time"])

# 행 기준 상대도수 (각 요일에서 시간대 비율)
pd.crosstab(df["day"], df["time"], normalize="index")

# 열 기준 상대도수
pd.crosstab(df["day"], df["time"], normalize="columns")
```
요일×식사시간 도수 분할표의 한 예:

|  | Dinner | Lunch |
|--|--------|-------|
| Thur | 1 | 61 |
| Fri | 12 | 7 |
| Sat | 87 | 0 |
| Sun | 76 | 0 |

토·일은 점심 식사가 0건으로, 주말 손님은 저녁에만 온다는 패턴이 드러납니다.

**4. 헷갈리기 쉬운 점**
`normalize="index"`는 행마다 합이 1(각 요일 안에서의 비율), `normalize="columns"`는 열마다 합이 1(각 시간대 안에서의 비율)입니다. 무엇을 기준으로 비교하느냐에 따라 골라 씁니다.

**5. 한 줄 정리**
분할표는 두 범주가 동시에 갖는 빈도를 담은 2차원 표.

---

### 산점도 — 두 연속형 변수의 관계 그리기

**1. 정의**
**산점도(Scatter Plot)**는 두 연속형 변수의 관측값 쌍을 좌표평면에 점으로 찍은 그림입니다.

**2. 왜 필요한가?**
두 변수가 같이 움직이는지, 방향은 어느 쪽인지를 **시각적으로** 가장 먼저 파악하는 방법입니다. 점이 많으면 일정한 띠(band) 형태를 이룹니다.

**3. 예시**
```python
plt.scatter(df["total_bill"], df["tip"])   # Matplotlib
sns.scatterplot(data=df, x="total_bill", y="tip")  # Seaborn

# 특정 범위만 보고 싶을 때
sns.scatterplot(data=df, x="어른", y="어린이")
plt.xlim(0, 35000)   # x축 범위 제한
plt.ylim(0, 6000)    # y축 범위 제한
```

**4. 헷갈리기 쉬운 점**
**상관계수를 계산하기 전에 반드시 산점도를 먼저** 그려야 합니다. 곡선 관계나 이상치 하나가 상관계수를 왜곡할 수 있는데, 산점도는 그것을 눈으로 잡아 줍니다(1편 앤스컴 콰르텟의 교훈).

**5. 한 줄 정리**
두 연속형 변수의 관계는 산점도로 먼저 눈으로 본다.

---

### 공분산과 상관계수

**1. 정의**
- **공분산(Covariance)**: 두 변수가 함께 변하는 방향과 크기를 나타냅니다. 같은 방향이면 +, 반대 방향이면 −. `dataframe.cov()`
- **상관계수(Correlation)**: 공분산을 두 변수의 표준편차로 나눠 **단위를 없앤** 값. −1~+1 사이. 피어슨이 제안해 피어슨 상관계수라고도 합니다. `dataframe.corr()`

**2. 왜 필요한가?**
공분산은 방향은 알려 주지만 단위(스케일)에 따라 값이 달라져 크기 비교가 어렵습니다. 상관계수는 −1~+1로 정규화돼 있어, **단위가 다른 변수끼리도** 직선관계의 강도를 비교할 수 있습니다.

**3. 예시**
```python
x = df["total_bill"]
y = df["tip"]

cov_val = np.cov(x, y, ddof=1)[0, 1]   # 공분산
r_val   = np.corrcoef(x, y)[0, 1]      # 상관계수
# r > 0: 정비례, r < 0: 반비례, r ≈ 0: 선형관계 없음

# 여러 변수의 상관 행렬
df[["total_bill", "tip", "size"]].corr().round(3)
```

**4. 헷갈리기 쉬운 점**
상관계수는 **직선(선형) 관계만** 측정합니다. 뚜렷한 곡선 관계가 있어도 r이 0에 가까울 수 있습니다. 또 이상치 하나가 r을 크게 바꿀 수 있습니다.

**5. 한 줄 정리**
공분산은 방향(단위 있음), 상관계수는 방향+강도(단위 없음, −1~+1).

> 비유: 공분산은 "둘이 같이 걷는다"는 사실, 상관계수는 "얼마나 발을 맞춰 걷는가"를 0~1로 점수화한 것.

### 히트맵과 인과관계의 함정

**1. 정의**
- **히트맵(Heatmap)**: 데이터 값의 상대적 크기를 색으로 표현한 그림. 보통 상관계수 행렬을 색으로 보여 줍니다.
- **인과관계**: x가 y의 원인이 된다고 믿어지는 관계.

**2. 왜 필요한가?**
변수가 많으면 상관계수 행렬이 숫자로 빽빽해 읽기 힘듭니다. 히트맵은 값이 1이나 −1에 가까울수록 진한 색으로 칠해 **강한 상관을 한눈에** 보여 줍니다.

**3. 예시**
```python
df_corr = df.corr(numeric_only=True)   # 수치형 변수들의 상관 행렬
sns.heatmap(df_corr)                    # 색으로 표현
```

**4. 헷갈리기 쉬운 점**
가장 중요한 경고입니다. **상관계수가 높다고 인과관계가 있는 것은 아닙니다.** 여름철 상어 사고와 아이스크림 판매량은 강한 양의 상관을 보이지만, 둘 다 "여름"이라는 제3의 공통 원인 때문에 함께 늘어난 것입니다. 이렇게 직접 인과 없이 제3 변수로 함께 움직이는 현상을 **허위 상관(spurious correlation)**이라 합니다. 원인과 결과를 판단하려면 추가 분석과 도메인 지식이 필요합니다.

**5. 한 줄 정리**
히트맵은 상관을 색으로 요약하지만, **상관 ≠ 인과**임을 늘 기억해야 한다.

> 비유: 우산 판매와 교통사고가 같이 는다고 우산이 사고를 내는 게 아니다. 범인은 "비"라는 공통 원인이다.

## 코드로 보기 — 산점도부터 상관계수·히트맵까지

두 연속형 변수의 관계를 그림 → 수치 → 행렬 순으로 요약하는 흐름입니다.

```python
import numpy as np
import seaborn as sns
import matplotlib.pyplot as plt

x = df["total_bill"]
y = df["tip"]

# 1단계: 수치 요약
cov_val = np.cov(x, y, ddof=1)[0, 1]
r_val   = np.corrcoef(x, y)[0, 1]
print(f"공분산: {cov_val:.4f}")
print(f"상관계수 r: {r_val:.4f}")   # 양수 → 청구금액↑ 일 때 팁↑ 경향

# 2단계: 산점도 + 추세선으로 눈으로 확인
fig, ax = plt.subplots(figsize=(7, 5))
ax.scatter(x, y, alpha=0.55, s=30)
m, b = np.polyfit(x, y, 1)                 # 1차 추세선 계수
xline = np.linspace(x.min(), x.max(), 200)
ax.plot(xline, m * xline + b, ls="--")     # 추세선
ax.set_xlabel("total_bill ($)")
ax.set_ylabel("tip ($)")
ax.set_title(f"total_bill vs tip  (r = {r_val:.2f})")
plt.show()

# 3단계: 여러 변수의 상관을 히트맵으로
df_corr = df.corr(numeric_only=True)
sns.heatmap(df_corr)
plt.show()
```

**코드목적**
두 변수의 관계를 ① 수치(공분산·상관계수)로 재고, ② 산점도로 눈으로 확인하고, ③ 여러 변수로 확장해 히트맵으로 보는, 표준 분석 절차를 한 번에 보여 줍니다.

**해석**
상관계수가 양수로 나오면 "청구금액이 클수록 팁도 많은 경향"으로 읽습니다. 하지만 그 값을 믿기 전에 산점도를 봐서 점들이 정말 직선 띠를 이루는지, 이상치가 값을 끌어올리진 않았는지 확인합니다. 히트맵에서는 진한 색일수록 강한 상관이며, 대각선은 항상 1(자기 자신과의 상관)입니다.

**실무 연결**
마케팅에서 "광고비와 매출의 상관이 0.9"라는 결과가 나와도, 그것만으로 "광고비를 올리면 매출이 오른다"고 결론 내릴 수 없습니다. 계절·신제품 출시 같은 공통 요인이 숨어 있을 수 있기 때문입니다. 히트맵은 변수가 많은 데이터에서 어떤 변수쌍을 더 깊이 파볼지 빠르게 골라 주는 길잡이로 유용합니다.

## 헷갈리기 쉬운 포인트

- **분할표 vs 산점도**: 범주형 짝은 분할표, 연속형 짝은 산점도.
- **공분산 vs 상관계수**: 공분산은 단위 있음(크기 비교 곤란), 상관계수는 단위 없음(−1~+1로 비교 가능).
- **상관 vs 인과**: 함께 움직임(상관)과 원인-결과(인과)는 다르다. 높은 상관도 제3 변수 때문일 수 있다.
- **`normalize="index"` vs `"columns"`**: 행 기준 비율 vs 열 기준 비율.

## 한 줄 정리

> 두 변수 관계는 분할표·산점도·상관계수·히트맵으로 요약하되, "함께 움직인다(상관)"를 "원인이 된다(인과)"로 착각하지 않는 것이 핵심이다.
