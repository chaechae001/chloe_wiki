# ROC 커브·AUC와 임계값 조정

> 0.5로 자를 필요는 없다. 확률을 어디서 자를지 정하는 기술.

`ROC` · `AUC` · `임계값` · `TPR` · `FPR`

## 핵심요약

- 분류기는 대개 확률을 먼저 내고, 임계값으로 0/1을 나눈다. 임계값은 바꿀 수 있다.
- ROC 커브는 임계값을 0에서 1까지 훑으며 (FPR, TPR)의 궤적을 그린 그래프다.
- AUC는 ROC 커브 아래 넓이로, 임계값과 무관하게 모델의 판별력을 하나의 숫자로 요약한다.
- AUC 0.5는 무작위, 1.0은 완벽. 불균형 데이터에서도 비교적 안정적이다.
- 임계값을 조정하면 정밀도와 재현율의 균형을 문제에 맞게 바꿀 수 있다.

---

## 1. 임계값(Threshold)이라는 손잡이

### 1) 정의

임계값은 확률을 클래스로 바꿀 때의 기준선이다. 예측 확률이 임계값 이상이면 양성, 미만이면 음성으로 분류한다. 기본값은 0.5지만 고정된 것이 아니다.

### 2) 왜 필요한가

같은 모델이라도 임계값을 낮추면 더 공격적으로 양성을 잡고(재현율↑), 높이면 신중하게 잡는다(정밀도↑). 문제의 비용 구조에 따라 이 손잡이를 돌려 최적점을 찾아야 한다.

### 3) 핵심 흐름 재구성

두 가지 비율이 임계값에 따라 함께 움직인다.

```text
TPR(재현율) = TP / (TP + FN)   ← 실제 양성을 얼마나 잡았나
FPR         = FP / (FP + TN)   ← 실제 음성을 얼마나 잘못 양성으로 봤나
```

임계값을 낮추면 TPR과 FPR이 함께 오르고, 높이면 함께 내린다. 좋은 모델은 낮은 FPR에서도 높은 TPR을 유지한다.

### 4) 쉬운 예시

공항 금속탐지기의 민감도를 생각하자. 민감하게 맞추면(임계값↓) 위험물은 다 잡지만 열쇠에도 삐 소리가 난다(오탐↑). 둔감하게 맞추면(임계값↑) 오탐은 줄지만 진짜 위험물을 놓칠 수 있다.

### 5) 코드 예시

```python
from sklearn.metrics import precision_score, recall_score, f1_score

proba = clf.predict_proba(X_te_s)[:, 1]   # 양성 확률

for t in [0.3, 0.5, 0.7]:
    p = (proba >= t).astype(int)
    print(f"thr={t}: precision={precision_score(y_te, p):.3f} "
          f"recall={recall_score(y_te, p):.3f} f1={f1_score(y_te, p):.3f}")
```

실행 결과:

```text
thr=0.3: precision=0.643 recall=0.828 f1=0.724
thr=0.5: precision=0.713 recall=0.713 f1=0.713
thr=0.7: precision=0.920 recall=0.529 f1=0.672
```

임계값 0.3에서는 재현율이 0.828로 높지만 정밀도가 낮고, 0.7에서는 정밀도가 0.920으로 치솟는 대신 재현율이 급락한다. 손잡이 하나로 균형이 바뀌는 것이 한눈에 보인다.

### 6) 헷갈리는 점

- `predict`는 내부적으로 0.5 임계값을 쓴다. 다른 임계값을 쓰려면 `predict_proba`로 확률을 받아 직접 잘라야 한다.
- 임계값을 바꿔도 **모델 자체는 그대로**다. 바뀌는 것은 확률을 자르는 기준뿐이다.

### 7) 한 줄 정리

> 임계값은 모델을 다시 학습하지 않고도 정밀도와 재현율의 균형을 조절하는 손잡이다.

## 2. ROC 커브와 AUC

### 1) 정의

ROC(Receiver Operating Characteristic) 커브는 임계값을 0에서 1까지 연속적으로 바꾸며 각 지점의 (FPR, TPR)을 이은 곡선이다. AUC(Area Under the Curve)는 그 곡선 아래 면적이다.

### 2) 왜 필요한가

정밀도·재현율은 특정 임계값에서의 스냅샷이다. ROC 커브는 **모든 임계값에서의 성능을 한 그림**에 담아, 임계값 선택 이전에 모델의 전반적 판별력을 비교하게 해준다.

### 3) 핵심 흐름 재구성

- 곡선이 왼쪽 위 모서리에 가까울수록 좋다(낮은 FPR에서 높은 TPR).
- 대각선(AUC=0.5)은 무작위 추측 수준이다.
- AUC=1.0은 완벽한 분리, 0.5는 동전 던지기다.
- AUC는 "무작위로 고른 양성 샘플이 무작위 음성 샘플보다 높은 점수를 받을 확률"로도 해석된다.

### 4) 쉬운 예시

시험 점수로 합격/불합격을 나눈다고 하자. 합격자들의 점수가 불합격자보다 대체로 높게 매겨져 있으면(잘 분리되면) AUC가 1에 가깝다. 점수가 뒤섞여 있으면 어디서 잘라도 잘 안 나뉘고 AUC는 0.5에 가까워진다.

### 5) 코드 예시

```python
from sklearn.metrics import roc_auc_score, roc_curve

proba = clf.predict_proba(X_te_s)[:, 1]
print(f"ROC-AUC = {roc_auc_score(y_te, proba):.3f}")

fpr, tpr, thresholds = roc_curve(y_te, proba)   # 시각화용 좌표
```

실행 결과:

```text
ROC-AUC = 0.844
```

AUC 0.844는 무작위(0.5)보다 확실히 높아, 이 모델이 두 클래스를 꽤 잘 구분한다는 뜻이다.

### 6) 헷갈리는 점

- AUC는 임계값과 무관하다. "AUC가 높다"와 "지금 임계값에서 성능이 좋다"는 다른 이야기다.
- 극단적 불균형에서는 ROC-AUC가 낙관적으로 보일 수 있어, PR 커브(정밀도-재현율)를 함께 보는 것이 안전하다.

### 7) 한 줄 정리

> ROC 커브는 모든 임계값의 성능을 그리고, AUC는 그 판별력을 하나의 숫자로 요약한다.

## 코드로 보기 — AUC 계산과 임계값 스윕 함께 보기

```python
import numpy as np
from sklearn.metrics import roc_auc_score, f1_score

proba = clf.predict_proba(X_te_s)[:, 1]
print("AUC:", round(roc_auc_score(y_te, proba), 3))

# 여러 임계값에서 F1이 가장 높은 지점 찾기
best_t, best_f1 = 0.5, 0
for t in np.arange(0.1, 0.9, 0.05):
    f1 = f1_score(y_te, (proba >= t).astype(int))
    if f1 > best_f1:
        best_t, best_f1 = t, f1
print(f"F1 최대 임계값 ≈ {best_t:.2f}, F1 ≈ {best_f1:.3f}")
```

### 코드 목적

AUC로 모델의 전반적 판별력을 확인하고, 임계값을 훑어 F1이 가장 좋은 운영 지점을 찾기 위한 코드다.

### 코드 흐름

1. 양성 확률을 얻는다.
2. AUC로 모델 전체를 평가한다.
3. 임계값을 촘촘히 바꾸며 F1을 계산한다.
4. 가장 좋은 임계값을 운영값으로 고른다.

### 실행 결과 해석

AUC는 모델을 바꾸지 않는 한 고정이지만, 임계값 스윕으로 찾은 최적 지점은 정밀도·재현율의 목표에 따라 달라진다. F1을 최대화하는 임계값이 반드시 0.5인 것은 아니다.

### 실무 연결

사기 탐지에서 "하루에 검토 가능한 알림 수"에 맞춰 임계값을 정하거나, 마케팅에서 "쿠폰 예산" 안에서 타겟 수를 맞추는 등, 비즈니스 제약에 맞춰 운영 임계값을 정하는 데 쓰인다.

1. 임계값을 0.5에서 0.3으로 낮추면 재현율과 정밀도는 각각 어떻게 변하는 경향이 있나?
2. AUC가 0.5라는 것은 무엇을 의미하는가?
3. 놓치면 큰일 나는 질병 스크리닝 모델의 임계값을 정할 때, 정밀도와 재현율 중 무엇을 우선해 임계값을 어느 방향으로 옮기겠는가?

<details>
<summary>정답 보기</summary>

1. 임계값을 낮추면 양성 판정이 늘어 재현율은 오르고, 오탐도 늘어 정밀도는 내려가는 경향이 있다.
2. 모델이 두 클래스를 전혀 구분하지 못해 무작위 추측과 같은 수준이라는 뜻이다.
3. 재현율을 우선한다. 환자를 놓치는 비용이 크므로 임계값을 낮춰(예: 0.5 → 0.3) 더 많이 양성으로 잡는다. 오탐은 2차 정밀검사로 걸러낸다.

</details>

## 헷갈리기 쉬운 포인트

| 헷갈리는 개념 | 차이 |
|---|---|
| TPR vs FPR | 실제 양성 중 잡은 비율은 TPR, 실제 음성 중 오탐 비율은 FPR |
| 임계값 조정 vs 재학습 | 임계값은 확률 자르는 기준만 바꿈, 재학습은 모델을 다시 만듦 |
| AUC vs 정확도 | AUC는 모든 임계값 판별력, 정확도는 특정 임계값 정답률 |
| ROC vs PR 커브 | 균형 데이터엔 ROC, 극단적 불균형엔 PR 커브가 더 정직 |

### 복습 질문 및 답변

**Q1. 임계값을 바꾸면 AUC도 바뀌는가?**

<details>
<summary>답</summary>

바뀌지 않는다. AUC는 모든 임계값에 걸친 성능을 요약한 값이라 특정 임계값 선택과 무관하다. 임계값을 바꾸면 정밀도·재현율 같은 특정 지점의 지표만 바뀐다.

</details>

**Q2. ROC 커브가 대각선에 가깝다면 어떻게 해석해야 하나?**

<details>
<summary>답</summary>

모델이 두 클래스를 거의 구분하지 못한다는 뜻이다. 특성 엔지니어링, 다른 알고리즘, 더 많은 데이터 등을 검토해야 한다.

</details>

**Q3. 불균형이 심한 데이터에서 ROC-AUC만 믿으면 안 되는 이유는?**

<details>
<summary>답</summary>

음성이 압도적으로 많으면 FPR이 작게 유지되기 쉬워 AUC가 낙관적으로 보일 수 있다. 이럴 때는 정밀도-재현율(PR) 커브를 함께 봐 소수 양성 클래스에 대한 실제 성능을 확인해야 한다.

</details>

## 한 줄 정리

> AUC로 모델의 판별력을 임계값과 무관하게 비교하고, 임계값 조정으로 문제에 맞는 정밀도·재현율 균형을 찾는다.
