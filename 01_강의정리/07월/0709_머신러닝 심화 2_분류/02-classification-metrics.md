# 분류 평가지표 — 혼동행렬·정밀도·재현율·F1

> 정확도 하나만 보면 속는다. 무엇을 맞히고 무엇을 놓쳤는지 뜯어보는 방법.

`혼동행렬` · `정밀도` · `재현율` · `F1` · `평가지표`

## 핵심요약

- 혼동행렬은 예측과 실제를 교차한 2×2 표로, 모든 분류 지표의 출발점이다.
- 정밀도는 "양성이라 예측한 것 중 진짜 양성 비율", 재현율은 "실제 양성 중 잡아낸 비율"이다.
- F1은 정밀도와 재현율의 조화평균으로, 둘의 균형을 하나의 숫자로 본다.
- 불균형 데이터에서는 정확도가 높아도 쓸모없을 수 있다.
- 어떤 지표가 중요한지는 문제의 비용 구조가 결정한다.

---

## 1. 혼동행렬(Confusion Matrix)

### 1) 정의

혼동행렬은 실제 값과 예측 값을 교차시켜 만든 표다. 이진 분류에서는 네 칸으로 나뉜다.

- **TP(True Positive)**: 실제 양성을 양성으로 맞힘
- **TN(True Negative)**: 실제 음성을 음성으로 맞힘
- **FP(False Positive)**: 실제 음성을 양성으로 잘못 예측(거짓 경보)
- **FN(False Negative)**: 실제 양성을 음성으로 놓침(놓친 사례)

### 2) 왜 필요한가

정확도 한 숫자는 "어떤 종류의 실수를 했는지"를 숨긴다. 암 진단에서 환자를 정상으로 놓친 실수(FN)와 정상인을 환자로 오인한 실수(FP)는 무게가 다르다. 혼동행렬은 이 둘을 분리해서 보여준다.

### 3) 핵심 흐름 재구성

scikit-learn의 `confusion_matrix`는 기본적으로 다음 배치로 반환한다.

```text
[[TN, FP],
 [FN, TP]]
```

행은 실제(0/1), 열은 예측(0/1) 순서다. 여기서 나오는 네 값으로 이후 모든 지표를 계산한다.

### 4) 쉬운 예시

낚시를 한다고 하자. TP는 물고기를 물고기라고 잡은 것, FP는 쓰레기를 물고기인 줄 알고 건진 것, FN은 물고기인데 놓친 것, TN은 쓰레기를 그냥 둔 것이다.

### 5) 코드 예시

```python
from sklearn.metrics import confusion_matrix

cm = confusion_matrix(y_te, pred)      # pred는 모델 예측
print(cm)
tn, fp, fn, tp = cm.ravel()            # 네 값을 각각 꺼낸다
print(f"TN={tn} FP={fp} FN={fn} TP={tp}")
```

실행 결과:

```text
[[103  25]
 [ 25  62]]
TN=103 FP=25 FN=25 TP=62
```

### 6) 헷갈리는 점

- Positive/Negative는 "좋다/나쁘다"가 아니라 "관심 클래스인가 아닌가"다. 생존 예측이면 생존이 Positive일 수도, 사망이 Positive일 수도 있다. 무엇을 양성으로 두는지 먼저 정해야 한다.
- 라이브러리마다 행/열 배치가 다를 수 있으니 축 라벨을 항상 확인한다.

### 7) 한 줄 정리

> 혼동행렬은 "무엇을 맞히고 무엇을 틀렸는지"를 네 칸으로 분해한 지도다.

## 2. 정밀도 · 재현율 · F1

### 1) 정의

혼동행렬의 네 값으로 세 지표를 만든다.

```text
Precision(정밀도) = TP / (TP + FP)
Recall(재현율)    = TP / (TP + FN)
F1 = 2 × Precision × Recall / (Precision + Recall)
Accuracy(정확도)  = (TP + TN) / (TP + TN + FP + FN)
```

### 2) 왜 필요한가

정밀도는 "예측이 얼마나 믿을 만한가", 재현율은 "놓치지 않고 얼마나 잡았는가"를 각각 다룬다. 둘은 대개 한쪽을 올리면 다른 쪽이 내려가는 트레이드오프 관계라, 상황에 맞는 균형점을 골라야 한다.

### 3) 핵심 흐름 재구성

- **정밀도 중시**: 잘못 양성 판정하는 비용이 클 때(예: 정상 메일을 스팸으로 막기)
- **재현율 중시**: 양성을 놓치는 비용이 클 때(예: 암 환자를 정상으로 판정)
- **F1**: 둘 다 중요하고 데이터가 불균형할 때 균형 지표로 사용

F1이 산술평균이 아니라 **조화평균**인 이유는, 한쪽이 극단적으로 낮으면 F1도 크게 떨어지도록 만들기 위해서다. 정밀도 1.0·재현율 0.0이면 F1은 0이 된다.

### 4) 쉬운 예시

경보 시스템을 생각하자. 정밀도가 높으면 "울리면 진짜 위험"이라 믿을 만하지만 놓치는 게 있을 수 있고, 재현율이 높으면 "위험은 다 잡지만" 오작동 경보도 많아진다. F1은 이 둘의 절충을 한 숫자로 요약한다.

### 5) 코드 예시

```python
from sklearn.metrics import (accuracy_score, precision_score,
                             recall_score, f1_score)

print(f"Accuracy ={accuracy_score(y_te, pred):.3f}")
print(f"Precision={precision_score(y_te, pred):.3f}")
print(f"Recall   ={recall_score(y_te, pred):.3f}")
print(f"F1       ={f1_score(y_te, pred):.3f}")
```

실행 결과:

```text
Accuracy =0.767
Precision=0.713
Recall   =0.713
F1       =0.713
```

이 예시는 FP와 FN이 25로 같아 정밀도·재현율·F1이 우연히 같은 값이 됐다. 보통은 세 값이 서로 다르다.

### 6) 헷갈리는 점

- 정밀도와 재현율은 **분모가 다르다**. 정밀도는 "예측 양성" 기준(TP+FP), 재현율은 "실제 양성" 기준(TP+FN)이다.
- F1이 높다고 정밀도·재현율이 둘 다 높은 것은 아니다. 값 자체를 함께 봐야 한다.

### 7) 한 줄 정리

> 정밀도는 예측의 신뢰도, 재현율은 놓치지 않는 능력, F1은 둘의 균형이다.

## 3. 정확도의 함정

### 1) 정의

정확도(Accuracy)는 전체 중 맞힌 비율이다. 직관적이지만 클래스가 심하게 불균형하면 심각하게 오해를 부른다.

### 2) 왜 필요한가

이 함정을 모르면 "정확도 95% 모델"에 만족했다가 정작 중요한 소수 클래스를 하나도 못 잡는 모델을 배포하게 된다. 사기 탐지, 희귀 질환처럼 양성이 드문 문제에서 특히 위험하다.

### 3) 핵심 흐름 재구성

양성이 5%인 데이터에서 무조건 "음성"이라고 찍기만 해도 정확도 95%가 나온다. 하지만 이 모델의 재현율(양성 포착률)은 0이다. 정확도만 보면 훌륭해 보이지만 실제로는 쓸모가 없다.

### 4) 쉬운 예시

1000명 중 사기꾼이 50명인데, "모두 정상"이라고 예측하면 950명을 맞혀 정확도 95%다. 그러나 사기꾼은 한 명도 못 잡았다. 이 모델을 배포하면 회사는 손해를 본다.

### 5) 코드 예시

```python
import numpy as np
from sklearn.metrics import accuracy_score, recall_score

# 양성 5%인 불균형 데이터
y_imb = np.array([0]*95 + [1]*5)
y_all_zero = np.zeros(100, dtype=int)   # 전부 음성으로 예측

print(f"Accuracy    = {accuracy_score(y_imb, y_all_zero):.3f}")
print(f"Recall(양성) = {recall_score(y_imb, y_all_zero):.3f}")
```

실행 결과:

```text
Accuracy    = 0.950
Recall(양성) = 0.000
```

정확도 0.95는 화려하지만 양성 재현율 0은 이 모델이 목적을 전혀 달성하지 못함을 드러낸다.

### 6) 헷갈리는 점

- 정확도가 높다고 좋은 모델이 아니다. **베이스라인(무조건 다수 클래스로 찍기)** 정확도와 비교해야 한다.
- 불균형 데이터에서는 F1, 재현율, ROC-AUC를 함께 봐야 한다.

### 7) 한 줄 정리

> 불균형 데이터에서 정확도는 착시를 일으킨다. 반드시 다른 지표와 함께 본다.

## 코드로 보기 — 하나의 예측에서 전체 지표 뽑기

```python
from sklearn.metrics import classification_report, confusion_matrix

print(confusion_matrix(y_te, pred))
print(classification_report(y_te, pred, digits=3))
```

### 코드 목적

한 번의 예측 결과에서 혼동행렬과 클래스별 정밀도·재현율·F1을 한꺼번에 확인해, 모델을 다각도로 진단하기 위한 코드다.

### 코드 흐름

1. 예측값과 실제값을 준비한다.
2. 혼동행렬로 네 칸을 확인한다.
3. `classification_report`로 클래스별 지표를 본다.
4. 문제 상황에 맞는 지표를 골라 판단한다.

### 실행 결과 해석

`classification_report`는 클래스 0과 1 각각의 정밀도·재현율·F1과 지원 개수(support)를 보여준다. 한쪽 클래스의 재현율만 낮다면 그 클래스를 잘 못 잡고 있다는 신호다.

### 실무 연결

이탈 예측 대시보드나 모델 검증 리포트에서 "정확도 몇 %"만 쓰지 않고 정밀도·재현율·F1을 함께 제시하는 것이 표준이다. A/B 테스트 결과 해석, 사기 탐지 임계값 결정에도 이 지표들이 기준이 된다.

## 직접 해보기

1. 혼동행렬이 `[[80, 20], [10, 90]]`일 때(왼쪽 위가 TN) TP, FP, FN, TN은 각각 얼마인가?
2. 위 값으로 정밀도와 재현율을 계산하라.
3. 응급실 중증 환자 선별 모델이라면 정밀도와 재현율 중 무엇을 더 높여야 하며, 그 이유는?

<details>
<summary>정답 보기</summary>

1. 배치 `[[TN, FP], [FN, TP]]` 기준으로 TN=80, FP=20, FN=10, TP=90.
2. 정밀도 = TP/(TP+FP) = 90/110 ≈ 0.818, 재현율 = TP/(TP+FN) = 90/100 = 0.900.
3. 재현율을 높여야 한다. 중증 환자(양성)를 놓치면(FN) 생명이 위험하므로, 다소 오탐(FP)이 늘더라도 놓치지 않는 쪽이 안전하다.

</details>

## 헷갈리기 쉬운 포인트

| 헷갈리는 개념 | 차이 |
|---|---|
| 정밀도 vs 재현율 | 예측 양성 기준(TP+FP)이면 정밀도, 실제 양성 기준(TP+FN)이면 재현율 |
| FP vs FN | 정상을 양성으로 오탐하면 FP, 양성을 놓치면 FN |
| 정확도 vs F1 | 전체 정답률은 정확도, 정밀도·재현율의 균형은 F1 |
| 산술평균 vs 조화평균 | F1은 조화평균이라 한쪽이 낮으면 크게 떨어진다 |
