# 의사결정나무 — 분할·불순도·과적합

> 스무고개처럼 질문을 던져 데이터를 나누는 모델. 해석은 쉽지만 과적합에 약하다.

`의사결정나무` · `지니` · `엔트로피` · `정보이득` · `과적합`

## 핵심요약

- 의사결정나무는 특성 조건으로 데이터를 계속 둘로 나누며 규칙을 만드는 모델이다.
- 좋은 분할은 나눈 뒤 각 그룹이 한 클래스로 순수해지는 분할이다.
- 순수한 정도(불순도)는 지니 지수나 엔트로피로 측정한다.
- 정보이득은 분할 전후 불순도가 얼마나 줄었는지를 나타낸다.
- 깊이를 제한하지 않으면 훈련 데이터를 통째로 외워 과적합된다.

---

## 1. 의사결정나무의 구조

### 1) 정의

의사결정나무(Decision Tree)는 "특성이 어떤 값 이상인가?" 같은 질문(분할 조건)을 노드마다 던져, 데이터를 가지치기하듯 나누는 모델이다. 최종 잎(leaf) 노드에서 다수 클래스로 예측한다.

### 2) 왜 필요한가

규칙이 사람이 읽을 수 있는 형태라 해석이 쉽다. "여성이고 1등석이면 생존" 같은 규칙을 그대로 보여줄 수 있어, 왜 그렇게 예측했는지 설명이 필요한 분야에서 강력하다. 또한 랜덤 포레스트·부스팅 같은 강력한 앙상블의 기본 부품이기도 하다.

### 3) 핵심 흐름 재구성

트리는 루트에서 시작해 매 단계 "가장 잘 나누는 질문"을 골라 가지를 친다. "잘 나눈다"는 것은 나눈 뒤 각 그룹의 불순도가 최대한 낮아진다는 뜻이다. 더 나눌 이득이 없거나 정지 조건(최대 깊이 등)에 닿으면 멈춘다.

### 4) 쉬운 예시

동물 스무고개를 떠올리자. "날개가 있나?" → "네" → "날 수 있나?"처럼 질문을 던지며 후보를 좁힌다. 각 질문은 남은 후보를 최대한 확실하게 갈라야 좋은 질문이다.

### 5) 코드 예시

```python
import seaborn as sns
from sklearn.model_selection import train_test_split
from sklearn.tree import DecisionTreeClassifier, export_text

df = sns.load_dataset('titanic')[['survived','age','fare','pclass','sex']].dropna().copy()
df['sex'] = (df['sex'] == 'female').astype(int)
X = df[['age','fare','pclass','sex']]
y = df['survived']
X_tr, X_te, y_tr, y_te = train_test_split(X, y, test_size=0.3, stratify=y, random_state=42)

tree = DecisionTreeClassifier(max_depth=2, criterion='gini', random_state=42)
tree.fit(X_tr, y_tr)
print(export_text(tree, feature_names=list(X.columns)))
```

실행 결과:

```text
|--- sex <= 0.50
|   |--- pclass <= 1.50
|   |   |--- class: 0
|   |--- pclass >  1.50
|   |   |--- class: 0
|--- sex >  0.50
|   |--- pclass <= 2.50
|   |   |--- class: 1
|   |--- pclass >  2.50
|   |   |--- class: 0
```

트리가 먼저 성별(sex)로 나누고, 그다음 객실 등급(pclass)으로 나눈 규칙이 그대로 보인다. 여성이고 2등석 이하(pclass ≤ 2.5)이면 생존(class 1)으로 예측한다.

### 6) 헷갈리는 점

- 트리는 스케일링이 거의 필요 없다. 크기 비교로 분할하기 때문에 단위 차이에 둔감하다.
- 하나의 트리는 데이터가 조금만 바뀌어도 구조가 크게 흔들리는 불안정성이 있다.

### 7) 한 줄 정리

> 의사결정나무는 불순도를 낮추는 질문을 연달아 던져 규칙을 만드는, 해석 쉬운 분류기다.

## 2. 불순도 — 지니와 엔트로피

### 1) 정의

불순도(impurity)는 한 노드에 여러 클래스가 얼마나 섞여 있는지를 나타낸다. 한 클래스만 있으면 0(순수), 반반 섞이면 최대다.

```text
지니 지수     Gini = 1 − (P(양성)² + P(음성)²)
엔트로피      Entropy = − Σ pᵢ × log₂(pᵢ)
```

### 2) 왜 필요한가

트리는 "어떤 분할이 좋은가"를 판단해야 한다. 그 기준이 불순도다. 분할 후 자식 노드들의 불순도가 낮아질수록 좋은 분할이다.

### 3) 핵심 흐름 재구성

- 완전히 순수(한 클래스만)하면 지니·엔트로피 모두 0
- 반반(50:50)이면 지니 0.5, 엔트로피 1.0으로 최대
- 지니는 계산이 빠르고, 엔트로피는 로그 계산이 들어가 조금 무겁지만 결과는 비슷한 경우가 많다

### 4) 쉬운 예시

과일 바구니를 상상하자. 사과만 있으면 "순수"(불순도 0)하고, 사과와 배가 반반이면 가장 "섞여 있다"(불순도 최대). 좋은 분할은 바구니를 나눴을 때 각 바구니가 한 과일에 가까워지게 만든다.

### 5) 코드 예시

```python
import numpy as np

def gini(pos, neg):
    n = pos + neg
    p, q = pos/n, neg/n
    return 1 - (p**2 + q**2)

def entropy(pos, neg):
    n = pos + neg
    e = 0
    for x in (pos/n, neg/n):
        if x > 0:
            e -= x * np.log2(x)
    return e

for pos, neg in [(10,0), (5,5), (8,2), (9,1)]:
    print(f"양성{pos}/음성{neg}: Gini={gini(pos,neg):.3f}  Entropy={entropy(pos,neg):.3f}")
```

실행 결과:

```text
양성10/음성0: Gini=0.000  Entropy=0.000
양성5/음성5: Gini=0.500  Entropy=1.000
양성8/음성2: Gini=0.320  Entropy=0.722
양성9/음성1: Gini=0.180  Entropy=0.469
```

순수할수록 0에 가깝고 반반일수록 최댓값에 가까워지는 흐름이 확인된다.

### 6) 헷갈리는 점

- 지니와 엔트로피는 척도만 다를 뿐, 대체로 비슷한 분할을 고른다. 어느 하나가 압도적으로 우월하지 않다.
- 엔트로피의 로그는 밑이 2다. 밑이 다르면 값의 스케일이 달라진다.

### 7) 한 줄 정리

> 불순도는 노드의 섞임 정도이고, 트리는 이를 낮추는 방향으로 분할을 고른다.

## 3. 정보이득과 과적합

### 1) 정의

정보이득(Information Gain)은 분할 전 부모의 불순도에서, 분할 후 자식들의 (가중) 불순도를 뺀 값이다. 클수록 좋은 분할이다.

```text
정보이득 = 부모 불순도 − Σ (자식 크기 비율 × 자식 불순도)
```

### 2) 왜 필요한가

트리는 매 단계 가능한 모든 분할 중 정보이득이 가장 큰 것을 고른다. 정보이득이 분할의 "품질 점수"인 셈이다. 또한 트리가 깊어질수록 훈련 데이터에만 맞춰지는 과적합을 관리해야 한다.

### 3) 핵심 흐름 재구성

깊이를 무한정 허용하면 트리는 훈련 데이터의 노이즈까지 외워 훈련 정확도는 1에 가깝지만 새 데이터에서는 성능이 떨어진다. `max_depth`, `min_samples_leaf` 같은 제약이 과적합을 막는 브레이크다.

### 4) 쉬운 예시

시험공부를 하는데 기출문제의 정답 번호만 통째로 외운 학생을 생각하자. 그 시험은 만점이지만 문제가 조금만 바뀌면 무너진다. 깊이 제한 없는 트리가 딱 이런 상태다.

### 5) 코드 예시

```python
from sklearn.tree import DecisionTreeClassifier
from sklearn.metrics import accuracy_score

for d in [1, 2, 3, 5, 10, None]:
    t = DecisionTreeClassifier(max_depth=d, random_state=42).fit(X_tr, y_tr)
    tr = accuracy_score(y_tr, t.predict(X_tr))
    te = accuracy_score(y_te, t.predict(X_te))
    print(f"depth={str(d):4s} train={tr:.3f} test={te:.3f}")
```

실행 결과:

```text
depth=1    train=0.784 test=0.772
depth=2    train=0.796 test=0.781
depth=5    train=0.858 test=0.828
depth=10   train=0.950 test=0.781
depth=None train=0.992 test=0.763
```

깊이가 깊어질수록 train 정확도는 0.992까지 오르지만 test는 5에서 정점을 찍고 오히려 떨어진다. train과 test의 벌어지는 간격이 과적합의 신호다.

### 6) 헷갈리는 점

- train 정확도가 오른다고 좋은 게 아니다. **train과 test의 격차**를 봐야 한다.
- 정보이득이 아무리 커도, 그 분할이 새 데이터에서 유효하다는 보장은 없다. 그래서 깊이 제한이 필요하다.

### 7) 한 줄 정리

> 정보이득이 큰 분할을 고르되, 깊이를 제한해 훈련 데이터를 외우는 과적합을 막아야 한다.

## 코드로 보기 — 정보이득 직접 계산해 보기

```python
import numpy as np

def entropy(pos, neg):
    n = pos + neg
    e = 0
    for x in (pos/n, neg/n):
        if x > 0:
            e -= x * np.log2(x)
    return e

parent = entropy(6, 4)                       # 부모: 양성6, 음성4
left   = 0.0                                  # 왼쪽 자식(4,0)은 순수
right  = entropy(2, 4)                        # 오른쪽 자식(2,4)
weighted = (4/10)*left + (6/10)*right          # 자식 크기 가중 평균
print(f"부모 엔트로피={parent:.3f}")
print(f"가중 자식 엔트로피={weighted:.3f}")
print(f"정보이득={parent - weighted:.3f}")
```

### 코드 목적

분할 전후 불순도 변화를 직접 계산해, 트리가 어떤 기준으로 "좋은 질문"을 고르는지 손으로 확인하기 위한 코드다.

### 코드 흐름

1. 부모 노드의 불순도를 계산한다.
2. 분할 후 각 자식의 불순도를 계산한다.
3. 자식 크기 비율로 가중 평균한다.
4. 부모에서 빼 정보이득을 구한다.

### 실행 결과 해석

```text
부모 엔트로피=0.971
가중 자식 엔트로피=0.551
정보이득=0.420
```

이 분할은 불순도를 0.971에서 0.551로 낮춰 0.420만큼의 정보이득을 준다. 트리는 가능한 분할 중 이 값이 가장 큰 것을 선택한다.

### 실무 연결

신용 승인, 이탈 사유 분석처럼 "왜 그런 결정을 내렸는지" 규칙으로 설명해야 하는 업무에서 트리는 해석 가능한 기준선으로 쓰인다. 이후 배우는 부스팅은 이 트리를 수백 개 결합해 성능을 끌어올린다.

## 헷갈리기 쉬운 포인트

| 헷갈리는 개념 | 차이 |
|---|---|
| 지니 vs 엔트로피 | 둘 다 불순도, 지니는 계산이 가볍고 엔트로피는 로그 기반 |
| 불순도 vs 정보이득 | 노드 섞임 정도는 불순도, 분할로 줄어든 불순도는 정보이득 |
| 얕은 트리 vs 깊은 트리 | 얕으면 과소적합 위험, 깊으면 과적합 위험 |
| 단일 트리 vs 앙상블 | 단일 트리는 불안정, 여러 트리 결합(포레스트·부스팅)은 안정적 |

## 연결되는 개념

- 이전에 알면 좋은 개념: ROC 커브·AUC와 임계값 조정
- 다음에 이어지는 개념: 그래디언트 부스팅 3형제 비교 — XGBoost·LightGBM·CatBoost
- 함께 보면 좋은 키워드: `랜덤포레스트`, `max_depth`, `해석가능성`
