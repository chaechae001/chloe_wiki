# GLOSSARY

## 배터리·재료 데이터

| 용어 | 설명 |
|---|---|
| 양극재 | 배터리 용량과 평균 전압에 큰 영향을 주는 핵심 소재 |
| 결정계 | 결정의 대칭성과 축 관계에 따른 구조 분류 |
| Materials Project | 계산 재료과학 데이터와 API를 제공하는 공개 프로젝트 |
| Formation Energy | 화합물 형성의 에너지적 유리함을 나타내는 값 |
| E Above Hull | 열역학적 안정성과 관련된 에너지 지표 |
| Band Gap | 전자가 이동하기 위해 넘어야 하는 에너지 차이 |

## 데이터 처리

| 용어 | 설명 |
|---|---|
| 결측치 | 관측되지 않아 비어 있는 값 |
| 대치 | 결측값을 추정값으로 채우는 처리 |
| 이상치 | 다른 관측과 크게 떨어진 값 |
| 원-핫 인코딩 | 범주마다 0/1 열을 만드는 표현 방식 |
| 정규화 | 값을 일정 범위로 조정하는 변환 |
| 표준화 | 평균 0, 표준편차 1 기준으로 조정하는 변환 |
| 데이터 누수 | 평가 시점에 알 수 없는 정보가 학습에 들어가는 문제 |
| 피처 엔지니어링 | 모델에 유용하도록 입력 표현을 생성·선택·변환하는 과정 |

## 모델과 평가

| 용어 | 설명 |
|---|---|
| 로지스틱 회귀 | 클래스 확률을 모델링하는 선형 분류기 |
| PCA | 분산을 많이 설명하는 축으로 차원을 줄이는 기법 |
| KNN | 가까운 이웃의 라벨을 이용하는 모델 |
| 랜덤 포레스트 | 여러 결정 트리의 결과를 결합하는 앙상블 |
| XGBoost | 이전 모델의 오류를 순차적으로 보완하는 부스팅 모델 |
| MLP | 여러 완전연결층으로 구성된 신경망 |
| Macro F1 | 클래스별 F1을 동일한 비중으로 평균한 값 |
| ROC-AUC | 분류 임계값 전반에서 순위 판별 능력을 요약한 값 |

## 일반화와 최적화

| 용어 | 설명 |
|---|---|
| 과적합 | 학습 데이터에는 잘 맞지만 새 데이터 성능이 낮은 상태 |
| 조기 종료 | 검증 성능이 개선되지 않을 때 학습을 멈추는 방법 |
| L2 규제 | 큰 가중치에 벌점을 부여하는 규제 |
| 드롭아웃 | 학습 중 일부 뉴런을 확률적으로 비활성화하는 기법 |
| 옵티마이저 | 손실을 줄이는 방향으로 파라미터를 갱신하는 알고리즘 |
| AutoML | 모델·하이퍼파라미터 탐색을 자동화하는 방법 |
