# 정상성과 확률보행 — 예측 가능한 시계열 만들기

> ADF 검정으로 정상성을 진단하고, 차분으로 예측 가능한 형태로 바꾸는 과정을 정리한 글입니다.

`정상성` · `확률보행` · `ADF검정` · `차분` · `ACF`

## 핵심요약

- 정상성(Stationarity)은 시계열의 평균·분산이 시간이 지나도 일정한 성질로, 많은 예측 모델의 전제 조건이다.
- 확률보행(Random Walk)은 "오늘 값 = 어제 값 + 무작위 오차"로 움직이는 대표적 비정상 시계열이다.
- ADF 검정의 p-value가 **0.05보다 크면 비정상**, **작으면 정상**으로 판정한다(관례).
- 차분(Differencing)은 연속한 값의 차이를 취해 비정상 시계열을 정상으로 바꾸는 핵심 전처리다.
- ACF(자기상관함수)는 현재 값이 과거 값과 얼마나 닮았는지 보여줘, 남은 패턴이 있는지 진단한다.

## 1. 정상성(Stationarity)

### 1) 정의

정상성은 시계열의 통계적 성질(평균, 분산 등)이 시간에 따라 변하지 않는 상태입니다. 정상 시계열은 언제 잘라 봐도 대체로 비슷한 평균과 흔들림을 보입니다. 비정상 시계열은 평균이 계속 오르거나(추세) 흔들림의 크기가 점점 커집니다(발산하는 분산).

### 2) 왜 필요한가

- 많은 전통적 시계열 모델(예: ARIMA)은 데이터가 정상이라는 가정 위에서 작동합니다.
- 비정상 데이터를 그대로 예측하면 추세를 잘못 학습하거나 예측이 발산할 수 있습니다.
- 그래서 예측 전에 "이 데이터가 정상인가"를 진단하고, 아니라면 정상으로 바꾸는 절차가 필요합니다.

### 3) 핵심 흐름 재구성

```
1. 진단  : ADF 검정으로 정상/비정상 판정
   - p-value > 0.05 → 비정상 (귀무가설: '비정상이다'를 기각 못 함)
   - p-value < 0.05 → 정상   (귀무가설 기각)
2. 변환  : 비정상이면 차분(diff)으로 변환
3. 재진단: 차분한 데이터에 다시 ADF 검정
4. 확인  : ACF로 남은 자기상관 패턴이 없는지 점검
```

### 4) 쉬운 예시

주가는 대표적인 비정상 시계열입니다. 오늘 주가는 어제 주가에 그날의 무작위 등락을 더한 값에 가깝고, 장기적으로 평균이 계속 이동합니다. 반면 "어제 대비 오늘의 변화량(차분)"은 평균이 0 근처에서 일정하게 흔들리는 정상 시계열에 가까워집니다. 그래서 주가 자체보다 변화량을 다루는 편이 예측에 유리합니다.

### 5) 코드 예시

확률보행을 만들어 ADF 검정으로 정상성을 진단합니다.

```python
import numpy as np
from statsmodels.tsa.stattools import adfuller
np.random.seed(42)

# 확률보행: 오늘 값 = 어제 값 + 무작위 오차(누적합)
steps = np.random.normal(0, 1, 1000)
random_walk = np.cumsum(steps)

adf = adfuller(random_walk)
print(f'ADF 통계량={adf[0]:.3f}, p-value={adf[1]:.3f}')
# ADF 통계량=-0.101, p-value=0.949  → p>0.05: 비정상
```

확률보행의 정의는 다음과 같습니다.

```
yₜ = yₜ₋₁ + εₜ     (εₜ: 평균 0의 무작위 오차)
오늘 값은 어제 값에 무작위 충격을 더해 결정된다
```

### 6) 헷갈리는 점

- ADF 검정의 귀무가설은 "비정상이다"입니다. 그래서 **p-value가 커야 비정상**, 작아야 정상입니다. 다른 검정의 습관과 반대라 헷갈리기 쉽습니다.
- 확률보행은 언뜻 추세가 있어 보이지만, 그 "추세"는 실제로는 무작위 누적일 뿐입니다. 그래서 확률보행의 미래는 원리적으로 예측이 매우 어렵습니다.
- 차분을 여러 번 하면 정상이 되지만, 과하게 하면 데이터가 오히려 잡음처럼 변합니다. 보통 1차 차분으로 충분한지 먼저 확인합니다.

### 7) 한 줄 정리

> 정상성은 시간이 지나도 평균·분산이 일정한 성질이며, 예측 모델이 잘 작동하기 위한 전제입니다.

## 코드로 보기 — 차분으로 정상성 만들기

```python
# 1차 차분: 연속한 값의 차이
diff = np.diff(random_walk, n=1)

adf2 = adfuller(diff)
print(f'차분 후 ADF 통계량={adf2[0]:.3f}, p-value={adf2[1]:.2e}')
# 차분 후 ADF 통계량=-31.860, p-value=0.00e+00  → p<0.05: 정상
```

차분의 정의:

```
차분값ₜ = yₜ − yₜ₋₁
어제와 오늘의 '차이'만 남긴다 → 추세가 제거되어 평균이 일정해짐
```

### 코드 목적

비정상이던 확률보행을 1차 차분해, 정상 시계열로 바뀌는지 ADF 검정으로 확인합니다.

### 코드 흐름

1. `np.diff`로 연속한 값의 차이를 계산한다.
2. 차분한 데이터에 다시 ADF 검정을 적용한다.
3. p-value가 0.05 밑으로 떨어졌는지 확인한다.

### 실행 결과 해석

차분 전 p-value는 0.949(비정상)였지만, 1차 차분 후에는 0에 가깝게 떨어져 정상으로 판정됩니다. 확률보행의 "어제 대비 변화량"은 평균 0 근처에서 일정하게 흔들리는 백색 잡음에 가깝기 때문입니다. 이처럼 차분은 추세를 제거해 비정상을 정상으로 바꾸는 가장 기본적인 전처리입니다.

### 실무 연결

주가·환율·매출처럼 추세가 강한 시계열을 예측할 때, 원본 대신 차분한 변화량을 모델에 넣는 것이 일반적입니다. ARIMA의 'I'(Integrated)가 바로 이 차분 횟수를 뜻합니다. 참고로, 확률보행이 순수한 백색 잡음의 누적이라면(즉 차분이 예측 불가능한 잡음이라면), 그 시계열의 내일 값에 대한 최선의 예측은 "오늘 값 그대로"가 됩니다.

3. 많은 예측 모델이 평균·분산이 일정하다는 전제 위에서 설계되어, 정상 시계열에서 더 안정적이고 발산하지 않는 예측을 내놓기 때문입니다.

## 헷갈리기 쉬운 포인트

| 헷갈리는 개념 | 차이 |
|---|---|
| 정상 vs 비정상 | 평균·분산이 일정하면 정상, 시간에 따라 변하면 비정상 |
| ADF p-value 방향 | 0.05보다 크면 비정상, 작으면 정상(귀무가설이 '비정상') |
| 추세 vs 확률보행 | 방향이 뚜렷한 규칙적 상승은 추세, 무작위 누적으로 생긴 겉보기 추세는 확률보행 |
| 차분 vs 보간 | 추세 제거로 정상화하는 것이 차분, 빈 값을 채우는 것이 보간 |

## 한 줄 정리

> 정상성 진단(ADF)과 차분은 비정상 시계열을 예측 가능한 형태로 바꾸는, 시계열 전처리의 핵심 절차입니다.
