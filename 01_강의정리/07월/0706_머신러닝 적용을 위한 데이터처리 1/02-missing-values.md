# 결측치 처리 — 비어 있는 값을 어떻게 다룰까

> 삭제할지, 채울지, 어떤 값으로 채울지. 결측치 앞에서의 판단 기준을 정리한 글입니다.

`결측치` · `isnull` · `fillna` · `보간법` · `데이터정제`

## 핵심요약

- 결측치는 수집·입력 과정에서 값이 비어 있는 상태이며, 전처리의 가장 먼저 확인할 항목이다.
- 처리 전략은 크게 **삭제, 대체(통계값), 보간(순서 기반)** 세 갈래로 나뉜다.
- 개수뿐 아니라 **비율(%)**을 함께 보면 "열을 통째로 지울지 vs 채울지"를 판단하기 쉽다.
- 치우친 분포에서는 평균보다 **중앙값** 대체가 이상치에 덜 흔들린다.
- 순서가 있는(시계열) 데이터는 앞뒤 값을 잇는 **보간(interpolate)**이 더 자연스럽다.

## 1. 결측치(Missing Values)

### 1) 정의

결측치는 데이터프레임에서 값이 존재해야 할 자리가 비어 있는 상태입니다. Pandas에서는 대개 `NaN`(Not a Number)으로 표시됩니다. "0"이나 "없음"이라는 값이 아니라, **아예 값이 기록되지 않은** 상태라는 점이 핵심입니다.

### 2) 왜 필요한가

- 대부분의 머신러닝 모델은 `NaN`이 섞인 데이터를 그대로 학습하지 못하고 에러를 냅니다.
- 결측을 아무 값으로나 채우면 분포가 왜곡되어 잘못된 패턴을 학습합니다.
- 결측이 생긴 이유(수집 실패, 해당 없음, 입력 누락)에 따라 올바른 처리 방법이 달라집니다.
- 실무 데이터는 거의 항상 결측을 포함하므로, 결측 처리 없이는 다음 단계로 넘어갈 수 없습니다.

### 3) 핵심 흐름 재구성

결측치를 만나면 아래 순서로 판단하면 정리하기 쉽습니다.

```
1. 확인   : 어느 컬럼에, 몇 개(비율 %) 비어 있나?      → isnull().sum(), isnull().mean()
2. 결정   : 삭제 vs 대체 vs 보간 중 무엇이 적절한가?
3-a 삭제  : 결측 비율이 매우 높은 열, 또는 결측이 극소수인 행
3-b 대체  : 중앙값·평균·최빈값, 또는 그룹별 통계값
3-c 보간  : 순서/시간 정보가 있는 데이터의 앞뒤 값 연결
4. 검증   : 처리 전·후 분포를 비교해 편향이 생기지 않았나 확인
```

판단 기준의 대략적인 감각은 이렇습니다. 결측 비율이 매우 높으면(예: 70% 이상) 그 열은 대체해도 신뢰가 낮아 **열 제거**가 합리적입니다. 결측이 극소수(몇 건)면 그 **행만 삭제**해도 손실이 작습니다. 그 사이라면 **대체**를 검토합니다.

### 4) 쉬운 예시

설문지에서 "나이" 칸을 비워둔 응답자가 있다고 해봅시다. 나이 결측이 전체의 20%라면, 그 응답을 모두 버리기엔 아깝습니다. 이럴 때 전체 나이의 중앙값으로 채우거나, 더 정교하게는 "같은 소득 구간 응답자들의 나이 중앙값"으로 채웁니다. 반면 결측이 딱 2건이라면 그냥 그 두 명을 빼는 것이 간단합니다.

### 5) 코드 예시

공개 데이터셋 `titanic`으로 결측 확인과 대체를 정리했습니다.

```python
import seaborn as sns
titanic = sns.load_dataset('titanic')

# (1) 확인 — 개수와 비율
print(titanic.isnull().sum())          # age 177, deck 688 ...
print((titanic.isnull().mean() * 100).round(1))  # age 19.9%, deck 77.2% ...
```

`deck`은 결측 비율이 77.2%로 매우 높아 대체보다 열 제거가 합리적입니다. `age`는 19.9%이므로 대체가 적절합니다.

```python
# (2) 중앙값 대체 — 나이는 치우칠 수 있어 평균보다 중앙값
df = titanic.copy()
med = df['age'].median()               # 28.0
df.loc[:, 'age'] = df['age'].fillna(med)
print(df['age'].isnull().sum())        # 0
```

```python
# (3) 그룹별 중앙값 대체 — 객실 등급마다 나이 분포가 다르다
df2 = titanic.copy()
df2.loc[:, 'age'] = df2.groupby('pclass')['age'].transform(
    lambda s: s.fillna(s.median())
)
# pclass별 age 중앙값: 1등급 37.0 / 2등급 29.0 / 3등급 24.0
```

전체 중앙값 하나로 채우는 것보다, 그룹별 중앙값으로 채우면 "1등급 승객이 대체로 나이가 많다"는 실제 패턴을 살릴 수 있습니다.

### 6) 헷갈리는 점

- `isnull().sum()`은 **개수**를, `isnull().mean()`은 **비율(0~1)**을 반환합니다. 비율에 100을 곱하면 %가 됩니다.
- `fillna`는 원본을 바꾸지 않고 채워진 복사본을 반환합니다. 반영하려면 재할당(`df.loc[:, 'age'] = ...`)해야 합니다.
- 평균 대체는 이상치가 있으면 채운 값 자체가 왜곡됩니다. 치우친 데이터에는 중앙값이 안전합니다.

### 7) 한 줄 정리

> 결측치 처리는 "지울까, 채울까, 무엇으로 채울까"를 데이터의 비율과 분포를 근거로 결정하는 일입니다.

## 코드로 보기 — 시계열 보간법

순서가 있는 데이터는 통계값 대체보다 앞뒤 값을 잇는 보간이 자연스럽습니다.

```python
import numpy as np
import pandas as pd

s = pd.Series([10, np.nan, np.nan, 40, 50],
              index=pd.date_range('2024-01-01', periods=5))

s.interpolate(method='linear')
```

실행 결과:

```
2024-01-01    10.0
2024-01-02    20.0    ← 10과 40 사이를 직선으로 채움
2024-01-03    30.0    ← 10과 40 사이를 직선으로 채움
2024-01-04    40.0
2024-01-05    50.0
```

### 코드 목적

시간 순서가 있는 데이터에서, 빈 구간을 앞뒤 값의 직선(linear)으로 자연스럽게 이어 채우는 코드입니다.

### 코드 흐름

1. 날짜 인덱스를 가진 시계열을 만든다.
2. 중간에 `NaN`이 있는 구간을 확인한다.
3. `interpolate(method='linear')`로 앞뒤 값 사이를 직선 보간한다.

### 실행 결과 해석

10과 40 사이의 두 결측이 20, 30으로 채워졌습니다. 두 값 사이를 균등한 간격의 직선으로 이었기 때문입니다. `method='time'`을 쓰면 날짜 간격(주말·휴일 등 실제 시간 차이)을 반영해 더 정교하게 채웁니다.

### 실무 연결

주가, 센서 측정치, 매출 로그처럼 시간 순서가 중요한 데이터에서 널리 쓰입니다. 다만 시계열 **양 끝**의 결측은 앞이나 뒤 값이 없어 보간이 안 되는 경우가 있어, 마지막에 남은 결측을 확인·제거하는 절차가 필요합니다.

## 헷갈리기 쉬운 포인트

| 헷갈리는 개념 | 차이 |
|---|---|
| 삭제 vs 대체 | 결측 비율이 높거나 극소수면 삭제, 그 사이면 대체를 검토 |
| 평균 vs 중앙값 대체 | 대칭 분포면 평균, 치우쳤거나 이상치가 있으면 중앙값 |
| 전체 대체 vs 그룹별 대체 | 하나의 통계값으로 채우면 전체 대체, 그룹 특성을 반영하면 그룹별 대체 |
| `ffill`/`bfill` vs `interpolate` | 앞뒤 값을 그대로 복사하면 fill, 사이를 수치로 계산해 채우면 보간 |

### 복습 질문 및 답변

**Q1. `NaN`은 값이 0이라는 뜻인가요?**

<details>
<summary>답</summary>

아닙니다. `NaN`은 "값이 아예 기록되지 않은" 상태이고, 0은 "0이라는 값이 기록된" 상태입니다. 둘을 혼동하면, 예컨대 "구매 금액 결측"을 0원으로 채워 실제 구매를 안 한 것처럼 왜곡할 수 있습니다.

</details>

**Q2. 그룹별 중앙값 대체는 왜 전체 중앙값 대체보다 나을 수 있나요?**

<details>
<summary>답</summary>

그룹마다 분포가 다르기 때문입니다. 타이타닉에서 1등급 승객의 나이 중앙값(37)과 3등급(24)은 크게 다릅니다. 전체 중앙값(28) 하나로 모두 채우면 이 차이가 뭉개지지만, 그룹별로 채우면 실제 패턴을 살릴 수 있습니다.

</details>

**Q3. 결측을 처리한 뒤에는 무엇을 확인해야 하나요?**

<details>
<summary>답</summary>

처리 전·후의 분포를 비교합니다. 히스토그램을 나란히 그려 형태가 크게 달라지지 않았다면, 결측 처리가 데이터에 큰 편향을 만들지 않았다고 볼 수 있습니다. 분포가 급격히 뾰족해졌다면(예: 한 값으로 몰림) 대체 방법을 재검토해야 합니다.

</details>
