# 용어집

이번 노트에 등장한 핵심 용어를 비전공자도 이해할 수 있게 쉬운 말로 정리했습니다.

## 탐색적 데이터 분석(EDA)

| 용어 | 쉬운 설명 | 관련 글 | 함께 보면 좋은 개념 |
| ---- | --------- | ------- | ------------------- |
| EDA | 모델을 돌리기 전에 데이터의 구조·분포·결측을 살펴 "이게 어떤 데이터인지" 파악하는 정찰 과정 | [EDA 4단계 워크플로우](01-eda-workflow.md) | 데이터 확인, 상관관계 분석 |
| `.loc` | 라벨(컬럼 이름, 조건)을 기준으로 원하는 행과 열을 뽑는 명시적 선택 방법 | [EDA 4단계 워크플로우](01-eda-workflow.md) | `.iloc`, 불리언 마스크 |
| `groupby` | 데이터를 특정 기준(예: 종, 등급)으로 묶어 그룹별 통계를 내는 집계 도구 | [EDA 4단계 워크플로우](01-eda-workflow.md) | 집계, `value_counts` |
| 파생변수 | 기존 컬럼을 조합해 새로운 의미를 가진 변수를 만드는 것(예: 팁 ÷ 계산서 = 팁 비율) | [EDA 4단계 워크플로우](01-eda-workflow.md) | 특성 엔지니어링, 바이닝 |
| `describe()` | 수치형 변수의 개수·평균·표준편차·최소·최대를 한 번에 요약해 주는 함수 | [EDA 4단계 워크플로우](01-eda-workflow.md) | 기술통계, 분포 |

## 데이터 정제 (결측치 · 이상치)

| 용어 | 쉬운 설명 | 관련 글 | 함께 보면 좋은 개념 |
| ---- | --------- | ------- | ------------------- |
| 결측치(NaN) | 값이 기록되어야 할 자리가 아예 비어 있는 상태(0이 아님) | [결측치 처리](02-missing-values.md) | 대체, 보간 |
| 중앙값 대체 | 결측을 그 컬럼의 가운데 값으로 채우는 방법. 이상치에 강해 치우친 데이터에 적합 | [결측치 처리](02-missing-values.md) | 평균 대체, 그룹별 대체 |
| 보간(interpolate) | 순서·시간 정보가 있는 데이터에서 빈 구간을 앞뒤 값을 이어 수치로 채우는 방법 | [결측치 처리](02-missing-values.md) | 선형 보간, 시계열 |
| 이상치(Outlier) | 대부분의 데이터에서 크게 벗어난 값. 오류일 수도, 진짜 극단 사례일 수도 있음 | [이상치 처리](03-outliers.md) | IQR, 박스플롯 |
| IQR | 25% 지점(Q1)과 75% 지점(Q3) 사이 범위. 이상치 경계를 정하는 기준으로 널리 쓰임 | [이상치 처리](03-outliers.md) | 사분위수, 박스플롯 |
| Winsorizing(clip) | 이상치를 삭제하지 않고 경계값으로 눌러, 데이터 개수를 유지하며 극단값을 완화하는 방법 | [이상치 처리](03-outliers.md) | 이상치 제거, binning |
| 구간화(binning) | 연속된 숫자를 몇 개의 구간(소액·중간·고액 등) 범주로 묶는 것 | [이상치 처리](03-outliers.md) | `pd.cut`, 파생변수 |

## 관계 분석 · 통계 검정

| 용어 | 쉬운 설명 | 관련 글 | 함께 보면 좋은 개념 |
| ---- | --------- | ------- | ------------------- |
| 상관계수 | 두 수치 변수가 함께 움직이는 선형 관계의 세기를 −1~1로 나타낸 값 | [상관관계와 통계 검정](04-correlation-and-tests.md) | heatmap, 다중공선성 |
| p-value | 관측된 차이·관계가 우연히 나타났을 확률. 관례적으로 0.05보다 작으면 "우연이 아니다"로 판정 | [상관관계와 통계 검정](04-correlation-and-tests.md) | t-test, 카이제곱 |
| t-test | 두 그룹의 평균 차이가 통계적으로 유의한지 판정하는 검정 | [상관관계와 통계 검정](04-correlation-and-tests.md) | 독립표본, p-value |
| 카이제곱 검정 | 두 범주형 변수(예: 성별·생존)가 서로 연관되어 있는지 판정하는 검정 | [상관관계와 통계 검정](04-correlation-and-tests.md) | 교차표, 연관성 |
| 다중공선성 | 서로 너무 강하게 상관된 변수들을 함께 넣었을 때 생기는 문제 | [상관관계와 통계 검정](04-correlation-and-tests.md) | 상관계수, 변수 선택 |

## 시계열

| 용어 | 쉬운 설명 | 관련 글 | 함께 보면 좋은 개념 |
| ---- | --------- | ------- | ------------------- |
| STL 분해 | 시계열을 추세·계절성·잔차 세 성분으로 나눠 구조를 드러내는 기법 | [시계열 분석 입문](05-timeseries-baseline.md) | 추세, 계절성 |
| 계절성 | 특정 주기(분기·월 등)마다 반복되는 패턴 | [시계열 분석 입문](05-timeseries-baseline.md) | STL, period |
| 베이스라인 모델 | 복잡한 모델의 성능을 평가할 기준선이 되는 단순 예측(전체 평균·계절 naive 등) | [시계열 분석 입문](05-timeseries-baseline.md) | MAPE, naive seasonal |
| MAPE | 예측 오차를 실제값 대비 백분율(%)로 나타낸 평가지표 | [시계열 분석 입문](05-timeseries-baseline.md) | MSE, 평가지표 |
| 정상성(Stationarity) | 시간이 지나도 평균·분산이 일정한 시계열의 성질. 많은 예측 모델의 전제 | [정상성과 확률보행](06-stationarity-random-walk.md) | ADF, 차분 |
| 확률보행 | 오늘 값 = 어제 값 + 무작위 오차로 움직이는 대표적 비정상 시계열 | [정상성과 확률보행](06-stationarity-random-walk.md) | 정상성, 차분 |
| ADF 검정 | 시계열이 정상인지 판정하는 검정. p-value가 0.05보다 크면 비정상 | [정상성과 확률보행](06-stationarity-random-walk.md) | 정상성, p-value |
| 차분(Differencing) | 연속한 값의 차이를 취해 추세를 제거하고 비정상을 정상으로 바꾸는 전처리 | [정상성과 확률보행](06-stationarity-random-walk.md) | ADF, ACF |
| ACF | 현재 값이 과거 값과 얼마나 닮았는지(자기상관) 보여주는 함수 | [정상성과 확률보행](06-stationarity-random-walk.md) | 차분, 백색 잡음 |

## 회귀 · 파이프라인

| 용어 | 쉬운 설명 | 관련 글 | 함께 보면 좋은 개념 |
| ---- | --------- | ------- | ------------------- |
| 회귀 | 연속적인 수치(가격·팁 등)를 예측하는 문제 유형 | [회귀 파이프라인 실전](07-regression-pipeline.md) | 분류, RMSE |
| Pipeline | 전처리와 모델 학습을 하나의 흐름으로 묶어 일관성과 안전성을 확보하는 도구 | [회귀 파이프라인 실전](07-regression-pipeline.md) | ColumnTransformer, 데이터 누수 |
| ColumnTransformer | 수치형·범주형 컬럼에 서로 다른 전처리를 컬럼별로 적용하도록 묶어 주는 도구 | [회귀 파이프라인 실전](07-regression-pipeline.md) | Pipeline, OneHotEncoder |
| 데이터 누수 | 평가용 데이터의 정보가 학습에 새어 들어가 성능이 실제보다 좋아 보이는 문제 | [회귀 파이프라인 실전](07-regression-pipeline.md) | Pipeline, 교차검증 |
| 교차검증 | 데이터를 여러 폴드로 나눠 번갈아 평가해 성능의 안정성을 확인하는 방법 | [회귀 파이프라인 실전](07-regression-pipeline.md) | KFold, 과적합 |
| RMSE | 실제와 예측 차이를 제곱·평균·제곱근한 오차. 큰 오차에 더 큰 벌점을 줌 | [회귀 파이프라인 실전](07-regression-pipeline.md) | MAE, R² |
| R²(결정계수) | 모델이 데이터의 분산을 얼마나 설명하는지 나타내는 값(1에 가까울수록 좋음) | [회귀 파이프라인 실전](07-regression-pipeline.md) | RMSE, 과적합 |
| 과적합 | 학습 데이터는 잘 맞히지만 새 데이터에는 약한 상태. train·valid 점수 격차로 진단 | [회귀 파이프라인 실전](07-regression-pipeline.md) | 교차검증, 정규화 |
