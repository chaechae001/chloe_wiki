# 이상치 처리 — IQR, Winsorizing, 구간화

> 튀는 값을 지울지, 자를지, 묶을지. 데이터 손실을 줄이며 이상치를 다루는 방법을 정리한 글입니다.

`이상치` · `IQR` · `boxplot` · `winsorizing` · `binning`

## 핵심요약

- 이상치는 다른 관측값과 현저히 동떨어진 값으로, 수집 오류일 수도 있고 진짜 극단 사례일 수도 있다.
- 가장 널리 쓰는 탐지 기준은 **IQR(사분위수 범위)**이며, 박스플롯의 수염 밖 점이 곧 이상치다.
- 처리 방법은 **삭제, 경계값으로 자르기(Winsorizing/clip), 구간화(binning)** 세 가지가 대표적이다.
- 소규모 데이터에서는 삭제 시 손실이 크므로, 삭제보다 **clip이나 binning**을 우선 검토한다.
- 이상치는 무조건 제거 대상이 아니다. "왜 튀는가"를 먼저 이해하고 처리 방법을 정한다.

## 1. 이상치(Outliers)

### 1) 정의

이상치는 대부분의 데이터가 모여 있는 범위에서 크게 벗어난 값입니다. 예를 들어 식당 계산서가 대부분 10~30달러인데 홀로 200달러인 값이 있다면, 그 값은 이상치일 가능성이 높습니다.

### 2) 왜 필요한가

- 이상치는 평균, 표준편차, 회귀계수 같은 통계량을 크게 왜곡합니다.
- 모델이 소수의 극단값에 과하게 반응해 일반적인 데이터를 잘 예측하지 못할 수 있습니다.
- 반대로 사기 탐지·불량 검출처럼 이상치 자체가 분석 목표인 경우도 있습니다.
- 따라서 "제거"가 아니라 "어떻게 다룰지"를 목적에 맞게 결정하는 판단이 필요합니다.

### 3) 핵심 흐름 재구성

이상치 처리는 아래 흐름으로 정리하면 기억하기 쉽습니다.

```
1. 탐지   : IQR 경계 계산 + 박스플롯으로 눈으로 확인
2. 이해   : 이 값이 오류인가, 진짜 극단 사례인가?
3. 처리   : 삭제 / clip(경계값으로 자르기) / binning(구간으로 묶기)
4. 비교   : 처리 전·후 박스플롯·히스토그램으로 효과 확인
```

IQR 기준 경계는 다음과 같이 계산합니다.

```
IQR = Q3 − Q1                    (Q1: 25% 지점, Q3: 75% 지점)
하한 = Q1 − 1.5 × IQR
상한 = Q3 + 1.5 × IQR
이 범위를 벗어나면 이상치로 표시
```

`1.5`라는 숫자는 관례적으로 널리 쓰이는 값입니다. 더 엄격하게 보려면 `3`을 쓰기도 합니다.

### 4) 쉬운 예시

반 학생들의 시험 점수가 대부분 60~90점인데 한 명이 5점이라면, 그 5점은 이상치로 보입니다. 이때 선택지는 세 가지입니다. 그 학생을 분석에서 빼거나(삭제), 하한 경계인 예컨대 45점으로 올려 잡거나(clip), 점수를 "하/중/상" 구간으로 묶어 극단값의 영향을 줄이는(binning) 것입니다.

### 5) 코드 예시

공개 데이터셋 `tips`의 `total_bill`로 IQR 경계를 계산하고 이상치를 확인합니다.

```python
import seaborn as sns
tips = sns.load_dataset('tips')
tb = tips['total_bill']

q1, q3 = tb.quantile(0.25), tb.quantile(0.75)
iqr = q3 - q1
low, high = q1 - 1.5 * iqr, q3 + 1.5 * iqr

print(f'Q1={q1:.2f}, Q3={q3:.2f}, IQR={iqr:.2f}')
# Q1=13.35, Q3=24.13, IQR=10.78
print(f'하한={low:.2f}, 상한={high:.2f}')
# 하한=-2.82, 상한=40.30

out = tips.loc[(tb < low) | (tb > high)]
print('이상치 개수:', len(out))   # 9
```

상한이 40.30이므로, 40.30을 넘는 계산서 9건이 이상치로 잡힙니다(가장 큰 값은 50.81). 하한이 음수(−2.82)인 이유는 계산서 금액이 0 밑으로 내려갈 수 없으니, 사실상 "작은 쪽 이상치는 없다"는 뜻입니다.

### 6) 헷갈리는 점

- IQR 경계가 음수여도 정상입니다. 그저 그 방향으로는 이상치가 없다는 의미입니다.
- 박스플롯의 점(수염 밖)은 정확히 IQR ±1.5 기준으로 찍힙니다. 그래서 IQR 계산과 박스플롯은 같은 규칙을 공유합니다.
- clip은 이상치를 삭제하지 않고 경계값으로 "눌러" 데이터 개수를 유지합니다. 표본이 적을 때 유리합니다.

### 7) 한 줄 정리

> 이상치 처리는 IQR로 튀는 값을 찾아, 목적에 맞게 삭제·clip·구간화 중 하나로 다루는 일입니다.

## 코드로 보기 — Winsorizing(clip)과 구간화

```python
# (1) Winsorizing — 경계값으로 자르기 (개수 유지)
clipped = tb.clip(lower=low, upper=high)
print('원본 최대:', round(tb.max(), 2))       # 50.81
print('clip 후 최대:', round(clipped.max(), 2)) # 40.30
print('clip 후 이상치 개수:', ((clipped < low) | (clipped > high)).sum())  # 0
```

```python
# (2) 구간화 — 연속값을 범주로 묶기
import pandas as pd
tips.loc[:, 'bill_band'] = pd.cut(
    tips['total_bill'],
    bins=[0, 15, 30, 100],
    labels=['소액', '중간', '고액']
)
print(tips['bill_band'].value_counts().sort_index())
# 소액 80 / 중간 132 / 고액 32
```

### 코드 목적

극단값을 삭제하지 않고 처리하는 두 가지 방법을 보여줍니다. clip은 경계값으로 자르고, binning은 값을 구간 범주로 바꿉니다.

### 코드 흐름

1. `clip(lower, upper)`로 하한·상한을 벗어난 값을 경계값으로 대체한다.
2. clip 후 최대값이 상한(40.30)으로 눌린 것을 확인한다.
3. `pd.cut`으로 연속값을 소액·중간·고액 구간으로 묶는다.

### 실행 결과 해석

clip 후 최대값이 50.81에서 40.30으로 눌렸고, 이상치 개수가 0이 되었습니다. 데이터 244건은 그대로 유지되었습니다. binning 결과는 대부분이 '중간'(132건)에 몰려 있고 '고액'이 32건입니다. 구간화하면 50달러든 45달러든 모두 '고액' 하나로 취급되어, 극단값 하나하나에 모델이 과민 반응하는 것을 줄입니다.

### 실무 연결

가격, 소득, 체류 시간처럼 소수의 큰 값이 평균을 왜곡하는 데이터에서 자주 쓰입니다. 특히 표본이 적은 경우, 이상치를 삭제하면 데이터가 더 줄어들어 손실이 크므로 clip을 우선 검토합니다. 신용점수를 등급으로 묶거나 나이를 연령대로 묶는 것도 같은 binning 원리입니다.

## 헷갈리기 쉬운 포인트

| 헷갈리는 개념 | 차이 |
|---|---|
| 결측치 vs 이상치 | 값이 비어 있으면 결측치, 값은 있지만 크게 벗어나면 이상치 |
| 삭제 vs clip | 이상치 행을 없애면 삭제, 경계값으로 눌러 개수를 유지하면 clip |
| clip vs binning | 값 자체를 경계로 자르면 clip, 값을 구간 범주로 바꾸면 binning |
| IQR 1.5 vs 3.0 | 일반적 기준은 1.5, 더 극단만 잡으려면 3.0 사용 |
