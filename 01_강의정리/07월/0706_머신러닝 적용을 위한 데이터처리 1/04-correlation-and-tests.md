# 상관관계와 통계 검정 — 눈으로 본 패턴을 확률로 확인하기

> heatmap에서 본 관계가 우연이 아닌지, t-test·상관 검정·카이제곱으로 뒷받침하는 글입니다.

`상관계수` · `heatmap` · `t-test` · `pearsonr` · `카이제곱`

## 핵심요약

- 상관계수는 두 수치 변수의 **선형 관계 강도**를 −1~1로 요약한다.
- 상관 heatmap은 여러 변수 쌍의 관계를 색으로 한눈에 보여주는 EDA 도구다.
- 상관이 높다고 인과가 있는 것은 아니며, 높은 상관은 **다중공선성**의 신호일 수 있다.
- t-test는 두 그룹의 **평균 차이**가 유의한지, pearsonr은 상관이 유의한지, 카이제곱은 두 범주의 **연관**이 유의한지 판정한다.
- 세 검정 모두 **p-value < 0.05**를 "우연으로 보기 어렵다"의 관례적 기준으로 삼는다.

## 1. 피어슨 상관계수

### 1) 정의

피어슨 상관계수는 두 수치 변수가 함께 커지고 함께 작아지는 정도를 −1에서 1 사이 하나의 숫자로 나타냅니다. 1에 가까우면 강한 양의 관계, −1에 가까우면 강한 음의 관계, 0에 가까우면 선형 관계가 거의 없음을 뜻합니다.

### 2) 왜 필요한가

- 어떤 변수들이 서로 밀접한지 파악하면, 모델에 쓸 변수를 고르는 데 도움이 됩니다.
- 너무 강하게 상관된 두 변수를 함께 넣으면 다중공선성 문제가 생길 수 있습니다.
- 타깃(예측 대상)과 상관이 높은 변수는 유력한 예측 후보가 됩니다.

### 3) 핵심 흐름 재구성

상관 분석은 아래 흐름으로 진행합니다.

```
1. 수치형 변수만 골라 상관행렬 계산   → df.corr()
2. heatmap으로 색으로 확인            → sns.heatmap(corr, annot=True)
3. 눈에 띄는 쌍을 scatter로 재확인
4. 필요하면 통계 검정으로 유의성 확인
```

상관계수의 대략적인 해석 기준은 다음과 같습니다.

```
|r| 0.0 ~ 0.2  : 거의 없음
|r| 0.2 ~ 0.4  : 약함
|r| 0.4 ~ 0.6  : 보통
|r| 0.6 ~ 0.8  : 강함
|r| 0.8 ~ 1.0  : 매우 강함
```

### 4) 쉬운 예시

키와 몸무게는 대체로 함께 커지므로 양의 상관(예: r ≈ 0.7)을 보입니다. 반면 운동 시간과 체지방률은 대체로 반대로 움직여 음의 상관을 보일 수 있습니다. 상관계수는 이런 "함께 움직이는 정도"를 숫자로 요약해 줍니다.

### 5) 코드 예시

공개 데이터셋 `penguins`의 수치형 변수로 상관행렬을 계산합니다.

```python
import seaborn as sns
peng = sns.load_dataset('penguins')
num = peng[['bill_length_mm', 'bill_depth_mm',
            'flipper_length_mm', 'body_mass_g']].dropna()

print(num.corr().round(2))
```

실행 결과:

```
                   bill_length  bill_depth  flipper_length  body_mass
bill_length              1.00       -0.24            0.66       0.60
bill_depth              -0.24        1.00           -0.58      -0.47
flipper_length           0.66       -0.58            1.00       0.87
body_mass                0.60       -0.47            0.87       1.00
```

`flipper_length`와 `body_mass`의 상관이 0.87로 매우 강합니다. 지느러미가 길수록 체중도 큰 경향이 뚜렷하다는 뜻입니다. 이런 쌍은 모델에 둘 다 넣으면 다중공선성을 염두에 둬야 합니다.

### 6) 헷갈리는 점

- 상관은 **선형** 관계만 잡습니다. U자 곡선처럼 휘어진 관계는 상관이 0에 가깝게 나올 수 있습니다.
- 상관이 높다고 인과가 있는 것은 아닙니다. "아이스크림 판매와 익사 사고"는 여름이라는 공통 원인 때문에 함께 오를 뿐입니다.
- 상관계수 하나만으로 결론짓지 말고 scatter로 실제 분포를 함께 봐야 합니다.

### 7) 한 줄 정리

> 상관계수는 두 변수가 함께 움직이는 선형 관계의 강도를 −1~1로 요약한 지표입니다.

## 코드로 보기 — 세 가지 통계 검정

heatmap이나 bar chart에서 발견한 패턴이 우연이 아닌지 확인하는 대표적인 세 검정입니다.

```python
from scipy import stats
import seaborn as sns
peng = sns.load_dataset('penguins').dropna(subset=['body_mass_g'])

# (1) 독립표본 t-test — 두 그룹의 평균 차이
gen = peng.loc[peng['species'] == 'Gentoo', 'body_mass_g']
ade = peng.loc[peng['species'] == 'Adelie', 'body_mass_g']
t, p = stats.ttest_ind(gen, ade)
print(f't={t:.2f}, p-value={p:.2e}')
# Gentoo 평균=5076, Adelie 평균=3701 / t=23.61, p-value=8.03e-68
```

```python
# (2) 상관 검정 — 상관이 유의한지 (계수 + p-value)
num = peng[['flipper_length_mm', 'body_mass_g']].dropna()
r, p = stats.pearsonr(num['flipper_length_mm'], num['body_mass_g'])
print(f'r={r:.3f}, p-value={p:.2e}')   # r=0.871, p-value=4.37e-107
```

```python
# (3) 카이제곱 — 두 범주 변수의 연관성
import pandas as pd
titanic = sns.load_dataset('titanic')
ct = pd.crosstab(titanic['sex'], titanic['survived'])
chi2, p, dof, _ = stats.chi2_contingency(ct)
print(f'chi2={chi2:.2f}, p-value={p:.2e}')  # chi2=260.72, p-value=1.20e-58
```

### 코드 목적

세 검정은 각각 다른 질문에 답합니다. t-test는 "두 그룹 평균이 정말 다른가?", 상관 검정은 "이 상관이 우연이 아닌가?", 카이제곱은 "두 범주가 서로 연관되어 있는가?"를 확률로 판정합니다.

### 코드 흐름

1. t-test: 두 종의 체중 평균을 비교한다.
2. pearsonr: 지느러미 길이와 체중의 상관과 그 유의성을 함께 구한다.
3. chi2: 성별과 생존을 교차표로 만들어 연관성을 검정한다.

### 실행 결과 해석

세 검정 모두 p-value가 0.05보다 훨씬 작습니다(각각 8.03e-68, 4.37e-107, 1.20e-58). 이는 "관측된 차이·관계가 단지 우연히 나타났을 확률이 거의 0에 가깝다"는 뜻으로, 종별 체중 차이·지느러미와 체중의 상관·성별과 생존의 연관이 모두 통계적으로 유의하다고 해석합니다. 앞선 heatmap과 bar chart에서 눈으로 본 패턴을 숫자로 확인한 셈입니다.

### 실무 연결

A/B 테스트에서 두 버전의 전환율 평균 차이를 검정할 때 t-test를, 마케팅 채널과 구매 여부의 연관을 볼 때 카이제곱을 사용합니다. "눈으로 본 차이"를 의사결정 근거로 삼기 전에 검정으로 뒷받침하는 것이 보고서 신뢰도를 높입니다.

## 직접 해보기

1. 상관계수 r = 0.9와 r = −0.9 중 어느 쪽이 더 강한 관계일까요? 이유와 함께 답하세요.
2. 두 그룹의 평균 차이가 유의한지 확인할 때 쓰는 검정과, 그 판정 기준(p-value)을 쓰세요.
3. "아이스크림 판매량과 물놀이 사고 건수의 상관이 0.8"이라는 결과를 보고, 아이스크림을 금지하면 사고가 줄어든다고 결론 내릴 수 있을까요?

<details>
<summary>정답 보기</summary>

1. 강도는 부호가 아니라 절댓값으로 판단하므로, |0.9| = |−0.9| = 0.9로 두 관계의 강도는 같습니다. 다만 방향이 다릅니다. r=0.9는 함께 커지는 양의 관계, r=−0.9는 하나가 커질 때 다른 하나가 작아지는 음의 관계입니다.

2. 독립표본 t-test(`ttest_ind`)를 사용하며, 관례적으로 p-value가 0.05보다 작으면 "두 그룹 평균 차이가 우연이라고 보기 어렵다"고 판정합니다.

3. 없습니다. 이는 상관이 인과가 아닌 대표적 사례입니다. 여름이라는 공통 원인이 아이스크림 판매와 물놀이를 동시에 늘린 것이지, 아이스크림이 사고를 일으킨 것이 아닙니다. 인과를 주장하려면 통제된 실험이 필요합니다.

</details>

## 헷갈리기 쉬운 포인트

| 헷갈리는 개념 | 차이 |
|---|---|
| 상관 vs 인과 | 함께 움직이면 상관, 하나가 다른 하나를 일으키면 인과 |
| t-test vs 카이제곱 | 수치형 두 그룹 평균 비교는 t-test, 범주형 두 변수 연관은 카이제곱 |
| 상관계수 r vs p-value | 관계의 세기는 r, 그 관계가 우연이 아닐 근거는 p-value |
| 양의 상관 vs 음의 상관 | 함께 커지면 양, 하나가 커질 때 다른 하나가 작아지면 음 |

### 복습 질문 및 답변

**Q1. 상관계수가 0이면 두 변수는 아무 관계가 없나요?**

<details>
<summary>답</summary>

선형 관계가 없다는 뜻일 뿐, 관계 자체가 없다는 보장은 아닙니다. U자 곡선처럼 휘어진 관계는 상관이 0에 가깝게 나올 수 있습니다. 그래서 상관계수와 함께 scatter로 실제 모양을 확인하는 것이 중요합니다.

</details>

**Q2. p-value가 작을수록 효과가 크다는 뜻인가요?**

<details>
<summary>답</summary>

아닙니다. p-value는 "관측된 차이가 우연일 확률"이지 효과의 크기가 아닙니다. 표본이 아주 크면 아주 작은 차이도 p-value가 작게 나올 수 있습니다. 효과의 크기는 평균 차이나 상관계수 같은 별도의 지표로 봐야 합니다.

</details>

**Q3. 카이제곱 검정은 어떤 데이터에 쓰나요?**

<details>
<summary>답</summary>

두 개의 범주형 변수(예: 성별과 생존 여부)가 서로 연관되어 있는지 볼 때 씁니다. 교차표(crosstab)를 만들어 "만약 두 변수가 무관하다면 기대되는 빈도"와 "실제 관측된 빈도"의 차이가 우연인지 판정합니다.

</details>
