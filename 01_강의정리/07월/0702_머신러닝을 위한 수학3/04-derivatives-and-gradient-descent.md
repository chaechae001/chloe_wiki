# 미분과 경사하강법 — 기계가 스스로 답을 찾아가는 원리

> 미분은 "지금 어느 쪽으로 얼마나 기울어져 있는가"를 알려 줍니다. 경사하강법은 그 기울기를 이용해 손실을 조금씩 줄여 가며 최적의 값을 찾습니다.

`미분` · `연쇄법칙` · `경사하강법` · `학습률` · `임계점`

## 핵심요약

- 미분(도함수)은 한 점에서의 순간 변화율, 즉 접선의 기울기다.
- 연쇄법칙은 겹쳐진 함수의 미분을 단계별 기울기의 곱으로 계산한다.
- 경사하강법은 기울기의 반대 방향으로 조금씩 이동해 손실을 줄인다.
- 학습률은 한 걸음의 보폭으로, 너무 크면 발산하고 너무 작으면 느리다.
- 임계점은 기울기가 0인 지점이며, 2차 미분으로 그 성질을 구분한다.

## 1. 미분과 연쇄법칙

### 1) 정의

미분은 함수가 한 점에서 얼마나 빠르게 변하는지를 나타내는 값이다. 그래프에서는 그 점에 그은 접선의 기울기와 같다. 연쇄법칙은 함수가 함수 안에 들어 있는 합성함수를 미분하는 규칙이다.

### 2) 왜 필요한가

머신러닝 모델은 "손실을 가장 작게 만드는 값"을 찾는다. 손실이 지금 어느 방향으로 늘고 주는지를 알아야 값을 조정할 수 있는데, 그 방향과 크기를 알려 주는 것이 미분이다. 신경망처럼 함수가 여러 겹으로 쌓인 구조에서는 연쇄법칙이 반드시 필요하다.

### 3) 핵심 흐름 재구성

미분의 기본 아이디어는 "아주 작은 변화에 대한 출력의 변화 비율"이다.

```
기울기 ≈ (f(x + 아주작은값) − f(x)) ÷ (아주작은값)
```

연쇄법칙은 다음처럼 기울기를 곱으로 이어 붙인다.

```
겉함수(속함수(x))를 미분하면
= 겉함수의 기울기 × 속함수의 기울기
```

### 4) 쉬운 예시

산을 내려간다고 하자. 미분은 "지금 발밑이 얼마나 가파른가"를 알려 준다. 연쇄법칙은 "기어 → 바퀴 → 속도"처럼 단계가 이어질 때, 전체 변화가 각 단계 변화의 곱으로 전달되는 것과 같다.

### 5) 코드 예시

수치적으로 기울기를 근사해 보는 최소 예제다.

```python
def f(x):
    return (x - 3) ** 2 + 1     # 직접 정한 예시 함수

def numeric_slope(x, h=1e-5):
    return (f(x + h) - f(x)) / h

print(round(numeric_slope(0), 3))   # x=0에서의 기울기 ≈ -6
print(round(numeric_slope(3), 3))   # x=3에서의 기울기 ≈ 0
```

x=3에서 기울기가 0이라는 것은 그 지점이 이 함수의 바닥(최소)이라는 신호다.

### 6) 헷갈리는 점

- 기울기의 부호가 방향을, 크기가 가파름을 나타낸다. 부호만 보면 어디로 가야 할지 알 수 있다.
- 연쇄법칙에서 곱해야 할 기울기를 하나라도 빠뜨리면 전체 미분이 틀어진다.

### 7) 한 줄 정리

> 미분은 "지금의 기울기"를 알려 주는 나침반이고, 연쇄법칙은 겹친 함수의 기울기를 곱으로 이어 붙이는 규칙이다.

## 2. 테일러 급수 (1차 근사)

### 1) 정의

테일러 급수는 복잡한 함수를 어떤 점 근처에서 다항식으로 근사하는 방법이다. 가장 단순한 1차 근사는 그 점의 접선으로 함수를 대신 보는 것이다.

### 2) 왜 필요한가

복잡한 함수를 그대로 다루기는 어렵다. 관심 있는 지점 근처에서만 접선(직선)으로 바꿔 보면 계산이 훨씬 쉬워진다. 경사하강법이 "지금 위치의 기울기"만으로 다음 걸음을 정하는 것도 이 1차 근사 아이디어에 기반한다.

### 3) 핵심 흐름 재구성

```
f(x + Δ) ≈ f(x) + f'(x) × Δ
```

"현재 값 + 기울기 × 이동량"으로 근처 값을 추정한다는 뜻이다. 이동량 Δ가 작을수록 근사가 정확하다.

### 4) 쉬운 예시

지금 위치의 높이와 경사만 알면, 한 걸음 앞의 높이를 "현재 높이 + 경사 × 걸음 크기"로 어림할 수 있다. 걸음이 작을수록 이 어림이 잘 맞는다.

### 5) 코드 예시

```python
def f(x):
    return (x - 3) ** 2 + 1

x, delta = 1.0, 0.1
slope = 2 * (x - 3)                 # f'(x)
approx = f(x) + slope * delta       # 1차 근사
print(round(approx, 4), round(f(x + delta), 4))  # 근사값 vs 실제값
```

### 6) 헷갈리는 점

- 1차 근사는 가까운 곳에서만 잘 맞는다. 멀리 갈수록 오차가 커진다.
- 근사가 부정확해지는 정도는 함수의 휘어짐(2차 미분)과 관련이 있다.

### 7) 한 줄 정리

> 테일러 1차 근사는 "복잡한 곡선을 지금 지점의 접선으로 잠깐 대신 보는" 방법이다.

## 3. 경사하강법과 학습률

### 1) 정의

경사하강법은 현재 위치의 기울기를 구해, 그 **반대 방향**으로 조금씩 이동하며 손실을 줄여 가는 방법이다. 학습률(learning rate)은 한 걸음의 보폭이다.

### 2) 왜 필요한가

손실을 최소로 만드는 값을 한 번에 계산하기 어려운 경우가 많다. 대신 지금 위치에서 "손실이 줄어드는 방향"으로 반복해서 조금씩 움직이면 점점 바닥에 가까워진다. 이것이 대부분의 머신러닝 모델이 학습하는 방식이다.

### 3) 핵심 흐름 재구성

```
새 위치 = 현재 위치 − 학습률 × (현재 위치의 기울기)
```

기울기가 양수면 왼쪽으로, 음수면 오른쪽으로 움직여 바닥을 향한다. 이 갱신을 여러 번 반복한다.

### 4) 쉬운 예시 (학습률의 효과)

함수의 바닥이 x=3에 있는 예시에서, x=0부터 시작해 학습률만 바꿔 보면 결과가 크게 달라진다.

```
학습률 0.10 : 0.000 → 0.600 → 1.080 → 1.464 → 1.771 → 2.017 → ...  (천천히 수렴)
학습률 0.50 : 0.000 → 3.000 → 3.000 → ...                          (한 번에 도달)
학습률 0.90 : 0.000 → 5.400 → 1.080 → 4.536 → 1.771 → ...          (좌우로 튐)
학습률 1.05 : 0.000 → 6.300 → -0.630 → 6.993 → -1.392 → ...        (점점 발산)
```

학습률이 작으면 안전하지만 느리고, 적당하면 빠르게 수렴하며, 너무 크면 바닥을 지나쳐 오히려 멀어진다.

### 5) 코드 예시

```python
def df(x):
    return 2 * (x - 3)      # f(x)=(x-3)^2+1 의 도함수

def gradient_descent(start, lr, steps):
    x = start
    for _ in range(steps):
        x = x - lr * df(x)   # 기울기 반대로 이동
    return x

print(round(gradient_descent(0.0, 0.1, 50), 3))   # 약 3.0 으로 수렴
```

### 6) 헷갈리는 점

- 기울기의 "반대" 방향으로 가야 손실이 줄어든다. 부호를 빼먹으면 반대로 올라간다.
- 학습률은 문제마다 적절한 값이 다르다. 발산하면 줄이고, 너무 느리면 조금 키운다.

### 7) 한 줄 정리

> 경사하강법은 "기울기 반대로 한 걸음씩" 반복해 바닥을 찾는 방법이고, 학습률은 그 걸음의 크기다.

## 4. 임계점과 2차 미분

### 1) 정의

임계점은 기울기(1차 미분)가 0인 지점이다. 2차 미분은 기울기의 변화율, 즉 곡선이 얼마나 휘었는지를 나타낸다.

### 2) 왜 필요한가

경사하강법은 기울기가 0인 곳에서 멈춘다. 하지만 기울기가 0이라고 해서 모두 "최소"는 아니다. 최소인지 최대인지, 혹은 잠깐 평평한 곳인지 구분하려면 2차 미분이 필요하다.

### 3) 핵심 흐름 재구성

```
1차 미분 = 0            → 임계점(멈추는 후보)
2차 미분 > 0            → 아래로 볼록 → 최소 후보
2차 미분 < 0            → 위로 볼록 → 최대 후보
```

또 국소 최소(주변에서만 가장 낮음)와 전역 최소(전체에서 가장 낮음)를 구분해야 한다. 경사하강법은 국소 최소에 갇힐 수 있다.

### 4) 쉬운 예시

계곡의 바닥(임계점)은 여러 개일 수 있다. 그중 가장 깊은 곳이 전역 최소이고, 얕은 웅덩이는 국소 최소다. 눈을 감고 내려가다 보면 얕은 웅덩이에서 멈춰 버릴 수 있다.

### 5) 코드 예시

```python
# f(x)=(x-3)^2+1 의 임계점 확인
def df(x):  return 2 * (x - 3)   # 1차 미분
def ddf(x): return 2             # 2차 미분(상수 > 0)

x_star = 3
print(df(x_star), ddf(x_star))   # 0, 2 → 임계점이며 최소
```

### 6) 헷갈리는 점

- 기울기 0이 곧 최소는 아니다. 최대나 안장점일 수도 있다.
- 평균값 정리는 "두 점을 잇는 평균 기울기와 같은 순간 기울기를 갖는 점이 그 사이에 존재한다"는 성질로, 미분 개념을 뒷받침하는 정리다.

### 7) 한 줄 정리

> 임계점은 "기울기가 0인 멈춤 후보"이고, 2차 미분은 그곳이 최소인지 최대인지 판정하는 도구다.

## 코드로 보기 — 학습률에 따른 수렴/발산 비교

```python
def df(x):
    return 2 * (x - 3)

def path(start, lr, steps):
    x = start
    history = [x]
    for _ in range(steps):
        x = x - lr * df(x)
        history.append(round(x, 3))
    return history

for lr in [0.1, 0.5, 0.9, 1.05]:
    print(f"lr={lr}: {path(0.0, lr, 5)}")
```

### 코드 목적

같은 시작점에서 학습률만 바꿔, 경사하강법이 수렴하는지 튀는지 발산하는지를 직접 눈으로 비교하기 위한 코드다.

### 코드 흐름

1. 손실 함수의 도함수를 정의한다.
2. 시작점에서 "기울기 반대로 이동"을 반복하며 위치를 기록한다.
3. 여러 학습률로 경로를 각각 출력한다.

### 실행 결과 해석

작은 학습률은 바닥(x=3)을 향해 천천히 다가가고, 적당한 학습률은 빠르게 도달한다. 큰 학습률은 바닥을 지나쳐 좌우로 튀고, 임계값을 넘으면 값이 점점 커지며 발산한다. "학습률을 잘못 잡으면 학습이 아예 실패할 수 있다"는 점을 직관적으로 보여 준다.

### 실무 연결

딥러닝 학습에서 학습률은 가장 먼저 조정하는 값 중 하나다. 손실이 줄지 않고 튀면 학습률을 낮추고, 너무 느리면 조금 키운다. 학습률을 점점 줄여 가는 스케줄링 기법도 널리 쓰인다.

## 헷갈리기 쉬운 포인트

| 헷갈리는 개념 | 차이 |
|---|---|
| 1차 미분 vs 2차 미분 | 기울기(어디로)를 보는 것이 1차, 휘어짐(최소/최대)을 보는 것이 2차 |
| 학습률 큼 vs 작음 | 크면 빠르지만 발산 위험, 작으면 안전하지만 느림 |
| 국소 최소 vs 전역 최소 | 주변에서만 최저면 국소, 전체에서 최저면 전역 |
| 임계점 vs 최소점 | 기울기 0은 임계점, 그중 실제로 가장 낮은 곳이 최소점 |
