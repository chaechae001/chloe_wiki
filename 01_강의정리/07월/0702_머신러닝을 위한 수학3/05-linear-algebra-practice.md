# 선형대수 핵심 연산 실습 — 내적·랭크·고유값·SVD

> 데이터는 대부분 행렬로 표현됩니다. 내적으로 유사도를 재고, 랭크로 정보량을 보고, 고유값과 SVD로 중요한 방향을 찾아내는 것이 데이터 분석의 기본기입니다.

`내적` · `랭크` · `고유값` · `SVD` · `차원축소`

## 핵심요약

- 벡터 내적은 두 벡터가 같은 방향을 향하는 정도(유사도)를 한 숫자로 요약한다.
- 랭크는 행렬이 담은 "독립적인 정보의 개수"다.
- 고유값·고유벡터는 변환해도 방향이 유지되는 축과 그 크기 배율이다.
- SVD는 임의의 행렬을 세 조각으로 분해해 중요한 방향을 크기 순으로 드러낸다.
- 이 연산들은 추천, 차원 축소, 유사도 계산의 밑바탕이 된다.

## 1. 벡터 내적

### 1) 정의

내적은 두 벡터의 같은 위치 성분끼리 곱해 모두 더한 값이다. 결과는 하나의 숫자이며, 두 벡터가 얼마나 같은 방향을 향하는지를 나타낸다.

### 2) 왜 필요한가

"두 대상이 얼마나 비슷한가"를 수치로 재야 할 때가 많다. 문서 유사도, 사용자 취향 유사도, 추천 점수 계산이 모두 내적에서 출발한다.

### 3) 핵심 흐름 재구성

```
a·b = a₁×b₁ + a₂×b₂ + ... + aₙ×bₙ
```

내적이 크면 두 벡터가 비슷한 방향, 0이면 직교(서로 무관), 음수면 반대 방향에 가깝다.

### 4) 쉬운 예시

두 벡터 a=(2,1,−1), b=(1,3,0)의 내적은 다음과 같다.

```
a·b = 2×1 + 1×3 + (−1)×0 = 2 + 3 + 0 = 5
```

값이 양수이므로 두 벡터는 대체로 같은 방향을 향한다고 볼 수 있다.

### 5) 코드 예시

```python
import numpy as np

a = np.array([2, 1, -1])
b = np.array([1, 3, 0])
print(a @ b)          # 내적: 5
print(np.dot(a, b))   # 같은 결과
```

### 6) 헷갈리는 점

- 내적(`@`)은 하나의 숫자를, 성분별 곱(`*`)은 같은 크기의 벡터를 만든다. 둘은 완전히 다르다.
- 내적이 0이면 "직교"이며, 이는 두 방향이 서로 독립적임을 뜻한다.

### 7) 한 줄 정리

> 내적은 두 벡터의 "방향이 얼마나 겹치는가"를 하나의 숫자로 요약한 유사도다.

## 2. 랭크와 해의 존재

### 1) 정의

랭크는 행렬에서 서로 독립인 행(또는 열)의 최대 개수다. 다시 말해 그 행렬이 담고 있는 "중복되지 않는 정보의 양"이다.

### 2) 왜 필요한가

랭크는 선형 방정식의 해가 유일한지, 무수히 많은지, 아예 없는지를 판별하는 열쇠다. 데이터 관점에서는 특성들 사이에 중복(선형 종속)이 있는지도 알려 준다.

### 3) 핵심 흐름 재구성

```
풀랭크(행/열 수만큼 독립)  → 역행렬 존재 → 해가 유일
랭크 부족(독립 정보 부족)  → 역행렬 없음 → 해가 무수히 많거나 없음
```

랭크가 부족하다는 것은 "새로 보이는 정보가 실은 기존 정보의 조합"이라는 뜻이다.

### 4) 쉬운 예시

세 개의 행이 있지만 한 행이 다른 행의 2배라면, 실제로 독립인 정보는 두 개뿐이다.

```
행1 = (1, 2, 3)
행2 = (2, 4, 6)   ← 행1의 2배 (중복 정보)
행3 = (0, 1, 1)
→ 독립 정보 2개이므로 랭크 = 2
```

### 5) 코드 예시

```python
import numpy as np

M = np.array([[1, 2, 3],
              [2, 4, 6],   # 첫 행의 2배
              [0, 1, 1]])
print(np.linalg.matrix_rank(M))   # 2
```

### 6) 헷갈리는 점

- 행렬의 크기(행·열 수)와 랭크는 다르다. 3×3 행렬이라도 랭크는 2일 수 있다.
- 랭크가 부족하면 역행렬이 없으므로, 유일한 해를 기대할 수 없다.

### 7) 한 줄 정리

> 랭크는 행렬이 담은 "진짜 독립 정보의 개수"이며, 해의 종류를 판별하는 기준이다.

## 3. 고유값과 고유벡터

### 1) 정의

행렬로 벡터를 변환할 때, 방향은 그대로이고 길이만 상수배로 바뀌는 특별한 벡터가 고유벡터다. 그 배율이 고유값이다.

### 2) 왜 필요한가

고유벡터는 "이 변환에서 변하지 않는 축"을 알려 준다. 데이터에서 가장 중요한 방향을 찾는 주성분 분석(PCA)이 바로 이 개념을 사용한다.

### 3) 핵심 흐름 재구성

```
A · v = λ · v
```

여기서 v가 고유벡터, λ(람다)가 고유값이다. "행렬 A로 변환해도 v의 방향은 유지되고 크기만 λ배가 된다"는 뜻이다.

### 4) 쉬운 예시

대각행렬처럼 축을 그대로 늘리는 변환에서는 축 방향 벡터가 그대로 고유벡터가 된다.

```
A = [[2, 0],
     [0, 3]]
→ x축 방향은 2배, y축 방향은 3배 → 고유값 2, 3
```

### 5) 코드 예시

```python
import numpy as np

A = np.array([[2, 0],
              [0, 3]])
values, vectors = np.linalg.eig(A)
print(values)    # [2. 3.]
```

### 6) 헷갈리는 점

- 고유값은 "얼마나 늘어나는지", 고유벡터는 "어느 방향이 유지되는지"를 나타낸다. 역할이 다르다.
- 고유값 분해는 정사각행렬에만 적용된다.

### 7) 한 줄 정리

> 고유벡터는 "변환해도 방향이 유지되는 축", 고유값은 "그 축이 늘어나는 배율"이다.

## 4. 특이값 분해(SVD)

### 1) 정의

SVD는 임의의 행렬(정사각이 아니어도 됨)을 세 행렬의 곱으로 분해하는 방법이다. 각 방향의 중요도를 특이값으로 크기 순으로 정렬해 준다.

### 2) 왜 필요한가

고유값 분해는 정사각행렬만 다루지만, 실제 데이터는 사용자×아이템, 문서×단어처럼 직사각형인 경우가 대부분이다. SVD는 이런 직사각 행렬에도 적용돼 차원 축소와 추천 시스템의 핵심 도구가 된다.

### 3) 핵심 흐름 재구성

```
A = U Σ Vᵀ
```

- Σ(시그마)의 대각에 놓인 값들이 특이값이며, 각 방향의 중요도(세기)를 나타낸다.
- 특이값이 큰 방향 몇 개만 남기면, 정보 손실을 최소화하며 차원을 줄일 수 있다.

### 4) 쉬운 예시

특이값이 [1.732, 1.0]처럼 나오면, 첫 번째 방향이 두 번째보다 더 큰 정보를 담고 있다는 뜻이다. 덜 중요한 방향을 버리면 데이터를 더 적은 차원으로 요약할 수 있다.

### 5) 코드 예시

```python
import numpy as np

A = np.array([[1, 0, 1],
              [0, 1, 1]])
U, S, Vt = np.linalg.svd(A)
print(np.round(S, 3))   # 특이값(중요도 순): [1.732 1.   ]
```

### 6) 헷갈리는 점

- 고유값 분해는 정사각행렬 전용, SVD는 임의 행렬에 적용된다. 적용 범위가 다르다.
- 특이값은 항상 0 이상이며 큰 순서로 정렬돼 나온다. 앞쪽 몇 개가 대부분의 정보를 담는다.

### 7) 한 줄 정리

> SVD는 임의의 행렬을 "중요한 방향과 그 세기"로 분해해, 차원 축소와 추천의 바탕을 만든다.

## 코드로 보기 — 네 가지 핵심 연산 한눈에

```python
import numpy as np

# 1) 내적: 유사도
a = np.array([2, 1, -1]); b = np.array([1, 3, 0])
print("dot :", a @ b)

# 2) 랭크: 독립 정보 개수
M = np.array([[1, 2, 3], [2, 4, 6], [0, 1, 1]])
print("rank:", np.linalg.matrix_rank(M))

# 3) 고유값: 유지되는 축의 배율
A = np.array([[2, 0], [0, 3]])
print("eig :", np.linalg.eig(A)[0])

# 4) SVD: 중요한 방향의 세기
B = np.array([[1, 0, 1], [0, 1, 1]])
print("svd :", np.round(np.linalg.svd(B)[1], 3))
```

### 코드 목적

내적·랭크·고유값·SVD를 각각 NumPy 함수로 계산해, 어떤 상황에 어떤 함수를 쓰는지 한눈에 정리하기 위한 코드다.

### 코드 흐름

1. 두 벡터의 내적으로 유사도를 구한다.
2. 행렬의 랭크로 독립 정보 개수를 확인한다.
3. 정사각행렬의 고유값으로 유지되는 축의 배율을 본다.
4. 직사각행렬에 SVD를 적용해 방향별 중요도를 얻는다.

### 실행 결과 해석

```
dot : 5          → 두 벡터가 대체로 같은 방향(양수)
rank: 2          → 3행이지만 독립 정보는 2개(한 행이 중복)
eig : [2. 3.]    → x축 2배, y축 3배로 늘어나는 변환
svd : [1.732 1.] → 첫 방향이 둘째보다 더 큰 정보를 담음
```

각 결과는 "유사도, 정보량, 유지되는 축, 중요한 방향"이라는 서로 다른 질문에 답한다.

### 실무 연결

내적은 추천·검색의 유사도 계산에, 랭크는 다중공선성 진단에, 고유값·SVD는 PCA 같은 차원 축소와 추천 시스템의 잠재 요인 분석에 쓰인다. 데이터가 커질수록 "중요한 방향만 남기는" 이 도구들의 가치가 커진다.

## 헷갈리기 쉬운 포인트

| 헷갈리는 개념 | 차이 |
|---|---|
| 내적 `@` vs 성분별 곱 `*` | 하나의 숫자를 만들면 내적, 같은 크기 벡터를 만들면 성분별 곱 |
| 행렬 크기 vs 랭크 | 행·열의 개수가 크기, 그중 독립 정보 개수가 랭크 |
| 고유값 vs 고유벡터 | 늘어나는 배율이 고유값, 유지되는 방향이 고유벡터 |
| 고유값 분해 vs SVD | 정사각행렬 전용이 고유값 분해, 임의 행렬 가능이 SVD |
