# 조건부 확률과 베이즈 정리 — 결과로 원인을 거꾸로 추론하기

> "증거를 봤을 때 원인은 무엇일까?"를 다루는 것이 조건부 확률과 베이즈 정리입니다. 머신러닝이 데이터를 보고 판단을 갱신하는 방식의 밑바탕이 됩니다.

`조건부확률` · `베이즈정리` · `사전확률` · `사후확률` · `정규분포`

## 핵심요약

- 조건부 확률은 "어떤 사실을 이미 알 때"의 확률이다.
- 베이즈 정리는 결과(증거)를 보고 원인의 확률을 거꾸로 갱신하는 공식이다.
- 사전확률(믿음)은 증거를 반영해 사후확률로 바뀐다.
- 증거가 여러 개면 사후확률을 계속 이어서 갱신할 수 있다.
- 정규분포와 조건부 독립은 확률 기반 모델의 자주 쓰이는 재료다.

## 1. 조건부 확률

### 1) 정의

조건부 확률은 "사건 B가 일어났다는 사실을 알 때, 사건 A가 일어날 확률"이다. 기호로는 P(A|B)로 쓴다.

### 2) 왜 필요한가

현실의 판단은 대개 "아무 정보도 없는 상태"가 아니라 "일부 정보를 아는 상태"에서 이뤄진다. 어떤 단서를 알았을 때 결론이 어떻게 바뀌는지를 다루려면 조건부 확률이 필요하다.

### 3) 핵심 흐름 재구성

조건부 확률은 다음과 같이 정의된다.

```
P(A|B) = P(A 그리고 B) ÷ P(B)
```

"B라는 세계 안에서 A가 차지하는 비율"로 이해하면 쉽다. 전체가 아니라 "B가 일어난 경우들"로 분모가 좁아진다는 점이 핵심이다.

### 4) 쉬운 예시

한 반에 학생이 40명이고 그중 안경 쓴 학생이 14명, 안경 쓴 학생 중 앞자리에 앉은 학생이 6명이라고 하자. "안경 쓴 학생일 때 앞자리일 확률"은 전체 40명이 아니라 안경 쓴 14명을 분모로 본다.

```
P(앞자리 | 안경) = 6 ÷ 14 ≈ 0.429
```

### 5) 코드 예시

```python
# 표본에서 조건부 확률을 세어 보는 최소 예제
glasses = 14      # B: 안경 쓴 학생 수
glasses_and_front = 6   # A 그리고 B
print(glasses_and_front / glasses)   # P(앞자리 | 안경)
```

### 6) 헷갈리는 점

- P(A|B)와 P(B|A)는 다르다. "안경일 때 앞자리 확률"과 "앞자리일 때 안경 확률"은 분모가 다르므로 값도 다르다.
- 조건이 붙으면 분모가 전체가 아니라 "조건이 성립한 경우"로 바뀐다.

### 7) 한 줄 정리

> 조건부 확률은 "이미 아는 사실"로 세계를 좁힌 뒤, 그 안에서 다시 계산한 확률이다.

## 2. 베이즈 정리

### 1) 정의

베이즈 정리는 조건부 확률의 방향을 뒤집는 공식이다. "원인 → 결과"의 확률을 알 때 "결과 → 원인"의 확률을 구하게 해 준다.

### 2) 왜 필요한가

우리가 관찰하는 것은 대개 결과(증거)이고, 알고 싶은 것은 원인이다. "이 증상이 있을 때 실제 병일 확률", "이 단어가 있을 때 스팸일 확률"처럼, 관찰된 증거로 숨은 원인을 추론하려면 베이즈 정리가 필요하다.

### 3) 핵심 흐름 재구성

```
                P(증거|원인) × P(원인)
P(원인|증거) = ─────────────────────────
                       P(증거)

P(증거) = P(증거|원인)×P(원인) + P(증거|원인아님)×P(원인아님)
```

- P(원인): 사전확률 — 증거를 보기 전의 믿음
- P(증거|원인): 우도 — 원인이 있을 때 이 증거가 나올 가능성
- P(원인|증거): 사후확률 — 증거를 반영해 갱신된 믿음

### 4) 쉬운 예시 (설명용 가상 수치)

아래 숫자는 개념을 보여 주기 위해 임의로 정한 예시이며, 실제 의료 데이터가 아니다.

어떤 병의 유병률이 2%라고 하자. 검사는 실제 환자를 95% 잡아내지만(민감도), 건강한 사람도 8%를 양성으로 잘못 표시한다(위양성). 검사가 양성일 때 실제 병일 확률은?

```
분자 = 0.95 × 0.02 = 0.019
분모 = 0.95 × 0.02 + 0.08 × 0.98 ≈ 0.0974
P(병 | 양성) ≈ 0.019 ÷ 0.0974 ≈ 0.195
```

양성이어도 실제 병일 확률은 약 20%에 불과하다. 병 자체가 드물기 때문에, 위양성의 절대 수가 진짜 환자보다 많아지는 것이다. 이는 "드문 사건에서는 검사 하나만으로 단정하기 어렵다"는 직관을 수치로 보여 준다.

### 5) 코드 예시

```python
prev = 0.02      # 사전확률: 유병률
sens = 0.95      # P(양성 | 병)
fpr  = 0.08      # P(양성 | 정상)

post = sens * prev / (sens * prev + fpr * (1 - prev))
print(round(post, 3))   # 약 0.195
```

### 6) 헷갈리는 점

- 민감도(P(양성|병))와 사후확률(P(병|양성))은 전혀 다른 값이다. 이 둘을 혼동하면 위양성을 과소평가한다.
- 사전확률(유병률)이 작을수록 같은 검사라도 사후확률이 낮아진다.

### 7) 한 줄 정리

> 베이즈 정리는 "원인일 때 증거가 나올 확률"을 "증거를 봤을 때 원인일 확률"로 뒤집는 도구다.

## 3. 사후확률의 순차 갱신

### 1) 정의

증거가 여러 개일 때, 한 증거로 얻은 사후확률을 다음 증거의 사전확률로 삼아 계속 갱신하는 방식이다.

### 2) 왜 필요한가

정보는 대개 한 번에 오지 않고 조금씩 쌓인다. 새 증거가 들어올 때마다 처음부터 다시 계산하지 않고, 지금까지의 믿음에 증거를 이어 붙이면 효율적으로 판단을 갱신할 수 있다.

### 3) 핵심 흐름 재구성

각 단계에서 "이전 사후확률 → 이번 증거로 갱신 → 새 사후확률"을 반복한다. 스팸 필터가 의심 단어를 하나씩 볼 때마다 스팸 확률을 높여 가는 과정이 이 방식이다.

### 4) 쉬운 예시

사전확률(스팸일 확률)을 30%로 두고, 의심 단어를 하나씩 관측하며 갱신한다고 하자. 각 단어의 우도(스팸일 때 등장 확률, 정상일 때 등장 확률)를 반영하면 다음처럼 변한다.

```
시작            P(스팸) = 0.300
'무료' 관측 후   P(스팸) ≈ 0.720
'당첨' 관측 후   P(스팸) ≈ 0.963
'클릭' 관측 후   P(스팸) ≈ 0.981
'지금' 관측 후   P(스팸) ≈ 0.987
```

증거가 쌓일수록 믿음이 한 방향으로 수렴하는 것을 볼 수 있다.

### 5) 코드 예시

```python
p = 0.30   # 사전확률
# (스팸일 때 등장확률, 정상일 때 등장확률)
words = [(0.6, 0.1), (0.5, 0.05), (0.4, 0.2), (0.45, 0.3)]

for like_spam, like_ham in words:
    p = (like_spam * p) / (like_spam * p + like_ham * (1 - p))
    print(round(p, 3))
```

### 6) 헷갈리는 점

- 순차 갱신은 증거들이 조건부로 독립이라고 가정할 때 깔끔하게 이어 붙는다. 실제로는 이 가정이 완벽하지 않을 수 있다.
- 한 번 강한 증거가 들어오면 확률이 크게 움직이므로, 초반 증거의 신뢰도가 중요하다.

### 7) 한 줄 정리

> 순차 갱신은 "지금까지의 믿음"을 다음 계산의 출발점으로 삼아 증거를 이어 반영하는 방법이다.

## 4. 정규분포와 조건부 독립

### 1) 정의

정규분포는 평균을 중심으로 좌우 대칭인 종 모양 분포로, 평균과 표준편차 두 값으로 모양이 정해진다. 조건부 독립은 "어떤 조건 Z를 알면 X와 Y가 서로 무관해지는" 성질이다.

### 2) 왜 필요한가

정규분포는 수많은 자연·사회 현상의 근사 모델이자 통계·머신러닝의 기본 가정으로 자주 등장한다. 조건부 독립은 확률 모델을 단순하게 계산할 수 있게 해 주는 핵심 가정이다(예: 나이브 베이즈).

### 3) 핵심 흐름 재구성

정규분포에서는 평균에서 표준편차 1칸 안에 약 68%, 2칸 안에 약 95%의 데이터가 들어온다. 조건부 독립은 다음 등식으로 표현된다.

```
P(X, Y | Z) = P(X | Z) × P(Y | Z)
```

즉 Z를 알고 나면 X와 Y를 따로따로 곱해도 된다는 뜻이다.

### 4) 쉬운 예시

정규분포: 평균 2, 표준편차 1인 분포에서 표본을 많이 뽑으면 평균은 2, 약 68%가 1과 3 사이에 모인다.

조건부 독립: 날씨(Z)를 알면, 우산 판매(X)와 아이스크림 판매 감소(Y)가 서로를 직접 일으키지 않아도 함께 움직이는 것처럼 보인다. 하지만 "비가 온다"는 조건을 알고 나면 둘의 겉보기 연관은 상당 부분 사라진다.

### 5) 코드 예시

```python
import numpy as np

rng = np.random.default_rng(0)
sample = rng.normal(2, 1, 10000)   # 평균 2, 표준편차 1
print(round(sample.mean(), 3))     # 약 2.0
print(round(sample.std(), 3))      # 약 1.0
print(round(np.mean(np.abs(sample - 2) < 1), 3))  # 1칸 이내 비율 ≈ 0.68
```

### 6) 헷갈리는 점

- "무관해 보인다"와 "조건부 독립이다"는 다르다. 공통 원인(Z)을 넣어야 비로소 독립이 드러나는 경우가 많다.
- 정규분포 가정이 항상 맞는 것은 아니다. 데이터가 한쪽으로 치우치면 다른 분포를 고려해야 한다.

### 7) 한 줄 정리

> 정규분포는 "종 모양의 표준 재료", 조건부 독립은 "공통 원인을 알면 나눠서 곱해도 되는 성질"이다.

## 코드로 보기 — 조건부 독립을 시뮬레이션으로 확인

```python
import numpy as np

rng = np.random.default_rng(1)
N = 2_000_000

z = rng.integers(0, 2, N)                                  # 공통 원인
x = (rng.random(N) < np.where(z == 1, 0.8, 0.2)).astype(int)
y = (rng.random(N) < np.where(z == 1, 0.7, 0.3)).astype(int)

mask = z == 1
joint = np.mean((x[mask] == 1) & (y[mask] == 1))          # P(x=1,y=1 | z=1)
prod  = np.mean(x[mask] == 1) * np.mean(y[mask] == 1)     # P(x=1|z=1)P(y=1|z=1)
print(round(joint, 3), round(prod, 3))
```

### 코드 목적

Z를 고정했을 때 X와 Y가 정말로 조건부 독립인지, 즉 "결합확률 = 곱"이 성립하는지를 대규모 시뮬레이션으로 확인한다.

### 코드 흐름

1. 공통 원인 Z를 무작위로 만든다.
2. Z 값에 따라 X, Y가 나올 확률을 다르게 설정해 생성한다.
3. Z=1인 경우만 골라 결합확률과 곱을 각각 계산한다.
4. 두 값이 거의 같은지 비교한다.

### 실행 결과 해석

두 값 모두 약 0.560으로 거의 일치한다. 이는 Z를 알고 나면 X와 Y가 조건부 독립임을 수치로 확인해 준다. 표본이 매우 크기 때문에 이론값에 가깝게 수렴한다.

### 실무 연결

나이브 베이즈 분류기는 "특성들이 조건부 독립"이라는 가정을 이용해 계산을 단순화한다. 스팸 필터, 문서 분류에서 이 가정이 실용적으로 잘 작동하는 경우가 많다.

## 헷갈리기 쉬운 포인트

| 헷갈리는 개념 | 차이 |
|---|---|
| P(A\|B) vs P(B\|A) | 조건과 결론을 뒤바꾼 값으로, 분모가 달라 값도 다름 |
| 사전확률 vs 사후확률 | 증거 반영 전 믿음이 사전, 반영 후 갱신된 믿음이 사후 |
| 민감도 vs 사후확률 | "병일 때 양성 확률"과 "양성일 때 병 확률"은 별개 |
| 독립 vs 조건부 독립 | 그냥 무관한 것과 "조건을 알면 무관해지는 것"은 다름 |

사전확률은 증거를 보기 전의 출발 믿음이다. 같은 검사 결과라도 사전확률(예: 유병률)이 낮으면 사후확률도 낮게 나온다. 즉 최종 판단은 증거의 강도뿐 아니라 출발 믿음에도 크게 좌우된다.

</details>

**Q2. 드문 병에서 양성 결과의 사후확률이 낮게 나오는 이유는?**

<details>
<summary>답</summary>

병이 드물면 건강한 사람의 수가 압도적으로 많아, 위양성으로 생기는 양성의 절대 수가 진짜 환자보다 많아질 수 있다. 그래서 양성 중 실제 환자의 비율(사후확률)이 낮아진다.

</details>

**Q3. 조건부 독립 가정은 실무에서 왜 유용한가?**

<details>
<summary>답</summary>

여러 특성의 결합확률을 각 특성의 조건부 확률의 곱으로 단순화할 수 있어 계산이 훨씬 가벼워진다. 가정이 완벽하지 않아도 나이브 베이즈처럼 실용적으로 잘 작동하는 경우가 많다.

</details>

## 한 줄 정리

> 조건부 확률과 베이즈 정리는 "관찰된 증거로 숨은 원인의 믿음을 갱신하는" 사고 틀이며, 확률 기반 머신러닝의 출발점이다.
