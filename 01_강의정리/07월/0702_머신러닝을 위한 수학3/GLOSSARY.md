# 용어집

이번 강의에서 등장한 핵심 용어를 쉬운 말로 정리했습니다. 주제별로 나눠 필요한 부분을 빠르게 찾아볼 수 있습니다.

## 머신러닝 실습 (회귀·분류)

| 용어 | 쉬운 설명 | 관련 글 | 함께 보면 좋은 개념 |
| ---- | --------- | ------- | ------------------- |
| 회귀(Regression) | 팁·가격처럼 연속적인 숫자 값을 예측하는 문제 | 머신러닝 회귀 실습 | 분류, 지도학습 |
| 분류(Classification) | 생존/사망처럼 정해진 범주를 예측하는 문제 | 머신러닝 분류 실습 | 회귀, 평가지표 |
| 지도학습 | 입력과 정답을 함께 주고 규칙을 배우게 하는 방식 | 머신러닝 회귀 실습 | 회귀, 분류 |
| Pipeline | 전처리와 모델을 하나로 묶어 자동 실행하는 구조 | 머신러닝 회귀 실습 | StandardScaler, 데이터 누출 |
| StandardScaler | 특성의 크기를 평균 0, 표준편차 1 근처로 맞추는 표준화 | 머신러닝 회귀 실습 | 전처리, Pipeline |
| train_test_split | 데이터를 학습용과 평가용으로 나누는 도구 | 머신러닝 회귀 실습 | 과적합, 평가 |
| MAE / MSE | 예측과 실제의 오차 평균(절댓값/제곱). 낮을수록 좋음 | 머신러닝 회귀 실습 | R², 회귀 평가 |
| R²(결정계수) | 모델이 데이터 변동을 설명하는 비율. 높을수록 좋음 | 머신러닝 회귀 실습 | MAE, 설명력 |
| 정확도(Accuracy) | 전체 예측 중 맞은 비율 | 머신러닝 분류 실습 | 혼동행렬, 클래스 불균형 |
| 정밀도(Precision) | 양성이라 예측한 것 중 실제 양성 비율 | 머신러닝 분류 실습 | 재현율, F1 |
| 재현율(Recall) | 실제 양성 중 모델이 맞힌 비율 | 머신러닝 분류 실습 | 정밀도, F1 |
| F1 score | 정밀도와 재현율의 조화 평균(균형 지표) | 머신러닝 분류 실습 | 정밀도, 재현율 |
| 혼동행렬 | 예측과 실제를 교차해 실수 종류를 보여 주는 표 | 머신러닝 분류 실습 | 정밀도, 재현율 |

## 확률

| 용어 | 쉬운 설명 | 관련 글 | 함께 보면 좋은 개념 |
| ---- | --------- | ------- | ------------------- |
| 조건부 확률 | 어떤 사실을 이미 알 때의 확률 P(A\|B) | 조건부 확률과 베이즈 정리 | 베이즈 정리 |
| 베이즈 정리 | 증거를 보고 원인의 확률을 거꾸로 갱신하는 공식 | 조건부 확률과 베이즈 정리 | 사전확률, 사후확률 |
| 사전확률(Prior) | 증거를 보기 전에 갖고 있던 믿음 | 조건부 확률과 베이즈 정리 | 사후확률, 우도 |
| 사후확률(Posterior) | 증거를 반영해 갱신된 믿음 | 조건부 확률과 베이즈 정리 | 사전확률, 순차 갱신 |
| 우도(Likelihood) | 원인이 있을 때 이 증거가 나올 확률 | 조건부 확률과 베이즈 정리 | 베이즈 정리 |
| 위양성 | 실제로는 아닌데 양성으로 나오는 오탐 | 조건부 확률과 베이즈 정리 | 사후확률, 유병률 |
| 정규분포 | 평균과 표준편차로 모양이 정해지는 종 모양 분포 | 조건부 확률과 베이즈 정리 | 표준편차, 68-95 규칙 |
| 조건부 독립 | 조건을 알면 두 변수가 서로 무관해지는 성질 | 조건부 확률과 베이즈 정리 | 나이브 베이즈, 결합확률 |

## 미분·최적화

| 용어 | 쉬운 설명 | 관련 글 | 함께 보면 좋은 개념 |
| ---- | --------- | ------- | ------------------- |
| 미분(도함수) | 한 점에서의 순간 변화율 = 접선의 기울기 | 미분과 경사하강법 | 연쇄법칙, 기울기 |
| 연쇄법칙 | 겹친 함수의 미분을 단계별 기울기의 곱으로 계산 | 미분과 경사하강법 | 역전파, 합성함수 |
| 테일러 근사 | 함수를 한 점 근처에서 접선(다항식)으로 근사 | 미분과 경사하강법 | 1차 근사, 접선 |
| 경사하강법 | 기울기 반대 방향으로 조금씩 이동해 손실을 줄이는 방법 | 미분과 경사하강법 | 학습률, 임계점 |
| 학습률(Learning Rate) | 한 걸음의 보폭. 크면 발산, 작으면 느림 | 미분과 경사하강법 | 경사하강법, 발산 |
| 임계점 | 기울기가 0인 지점(멈추는 후보) | 미분과 경사하강법 | 최소점, 2차 미분 |
| 국소/전역 최소 | 주변에서만 최저 vs 전체에서 최저인 지점 | 미분과 경사하강법 | 임계점, 손실 곡면 |
| 2차 미분 | 곡선의 휘어짐. 최소/최대 판정에 사용 | 미분과 경사하강법 | 임계점, 볼록성 |

## 선형대수

| 용어 | 쉬운 설명 | 관련 글 | 함께 보면 좋은 개념 |
| ---- | --------- | ------- | ------------------- |
| 벡터 내적 | 두 벡터가 같은 방향을 향하는 정도를 한 숫자로 요약 | 선형대수 핵심 연산 실습 | 코사인 유사도, 직교 |

| 특이값 | 각 방향의 중요도(세기)를 큰 순서로 나타낸 값 | 선형대수 핵심 연산 실습 | SVD, 차원축소 |
