# 클러스터링 타당성 — 정답이 없는데 잘 나눴는지 어떻게 알까

> 군집화는 정답 레이블 없이 그룹을 만듭니다. 그러면 "잘 나눴다"는 걸 무엇으로 증명할까요? 이 글은 응집도와 분리도라는 두 잣대로 군집 품질을 수치화하는 Silhouette 계수와 Dunn Index를 정리합니다.

`Silhouette` · `Dunn Index` · `응집도` · `분리도` · `타당성 지표`

## 핵심요약

- 정답이 없는 군집화는 "같은 그룹은 빽빽하게(응집도), 다른 그룹과는 멀게(분리도)"라는 기준으로 품질을 평가한다.
- Silhouette 계수는 각 점마다 $s = (b-a)/\max(a,b)$ 로 계산하며, 1에 가까울수록 잘 군집된 것이다.
- Dunn Index는 "가장 가까운 두 클러스터 사이 거리 ÷ 가장 퍼진 클러스터의 직경"으로, 클수록 좋다.
- 두 지표 모두 K를 바꿔 가며 계산해, 값이 가장 좋은 K를 최적 후보로 본다.
- 지표가 가리키는 K와 도메인 지식이 말하는 K가 다를 수 있으므로, 지표는 참고이고 최종 판단은 함께 봐야 한다.

## 1. Silhouette 계수 — 응집도와 분리도를 한 점씩

### 1) 정의

Silhouette(실루엣) 계수는 각 점 하나하나에 대해 "이 점이 지금 속한 그룹에 잘 어울리는가"를 −1에서 1 사이 숫자로 매기는 지표입니다. 같은 그룹 안에서는 가깝고(응집), 다른 그룹과는 멀수록(분리) 값이 1에 가까워집니다.

### 2) 왜 필요한가

지도학습이라면 정답과 비교해 정확도를 재면 됩니다. 하지만 군집화는 정답이 없으니 "얼마나 잘 나눴는지"를 데이터 스스로의 구조만으로 판단해야 합니다. Silhouette은 정답 없이도 군집 품질을 숫자로 뽑아 주기 때문에, 서로 다른 K끼리 어느 쪽이 더 나은지 객관적으로 비교할 수 있게 해 줍니다.

### 3) 핵심 흐름 재구성

각 점 $i$ 에 대해 두 거리를 잽니다.

$$
s(i) = \frac{b(i) - a(i)}{\max\big(a(i),\, b(i)\big)}
$$

- $a(i)$: 같은 클러스터 안 다른 점들과의 **평균 거리** — 작을수록 자기 그룹에 잘 뭉쳐 있음(응집도)
- $b(i)$: 가장 가까운 **다른** 클러스터까지의 평균 거리 — 클수록 이웃 그룹과 잘 떨어져 있음(분리도)

이 식은 "이웃 그룹까지 거리($b$)가 내 그룹 안 거리($a$)보다 얼마나 더 먼지를, 둘 중 큰 값으로 나눠 −1~1로 맞춘 것"입니다. 해석 기준은 다음과 같습니다.

- **1에 가까움**: 자기 그룹엔 딱 붙고 다른 그룹과는 멀다 → 잘 군집됨
- **0 근처**: 두 그룹 경계에 걸쳐 있다 → 애매함
- **음수**: 다른 그룹이 오히려 더 가깝다 → 잘못 배정됐을 가능성

전체 데이터의 Silhouette Score는 모든 점 $s(i)$ 의 평균입니다.

### 4) 쉬운 예시

동아리 방에 앉아 있다고 해봅시다. 내가 속한 동아리 사람들과는 바로 옆에 붙어 있고($a$ 작음), 옆 동아리는 저 멀리 있으면($b$ 큼) 나는 확실히 이 동아리 사람입니다(s가 1에 가까움). 반대로 두 동아리 사이 통로에 어정쩡하게 앉아 있으면 s는 0에 가깝고, 옆 동아리 무리 속에 잘못 앉아 있으면 s는 음수가 됩니다.

### 5) 코드 예시

K를 2부터 10까지 바꿔 가며 전체 Silhouette Score를 구합니다.

```python
from sklearn.cluster import KMeans
from sklearn.metrics import silhouette_score

for k in range(2, 11):
    labels = KMeans(n_clusters=k, random_state=42, n_init=10).fit_predict(X_scaled)
    print(f'K={k:2d}  silhouette={silhouette_score(X_scaled, labels):.4f}')
```

```text
K= 2  silhouette=0.5315
K= 3  silhouette=0.4472
K= 4  silhouette=0.3996
K= 5  silhouette=0.3789
K= 6  silhouette=0.3680
...
```

### 6) 헷갈리는 점

"Silhouette이 가장 높은 K가 무조건 정답"이라고 받아들이기 쉽습니다. 하지만 지표는 데이터의 기하학적 구조만 보기 때문에, 크게 뭉친 두 덩어리가 있으면 실제 그룹이 셋이어도 K=2를 최고로 뽑을 수 있습니다. 지표는 강력한 참고 자료이지, 도메인 지식을 대체하지는 않습니다.

### 7) 한 줄 정리

> Silhouette은 각 점이 "자기 그룹엔 가깝고 남의 그룹엔 먼지"를 −1~1로 재서, 정답 없이 군집 품질을 평가한다.

## 2. Dunn Index — 클러스터 전체를 하나로 놓고

### 1) 정의

Dunn Index(던 지수)는 군집 전체를 놓고 "가장 가까운 두 그룹이 얼마나 떨어져 있는지"를 "가장 퍼진 그룹이 얼마나 넓은지"로 나눈 값입니다. 그룹끼리는 멀고 각 그룹은 빽빽할수록 값이 커집니다.

### 2) 왜 필요한가

Silhouette이 점 하나하나를 평균 낸 관점이라면, Dunn Index는 클러스터 덩어리 전체의 관계를 봅니다. 특히 "가장 안 좋은 경우"에 주목합니다. 그룹 사이 최소 거리와 그룹 내 최대 직경을 쓰기 때문에, 하나라도 겹치거나 퍼진 그룹이 있으면 값이 확 떨어집니다. 관점이 다른 두 지표를 함께 보면 K 선택이 훨씬 튼튼해집니다.

### 3) 핵심 흐름 재구성

$$
DI = \frac{\min_{i \neq j} \delta(C_i, C_j)}{\max_k \Delta(C_k)}
$$

- 분자 $\min_{i \neq j} \delta(C_i, C_j)$: 서로 다른 두 클러스터 사이의 **가장 가까운 거리** 중 최솟값 → 그룹들이 멀수록 커짐
- 분모 $\max_k \Delta(C_k)$: 한 클러스터 안에서 가장 멀리 떨어진 두 점 사이 거리(직경) 중 최댓값 → 그룹이 빽빽할수록 작아짐

즉 "가장 붙어 있는 두 그룹 간격 ÷ 가장 퍼진 그룹의 폭"이며, **값이 클수록** 잘 분리되고 잘 뭉친 좋은 군집입니다. scikit-learn에는 내장돼 있지 않아 거리 계산 함수로 직접 구현합니다.

### 4) 쉬운 예시

주차장에 차들을 그룹으로 세운다고 해봅시다. 그룹끼리는 서로 멀찍이 떨어뜨리고(분자 큼), 같은 그룹 차들은 오밀조밀 붙여 세우면(분모 작음) 정리가 아주 잘 된 상태입니다. 반대로 두 그룹이 딱 붙어 있거나 한 그룹이 주차장 전체에 퍼져 있으면 정리 점수(Dunn)가 뚝 떨어집니다.

### 5) 코드 예시

K별 Dunn Index를 계산해 Silhouette 결과와 나란히 비교합니다.

```python
from scipy.spatial.distance import pdist, cdist
import numpy as np

def dunn_index(X_arr, labels):
    groups = [X_arr[labels == g] for g in np.unique(labels)]
    intra_max = max(pdist(g).max() for g in groups if len(g) >= 2)   # 그룹 내 최대 직경
    inter_min = min(cdist(a, b).min()                                 # 그룹 간 최소 거리
                    for i, a in enumerate(groups) for b in groups[i+1:])
    return inter_min / intra_max
```

```text
K= 2  dunn_index=0.2722
K= 3  dunn_index=0.0572
K= 4  dunn_index=0.0687
K= 5  dunn_index=0.0636
...
```

### 6) 헷갈리는 점

Dunn Index는 최솟값·최댓값을 쓰기 때문에 이상치 하나에 크게 흔들립니다. 멀리 떨어진 점 하나가 클러스터 직경을 부풀리면 분모가 커져 값이 뚝 떨어집니다. 그래서 Silhouette처럼 평균 기반 지표와 함께 보며 서로 보완하는 것이 안전합니다.

### 7) 한 줄 정리

> Dunn Index는 "가장 붙은 두 그룹 간격 ÷ 가장 퍼진 그룹 폭"으로, 클수록 잘 분리되고 잘 뭉친 군집이다.

## 코드로 보기 — 두 지표로 K 후보 좁히기

```python
# K별로 두 지표를 함께 출력해 비교
for k in range(2, 6):
    labels = KMeans(n_clusters=k, random_state=42, n_init=10).fit_predict(X_scaled)
    sil = silhouette_score(X_scaled, labels)
    dunn = dunn_index(X_scaled, labels)
    print(f'K={k}  silhouette={sil:.4f}  dunn={dunn:.4f}')
```

```text
K=2  silhouette=0.5315  dunn=0.2722
K=3  silhouette=0.4472  dunn=0.0572
K=4  silhouette=0.3996  dunn=0.0687
K=5  silhouette=0.3789  dunn=0.0636
```

### 코드 목적

관점이 다른 두 타당성 지표를 같은 K 범위에서 뽑아, 서로 무엇을 가리키는지 대조합니다.

### 코드 흐름

1. K마다 K-Means로 군집을 만든다.
2. Silhouette(점 단위 평균)과 Dunn(클러스터 단위)을 각각 계산한다.
3. 두 지표를 나란히 놓고 최적 K 후보를 좁힌다.

### 실행 결과 해석

두 지표 모두 **K=2에서 최고값**(Silhouette 0.5315, Dunn 0.2722)을 냈고, K=3부터는 뚜렷하게 낮아집니다. 순수하게 기하학적 구조만 보면 이 데이터는 "아주 큰 덩어리 하나 + 나머지"처럼 두 무리로 갈랐을 때 가장 깔끔하게 떨어진다는 뜻입니다. 그런데 [Elbow Method](04-kmeans-and-elbow.md)의 꺾임은 K=3 부근을 가리켰습니다. 이렇게 지표마다 답이 갈릴 수 있는데, 이는 실제 그룹 중 둘이 서로 가까이 붙어 있어 지표가 하나로 합치는 편을 선호하기 때문입니다. 최종 K는 지표 값만이 아니라 "이 데이터가 원래 몇 개 그룹일 법한가"라는 배경지식과 [실제 정답과의 대조](07-full-pipeline-and-evaluation.md)까지 봐야 결정할 수 있습니다.

### 실무 연결

고객 세분화나 상품 묶음에서 그룹 수를 정할 때, Silhouette·Dunn 값을 표로 만들어 근거로 삼습니다. 다만 지표가 가장 높은 K가 사업적으로 무의미할 수도 있습니다(예: 고객을 2그룹으로만 나누면 전략이 안 나옴). 이럴 때는 지표를 참고하되, 실무 목적에 맞는 K를 함께 고려해 최종 결정을 문서에 근거와 함께 남깁니다.

## 직접 해보기

1. Silhouette 계수에서 $a(i)$ 와 $b(i)$ 는 각각 무엇을 재나요? 값이 1에 가까우려면 두 값이 어떤 관계여야 하나요?
2. 어떤 점의 $a(i)=2$, $b(i)=5$ 입니다. Silhouette 계수 $s(i)$ 를 계산하고, 이 점이 잘 군집됐는지 판단하세요.
3. Silhouette과 Dunn이 모두 K=2를 가리키는데 도메인 전문가는 "그룹이 3개일 것"이라고 합니다. 어떻게 결론지어야 할까요?

<details>
<summary>정답 보기</summary>

1. $a(i)$ 는 같은 클러스터 안 다른 점들과의 평균 거리(응집도), $b(i)$ 는 가장 가까운 다른 클러스터까지의 평균 거리(분리도)입니다. $s$ 가 1에 가까우려면 $a$ 는 작고 $b$ 는 커야 합니다(자기 그룹엔 붙고 남의 그룹과는 멀어야 함).
2. $s(i) = (b-a)/\max(a,b) = (5-2)/\max(2,5) = 3/5 = 0.6$. 양수이고 0.5보다 크므로 비교적 잘 군집된 편입니다.
3. 지표는 기하학적 구조만 보므로, 서로 가까운 두 실제 그룹을 하나로 합치는 K=2를 선호할 수 있습니다. 지표를 참고 자료로 두되, 도메인 지식과 실제 레이블 대조(ARI·NMI, 교차표)까지 확인해 K=3의 타당성을 검증한 뒤 결론짓습니다.

</details>

## 헷갈리기 쉬운 포인트

| 헷갈리는 개념 | 차이 |
|---|---|
| 응집도 vs 분리도 | 같은 그룹이 얼마나 뭉쳤나가 응집도, 다른 그룹과 얼마나 떨어졌나가 분리도 |
| Silhouette vs Dunn | 점 단위로 평균 내면 Silhouette, 클러스터 덩어리 전체로 보면 Dunn |
| Silhouette vs Inertia | Silhouette은 분리도까지 보는 −1~1 지표, Inertia는 응집도만 보는 거리 제곱합 |
| 지표 최적 K vs 실제 K | 지표가 가리키는 K는 기하학적 최적일 뿐, 실제 그룹 수와 다를 수 있음 |
