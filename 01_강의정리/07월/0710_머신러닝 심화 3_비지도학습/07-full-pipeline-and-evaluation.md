# 전체 파이프라인과 최종 평가 — 레이블 없이 찾은 군집, 실제와 맞았을까

> 스케일링부터 차원 축소, 군집화, 타당성 평가까지 이어 붙이면 하나의 비지도학습 파이프라인이 됩니다. 마지막에 그동안 숨겨 둔 진짜 정답을 꺼내 대조하면, "정답 없이 찾은 구조"가 현실과 얼마나 맞았는지 검증할 수 있습니다. 이 글은 그 전 과정을 하나의 이야기로 엮습니다.

`파이프라인` · `crosstab` · `ARI` · `NMI` · `고객 세분화`

## 핵심요약

- 비지도학습 실습은 스케일링 → 차원 축소(PCA·t-SNE) → 군집화(K-Means·GMM) → 타당성 평가 → 정답 대조 순으로 이어진다.
- 학습 내내 실제 레이블은 숨겨 두고, 오직 특성만으로 군집을 만든 뒤 마지막에만 정답을 꺼낸다.
- 교차표(crosstab)는 "실제 그룹 × 예측 클러스터"를 표로 만들어, 어느 군집이 어느 실제 그룹에 대응되는지 보여 준다.
- ARI와 NMI는 군집 결과와 실제 정답의 일치도를 하나의 숫자로 요약하며, 1에 가까울수록 잘 맞은 것이다.
- 같은 데이터에서 GMM(ARI 0.960)이 K-Means(ARI 0.793)보다 실제 그룹에 훨씬 가깝게 맞았는데, 이는 그룹들이 구형이 아니라 타원형이기 때문이다.

## 1. 비지도학습 전체 파이프라인

### 1) 정의

파이프라인은 여러 처리 단계를 정해진 순서로 이어 붙인 하나의 흐름입니다. 비지도학습에서는 원본 특성을 다듬고(스케일링), 차원을 줄여 살펴보고(PCA·t-SNE), 그룹으로 묶고(K-Means·GMM), 잘 묶였는지 평가하는(타당성 지표) 단계가 순서대로 연결됩니다.

### 2) 왜 필요한가

개별 기법을 따로따로 아는 것과, 그것들을 올바른 순서로 엮어 하나의 분석을 완성하는 것은 다릅니다. 예를 들어 스케일링을 빼먹으면 뒤의 PCA와 K-Means가 전부 왜곡됩니다. 파이프라인 관점은 "무엇을 먼저 하고 무엇을 나중에 해야 결과가 신뢰할 만한가"라는 실무 감각을 길러 줍니다.

### 3) 핵심 흐름 재구성

전체 흐름을 정리하면 다음과 같습니다.

```text
1. 정답 분리   : 실제 레이블을 금고에 잠그고, 수치형 특성만 남긴다.
2. 스케일링    : StandardScaler로 모든 특성을 평균 0·분산 1로 맞춘다.
3. 차원 축소   : PCA로 분산을 보존해 축소, t-SNE로 군집을 눈으로 확인한다.
4. 군집화      : K-Means(Hard)와 GMM(Soft)으로 그룹을 만든다.
5. 타당성 평가 : Silhouette·Dunn으로 정답 없이 품질을 채점하고 K를 정한다.
6. 최종 검증   : 숨겨 둔 정답과 교차표·ARI·NMI로 대조한다.
```

여기서 1~5단계는 정답을 전혀 쓰지 않습니다. 이 실습의 핵심 설계는 "실제 그룹 정보를 마지막 순간까지 숨긴 채, 알고리즘이 특성만으로 구조를 스스로 찾아내는가"를 검증하는 데 있습니다. 참고로 축소 단계에서 [PCA](02-pca-and-scaling.md)의 첫 두 성분만으로 전체 분산의 약 88%가 설명되어, 2차원 평면에서 군집을 관찰하기에 충분했습니다.

### 4) 쉬운 예시

요리에 비유하면 파이프라인은 레시피의 순서입니다. 재료를 씻고(스케일링), 먹기 좋게 썰고(차원 축소), 조리하고(군집화), 간을 보는(타당성 평가) 순서를 지켜야 제대로 된 요리가 나옵니다. 씻지 않고 조리하거나 간을 안 보고 내면 결과가 엉망이 되듯, 단계 순서가 곧 품질을 결정합니다.

### 5) 코드 예시

앞 단계에서 만든 결과물을 이어받아 군집을 만드는 부분입니다.

```python
from sklearn.preprocessing import StandardScaler
from sklearn.cluster import KMeans
from sklearn.mixture import GaussianMixture

X_scaled = StandardScaler().fit_transform(X)               # 2. 스케일링
km_labels  = KMeans(n_clusters=3, random_state=42,
                    n_init=10).fit_predict(X_scaled)        # 4. K-Means
gmm_labels = GaussianMixture(n_components=3, random_state=42,
                    n_init=5).fit(X_scaled).predict(X_scaled)  # 4. GMM
```

각 단계의 출력이 다음 단계의 입력이 되는, 전형적인 파이프라인 구조입니다.

### 6) 헷갈리는 점

"차원 축소를 반드시 먼저 하고 군집화를 해야 한다"고 오해하기 쉽습니다. 실제로는 군집화를 원본(스케일링된) 특성에서 수행하고, PCA·t-SNE는 결과를 **눈으로 확인**하는 시각화 용도로 쓰는 경우가 많습니다. 축소와 군집화의 순서는 목적에 따라 달라집니다.

### 7) 한 줄 정리

> 비지도학습 파이프라인은 스케일링부터 정답 대조까지를 순서대로 엮은 흐름이며, 단계 순서가 결과의 신뢰도를 좌우한다.

## 2. 숨겨둔 정답으로 최종 검증 — 교차표·ARI·NMI

### 1) 정의

교차표(crosstab)는 "실제 그룹"을 행에, "예측 클러스터"를 열에 놓고 겹치는 개수를 세어 만든 표입니다. ARI(Adjusted Rand Index)와 NMI(Normalized Mutual Information)는 군집 결과와 실제 정답이 얼마나 일치하는지를 하나의 숫자로 요약한 지표입니다.

### 2) 왜 필요한가

타당성 지표(Silhouette·Dunn)는 정답 없이 "구조적으로" 잘 나뉘었는지만 봅니다. 하지만 정말 중요한 질문은 "그 군집이 현실의 의미 있는 그룹과 맞느냐"입니다. 실제 레이블이 있는 실습 환경에서는 이를 직접 대조해 볼 수 있고, 이는 비지도학습이 헛것을 잡은 게 아니라 진짜 구조를 읽었음을 확인하는 마지막 관문입니다.

### 3) 핵심 흐름 재구성

먼저 교차표로 "어느 군집이 어느 실제 그룹으로 채워졌는지" 눈으로 봅니다. 한 실제 그룹이 한 군집에 몰려 있으면 잘 맞은 것이고, 여러 군집에 흩어져 있으면 그 그룹을 제대로 못 잡은 것입니다. 그다음 ARI·NMI로 전체 일치도를 요약합니다.

- **ARI**: 두 그룹 나눔이 얼마나 같은지를 우연히 맞을 확률까지 보정해 −1~1로 표현. 1이면 완벽 일치.
- **NMI**: 한쪽 그룹을 알면 다른 쪽을 얼마나 알 수 있는지를 정보량으로 재서 0~1로 표현. 1이면 완벽 일치.

두 지표는 계산 방식이 다르지만 모두 "1에 가까울수록 좋다"는 방향은 같습니다.

### 4) 쉬운 예시

시험 채점에 비유할 수 있습니다. 학생(알고리즘)이 정답을 안 보고 문제를 풀었고(군집화), 마지막에 정답지(실제 레이블)와 맞춰 봅니다. 교차표는 "어느 문제를 어떻게 답했는지" 하나하나 보여 주는 오답노트이고, ARI·NMI는 "총점 몇 점"에 해당하는 요약 점수입니다.

### 5) 코드 예시

숨겨 둔 정답을 꺼내 교차표와 요약 지표를 만듭니다.

```python
import pandas as pd
from sklearn.metrics import adjusted_rand_score, normalized_mutual_info_score

# 그동안 잠가 둔 실제 레이블(y_true)을 이제야 사용
ct = pd.crosstab(y_true, km_labels, rownames=['실제 그룹'], colnames=['K-Means'])
print(ct)

print(f'K-Means  ARI={adjusted_rand_score(y_true, km_labels):.3f}  '
      f'NMI={normalized_mutual_info_score(y_true, km_labels):.3f}')
print(f'GMM      ARI={adjusted_rand_score(y_true, gmm_labels):.3f}  '
      f'NMI={normalized_mutual_info_score(y_true, gmm_labels):.3f}')
```

### 6) 헷갈리는 점

교차표에서 "군집 번호와 실제 그룹 번호가 같아야 한다"고 생각하면 안 됩니다. 군집화는 그룹에 임의의 번호를 붙일 뿐이라, 실제 그룹 A가 군집 2번에 담길 수 있습니다. 번호가 아니라 "한 그룹이 한 군집에 몰려 있는가"라는 대응 패턴을 봐야 합니다. ARI·NMI는 이 번호 뒤섞임에 영향받지 않도록 설계돼 있습니다.

### 7) 한 줄 정리

> 교차표는 군집과 실제 그룹의 대응을 눈으로 보여 주고, ARI·NMI는 그 일치도를 하나의 점수로 요약한다.

## 코드로 보기 — 군집과 실제 종을 맞춰 보기

```python
# K-Means × 실제 그룹
print(pd.crosstab(y_true, km_labels, rownames=['실제'], colnames=['K-Means']))
# GMM × 실제 그룹
print(pd.crosstab(y_true, gmm_labels, rownames=['실제'], colnames=['GMM']))
```

```text
=== K-Means × 실제 ===
실제         0    1    2
그룹A       24    0  127
그룹B       63    0    5
그룹C        0  123    0

=== GMM × 실제 ===
실제         0    1    2
그룹A      149    0    2
그룹B        3    0   65
그룹C        0  123    0

K-Means  ARI=0.793  NMI=0.786
GMM      ARI=0.960  NMI=0.935
```

### 코드 목적

정답 없이 만든 두 군집(K-Means·GMM)이 실제 세 그룹과 얼마나 맞는지, 표와 요약 지표로 동시에 확인합니다.

### 코드 흐름

1. 잠가 두었던 실제 레이블을 꺼낸다.
2. K-Means·GMM 결과를 각각 실제 그룹과 교차표로 만든다.
3. ARI·NMI로 전체 일치도를 요약해 두 방법을 비교한다.

### 실행 결과 해석

먼저 **그룹C는 두 방법 모두 완벽하게 잡았습니다**. K-Means와 GMM 모두 그룹C 123개 전부를 군집 1번 하나에 담았고, 군집 1번에는 다른 그룹이 전혀 섞이지 않았습니다. 이 그룹은 특성상 나머지와 확연히 떨어져 있어 어떤 방법으로도 쉽게 분리됩니다.

문제는 **그룹A와 그룹B**입니다. K-Means 교차표를 보면 그룹A가 군집 0번에 24개, 군집 2번에 127개로 **쪼개졌고**, 그룹B도 군집 0번 63개·군집 2번 5개로 흩어졌습니다. 즉 K-Means는 서로 가까이 붙은 이 두 그룹의 경계를 깔끔하게 긋지 못했습니다. 반면 GMM은 그룹A 149개를 군집 0번에, 그룹B 65개를 군집 2번에 거의 몰아넣어 **훨씬 선명하게** 분리했습니다.

이 차이가 요약 지표에 그대로 드러납니다. **GMM의 ARI 0.960이 K-Means의 0.793을 크게 앞섭니다**(NMI도 0.935 대 0.786). 이유는 명확합니다. 그룹A와 그룹B는 완벽한 구형이 아니라 타원형으로 늘어나 서로 겹쳐 있는데, 둥근 군집을 가정하는 [K-Means](04-kmeans-and-elbow.md)는 여기서 약하고, 타원형을 허용하는 [GMM](06-gmm-soft-clustering.md)이 이 모양을 제대로 잡아냈기 때문입니다. 정답 없이 시작했지만, 알고리즘이 실제 생물학적 그룹과 96%까지 일치하는 구조를 스스로 찾아낸 셈입니다.

### 실무 연결

이 "레이블 없이 구조를 찾고 나중에 검증한다"는 흐름은 실무 곳곳에서 반복됩니다.

- **고객 세분화**: 구매 이력만으로 고객을 군집한 뒤, 나중에 실제 이탈 여부나 구매 등급 같은 알려진 라벨과 대조해 군집이 사업적으로 의미 있는지 확인합니다. 여기서 ARI·NMI가 낮으면 특성이나 K를 다시 조정합니다.
- **이상 탐지**: 정상 거래를 군집으로 학습한 뒤, 확보된 사기 사례와 대조해 어느 군집에 이상 거래가 몰리는지 봅니다. GMM의 소속 확률까지 쓰면 애매한 경계 사례를 정밀하게 걸러냅니다.
- **문서·콘텐츠 분류**: 라벨 없는 문서를 주제별로 군집하고, 일부 사람이 붙인 태그와 교차표로 맞춰 봐 자동 분류의 품질을 점검합니다.
- **추천 시스템**: 사용자를 취향 그룹으로 묶은 뒤, 실제 구매·클릭 데이터로 그룹 정의가 타당한지 검증하고 그룹별 추천 전략을 세웁니다.

핵심 교훈은 하나입니다. 비지도학습은 "정답을 못 쓰는" 상황을 위한 도구이지만, 검증 가능한 라벨이 조금이라도 있다면 반드시 대조해 신뢰도를 확인해야 한다는 것입니다.

## 헷갈리기 쉬운 포인트

| 헷갈리는 개념 | 차이 |
|---|---|
| 타당성 지표 vs 정답 대조 | Silhouette·Dunn은 정답 없이 구조만 평가, ARI·NMI는 실제 정답과 일치도 평가 |
| 군집 번호 vs 실제 그룹 번호 | 군집 번호는 임의로 붙으므로, 번호 일치가 아니라 대응 패턴을 봐야 함 |
| ARI vs NMI | 우연 보정한 쌍 비교가 ARI, 정보량 기반 일치 측정이 NMI |
| K-Means vs GMM 결과 | 구형에 강한 K-Means vs 타원형·겹침을 잡는 GMM — 여기선 GMM이 정답에 더 근접 |

### 복습 질문 및 답변

**Q1. 비지도학습 실습에서 정답 레이블을 왜 마지막까지 숨기나요?**

<details>
<summary>답</summary>

알고리즘이 정답을 참고하지 않고 오직 특성만으로 구조를 찾았는지 공정하게 검증하기 위해서입니다. 중간에 정답을 쓰면 그것은 이미 지도학습이 되어, 비지도학습의 성능을 제대로 평가할 수 없습니다.

</details>

**Q2. 교차표에서 군집 번호와 실제 그룹 번호가 달라도 괜찮은 이유는?**

<details>
<summary>답</summary>

군집화는 그룹에 임의의 번호를 붙일 뿐이라, 실제 그룹이 어느 번호 군집에 담길지는 정해져 있지 않습니다. 중요한 것은 "한 그룹이 한 군집에 몰려 있는가"라는 대응 패턴이며, ARI·NMI는 번호 뒤섞임에 영향받지 않습니다.

</details>

**Q3. 같은 데이터에서 GMM이 K-Means보다 정답에 더 잘 맞은 이유는?**

<details>
<summary>답</summary>

서로 가깝게 붙은 두 실제 그룹이 완벽한 구형이 아니라 타원형으로 겹쳐 있었기 때문입니다. 둥근 군집을 가정하는 K-Means는 이 경계를 잘못 그었지만, 타원형을 허용하는 GMM은 모양을 제대로 잡아 ARI 0.960으로 K-Means의 0.793을 크게 앞섰습니다.

</details>

## 한 줄 정리

> 비지도학습은 정답 없이 구조를 찾는 여정이며, 마지막에 숨겨 둔 정답과 교차표·ARI·NMI로 대조해야 그 구조가 현실과 맞았는지 확인할 수 있다.
