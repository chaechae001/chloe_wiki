# 비지도학습의 기초 — 정답표 없이 구조를 읽는 법

> 지도학습은 "정답을 주고 맞히게" 하지만, 현실 데이터에는 정답표가 없는 경우가 훨씬 많습니다. 이 글은 정답 없이 데이터 스스로 구조를 찾는 비지도학습이 무엇인지, 왜 필요한지, 그리고 군집 문제를 어떻게 설계하는지 정리합니다.

`비지도학습` · `클러스터링` · `Hard/Soft Clustering` · `레이블 없는 데이터` · `고객 세분화`

## 핵심요약

- 비지도학습은 정답 레이블($Y$) 없이 입력 특성($X$)만으로 데이터의 구조·그룹·이상치를 스스로 찾는 학습이다.
- 현실 데이터 대부분은 라벨이 없거나 라벨을 다는 비용이 크기 때문에 비지도학습이 필요하다.
- 대표 문제인 클러스터링은 "비슷한 것끼리 묶어 그룹을 만드는" 작업으로, 고객 세분화·이상치 탐지 등에 쓰인다.
- Hard Clustering은 한 점을 한 그룹에만 배정하고, Soft Clustering은 여러 그룹에 확률로 나눠 배정한다.
- 이번 실습은 펭귄 데이터에서 종(정답)을 일부러 숨긴 채 시작해, 알고리즘이 정답 없이 구조를 찾는지 검증하도록 설계된다.

## 1. 비지도학습이란 무엇인가

### 1) 정의

머신러닝은 크게 두 갈래로 나뉩니다. **지도학습**은 입력과 정답이 짝지어진 데이터 $(X, Y)$를 주고, 그 정답을 맞히도록 모델을 학습시킵니다. 스팸 여부가 붙은 메일로 스팸 분류기를 만드는 식입니다. 반면 **비지도학습**은 정답 레이블 $Y$ 없이 오직 입력 특성 $X$만 가지고, 데이터 안에 숨은 그룹 구조·패턴·이상치를 스스로 찾아냅니다.

한 유명한 비유가 있습니다. 지능을 케이크에 빗대면, 비지도학습은 케이크의 몸통이 되는 시트(빵)이고 지도학습은 그 위에 바르는 아이싱이라는 것입니다. 그만큼 "정답 없이 세상의 구조를 이해하는 능력"이 학습의 근본 토대라는 뜻입니다.

### 2) 왜 필요한가

지도학습이 강력한데도 비지도학습을 배워야 하는 이유는, 현실 데이터에 정답표가 거의 없기 때문입니다.

- **데이터 분석에서**: 수집된 로그·설문·거래 기록에는 "이 사람은 A유형"이라는 라벨이 붙어 있지 않습니다. 먼저 구조를 파악해야 다음 분석이 가능합니다.
- **머신러닝에서**: 라벨을 사람이 일일이 다는 작업은 비싸고 느립니다. 라벨이 없는 대량 데이터에서 먼저 표현(구조)을 학습해 두면, 이후 소량의 라벨만으로도 효율적으로 지도학습을 이어갈 수 있습니다.
- **실무에서**: 고객 세분화, 이상 거래 탐지, 추천을 위한 사용자 그룹핑처럼 "정답이 애초에 존재하지 않는" 문제가 많습니다.

정리하면, 비지도학습은 "정답이 없어서 못 하는" 상황이 아니라 "정답이 없어도 할 수 있는" 도구입니다.

### 3) 핵심 흐름 재구성

비지도학습의 대표 과제는 세 가지로 정리됩니다.

1. **차원 축소**: 특성이 너무 많아 눈으로 볼 수 없는 데이터를 2~3차원으로 압축한다. → [PCA·스케일링](02-pca-and-scaling.md), [t-SNE](03-tsne-visualization.md)
2. **클러스터링(군집화)**: 비슷한 데이터끼리 묶어 그룹을 만든다. → [K-Means](04-kmeans-and-elbow.md), [GMM](06-gmm-soft-clustering.md)
3. **타당성 검증**: 정답이 없으므로, 만들어진 그룹이 잘 나뉜 것인지 별도 지표로 확인한다. → [Silhouette·Dunn](05-clustering-validity.md)

지도학습과 결정적으로 다른 점은 **채점표가 없다는 것**입니다. 정확도(accuracy) 같은 지표를 바로 쓸 수 없으므로, "이 그룹핑이 믿을 만한가"를 스스로 만들어 내는 검증 장치가 항상 따라붙습니다.

### 4) 쉬운 예시

쇼핑몰이 고객 1만 명의 구매 기록만 가지고 있다고 합시다. 누구도 "이 고객은 알뜰형", "저 고객은 충동구매형"이라고 라벨을 붙여 주지 않았습니다. 비지도학습은 구매 빈도·평균 결제액·방문 시간대 같은 특성만 보고 비슷한 고객끼리 자동으로 묶어 줍니다. 그 결과 "주말 저녁에 크게 지르는 그룹", "평일 낮에 소액을 자주 쓰는 그룹" 같은 덩어리가 드러납니다. 이렇게 발견한 그룹에 나중에 사람이 이름을 붙이고 마케팅 전략을 세우는 것이 전형적인 활용법입니다.

### 5) 코드 예시

이번 회차의 데이터는 펭귄 측정치입니다. 핵심 설계는 "정답(종)을 학습에서 완전히 떼어 놓는 것"입니다.

```python
import seaborn as sns

raw = sns.load_dataset('penguins')

# 학습에 쓸 수치형 특성 4개만 사용
FEATURE_COLS = ['bill_length_mm', 'bill_depth_mm',
                'flipper_length_mm', 'body_mass_g']

# 결측 행 제거 후 정답과 특성을 분리
df = raw.loc[raw[FEATURE_COLS + ['species']].notnull().all(axis=1)].reset_index(drop=True)

y_true = df['species'].copy()   # 정답 = 금고에 넣고 마지막까지 사용 금지
X = df[FEATURE_COLS].copy()      # 알고리즘은 X만 본다

print('X shape:', X.shape)
print('실제 종류 수(확인용):', y_true.nunique())
```

```text
X shape: (342, 4)
실제 종류 수(확인용): 3
```

### 코드 목적

데이터를 "알고리즘이 볼 수 있는 특성 $X$"와 "끝까지 숨길 정답 $y\_true$"로 분리해, 완전한 비지도 환경을 만드는 것입니다.

### 실행 결과 해석

342마리 × 4개 특성만 남았고, 정답 종류는 3종입니다. 하지만 이 "3"은 우리가 마지막 검증 때 쓸 정보일 뿐, 알고리즘에게는 알려 주지 않습니다. 알고리즘은 오직 4개 숫자 특성만 보고 "데이터가 몇 덩어리로 나뉘는지"를 스스로 판단해야 합니다. 실습 내내 정답을 숨기는 이 설계 덕분에, 마지막에 "정답 없이 찾은 구조가 실제 종과 얼마나 맞았는가"를 정직하게 채점할 수 있습니다.

### 6) 헷갈리는 점

"비지도학습에는 정답이 아예 없다"는 말과 "정답을 사용하지 않는다"는 말은 다릅니다. 이번 실습처럼 정답이 존재하더라도(펭귄 종), 학습 과정에서는 쓰지 않고 검증할 때만 꺼내는 경우가 많습니다. 핵심은 **학습 신호로 정답을 쓰지 않는다**는 점입니다.

### 7) 한 줄 정리

> 비지도학습은 정답 레이블 없이 입력만으로 데이터의 숨은 구조를 찾는 학습이며, 채점표가 없기에 검증 장치가 늘 함께 간다.

## 2. Hard Clustering vs Soft Clustering

### 1) 정의

클러스터링은 소속을 정하는 방식에 따라 둘로 나뉩니다.

- **Hard Clustering**: 각 데이터를 정확히 하나의 군집에만 배정합니다. "이 펭귄은 1번 그룹" 하고 딱 잘라 정합니다. K-Means가 대표입니다.
- **Soft Clustering**: 각 데이터를 여러 군집에 확률로 나눠 배정합니다. "이 펭귄은 0번에 70%, 1번에 30% 소속"처럼 애매한 경계도 표현합니다. GMM이 대표입니다.

### 2) 왜 필요한가

현실의 경계는 칼로 자른 듯 명확하지 않을 때가 많습니다. 두 그룹의 경계에 걸친 데이터를 억지로 한쪽에 몰아넣으면 정보가 사라집니다. Soft Clustering은 "이 데이터는 애매하다"는 사실 자체를 확률로 남겨 두어, 경계 사례를 더 섬세하게 다룰 수 있게 합니다.

### 3) 핵심 흐름 재구성

Hard는 "너는 몇 번 그룹이야"라는 배정표를 출력하고, Soft는 "각 그룹에 속할 확률"을 출력합니다. Soft 결과에서 가장 확률이 높은 그룹만 취하면 Hard처럼 쓸 수도 있습니다. 실제로 K-Means는 GMM(구형 분포·확률을 0/1로 몰아붙인 특수한 경우)로 볼 수 있어, 두 방법은 완전히 별개가 아니라 연속선 위에 있습니다. 자세한 비교는 [GMM 글](06-gmm-soft-clustering.md)에서 이어집니다.

### 4) 쉬운 예시

영화 취향으로 사람을 묶는다고 합시다. Hard 방식은 "당신은 액션 팬"이라고 하나로 못 박습니다. Soft 방식은 "액션 60%, 로맨스 40%"라고 말합니다. 액션과 로맨스를 모두 즐기는 사람에게는 Soft 쪽이 훨씬 현실적입니다.

### 5) 코드 예시

같은 데이터에 Hard(K-Means)와 Soft(GMM)를 각각 적용하면 출력 형태가 다릅니다.

```python
from sklearn.cluster import KMeans
from sklearn.mixture import GaussianMixture

# Hard: 각 점의 그룹 번호 하나
hard = KMeans(n_clusters=3, n_init=10, random_state=42).fit_predict(X_scaled)

# Soft: 각 점이 각 그룹에 속할 확률 벡터
gmm = GaussianMixture(n_components=3, random_state=42).fit(X_scaled)
soft = gmm.predict_proba(X_scaled)  # shape (n, 3), 각 행 합=1
```

### 실행 결과 해석

`hard`는 `[2, 0, 2, 1, ...]`처럼 정수 하나로 나오고, `soft`의 각 행은 `[1.000, 0.000, 0.000]`처럼 합이 1인 확률로 나옵니다. Soft 출력에서 대부분의 확률이 한 그룹에 몰려 있으면 그 점은 확신 있게 배정된 것이고, 확률이 여러 그룹에 퍼져 있으면 경계에 걸친 애매한 점입니다.

### 6) 헷갈리는 점

Soft라고 해서 항상 애매한 값이 나오는 건 아닙니다. 데이터가 뚜렷하게 나뉘어 있으면 확률이 거의 1과 0으로 갈라져 Hard와 결과가 비슷해집니다. Soft의 장점은 "필요할 때 애매함을 표현할 수 있다"는 여지에 있습니다.

### 7) 한 줄 정리

> Hard는 하나의 그룹으로 딱 잘라 배정하고, Soft는 여러 그룹에 확률로 나눠 배정해 경계의 애매함까지 담는다.

## 코드로 보기 — 비지도 환경 만들기

```python
import seaborn as sns

raw = sns.load_dataset('penguins')
FEATURE_COLS = ['bill_length_mm', 'bill_depth_mm', 'flipper_length_mm', 'body_mass_g']

df = raw.loc[raw[FEATURE_COLS + ['species']].notnull().all(axis=1)].reset_index(drop=True)
y_true = df['species'].copy()     # 정답 격리
X = df[FEATURE_COLS].copy()       # 특성만 학습에 사용
```

### 코드 목적

정답을 학습 과정에서 완전히 분리해, 알고리즘이 오직 특성만으로 구조를 찾도록 강제하는 실습 뼈대를 만듭니다.

### 코드 흐름

1. 데이터를 불러온다.
2. 결측치가 있는 행을 걸러낸다.
3. 정답(종)을 `y_true`로 따로 보관한다.
4. 수치형 특성 4개만 `X`로 남겨 학습에 쓴다.

### 실행 결과 해석

이제 `X`에는 라벨이 전혀 없습니다. 이후 모든 단계(PCA·K-Means·GMM·t-SNE)는 이 `X`만 사용하고, `y_true`는 [마지막 검증 단계](07-full-pipeline-and-evaluation.md)에서야 등장합니다.

### 실무 연결

실무의 비지도 프로젝트도 똑같은 구조입니다. "라벨이 없는(혹은 라벨을 배제한) 특성 행렬"에서 시작해, 구조를 찾고, 나중에 도메인 지식이나 소량의 정답으로 결과를 해석·검증합니다.

## 헷갈리기 쉬운 포인트

| 헷갈리는 개념 | 차이 |
|---|---|
| 지도학습 vs 비지도학습 | 정답 $Y$를 학습 신호로 쓰면 지도학습, 정답 없이 $X$만으로 구조를 찾으면 비지도학습 |
| 클러스터링 vs 분류 | 정답 그룹이 정해져 있고 맞히는 것이 분류, 그룹 자체를 데이터에서 새로 만드는 것이 클러스터링 |
| Hard vs Soft Clustering | 한 점을 한 그룹에만 배정하면 Hard, 여러 그룹에 확률로 나눠 배정하면 Soft |
| 정답이 없다 vs 정답을 안 쓴다 | 애초에 라벨이 없는 경우와, 라벨은 있지만 학습에 쓰지 않고 검증용으로만 두는 경우는 다르다 |

비지도학습이 정답 없이도 데이터 구조를 제대로 찾는지 정직하게 검증하기 위해서입니다. 정답을 마지막까지 숨겨야, 마지막에 꺼냈을 때 "정답 없이 찾은 결과가 실제와 얼마나 맞는지"를 공정하게 채점할 수 있습니다.

**Q3. 애매한 경계 데이터가 많은 고객 세분화 문제에 Soft Clustering이 유리한 이유는?**

<details>
<summary>답</summary>

Soft Clustering은 한 고객을 여러 그룹에 확률로 소속시키므로, 두 그룹 사이에 걸친 고객의 애매함을 억지로 지우지 않고 확률로 보존합니다. 이렇게 하면 경계 고객을 대상으로 한 세밀한 전략 수립이 가능합니다.

</details>
