# GMM과 Soft Clustering — 딱 잘라 나누지 않고 확률로 소속시키기

> K-Means는 각 점을 한 그룹에 딱 배정합니다. 하지만 경계에 걸친 점은 "70%는 A, 30%는 B"라고 말하는 게 더 정직할 때가 있습니다. 이 글은 데이터를 여러 정규분포의 혼합으로 보는 GMM과, 확률로 소속을 표현하는 Soft Clustering을 정리합니다.

`GMM` · `Soft Clustering` · `가우시안 혼합` · `EM 알고리즘` · `소속 확률`

## 핵심요약

- GMM(Gaussian Mixture Model)은 데이터가 여러 개의 정규분포(가우시안)가 섞여서 생성됐다고 가정하는 군집 모델이다.
- 각 점을 한 그룹에 딱 넣지 않고, "각 그룹에 속할 확률"로 표현하는 방식을 Soft Clustering이라고 한다.
- GMM은 EM 알고리즘으로 학습한다: E-step에서 소속 확률을 추정하고, M-step에서 분포의 평균·모양을 갱신하며 반복한다.
- K-Means는 둥근 군집만 잘 잡지만, GMM은 타원형으로 늘어나거나 크기가 다른 군집도 표현할 수 있다.
- 대신 GMM은 계산이 더 무겁고, 각 그룹이 대략 정규분포를 따른다는 가정이 필요하다.

## 1. GMM — 데이터를 여러 정규분포의 혼합으로 보기

### 1) 정의

GMM은 전체 데이터가 K개의 정규분포(종 모양 분포)가 겹쳐서 만들어졌다고 가정하는 모델입니다. 각 정규분포는 하나의 클러스터에 해당하며, 자기만의 중심(평균)과 퍼진 모양(공분산), 그리고 전체에서 차지하는 비중(혼합 비율)을 가집니다. 새 점이 주어지면 "이 점은 각 분포에서 나왔을 확률이 얼마인가"를 계산합니다.

### 2) 왜 필요한가

K-Means는 중심에서의 거리로만 그룹을 나눠 둥근 군집을 가정합니다. 하지만 현실 데이터의 그룹은 길쭉하거나, 크기가 제각각이거나, 서로 겹쳐 있습니다. GMM은 각 그룹을 타원형 분포로 표현할 수 있어, 이런 모양을 훨씬 유연하게 잡아냅니다. 또한 경계에 걸친 점을 "억지로 한쪽"으로 몰지 않고 확률로 표현해, 불확실성까지 다룰 수 있습니다.

### 3) 핵심 흐름 재구성

GMM은 정답이 없는 상태에서 "어느 분포에서 나왔는지"를 모른 채 분포의 모양을 추정해야 합니다. 이 닭과 달걀 문제를 **EM 알고리즘**으로 풉니다.

```text
E-step (기댓값)  : 현재 분포들을 기준으로, 각 점이 각 분포에 속할 확률(책임값)을 계산
M-step (최대화)  : 그 확률을 가중치로 삼아 각 분포의 평균·공분산·혼합 비율을 갱신
반복             : 두 단계를 로그우도가 안정될 때까지 되풀이
```

한 점 $x$ 가 클러스터 $k$ 에서 나왔을 확률(책임값, responsibility)은 다음처럼 씁니다.

$$
\gamma_k(x) = \frac{\pi_k \, \mathcal{N}(x \mid \mu_k, \Sigma_k)}{\sum_{j=1}^{K} \pi_j \, \mathcal{N}(x \mid \mu_j, \Sigma_j)}
$$

이 식은 "각 분포가 이 점을 설명하는 정도($\pi_k \mathcal{N}$)를, 전체 분포들이 설명하는 양으로 나눠 비율로 만든 것"입니다. $\pi_k$ 는 클러스터 $k$ 의 비중, $\mathcal{N}(x \mid \mu_k, \Sigma_k)$ 은 평균 $\mu_k$·모양 $\Sigma_k$ 를 가진 정규분포에서 $x$ 가 나올 밀도입니다. 결과적으로 한 점에 대해 각 클러스터 확률을 모두 더하면 1이 됩니다.

### 4) 쉬운 예시

키 데이터만 보고 성별 그룹을 나눈다고 해봅시다. 남성 키와 여성 키는 각각 대략 종 모양 분포를 이루지만 중간 구간(예: 168cm)에서는 겹칩니다. 168cm인 사람을 "무조건 남성"이라고 딱 자르면 정보가 사라집니다. GMM은 "이 사람은 남성 분포에서 나왔을 확률 55%, 여성 분포 45%"처럼 겹치는 정도까지 표현합니다.

### 5) 코드 예시

GMM을 학습하고 각 점의 소속 확률을 확인합니다.

```python
from sklearn.mixture import GaussianMixture
import pandas as pd

gmm = GaussianMixture(n_components=3, random_state=42, n_init=5)
gmm.fit(X_scaled)

gmm_labels = gmm.predict(X_scaled)        # 가장 확률 높은 그룹 (Hard처럼 사용)
gmm_proba  = gmm.predict_proba(X_scaled)  # 각 그룹 소속 확률 (Soft)

print('BIC:', round(gmm.bic(X_scaled), 1), ' AIC:', round(gmm.aic(X_scaled), 1))
print(pd.DataFrame(gmm_proba[:5], columns=['C0', 'C1', 'C2']).round(3))
```

```text
BIC: 2553.6  AIC: 2384.9
      C0   C1     C2
0  1.000  0.0  0.000
1  0.999  0.0  0.001
2  0.976  0.0  0.024
3  1.000  0.0  0.000
4  1.000  0.0  0.000
```

BIC와 AIC는 "모델이 데이터를 잘 설명하면서도 지나치게 복잡하지 않은지"를 재는 값으로, 여러 K를 비교할 때 낮은 쪽이 좋습니다.

### 6) 헷갈리는 점

`predict`로 그룹 번호만 뽑아 쓰면 GMM을 K-Means처럼 딱딱하게 쓰는 셈입니다. GMM의 진짜 강점은 `predict_proba`로 나오는 소속 확률에 있습니다. 위 출력에서 세 번째 점은 C0에 97.6%, C2에 2.4%로 약간의 애매함이 드러나는데, 이 정보는 Hard 배정에서는 사라집니다.

### 7) 한 줄 정리

> GMM은 데이터를 여러 정규분포의 혼합으로 보고, EM 알고리즘으로 각 분포의 모양과 소속 확률을 함께 추정한다.

## 2. Soft Clustering — 확률로 소속시키기

### 1) 정의

Soft Clustering은 각 점을 한 그룹에만 딱 배정하지 않고, 여러 그룹에 대한 소속 확률로 표현하는 방식입니다. 예를 들어 "이 점은 그룹 0에 70%, 그룹 1에 30%"처럼 나타냅니다. 반대로 각 점을 한 그룹에만 배정하는 [K-Means](04-kmeans-and-elbow.md)는 Hard Clustering입니다.

### 2) 왜 필요한가

현실에서는 딱 잘라 말하기 어려운 경계 사례가 많습니다. 애매한 점을 억지로 한쪽에 넣으면, 그 점이 사실은 두 그룹 사이에 걸쳐 있다는 중요한 정보가 사라집니다. Soft Clustering은 이 불확실성을 확률로 남겨, "확신하는 점"과 "애매한 점"을 구분할 수 있게 해 줍니다. 이 정보는 뒤이은 의사결정에서 위험 관리에 쓰입니다.

### 3) 핵심 흐름 재구성

GMM의 `predict_proba`가 곧 Soft Clustering의 결과입니다. 각 점마다 클러스터 개수만큼의 확률이 나오고, 그 합은 1입니다. 확률이 한 그룹에 0.99처럼 몰려 있으면 그 점은 소속이 확실한 것이고, 0.55 대 0.45처럼 갈리면 경계에 걸친 애매한 점입니다. 최종적으로 하나만 골라야 하면 가장 큰 확률의 그룹을 택하지만(`predict`), 확률 자체를 활용도 지표로 쓸 수 있습니다.

### 4) 쉬운 예시

영화 추천을 생각해 봅시다. 어떤 사용자를 "액션 팬"이라고 딱 못 박는 대신, "액션 60%, SF 30%, 코미디 10%"로 표현하면 추천이 훨씬 풍부해집니다. 취향이 애매한 사용자에게는 여러 장르를 섞어 추천할 수 있습니다. 이것이 Soft Clustering이 주는 유연함입니다.

### 5) 코드 예시

K-Means(Hard)와 GMM(Soft)의 결과가 얼마나 일치하는지 확인합니다.

```python
from sklearn.metrics import adjusted_rand_score

agreement = adjusted_rand_score(cluster_labels, gmm_labels)
print(f'K-Means vs GMM 일치도(ARI): {agreement:.3f}')
```

```text
K-Means vs GMM 일치도(ARI): 0.824
```

ARI(Adjusted Rand Index)는 두 군집 결과가 얼마나 같게 나눴는지를 재는 값으로, 1에 가까울수록 비슷합니다.

### 6) 헷갈리는 점

Soft Clustering이라고 해서 "정답을 여러 개 준다"는 뜻이 아닙니다. 소속 확률을 주는 것이지, 최종적으로 하나를 골라야 하는 상황에서는 가장 큰 확률의 그룹을 택합니다. Soft는 "확신의 정도를 함께 알려 준다"는 의미로 이해하는 것이 정확합니다.

### 7) 한 줄 정리

> Soft Clustering은 소속을 확률로 표현해, 경계에 걸친 점의 애매함까지 정보로 남긴다.

## 코드로 보기 — 같은 K로 K-Means와 GMM 비교

```python
# 같은 데이터, 같은 K=3으로 두 방법을 학습해 결과를 대조
km_labels  = KMeans(n_clusters=3, random_state=42, n_init=10).fit_predict(X_scaled)
gmm = GaussianMixture(n_components=3, random_state=42, n_init=5).fit(X_scaled)
gm_labels  = gmm.predict(X_scaled)

print('ARI(두 방법 일치도):', round(adjusted_rand_score(km_labels, gm_labels), 3))
```

```text
ARI(두 방법 일치도): 0.824
```

### 코드 목적

같은 K에서 Hard(K-Means)와 Soft(GMM)가 얼마나 비슷하게, 또는 다르게 나누는지 수치로 확인합니다.

### 코드 흐름

1. 동일한 스케일링 데이터에 K=3으로 K-Means와 GMM을 각각 학습한다.
2. 두 결과의 그룹 배정을 ARI로 비교한다.
3. 일치도가 1에서 얼마나 떨어지는지로 두 방법의 차이를 읽는다.

### 실행 결과 해석

일치도(ARI)가 **0.824**로, 두 방법이 대체로 비슷하게 나눴지만 완전히 같지는 않습니다. 차이가 나는 부분은 주로 두 그룹이 서로 가깝게 붙어 있는 경계 구역입니다. K-Means는 이 구역을 중심 거리로 딱 잘라 나누는 반면, GMM은 타원형 분포로 겹침을 표현하며 경계 점의 소속을 다르게 판단합니다. 실제로 이 데이터에서는 [숨겨둔 정답과 대조](07-full-pipeline-and-evaluation.md)했을 때 GMM이 K-Means보다 실제 그룹에 더 가깝게 맞았는데, 이는 그룹들이 완벽한 구형이 아니라 타원형으로 늘어나 있기 때문입니다.

### 실무 연결

이상 탐지가 좋은 예입니다. GMM으로 정상 데이터의 분포를 학습해 두면, 새 데이터가 어느 분포에도 낮은 확률로만 속할 때 "이상값 후보"로 걸러낼 수 있습니다. Hard 배정만으로는 "무조건 가장 가까운 그룹"에 넣어 버려 이상값을 놓치지만, 소속 확률을 보면 "어디에도 잘 안 맞는 점"을 잡아낼 수 있습니다.

## 헷갈리기 쉬운 포인트

| 헷갈리는 개념 | 차이 |
|---|---|
| K-Means vs GMM | 거리로 딱 나누는 Hard가 K-Means, 확률로 소속시키는 Soft가 GMM |
| Hard vs Soft Clustering | 한 그룹에만 배정하면 Hard, 여러 그룹 확률로 표현하면 Soft |
| 구형 가정 vs 타원 허용 | K-Means는 둥근 군집만, GMM은 공분산으로 타원형·크기 차이도 표현 |
| predict vs predict_proba | 가장 큰 확률의 그룹만 주면 predict, 모든 그룹 확률을 주면 predict_proba |
