# t-SNE 시각화 — 이웃 관계를 지켜 군집을 눈에 보이게

> PCA가 "분산이 큰 방향"으로 축소한다면, t-SNE는 "가까운 것은 가깝게, 먼 것은 멀게" 이웃 관계를 지키며 데이터를 2차원에 펼칩니다. 군집 덩어리를 선명하게 보여주지만, 시각화 전용이라는 뚜렷한 한계도 함께 이해해야 합니다.

`t-SNE` · `비선형 차원축소` · `perplexity` · `이웃 유사도` · `시각화 전용`

## 핵심요약

- t-SNE는 고차원에서의 이웃 유사도(가까운 정도)를 저차원에서도 최대한 보존하도록 점을 재배치하는 비선형 시각화 기법이다.
- PCA는 선형·전역 분산 중심이고, t-SNE는 비선형·국소 군집 중심이라 군집 경계가 더 선명하게 보인다.
- perplexity는 "각 점이 몇 명의 이웃을 고려할지" 정하는 값으로, 그림 모양을 좌우한다(보통 5~50).
- t-SNE는 시각화 전용이라 새 데이터에 `transform`을 적용할 수 없고, 실행마다 결과가 달라질 수 있다.
- t-SNE 그림에서 군집 사이의 거리나 덩어리 크기는 실제 의미로 해석하면 안 된다. 오직 "덩어리가 나뉘는가"만 본다.

## 1. t-SNE의 원리

### 1) 정의

**t-SNE(t-Distributed Stochastic Neighbor Embedding)** 는 고차원 데이터를 2~3차원으로 줄여 시각화하는 비선형 기법입니다. 핵심 아이디어는 "고차원에서 서로 가까운 점들은 저차원에서도 가깝게, 먼 점들은 멀게 배치한다"입니다. 즉 거리 자체가 아니라 **이웃 관계(누가 누구와 가까운가)** 를 보존합니다.

### 2) 왜 필요한가

PCA는 직선 축으로만 데이터를 펼치기 때문에, 곡면 위에 놓이거나 복잡하게 얽힌 구조는 잘 풀어내지 못합니다. 데이터가 비선형으로 뭉쳐 있을 때, PCA 산점도에서는 겹쳐 보이던 군집이 t-SNE에서는 뚜렷하게 갈라지는 경우가 많습니다. 그래서 t-SNE는 특히 **탐색적 데이터 분석(EDA)** 에서 "이 데이터가 대략 몇 덩어리로 나뉘는가"를 눈으로 확인하는 데 강력합니다.

### 3) 핵심 흐름 재구성

t-SNE는 두 단계로 작동합니다.

1. **고차원에서 이웃 확률 계산**: 각 점에 대해 "다른 점이 이웃일 확률"을 거리로부터 구합니다. 가까울수록 확률이 높습니다.
2. **저차원에서 같은 이웃 관계 재현**: 2차원 평면에 점들을 놓고, 저차원에서의 이웃 확률이 고차원의 확률과 최대한 비슷해지도록 점들을 조금씩 움직입니다. 이때 저차원에서는 꼬리가 두꺼운 t-분포를 써서, 먼 점들이 지나치게 뭉치지 않고 군집이 잘 분리되게 합니다.

두 확률 분포의 차이는 **KL divergence** 라는 값으로 재는데, 이 값이 작을수록 고차원의 이웃 관계가 잘 보존된 것입니다.

### 4) 쉬운 예시

파티장에서 사람들의 관계를 사진 한 장에 담는다고 합시다. "친한 사람끼리는 가까이, 모르는 사람끼리는 멀리" 세워 배치하면, 사진만 봐도 친구 그룹이 덩어리로 보입니다. t-SNE가 하는 일이 바로 이 "친밀도 기준 자리 배치"입니다. 단, 사진 속 두 그룹 사이의 실제 거리가 "얼마나 안 친한지"를 정확히 나타내지는 않습니다. 그저 "다른 그룹"이라는 사실만 보여줍니다.

### 5) 코드 예시

```python
from sklearn.manifold import TSNE

tsne = TSNE(
    n_components=2,
    perplexity=30,        # 고려할 이웃 규모
    init='pca',           # 초기 배치를 PCA로 (안정성↑)
    learning_rate='auto',
    random_state=42,
)
X_tsne = tsne.fit_transform(X_scaled)

print('t-SNE 2D shape:', X_tsne.shape)
print('KL divergence(낮을수록 좋음):', round(tsne.kl_divergence_, 3))
```

```text
t-SNE 2D shape: (342, 2)
KL divergence(낮을수록 좋음): 0.373
```

### 코드 목적

4차원 특성을 이웃 관계를 지키며 2차원으로 펼쳐, 군집 덩어리를 눈으로 확인할 수 있게 만드는 것입니다.

### 코드 흐름

1. `perplexity`와 초기화 방식을 정한다.
2. 스케일링된 데이터에 `fit_transform`을 적용해 2차원 좌표를 얻는다.
3. KL divergence로 배치 품질을 확인한다.

### 실행 결과 해석

342개 점이 2차원 좌표로 변환됐고, KL divergence는 0.373으로 낮은 편입니다. 이 값이 작다는 것은 고차원에서의 이웃 관계가 2차원에서도 잘 유지됐다는 뜻입니다. 이 좌표를 산점도로 그리면, 정답(종) 색을 칠하지 않아도 2~3개의 덩어리가 눈에 들어옵니다. 색 없이도 덩어리가 보인다는 것 자체가, 비지도학습이 데이터 구조를 읽어내고 있다는 신호입니다.

### 6) 헷갈리는 점

`init='pca'`로 시작해도 t-SNE는 최적화 과정에 무작위성이 있어, 실행할 때마다 그림이 조금씩 달라질 수 있습니다. `random_state`를 고정하면 같은 결과를 재현할 수 있지만, PCA처럼 "언제나 같은 결정적 변환"은 아니라는 점을 기억해야 합니다.

### 7) 한 줄 정리

> t-SNE는 고차원의 이웃 관계를 저차원에서 재현해, 군집 덩어리를 눈으로 확인하게 해주는 비선형 시각화 도구다.

## 2. PCA vs t-SNE, 그리고 t-SNE의 한계

### 1) 정의

두 기법 모두 차원을 줄이지만 목적과 성질이 다릅니다.

- **PCA**: 선형 기법. 분산이 큰 방향을 축으로 삼아 **전역 구조**를 보존하고, 축에 해석(어떤 특성이 얼마나 기여했는지)이 가능합니다. 새 데이터에 `transform`을 적용할 수 있습니다.
- **t-SNE**: 비선형 기법. **국소 이웃 구조**를 보존해 군집을 선명하게 보여주지만, 축에 의미가 없고 새 데이터에 적용할 수 없습니다.

### 2) 왜 필요한가

"차원을 줄인다"는 같은 목표라도 상황에 따라 적합한 도구가 다릅니다. 모델의 입력 특성을 줄이거나 새 데이터에도 같은 변환을 적용해야 한다면 PCA가 맞고, 데이터를 눈으로 살펴보며 군집 개수를 가늠하는 탐색 단계라면 t-SNE가 맞습니다. 둘의 성격을 알아야 잘못된 도구를 고르지 않습니다.

### 3) 핵심 흐름 재구성

t-SNE의 한계는 시험·면접에서 자주 묻는 부분이라 명확히 정리해 둘 필요가 있습니다.

- **새 데이터 transform 불가**: t-SNE는 `fit`한 데이터의 좌표만 만듭니다. 나중에 들어온 새 샘플을 같은 좌표계에 넣는 `transform`이 없습니다. 그래서 "학습된 변환 함수"로 재사용할 수 없습니다.
- **재현성 제약**: 최적화에 무작위성이 있어 실행마다 그림이 달라질 수 있습니다.
- **거리·크기 해석 금지**: t-SNE 그림에서 군집 사이의 거리가 멀다고 "매우 다른 그룹"이라 단정하거나, 덩어리가 크다고 "데이터가 많다"고 해석하면 안 됩니다. 국소 이웃만 보존할 뿐 전역 거리는 신뢰할 수 없기 때문입니다.
- **하이퍼파라미터 민감성**: perplexity나 학습률에 따라 모양이 크게 바뀝니다.

### 4) 쉬운 예시

t-SNE 그림은 지하철 노선도와 비슷합니다. 노선도는 역의 연결 관계(순서·이웃)는 정확히 보여주지만, 역 사이의 실제 물리적 거리는 왜곡돼 있습니다. t-SNE도 "누가 누구와 한 덩어리인가"는 잘 보여주지만, 덩어리 사이 거리는 실제 척도가 아닙니다.

### 5) 코드 예시

PCA와 t-SNE 결과를 나란히 그려 성격 차이를 봅니다.

```python
import matplotlib.pyplot as plt

fig, axes = plt.subplots(1, 2, figsize=(12, 5))
for ax, data, title in zip(axes, [X_pca2, X_tsne],
                           ['PCA (선형·전역)', 't-SNE (비선형·국소)']):
    ax.scatter(data[:, 0], data[:, 1], alpha=0.7, s=40, c='teal',
               edgecolors='white', linewidth=0.3)
    ax.set_title(title)
plt.show()
```

### 실행 결과 해석

PCA 산점도는 데이터의 전체적 퍼짐(전역 분산)을 보여주지만 군집 경계가 다소 겹쳐 보일 수 있습니다. t-SNE 산점도는 같은 데이터인데도 덩어리가 더 또렷하게 갈라져 보입니다. 이것이 "EDA에서 군집을 눈으로 확인할 때는 t-SNE, 재사용 가능한 축소·전처리에는 PCA"라는 실무 기준의 근거입니다.

### 6) 헷갈리는 점

t-SNE가 군집을 더 선명하게 보여준다고 해서 "더 좋은 알고리즘"인 것은 아닙니다. 선명함은 국소 구조를 강조한 결과일 뿐, 그 대가로 전역 거리 정보와 재사용성을 잃습니다. 목적이 다른 도구이지 우열 관계가 아닙니다.

### 7) 한 줄 정리

> PCA는 해석 가능하고 재사용되는 선형 축소, t-SNE는 군집을 선명하게 보여주지만 시각화 전용인 비선형 축소다.

## 코드로 보기 — 색 없이 구조 확인하기

```python
import matplotlib.pyplot as plt

fig, ax = plt.subplots(figsize=(7, 5.5))

ax.set_xlabel('t-SNE 1'); ax.set_ylabel('t-SNE 2')
ax.set_title('t-SNE 2D (정답 색 없음)')

```

### 코드 목적

정답 레이블 색을 전혀 칠하지 않고 t-SNE 좌표만 그려, "정답 없이도 덩어리가 보이는가"를 확인합니다.

### 코드 흐름

1. t-SNE로 얻은 2차원 좌표를 준비한다.
2. 모든 점을 같은 색으로 산점도를 그린다.
3. 눈으로 덩어리 개수를 가늠한다.

### 실행 결과 해석

한 가지 색으로만 그렸는데도 2~3개의 덩어리가 구분돼 보이면, 데이터 자체에 구조가 있다는 뜻입니다. 이 "몇 덩어리로 보이는가"라는 눈어림은 이후 [K-Means에서 K를 정할 때](04-kmeans-and-elbow.md)의 좋은 출발점이 됩니다. 실제 정답과 맞는지는 [마지막 검증 단계](07-full-pipeline-and-evaluation.md)에서 확인합니다.

### 실무 연결

고차원 임베딩(이미지·텍스트·사용자 벡터)을 t-SNE로 펼쳐 보는 것은 실무 EDA의 단골 작업입니다. "우리 사용자가 대략 몇 유형으로 나뉘는가"를 빠르게 눈으로 가늠할 때 유용합니다. 단, 그 결과를 모델 입력으로 재사용하려 하면 안 됩니다. 그 용도는 PCA나 오토인코더의 몫입니다.
