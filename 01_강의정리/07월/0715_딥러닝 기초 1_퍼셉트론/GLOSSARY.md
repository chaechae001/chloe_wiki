| 머신러닝(ML) | 규칙을 사람이 적는 대신, 데이터에서 판단 기준을 찾아내게 하는 방법 | [01](01-deep-learning-intro.md) | 인공지능, 딥러닝 |
| 딥러닝(DL) | 머신러닝 중 신경망을 여러 겹 쌓는 갈래. 판단 기준뿐 아니라 "무엇을 볼지"까지 스스로 만듦 | [01](01-deep-learning-intro.md) | 은닉층, 인공신경망 |
| 인공신경망(ANN) | 생물학의 뉴런 연결에서 아이디어를 빌린 학습 구조. 입력층·은닉층·출력층으로 이뤄짐 | [01](01-deep-learning-intro.md) | 퍼셉트론, 은닉층 |
| AI 겨울 | 기대가 꺾이며 연구 투자와 관심이 급감한 침체기. 아이디어의 실패가 아니라 조건의 부재였음 | [04](04-xor-problem-and-single-layer-limits.md) | XOR, 역전파 |

## 퍼셉트론 구성 요소

| 용어 | 쉬운 설명 | 관련 글 | 함께 보면 좋은 개념 |
| ---- | --------- | ------- | ------------------- |
| 퍼셉트론(Perceptron) | 뉴런 하나를 숫자로 옮긴 가장 작은 계산 단위. 입력에 가중치를 곱해 더하고 임계값을 넘는지 봄 | [02](02-perceptron-structure.md) | 가중치, 활성화 함수 |
| 가중치(Weight, $w$) | 각 입력을 얼마나 신뢰할지 정하는 숫자. 근거마다 매기는 비중이라고 보면 됨 | [02](02-perceptron-structure.md) | 편향, 가중합 |
| 편향(Bias, $b$) | 얼마나 쉽게 반응할지를 정하는 숫자. 판정선의 위치를 좌우로 밀어 줌 | [02](02-perceptron-structure.md) | 가중치, 결정 경계 |
| 가중합($z$) | 입력×가중치를 모두 더하고 편향을 얹은 값. 판단 이전의 "점수"에 해당 | [02](02-perceptron-structure.md) | 활성화 함수 |
| 활성화 함수 | 가중합이라는 점수를 실제 출력으로 바꾸는 장치. 신경망에 비선형성을 넣는 역할도 함 | [02](02-perceptron-structure.md) | Step, Sigmoid |
| Step(계단) 함수 | 가중합이 0 이상이면 1, 아니면 0을 내보내는 가장 단순한 활성화 함수 | [02](02-perceptron-structure.md) | 활성화 함수, 편향 |

## 논리 게이트와 선형 분류

| 용어 | 쉬운 설명 | 관련 글 | 함께 보면 좋은 개념 |
| ---- | --------- | ------- | ------------------- |
| 논리 게이트 | 0과 1을 받아 정해진 규칙대로 0 또는 1을 내놓는 가장 단순한 판단 장치. 퍼셉트론이 판단을 흉내 내는지 확인하는 시험 문제로 쓰임 | [03](03-logic-gates-and-linear-classifier.md) | AND·OR·NAND·NOR |
| AND·OR·NAND·NOR | 둘 다 1이어야 1인 것이 AND, 하나라도 1이면 1인 것이 OR, 그 둘의 결과를 각각 뒤집은 것이 NAND·NOR | [03](03-logic-gates-and-linear-classifier.md) | 논리 게이트, XOR |
| 결정 경계(Decision Boundary) | 0으로 판정할 영역과 1로 판정할 영역을 가르는 선. 단층 퍼셉트론에서는 항상 직선 | [03](03-logic-gates-and-linear-classifier.md) | 선형 분류기 |
| 선형 분류기 | 직선(고차원에서는 평면) 하나로 두 부류를 나누는 분류기. 단층 퍼셉트론이 여기 해당 | [03](03-logic-gates-and-linear-classifier.md) | 결정 경계, XOR |
| 선형 분리 가능(Linearly Separable) | 직선 하나로 두 부류를 완전히 갈라낼 수 있는 상태. 단층 퍼셉트론의 능력 한계선 | [04](04-xor-problem-and-single-layer-limits.md) | XOR, 선형 분류기 |
| XOR | 두 입력이 서로 다를 때만 1을 내는 게이트. 정답이 대각선으로 엇갈려 직선 하나로는 못 나눔 | [04](04-xor-problem-and-single-layer-limits.md) | 선형 분리 가능, 은닉층 |

## 다층 신경망

| 용어 | 쉬운 설명 | 관련 글 | 함께 보면 좋은 개념 |
| ---- | --------- | ------- | ------------------- |
| 단층 퍼셉트론 | 입력층과 출력층만 있는 한 겹짜리 구조. 직선 하나로 풀리는 문제만 해결 가능 | [04](04-xor-problem-and-single-layer-limits.md) | 다층 퍼셉트론 |
| 다층 퍼셉트론(MLP) | 퍼셉트론을 여러 층으로 쌓은 구조. 은닉층 덕분에 직선으로 안 되던 비선형 문제도 풀 수 있음 | [05](05-mlp-hidden-layer.md) | 은닉층, 딥러닝 |
| 은닉층(Hidden Layer) | 입력층과 출력층 사이에 끼워 넣는 중간 층. 입력을 직선으로 나눌 수 있는 새 좌표계로 옮겨 줌 | [05](05-mlp-hidden-layer.md) | MLP, 깊이 |
| 깊이(Depth) | 은닉층이 몇 겹인지를 뜻함. 은닉층이 늘수록 만들 수 있는 결정 영역이 넓어지고, 3층 이상이면 딥러닝이라 부름 | [05](05-mlp-hidden-layer.md) | 딥러닝, 은닉층 |
| 비선형성(Non-linearity) | 직선만으로는 표현할 수 없는 관계. 활성화 함수가 없으면 층을 쌓아도 결국 직선 하나와 같아짐 | [05](05-mlp-hidden-layer.md) | 활성화 함수, XOR |

## PyTorch와 학습

| 용어 | 쉬운 설명 | 관련 글 | 함께 보면 좋은 개념 |
| ---- | --------- | ------- | ------------------- |
| 텐서(Tensor) | 숫자 배열에 계산 이력까지 함께 들고 다니는 자료구조. 자동미분의 재료가 됨 | [06](06-pytorch-mlp-training.md) | Autograd |
| Autograd(자동미분) | 계산 이력을 거꾸로 훑어 "가중치를 어느 쪽으로 옮겨야 오차가 줄지"를 자동으로 알려 주는 기능 | [06](06-pytorch-mlp-training.md) | 역전파, 학습 루프 |
| 역전파(Backpropagation) | 출력의 오차를 뒤에서 앞으로 되돌려 각 층의 가중치를 어떻게 고칠지 계산하는 방법 | [06](06-pytorch-mlp-training.md) | Autograd, 학습 루프 |
| `nn.Module` | 모델을 만들 때 상속하는 기본 클래스. 안에 넣은 층과 파라미터가 학습 대상으로 자동 등록됨 | [06](06-pytorch-mlp-training.md) | 텐서, 학습 루프 |
| Sigmoid | 어떤 값이든 0과 1 사이로 눌러 주는 활성화 함수. Step과 달리 매끄러워 미분이 가능함 | [06](06-pytorch-mlp-training.md) | Step 함수, BCE |
| 손실 함수(Loss) / BCE | 예측이 정답에서 얼마나 벗어났는지를 한 숫자로 요약하는 함수가 손실 함수이고, 그중 0/1 이진 분류에 쓰는 것이 BCE. 확신에 찬 오답일수록 더 큰 벌점을 매김 | [06](06-pytorch-mlp-training.md) | Sigmoid, 학습 루프 |
| 학습 루프 | 순전파 → 손실 계산 → 역전파 → 가중치 갱신을 반복하는 학습의 기본 골격 | [06](06-pytorch-mlp-training.md) | 역전파, zero_grad |
| `zero_grad()` | 기울기가 이전 반복 값과 더해지지 않도록 매 반복 앞에서 비워 주는 호출 | [06](06-pytorch-mlp-training.md) | 학습 루프, 역전파 |
