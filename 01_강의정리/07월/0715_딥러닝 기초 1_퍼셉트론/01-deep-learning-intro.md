# 딥러닝 개론 — 지도부터 펴고 시작하기

> 딥러닝은 갑자기 등장한 마법이 아니라, 인공지능이라는 큰 땅 안에서 60년 넘게 오르내린 한 갈래입니다. 이 글은 AI·머신러닝·딥러닝이 어떻게 겹쳐 있는지, 신경망이 왜 "층"으로 되어 있는지, 왜 겨울이 두 번이나 왔는지를 정리합니다.

`인공지능` · `머신러닝` · `딥러닝` · `인공신경망` · `은닉층`

## 핵심요약

- 인공지능 ⊃ 머신러닝 ⊃ 딥러닝의 포함 관계이며, 안으로 들어갈수록 사람이 손으로 하던 일이 더 많이 자동화된다.
- 머신러닝은 "판단 기준"을 데이터에서 찾고, 딥러닝은 거기에 더해 "무엇을 볼지(특징)"까지 스스로 만든다.
- 인공신경망은 생물학의 뉴런 시스템에서 아이디어를 빌린 학습 알고리즘으로, 입력층·은닉층·출력층으로 구성된다.
- "깊다(deep)"는 은닉층을 여러 겹 쌓았다는 뜻이며, 층을 쌓을수록 표현력과 파라미터 수가 함께 늘어난다.
- 역사는 1958년 등장 → 1969년 한계 증명으로 첫 겨울 → 1986년 역전파로 부흥 → 1990년대 두 번째 겨울 → 2010년대 재부흥의 흐름을 따른다.

## 1. 인공지능 · 머신러닝 · 딥러닝의 포함 관계

### 1) 정의

세 단어는 나란한 경쟁 개념이 아니라 겹겹이 포개진 동심원입니다. **인공지능(AI)** 은 기계가 지능적으로 행동하게 만드는 분야 전체이고, 그 안의 **머신러닝(ML)** 은 데이터로부터 규칙을 학습하는 방법이며, 다시 그 안의 **딥러닝(DL)** 은 인공신경망을 깊게 쌓는 방법론입니다. 딥러닝은 머신러닝의 여러 방법론 가운데 하나이며, 인공신경망에 기반해 컴퓨터에게 사람의 사고방식을 가르치는 방법입니다.

### 2) 왜 필요한가

이 구분이 중요한 이유는 **모든 문제에 딥러닝이 정답은 아니기 때문**입니다. 표 형태의 정형 데이터에서 고객 이탈을 예측하는 일이라면 트리 기반 머신러닝이 더 빠르고 정확한 경우가 많습니다. 반대로 사진 속 얼굴, 음성, 문장처럼 "무엇을 특징으로 삼아야 할지조차 사람이 말로 못 적는" 데이터에서는 딥러닝이 압도적입니다. 세 개념의 위치를 알아야 문제를 보고 도구를 고를 수 있습니다.

### 3) 핵심 흐름 재구성

세 단계를 가르는 기준은 "**사람이 어디까지 손으로 적어야 하는가**"입니다. 안쪽 원으로 들어갈수록 사람의 개입이 줄고, 대신 필요한 데이터의 양과 연산량이 늘어납니다.

| 단계 | 사람이 하는 일 | 기계가 하는 일 |
|---|---|---|
| 규칙 기반 AI | 판단 규칙을 전부 직접 작성 | 작성된 규칙을 그대로 실행 |
| 머신러닝 | 무엇을 볼지(특징)를 설계 | 그 특징으로 판단 기준을 학습 |
| 딥러닝 | 데이터와 목표만 제시 | 특징 추출과 판단 기준을 모두 학습 |

### 4) 쉬운 예시

광고성 메일을 걸러내는 일을 떠올려 봅시다. 규칙 기반이라면 "무료, 당첨, 한정특가 같은 단어가 있으면 광고"라고 목록을 직접 적어야 하고, 새로운 표현이 등장할 때마다 사람이 목록을 고쳐야 합니다. 머신러닝은 단어 목록은 사람이 정하되 "몇 개 이상이면 광고인가"라는 경계선을 데이터에서 찾습니다. 딥러닝은 한 걸음 더 나아가, 어떤 단어 조합이 광고를 나타내는지까지 스스로 뽑아냅니다.

### 5) 코드 예시

사람이 규칙을 적는 방식과 데이터에서 기준을 찾는 방식이 어떻게 갈리는지 최소 예제로 비교해 봅니다.

```python
import numpy as np

samples = [('무료 쿠폰 당첨', 1), ('내일 일정 공유', 0), ('한정특가 마지막 기회', 1),
           ('회의 시간 변경 안내', 0), ('경품 이벤트 참여', 1), ('분기 실적 정리', 0)]

# (1) 사람이 규칙을 직접 적는 방식
rule = lambda t: int(any(k in t for k in ['무료', '당첨', '한정특가']))
# (2) 특징을 세고, 판단 경계선만 데이터에서 고르는 방식
feat = lambda t: sum(t.count(v) for v in ['무료', '당첨', '한정특가', '경품', '이벤트'])
print(f'규칙 방식 정확도: {np.mean([rule(x) == l for x, l in samples]):.2f}')
for t in range(1, 4):
    print(f'임계값 {t} 학습 시 정확도: {np.mean([(feat(x) >= t) == bool(l) for x, l in samples]):.2f}')
```

```text
규칙 방식 정확도: 0.83
임계값 1 학습 시 정확도: 1.00
임계값 2 학습 시 정확도: 0.83
임계값 3 학습 시 정확도: 0.50
```

규칙 방식은 정확도 0.83에 그쳤습니다. `경품 이벤트 참여`가 광고인데도 사람이 적어 둔 단어 목록에 그 표현이 없어 놓쳤기 때문입니다. 반면 임계값을 데이터에서 고르는 방식은 임계값 1에서 정확도 1.00을 얻었습니다. 다만 여기서도 단어 목록 자체는 여전히 사람이 정했다는 점이 머신러닝의 한계이고, 그 목록까지 기계가 만들게 하는 것이 딥러닝입니다.

### 6) 헷갈리는 점

"딥러닝이 머신러닝보다 항상 좋다"는 오해가 가장 흔합니다. 딥러닝은 데이터가 적으면 오히려 불리하고, 학습 시간과 연산 자원도 훨씬 많이 씁니다. "AI = 딥러닝"으로 붙여 쓰는 습관도 위험합니다. 규칙 기반 전문가 시스템, 탐색 알고리즘도 모두 인공지능입니다.

### 7) 한 줄 정리

> 인공지능은 목표, 머신러닝은 그 목표를 데이터로 달성하는 방법, 딥러닝은 그중 신경망을 깊게 쌓는 갈래다.

## 2. 인공신경망과 층 구조

### 1) 정의

인공신경망은 생물학의 신경망에서 영감을 얻어 사람의 신경 시스템을 모방한 학습 알고리즘입니다. 두뇌의 가장 작은 정보처리 단위인 뉴런이 여러 갈래로 신호를 받아 하나의 신호를 내보내듯, 인공 뉴런도 여러 입력을 받아 하나의 출력을 내놓습니다.

### 2) 왜 필요한가

뉴런 하나가 하는 일은 단순합니다. 그런데 뉴런을 층으로 쌓고 서로 연결하면, 하나로는 표현하지 못하던 복잡한 판단이 가능해집니다. 구조를 이해해야 "왜 층을 늘리는가", "은닉층은 무엇을 하는가"에 답할 수 있고, 이후 다층 퍼셉트론으로 넘어갈 때 길을 잃지 않습니다.

### 3) 핵심 흐름 재구성

생물학적 뉴런에서 빌려 온 아이디어는 세 가지입니다. 여러 갈래의 입력을 받고(입력 $x_1, x_2, \dots$), 연결마다 신호가 전달되는 강도가 다르며(가중치 $w_1, w_2, \dots$), 신호의 합이 일정 수준을 넘어야 발화한다(활성화 함수의 임계값)는 것입니다. 이 뉴런들을 역할별로 묶은 것이 층(layer)입니다.

```text
[Input Layer]     [Hidden Layer]     [Output Layer]
   x1 ────┐      ┌── h1 ──┐
          ├──────┼── h2 ──┼──────────►    y
   x2 ────┘      └── h3 ──┘
 데이터를 받는 곳   중간 표현을 만드는 곳   최종 판단을 내는 곳
```

**입력층**은 데이터를 그대로 받는 자리로, 계산을 하지 않아 보통 층 수에 세지 않습니다. **은닉층**은 입력을 조합해 새로운 표현을 만드는 자리이며, 사람 눈에 직접 보이지 않아 "은닉"입니다. **출력층**은 최종 결과를 내는 자리로, 회귀면 숫자 하나, 이진 분류면 판정 하나를 내놓습니다.

여기서 "깊다(deep)"는 은닉층이 여러 겹이라는 뜻입니다. 은닉층이 없으면 단층, 하나면 얕은 신경망, 여러 개면 깊은 신경망입니다. 인공신경망은 모델 스스로 데이터의 특성을 학습하기 때문에 회귀 분석, 분류, 패턴 파악처럼 지도학습과 비지도학습 양쪽에 모두 적용할 수 있습니다.

### 4) 쉬운 예시

회사의 결재 라인을 떠올려 봅시다. 현장 담당자들이 각자 자료를 올리면(입력층), 팀장들이 그것을 자기 관점으로 요약합니다(은닉층). 임원은 팀장의 요약만 보고 최종 결정을 내립니다(출력층). 팀장 단계를 여러 겹으로 두면 더 정교한 요약이 가능하지만 시간과 비용도 함께 늘어납니다. 신경망의 깊이도 정확히 같은 절충입니다.

### 5) 코드 예시

인공 뉴런 하나가 하는 계산을 그대로 옮기면 놀랄 만큼 단순합니다.

```python
import numpy as np

x = np.array([2.0, 3.0])    # 입력 두 개
w = np.array([0.5, -1.0])   # 연결 강도
b = 1.0                     # 편향
z = float(x @ w + b)        # 가중합: 0.5*2 + (-1.0)*3 + 1.0
y = 1 if z >= 0 else 0      # 임계값을 넘으면 발화
print(f'가중합 z = {z:+.1f}, 출력 y = {y}')   # 가중합 z = -1.0, 출력 y = 0
```

가중합이 $-1.0$으로 0보다 작으니 이 뉴런은 발화하지 않았습니다. 두 번째 입력의 가중치가 $-1.0$으로 음수라 입력값 3이 오히려 결과를 강하게 끌어내렸기 때문입니다.

### 6) 헷갈리는 점

은닉층의 뉴런 개수와 층 수를 혼동하기 쉽습니다. 층 수는 "몇 단계를 거치는가"(깊이), 뉴런 개수는 "한 단계에서 몇 갈래로 보는가"(너비)입니다. 또 입력층은 계산을 하지 않으므로 "3층 신경망"이라고 하면 보통 은닉층 2개 + 출력층 1개를 뜻합니다.

### 7) 한 줄 정리

> 인공신경망은 단순한 뉴런을 층으로 쌓아 복잡한 판단을 만들어내는 구조이며, 깊이는 은닉층의 겹 수를 뜻한다.

## 3. 딥러닝의 역사 — 두 번의 겨울과 두 번의 부흥

### 1) 정의

딥러닝의 역사는 "기대 → 한계 발견 → 침체 → 돌파구 → 재부흥"이 두 번 반복된 흐름입니다.

| 시기 | 사건 | 방향 |
|---|---|---|
| 1958 | 퍼셉트론 등장 (Rosenblatt, 1958) | 부흥 |
| 1969 | 단층 퍼셉트론의 한계 증명 (Minsky & Papert, 1969) | 첫 번째 겨울 |
| 1986 | 역전파 알고리즘 재조명 (Rumelhart, Hinton & Williams, 1986) | 부흥 |
| 1990년대 | 학습 난이도·데이터·연산력 한계 | 두 번째 겨울 |
| 2012~ | 대규모 데이터와 GPU로 재부흥 (Krizhevsky et al., 2012), 이후 대규모 모델 시대 | 부흥 |

### 2) 왜 필요한가

역사를 아는 것은 교양이 아니라 **개념의 순서를 이해하는 지름길**입니다. 왜 활성화 함수를 배우고 나서 곧바로 XOR 문제를 다루는지, 왜 은닉층이 등장하는지, 왜 역전파가 그토록 중요한지가 모두 이 타임라인 위에 놓여 있습니다.

### 3) 핵심 흐름 재구성

**첫 번째 겨울(1969)** 은 퍼셉트론이 부족해서가 아니라 **단층 퍼셉트론이 직선 하나로만 데이터를 나눌 수 있다**는 사실이 수학적으로 증명되었기 때문에 왔습니다. 직선 하나로는 XOR처럼 대각선으로 엇갈린 문제를 절대 풀 수 없습니다. **첫 번째 부흥(1986)** 은 은닉층을 쌓으면 XOR도 풀린다는 사실보다, **쌓은 층의 가중치를 어떻게 조정할지**에 대한 답인 역전파가 널리 알려지면서 시작되었습니다. 층이 여러 개면 오차의 책임을 어느 가중치에 얼마나 물어야 할지가 문제인데, 역전파가 그것을 미분의 연쇄법칙으로 풀었습니다.

**두 번째 겨울(1990년대)** 은 이론은 있으나 현실이 못 따라온 시기입니다. 층을 깊게 쌓으면 학습 신호가 뒤로 갈수록 사라지고(기울기 소실), 데이터도 연산 자원도 부족했습니다. **두 번째 부흥(2010년대)** 은 알고리즘 하나가 아니라 인터넷이 만든 대규모 데이터, 병렬 연산을 감당하는 GPU, 깊은 망을 학습시키는 기법이 동시에 갖춰지면서 왔습니다. 정리하면, **겨울은 아이디어의 실패가 아니라 그 아이디어를 실현할 조건이 아직 없었기 때문**에 왔습니다.

### 4) 쉬운 예시

전기차의 역사와 닮았습니다. 전기차 아이디어는 100년 전에도 있었지만 배터리 성능이 받쳐 주지 못해 사라졌습니다. 아이디어가 틀린 게 아니라 조건이 안 갖춰졌던 것이고, 배터리가 좋아지자 다시 주류가 되었습니다. 딥러닝에서 배터리에 해당하는 것이 데이터와 연산력입니다.

### 5) 코드 예시

"깊게 쌓는다"는 말이 계산량으로 무엇을 뜻하는지 파라미터 개수로 확인해 봅니다.

```python
def param_count(layers):
    # 인접한 두 층 사이의 가중치 수 + 편향 수를 모두 더한다
    return sum(a * b + b for a, b in zip(layers[:-1], layers[1:]))

for layers in [[2, 1], [2, 3, 1], [2, 64, 64, 64, 1]]:
    name = '-'.join(map(str, layers))
    print(f'{name:>14} | 층 {len(layers)-1}개 | 파라미터 {param_count(layers):>5}개')
```

```text
           2-1 | 층 1개 | 파라미터     3개
         2-3-1 | 층 2개 | 파라미터    13개
  2-64-64-64-1 | 층 4개 | 파라미터  8577개
```

층을 1개에서 4개로 늘렸을 뿐인데 조정해야 할 숫자는 3개에서 8,577개로 늘었습니다. 1990년대에 두 번째 겨울이 온 이유가 이 표에 담겨 있습니다. 표현력은 커지지만, 그만큼 많은 숫자를 조정할 데이터와 연산력이 없으면 학습이 되지 않습니다.

### 6) 헷갈리는 점

AI 겨울이 "퍼셉트론이 쓸모없어서" 온 것으로 오해하기 쉽습니다. 정확히는 **단층 퍼셉트론의 표현력 한계**가 증명된 것이고, 다층으로 쌓으면 그 한계는 사라집니다. 다만 당시에는 다층을 학습시킬 방법이 정립되지 않았던 것이 진짜 문제였습니다.

### 7) 한 줄 정리

> 딥러닝의 겨울은 아이디어의 실패가 아니라 조건의 부재였고, 조건이 갖춰지자 같은 아이디어가 다시 살아났다.

## 코드로 보기 — 데이터가 층을 통과하며 모양이 어떻게 변하는가

```python
import numpy as np
np.random.seed(4)
step = lambda z: (z >= 0).astype(float)

W1, b1 = np.random.randn(2, 3), np.random.randn(3)  # 입력 2 -> 은닉 3
W2, b2 = np.random.randn(3, 1), np.random.randn(1)  # 은닉 3 -> 출력 1
X = np.array([[0., 0.], [0., 1.], [1., 0.], [1., 1.]])

h = step(X @ W1 + b1)   # 은닉층 통과
y = step(h @ W2 + b2)   # 출력층 통과
print(f'shape 변화: {X.shape} -> {h.shape} -> {y.shape}')
for xi, hi, yi in zip(X, h, y):
    print(f'입력 {xi.astype(int)} -> 은닉 {hi.astype(int)} -> 출력 {int(yi[0])}')
```

```text
shape 변화: (4, 2) -> (4, 3) -> (4, 1)
입력 [0 0] -> 은닉 [0 1 1] -> 출력 1
입력 [0 1] -> 은닉 [1 1 0] -> 출력 0
입력 [1 0] -> 은닉 [0 1 0] -> 출력 1
입력 [1 1] -> 은닉 [1 1 0] -> 출력 0
```

### 코드 목적

층 구조가 실제 계산에서 무엇을 뜻하는지, 즉 데이터가 각 층을 지날 때마다 모양(shape)이 어떻게 바뀌는지를 눈으로 확인합니다.

### 코드 흐름

1. 입력 2개 → 은닉 3개 → 출력 1개 구조의 가중치를 무작위로 만든다.
2. 입력 4건을 은닉층에 통과시켜 중간 표현을 얻고, 다시 출력층에 통과시켜 최종 판단을 얻는다.
3. 각 단계의 shape과 값을 비교한다.

### 실행 결과 해석

입력은 `(4, 2)`, 은닉층을 지나면 `(4, 3)`, 출력층을 지나면 `(4, 1)`이 됩니다. **행(4)은 데이터 건수라 끝까지 변하지 않고, 열은 그 층의 뉴런 개수를 따라 2 → 3 → 1로 바뀝니다.** 이것이 "층을 통과한다"는 말의 실체입니다. 값을 보면 이 망은 두 번째 입력이 0일 때만 1을 내놓고 있는데(`(0,0)`과 `(1,0)`에서 출력 1), 사람이 의도한 규칙이 아니라 무작위 가중치가 우연히 만든 판단입니다. 게다가 은닉층의 두 번째 값은 네 경우 모두 1로 고정되어 아무 정보도 전달하지 못합니다. **구조를 갖췄다고 유용한 함수가 되는 것이 아니며, 가중치를 데이터에 맞게 조정하는 학습 과정이 반드시 필요하다**는 점을 이 결과가 보여 줍니다.

### 실무 연결

실무에서 모델을 만들 때 가장 자주 마주치는 오류가 shape 불일치입니다. 층마다 입력 차원과 출력 차원을 손으로 따라가며 맞춰 보는 습관은 이미지 분류, 텍스트 분류, 추천 시스템 어디에서든 그대로 쓰입니다. 또 "층을 늘리면 성능이 오른다"는 기대는 파라미터 수와 데이터 양의 균형을 함께 봐야 합니다.
