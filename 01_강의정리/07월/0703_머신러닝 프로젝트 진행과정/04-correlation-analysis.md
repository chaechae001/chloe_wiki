# 상관관계 분석

> 어떤 변수가 예측에 도움이 되고, 어떤 변수끼리 겹치는지 한눈에 보는 방법.

`상관관계` · `피어슨` · `heatmap` · `pairplot` · `다중공선성`

## 핵심요약

- 상관관계는 두 변수 간 관계의 방향과 강도를 나타내는 통계 개념이다.
- 상관계수는 -1에서 1 사이 값을 가지며, 0은 관계 없음을 뜻한다.
- `.corr()`로 상관계수 행렬을 구하고 heatmap으로 시각화한다.
- pairplot은 변수 쌍의 산점도를 한 번에 그려 관계를 눈으로 확인한다.
- 상관관계 분석은 중복 변수(다중공선성)를 찾고 모델 선택 방향을 잡는 데 쓴다.

## 1. 상관관계란

### 1) 정의

**상관관계(Correlation)**는 한 변수가 변할 때 다른 변수가 어떻게 함께 변하는지를 나타냅니다. 상관계수 $r$은 다음 범위를 가집니다.

$$-1 \leq r \leq 1$$

| 값 | 의미 |
|----|------|
| $r = 1$ | 완전한 양의 상관관계 (같이 증가) |
| $r = 0$ | 독립 (관계 없음) |
| $r = -1$ | 완전한 음의 상관관계 (하나 늘면 다른 하나 줄어듦) |

### 2) 왜 필요한가

- 예측 대상과 상관이 높은 변수를 찾아 중요한 특성을 파악합니다.
- 서로 상관이 매우 높은 두 변수는 중복(다중공선성)이므로 하나를 제거할 수 있습니다.
- 결과를 바탕으로 어떤 모델이 적합할지 방향을 잡습니다.

### 3) 핵심 흐름 재구성

수치로 확인할 때는 `.corr()`로 상관계수 행렬을 만들고, 시각적으로 확인할 때는 heatmap과 pairplot을 씁니다. 가장 흔히 쓰는 방식은 **피어슨 상관계수**로, 두 변수의 선형 관계 강도를 잽니다. 이 밖에 kendall, spearman 같은 방식도 있습니다.

### 4) 쉬운 예시

키와 몸무게는 대체로 함께 커지므로 양의 상관관계입니다. 반대로 운동 시간과 체지방률은 하나가 늘면 다른 하나가 줄어드는 경향이 있어 음의 상관관계에 가깝습니다. 상관계수가 0에 가깝다면 두 변수는 서로 별 관계가 없다는 뜻입니다.

### 5) 헷갈리는 점

상관관계는 **인과관계가 아닙니다**. 아이스크림 판매와 익사 사고가 함께 늘어난다고 해서 아이스크림이 익사를 유발하는 것이 아닙니다. 둘 다 "여름"이라는 숨은 요인의 영향을 받을 뿐입니다.

### 6) 한 줄 정리

> 상관관계는 두 변수가 얼마나 함께 움직이는지를 -1에서 1 사이 숫자로 요약한다.

## 2. heatmap과 pairplot

### 1) 정의

- **heatmap**: 상관계수 행렬을 색으로 표현해 어떤 변수 쌍이 강하게 연관되는지 한눈에 보여줍니다.
- **pairplot**: 모든 수치형 변수 쌍의 산점도를 격자로 그려 관계의 모양을 직접 보여줍니다.

### 2) 왜 필요한가

숫자 행렬만 보면 값이 많아 한눈에 안 들어옵니다. 색과 그림으로 바꾸면 강한 관계와 약한 관계가 즉시 구분됩니다.

### 3) 코드 예시

```python
import seaborn as sns
import matplotlib.pyplot as plt

# 수치형 변수만 선택해 피어슨 상관계수 행렬 계산
numeric_df = df.select_dtypes(include='number')
corr = numeric_df.corr(method='pearson')

# heatmap: 각 셀에 상관계수 값 표시
sns.heatmap(corr, annot=True, fmt='.2f', cmap='coolwarm', vmin=-1, vmax=1)
plt.show()

# pairplot: 변수 쌍의 산점도 격자
sns.pairplot(df[['total_bill', 'tip', 'size']])
plt.show()
```

`.corr(method='pearson')`은 상관계수 행렬을 반환하고, `sns.heatmap(..., annot=True)`은 각 칸에 값을 함께 표시합니다.

### 4) 한 줄 정리

> heatmap은 색으로, pairplot은 산점도로 변수 관계를 직관적으로 드러낸다.

## 코드로 보기 — 상관계수 행렬과 heatmap 읽기

```python
import seaborn as sns
import matplotlib.pyplot as plt

numeric_df = df.select_dtypes(include='number')
corr = numeric_df.corr(method='pearson')

sns.heatmap(corr, annot=True, fmt='.2f', cmap='coolwarm',
            vmin=-1, vmax=1, square=True)
plt.show()
```

### 코드 목적

수치형 변수들 사이의 선형 관계를 한 장의 색상표로 정리해, 중요한 변수와 중복 변수를 찾으려는 코드입니다.

### 코드 흐름

1. 수치형 변수만 골라낸다.
2. `.corr()`로 상관계수 행렬을 만든다.
3. heatmap으로 시각화한다.
4. 예측 대상과 상관이 높은 변수, 서로 겹치는 변수를 읽는다.

### 실행 결과 해석

대각선은 항상 1입니다(자기 자신과의 상관). 색이 진한 빨강이면 강한 양의 상관, 진한 파랑이면 강한 음의 상관입니다. 예측하려는 변수의 행(또는 열)을 따라가며 값이 큰 변수를 찾으면, 그 변수가 예측에 중요할 가능성이 높습니다. 반대로 두 특성이 서로 0.9처럼 매우 높으면 중복이므로 하나만 남기는 것을 고려합니다.

### 실무 연결

마케팅 분석에서 어떤 지표가 매출과 연관되는지 파악하거나, 모델 입력 변수를 줄여 과적합을 방지할 때 이 분석을 씁니다. 중복 변수를 걸러내면 모델이 단순하고 안정적이 됩니다.

## 헷갈리기 쉬운 포인트

| 헷갈리는 개념 | 차이 |
|---|---|
| 상관관계 vs 인과관계 | 함께 움직이면 상관, 원인-결과가 있으면 인과. 상관이 인과를 보장하지 않음 |
| 양의 상관 vs 음의 상관 | 같이 커지면 양(+), 하나 커질 때 다른 하나 작아지면 음(−) |
| heatmap vs pairplot | 색으로 상관계수를 요약 vs 산점도로 관계 모양을 직접 표시 |
| 피어슨 vs 스피어만 | 선형 관계 측정 vs 순위(단조) 관계 측정 |
