# 특성 엔지니어링

> 새 데이터를 더 모으지 않고도, 이미 가진 데이터를 모델이 쓰기 좋게 다듬으면 성능이 올라간다.

`특성 생성` · `바이닝` · `더미 변환` · `스케일링` · `전처리`

## 핵심요약

- 특성 엔지니어링은 새 관측치를 추가하지 않고 **기존 데이터를 더 유용하게** 가공하는 방법이다.
- 대표 기법은 특성 생성, 특성 선택, 바이닝, 더미 변환, 스케일링이다.
- 바이닝은 연속형을 범주형으로, 더미 변환은 범주형을 수치형으로 바꾼다.
- 스케일링은 변수의 단위 차이가 만드는 왜곡을 없앤다.
- 트리 계열 모델은 스케일링이 필수가 아니지만, 거리 기반 모델은 필수에 가깝다.

## 1. 특성 생성

### 1) 정의

**특성 생성**은 기존 변수들을 조합해 새로운 변수를 만드는 것입니다. 예를 들어 키와 몸무게로 BMI를 계산하거나, 총 금액과 팁으로 "팁 비율"을 만드는 식입니다.

### 2) 왜 필요한가

- 원본 변수만으로는 드러나지 않던 관계가 새 변수에서 드러날 수 있습니다.
- 도메인 지식을 반영한 변수는 모델 성능을 크게 끌어올리기도 합니다.

### 3) 핵심 흐름 재구성

날짜를 연·월·일로 쪼개거나(날짜 처리), 두 변수를 곱하거나 나눠 상호작용 특성을 만드는 것이 대표적입니다. 핵심은 "이 조합이 예측에 도움이 될까?"라는 질문을 던지는 것입니다.

### 4) 쉬운 예시

식당 데이터에서 팁 금액만 보면 "많이 낸 사람"과 "적게 낸 사람"만 구분됩니다. 하지만 `팁 ÷ 총 금액`으로 팁 비율을 만들면 "금액 대비 후하게 주는 고객"이라는 새로운 성격이 드러납니다.

### 5) 코드 예시

```python
import seaborn as sns

tips = sns.load_dataset('tips')
df = tips.copy()

# 특성 생성: 총 금액 대비 팁 비율
df['tip_rate'] = df['tip'] / df['total_bill']
```

### 6) 헷갈리는 점

새로 만든 특성이 예측하려는 정답과 너무 직접적으로 연결되면 **데이터 누수(leakage)**가 생깁니다. 예를 들어 팁을 예측하는데 팁으로 만든 비율을 그대로 특성에 넣으면 반칙이 됩니다.

### 7) 한 줄 정리

> 특성 생성은 도메인 지식으로 "숨어 있던 정보"를 새 변수로 끄집어내는 작업이다.

## 2. 바이닝(Binning)

### 1) 정의

**바이닝**은 연속형 데이터를 구간으로 나눠 범주형으로 바꾸는 것입니다. 나이(연속형)를 어린이·청소년·청년·중년·노인(범주형)으로 묶는 식입니다.

### 2) 왜 필요한가

- 연속값을 구간으로 묶으면 노이즈가 줄고 해석이 쉬워집니다.
- 범주형 입력을 요구하는 모델에 맞출 수 있습니다.

### 3) 코드 예시

```python
import pandas as pd

# 나이를 연령대로 바이닝
df['age_group'] = pd.cut(
    df['age'],
    bins=[0, 12, 18, 35, 60, 100],
    labels=['어린이', '청소년', '청년', '중년', '노인']
)
```

`pd.cut()`은 `bins`로 준 경계에 따라 값을 구간으로 나누고 `labels`로 이름을 붙입니다.

### 4) 한 줄 정리

> 바이닝은 연속값을 "구간"이라는 범주로 묶어 단순하고 해석 가능하게 만든다.

## 3. 더미 변환(Dummy / One-Hot Encoding)

### 1) 정의

**더미 변환**은 범주형 데이터를 0과 1의 수치형으로 바꾸는 것입니다. 성별(male/female)을 별도의 0/1 컬럼으로 펼칩니다.

### 2) 왜 필요한가

대부분의 머신러닝 모델은 문자를 직접 다루지 못합니다. 범주를 숫자로 바꿔야 학습이 가능합니다.

### 3) 코드 예시

```python
import pandas as pd

# 범주형 변수를 0/1 컬럼으로 변환
df = pd.get_dummies(
    df,
    columns=['sex', 'embarked'],
    drop_first=True,   # 첫 범주 제거로 다중공선성 방지
    dtype=int          # True/False 대신 1/0 로 저장
)
```

`drop_first=True`는 범주 하나를 제거해 불필요한 중복(다중공선성)을 줄입니다. 예를 들어 성별이 male/female 둘뿐이면 하나만 있어도 나머지를 알 수 있습니다.

### 4) 한 줄 정리

> 더미 변환은 모델이 이해할 수 있도록 범주를 0/1 숫자로 펼치는 작업이다.

## 4. 스케일링(Scaling)

### 1) 정의

**스케일링**은 변수마다 다른 단위나 크기를 비슷한 범위로 맞추는 것입니다. 대표적으로 StandardScaler는 평균 0, 표준편차 1로 변환합니다(Z-score 정규화).

### 2) 왜 필요한가

변수의 숫자가 크다고 해서 더 중요한 것이 아닙니다. 예를 들어 무게를 g으로 재면 1000, kg으로 재면 1이지만 같은 정보입니다. 단위 차이 때문에 모델이 큰 숫자 변수에 과도한 가중치를 주지 않도록 스케일을 맞춥니다.

### 3) 핵심 흐름 재구성

스케일링을 해도 데이터의 분포 **모양**은 바뀌지 않습니다. 위치와 폭만 표준 단위로 옮겨질 뿐입니다. 그래서 히스토그램의 형태는 그대로이고 x축 눈금만 바뀝니다.

한 가지 중요한 주의점이 있습니다. 스케일러는 **훈련 데이터에만 `fit`**하고, 테스트 데이터에는 `transform`만 적용해야 합니다. 테스트 데이터에 `fit`하면 테스트 정보가 학습에 새어 들어가는 데이터 누수가 발생합니다.

### 4) 쉬운 예시

시험 점수(0~100)와 출석 일수(0~30)를 함께 쓴다고 해봅시다. 스케일을 맞추지 않으면 점수의 큰 숫자가 출석보다 무조건 더 중요하게 취급될 수 있습니다. 표준화하면 둘을 공정하게 비교할 수 있습니다.

### 5) 코드 예시

```python
from sklearn.preprocessing import StandardScaler

scaler = StandardScaler()

# 훈련 데이터: 학습(fit) + 변환(transform)
X_train_scaled = scaler.fit_transform(X_train)

# 테스트 데이터: 변환(transform)만!
X_test_scaled = scaler.transform(X_test)
```

### 6) 헷갈리는 점

트리 계열 모델(랜덤 포레스트 등)은 값의 크기가 아니라 분기 기준으로 학습하므로 스케일링이 필수가 아닙니다. 반면 거리 기반 모델(KNN, SVM)이나 로지스틱 회귀는 스케일에 민감하므로 스케일링이 중요합니다.

### 7) 한 줄 정리

> 스케일링은 단위 차이가 만드는 왜곡을 없애 변수들을 공정하게 비교하도록 맞추는 작업이다.

## 코드로 보기 — 특성 엔지니어링 한 번에 적용하기

```python
import pandas as pd
from sklearn.preprocessing import StandardScaler

# 1) 특성 생성
df['tip_rate'] = df['tip'] / df['total_bill']

# 2) 바이닝
df['bill_category'] = pd.cut(
    df['total_bill'],
    bins=[0, 10, 20, 30, 50, 100],
    labels=['매우낮음', '낮음', '보통', '높음', '매우높음']
)

# 3) 더미 변환
df = pd.get_dummies(df, columns=['sex', 'smoker'], drop_first=True, dtype=int)

# 4) 스케일링
scaler = StandardScaler()
df[['total_bill', 'size']] = scaler.fit_transform(df[['total_bill', 'size']])
```

### 코드 목적

한 데이터프레임에 특성 생성 → 바이닝 → 더미 변환 → 스케일링을 차례로 적용해 모델 학습 직전 상태로 만드는 코드입니다.

### 코드 흐름

1. 새 특성(팁 비율)을 만든다.
2. 연속형 금액을 구간으로 바이닝한다.
3. 범주형을 0/1로 더미 변환한다.
4. 수치형 변수를 표준화한다.

### 실행 결과 해석

스케일링 후 `total_bill`의 평균은 0에 가깝고 표준편차는 1에 가까워집니다. 값의 범위는 대략 -2~3 사이로 옮겨지지만 분포의 모양(치우침)은 유지됩니다.

### 실무 연결

고객 세분화, 신용 평가, 추천 시스템 등 대부분의 모델링에서 이 네 가지 가공은 표준 절차처럼 반복됩니다. 특히 스케일링의 fit/transform 규칙은 실무에서 성능 재현성과 직결됩니다.

3. 테스트 데이터의 평균·표준편차 정보가 전처리에 반영되어 학습에 새어 들어가는 데이터 누수가 발생합니다. 테스트에는 `transform`만 적용해야 합니다.

## 헷갈리기 쉬운 포인트

| 헷갈리는 개념 | 차이 |
|---|---|
| 바이닝 vs 더미 변환 | 연속형→범주형이 바이닝, 범주형→수치형이 더미 변환 |
| 특성 생성 vs 특성 선택 | 새 변수를 만들면 생성, 불필요한 변수를 걸러내면 선택 |
| `fit_transform` vs `transform` | 훈련은 학습+변환, 테스트는 변환만 |
| 스케일링 필요 모델 vs 불필요 모델 | 거리 기반·로지스틱은 필요, 트리 계열은 필수 아님 |
