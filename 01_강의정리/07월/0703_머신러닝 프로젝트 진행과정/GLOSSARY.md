# 용어집

이번 노트에 등장한 핵심 용어를 쉬운 말로 정리했습니다. 처음 보는 용어가 나오면 여기서 먼저 개념을 잡고 본문으로 돌아가면 이해가 빠릅니다.

## 전체 흐름과 EDA

| 용어 | 쉬운 설명 | 관련 글 | 함께 보면 좋은 개념 |
| ---- | --------- | ------- | ------------------- |
| 머신러닝 프로젝트 흐름 | 데이터 수집부터 평가까지 이어지는 전체 작업 순서. 데이터 분석 단계와 머신러닝 단계로 나뉜다 | 전체 흐름과 EDA | EDA, 전처리 |
| EDA | 모델을 적용하기 전에 데이터의 크기·자료형·분포를 살펴 데이터를 이해하는 과정 | 전체 흐름과 EDA | 데이터 확인, 분포 |
| 데이터 확인 | `.shape`, `.info()`, `.head()` 등으로 데이터의 구조와 값 모양을 파악하는 단계 | 전체 흐름과 EDA | 기술통계량 |
| 기술통계량 | 평균·표준편차·분위수처럼 데이터를 숫자로 요약한 값. `.describe()`로 확인 | 전체 흐름과 EDA | 분포, 중앙값 |
| 분포 | 값들이 어떤 범위에 얼마나 몰려 있는지를 나타내는 데이터의 형태 | 전체 흐름과 EDA | 히스토그램, 치우침 |
| 클래스 불균형 | 분류 문제에서 정답 종류의 개수가 크게 차이 나는 상태(예: 정상 99, 불량 1) | 전체 흐름과 EDA | 재현율, 샘플링 |
| 과적합 | 훈련 데이터에만 지나치게 맞아 새 데이터에서는 성능이 떨어지는 현상 | 모델 학습과 평가 | 교차검증, 일반화 |

## 데이터 정제

| 용어 | 쉬운 설명 | 관련 글 | 함께 보면 좋은 개념 |
| ---- | --------- | ------- | ------------------- |
| 결측치 | 데이터에서 값이 비어 있는 상태. 모델 성능에 나쁜 영향을 준다 | 데이터 정제 | 대체, 삭제 |
| `isnull()` | 각 칸이 결측인지 True/False로 반환하는 함수. `.sum()`과 함께 쓰면 개수를 센다 | 데이터 정제 | 결측치 |
| 대체(Imputation) | 결측치를 평균·중앙값·추정값 등으로 채워 넣는 처리 | 데이터 정제 | 중앙값, fillna |
| 중앙값 | 값을 크기순으로 줄 세웠을 때 한가운데 값. 극단값에 덜 흔들려 대체에 자주 쓴다 | 데이터 정제 | 평균, 결측치 |
| 이상치 | 다른 값들과 크게 벗어난 값. 모델을 왜곡할 수 있다 | 데이터 정제 | IQR, boxplot |
| IQR | 3사분위수와 1사분위수의 차이(Q3−Q1). 이상치 경계를 정하는 데 쓴다 | 데이터 정제 | 사분위수, boxplot |
| boxplot | 데이터 분포를 상자와 수염으로 그린 그림. 수염 밖 점이 이상치 후보 | 데이터 정제 | IQR, 분포 |
| Winsorizing | 이상치를 삭제 대신 상한·하한 경계값으로 눌러 교체하는 방법. `.clip()`으로 구현 | 데이터 정제 | 이상치, clip |
| 변수화 | 이상치가 의미 있는 신호일 때 "이상치 여부"를 새 컬럼으로 만드는 처리 | 데이터 정제 | 특성 생성 |

## 특성 엔지니어링

| 용어 | 쉬운 설명 | 관련 글 | 함께 보면 좋은 개념 |
| ---- | --------- | ------- | ------------------- |
| 특성 엔지니어링 | 새 데이터를 모으지 않고 기존 데이터를 모델이 쓰기 좋게 가공하는 작업 | 특성 엔지니어링 | 바이닝, 스케일링 |
| 특성 생성 | 기존 변수를 조합해 새 변수를 만드는 것(예: 키·몸무게 → BMI) | 특성 엔지니어링 | 도메인 지식 |
| 바이닝(Binning) | 연속형 데이터를 구간으로 나눠 범주형으로 바꾸는 것. `pd.cut()` 사용 | 특성 엔지니어링 | 범주형, pd.cut |
| 더미 변환 | 범주형 데이터를 0/1 수치형 컬럼으로 펼치는 것(One-Hot Encoding) | 특성 엔지니어링 | get_dummies, 다중공선성 |
| 스케일링 | 변수마다 다른 단위·크기를 비슷한 범위로 맞추는 것 | 특성 엔지니어링 | StandardScaler, 정규화 |
| StandardScaler | 평균 0, 표준편차 1로 바꾸는 스케일링 도구(Z-score 정규화) | 특성 엔지니어링 | 스케일링, fit/transform |
| 데이터 누수(Leakage) | 테스트나 정답 정보가 학습에 새어 들어가 성능이 부풀려지는 문제 | 특성 엔지니어링 | fit/transform, 평가 |
| fit / transform | fit은 기준을 학습, transform은 그 기준으로 변환. 테스트에는 transform만 | 특성 엔지니어링 | 데이터 누수, 스케일링 |

| 용어 | 쉬운 설명 | 관련 글 | 함께 보면 좋은 개념 |
| ---- | --------- | ------- | ------------------- |
| 상관관계 | 두 변수가 얼마나 함께 움직이는지를 나타내는 통계 개념. -1~1 값 | 상관관계 분석 | 피어슨, 다중공선성 |
| 피어슨 상관계수 | 두 변수의 선형 관계 강도를 재는 대표적 상관계수 | 상관관계 분석 | corr, heatmap |
| heatmap | 상관계수 행렬을 색으로 표현해 관계 강도를 한눈에 보는 그림 | 상관관계 분석 | 상관관계, corr |
| pairplot | 변수 쌍의 산점도를 격자로 그려 관계 모양을 보는 그림 | 상관관계 분석 | 산점도 |
| 다중공선성 | 두 변수가 서로 매우 강하게 상관돼 사실상 같은 정보를 담는 상태 | 상관관계 분석 | 특성 선택, heatmap |
| 인과관계 | 한쪽이 원인이 되어 다른 쪽 결과를 만드는 관계. 상관관계와 구별해야 함 | 상관관계 분석 | 상관관계 |

## 모델 학습과 평가

| 용어 | 쉬운 설명 | 관련 글 | 함께 보면 좋은 개념 |
| ---- | --------- | ------- | ------------------- |
| train_test_split | 데이터를 훈련용과 테스트용으로 나누는 함수 | 모델 학습과 평가 | 과적합, random_state |
| 훈련 세트 / 테스트 세트 | 학습에 쓰는 데이터 / 성능 평가에 쓰는 처음 보는 데이터 | 모델 학습과 평가 | 일반화 |
| random_state | 같은 분할·같은 결과를 재현하기 위한 난수 시드 | 모델 학습과 평가 | 재현성 |
| K-fold 교차검증 | 데이터를 K조각으로 나눠 번갈아 검증하며 성능을 안정적으로 추정하는 방법 | 모델 학습과 평가 | 과적합, cross_val_score |
| R²(결정계수) | 모델이 데이터 변동을 얼마나 설명하는지. 1에 가까울수록 좋다 | 모델 학습과 평가 | RMSE, 회귀 |
| RMSE | 예측이 실제와 평균적으로 얼마나 벗어났는지. 낮을수록 좋다 | 모델 학습과 평가 | R², 회귀 |
| 정확도(Accuracy) | 전체 예측 중 맞춘 비율. 불균형 데이터에서는 오해를 부를 수 있다 | 모델 학습과 평가 | 재현율, F1 |
| 정밀도(Precision) | 양성이라 예측한 것 중 실제 양성의 비율 | 모델 학습과 평가 | 재현율, 혼동 행렬 |
| 재현율(Recall) | 실제 양성 중 모델이 잡아낸 비율. 놓치면 안 될 때 중요 | 모델 학습과 평가 | 정밀도, F1 |
| F1-score | 정밀도와 재현율의 조화평균. 둘의 균형을 보는 지표 | 모델 학습과 평가 | 정밀도, 재현율 |
| 혼동 행렬 | 실제값과 예측값을 교차한 표. 어디서 틀렸는지 보여준다 | 모델 학습과 평가 | 정밀도, 재현율 |
| Pipeline | 전처리와 모델을 하나로 묶어 일관되게 학습·예측하는 도구 | 모델 학습과 평가 | ColumnTransformer, 데이터 누수 |
| ColumnTransformer | 컬럼마다 다른 전처리를 지정해 묶는 도구 | 모델 학습과 평가 | Pipeline |
