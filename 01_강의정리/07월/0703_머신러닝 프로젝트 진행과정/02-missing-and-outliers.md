# 데이터 정제 — 결측치와 이상치 처리

> 비어 있는 값과 튀는 값을 "무조건 지우기"로 처리하면 소중한 데이터를 잃는다. 언제 지우고 언제 살릴지가 핵심이다.

`결측치` · `이상치` · `IQR` · `대체` · `데이터 정제`

## 핵심요약

- 결측치는 데이터세트에서 누락된 값으로, 모델 성능에 부정적 영향을 준다.
- 결측치 처리는 삭제(열/행)와 대체(평균·중앙값·유사 유형)로 나뉜다.
- "결측치가 많다"가 삭제의 기준이 아니라, "패턴을 찾을 수 없다"가 기준이다.
- 이상치는 다른 값들과 크게 벗어난 값으로, IQR이나 boxplot으로 찾을 수 있다.
- 이상치도 삭제·대체·변수화 중에서 상황에 맞게 골라야 한다.

## 1. 결측치 처리

### 1) 정의

**결측치(Missing Value)**는 데이터세트에서 값이 비어 있는 상태입니다. 수집 과정에서 누락되거나, 애초에 측정되지 않아 생깁니다. 결측치가 남아 있으면 많은 머신러닝 모델이 학습을 제대로 하지 못합니다.

### 2) 왜 필요한가

- 결측치가 있는 상태로 학습하면 모델이 왜곡되거나 오류가 납니다.
- 어떻게 채우느냐에 따라 데이터의 성격이 바뀌므로 신중한 판단이 필요합니다.
- 실무에서는 결측 자체가 하나의 정보(예: 응답을 거부한 고객)일 수도 있습니다.

### 3) 핵심 흐름 재구성

먼저 결측치가 어디에 얼마나 있는지 확인합니다.

- `isnull()`은 각 칸이 결측인지 True/False로 반환합니다.
- `isnull().sum()`은 변수별 결측치 개수를 세어 줍니다.

확인 후 처리 방법을 고릅니다.

| 방법 | 언제 쓰나 | 대표 함수 |
|------|----------|----------|
| 열 전체 삭제 | 특정 열에 결측이 매우 많아 패턴을 못 찾을 때 | `.drop(['컬럼'], axis='columns')` |
| 행 삭제 | 데이터가 충분히 많고 결측 행이 소수일 때 | `.dropna()` |
| 일괄 대체 | 데이터 수가 적어 삭제가 아까울 때 | `.fillna(평균/중앙값)` |
| 유사 유형 대체 | 다른 변수로 결측값을 추정할 수 있을 때 | 회귀·최근접 이웃 등 모델 활용 |

여기서 꼭 기억할 판단 기준이 있습니다. **결측치가 많아서 지우는 것이 아니라, 결측이 너무 많아 패턴을 발견할 수 없어서 지우는 것**입니다. 반대로 확보한 데이터가 적거나 다른 변수로 값을 추정할 수 있다면, 함부로 삭제하면 안 됩니다.

### 4) 쉬운 예시

지역 데이터가 "서울 500건, 경기도 499건, 결측 5건"이라고 해봅시다. 결측 5건을 전부 최빈값인 서울로 채우는 것이 과연 맞을까요? 서울과 경기가 거의 반반이라 결측을 한쪽으로 몰면 분포가 왜곡됩니다. 이처럼 "일괄 대체가 늘 정답은 아니다"라는 감각이 중요합니다.

### 5) 코드 예시

```python
import seaborn as sns

titanic = sns.load_dataset('titanic')
df = titanic.copy()   # 원본 보존을 위해 복사본에서 작업

# 변수별 결측치 개수 확인
print(df.isnull().sum())

# 1) 결측 비율이 매우 높은 열은 열 전체 삭제
df.drop(['deck'], axis='columns', inplace=True)

# 2) 결측이 소수인 열은 해당 행만 삭제
df.dropna(subset=['embarked', 'embark_town'], inplace=True)

# 3) 결측이 적당한 수치형 변수는 중앙값으로 대체
df['age'] = df['age'].fillna(df['age'].median())
```

### 6) 헷갈리는 점

`axis='columns'`를 빠뜨리면 `.drop()`이 행을 지웁니다. 열을 지우려면 축을 명시해야 합니다. 또한 평균과 중앙값 중에서, 분포가 치우쳐 있으면 극단값에 덜 흔들리는 **중앙값**이 더 안전한 경우가 많습니다.

### 7) 한 줄 정리

> 결측치 처리는 "지울지 채울지"를 데이터 양과 패턴을 근거로 결정하는 판단의 문제다.

## 2. 이상치 처리

### 1) 정의

**이상치(Outlier)**는 다른 데이터 포인트들과 크게 벗어난 값입니다. 예를 들어 나이 데이터에 음수(-5)나 소수(32.5)가 섞여 있으면 이상치로 볼 수 있습니다.

### 2) 왜 필요한가

- 이상치는 평균이나 회귀선을 끌어당겨 모델을 왜곡합니다.
- 다만 이상치가 "오류"인지 "의미 있는 극단값"인지 구분해야 합니다. 사기 거래처럼 이상치 자체가 찾고 싶은 대상일 수도 있습니다.

### 3) 핵심 흐름 재구성

이상치를 찾는 대표적 방법은 두 가지입니다.

- **시각화**: boxplot이나 히스토그램으로 분포를 보고 눈으로 식별합니다. boxplot의 수염 바깥에 찍힌 점이 이상치 후보입니다.
- **IQR 방법**: 사분위수 범위를 이용한 통계적 기준입니다.

IQR 기준은 다음과 같습니다.

$$\text{IQR} = Q_3 - Q_1$$

$$x < Q_1 - 1.5 \times \text{IQR} \quad \text{또는} \quad x > Q_3 + 1.5 \times \text{IQR}$$

여기서 $Q_1$은 하위 25% 지점, $Q_3$은 상위 25% 지점의 값입니다. 이 범위를 벗어나면 이상치로 봅니다. 이 식은 "가운데 50% 데이터가 퍼진 폭의 1.5배보다 더 멀리 떨어진 값"을 이상치로 잡겠다는 의미입니다.

다만 이 기준을 기계적으로 쓰면 안 됩니다. 예를 들어 계산서 금액에서 하한선이 음수로 나오면 현실적으로 말이 안 되므로 도메인 지식으로 조정해야 합니다.

처리 방법은 세 가지입니다.

| 방법 | 언제 쓰나 |
|------|----------|
| 단순 삭제 | 사람 실수(오입력)로 생긴 명백한 오류일 때 |
| 대체 | 데이터가 적어 삭제가 아까울 때, 경계값이나 중앙값으로 교체 |
| 변수화 | 이상치 자체가 의미 있는 정보일 때, "이상치 여부" 컬럼으로 활용 |

### 4) 쉬운 예시

키·몸무게·나이 데이터에서 나이에 -5가 있다면 이건 명백한 오입력이므로 삭제나 대체 대상입니다. 반면 온라인 쇼핑에서 어떤 고객의 구매액이 유난히 크다면, 그건 오류가 아니라 "VIP 고객"이라는 의미 있는 신호일 수 있어 변수화가 낫습니다.

### 5) 코드 예시

```python
import seaborn as sns

tips = sns.load_dataset('tips')
df = tips.copy()

# IQR 계산
Q1 = df['total_bill'].quantile(0.25)
Q3 = df['total_bill'].quantile(0.75)
IQR = Q3 - Q1

lower = Q1 - 1.5 * IQR   # 하한선
upper = Q3 + 1.5 * IQR   # 상한선

# 데이터가 적어 삭제 대신 경계값으로 교체 (Winsorizing)
df['total_bill_clean'] = df['total_bill'].clip(lower=lower, upper=upper)
```

`.clip()`은 하한선보다 작은 값은 하한선으로, 상한선보다 큰 값은 상한선으로 눌러 줍니다.

### 6) 헷갈리는 점

이상치를 무조건 삭제하는 것이 최선은 아닙니다. 데이터가 적으면 삭제가 데이터 부족을 부르고, 이상치가 진짜 신호라면 삭제로 정보를 잃습니다.

### 7) 한 줄 정리

> 이상치 처리는 "이 값이 오류인가, 신호인가"를 먼저 판단한 뒤 삭제·대체·변수화를 고르는 일이다.

## 코드로 보기 — boxplot으로 이상치 눈으로 확인하기

```python
import seaborn as sns
import matplotlib.pyplot as plt

tips = sns.load_dataset('tips')

sns.boxplot(x=tips['total_bill'])
plt.xlabel('total_bill')
plt.show()
```

### 코드 목적

연속형 변수의 분포를 상자그림으로 그려 이상치 후보를 시각적으로 찾으려는 코드입니다.

### 코드 흐름

1. 데이터를 불러온다.
2. `boxplot`으로 대상 변수를 그린다.
3. 상자 바깥(수염 너머)에 찍힌 점을 이상치 후보로 본다.
4. IQR 기준과 도메인 지식으로 실제 처리 여부를 정한다.

### 실행 결과 해석

상자는 가운데 50%의 데이터 범위(Q1~Q3)를 나타내고, 상자 안 선은 중앙값입니다. 수염 밖의 점들이 통계적으로 튀는 값입니다. 점이 몇 개인지, 얼마나 멀리 떨어졌는지를 보고 처리 강도를 정합니다.

### 실무 연결

품질 관리에서 불량 센서값 탐지, 금융에서 이상 거래 탐지처럼 "튀는 값"을 찾는 일은 실무 곳곳에서 반복됩니다. 이때 이상치를 지울지 살릴지는 문제 목적에 따라 정반대가 됩니다.

## 헷갈리기 쉬운 포인트

| 헷갈리는 개념 | 차이 |
|---|---|
| 삭제 vs 대체 | 값을 없애면 삭제, 다른 값으로 채우면 대체 |
| 열 삭제 vs 행 삭제 | 변수(컬럼) 통째로 지우면 열 삭제, 결측이 있는 관측치만 지우면 행 삭제 |
| 이상치 삭제 vs 변수화 | 오류면 삭제, 의미 있는 신호면 "이상치 여부"로 변수화 |
| 평균 대체 vs 중앙값 대체 | 분포가 대칭이면 평균, 치우쳐 극단값이 있으면 중앙값이 안전 |
