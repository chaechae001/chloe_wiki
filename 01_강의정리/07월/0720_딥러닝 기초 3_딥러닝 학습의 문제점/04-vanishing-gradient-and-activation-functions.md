# 기울기 소실과 활성화 함수 — 깊은 층까지 학습 신호를 전달하는 법

> 깊은 신경망은 층을 많이 쌓았다는 이유만으로 더 잘 배우지 않습니다. 역전파 과정에서 작은 미분값이 계속 곱해지면 입력에 가까운 층은 고칠 방향을 거의 받지 못합니다. 활성화 함수의 도함수는 그 신호가 얼마나 살아남는지를 결정합니다.

`Vanishing Gradient` · `Sigmoid` · `Tanh` · `ReLU` · `Backpropagation`

## 핵심요약

- 기울기 소실은 역전파 신호가 앞쪽 층으로 갈수록 매우 작아져 학습이 느려지는 현상이다.
- 연쇄법칙에서 여러 층의 미분값이 곱해지므로 1보다 작은 값이 반복되면 기울기가 빠르게 줄어든다.
- Sigmoid와 Tanh는 입력 절댓값이 클 때 포화되어 도함수가 0에 가까워질 수 있다.
- ReLU는 양수 구간에서 도함수가 1이지만 음수 구간에서는 0이므로 기울기 소실을 완전히 해결하지 않는다.
- 저장된 깊은 모델의 정확도는 Sigmoid `0.493`, Tanh `0.963`, ReLU `0.983`이었지만 gradient norm을 직접 측정한 실험이 아니므로 정확도 차이만으로 기울기 소실의 크기를 확정할 수 없다.

## 1. 역전파와 기울기 소실

### 1) 정의

기울기 소실(Vanishing Gradient)은 출력층에서 계산한 오차 신호가 역전파되면서 지나치게 작아져, 입력과 가까운 앞쪽 층의 가중치가 거의 갱신되지 않는 현상입니다.

여러 함수가 합성된 신경망에서 연쇄법칙은 다음처럼 표현됩니다.

$$
\frac{\partial L}{\partial h_1}
=
\frac{\partial L}{\partial h_n}
\frac{\partial h_n}{\partial h_{n-1}}
\cdots
\frac{\partial h_2}{\partial h_1}
$$

각 층의 미분값 절댓값이 1보다 작다면 층을 거칠 때마다 값이 곱해져 전체 기울기가 작아질 수 있습니다.

예를 들어 미분값 `0.5`가 10번 곱해지면 다음과 같습니다.

$$
0.5^{10} \approx 0.00098
$$

### 2) 왜 필요한가

앞쪽 층은 원시 입력에서 기본 패턴을 추출합니다. 이 층들이 충분히 갱신되지 않으면 뒤쪽 층도 좋은 표현을 전달받기 어렵습니다.

기울기 소실을 이해하면 다음 현상을 진단할 수 있습니다.

- 손실이 초반부터 거의 줄지 않는다.
- 출력층 근처는 바뀌지만 앞쪽 층의 가중치는 거의 변하지 않는다.
- 네트워크를 깊게 만들수록 성능이 오히려 나빠진다.
- 활성화 함수나 초기화를 바꾸면 학습이 크게 달라진다.

### 3) 핵심 흐름 재구성

순전파에서는 입력이 층을 따라 출력으로 이동합니다.

$$
z^{(l)} = W^{(l)}h^{(l-1)} + b^{(l)},
\qquad h^{(l)} = f(z^{(l)})
$$

역전파에서는 손실의 기울기가 반대 방향으로 이동합니다. 이때 가중치와 활성화 함수의 도함수가 반복해서 곱해집니다.

활성화 함수가 포화되어 $f'(z)$가 0에 가까워지면 그 지점이 좁은 수도관처럼 신호를 막습니다. 이런 층이 여러 개 이어지면 앞쪽으로 전달되는 기울기는 더 작아집니다.

### 4) 쉬운 예시

여러 사람이 한 줄로 서서 메시지를 전달한다고 생각해 봅시다. 각 사람이 들은 목소리의 절반 크기로만 다음 사람에게 말하면 열 사람 뒤에서는 거의 들리지 않습니다.

역전파의 작은 미분값도 비슷합니다. 한 층에서는 작은 감소처럼 보여도 여러 층에서 곱해지면 앞쪽 층에 도달할 때는 학습에 부족한 신호가 될 수 있습니다.

### 5) 코드 예시

```python
import numpy as np

local_derivatives = np.full(10, 0.5)
backprop_signal = np.cumprod(local_derivatives)

for layer, value in enumerate(backprop_signal, start=1):
    print(layer, f"{value:.6f}")
```

```text
1 0.500000
2 0.250000
3 0.125000
...
10 0.000977
```

실제 신경망의 기울기는 가중치 행렬과 손실의 미분까지 포함해 더 복잡합니다. 이 코드는 1보다 작은 국소 미분이 반복해서 곱해질 때의 핵심만 보여 줍니다.

### 6) 헷갈리는 점

기울기 소실은 손실값 자체가 0이 된다는 뜻이 아닙니다. 손실은 여전히 클 수 있지만 그 손실을 앞쪽 가중치에 전달하는 미분값이 작아지는 문제입니다.

반대로 미분값이나 가중치가 반복해서 너무 크게 곱해지면 기울기 폭주가 발생할 수 있습니다. 두 문제 모두 신호의 크기가 층을 지나며 안정적으로 유지되지 않는 현상입니다.

### 7) 한 줄 정리

> 기울기 소실은 연쇄법칙의 곱셈 과정에서 앞쪽 층의 학습 신호가 지나치게 작아지는 문제다.

## 2. Sigmoid와 Tanh의 포화

### 1) 정의

Sigmoid는 모든 실수를 0과 1 사이로 압축합니다.

$$
\sigma(x) = \frac{1}{1+e^{-x}}
$$

도함수는 다음과 같습니다.

$$
\sigma'(x) = \sigma(x)(1-\sigma(x))
$$

Sigmoid 도함수의 최댓값은 $x=0$에서 `0.25`입니다. 입력의 절댓값이 커져 출력이 0이나 1에 가까워지면 도함수는 0에 가까워집니다.

Tanh는 입력을 -1과 1 사이로 압축합니다.

$$
\tanh'(x) = 1-\tanh^2(x)
$$

중심이 0이라 Sigmoid보다 신호 전파에 유리한 경우가 있지만, 양 끝에서 포화되는 성질은 남아 있습니다.

### 2) 왜 필요한가

활성화 함수는 비선형성을 추가할 뿐 아니라 역전파되는 기울기의 크기도 결정합니다. 깊은 은닉층에 포화 함수가 반복되면 작은 도함수가 계속 곱해질 가능성이 커집니다.

Sigmoid는 출력층에서 이진 확률을 표현할 때 여전히 유용합니다. 문제는 함수 자체가 나쁘다는 것이 아니라 **깊은 은닉층에서 반복 사용할 때** 포화와 기울기 소실 위험이 커진다는 점입니다.

### 3) 핵심 흐름 재구성

저장된 도함수 확인에서 Sigmoid의 최대 도함수는 `0.2500`이었습니다. 이론적인 최댓값과 일치합니다.

Sigmoid 출력이 0.99라면 도함수는 다음처럼 작습니다.

$$
0.99(1-0.99) = 0.0099
$$

Tanh는 원점 근처에서 도함수가 최대 1이므로 중심 구간에서는 신호를 더 잘 전달할 수 있습니다. 하지만 출력이 1이나 -1에 가까워지면 도함수는 다시 0에 가까워집니다.

### 4) 쉬운 예시

Sigmoid와 Tanh는 넓은 풍경을 좁은 사진 안에 눌러 담는 렌즈와 비슷합니다. 중앙의 변화는 비교적 잘 보이지만 가장자리에서는 큰 입력 변화도 사진 속 위치가 거의 달라지지 않습니다.

출력이 거의 변하지 않는 포화 구간에서는 도함수도 작습니다. 모델은 “입력을 바꿔도 출력이 얼마나 달라지는지”에 대한 신호를 거의 받지 못합니다.

### 5) 코드 예시

```python
import tensorflow as tf

x = tf.constant([-5.0, 0.0, 5.0])

with tf.GradientTape(persistent=True) as tape:
    tape.watch(x)
    sigmoid_y = tf.math.sigmoid(x)
    tanh_y = tf.math.tanh(x)

sigmoid_grad = tape.gradient(sigmoid_y, x)
tanh_grad = tape.gradient(tanh_y, x)

print("sigmoid:", sigmoid_y.numpy())
print("sigmoid grad:", sigmoid_grad.numpy())
print("tanh grad:", tanh_grad.numpy())
```

원점 주변과 양 끝에서 도함수 크기가 어떻게 달라지는지 직접 비교할 수 있습니다.

### 6) 헷갈리는 점

Tanh는 중심이 0이고 원점의 도함수가 1이지만 기울기 소실에서 완전히 자유롭지 않습니다. 입력 절댓값이 커지면 Tanh도 포화됩니다.

Sigmoid를 은닉층에서 피한다고 해서 출력층에서도 쓰면 안 되는 것은 아닙니다. 이진 분류의 출력 확률에는 Sigmoid가 자연스러운 선택입니다.

### 7) 한 줄 정리

> Sigmoid와 Tanh는 입력이 포화 구간에 들어가면 도함수가 작아져 깊은 층의 역전파를 약하게 만들 수 있다.

## 3. ReLU의 장점과 한계

### 1) 정의

ReLU는 음수 입력을 0으로 만들고 양수 입력은 그대로 통과시킵니다.

$$
\operatorname{ReLU}(x) = \max(0, x)
$$

도함수는 구간별로 다음과 같습니다.

$$
\operatorname{ReLU}'(x) =
\begin{cases}
0, & x < 0 \\
1, & x > 0
\end{cases}
$$

$x=0$에서는 수학적으로 미분이 정의되지 않으며, 구현에서는 보통 특정 하위 기울기 값을 정해 사용합니다.

### 2) 왜 필요한가

ReLU는 양수 영역에서 도함수가 1이므로 Sigmoid처럼 양의 큰 입력에서 포화되지 않습니다. 계산도 단순해 깊은 은닉층의 기본 활성화 함수로 널리 사용됩니다.

하지만 음수 영역의 도함수는 0입니다. 뉴런의 입력이 계속 음수에 머물면 가중치가 업데이트되지 않는 Dead ReLU 문제가 생길 수 있습니다.

### 3) 핵심 흐름 재구성

8개 은닉층을 둔 한 저장 실험의 정확도는 다음과 같았습니다.

| 활성화 함수 | 저장된 정확도 |
|---|---:|
| Sigmoid | 0.493 |
| Tanh | 0.963 |
| ReLU | 0.983 |

이 실행에서는 ReLU 모델의 정확도가 가장 높고 Sigmoid 모델은 약 `0.493`에 머물렀습니다. 이는 깊은 모델에서 활성화 함수 선택이 학습 결과와 함께 달라질 수 있음을 보여 줍니다.

다만 이 실험은 층별 gradient norm을 직접 기록하지 않았습니다. 정확도는 데이터 적합 결과이며, 기울기의 크기 자체가 아닙니다. 따라서 “Sigmoid의 기울기가 몇 배 더 작았다”거나 “ReLU가 기울기 소실을 완전히 없앴다”고 결론 내릴 수 없습니다.

### 4) 쉬운 예시

ReLU는 한쪽 방향으로만 열리는 문과 비슷합니다. 양수 신호는 크기를 유지한 채 지나가지만 음수 신호는 문 앞에서 멈춥니다.

양수 영역에서는 메시지가 잘 전달되지만 항상 음수만 받는 뉴런은 아무 메시지도 보내지 못합니다. 그래서 ReLU는 포화를 줄이는 유용한 선택이지 모든 기울기 문제의 완전한 해결책은 아닙니다.

### 5) 코드 예시

```python
import tensorflow as tf

x = tf.constant([-2.0, -0.5, 0.5, 2.0])

with tf.GradientTape() as tape:
    tape.watch(x)
    y = tf.nn.relu(x)

gradient = tape.gradient(y, x)
print("output:", y.numpy())
print("gradient:", gradient.numpy())
```

```text
output: [0.  0.  0.5 2. ]
gradient: [0. 0. 1. 1.]
```

음수 입력에서는 출력과 기울기가 모두 0이고, 양수 입력에서는 기울기가 1인 성질을 확인할 수 있습니다.

### 6) 헷갈리는 점

ReLU가 양수 영역에서 도함수 1을 유지한다는 말은 네트워크 전체 기울기가 항상 1이라는 뜻이 아닙니다. 역전파에는 가중치 행렬과 손실 함수의 미분도 함께 곱해집니다.

정확도 `0.983`은 해당 실험에서 약 98.3%를 맞혔다는 뜻이지 ReLU가 모든 깊은 모델에서 최선이라는 뜻은 아닙니다. 초기화, 학습률, 데이터 분포와 모델 구조가 달라지면 결과도 달라집니다.

### 7) 한 줄 정리

> ReLU는 양수 구간의 기울기를 유지하지만 음수 구간에서는 0이므로 장점과 Dead ReLU 위험을 함께 봐야 한다.

## 코드로 보기 — 활성화 함수와 도함수를 같은 축에서 비교하기

```python
import tensorflow as tf

x = tf.linspace(-5.0, 5.0, 11)

def values_and_gradients(function, inputs):
    with tf.GradientTape() as tape:
        tape.watch(inputs)
        outputs = function(inputs)
    return outputs, tape.gradient(outputs, inputs)

functions = {
    "Sigmoid": tf.math.sigmoid,
    "Tanh": tf.math.tanh,
    "ReLU": tf.nn.relu,
}

for name, function in functions.items():
    outputs, gradients = values_and_gradients(function, x)
    print(name)
    print(" output:", tf.round(outputs * 1000) / 1000)
    print(" gradient:", tf.round(gradients * 1000) / 1000)
```

### 코드 목적

같은 입력 구간에서 세 활성화 함수의 출력과 도함수를 함께 계산해 포화 구간과 ReLU의 음수 구간을 비교합니다.

### 코드 흐름

1. -5부터 5까지 같은 입력을 만듭니다.
2. 자동 미분이 입력을 추적하도록 설정합니다.
3. 각 활성화 함수의 출력과 입력에 대한 기울기를 계산합니다.
4. 원점과 양 끝 구간의 도함수 크기를 비교합니다.

### 실행 결과 해석

Sigmoid와 Tanh는 입력 절댓값이 커질수록 출력이 양 끝값에 가까워지고 도함수는 0에 가까워집니다. ReLU는 음수에서 도함수 0, 양수에서 1을 가집니다.

별도의 저장된 깊은 모델 실험에서는 정확도가 Sigmoid `0.493`, Tanh `0.963`, ReLU `0.983`으로 관찰되었습니다. 이 값은 활성화 함수별 최종 예측 성능을 비교한 것이며, 층별 기울기 크기를 직접 보여 주는 값은 아닙니다.

### 실무 연결

기울기 소실을 진단할 때는 정확도 곡선만 보지 말고 층별 gradient norm, 활성값 분포, 0에 가까운 기울기의 비율을 함께 기록하는 것이 좋습니다. 활성화 함수뿐 아니라 [가중치 초기화와 신호 전파](05-weight-initialization-and-signal-propagation.md), 잔차 연결, 정규화도 학습 신호에 영향을 줍니다.

3. 각 층 가중치의 gradient norm과 활성값 분포를 epoch별로 기록합니다. 초기값과 모델 구조, 데이터 순서도 같게 통제해야 활성화 함수의 영향을 더 직접 비교할 수 있습니다.

</details>

## 헷갈리기 쉬운 포인트

| 헷갈리는 개념 | 차이 |
|---|---|
| 기울기 소실 vs 낮은 손실 | 앞쪽 층의 미분 신호가 작아짐 vs 예측 오차 자체가 작음 |
| Sigmoid vs Tanh | 출력 범위 0~1·중심 0 아님 vs 출력 범위 -1~1·중심 0 |
| Tanh vs ReLU | 양 끝에서 포화 vs 양수는 선형, 음수는 0 |
| ReLU의 장점 vs 완전한 해결 | 양수 구간 도함수 1 vs 음수 구간 도함수 0과 Dead ReLU 위험 |
| 정확도 vs gradient norm | 최종 예측의 정답 비율 vs 층별 학습 신호의 크기 |
| 기울기 소실 vs 기울기 폭주 | 기울기가 지나치게 작아짐 vs 지나치게 커짐 |

### 복습 질문 및 답변

**Q1. Sigmoid를 사용하면 반드시 기울기 소실이 발생하나요?**

<details>
<summary>답</summary>

반드시 발생하는 것은 아닙니다. 네트워크 깊이, 입력 분포, 가중치 초기화와 다른 미분항이 함께 영향을 줍니다. 다만 깊은 은닉층에서 Sigmoid가 포화되면 작은 도함수가 반복될 위험이 커집니다.

</details>

**Q2. ReLU가 기울기 소실을 완전히 해결하지 못하는 이유는 무엇인가요?**

<details>
<summary>답</summary>

음수 입력에서 도함수가 0이어서 해당 뉴런으로 기울기가 흐르지 않을 수 있고, 전체 역전파에는 가중치 행렬과 다른 미분값도 곱해지기 때문입니다. 양수 구간 도함수 1만으로 전체 신호 보존이 보장되지는 않습니다.

</details>

**Q3. 저장된 정확도만으로 활성화 함수의 기울기 소실 정도를 비교할 수 있나요?**

<details>
<summary>답</summary>

정확도는 최종 예측 성능을 보여 주지만 층별 기울기 크기를 직접 측정하지 않습니다. gradient norm, 활성값 분포, 0 기울기 비율을 기록하고 나머지 조건을 통제해야 더 직접적인 비교가 가능합니다.

</details>
