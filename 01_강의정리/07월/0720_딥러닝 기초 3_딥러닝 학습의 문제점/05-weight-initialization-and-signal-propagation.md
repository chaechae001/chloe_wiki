# 가중치 초기화와 신호 전파 — 학습의 출발점이 깊은 층의 상태를 결정한다

> 같은 구조의 신경망도 첫 가중치를 어떻게 뽑느냐에 따라 신호가 층마다 사라지거나 지나치게 커질 수 있습니다. 좋은 초기화의 목적은 정답에 가까운 가중치를 맞히는 것이 아니라, 학습 가능한 크기의 활성값과 기울기를 출발점부터 유지하는 것입니다.

`가중치 초기화` · `fan-in` · `Xavier` · `He` · `신호 전파`

## 핵심요약

- 모든 가중치를 같은 값으로 시작하면 뉴런이 비슷한 계산을 반복해 표현을 나누어 배우기 어렵다.
- 초기 가중치의 스케일이 너무 작으면 층을 지날수록 신호가 약해지고, 너무 크면 활성화 함수의 포화 구간에 몰릴 수 있다.
- Xavier 초기화는 입력·출력 연결 수를 고려해 분산을 조절하며 Sigmoid나 Tanh 계열과 자주 연결된다.
- He 초기화는 음수 입력을 0으로 만드는 ReLU 계열의 특성을 고려해 더 큰 분산을 사용한다.
- 저장된 실험에서는 Xavier+Tanh의 마지막 손실이 0.0704, He+ReLU가 0.0508이었지만 한 번의 실행만으로 절대 우열을 정할 수 없다.
- 초기화의 품질은 활성값의 층별 분포, 기울기 크기, 학습 곡선을 함께 보고 판단해야 한다.

## 1. 초기화는 왜 신호 전파 문제인가

### 1) 정의

가중치 초기화는 학습을 시작하기 전 각 층의 가중치 $W$에 첫 값을 부여하는 과정입니다. 완전연결층의 순전파는 다음처럼 표현할 수 있습니다.

$$
z^{(l)} = W^{(l)}a^{(l-1)} + b^{(l)}, \qquad
a^{(l)} = f\left(z^{(l)}\right)
$$

앞 층의 출력 $a^{(l-1)}$가 가중치와 곱해져 다음 층의 입력이 됩니다. 이 계산이 반복되므로 초기 가중치의 분산은 한 층만이 아니라 깊은 네트워크 전체의 신호 크기에 영향을 줍니다.

### 2) 왜 필요한가

가중치가 지나치게 작으면 곱셈이 반복될 때 활성값이 좁은 구간으로 모일 수 있습니다. 반대로 너무 크면 Sigmoid 같은 함수의 양끝 포화 구간으로 입력이 밀려 미분값이 작아질 수 있습니다.

목표는 모든 층의 값이 완전히 같은 분포를 갖게 하는 것이 아닙니다. 층이 깊어져도 정보와 기울기가 학습 가능한 범위에 머물도록 **스케일을 관리하는 것**입니다.

### 3) 핵심 흐름 재구성

입력 성분이 서로 독립이고 평균이 0이라고 단순화하면, 선형 결합의 분산은 대략 입력 연결 수에 비례합니다.

$$
\operatorname{Var}(z)
\approx \text{fan\_in}\cdot\operatorname{Var}(W)\cdot\operatorname{Var}(a)
$$

여기서 `fan_in`은 한 뉴런으로 들어오는 연결 수입니다. 입력 수가 많은데 가중치 분산을 그대로 두면 출력 분산이 커질 수 있으므로, 연결 수에 맞춰 가중치 크기를 줄이는 발상이 나옵니다.

### 4) 쉬운 예시

여러 사람이 한 마이크에 동시에 말한다고 생각해 봅시다. 사람 수가 늘어도 각자의 음량을 그대로 두면 소리가 지나치게 커집니다. 반대로 음량을 너무 많이 줄이면 전달할 내용을 알아들을 수 없습니다. 초기화는 연결 수에 맞춰 첫 음량을 조정하는 작업과 비슷합니다.

### 5) 코드 예시

```python
import numpy as np

rng = np.random.default_rng(42)
x = rng.normal(size=(1000, 64))

for scale in [0.01, 1 / np.sqrt(64), 1.0]:
    w = rng.normal(size=(64, 64)) * scale
    z = x @ w
    print(f"scale={scale:.3f}, std={z.std():.3f}")
```

입력 연결 수가 64일 때 $1/\sqrt{64}$ 스케일은 선형 결합의 표준편차가 급격히 커지는 것을 완화합니다. 정확한 출력값은 난수에 따라 달라지므로 수치 하나보다 스케일 변화의 방향을 봐야 합니다.

### 6) 헷갈리는 점

초기화가 좋다고 최종 성능이 보장되지는 않습니다. 초기화는 학습 가능한 출발점을 제공할 뿐이며, 데이터 품질·모델 구조·활성화 함수·학습률·옵티마이저도 결과에 함께 영향을 줍니다.

### 7) 한 줄 정리

> 가중치 초기화는 첫 값을 정하는 절차이면서, 깊은 층까지 활성값과 기울기의 크기를 전달하기 위한 신호 설계다.

## 2. 큰·작은 초기화와 Xavier·He 초기화

### 1) 정의

단순 초기화는 정규분포에서 값을 뽑은 뒤 고정된 표준편차를 곱합니다. Xavier와 He 초기화는 이 표준편차를 입력 또는 출력 연결 수에 맞춰 정합니다.

Xavier 계열의 대표적인 분산 형태는 다음과 같습니다.

$$
\operatorname{Var}(W) \approx \frac{1}{\text{fan\_in}}
$$

입력과 출력을 함께 고려하는 변형은 다음과 같습니다.

$$
\operatorname{Var}(W) \approx
\frac{2}{\text{fan\_in}+\text{fan\_out}}
$$

He 초기화는 ReLU 계열에서 자주 쓰이며 대표적인 분산은 다음과 같습니다.

$$
\operatorname{Var}(W) \approx \frac{2}{\text{fan\_in}}
$$

### 2) 왜 필요한가

ReLU는 음수 입력을 0으로 바꾸므로 통과하는 신호의 일부가 사라집니다. He 초기화는 이를 고려해 Xavier보다 넓은 초기 분산을 사용합니다. Tanh처럼 양수와 음수를 모두 부드럽게 통과시키는 활성화에는 Xavier가 자주 연결됩니다.

이는 외워야 할 절대 규칙이 아니라 **활성화 함수와 연결 구조를 함께 고려하는 기본 선택 기준**입니다.

### 3) 핵심 흐름 재구성

여섯 층을 통과한 활성값의 표준편차를 측정한 저장 결과는 다음과 같습니다.

```text
큰 분산 + Sigmoid : [0.448, 0.425, 0.428, 0.443, 0.449, 0.448]
작은 분산 + Sigmoid: [0.020, 0.010, 0.010, 0.010, 0.010, 0.010]
Xavier + Tanh      : [0.627, 0.484, 0.399, 0.351, 0.312, 0.288]
He + ReLU          : [0.829, 0.833, 0.888, 1.055, 1.053, 1.019]
Xavier + ReLU      : [0.595, 0.411, 0.303, 0.201, 0.139, 0.095]
```

작은 분산+Sigmoid와 Xavier+ReLU에서는 층이 깊어질수록 표준편차가 줄었습니다. He+ReLU는 이 실행에서 약 0.8~1.1 범위를 유지했습니다.

큰 분산+Sigmoid의 표준편차가 유지된다고 해서 기울기도 건강하다는 뜻은 아닙니다. 출력이 0과 1 근처로 갈라지면 표준편차는 커 보일 수 있지만 Sigmoid의 미분값은 작아질 수 있습니다.

### 4) 쉬운 예시

표준편차는 교실에 흩어진 학생들의 위치를 보는 지표와 같습니다. 학생들이 넓게 퍼져 있다고 모두 수업을 잘 듣는 것은 아닙니다. 문밖 양끝에 몰려 있다면 거리의 분산은 커도 소통은 어려울 수 있습니다. 활성값 분산과 기울기를 함께 봐야 하는 이유입니다.

### 5) 코드 예시

```python
from tensorflow import keras
from tensorflow.keras import layers

tanh_layer = layers.Dense(
    64,
    activation="tanh",
    kernel_initializer="glorot_normal",
)

relu_layer = layers.Dense(
    64,
    activation="relu",
    kernel_initializer="he_normal",
)
```

프레임워크의 초기화 이름은 구현을 간결하게 해 주지만, 어떤 활성화와 왜 묶었는지를 이해해야 다른 구조에도 적용할 수 있습니다.

### 6) 헷갈리는 점

“Xavier는 ReLU에 절대 사용하면 안 된다”라고 말하면 과도합니다. 저장 실험에서는 층별 표준편차가 감소했지만, 실제 영향은 깊이·폭·정규화 층·잔차 연결 등에 따라 달라집니다. 일반적으로 ReLU 계열에는 He가 더 잘 맞는 출발점이라고 표현하는 편이 정확합니다.

### 7) 한 줄 정리

> Xavier와 He는 가중치 크기를 연결 수에 맞춰 조절하며, 활성화 함수의 신호 통과 특성에 맞는 출발점을 제공한다.

## 3. 저장된 학습 결과를 조건부로 해석하기

### 1) 정의

초기화 실험의 평가는 학습이 끝난 뒤의 손실뿐 아니라, 층별 활성값 분포와 학습 곡선을 함께 비교하는 과정입니다.

### 2) 왜 필요한가

마지막 손실 하나만 보면 중간에 불안정했는지, 우연히 좋은 초기값을 뽑았는지 알기 어렵습니다. 여러 지표를 함께 보면 “왜 학습됐는가”를 더 안전하게 설명할 수 있습니다.

### 3) 핵심 흐름 재구성

동일한 형태의 이진 분류 모델을 30에포크 학습한 저장 결과는 다음과 같습니다.

| 초기화·활성화 조합 | 마지막 손실 |
|---|---:|
| 큰 분산 + Sigmoid | 0.3289 |
| 작은 분산 + Sigmoid | 0.5871 |
| Xavier + Tanh | 0.0704 |
| He + ReLU | 0.0508 |

이 실행에서는 He+ReLU의 마지막 손실이 가장 낮고 Xavier+Tanh가 뒤를 이었습니다. 그러나 네 조합은 초기화와 활성화 함수를 동시에 바꿨으므로 차이를 초기화 하나의 효과로 분리할 수 없습니다.

또한 저장된 셀의 실행 번호가 순서대로 이어지지 않습니다. 난수 상태와 실행 순서가 바뀌었을 가능성이 있으므로, 이 값은 **저장된 한 실행의 관찰값**으로 사용해야 하며 완전한 재현 결과로 단정하면 안 됩니다.

### 4) 쉬운 예시

서로 다른 신발을 신고 서로 다른 코스를 달린 기록을 비교한 것과 같습니다. 기록은 참고할 수 있지만 신발만의 효과를 알려면 같은 코스·날씨·주자를 고정하고 신발만 바꿔야 합니다.

### 5) 코드 예시

```python
def compare_initializers(make_model, initializers, seeds=(7, 21, 42)):
    records = []
    for init_name in initializers:
        for seed in seeds:
            keras.utils.set_random_seed(seed)
            model = make_model(init_name)
            history = model.fit(
                x_train,
                y_train,
                validation_data=(x_valid, y_valid),

            )

```

공정한 비교에서는 활성화 함수, 데이터 분할, 모델 구조, 학습률을 고정하고 초기화만 바꿉니다. 여러 시드의 평균과 변동성을 함께 기록하면 우연한 한 번의 결과를 줄일 수 있습니다.

### 6) 헷갈리는 점

낮은 훈련 손실은 좋은 초기화의 충분조건이 아닙니다. 훈련 손실이 낮아도 검증 성능이 나쁘면 과적합일 수 있습니다. 이 문제는 [과적합과 L1·L2 정규화](06-overfitting-and-regularization.md)에서 이어서 다룹니다.

### 7) 한 줄 정리

> 저장된 수치는 학습 가능성을 보여 주는 근거이지만, 조건을 통제하고 반복하기 전에는 초기화 방법의 절대 순위가 아니다.

## 코드로 보기 — 층별 활성값 표준편차 추적하기

```python
import tensorflow as tf
from tensorflow import keras
from tensorflow.keras import layers

def make_stack(initialization, activation, depth=6, width=64):
    return keras.Sequential([
        layers.Dense(
            width,
            activation=activation,
            kernel_initializer=initialization,
        )
        for _ in range(depth)
    ])

x = tf.random.normal((1000, 64), seed=42)
model = make_stack("he_normal", "relu")

h = x
for index, layer in enumerate(model.layers, start=1):
    h = layer(h)
    print(index, float(tf.math.reduce_std(h)))
```

### 코드 목적

학습 전 순전파만 수행해, 같은 초기화와 활성화 조합에서 층이 깊어질수록 활성값의 표준편차가 어떻게 변하는지 확인합니다.

### 코드 흐름

1. 평균 0의 가상 입력을 만든다.
2. 같은 폭의 층을 여섯 개 쌓는다.
3. 한 층씩 통과할 때마다 출력 표준편차를 기록한다.
4. 감소·폭증·안정 패턴을 비교한다.

### 실행 결과 해석

표준편차가 빠르게 0에 가까워지면 뒤쪽 층에 전달되는 표현이 약해지는 신호일 수 있습니다. 반대로 계속 커지면 수치가 불안정해질 가능성을 확인해야 합니다. 다만 표준편차만으로 포화나 기울기 상태를 모두 판단할 수 없으므로 활성값 히스토그램과 gradient norm도 함께 보는 것이 좋습니다.

### 실무 연결

새 모델이 첫 배치부터 손실 `NaN`을 내거나 층별 출력이 거의 같은 값이 된다면, 학습률만 바꾸기 전에 초기화와 활성화의 조합을 확인합니다. 사용자 정의 층을 만들 때는 기본 초기화가 무엇인지 명시하고 첫 순전파의 분포를 로깅하면 원인 추적이 빨라집니다.

## 헷갈리기 쉬운 포인트

| 헷갈리는 개념 | 차이 |
|---|---|
| 초기화 vs 학습 | 초기화는 첫 가중치를 정하고, 학습은 손실의 기울기로 그 값을 반복 수정 |
| 분산 vs 표준편차 | 분산은 편차 제곱의 평균, 표준편차는 분산의 제곱근 |
| `fan_in` vs `fan_out` | 한 뉴런으로 들어오는 연결 수 vs 한 층에서 다음 층으로 나가는 연결 수 |
| Xavier vs He | 전자는 선형·Tanh 계열에서 자주 쓰이고, 후자는 ReLU의 신호 감소를 고려한 더 큰 분산 사용 |
| 활성값 안정 vs 기울기 안정 | 순전파 신호가 유지되는 것과 역전파 기울기가 유지되는 것은 관련 있지만 동일하지 않음 |
| 단일 실행값 vs 일반 법칙 | 한 조건의 관찰값 vs 통제된 반복 실험으로 확인한 경향 |
