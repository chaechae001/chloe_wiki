# 손실 함수와 경사하강법 — 틀린 정도를 줄이는 학습의 나침반

> 모델은 처음부터 답을 아는 것이 아니라, 얼마나 틀렸는지를 숫자로 확인하며 조금씩 나아갑니다. 손실 함수가 목적지를 알려 주는 점수표라면, 경사하강법은 그 점수를 낮추는 이동 규칙입니다.

`손실 함수` · `평균제곱오차` · `경사하강법` · `학습률` · `최적화`

## 핵심요약

- 손실 함수는 정답과 예측의 차이를 하나의 숫자로 나타내며, 작을수록 현재 예측이 정답에 가깝다.
- 평균제곱오차는 오차를 제곱해 평균하므로 큰 실수에 더 큰 벌점을 준다.
- 경사하강법은 손실의 기울기와 반대 방향으로 가중치를 반복해서 이동시킨다.
- 학습률은 한 번에 움직이는 거리이며, 너무 작으면 느리고 너무 크면 최솟값을 지나칠 수 있다.
- 저장된 수렴 기록에서 $w$는 $2.988666 \rightarrow 2.995358$, 손실은 $0.000128 \rightarrow 0.000022$로 변했다.

## 1. 손실 함수 — 모델의 틀린 정도를 숫자로 만들기

### 1) 정의

손실 함수(loss function)는 정답 $y$와 모델의 예측 $\hat{y}$가 얼마나 다른지를 수치로 바꾸는 함수입니다.

회귀에서는 평균제곱오차(MSE)를 자주 사용합니다.

$$
\mathrm{MSE}=\frac{1}{N}\sum_{i=1}^{N}(y_i-\hat{y}_i)^2
$$

여기서 $N$은 데이터 개수이고, $y_i-\hat{y}_i$는 각 데이터의 예측 오차입니다. 오차를 제곱하므로 양수와 음수가 서로 지워지지 않으며, 크게 틀린 예측은 더 무겁게 반영됩니다.

이진 분류에서는 정답 확률을 얼마나 잘 맞혔는지 보는 이진 교차엔트로피(BCE)를 많이 사용합니다.

$$
\mathrm{BCE}=-\frac{1}{N}\sum_{i=1}^{N}\left[y_i\log \hat{y}_i+(1-y_i)\log(1-\hat{y}_i)\right]
$$

쉽게 말해, 정답인 범주에 낮은 확률을 자신 있게 주면 큰 손실을 받는 방식입니다.

### 2) 왜 필요한가

모델에게 “더 잘해”라고 말하는 것만으로는 가중치를 바꿀 수 없습니다. 어느 예측이 얼마나 나빴는지 계산 가능한 목표가 있어야 합니다.

손실 함수는 다음 세 역할을 합니다.

- 모델의 현재 상태를 하나의 숫자로 평가한다.
- 가중치를 어느 방향으로 바꿀지 미분할 기준을 만든다.
- 학습 전후의 개선 정도를 비교하게 한다.

결국 모델 학습은 “손실을 작게 만드는 파라미터를 찾는 문제”로 바뀝니다.

### 3) 핵심 흐름 재구성

학습 한 번의 흐름은 다음과 같습니다.

1. 입력을 이용해 예측값 $\hat{y}$를 계산한다.
2. 정답 $y$와 비교해 손실 $L$을 구한다.
3. 각 가중치가 손실에 미친 영향을 기울기로 계산한다.
4. 손실이 줄어드는 방향으로 가중치를 갱신한다.
5. 같은 과정을 반복하며 손실의 변화를 확인한다.

이때 손실은 “현재 위치가 얼마나 나쁜가”를 말해 주고, 기울기는 “어느 방향이 더 나빠지는가”를 말해 줍니다.

### 4) 쉬운 예시

다트판의 중심을 맞히는 연습을 떠올려 봅시다. 화살이 중심에서 2cm 벗어났다면 2라는 거리만 알 수 있습니다. 하지만 가로와 세로의 차이를 함께 계산하면 다음 화살을 어느 방향으로 조정할지도 알 수 있습니다.

손실은 중심에서 벗어난 정도이고, 기울기는 손을 어느 쪽으로 고쳐야 하는지 알려 주는 신호입니다.

### 5) 코드 예시

아래 코드는 두 예측의 평균제곱오차를 직접 계산하는 최소 예제입니다.

```python
def mean_squared_error(targets, predictions):
    squared_errors = [
        (target - prediction) ** 2
        for target, prediction in zip(targets, predictions)
    ]
    return sum(squared_errors) / len(squared_errors)


targets = [3.0, 1.0]
predictions = [2.5, 1.5]
print(f"MSE = {mean_squared_error(targets, predictions):.2f}")
```

```text
MSE = 0.25
```

두 데이터의 오차는 각각 $0.5$와 $-0.5$이고, 제곱하면 모두 $0.25$입니다. 두 값을 평균해도 손실은 $0.25$입니다.

### 6) 헷갈리는 점

손실이 작다고 해서 언제나 실무 목표를 잘 달성한 것은 아닙니다. 손실은 학습을 위한 계산 기준이고, 정확도나 재현율 같은 평가지표는 사용 목적에 맞춰 성능을 해석하는 기준입니다.

또한 MSE가 $0.25$라는 값만 보고 좋고 나쁨을 단정할 수 없습니다. 정답 값의 범위와 비교해야 의미가 생깁니다.

### 7) 한 줄 정리

> 손실 함수는 모델의 실수를 계산 가능한 목표로 바꾸어 학습의 출발점을 만든다.

## 2. 경사하강법 — 기울기의 반대 방향으로 이동하기

### 1) 정의

경사하강법(gradient descent)은 현재 위치에서 손실이 가장 빠르게 커지는 방향인 기울기를 구한 뒤, 그 반대 방향으로 파라미터를 이동시키는 최적화 방법입니다.

$$
w_{t+1}=w_t-\alpha\frac{dL}{dw}(w_t)
$$

$w_t$는 현재 가중치, $\alpha$는 학습률, $\frac{dL}{dw}$는 현재 위치의 기울기입니다. 식의 빼기 기호가 손실이 커지는 방향과 반대로 움직인다는 뜻입니다.

### 2) 왜 필요한가

신경망에는 수많은 가중치가 있어 가능한 값을 전부 대입해 볼 수 없습니다. 경사하강법은 현재 위치의 국소적인 정보만으로 다음 이동을 결정하므로, 매우 큰 파라미터 공간에서도 반복적으로 더 나은 값을 찾을 수 있습니다.

### 3) 핵심 흐름 재구성

간단한 손실 함수를 생각해 봅시다.

$$
L(w)=(w-3)^2
$$

이 식은 $w=3$일 때 $L(w)=0$이 되어 최솟값을 갖습니다. 미분하면 다음과 같습니다.

$$
\frac{dL}{dw}=2(w-3)
$$

쉬운 말로 풀면, 현재 $w$가 3보다 작을 때 기울기는 음수이고 3보다 클 때는 양수입니다.

- $w<3$: 음의 기울기를 빼므로 $w$가 커진다.
- $w>3$: 양의 기울기를 빼므로 $w$가 작아진다.
- $w=3$: 기울기가 0이어서 더 움직이지 않는다.

따라서 양쪽 어디에서 시작해도 적절한 학습률을 사용하면 $w=3$을 향해 이동합니다.

### 4) 쉬운 예시

안개가 낀 산에서 가장 낮은 계곡을 찾는 상황과 비슷합니다. 멀리 볼 수 없어도 발밑의 경사를 느끼고 내리막 방향으로 한 걸음씩 걸으면 낮은 곳에 가까워집니다.

기울기는 발밑 경사의 방향과 크기이고, 학습률은 보폭입니다. 보폭이 지나치게 크면 계곡 바닥을 넘어 반대편으로 튀고, 너무 작으면 도착하는 데 오래 걸립니다.

### 5) 코드 예시

한 번의 갱신을 수식 그대로 옮기면 다음과 같습니다.

```python
def loss(w):
    return (w - 3.0) ** 2


def gradient(w):
    return 2.0 * (w - 3.0)


w = 0.0
learning_rate = 0.1
w = w - learning_rate * gradient(w)

print(f"w = {w:.1f}")
print(f"loss = {loss(w):.2f}")
```

```text
w = 0.6
loss = 5.76
```

처음 $w=0$에서 기울기는 $-6$입니다. 이를 $0-0.1\times(-6)$으로 갱신하면 $w=0.6$이 되어 최솟값 3에 가까워집니다.

### 6) 헷갈리는 점

기울기가 음수라는 말은 손실이 나쁘다는 뜻이 아닙니다. 현재 위치에서 $w$를 증가시킬수록 손실이 내려간다는 방향 정보입니다.

또한 경사하강법이 언제나 전체에서 가장 낮은 지점을 찾는다고 보장할 수는 없습니다. 복잡한 손실 지형에서는 초기값과 학습률의 영향을 받습니다.

### 7) 한 줄 정리

> 경사하강법은 현재 기울기의 반대 방향으로 파라미터를 반복 이동시켜 손실을 줄인다.

## 코드로 보기 — 30번의 이동으로 $w=3$에 가까워지기

```python
def loss(w):
    return (w - 3.0) ** 2


def gradient(w):
    return 2.0 * (w - 3.0)


learning_rate = 0.1
w = 0.0
trace = []

for step in range(30):
    trace.append((step, w, loss(w), gradient(w)))
    w -= learning_rate * gradient(w)

for step, weight, current_loss, grad in trace[-5:]:
    print(
        f"{step:2d} w={weight:.6f} "
        f"loss={current_loss:.6f} grad={grad:.6f}"
    )
```

### 코드 목적

단순한 이차 손실에서 경사하강법이 최솟값 $w=3$을 향해 실제로 수렴하는 과정을 확인합니다.

### 코드 흐름

1. 손실과 기울기 함수를 각각 정의한다.
2. $w=0$, 학습률 $0.1$에서 시작한다.
3. 갱신 전의 단계·가중치·손실·기울기를 기록한다.
4. `w -= learning_rate * gradient(w)`로 30번 갱신한다.
5. 마지막 다섯 기록을 소수점 여섯 자리로 확인한다.

### 저장된 실행 결과

```text
25 w=2.988666 loss=0.000128 grad=-0.022667
26 w=2.990933 loss=0.000082 grad=-0.018134
27 w=2.992746 loss=0.000053 grad=-0.014507
28 w=2.994197 loss=0.000034 grad=-0.011606
29 w=2.995358 loss=0.000022 grad=-0.009285
```

### 실행 결과 해석

$w$는 마지막 다섯 기록에서 $2.988666 \rightarrow 2.995358$로 증가하며 목표값 3에 가까워졌습니다. 같은 구간에서 손실은 $0.000128 \rightarrow 0.000022$로 약 82.8% 감소했습니다.

기울기는 계속 음수이지만 절댓값은 $0.022667 \rightarrow 0.009285$로 작아집니다. 이는 아직 오른쪽으로 이동해야 하지만, 바닥에 가까워져 경사가 완만해졌다는 뜻입니다.

그래프로 그리면 가중치 점들은 $w=3$ 근처에 점점 빽빽하게 모이고, 단계별 손실 곡선은 0을 향해 빠르게 낮아지는 모양이 됩니다.

### 실무 연결

실제 모델에서는 하나의 $w$ 대신 많은 가중치와 편향을 동시에 갱신합니다. 원리는 같습니다. 학습 기록에서 손실이 안정적으로 내려가는지, 발산하거나 흔들리지는 않는지 관찰해 학습률과 최적화 설정을 조정합니다.

## 헷갈리기 쉬운 포인트

| 헷갈리는 개념 | 차이 |
|---|---|
| 손실 함수 vs 평가지표 | 손실 함수는 파라미터 갱신에 직접 쓰이고, 평가지표는 목표에 맞춰 성능을 해석하는 데 주로 쓰인다. |
| 손실값 vs 기울기 | 손실값은 현재 틀린 정도이고, 기울기는 파라미터를 늘릴 때 손실이 변하는 방향과 민감도다. |
| 기울기 방향 vs 이동 방향 | 기울기는 가장 빠른 증가 방향이고, 경사하강법은 그 반대 방향으로 이동한다. |
| 학습률이 작음 vs 큼 | 작으면 안정적이지만 느리고, 크면 빠를 수 있지만 진동하거나 발산할 수 있다. |
