# 순전파·역전파와 자동미분 — 예측의 길을 거꾸로 따라가기

> 신경망은 입력에서 출력으로 계산해 예측을 만들고, 출력에서 입력 쪽으로 영향을 되짚어 학습합니다. 자동미분은 이 긴 미분 경로를 기록하고 계산해 주어, 우리는 모델 구조와 결과 해석에 집중할 수 있게 합니다.

`순전파` · `역전파` · `연쇄법칙` · `자동미분` · `GradientTape`

## 핵심요약

- 순전파는 입력을 층별 연산에 통과시켜 예측값과 손실을 계산하는 과정이다.
- 역전파는 손실에서 출발해 각 파라미터가 손실에 미친 영향을 뒤쪽부터 계산한다.
- 연쇄법칙은 여러 함수가 이어질 때 각 구간의 미분값을 곱해 전체 변화율을 구하는 규칙이다.
- `GradientTape`는 블록 안의 연산을 기록하고 지정한 변수에 대한 손실의 기울기를 자동 계산한다.
- 저장된 단일 계산에서 `y_hat=0.5`, `loss=0.25`, `dL/dw=-0.5`, `dL/db=-0.25`가 확인된다.

## 1. 순전파 — 입력으로 예측 만들기

### 1) 정의

순전파(forward propagation)는 입력값이 모델의 각 층을 앞에서 뒤로 통과하며 최종 예측값을 만드는 과정입니다.

한 개의 뉴런에서는 먼저 선형 결합을 계산합니다.

$$z=wx+b$$

$x$는 입력, $w$는 입력의 영향력을 조절하는 가중치, $b$는 기준점을 옮기는 편향입니다. 이어서 활성화 함수를 적용합니다.

$$\hat{y}=\sigma(z)=\frac{1}{1+e^{-z}}$$

시그모이드 함수는 어떤 실수든 0과 1 사이로 바꾸므로 이진 결과의 확률처럼 해석하기 좋습니다.

### 2) 왜 필요한가

손실을 구하려면 먼저 예측값이 있어야 합니다. 순전파는 현재 가중치와 편향으로 모델이 어떤 답을 내는지 계산해, 학습의 출발점이 되는 손실을 만듭니다.

### 3) 핵심 흐름 재구성

입력 $x=2$, 가중치 $w=0.5$, 편향 $b=-1$을 넣어 계산해 봅시다.

$$z=0.5\times2+(-1)=0$$

쉬운 말로는, 가중합 1과 편향 -1이 서로 상쇄되어 활성화 함수에 0이 들어간다는 뜻입니다.

$$\hat{y}=\sigma(0)=\frac{1}{1+e^0}=0.5$$

정답이 $y=1$이고 제곱오차를 사용하면 손실은 다음과 같습니다.

$$L=(y-\hat{y})^2=(1-0.5)^2=0.25$$

### 4) 쉬운 예시

여러 단계로 가격을 계산하는 영수증을 떠올려 봅시다. 상품 가격에 수량을 곱하고, 할인액을 빼고, 세율을 적용해 최종 결제액을 구합니다. 이것이 앞 방향 계산입니다.

신경망의 순전파도 입력에 가중치·편향·활성화 함수를 차례로 적용해 최종 예측을 만듭니다.

### 5) 코드 예시

순전파 계산만 파이썬 표준 함수로 옮기면 다음과 같습니다.

```python
from math import exp
def sigmoid(value):
    return 1.0 / (1.0 + exp(-value))
x = 2.0
w = 0.5
b = -1.0
target = 1.0
z = w * x + b
y_hat = sigmoid(z)
loss = (target - y_hat) ** 2
print(f"z = {z:.1f}, y_hat = {y_hat:.1f}, loss = {loss:.2f}")
```

```text
z = 0.0, y_hat = 0.5, loss = 0.25
```

### 6) 헷갈리는 점

$z$와 $\hat{y}$는 같은 값이 아닙니다. $z$는 가중합이고, $\hat{y}$는 $z$를 활성화 함수에 통과시킨 결과입니다.

### 7) 한 줄 정리

> 순전파는 현재 파라미터로 입력을 변환해 예측과 손실을 만드는 앞 방향 계산이다.

## 2. 역전파와 연쇄법칙 — 책임을 뒤에서부터 나누기

### 1) 정의

역전파(backpropagation)는 최종 손실이 각 가중치와 편향에 얼마나 민감한지 출력 쪽에서 입력 쪽으로 계산하는 방법입니다.

여러 함수가 이어졌을 때 사용하는 연쇄법칙은 다음처럼 쓸 수 있습니다.

$$\frac{dL}{dw}=\frac{dL}{d\hat{y}}\cdot\frac{d\hat{y}}{dz}\cdot\frac{dz}{dw}$$

전체 변화율을 한 번에 외우는 대신, 손실→예측, 예측→가중합, 가중합→가중치의 작은 변화율을 차례로 곱합니다.

### 2) 왜 필요한가

가중치마다 손실에 끼친 영향이 다릅니다. 모든 가중치를 같은 크기로 바꾸면 어떤 것은 좋아지고 다른 것은 나빠질 수 있습니다.

### 3) 핵심 흐름 재구성

앞에서 계산한 $y=1$, $\hat{y}=0.5$, $x=2$를 이용해 직접 미분해 봅시다.

먼저 제곱오차를 예측값으로 미분합니다.

$$\frac{dL}{d\hat{y}}=2(\hat{y}-y)=2(0.5-1)=-1$$

쉽게 말해, 예측값을 조금 키우면 정답 1에 가까워져 손실이 감소하므로 기울기가 음수입니다.

시그모이드의 미분은 다음과 같습니다.

$$\frac{d\hat{y}}{dz}=\hat{y}(1-\hat{y})=0.5(1-0.5)=0.25$$

선형 결합 $z=wx+b$에서는 다음이 성립합니다.

$$\frac{dz}{dw}=x=2,\qquad \frac{dz}{db}=1$$

이제 각 구간을 곱합니다.

$$\frac{dL}{dw}=(-1)\times0.25\times2=-0.5$$

$$\frac{dL}{db}=(-1)\times0.25\times1=-0.25$$

### 4) 쉬운 예시

최종 결제액이 예상보다 1,000원 높다고 가정합시다. 원인을 찾으려면 마지막 세금 계산, 그전의 할인, 더 앞의 수량과 단가를 거꾸로 확인합니다.

### 5) 코드 예시

아래 코드는 연쇄법칙의 네 값을 직접 계산해 자동미분 결과와 비교할 기준을 만듭니다.

```python
y_hat = 0.5
target = 1.0
x = 2.0
d_loss_d_y_hat = 2.0 * (y_hat - target)
d_y_hat_d_z = y_hat * (1.0 - y_hat)
d_z_d_w = x
d_z_d_b = 1.0
d_loss_d_w = d_loss_d_y_hat * d_y_hat_d_z * d_z_d_w
d_loss_d_b = d_loss_d_y_hat * d_y_hat_d_z * d_z_d_b
print(f"dL/dw = {d_loss_d_w:.2f}")
print(f"dL/db = {d_loss_d_b:.2f}")
```

```text
dL/dw = -0.50
dL/db = -0.25
```

### 6) 헷갈리는 점

역전파와 파라미터 갱신은 같은 일이 아닙니다. 역전파는 기울기를 계산하고, 최적화 알고리즘은 그 기울기를 이용해 실제 값을 바꿉니다.

### 7) 한 줄 정리

> 역전파는 연쇄법칙으로 손실의 영향을 계산 경로 뒤쪽부터 나누어 각 파라미터의 기울기를 구한다.

## 3. 자동미분 — 계산 경로를 기록해 기울기 구하기

### 1) 정의

자동미분(automatic differentiation)은 프로그램이 수행한 기본 연산들을 기록한 뒤 연쇄법칙을 적용해 정확한 미분값을 계산하는 방식입니다.

TensorFlow의 `GradientTape`는 문맥 안에서 변수와 관련된 연산을 기록합니다. 이후 `tape.gradient(loss, [w, b])`를 호출하면 손실을 $w$와 $b$로 각각 미분한 값이 반환됩니다.

### 2) 왜 필요한가

층이 깊어지면 사람이 모든 편미분식을 직접 전개하기 어렵고 실수도 늘어납니다. 자동미분은 미분 가능한 연산의 연결을 추적해 같은 규칙을 일관되게 적용합니다.

### 3) 핵심 흐름 재구성

1. 바뀌지 않는 입력과 정답은 상수로 둔다.
2. 학습할 가중치와 편향은 변수로 만든다.
3. 테이프 문맥 안에서 순전파와 손실을 계산한다.
4. 문맥 밖에서 손실을 기준으로 변수들의 기울기를 요청한다.
5. 기울기의 부호와 크기를 해석한 뒤 갱신에 사용한다.

### 4) 쉬운 예시

테이프는 요리 과정을 순서대로 적는 조리 기록과 비슷합니다. 완성된 음식의 짠맛을 줄이고 싶을 때, 기록을 거꾸로 보며 소금 한 숟가락과 물 한 컵이 최종 맛에 미친 영향을 계산할 수 있습니다.

### 5) 코드 예시

```python
import tensorflow as tf
x = tf.constant(2.0)
target = tf.constant(1.0)
w = tf.Variable(0.5)
b = tf.Variable(-1.0)
with tf.GradientTape() as tape:
    z = w * x + b
    y_hat = tf.math.sigmoid(z)
    loss = (target - y_hat) ** 2
d_loss_d_w, d_loss_d_b = tape.gradient(loss, [w, b])
print("y_hat =", float(y_hat))
print("loss =", float(loss))
print("dL/dw =", float(d_loss_d_w))
print("dL/db =", float(d_loss_d_b))
```

### 6) 헷갈리는 점

상수는 기본적으로 학습 대상이 아닙니다. 입력 $x$와 정답은 고정하고, 모델이 바꿔야 할 $w$와 $b$를 변수로 두는 이유입니다.

### 7) 한 줄 정리

> 자동미분은 순전파에서 기록된 연산 관계를 역순으로 따라가며 각 학습 변수의 기울기를 계산한다.

## 코드로 보기 — 한 뉴런의 예측과 기울기 확인

### 코드 목적

하나의 시그모이드 뉴런에서 순전파 결과와 자동미분 결과를 함께 확인하고, 수동 연쇄법칙 계산과 일치하는지 검증합니다.

### 코드 흐름

1. 입력 2와 정답 1을 상수로 준비한다.
2. 가중치 0.5와 편향 -1을 학습 변수로 준비한다.
3. $z=wx+b$와 시그모이드를 거쳐 예측값을 구한다.
4. 제곱오차 손실을 계산한다.
5. 손실을 가중치와 편향으로 각각 미분한다.

### 저장된 실행 결과

```text
y_hat = 0.5
loss = 0.25
dL/dw = -0.5
dL/db = -0.25
```

### 실행 결과 해석

순전파에서 $z=0$이므로 예측값은 정확히 $0.5$이고, 정답 1과의 제곱오차는 $0.25$입니다.

$dL/dw=-0.5$와 $dL/db=-0.25$는 두 변수를 증가시키는 방향이 손실을 낮춘다는 뜻입니다. 예를 들어 학습률이 $0.1$이면 경사하강법의 한 번 갱신은 다음과 같습니다.

$$w_{new}=0.5-0.1(-0.5)=0.55$$

$$b_{new}=-1-0.1(-0.25)=-0.975$$

두 값이 모두 커지면 $z$와 $\hat{y}$가 커져 정답 1에 가까워지는 방향으로 움직입니다.

### 실무 연결

복잡한 신경망 학습에서도 모델 호출로 순전파를 수행하고, 자동미분으로 손실의 기울기를 구한 뒤, 최적화 도구가 파라미터를 갱신합니다. 기울기가 `None`이거나 모두 0에 가깝다면 계산 경로가 끊겼는지, 미분이 약해지는 활성화 구간인지 점검할 단서가 됩니다.

## 직접 해보기

1. $x=2$, $w=0.5$, $b=-1$일 때 $z$와 시그모이드 출력은 얼마인가요?
2. $y=1$, $\hat{y}=0.5$일 때 $\frac{dL}{d\hat{y}}$와 $\frac{d\hat{y}}{dz}$를 구하세요.
3. 입력 $x$가 4로 바뀌고 나머지 중간값이 같다고 가정하면, $\frac{dz}{dw}$의 변화가 $\frac{dL}{dw}$에 어떤 영향을 주나요?

<details>
<summary>정답 보기</summary>

1. $z=0.5\times2-1=0$이고, $\sigma(0)=0.5$입니다.
2. $\frac{dL}{d\hat{y}}=2(0.5-1)=-1$, $\frac{d\hat{y}}{dz}=0.5(1-0.5)=0.25$입니다.
3. $\frac{dz}{dw}=x$이므로 2에서 4로 두 배가 됩니다. 다른 미분값이 같다면 $\frac{dL}{dw}$의 절댓값도 두 배가 되어 입력 크기가 가중치 기울기에 직접 반영됩니다.

</details>

## 헷갈리기 쉬운 포인트

| 헷갈리는 개념 | 차이 |
|---|---|
| 순전파 vs 역전파 | 순전파는 예측과 손실을 계산하고, 역전파는 손실의 파라미터별 기울기를 계산한다. |
| 역전파 vs 경사하강법 | 역전파는 기울기를 구하는 절차이고, 경사하강법은 그 기울기로 파라미터를 갱신하는 규칙이다. |
| 수치미분 vs 자동미분 | 수치미분은 작은 값 변화를 대입해 근사하고, 자동미분은 연산별 미분 규칙을 연결해 계산한다. |
| 상수 vs 변수 | 상수는 고정 데이터에, 변수는 학습 중 바뀌는 파라미터에 사용한다. |

## 한 줄 정리

> 순전파가 예측과 손실을 만들면 역전파가 그 계산을 거꾸로 따라 기울기를 구하고, 자동미분은 이 연쇄법칙을 코드의 실제 연산 경로에 맞춰 정확하게 수행한다.
