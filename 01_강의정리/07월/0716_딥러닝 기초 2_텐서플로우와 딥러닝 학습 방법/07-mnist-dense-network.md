# MNIST 완전연결 신경망 — 28×28 픽셀을 열 개의 확률로 바꾸기

> 손글씨 이미지 한 장은 컴퓨터에게 784개의 숫자입니다. 이 숫자를 펼치고, 중요한 조합을 찾고, 열 개 후보의 확률로 바꾸는 과정을 따라가면 이미지 분류 신경망의 기본 구조가 보입니다.

`MNIST` · `Flatten` · `Dense` · `Dropout` · `Softmax`

## 핵심요약

- 데이터는 훈련용 60,000장과 테스트용 10,000장으로 구성되고, 각 이미지는 28×28 픽셀이다.
- 픽셀값을 0~255에서 0~1로 정규화한 뒤 `Flatten`으로 784개 입력 특성으로 펼친다.
- `Dense(128) → Dropout(0.2) → Dense(64) → Dense(10)` 구조의 학습 가능한 파라미터는 109,386개다.
- 저장된 실행 결과에서 훈련 정확도는 0.9094에서 0.9747로 높아졌고 마지막 검증 정확도는 0.9778이었다.
- 별도로 보관한 테스트 데이터의 정확도는 0.9747로, 약 97.47%를 올바르게 분류한 결과다.

## 1. 이미지 데이터를 신경망 입력으로 바꾸기

### 1) 정의

MNIST는 0부터 9까지의 손글씨 숫자 이미지를 분류하는 대표적인 다중 분류 데이터입니다. 한 이미지는 높이 28, 너비 28인 흑백 픽셀 배열이며, 정답은 숫자 클래스 하나입니다.

훈련 데이터의 모양은 `(60000, 28, 28)`, 테스트 데이터의 모양은 `(10000, 28, 28)`입니다. 첫 번째 축은 이미지 개수이고 뒤의 두 축은 세로와 가로 픽셀 수입니다.

### 2) 왜 필요한가

Dense 층은 각 관측값을 1차원 특성 벡터로 받습니다. 따라서 2차원 이미지를 784개 값으로 펼쳐야 합니다. 또한 픽셀 범위를 작고 일정하게 맞추면 기울기 기반 학습이 큰 숫자 범위에 끌려가지 않고 더 안정적으로 진행됩니다.

### 3) 핵심 흐름 재구성

전처리 과정은 두 단계로 볼 수 있습니다.

1. 픽셀값의 자료형을 실수형으로 바꾼다.
2. 모든 픽셀을 255로 나눠 0~1 범위로 옮긴다.

$$
x_{\text{scaled}} = \frac{x}{255}
$$

검은색에 가까운 픽셀은 0 부근, 밝은 픽셀은 1 부근이 되며 상대적 밝기는 유지됩니다.

그다음 `Flatten`은 위치의 순서를 유지한 채 행과 열을 한 줄로 폅니다.

$$
28 \times 28 = 784
$$

쉽게 말하면 28칸짜리 줄 28개를 위에서부터 차례대로 이어 붙여 784칸짜리 긴 줄로 만드는 것입니다.

### 4) 쉬운 예시

바둑판 사진을 서랍에 넣는다고 생각해 봅시다. Dense 층의 서랍은 한 줄짜리 칸만 받습니다. 그래서 첫째 줄 28칸 뒤에 둘째 줄 28칸을 이어 붙입니다. 모양을 한 줄로 바꿔도 각 칸의 밝기와 순서는 사라지지 않습니다.

정규화는 255점 만점의 점수를 1점 만점으로 환산하는 것과 같습니다. 127.5는 0.5가 되고, 값의 상대적 위치는 그대로입니다.

### 5) 코드 예시

아래 코드는 데이터 크기를 확인하고 픽셀을 정규화하는 최소 예제입니다.

```python
from tensorflow import keras

(x_train, y_train), (x_test, y_test) = keras.datasets.mnist.load_data()

x_train = x_train.astype("float32") / 255.0
x_test = x_test.astype("float32") / 255.0

print("train:", x_train.shape, y_train.shape)
print("test :", x_test.shape, y_test.shape)
```

```text
train: (60000, 28, 28) (60000,)
test : (10000, 28, 28) (10000,)
```

### 6) 헷갈리는 점

`Flatten`은 학습하는 층이 아닙니다. 값의 순서와 모양만 바꾸므로 가중치와 편향이 없습니다. 정규화도 이미지 수를 줄이거나 해상도를 낮추는 작업이 아니라 픽셀값의 범위만 바꾸는 작업입니다.

### 7) 한 줄 정리

> 이미지를 Dense 신경망에 넣기 위해 픽셀을 0~1로 맞추고 28×28 배열을 784개 특성으로 펼친다.

## 2. Dense·Dropout·Softmax로 분류기 만들기

### 1) 정의

Dense 층은 이전 층의 모든 출력과 연결되는 완전연결층입니다. 각 유닛은 입력의 가중합에 편향을 더하고 활성화 함수를 적용합니다.

$$
h = f(Wx+b)
$$

Dropout은 훈련 중 일부 은닉 출력을 무작위로 0으로 만들어 특정 연결에 지나치게 의존하지 않도록 돕습니다. 출력층의 Softmax는 열 개 점수를 합이 1인 확률로 바꿉니다.

### 2) 왜 필요한가

첫 Dense 층은 784개 픽셀의 조합에서 획, 굽음, 빈 공간처럼 분류에 도움이 되는 패턴을 학습합니다. 두 번째 Dense 층은 그 패턴을 다시 조합합니다. Dropout은 훈련 데이터에만 맞춘 공동 적응을 줄이는 규제 역할을 하며, Softmax는 열 개 클래스 중 어느 숫자일 가능성이 큰지 비교할 수 있게 합니다.

### 3) 핵심 흐름 재구성

출력층이 만든 클래스별 점수를 로짓 $z_k$라고 하면 Softmax 확률은 다음과 같습니다.

$$
p_k = \frac{e^{z_k}}{\sum_{j=0}^{9}e^{z_j}}
$$

열 개 확률의 합은 1이며 가장 큰 확률의 인덱스가 예측 숫자가 됩니다.

정답이 정수 레이블일 때 희소 범주형 교차엔트로피는 정답 클래스의 확률만 골라 로그 손실을 계산합니다.

$$
L = -\log p_y
$$

정답 숫자 $y$에 준 확률 $p_y$가 1에 가까우면 손실은 0에 가까워지고, 0에 가까우면 큰 벌점을 받습니다.

파라미터 수는 Dense 층마다 다음처럼 계산합니다.

$$
\text{parameters}=(\text{input units}\times\text{output units})+\text{output units}
$$

| 층 | 계산 | 파라미터 수 |
|---|---:|---:|
| 784 → 128 | $784\times128+128$ | 100,480 |
| 128 → 64 | $128\times64+64$ | 8,256 |
| 64 → 10 | $64\times10+10$ | 650 |
| 합계 | $100{,}480+8{,}256+650$ | 109,386 |

`Flatten`과 `Dropout`은 학습할 가중치가 없으므로 합계에 더해지지 않습니다.

### 4) 쉬운 예시

열 명의 심사위원이 숫자 후보 하나씩을 맡는다고 생각해 봅시다. 앞단의 Dense 층들은 획과 모양을 요약해 전달하고, 마지막 열 명은 각각 “0 같다”, “1 같다”라는 점수를 냅니다. Softmax는 이 점수를 전체 100%의 지지율로 환산합니다.

Dropout은 훈련할 때 일부 팀원을 무작위로 쉬게 하는 것과 비슷합니다. 특정 한 사람의 판단만 외우지 않고 여러 단서 조합으로 답하도록 연습시키는 효과를 노립니다.

### 5) 코드 예시

```python
from tensorflow import keras
from tensorflow.keras import layers

model = keras.Sequential([
    layers.Input(shape=(28, 28)),
    layers.Flatten(),
    layers.Dense(128, activation="relu"),
    layers.Dropout(0.2),
    layers.Dense(64, activation="relu"),
    layers.Dense(10, activation="softmax"),
])

model.summary()
```

이 구조의 학습 가능한 파라미터는 109,386개입니다.

### 6) 헷갈리는 점

Softmax가 가장 큰 확률의 클래스를 골라 주는 것은 맞지만, 확률이 잘 보정되었다는 뜻까지 보장하지는 않습니다. 또한 Dropout 0.2는 유닛을 영구 삭제하는 것이 아니라 훈련할 때만 일부 출력을 무작위로 끕니다. 평가와 예측에서는 모든 유닛을 사용합니다.

### 7) 한 줄 정리

> Dense 층은 픽셀 조합을 학습하고, Dropout은 의존을 분산시키며, Softmax는 열 개 점수를 비교 가능한 확률로 바꾼다.

## 코드로 보기 — 학습·검증·테스트까지 한 번에 연결하기

```python
from tensorflow import keras
from tensorflow.keras import layers

keras.utils.set_random_seed(42)

(x_train, y_train), (x_test, y_test) = keras.datasets.mnist.load_data()
x_train = x_train.astype("float32") / 255.0
x_test = x_test.astype("float32") / 255.0

network = keras.Sequential([
    layers.Input(shape=(28, 28)),
    layers.Flatten(),
    layers.Dense(128, activation="relu"),
    layers.Dropout(0.2),
    layers.Dense(64, activation="relu"),
    layers.Dense(10, activation="softmax"),
])

network.compile(
    optimizer="adam",
    loss="sparse_categorical_crossentropy",
    metrics=["accuracy"],
)

history = network.fit(
    x_train,
    y_train,
    epochs=5,
    batch_size=32,
    validation_split=0.1,
)

test_loss, test_accuracy = network.evaluate(x_test, y_test, verbose=0)
print("parameters:", network.count_params())
print("test accuracy:", round(float(test_accuracy), 4))
```

### 코드 목적

이미지 로드부터 정규화, 모델 구성, 학습, 검증, 최종 테스트까지 다중 분류의 기본 파이프라인을 한 흐름으로 연결합니다.

### 코드 흐름

1. 훈련용 60,000장과 테스트용 10,000장을 나눠 불러온다.
2. 픽셀값을 255로 나눠 0~1 범위로 맞춘다.
3. 784개 입력을 두 Dense 은닉층에 통과시켜 열 개 확률을 만든다.
4. Adam과 희소 범주형 교차엔트로피로 5에포크 학습한다.
5. 훈련 데이터의 10%를 검증에 사용하고, 마지막에 테스트 데이터를 한 번 평가한다.

`validation_split=0.1`이므로 60,000장 중 54,000장은 가중치 갱신에, 6,000장은 에포크별 검증에 쓰입니다. 배치 크기 32일 때 에포크당 학습 단계가 1,688회로 표시되는 이유는 $\lceil54{,}000/32\rceil=1{,}688$이기 때문입니다.

### 저장된 실행 결과

```text
train images: 60000
test images: 10000
parameters: 109386
epoch 1 train accuracy: 0.9094
epoch 5 train accuracy: 0.9747
epoch 5 validation accuracy: 0.9778
test accuracy: 0.9747
```

코드 셀의 실행 번호는 비어 있었지만 출력 블록에 위 값들이 보관되어 있었습니다. 따라서 새 실행을 가장해 만든 값이 아니라 **저장된 실행 결과**로 해석합니다. 다시 실행하면 초기화, 라이브러리 버전, 연산 장치에 따라 소수점 수준의 차이가 날 수 있습니다.

### 실행 결과 해석

훈련 정확도는 첫 에포크 0.9094에서 다섯 번째 에포크 0.9747로 0.0653, 즉 6.53%p 높아졌습니다. 모델이 반복 학습하며 픽셀 조합과 숫자 레이블의 관계를 더 잘 찾았다고 볼 수 있습니다.

마지막 검증 정확도는 0.9778로 훈련 정확도 0.9747과 가깝습니다. 이 한 번의 기록에서는 두 값이 크게 벌어지지 않았습니다. 다만 검증 정확도가 훈련 정확도보다 조금 높은 현상은 이상하지 않습니다. 훈련 중에는 Dropout이 켜져 문제가 더 어렵고, 검증할 때는 꺼지기 때문입니다.

테스트 정확도는 0.9747입니다. 테스트 이미지가 10,000장이므로 반올림한 정확도를 기준으로 약 9,747장을 맞히고 약 253장을 틀린 수준으로 해석할 수 있습니다. 정확도 하나만으로 어떤 숫자를 자주 혼동했는지는 알 수 없으므로, 다음 단계에서는 혼동행렬과 오분류 이미지를 확인해야 합니다.

### 실무 연결

이 구조는 이미지 분류의 입문 기준선으로 유용합니다. 영수증 숫자 판독이나 간단한 기호 분류에서 데이터 흐름과 평가 절차를 검증할 수 있습니다. 다만 Flatten은 픽셀의 2차원 이웃 관계를 명시적으로 활용하지 않으므로, 복잡한 이미지에서는 합성곱 신경망이 더 적합할 수 있습니다.

## 헷갈리기 쉬운 포인트

| 헷갈리는 개념 | 차이 |
|---|---|
| 정규화 vs Flatten | 정규화는 값의 범위를 바꾸고, Flatten은 배열의 모양을 바꿈 |
| Dense vs Dropout | Dense는 학습할 가중치가 있고, Dropout은 훈련 중 출력 일부를 무작위로 끄며 파라미터가 없음 |
| Sigmoid vs Softmax | Sigmoid는 각 출력을 독립적으로 0~1로 만들고, Softmax는 여러 클래스 확률의 합을 1로 만듦 |
| 범주형 교차엔트로피 vs 희소 범주형 교차엔트로피 | 정답이 원-핫 벡터면 전자, 정수 클래스면 후자를 사용 |
| 검증 데이터 vs 테스트 데이터 | 검증 데이터는 학습 선택을 점검하고, 테스트 데이터는 마지막 일반화 성능을 확인 |
| 훈련 모드 vs 평가 모드 | 훈련 중 Dropout은 켜지고, 평가·예측 중에는 꺼짐 |

**Q1. 첫 Dense 층에 파라미터가 100,480개인 이유는 무엇인가요?**

<summary>답</summary>

784개 입력이 128개 유닛 각각과 연결되어 가중치가 $784\times128=100{,}352$개 필요합니다. 여기에 유닛마다 편향 하나씩 128개를 더하면 100,480개입니다.

</details>
