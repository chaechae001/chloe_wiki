# 텐서와 즉시 실행 — 데이터의 모양을 읽고 계산 결과를 바로 확인하기

> 딥러닝 코드는 결국 숫자 묶음이 어떤 모양으로 들어와 어떻게 바뀌는지를 다루는 일입니다. 텐서의 rank와 shape를 읽고 즉시 실행의 결과를 확인할 수 있으면, 복잡한 모델도 작은 행렬 계산부터 차근차근 추적할 수 있습니다.

`Tensor` · `Eager Execution` · `rank` · `shape` · `matrix multiplication`

## 핵심요약

- 텐서는 스칼라·벡터·행렬을 모두 포함하는 다차원 숫자 배열이다.
- rank는 축의 개수이고 shape는 각 축의 길이이므로 서로 다른 정보를 말한다.
- 즉시 실행이 켜져 있으면 연산을 작성한 자리에서 결과가 계산되어 디버깅하기 쉽다.
- `+`는 같은 위치끼리 더하고 `tf.matmul`은 행과 열의 내적으로 새 값을 만든다.
- 저장된 환경 출력은 TensorFlow `2.20.0`, Eager `True`, GPU 목록 `[]`였으며 CPU만으로도 기본 텐서 연산은 수행된다.

## 1. 텐서와 rank·shape

### 1) 정의

텐서(Tensor)는 숫자를 일정한 축에 맞춰 담은 다차원 배열입니다.

- 숫자 하나는 rank 0인 스칼라입니다.
- 숫자를 한 줄로 모으면 rank 1인 벡터입니다.
- 행과 열로 펼치면 rank 2인 행렬입니다.
- 이미지 여러 장처럼 축이 더 늘어나면 rank 3 이상의 텐서가 됩니다.

rank는 **축이 몇 개인지**, shape는 **각 축에 원소가 몇 개인지**를 나타냅니다.
$$
T \in \mathbb{R}^{n_1 \times n_2 \times \cdots \times n_r}
$$

이 식은 텐서 $T$에 축이 $r$개 있고, 각 축의 길이가 $n_1, n_2, \ldots, n_r$이라는 뜻입니다.

전체 원소 수는 다음처럼 각 축의 길이를 모두 곱해 구합니다.

$$
|T| = \prod_{i=1}^{r} n_i
$$

예를 들어 shape가 `(2, 3)`이면 2행 3열이고, 원소는 $2 \times 3 = 6$개입니다.

### 2) 왜 필요한가

신경망의 한 층은 보통 텐서를 입력받아 다른 텐서를 출력합니다. 이때 shape가 맞지 않으면 행렬 곱을 수행할 수 없고, 데이터 축을 잘못 이해하면 샘플·특성·채널을 뒤섞게 됩니다.

따라서 모델을 만들기 전에 다음 세 가지를 확인하는 습관이 중요합니다.

1. 한 축이 무엇을 뜻하는가?
2. 각 축의 길이는 얼마인가?
3. 다음 연산이 요구하는 shape와 맞는가?

### 3) 핵심 흐름 재구성

다음 행렬 `a`는 가로와 세로라는 두 축을 가지므로 rank가 2입니다.

```python
import tensorflow as tf

a = tf.constant([[1.0, 2.0],
                 [3.0, 4.0]])

print(tf.rank(a).numpy())
print(a.shape)
```

```text
2
(2, 2)
```

`tf.rank(a)`는 축 개수를 텐서로 반환하고, `a.shape`는 각 축 길이를 담은 `TensorShape` 정보를 제공합니다. 저장된 실행 결과에서도 `rank(a) = 2`, `shape = (2, 2)`가 확인됩니다.

이는 원소가 네 개라는 사실보다 **2차원 구조로 배치되었다는 사실**을 알려 줍니다.

### 4) 쉬운 예시

책장을 떠올려 봅시다. 책 한 권의 가격만 적으면 숫자 하나이므로 rank 0입니다. 한 선반에 놓인 책들의 가격 목록은 한 방향으로만 나열되므로 rank 1입니다.

여러 선반과 각 선반의 칸을 함께 표현하면 행과 열이 생겨 rank 2가 됩니다.

여기에 지점 축까지 추가하면 `지점 × 선반 × 칸`의 rank 3 텐서가 됩니다.

rank는 책장의 방향 수이고, shape는 각 방향에 칸이 몇 개 있는지를 적은 설계도라고 볼 수 있습니다.

### 5) 코드 예시

```python
import tensorflow as tf

scalar = tf.constant(7)
vector = tf.constant([7, 8, 9])
matrix = tf.constant([[1, 2, 3], [4, 5, 6]])

for name, tensor in [("scalar", scalar), ("vector", vector), ("matrix", matrix)]:
    print(name, "rank=", tf.rank(tensor).numpy(), "shape=", tensor.shape)
```

```text
scalar rank= 0 shape= ()
vector rank= 1 shape= (3,)
matrix rank= 2 shape= (2, 3)
```

코드는 데이터 값이 아니라 축 구조가 어떻게 달라지는지 보여 주는 최소 예제입니다.

### 6) 헷갈리는 점

`(3,)`은 원소 3개짜리 1차원 벡터이고, `(1, 3)`은 1행 3열의 2차원 행렬입니다.

값이 세 개라는 점은 같아도 rank가 각각 1과 2이므로 행렬 연산에서 다르게 취급됩니다.

또한 rank는 선형대수에서 말하는 행렬의 독립성 개념과 이름이 같지만, 여기서는 텐서의 축 개수를 뜻합니다.

### 7) 한 줄 정리

> rank는 텐서의 축 개수, shape는 각 축의 길이를 나타내는 계산 전 점검표다.

## 2. 즉시 실행과 행렬 연산

### 1) 정의

즉시 실행(Eager Execution)은 연산을 작성하면 그 자리에서 실제 값이 계산되는 실행 방식입니다. TensorFlow 2 계열에서는 기본적으로 활성화되어 있어 일반적인 파이썬 코드처럼 중간 결과를 출력할 수 있습니다.

### 2) 왜 필요한가

딥러닝 계산은 여러 층과 수많은 연산을 통과합니다. 중간 텐서의 값과 shape를 바로 볼 수 있으면 오류가 생긴 지점을 빠르게 찾을 수 있습니다.

저장된 환경 확인 결과는 다음과 같습니다.

```text
TensorFlow version: 2.20.0
Eager Execution 활성화: True
사용 가능한 GPU: []
```

GPU 목록이 비어 있어도 덧셈과 행렬 곱 같은 기본 연산은 CPU에서 정상적으로 실행됩니다.

### 3) 핵심 흐름 재구성

두 행렬을 더할 때는 같은 위치의 값끼리 계산합니다.

$$
\begin{bmatrix}1&2\\3&4\end{bmatrix}
+
\begin{bmatrix}5&6\\7&8\end{bmatrix}
=
\begin{bmatrix}6&8\\10&12\end{bmatrix}
$$

반면 행렬 곱은 왼쪽 행과 오른쪽 열의 값을 짝지어 곱한 뒤 더합니다.

$$
(AB)_{ij} = \sum_k A_{ik}B_{kj}
$$

쉽게 말하면 결과의 한 칸을 만들기 위해 왼쪽의 한 행과 오른쪽의 한 열을 차례로 곱해 모두 더합니다.

첫 번째 결과 칸은 $1 \times 5 + 2 \times 7 = 19$가 됩니다.

### 4) 쉬운 예시

요소별 덧셈은 두 지점의 같은 상품 판매량을 합치는 일과 비슷합니다. 사과는 사과끼리, 우유는 우유끼리 더하므로 위치가 그대로 유지됩니다.

행렬 곱은 재료별 수량표와 재료별 가격표를 결합해 메뉴별 총비용을 계산하는 일에 가깝습니다.

한 행 전체와 한 열 전체가 만나 하나의 의미 있는 합계를 만듭니다.

### 5) 코드 예시

```python
import tensorflow as tf

a = tf.constant([[1.0, 2.0], [3.0, 4.0]])
b = tf.constant([[5.0, 6.0], [7.0, 8.0]])

element_sum = a + b
matrix_product = tf.matmul(a, b)

print(element_sum.numpy())
print(matrix_product.numpy())
```

```text
[[ 6.  8.]
 [10. 12.]]
[[19. 22.]
 [43. 50.]]
```

저장된 결과의 행렬 합과 행렬 곱이 각각 위 값으로 확인됩니다.

### 6) 헷갈리는 점

`a * b`는 같은 위치끼리 곱하는 성분별 곱이고, `tf.matmul(a, b)` 또는 `a @ b`는 행렬 곱입니다. 두 연산은 입력 shape가 같을 때 모두 실행될 수 있어도 결과의 의미와 숫자가 완전히 다릅니다.

`.numpy()`는 즉시 실행 중인 텐서 값을 NumPy 배열로 꺼내 확인할 때 편리합니다.

하지만 모델 학습 코드 안에서 무분별하게 변환하면 텐서 연산 흐름과 자동 미분 연결을 끊을 수 있으므로, 주로 출력 확인과 디버깅에 사용합니다.

### 7) 한 줄 정리

> 즉시 실행은 중간값을 바로 보여 주고, 행렬 곱은 행과 열을 결합해 새로운 관계를 계산한다.

## 코드로 보기 — 환경과 두 행렬의 계산 한 번에 확인하기

```python
import tensorflow as tf

print("TensorFlow version:", tf.__version__)
print("Eager:", tf.executing_eagerly())
print("GPU:", tf.config.list_physical_devices("GPU"))

a = tf.constant([[1.0, 2.0], [3.0, 4.0]])
b = tf.constant([[5.0, 6.0], [7.0, 8.0]])

print("a + b =\n", (a + b).numpy())
print("a @ b =\n", tf.matmul(a, b).numpy())
print("rank(a) =", tf.rank(a).numpy(), ", shape =", a.shape)
```

### 코드 목적

현재 실행 환경을 확인하고, 같은 두 텐서에 덧셈과 행렬 곱을 적용해 연산 의미의 차이를 비교합니다.

### 코드 흐름

1. 버전·즉시 실행 여부·GPU 장치 목록을 확인합니다.
2. shape가 `(2, 2)`인 두 상수 텐서를 만듭니다.
3. 같은 위치끼리 더한 결과와 행렬 곱 결과를 각각 계산합니다.
4. 첫 번째 텐서의 rank와 shape를 출력합니다.

### 실행 결과 해석

저장된 실행에서는 버전 `2.20.0`, Eager `True`, GPU `[]`가 출력됐습니다. 행렬 합은 `[[6, 8], [10, 12]]`, 행렬 곱은 `[[19, 22], [43, 50]]`으로 서로 달랐습니다.

또한 rank는 `2`, shape는 `(2, 2)`였으므로 두 축에 각각 길이 2가 있는 행렬임을 확인할 수 있습니다.

### 실무 연결

이미지 배치는 보통 `배치 × 높이 × 너비 × 채널`, 문장 배치는 `배치 × 토큰`처럼 표현됩니다.

모델 입력 오류를 만났을 때 값 몇 개만 보는 것보다 rank와 shape를 먼저 출력하면 축이 잘못 놓인 문제를 빠르게 찾을 수 있습니다.

추천 점수나 신경망 층의 출력처럼 여러 특성을 한꺼번에 결합할 때는 행렬 곱이 핵심 연산이 됩니다.

## 헷갈리기 쉬운 포인트

| 헷갈리는 개념 | 차이 |
|---|---|
| rank vs shape | rank는 축의 개수, shape는 축별 길이 |
| `(3,)` vs `(1, 3)` | 앞은 rank 1 벡터, 뒤는 rank 2 행렬 |
| `*` vs `tf.matmul` | 같은 위치끼리 곱하기 vs 행과 열의 내적 |
| 텐서 vs NumPy 배열 | 둘 다 다차원 배열이지만 텐서는 장치 연산·자동 미분 흐름에 참여 |
| 즉시 실행 vs 그래프 실행 | 연산 즉시 값 확인 vs 계산 구조를 묶어 최적화한 뒤 실행 |

**Q1. rank가 2라고 해서 shape도 반드시 `(2, 2)`인가요?**

<details>
<summary>답</summary>

아닙니다. rank 2는 축이 두 개라는 뜻일 뿐입니다. `(2, 3)`, `(10, 1)`, `(28, 28)`도 모두 rank 2입니다.

</details>

**Q2. 같은 두 행렬에 `*`와 `tf.matmul`을 적용하면 왜 결과가 다른가요?**

<details>
<summary>답</summary>

`*`는 같은 위치의 값만 곱하지만, `tf.matmul`은 왼쪽의 한 행과 오른쪽의 한 열을 내적해 결과 한 칸을 만듭니다. 계산 규칙과 결과가 나타내는 의미가 다릅니다.

</details>

**Q3. GPU 목록이 비어 있으면 텐서 계산을 할 수 없나요?**

<details>
<summary>답</summary>

아닙니다. CPU에서도 텐서 연산과 모델 학습을 수행할 수 있습니다. GPU는 큰 행렬 계산을 병렬로 빠르게 처리하는 가속 장치이며, 기본 연산의 필수 조건은 아닙니다.

</details>

## 한 줄 정리
