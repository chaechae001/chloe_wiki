# 회귀 기초와 손실 함수 — 모델은 무엇을 최소화하며 학습하는가

> 회귀 모델은 "정답과 예측의 차이"를 숫자로 정의하고, 그 숫자를 가장 작게 만드는 선을 찾는 과정입니다. 이 글은 그 출발점인 손실 함수와 선형·다중 회귀를 다룹니다.

`회귀` · `손실함수` · `MSE` · `선형회귀` · `회귀계수`

## 핵심요약

- 회귀는 연속형 값(가격, 팁 금액, 온도 등)을 예측하는 문제이고, 분류와 달리 결과가 범주가 아니라 숫자다.
- 모델 학습이란 "정답과 예측의 차이(오차)"를 정의하는 **손실 함수**를 최소화하는 계수를 찾는 것이다.
- 가장 널리 쓰는 손실은 MSE(평균제곱오차)로, 오차를 제곱해 평균 낸 값이다.
- 선형 회귀는 예측을 `ŷ = β₀ + β₁x` 형태의 직선으로, 다중 회귀는 여러 변수의 가중합으로 표현한다.
- 회귀계수 β는 "해당 변수가 1 늘어날 때 예측값이 평균적으로 얼마나 변하는가"를 의미한다.

## 1. 회귀와 손실 함수

### 1) 정의

회귀(Regression)는 입력 변수 X로부터 **연속적인 숫자 값** Y를 예측하는 문제입니다. 식당에서 결제 금액을 보고 팁 금액을 예측하거나, 다이아몬드의 무게로 가격을 예측하는 것이 회귀입니다. 결과가 "스팸/정상"처럼 범주로 나뉘면 분류, "3.5달러"처럼 연속값이면 회귀입니다.

손실 함수(Loss Function)는 **모델의 예측이 정답에서 얼마나 벗어났는지를 하나의 숫자로 요약**하는 함수입니다. 학습이란 이 숫자를 가장 작게 만드는 계수를 찾는 과정입니다.

### 2) 왜 필요한가

"좋은 모델"이라는 말은 애매합니다. 컴퓨터가 최적화를 하려면 좋고 나쁨을 숫자로 정의해야 합니다. 손실 함수는 바로 그 기준선을 제공합니다. 손실이 정의되어야 경사하강법 같은 최적화 알고리즘이 "어느 방향으로 계수를 움직여야 손실이 줄어드는지"를 계산할 수 있습니다. 손실 함수가 없으면 모델은 학습할 방향 자체를 잡지 못합니다.

### 3) 핵심 흐름 재구성

회귀에서 가장 기본이 되는 손실은 MSE(Mean Squared Error, 평균제곱오차)입니다. 오차를 제곱해서 평균을 냅니다.

```text
MSE = (1/n) × Σ (yᵢ − ŷᵢ)²

  yᵢ  : i번째 실제값(정답)
  ŷᵢ  : i번째 예측값
  n   : 데이터 개수
```

제곱을 하는 이유는 두 가지입니다. 첫째, 오차가 양수든 음수든 제곱하면 모두 양수가 되어 서로 상쇄되지 않습니다. 둘째, 큰 오차에 더 큰 벌점을 줍니다. 오차가 2배가 되면 제곱 오차는 4배가 되므로, 모델은 크게 틀리는 것을 특히 피하도록 학습됩니다.

MSE는 제곱을 했기 때문에 단위가 원래 값의 제곱(예: 달러²)이 되어 직관적이지 않습니다. 그래서 제곱근을 씌운 RMSE를 함께 봅니다. RMSE는 원래 단위로 돌아오므로 "평균적으로 몇 달러쯤 틀리는가"로 읽을 수 있습니다. RMSE·MAE의 차이는 [2편](02-overfitting-and-metrics.md)에서 자세히 다룹니다.

### 4) 쉬운 예시

시험 점수를 예측한다고 해 봅시다. 실제 점수가 80점인데 A모델은 82점, B모델은 95점으로 예측했습니다. A의 오차는 2점, B의 오차는 15점입니다. 제곱하면 A는 4, B는 225입니다. MSE는 크게 틀린 B에게 훨씬 무거운 벌점을 줍니다. 이것이 "MSE는 큰 실수를 특히 싫어한다"는 성질입니다.

### 5) 코드 예시

공개 데이터인 seaborn `tips`(식당 팁 데이터)로 손실을 직접 계산해 봅니다. 가장 단순한 예측인 "무조건 평균값으로 찍기"를 기준선(baseline)으로 삼고, 손실이 얼마인지 확인합니다.

```python
import numpy as np
import seaborn as sns

df = sns.load_dataset('tips')
y = df['tip'].values                     # 실제 팁 금액

# 베이스라인: 모든 예측을 평균값으로
y_pred = np.full_like(y, y.mean())

mse  = np.mean((y - y_pred) ** 2)        # 평균제곱오차
rmse = np.sqrt(mse)                      # 제곱근을 씌워 원래 단위로
mae  = np.mean(np.abs(y - y_pred))       # 절대값 오차의 평균

print(f'MSE={mse:.4f}  RMSE={rmse:.4f}  MAE={mae:.4f}')
```

```text
MSE=1.9066  RMSE=1.3808  MAE=1.0330
```

평균값으로만 찍어도 팁을 평균 1.38달러(RMSE) 정도 틀립니다. 이 값이 앞으로 만들 모델이 반드시 이겨야 할 최소 기준선입니다.

### 6) 헷갈리는 점

MSE와 RMSE는 순위를 매길 때는 동일합니다. 제곱근은 단조 증가 함수라서, MSE가 작으면 RMSE도 작습니다. 둘 중 어느 것으로 모델을 비교해도 "누가 더 좋은가"의 결론은 같습니다. 다만 사람이 결과를 해석할 때는 원래 단위인 RMSE가 편합니다.

### 7) 한 줄 정리

> 손실 함수는 모델에게 "무엇을 향해 학습해야 하는가"를 알려주는 나침반이고, 회귀에서는 보통 MSE가 그 역할을 한다.

## 2. 선형 회귀와 다중 회귀

### 1) 정의

선형 회귀(Linear Regression)는 예측값을 입력 변수의 **일차식(직선)**으로 표현합니다.

```text
단순 선형 회귀 :  ŷ = β₀ + β₁x
다중 선형 회귀 :  ŷ = β₀ + β₁x₁ + β₂x₂ + ... + βₖxₖ

  β₀ : 절편(intercept), x가 모두 0일 때의 기본 예측값
  βᵢ : i번째 변수의 계수(기울기), 그 변수의 영향력
```

### 2) 왜 필요한가

선형 회귀는 가장 단순하면서도 해석이 명확한 모델입니다. 계수 하나하나가 "이 변수가 결과에 얼마나, 어느 방향으로 영향을 주는가"를 그대로 말해 줍니다. 복잡한 모델을 쓰기 전에, 데이터가 어떤 구조인지 감을 잡는 기준 모델로 항상 먼저 시도할 가치가 있습니다.

### 3) 핵심 흐름 재구성

선형 회귀의 학습은 결국 β들을 조정해 MSE를 최소로 만드는 문제입니다. 변수가 하나면 직선 하나(기울기·절편), 변수가 여러 개면 각 변수마다 계수가 하나씩 붙습니다. 다중 회귀는 "여러 요인이 동시에 결과에 영향을 준다"는 현실을 반영합니다. 아이스크림 판매량이 기온과 강수량 모두에 영향을 받는 것처럼요.

### 4) 쉬운 예시

`판매량 ≈ 10 + 3 × 기온 − 2 × 강수량`이라는 다중 회귀식이 있다고 합시다. 기온 계수 3은 "다른 조건이 같을 때 기온이 1도 오르면 판매량이 평균 3만큼 는다", 강수량 계수 −2는 "비가 1mm 늘면 판매량이 평균 2 줄어든다"는 뜻입니다. 절편 10은 기온과 강수량이 모두 0일 때의 기준 판매량입니다.

### 5) 코드 예시

`tips`에서 결제 금액(`total_bill`)으로 팁(`tip`)을 예측하는 단순 선형 회귀입니다.

```python
from sklearn.linear_model import LinearRegression
from sklearn.metrics import r2_score
import seaborn as sns

df = sns.load_dataset('tips')
X = df[['total_bill']].values    # 독립변수는 2차원 형태로
y = df['tip'].values

lr = LinearRegression().fit(X, y)
y_hat = lr.predict(X)

print(f'절편  β₀ = {lr.intercept_:.4f}')
print(f'기울기 β₁ = {lr.coef_[0]:.4f}')
print(f'R²        = {r2_score(y, y_hat):.4f}')
```

```text
절편  β₀ = 0.9203
기울기 β₁ = 0.1050
R²        = 0.4566
```

### 코드 목적

결제 금액으로 팁을 설명하는 가장 단순한 직선을 학습하고, 그 계수가 무엇을 의미하는지 읽어 냅니다.

### 코드 흐름

1. `total_bill`을 독립변수 X, `tip`을 종속변수 y로 준비한다.
2. `LinearRegression().fit(X, y)`로 MSE를 최소화하는 직선을 찾는다.
3. `intercept_`, `coef_`로 절편과 기울기를 꺼낸다.
4. `r2_score`로 모델이 데이터의 변동을 얼마나 설명하는지 확인한다.

### 실행 결과 해석

기울기 0.1050은 "결제 금액이 1달러 늘면 팁이 평균 약 0.105달러(약 10센트) 는다"는 뜻입니다. 절편 0.92는 결제 금액이 0일 때의 이론적 기본 팁입니다(현실적으로는 외삽 영역이라 의미가 제한적입니다). R²는 0.4566으로, 팁 변동의 약 46%를 결제 금액만으로 설명한다는 의미입니다. 나머지 54%는 인원 수, 요일, 시간대 등 다른 요인에 있다는 신호입니다.

앞서 평균값 베이스라인의 RMSE가 1.38이었는데, 이 선형 모델의 RMSE는 약 1.02로 줄어듭니다. 단순한 직선 하나만으로도 베이스라인을 확실히 이겼습니다.

### 실무 연결

선형 회귀의 계수 해석은 마케팅에서 "광고비 1만원이 매출을 얼마나 올리는가", 부동산에서 "면적 1㎡당 가격이 얼마나 오르는가"처럼 **의사결정 근거를 수치로 제시**할 때 그대로 쓰입니다. 예측 정확도뿐 아니라 "왜 그런 예측이 나오는가"를 설명해야 하는 리포트에서 특히 강력합니다.

## 헷갈리기 쉬운 포인트

| 헷갈리는 개념 | 차이 |
|---|---|
| 회귀 vs 분류 | 결과가 연속 숫자면 회귀, 정해진 범주면 분류 |
| MSE vs RMSE | RMSE는 MSE에 제곱근을 씌워 원래 단위로 되돌린 값. 순위는 동일 |
| 절편 vs 기울기 | 절편은 x=0일 때 기준값, 기울기는 x가 1 변할 때의 예측 변화량 |
| 계수 크기 vs 중요도 | 변수 스케일이 다르면 계수 크기만으로 중요도를 비교하면 안 됨 |

## 한 줄 정리

> 회귀는 손실 함수(주로 MSE)를 최소화하며 계수를 찾는 과정이고, 그 계수는 각 변수가 결과에 미치는 영향을 그대로 말해 준다.
