# ARIMA와 잔차 진단 — 추세가 있는 데이터를 예측하고 검증하기

> 추세 때문에 비정상인 데이터는 차분으로 정상화한 뒤 예측합니다. 그리고 잔차 진단으로 "모델이 패턴을 다 뽑아냈는지"를 통계적으로 검증합니다.

`ARIMA` · `차분` · `잔차분석` · `Ljung-Box` · `백색잡음`

## 핵심요약

- 많은 실제 시계열은 추세 때문에 비정상이며, ARMA를 바로 쓸 수 없다.
- ARIMA는 ARMA에 차분(Integrated) 단계를 더한 모델로, 차수 (p, d, q)를 갖는다(d는 차분 횟수).
- 차분은 이웃한 값의 차이를 취해 추세를 제거하고 데이터를 정상화한다.
- 좋은 모델의 잔차는 아무 패턴 없는 백색잡음이어야 하며, 이를 Ljung-Box 검정으로 확인한다.
- Ljung-Box는 잔차에 자기상관이 없다는 가설을 검정하므로, p-value가 커야(> 0.05) 모델이 합격이다.

## 1. ARIMA와 차분

### 1) 정의

ARIMA(AutoRegressive Integrated Moving Average)는 ARMA에 **차분(Integrated) 단계**를 추가한 모델입니다. 차수는 세 개의 숫자 (p, d, q)로 표현합니다.

```text
ARIMA(p, d, q)
  p : AR(자기회귀) 차수 — 과거 관측값이 현재에 주는 영향
  d : 차분 횟수      — 정상화를 위해 몇 번 차분했는가
  q : MA(이동평균) 차수 — 과거 오차가 현재에 주는 영향
```

### 2) 왜 필요한가

서버 트래픽, 판매량, 인구처럼 시간에 따라 꾸준히 오르내리는 추세를 가진 데이터는 평균이 계속 변해 비정상입니다. ARMA는 정상성을 전제하므로 이런 데이터에 바로 쓸 수 없습니다. ARIMA의 차분 단계는 이 추세를 제거해 정상화한 뒤 ARMA를 적용할 수 있게 해 줍니다.

### 3) 핵심 흐름 재구성

차분(Differencing)은 이웃한 시점의 차이를 취하는 연산입니다.

```text
1차 차분 :  y'ₜ = yₜ − yₜ₋₁      (바로 앞 값과의 차이)

  선형 추세가 있으면 1차 차분으로 대개 제거된다.
  차분 후에도 비정상이면 한 번 더 차분한다(2차 차분, d=2).
```

전체 모델링 절차는 이렇습니다. ADF로 정상성을 확인하고, 비정상이면 차분 → 다시 ADF 확인을 정상이 될 때까지 반복해 d를 정합니다. 그다음 정상화된 데이터에서 ACF·PACF와 AIC로 p, q를 찾습니다. 마지막으로 잔차 진단으로 모델을 검증합니다.

### 4) 쉬운 예시

매일 키가 자라는 아이의 키를 예측한다고 합시다. 키 자체는 계속 커져서(추세) 비정상입니다. 하지만 "어제보다 오늘 몇 cm 자랐나"라는 **하루 증가량**으로 바꾸면(1차 차분), 그 값은 대체로 일정한 범위 안에서 움직여 예측하기 쉬워집니다. 예측한 증가량을 다시 누적하면 원래 키를 복원할 수 있습니다.

### 5) 코드 예시

추세를 가진 비정상 시계열을 만들어, 차분 전후로 ADF 검정을 비교하고 ARIMA 차수를 탐색합니다.

```python
import numpy as np, pandas as pd
from statsmodels.tsa.arima_process import ArmaProcess
from statsmodels.tsa.stattools import adfuller
from statsmodels.tsa.statespace.sarimax import SARIMAX
from itertools import product
np.random.seed(42)

# 정상 ARMA를 누적합해 추세를 가진 비정상 시계열 생성
stat = ArmaProcess(np.array([1, -0.5]), np.array([1, 0.4])).generate_sample(500)
series = np.cumsum(stat) + 50

adf0 = adfuller(series)
print(f'[원본]     ADF={adf0[0]:.4f}, p={adf0[1]:.4f}')
diff1 = np.diff(series, n=1)                 # 1차 차분
adf1 = adfuller(diff1)
print(f'[1차 차분] ADF={adf1[0]:.4f}, p={adf1[1]:.4f}')

# d=1 고정하고 (p, q) 탐색
def optimize(endog, order_list, d):
    res = []
    for (p, q) in order_list:
        try:
            m = SARIMAX(endog, order=(p, d, q), simple_differencing=False).fit(disp=False)
            res.append((p, q, m.aic))
        except Exception:
            continue
    return pd.DataFrame(res, columns=['p', 'q', 'AIC']).sort_values('AIC').reset_index(drop=True)

train = series[:-20]
tbl = optimize(train, list(product(range(0, 4), range(0, 4))), d=1)
print(tbl.head(3).to_string(index=False))
```

```text
[원본]     ADF=-1.5153, p=0.5259
[1차 차분] ADF=-7.8449, p=0.0000

 p  q          AIC
 1  1  1346.173022
 0  3  1346.499077
 3  3  1346.710392
```

### 코드 목적

차분이 실제로 비정상 데이터를 정상으로 바꾸는지 ADF로 확인하고, 정상화 후 ARIMA 차수를 찾습니다.

### 코드 흐름

1. 정상 ARMA를 누적합해 추세를 가진 비정상 시계열을 만든다.
2. 원본에 ADF 검정을 돌려 비정상임을 확인한다.
3. 1차 차분 후 다시 ADF로 정상화를 확인한다.
4. d=1로 고정하고 (p, q)를 AIC로 탐색한다.

### 실행 결과 해석

원본의 ADF p-value는 0.5259로 0.05보다 훨씬 커서 **비정상**입니다(추세 때문). 1차 차분을 하자 p-value가 0.0000으로 떨어져 **정상화**되었습니다. 이렇게 d=1이 결정됩니다. 이어 AIC 탐색에서 (1, 1)이 가장 낮게 나와 최종 모델은 ARIMA(1, 1, 1)이 됩니다. 이는 원래 데이터를 만들 때 쓴 ARMA(1,1) 구조와 정확히 일치해, 차분·탐색 절차가 올바르게 작동했음을 보여줍니다.

### 실무 연결

트래픽·수요·매출 예측에서 원 데이터는 대부분 추세가 있어 비정상입니다. 차분으로 증가량을 모델링하고 예측 후 누적해 원 스케일로 되돌리는 이 패턴은 실무 시계열 예측의 기본기입니다.

### 6) 헷갈리는 점

d를 무작정 키우면 안 됩니다. 과도한 차분(over-differencing)은 오히려 인위적인 패턴을 만들어 모델을 망칩니다. ADF가 정상을 가리키는 최소 횟수까지만 차분하는 것이 원칙입니다.

### 7) 한 줄 정리

> ARIMA는 차분으로 추세를 제거해 정상화한 뒤 ARMA를 적용하는 모델이며, d는 정상이 될 때까지의 최소 차분 횟수다.

## 2. 잔차 진단 — Ljung-Box 검정

### 1) 정의

잔차(Residual)는 실제값에서 모델의 예측값을 뺀 나머지, 즉 모델이 설명하지 못한 오차입니다. 잔차 진단은 이 나머지에 **아직 규칙(패턴)이 남아 있는지**를 확인하는 과정입니다. Ljung-Box(융-박스) 검정은 잔차에 자기상관이 남아 있는지를 통계적으로 판정합니다.

### 2) 왜 필요한가

모델이 데이터의 패턴을 완전히 뽑아냈다면, 남은 잔차에는 예측 가능한 규칙이 없어야 합니다. 즉 잔차는 아무 패턴 없는 **백색잡음(White Noise)**이어야 합니다. 잔차에 패턴이 남아 있다면, 모델이 아직 못 잡은 신호가 있다는 뜻이므로 차수를 바꾸거나 모델을 수정해야 합니다. 잔차 진단은 "이 모델을 믿고 써도 되는가"를 결정하는 최종 관문입니다.

### 3) 핵심 흐름 재구성

```text
Ljung-Box 검정 가설
  귀무가설 H0 : 잔차에 자기상관이 없다 = 백색잡음 (합격)
  대립가설 H1 : 잔차에 자기상관이 있다 = 패턴 잔존 (불합격)

판정
  p-value > 0.05  → H0 기각 실패 → "잔차가 백색잡음" → 모델 합격
  p-value ≤ 0.05  → H0 기각        → "패턴 남음"      → 모델 재수정
```

ADF와 반대로, 여기서는 **p-value가 커야 좋습니다.** 귀무가설이 "패턴 없음(백색잡음)"이라, 이를 기각하지 못해야(p가 큼) 모델이 합격입니다. 그래프로는 `plot_diagnostics`가 잔차 시계열·히스토그램·Q-Q 도식·상관도(ACF)를 한 번에 보여 줘, 잔차가 평균 0 주변에서 고르게 진동하고 정규분포에 가까우며 자기상관이 없는지를 한눈에 점검할 수 있습니다.

### 4) 쉬운 예시

퍼즐을 다 맞춘 뒤 남은 조각이 하나도 없어야 완성입니다. 잔차 진단은 "맞추고 남은 조각(잔차)에 아직 의미 있는 그림(패턴)이 있는지"를 보는 것입니다. 남은 조각이 그냥 부스러기(백색잡음)면 완성(합격), 조각들이 또 다른 그림을 이루면 아직 덜 맞춘 것(불합격)입니다.

### 5) 코드 예시

앞의 ARIMA(1,1,1) 모델을 적합하고, 잔차에 Ljung-Box 검정을 적용합니다.

```python
from statsmodels.stats.diagnostic import acorr_ljungbox

fit = SARIMAX(train, order=(1, 1, 1), simple_differencing=False).fit(disp=False)
resid = fit.resid[2:]     # 초기 불안정 구간 제외
lb = acorr_ljungbox(resid, lags=[10], return_df=True)
print(f"lb_stat  = {lb['lb_stat'].values[0]:.4f}")
print(f"p-value  = {lb['lb_pvalue'].values[0]:.4f}")
```

```text
lb_stat  = 5.0564
p-value  = 0.8874
```

### 코드 목적

최적 ARIMA 모델의 잔차가 백색잡음인지(패턴이 남지 않았는지)를 통계적으로 검증합니다.

### 코드 흐름

1. 결정한 차수 ARIMA(1,1,1)로 모델을 적합한다.
2. 잔차를 추출한다(초기 불안정 구간 제외).
3. 시차 10까지 묶어 Ljung-Box 검정을 돌린다.
4. p-value를 0.05와 비교해 합격 여부를 판정한다.

### 실행 결과 해석

p-value가 0.8874로 0.05보다 훨씬 큽니다. 따라서 귀무가설(잔차에 자기상관 없음)을 기각하지 못하고, **잔차가 백색잡음이라고 판정 → 모델 합격**입니다. 모델이 데이터의 패턴을 충분히 뽑아냈고, 남은 것은 예측 불가능한 순수 노이즈뿐이라는 뜻입니다. 이제 이 모델을 예측에 사용할 수 있습니다.

한 가지 실무 주의점: 표본이 수천~수만 개로 매우 크면, Ljung-Box가 인간이 무시해도 될 만큼 미세한 상관까지 잡아내 p-value를 0으로 떨어뜨리는 경향이 있습니다(과도한 검정력). 이럴 때는 p-value만 맹신하지 말고 잔차 그래프의 실제 패턴 크기를 함께 보고 판단해야 합니다.

### 실무 연결

잔차 진단은 배포 전 최종 체크리스트입니다. 잔차에 주기적 패턴이 남아 있다면 계절성을 반영하는 모델(SARIMA 등)로 확장해야 한다는 신호입니다. 즉 잔차 진단은 다음 단계 모델 개선의 방향까지 알려 줍니다.

### 6) 헷갈리는 점

ADF는 "p가 작아야 좋음(정상)", Ljung-Box는 "p가 커야 좋음(백색잡음)"으로 방향이 반대입니다. 두 검정의 귀무가설이 다르기 때문입니다. 이 방향을 섞으면 정반대의 결론을 내리게 됩니다.

### 7) 한 줄 정리

> 좋은 모델의 잔차는 백색잡음이어야 하며, Ljung-Box 검정에서 p-value가 0.05보다 커야 모델이 합격이다.

## 코드로 보기 — ARIMA 전체 모델링 절차(Box-Jenkins)

```text
[비정상 시계열]
   └─> ADF 검정 → 비정상이면 차분(d 결정) → 다시 ADF (정상 될 때까지)
         └─> 정상화 데이터에서 ACF·PACF + AIC로 (p, q) 결정
               └─> ARIMA(p, d, q) 적합
                     └─> 잔차 진단(plot_diagnostics + Ljung-Box)
                           ├─ 합격(p>0.05) → 예측에 사용
                           └─ 불합격      → 차수 조정 후 반복
```

### 코드 목적

정상성 확인·차분·차수 결정·적합·검증으로 이어지는 시계열 모델링 전 과정을 하나의 순환 절차로 정리합니다.

### 실행 결과 해석

핵심은 "잔차가 합격할 때까지 차수를 조정하며 반복한다"는 순환 구조입니다. 한 번에 끝나는 것이 아니라, 진단 결과가 다음 시도를 안내합니다.

### 실무 연결

이 절차를 표준 템플릿으로 두면, 어떤 시계열이 들어와도 같은 순서로 안정적으로 모델을 만들고 검증할 수 있습니다. 잔차에 주기성이 남으면 계절성 모델로 확장하는 것이 자연스러운 다음 단계입니다.

## 직접 해보기

1. 원본 시계열의 ADF p-value가 0.53, 1차 차분 후 0.00이라면 d는 얼마로 정하나요?
2. Ljung-Box 검정에서 p-value가 0.88이 나왔습니다. 모델은 합격인가요, 불합격인가요? 이유는?
3. ADF와 Ljung-Box는 둘 다 p-value로 판정하는데, "좋은" 방향이 서로 반대인 이유는 무엇인가요?

<details>
<summary>정답 보기</summary>

1. d=1입니다. 원본은 비정상(p=0.53)이지만 1차 차분 후 정상(p=0.00)이 되었으므로, 정상화에 필요한 최소 차분 횟수인 1을 d로 정합니다.
2. 합격입니다. Ljung-Box의 귀무가설은 "잔차에 자기상관 없음(백색잡음)"인데, p-value(0.88)가 0.05보다 커서 이를 기각하지 못하므로 잔차가 백색잡음으로 판정됩니다.
3. 귀무가설이 다르기 때문입니다. ADF는 H0가 "비정상"이라 이를 기각(p 작음)해야 정상으로 좋은 결론이고, Ljung-Box는 H0가 "백색잡음"이라 이를 유지(p 큼)해야 좋은 결론입니다.

## 헷갈리기 쉬운 포인트

| 헷갈리는 개념 | 차이 |
|---|---|
| ARMA vs ARIMA | 정상 데이터용 vs 차분(d)을 더해 비정상 데이터도 다룸 |
| 차분 d=1 vs d=2 | 선형 추세는 1차로, 그래도 비정상이면 2차 차분 |
| ADF의 p vs Ljung-Box의 p | ADF는 작아야 정상(좋음), Ljung-Box는 커야 백색잡음(좋음) |
| 잔차 패턴 있음 vs 없음 | 패턴 있으면 모델 미완성, 없으면(백색잡음) 합격 |

### 복습 질문 및 답변

**Q1. ARIMA의 'I(Integrated)'는 무엇을 의미하나요?**

<details>
<summary>답</summary>

차분(differencing)을 뜻합니다. 비정상 데이터를 정상화하기 위해 이웃 값의 차이를 취하는 단계이며, 그 횟수가 차수 d입니다. 예측 후에는 다시 누적(적분)해 원래 스케일로 되돌립니다.

</details>

**Q2. 잔차가 백색잡음이어야 하는 이유는 무엇인가요?**

<details>
<summary>답</summary>

모델이 데이터의 예측 가능한 패턴을 모두 뽑아냈다면, 남은 잔차에는 규칙이 없어야 하기 때문입니다. 잔차에 패턴이 남아 있다면 아직 모델이 못 잡은 신호가 있다는 뜻이므로, 차수를 바꾸거나 모델을 수정해야 합니다.

</details>

**Q3. 표본이 매우 클 때 Ljung-Box 결과를 해석할 때 주의할 점은?**

<details>
<summary>답</summary>

표본이 수천~수만 개로 크면 검정이 무시해도 될 만큼 미세한 상관까지 잡아내 p-value를 0으로 떨어뜨리는 경향(과도한 검정력)이 있습니다. 이럴 때는 p-value만 보지 말고 잔차 그래프에서 실제 상관의 크기가 실무적으로 유의미한지 함께 판단해야 합니다.

</details>

## 한 줄 정리

> ARIMA는 차분으로 추세를 다스려 예측하고, 잔차가 백색잡음인지를 Ljung-Box로 검증해 모델의 신뢰성을 확정한다.
