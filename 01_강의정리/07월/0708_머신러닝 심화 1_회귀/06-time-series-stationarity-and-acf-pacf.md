# 시계열 정상성과 ACF·PACF — 시간을 따라 흐르는 데이터 읽기

> 시계열 예측의 모든 것은 "이 데이터가 정상적인가?"라는 질문에서 시작합니다. 정상성을 확인하고, ACF·PACF로 모델의 차수를 읽고, AIC로 최적 모델을 고르는 과정을 정리합니다.

`시계열` · `정상성` · `ADF검정` · `ACF` · `PACF` · `AIC`

## 핵심요약

- 시계열은 시간 순서가 의미를 갖는 데이터로, 관측값들이 서로 독립이 아니라 과거가 현재에 영향을 준다.
- 정상성(Stationarity)은 평균·분산 같은 통계적 성질이 시간이 지나도 일정한 상태를 말하며, 대부분의 시계열 모델은 이를 전제로 한다.
- ADF 검정으로 정상성을 수치로 판정한다(p < 0.05면 정상).
- 자기상관(ACF)은 과거 값이 현재와 얼마나 닮았는지, 편자기상관(PACF)은 중간 시차의 영향을 뺀 순수한 직접 영향을 본다.
- ACF·PACF의 단절 패턴으로 MA·AR 차수를 읽고, AIC가 가장 낮은 (p, q) 조합을 최적 모델로 고른다.

## 1. 정상성과 ADF 검정

### 1) 정의

시계열(Time Series)은 시간 순서대로 기록된 데이터입니다. 시간 순서를 섞으면 정보가 사라진다는 점에서 일반 데이터와 다릅니다. 정상성은 시계열의 **평균·분산·자기상관 구조가 시간이 흘러도 변하지 않는** 성질입니다. 추세(꾸준히 오르내림)나 계절성(주기적 반복)이 있으면 평균이 시간에 따라 변하므로 비정상입니다.

### 2) 왜 필요한가

ARMA·ARIMA 같은 고전 시계열 모델은 데이터가 정상적이라는 가정 위에서 작동합니다. 비정상 데이터를 그대로 넣으면 모델이 엉뚱한 결과를 냅니다. 그래서 분석의 첫 단계는 항상 "이 데이터가 정상적인가?"를 확인하는 것입니다. 비정상이면 차분 등으로 정상화한 뒤 진행합니다.

### 3) 핵심 흐름 재구성

정상성을 눈대중이 아니라 수치로 판정하는 도구가 ADF 검정(Augmented Dickey-Fuller test)입니다.

```text
ADF 검정 가설
  귀무가설 H0 : 단위근이 존재한다 = 비정상(Non-stationary)
  대립가설 H1 : 단위근이 없다   = 정상(Stationary)

판정
  p-value < 0.05  → H0 기각 → "정상"
  p-value ≥ 0.05  → H0 기각 실패 → "비정상(차분 등 필요)"
```

주의할 점은 귀무가설이 "비정상"이라는 것입니다. 그래서 p-value가 작아야(0.05 미만) 정상이라고 결론 내립니다. 이 방향을 헷갈리면 정반대로 해석하게 됩니다.

### 4) 쉬운 예시

정상성은 "성격이 한결같은 사람"에 비유할 수 있습니다. 언제 만나도 기분의 평균과 기복(분산)이 비슷하면 예측하기 쉽습니다(정상). 반대로 만날 때마다 기분의 기준선 자체가 계속 오르내리면(추세) 다음을 예측하기 어렵습니다(비정상). 시계열 모델은 예측을 위해 "한결같은" 데이터를 원합니다.

### 5) 코드 예시

재현 가능한 합성 ARMA(1,1) 데이터를 만들어 ADF 검정을 돌립니다.

```python
import numpy as np
from statsmodels.tsa.arima_process import ArmaProcess
from statsmodels.tsa.stattools import adfuller
np.random.seed(42)

ar = np.array([1, -0.6])   # AR(1) 계수 0.6
ma = np.array([1,  0.4])   # MA(1) 계수 0.4
series = ArmaProcess(ar, ma).generate_sample(nsample=600)

adf = adfuller(series)
print(f'ADF Statistic = {adf[0]:.4f}')
print(f'p-value       = {adf[1]:.6f}')
```

```text
ADF Statistic = -8.2173
p-value       = 0.000000
```

### 코드 목적

만들어 둔 정상 시계열이 ADF 검정에서 실제로 "정상"으로 판정되는지 확인합니다.

### 코드 흐름

1. AR·MA 계수를 정해 정상 ARMA(1,1) 표본을 생성한다.
2. `adfuller`로 ADF 통계량과 p-value를 얻는다.
3. p-value를 0.05와 비교해 정상성을 판정한다.

### 실행 결과 해석

p-value가 0.000000으로 0.05보다 훨씬 작으므로, 귀무가설(비정상)을 기각하고 **정상성이 확보**되었다고 판단합니다. ADF 통계량 −8.22는 임계값보다 훨씬 아래로, 강하게 정상임을 뒷받침합니다. 이렇게 정상성이 확인되면 곧바로 ARMA 모델링으로 넘어갈 수 있습니다. 비정상이라면 [7편의 차분](07-arima-and-residual-diagnostics.md)으로 정상화부터 해야 합니다.

### 실무 연결

서버 트래픽, 판매량, 주가처럼 시간에 따라 기록되는 지표는 대부분 추세나 주기성 때문에 비정상입니다. 분석 파이프라인의 첫 관문으로 ADF 검정을 두면, 이후 모델링이 잘못된 전제 위에서 진행되는 사고를 막을 수 있습니다.

### 6) 헷갈리는 점

ADF의 귀무가설이 "비정상"이라 방향이 직관과 반대입니다. "p가 작으면 정상"을 반드시 기억하세요. 또 정상성 판정은 ADF 하나만으로 단정하기보다, ACF 그래프의 감쇠 속도 등과 함께 보는 것이 안전합니다.

### 7) 한 줄 정리

> 정상성은 시계열 모델링의 대전제이고, ADF 검정에서 p가 0.05보다 작아야 정상이라고 판정한다.

## 2. ACF·PACF와 AIC 모델 선택

### 1) 정의

자기상관함수(ACF, Autocorrelation Function)는 시계열이 자기 자신의 과거(여러 시차)와 얼마나 상관되는지를 나타냅니다. 편자기상관함수(PACF, Partial ACF)는 중간 시차들의 간접 영향을 제거하고, 특정 시차의 **순수한 직접 영향**만 남긴 값입니다.

### 2) 왜 필요한가

ARMA 모델은 AR 차수 p와 MA 차수 q를 정해 줘야 합니다. 이 차수를 무작정 찍는 대신, ACF·PACF 그래프의 패턴을 읽어 후보를 좁힐 수 있습니다. 두 그래프는 "어떤 모형(AR/MA)을 몇 차수로 쓸까"를 알려 주는 나침반입니다.

### 3) 핵심 흐름 재구성

패턴 판별의 핵심은 **어디서 뚝 끊기는가(cut-off)와 어떻게 서서히 줄어드는가(tailing off)**입니다.

```text
              ACF                      PACF               → 판별
  ─────────────────────────────────────────────────────────────
  AR(p)  모형   서서히 감소            시차 p에서 단절     → PACF로 p 읽기
  MA(q)  모형   시차 q에서 단절        서서히 감소         → ACF로 q 읽기
  ARMA        서서히 감소            서서히 감소         → 그래프로 차수 판별 어려움

  이 판별 절차 전체를 박스-젠킨스(Box-Jenkins) 방법론이라 부른다.
```

주의할 점은, 순수 AR이나 순수 MA는 그래프로 차수를 읽기 쉽지만, **AR과 MA가 섞인 ARMA는 두 그래프가 모두 서서히 줄어들어 눈으로 차수를 정하기 어렵다**는 것입니다. 이럴 때는 여러 (p, q) 후보를 모두 시도해 AIC로 고르는 방식이 실용적입니다.

### 4) 쉬운 예시

ACF는 "오늘 기분이 사흘 전, 일주일 전 기분과 얼마나 닮았나"를 통째로 재는 것이고, PACF는 "그 사이 날들의 영향을 다 빼고, 딱 일주일 전 기분만이 오늘에 주는 직접 영향"을 재는 것입니다. 예컨대 "정확히 이틀 전까지의 흐름만 오늘을 결정한다"면 PACF가 시차 2에서 뚝 끊깁니다. 이는 AR(2) 신호입니다.

### 5) 코드 예시

앞의 ARMA(1,1) 데이터로 ACF·PACF 값을 확인하고, AIC로 (p, q)를 탐색합니다.

```python
import pandas as pd
from statsmodels.tsa.stattools import acf, pacf
from statsmodels.tsa.statespace.sarimax import SARIMAX
from itertools import product

print('ACF (lag0~5):', acf(series, nlags=5).round(3))
print('PACF(lag0~5):', pacf(series, nlags=5).round(3))

def optimize(endog, order_list, d=0):
    res = []
    for (p, q) in order_list:
        try:
            m = SARIMAX(endog, order=(p, d, q), simple_differencing=False).fit(disp=False)
            res.append((p, q, m.aic))
        except Exception:
            continue
    return pd.DataFrame(res, columns=['p', 'q', 'AIC']).sort_values('AIC').reset_index(drop=True)

orders = list(product(range(0, 4), range(0, 4)))
print(optimize(series, orders).head(5).to_string(index=False))
```

```text
ACF (lag0~5): [1.    0.745 0.43  0.231 0.101 0.058]
PACF(lag0~5): [ 1.    0.746 -0.285  0.076 -0.072  0.094]

 p  q          AIC
 1  3  1672.829760
 3  1  1674.198617
 1  1  1674.435235
 2  3  1674.816870
 2  2  1675.725644
```

### 코드 목적

그래프로 판별이 애매한 ARMA 데이터에서, AIC 기반 탐색으로 최적 차수 조합을 자동으로 찾습니다.

### 코드 흐름

1. ACF·PACF 값을 뽑아 감쇠 패턴을 확인한다.
2. `(p, q)` 후보를 모두 만들어(0~3 × 0~3) 각 조합의 모델을 학습한다.
3. 각 모델의 AIC를 기록한다.
4. AIC가 낮은 순으로 정렬해 최적 조합을 고른다.

### 실행 결과 해석

ACF가 1 → 0.745 → 0.43처럼 서서히 감소하고 PACF도 뚜렷한 단절 없이 줄어드는데, 이는 AR·MA가 섞인 ARMA의 전형적 신호라 눈으로 차수를 정하기 어렵습니다. 그래서 AIC 탐색으로 넘어가면, 가장 낮은 AIC는 (1, 3)이지만 실제 정답인 **(1, 1)이 AIC 1674.44로 상위권**에 있습니다. AIC가 최소인 조합이 항상 진짜 차수와 일치하지는 않지만, 상위 후보 안에 정답이 들어오는 것을 볼 수 있습니다. 실무에서는 AIC 상위 몇 개를 후보로 두고 잔차 진단까지 통과하는 모델을 최종 선택합니다.

### 실무 연결

AIC는 "설명력은 높이되 파라미터가 많아지면 벌점을 준다"는 원리로, 과하게 복잡한 모델을 걸러 냅니다. 시계열뿐 아니라 여러 통계 모델 비교에서 두루 쓰이며, 낮을수록 좋은 지표입니다.

### 6) 헷갈리는 점

AR 차수는 PACF로, MA 차수는 ACF로 읽습니다. 이 짝을 반대로 기억하면 차수를 잘못 정합니다. 또 AIC 최솟값이 곧 진리는 아니며, 반드시 잔차 진단으로 모델의 타당성을 확인해야 합니다([7편](07-arima-and-residual-diagnostics.md)).

### 7) 한 줄 정리

> ACF·PACF의 단절 패턴으로 MA·AR 차수를 읽되, 섞인 ARMA는 AIC 탐색으로 최적 조합을 고른다.

## 코드로 보기 — 시계열 모델링 진입 절차

```text
[시계열 데이터]
   └─> ADF 검정으로 정상성 확인
         ├─ 정상   → ACF·PACF로 차수 힌트 → AIC로 (p,q) 탐색
         └─ 비정상 → 차분으로 정상화 후 위 과정 반복 (7편)
```

### 코드 목적

정상성 확인에서 차수 결정까지, 시계열 모델링의 앞단을 하나의 순서로 정리합니다.

### 실행 결과 해석

정상이면 바로 차수 탐색으로, 비정상이면 차분부터 하는 갈림길이 핵심입니다. 이 절차를 지키면 잘못된 전제 위에서 모델을 만드는 사고를 예방할 수 있습니다.

### 실무 연결

이 진입 절차를 함수로 감싸 두면, 새로운 시계열이 들어올 때마다 정상성 판정과 차수 탐색을 일관되게 자동화할 수 있습니다.

## 헷갈리기 쉬운 포인트

| 헷갈리는 개념 | 차이 |
|---|---|
| 정상 vs 비정상 | 통계 성질이 시간에 일정하면 정상, 추세·계절성이 있으면 비정상 |
| ADF의 H0 방향 | 귀무가설이 "비정상"이라 p가 작아야 정상으로 판정 |
| ACF vs PACF | 과거와의 전체 상관 vs 중간 시차 영향을 뺀 직접 상관 |
| AR 차수 vs MA 차수 | AR은 PACF의 단절로, MA는 ACF의 단절로 읽음 |
