# 고윳값·고유벡터·행렬의 대각화 — 변환의 뼈대를 찾다

> 행렬로 공간을 변환하면 대부분의 벡터는 방향이 바뀝니다. 그런데 **변환해도 방향이 그대로인 특별한 벡터**가 있습니다. 이 벡터(고유벡터)와 그 확대 비율(고윳값)을 찾으면 복잡한 행렬 연산이 놀랄 만큼 단순해지고, PCA·클러스터링·페이지랭크 같은 알고리즘의 원리가 열립니다.

`고윳값` `고유벡터` `특성다항식` `대각화` `대칭행렬` `Eigen Decomposition` `양의 정부호 행렬` `PDM` `스펙트럴 클러스터링` `Laplacian`

## 핵심요약

- **고유벡터**는 행렬 $A$ 로 변환해도 방향이 변하지 않고 크기만 $\lambda$ 배 되는 벡터다: $Av = \lambda v$.
- 고윳값은 **특성방정식** $\det(\lambda I - A) = 0$ 을 풀어 구한다.
- **대각화** $P^{-1}AP = D$ 는 행렬을 "고유벡터 좌표계"에서 단순한 대각행렬로 바꾸는 것이다.
- 독립인 고유벡터가 $n$ 개면 대각화 가능 — 고윳값이 모두 다르면 항상 가능하다.
- **대칭행렬**은 항상 대각화되고, 고유벡터들이 자동으로 서로 직교한다($A = Q^\top D Q$).
- **양의 정부호 행렬(PDM)** 은 모든 고윳값이 양수인 대칭행렬로, 공분산·최적화에서 핵심이다.
- 대각화로 $A^{100}$ 같은 거듭제곱을 순식간에 계산할 수 있다.
- **스펙트럴 클러스터링**은 그래프 Laplacian의 고유벡터로 데이터를 그룹으로 나눈다.

## 개념별 정리

### 고윳값과 고유벡터

**1. 정의**
0이 아닌 벡터 $v$ 가 $Av = \lambda v$ 를 만족하면, $\lambda$ 를 **고윳값**, $v$ 를 그에 대응하는 **고유벡터**라 합니다. 즉 행렬을 곱해도 방향은 그대로이고 크기만 $\lambda$ 배 변합니다.

**2. 왜 필요한가?**
고유벡터는 변환의 "축"입니다. PCA는 데이터 공분산행렬의 고유벡터(주성분)를 찾아 그 방향으로 데이터를 정렬합니다. 고윳값의 크기는 그 방향이 데이터를 얼마나 많이 설명하는지를 나타냅니다.

**3. 예시**

```python
import numpy as np

A = np.array([[1., -8.], [1., -5.]])
eigenvalues, eigenvectors = np.linalg.eig(A)
print("고윳값:", eigenvalues)

# Av = λv 검증
for i in range(2):
    lam = eigenvalues[i]
    v = eigenvectors[:, i]
    print(f"λ={lam:.0f}: Av={np.round(A @ v, 4)}, λv={np.round(lam * v, 4)}")
```

실행 결과:

```
고윳값: [-1. -3.]
λ=-1: Av=[-0.9701 -0.2425], λv=[-0.9701 -0.2425]
λ=-3: Av=[-2.6833 -1.3416], λv=[-2.6833 -1.3416]
```

$Av$ 와 $\lambda v$ 가 정확히 일치하므로, 이 벡터들이 방향을 유지하는 고유벡터임이 확인됩니다.

**4. 헷갈리기 쉬운 점**
고유벡터는 유일하지 않습니다. $v$ 가 고유벡터면 $2v$, $-v$ 도 같은 고윳값의 고유벡터입니다(방향만 같으면 됨). 그래서 numpy는 보통 길이 1로 정규화한 고유벡터를 반환하며, 부호는 다를 수 있습니다.

**5. 한 줄 정리**
고유벡터는 변환의 축, 고윳값은 그 축이 늘어나는 비율이다.

> 🍞 **비유**: 회전목마에서 대부분의 목마는 원을 그리며 위치가 바뀌지만, **정중앙의 축**은 제자리에서 방향이 안 변합니다. 고유벡터가 바로 그 축이고, 고윳값은 축이 위아래로 몇 배 늘었는지입니다.

### 특성다항식과 고윳값 구하기

**1. 정의**
고윳값은 **특성방정식** $\det(\lambda I - A) = 0$ 의 해입니다. 각 고윳값 $\lambda$ 에 대해 $(\lambda I - A)v = 0$ 을 풀면 고유벡터가 나옵니다.

**2. 왜 필요한가?**
행렬만 보고 고윳값을 바로 알 수는 없습니다. 특성방정식은 고윳값을 "다항식의 근"으로 바꿔 체계적으로 찾게 해 줍니다.

**3. 예시**
$A = \begin{pmatrix} 3 & 1 \\ 1 & 3 \end{pmatrix}$ 의 특성방정식은 $(\lambda-3)^2 - 1 = \lambda^2 - 6\lambda + 8 = (\lambda-4)(\lambda-2) = 0$ 이므로 고윳값은 4와 2입니다.

**4. 헷갈리기 쉬운 점**
고윳값에 **중근**(같은 값이 여러 번)이 있으면 상황이 복잡해집니다. 중근이 있어도 독립 고유벡터를 충분히 확보하면 대각화가 되지만, 그렇지 못하면 대각화가 불가능합니다. 이때는 rank로 독립 고유벡터 수를 확인합니다.

**5. 한 줄 정리**
특성방정식 $\det(\lambda I - A) = 0$ 의 근이 고윳값이다.

---

### 행렬의 대각화

**1. 정의**
정칙행렬 $P$ 가 있어 $P^{-1}AP = D$ (대각행렬)를 만족하면 $A$ 는 **대각화 가능**합니다. $P$ 의 열은 고유벡터, $D$ 의 대각 원소는 고윳값입니다. $n$ 개의 고유벡터가 일차독립이면 대각화됩니다.

**2. 왜 필요한가?**
대각행렬은 계산이 극도로 쉽습니다. 거듭제곱 $A^k = PD^kP^{-1}$ 로 바꾸면, 대각행렬의 거듭제곱은 각 대각 원소를 $k$ 제곱하는 것뿐이라 순식간에 계산됩니다. 마르코프 체인의 장기 상태, 반복 동역학 분석에 필수입니다.

**3. 예시** — 대각화로 거듭제곱 계산

```python
import numpy as np

A = np.array([[3., 1.], [1., 3.]])
eigenvalues, P = np.linalg.eig(A)
P_inv = np.linalg.inv(P)

# A = PDP⁻¹ 검증
D = np.diag(eigenvalues)
print("PDP⁻¹ == A ?", np.allclose(P @ D @ P_inv, A))

# A^100 = P D^100 P⁻¹
D_100 = np.diag(eigenvalues ** 100)
print("X = 4^100 =", int(4**100))
print("Y = 2^100 =", int(2**100))
```

실행 결과:

```
PDP⁻¹ == A ? True
X = 4^100 = 1606938044258990275541962092341162602522202993782792835301376
Y = 2^100 = 1267650600228229401496703205376
```

고윳값이 4와 2이므로 $A^{100} = P \begin{pmatrix} 4^{100} & 0 \\ 0 & 2^{100} \end{pmatrix} P^{-1}$. 100번 곱하는 대신 대각 원소만 100제곱하면 끝입니다.

**4. 헷갈리기 쉬운 점**
모든 행렬이 대각화되는 것은 아닙니다. 고윳값이 중근이면서 독립 고유벡터가 부족하면 대각화가 안 됩니다(예: $\begin{pmatrix} 3 & 2 & 0 \\ 0 & 2 & 0 \\ 1 & 1 & 2 \end{pmatrix}$ 는 $\lambda=2$ 의 rank가 2라 독립 고유벡터가 1개뿐 → 불가능).

**5. 한 줄 정리**
대각화는 행렬을 고유벡터 좌표계에서 단순 대각행렬로 다시 쓰는 것이다.

> 🍞 **비유**: 복잡하게 얽힌 톱니바퀴도, 각 바퀴의 회전축 방향으로 관점을 돌려서 보면 "그냥 각자 몇 배씩 도는 것"으로 단순해집니다. 대각화는 이 "축 정렬 관점"으로 갈아타는 일입니다.

---

### 대칭행렬의 대각화 (Eigen Decomposition)

**1. 정의**
대칭행렬($A = A^\top$)은 **항상** 대각화되며, 정규직교행렬 $Q$($Q^\top Q = I$)로 $A = Q^\top D Q$ 로 분해됩니다. 서로 다른 고윳값의 고유벡터들은 자동으로 직교합니다.

**2. 왜 필요한가?**
데이터의 공분산행렬은 항상 대칭입니다. 대칭행렬의 이 성질(실수 고윳값 + 직교 고유벡터) 덕분에 PCA가 안정적으로 작동합니다. 주성분들이 서로 수직인 것이 바로 이 정리의 결과입니다.

**3. 예시**

```python
import numpy as np

A = np.array([[1., 2.], [2., 1.]])         # 대칭
eigenvalues, Q = np.linalg.eigh(A)          # 대칭 전용 함수 eigh
print("고윳값:", eigenvalues)
print("고유벡터 직교? v₁·v₂ =", round(Q[:,0] @ Q[:,1], 10))
print("QᵀQ = I ?\n", np.round(Q.T @ Q, 10))
```

실행 결과:

```
고윳값: [-1.  3.]
고유벡터 직교? v₁·v₂ = 0.0
QᵀQ = I ?
 [[ 1.  0.]
 [ 0.  1.]]
```

두 고유벡터의 내적이 0(직교)이고 $Q^\top Q = I$ 로 정규직교행렬임이 확인됩니다.

**4. 헷갈리기 쉬운 점**
일반 행렬은 `np.linalg.eig`, 대칭행렬은 `np.linalg.eigh`를 씁니다. `eigh`는 대칭성을 이용해 더 정확하고 빠르며, 고윳값을 오름차순으로 정렬해 실수로 반환합니다.

**5. 한 줄 정리**
대칭행렬은 항상 직교하는 고유벡터 축으로 깔끔하게 분해된다.

---

### 양의 정부호 행렬 (Positive Definite Matrix, PDM)

**1. 정의**
대칭행렬 $A$ 가 모든 $x \neq 0$ 에 대해 $x^\top A x > 0$ 이면 **양의 정부호 행렬(PDM)**, $\geq 0$ 이면 **양의 준정부호(PSDM)** 입니다. PDM은 "모든 고윳값이 양수"인 것과 동치입니다.

**2. 왜 필요한가?**
최적화에서 목적함수가 볼록(최솟값이 하나)인지 판단하는 기준이고, 공분산행렬은 항상 PSDM입니다. 또 PDM은 제곱근 분해가 가능해 마할라노비스 거리·가우시안 분포 계산에 쓰입니다.

**3. 예시**

```python
import numpy as np

A = np.array([[2., -1., 0.], [-1., 2., -1.], [0., -1., 2.]])
eigenvalues = np.linalg.eigvalsh(A)
print("고윳값:", np.round(eigenvalues, 4))
print("모든 고윳값 > 0 ? (PDM) →", np.all(eigenvalues > 0))
```

실행 결과:

```
고윳값: [0.5858 2.     3.4142]
모든 고윳값 > 0 ? (PDM) → True
```

세 고윳값이 모두 양수이므로 이 대칭행렬은 양의 정부호 행렬입니다.

**4. 헷갈리기 쉬운 점**
임의의 행렬 $A$ 에 대해 $A^\top A$ 와 $AA^\top$ 는 **항상 PSDM**입니다($(Ax)^\top(Ax) = \|Ax\|^2 \geq 0$ 이므로). 이 사실이 다음 글의 SVD로 곧장 이어집니다.

**5. 한 줄 정리**
PDM은 모든 방향으로 "위로 볼록"한 대칭행렬이며, 고윳값이 전부 양수다.

**행렬의 제곱근**: PDM은 $A = P D P^\top$ 로 대각화한 뒤 $\sqrt{A} = P\sqrt{D}P^\top$ 로 제곱근을 정의할 수 있습니다. 예를 들어 $A = \begin{pmatrix} 4 & 2 \\ 2 & 3 \end{pmatrix}$ 의 제곱근은 $\begin{pmatrix} 1.9194 & 0.5622 \\ 0.5622 & 1.6383 \end{pmatrix}$ 이고, 이를 제곱하면 다시 $A$ 가 됩니다.

## 코드로 보기 — 스펙트럴 클러스터링

```python
import numpy as np

# 5개 노드 그래프의 인접행렬 W (앞 3개, 뒤 2개가 뭉쳐 있음)
W = np.array([[5., 4., 4., 0., 0.],
              [4., 5., 4., 0., 0.],
              [4., 4., 5., 1., 0.],
              [0., 0., 1., 5., 4.],
              [0., 0., 0., 4., 5.]])

D = np.diag(W.sum(axis=1))   # Degree 행렬 (대각)
L = D - W                    # Laplacian 행렬

eigenvalues, eigenvectors = np.linalg.eigh(L)
fiedler = eigenvectors[:, 1]              # 두 번째로 작은 고윳값의 고유벡터
print("Fiedler 벡터:", np.round(fiedler, 4))
print("클러스터 A (양수):", np.where(fiedler > 0)[0] + 1)
print("클러스터 B (음수):", np.where(fiedler <= 0)[0] + 1)
```

**코드목적**
그래프의 연결 관계(인접행렬)로부터 Laplacian 행렬 $L = D - W$ 를 만들고, 그 고유벡터를 이용해 노드를 두 그룹으로 나눕니다.

**해석**
실행 결과는 다음과 같습니다.

```
Fiedler 벡터: [ 0.3872  0.3872  0.3157 -0.4896 -0.6006]
클러스터 A (양수): [1 2 3]
클러스터 B (음수): [4 5]
```

두 번째로 작은 고윳값에 대응하는 고유벡터(**Fiedler 벡터**)의 부호가 클러스터를 가릅니다. 값이 양수인 노드 1·2·3이 한 그룹, 음수인 노드 4·5가 다른 그룹으로 자연스럽게 분리됩니다. 이는 원래 그래프에서 앞 세 노드가 강하게 연결(가중치 4~5)되고 뒤 두 노드가 따로 뭉친 구조와 정확히 일치합니다.

**실무 연결**
K-means가 원형 덩어리만 잘 나누는 것과 달리, 스펙트럴 클러스터링은 고윳값 정보를 이용해 **복잡한 모양의 그룹**도 나눌 수 있습니다. 소셜 네트워크의 커뮤니티 탐지, 이미지 분할(segmentation), 문서 군집화에 활용됩니다. 첫 고윳값이 0에 가깝다는 사실은 그래프가 연결되어 있다는 신호이기도 합니다.

## 헷갈리기 쉬운 포인트

- **eig vs eigh**: 일반 행렬은 `eig`, 대칭행렬은 `eigh`(더 정확·정렬됨).
- **고유벡터의 부호/크기**: 방향만 같으면 같은 고유벡터 — 부호나 배율이 달라도 정답.
- **대각화 가능 vs 불가능**: 독립 고유벡터가 $n$ 개여야 가능. 중근 + 부족한 고유벡터 → 불가능.
- **PDM vs PSDM**: 고윳값 전부 양수(>0)면 PDM, 0 포함 음수 아님(≥0)이면 PSDM.

## 연결되는 개념

- 다음 글: [특이값 분해 (SVD)](04-singular-value-decomposition.md) — 대칭이 아닌 임의의 행렬에도 통하도록 고유분해를 일반화한 것이 SVD입니다.
- 더 찾아볼 키워드: `PCA`, `페이지랭크`, `마르코프 체인`, `이차형식(quadratic form)`, `Fiedler 벡터`

## 셀프 체크

- [ ] $Av = \lambda v$ 의 의미를 그림으로 설명할 수 있다.
- [ ] 특성방정식으로 고윳값을 구하는 절차를 안다.
- [ ] 대각화 가능 조건(독립 고유벡터 $n$ 개)을 안다.
- [ ] 대각화로 거듭제곱을 빠르게 계산하는 원리를 안다.
- [ ] 대칭행렬의 고유벡터가 직교한다는 사실을 안다.
- [ ] PDM과 고윳값 부호의 관계를 설명할 수 있다.

**복습 질문 및 답변**

*기본* — 고유벡터란 무엇인가?
> 행렬 $A$ 를 곱해도 방향이 변하지 않고 크기만 $\lambda$ 배 되는 0이 아닌 벡터. $Av = \lambda v$ 를 만족한다.

*이해확인* — 고윳값이 모두 다른 행렬이 항상 대각화되는 이유는?
> 서로 다른 고윳값의 고유벡터는 항상 일차독립이므로, $n$ 개의 독립 고유벡터가 확보되어 대각화 조건을 만족한다.

*응용* — PCA에서 공분산행렬의 고유벡터와 고윳값은 각각 무엇을 의미하는가?
> 고유벡터는 데이터 분산이 큰 방향(주성분)이고, 고윳값은 그 방향이 설명하는 분산의 양이다. 큰 고윳값 방향 몇 개만 남기면 차원 축소가 된다. 공분산행렬이 대칭이라 주성분들이 서로 직교한다.

## 한 줄 정리

> 고유벡터는 변환의 축, 고윳값은 그 축의 확대 비율이며, 대각화·고유분해는 복잡한 행렬을 이 축들의 단순한 조합으로 다시 써 PCA·클러스터링·거듭제곱 계산을 가능하게 한다.
