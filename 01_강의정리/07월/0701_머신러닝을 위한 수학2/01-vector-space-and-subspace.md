# 벡터공간과 부분공간 — 벡터가 사는 세계의 규칙

> "벡터들을 아무렇게나 모아 놓으면 그게 '공간'이 될까?" 대부분은 안 됩니다. 공간이 되려면 지켜야 할 규칙이 있고, 그 규칙을 이해하면 PCA·차원 축소·직교화 같은 머신러닝 기법이 왜 그렇게 작동하는지가 한눈에 보입니다.

`벡터공간` `부분공간` `일차결합` `Span` `일차독립` `기저` `차원` `직교기저` `Gram-Schmidt` `직교여공간`

## 핵심요약

- **벡터공간**은 덧셈과 스칼라 곱이 정의된, 벡터들이 사는 무대다.
- **부분공간**은 그 무대 안의 작은 무대인데, 두 가지 규칙(덧셈에 닫힘·스칼라 곱에 닫힘)을 지켜야 하며 반드시 **원점을 포함**한다.
- **Span**은 벡터 몇 개로 만들 수 있는 모든 조합의 집합이고, 항상 부분공간이 된다.
- **일차독립**은 "서로 겹치는 정보가 없는" 벡터들, **일차종속**은 "하나가 나머지로 표현되는" 벡터들이다.
- **기저**는 공간을 낭비 없이(최소 개수로) 생성하는 벡터 묶음이고, 그 개수가 **차원**이다.
- **직교기저**는 서로 수직인 기저, 여기에 길이까지 1로 맞추면 **정규직교기저**다.
- **Gram-Schmidt**는 아무 기저나 받아서 직교기저로 바꿔 주는 절차다.
- 이 개념들은 PCA(주성분 분석), QR 분해, SVD의 직접적인 토대가 된다.

## 개념별 정리

### 부분공간 (Subspace)

**1. 정의**
벡터공간 $R^n$ 안의 부분집합 $W$가 다음 두 조건을 지키면 **부분공간**입니다.

1. 덧셈에 닫힘: $x, y \in W$ 이면 $x + y \in W$
2. 스칼라 곱에 닫힘: $x \in W$ 이면 임의의 실수 $\lambda$ 에 대해 $\lambda x \in W$

$\lambda = 0$ 을 넣으면 $0 \cdot x = 0 \in W$ 이 되므로, **부분공간은 반드시 원점(0벡터)을 포함**합니다.

**2. 왜 필요한가?**
데이터는 보통 고차원 공간에 흩어져 있지만, 실제로 의미 있는 정보는 그보다 낮은 차원의 "부분공간"에 몰려 있는 경우가 많습니다. 차원 축소(PCA)는 결국 "데이터를 가장 잘 담는 부분공간을 찾는 일"입니다. 부분공간의 조건을 알면 어떤 집합이 안정적인 계산 대상이 되는지 판별할 수 있습니다.

**3. 예시**
원점을 지나는 직선 $W = \{t(1,2) \mid t \in R\}$ 은 부분공간입니다.

```python
import numpy as np

direction = np.array([1, 2])

# [조건 1] 덧셈에 닫혀 있는가?
t1, t2 = 1.5, -0.5
v1 = t1 * direction   # 1.5*(1,2)
v2 = t2 * direction   # -0.5*(1,2)
v_sum = v1 + v2       # 다시 t*(1,2) 형태가 되는지 확인
print("v1 + v2 =", v_sum)

# [조건 2] 스칼라 곱에 닫혀 있는가?
lam = 3.0
v_scaled = lam * v1
print("λ*v1 =", v_scaled)
```

실행 결과:

```
v1 + v2 = [1. 2.]
λ*v1 = [4.5 9. ]
```

$v_1 + v_2 = (1,2) = 1\cdot(1,2)$, $\lambda v_1 = (4.5, 9) = 4.5\cdot(1,2)$ 로 둘 다 여전히 "$(1,2)$ 의 배수" 형태입니다. 즉 직선을 벗어나지 않으므로 부분공간입니다.

**4. 헷갈리기 쉬운 점**
원점을 지나지 **않는** 직선은 부분공간이 아닙니다(원점을 포함하지 않으므로). 원점을 지나는 **포물선** $\{(x, x^2)\}$ 도 부분공간이 아닙니다. $(1,1)$ 과 $(1,1)$ 을 더하면 $(2,2)$ 인데 $2^2 = 4 \neq 2$ 이므로 덧셈에 닫히지 않기 때문입니다.

**5. 한 줄 정리**
부분공간은 "원점을 품고, 더하거나 늘려도 밖으로 새지 않는" 집합이다.

> 🍞 **비유**: 부분공간은 **직원 전용 구역**입니다. 그 안의 두 사람이 힘을 합쳐도(덧셈), 한 사람이 몇 배로 늘어나도(스칼라 곱) 여전히 그 구역 안에 있어야 합니다. 밖으로 나가는 순간 "전용 구역"이 아니게 됩니다.

### 일차결합과 Span

**1. 정의**
벡터들에 각각 계수를 곱해 더한 것을 **일차결합(linear combination)** 이라 합니다.

$$\lambda_1 x_1 + \lambda_2 x_2 + \cdots + \lambda_m x_m$$

이 벡터들로 만들 수 있는 **모든** 일차결합의 집합이 **Span**입니다. Span은 언제나 부분공간이 됩니다.

**2. 왜 필요한가?**
"이 몇 개의 벡터로 어디까지 도달할 수 있는가?"를 답하는 개념입니다. 벡터 1개의 Span은 직선, 서로 다른 방향의 벡터 2개의 Span은 평면이 됩니다. 데이터가 놓인 공간의 "표현 범위"를 이해하는 데 쓰입니다.

**3. 예시**
$(3,0)$ 과 $(1,2)$ 를 각각 1배씩 더하면 $(4,2)$ 라는 새 벡터가 나옵니다. 이는 평행사변형의 대각선에 해당하며, 두 벡터의 Span은 평면 전체($R^2$)입니다.

**4. 헷갈리기 쉬운 점**
벡터가 2개여도 Span이 항상 평면인 것은 아닙니다. 두 벡터가 평행하면(일차종속) Span은 직선에 그칩니다. "벡터 개수"가 아니라 "서로 다른 방향의 개수"가 Span의 차원을 결정합니다.

**5. 한 줄 정리**
Span은 주어진 벡터들로 도달 가능한 모든 지점의 집합이다.

### 일차독립과 일차종속

**1. 정의**
$\lambda_1 x_1 + \cdots + \lambda_m x_m = 0$ 이라는 방정식에서, 해가 $\lambda_1 = \cdots = \lambda_m = 0$ (자명해)뿐이면 **일차독립**, 0이 아닌 다른 해가 있으면 **일차종속**입니다.

**2. 왜 필요한가?**
일차종속은 데이터에서 **다중공선성(중복 정보)** 과 직결됩니다. 어떤 변수가 다른 변수들의 조합으로 표현된다면, 그 변수는 새 정보를 주지 못합니다. 회귀분석·특성 선택에서 이런 중복을 걸러내는 판단 기준이 됩니다.

**3. 예시**

```python
import numpy as np

# 예제 2: u1, u2, u3 = u1+u2  → 종속
u1 = np.array([1, 0, 0])
u2 = np.array([0, 1, 0])
u3 = u1 + u2               # [1 1 0]
A = np.array([u1, u2, u3])
print("rank =", np.linalg.matrix_rank(A), "/ 벡터 수 =", len(A))

# 예제 3: 서로 다른 방향 → 독립
B = np.array([[1, -2, 2], [2, -1, -2], [2, 2, 1]])
print("det(B) =", round(np.linalg.det(B), 1))
```

실행 결과:

```
rank = 2 / 벡터 수 = 3
det(B) = 27.0
```

첫 예제는 rank(2)가 벡터 수(3)보다 작으므로 **종속**입니다($u_3 = u_1 + u_2$). 둘째 예제는 행렬식이 $27 \neq 0$ 이므로 세 벡터가 **독립**입니다.

**4. 헷갈리기 쉬운 점**
"일차종속 = 나쁜 것"이 아닙니다. 종속은 단지 "정보가 겹친다"는 사실일 뿐이고, 압축·차원 축소에서는 오히려 활용 대상입니다. 또 정사각행렬에서는 `det ≠ 0`이 독립의 편리한 판별법이지만, 직사각행렬에서는 rank로 판별해야 합니다.

**5. 한 줄 정리**
일차독립은 "겹치는 정보가 없음", 일차종속은 "하나가 나머지로 표현됨"이다.

> 🍞 **비유**: 팀원 3명이 있는데 한 명이 나머지 두 명 의견을 그대로 합친 것만 말한다면(종속), 실제로 목소리는 2개뿐입니다. 세 명이 각자 다른 관점을 낸다면(독립) 진짜 3인분의 정보가 있는 셈입니다.

### 기저와 차원

**1. 정의**
공간 전체를 Span하면서 동시에 일차독립인 벡터 묶음을 **기저(basis)** 라 하고, 기저에 속한 벡터의 개수를 그 공간의 **차원(dimension)** 이라 합니다.

**2. 왜 필요한가?**
기저는 공간을 표현하는 "좌표계"입니다. 같은 벡터라도 어떤 기저를 쓰느냐에 따라 좌표가 달라지며, PCA는 결국 "데이터를 가장 잘 설명하는 새로운 기저(주성분)"를 찾는 작업입니다.

**3. 예시**
$(1,1)$ 과 $(-1,1)$ 은 $R^2$ 의 기저입니다. 벡터 $(2,3)$ 을 이 기저로 표현하면:

```python
import numpy as np

B = np.array([[1, -1], [1, 1]])   # 기저 벡터를 열로
print("det =", np.linalg.det(B))   # 0이 아니면 독립 → 기저
coords = np.linalg.solve(B, np.array([2, 3]))
print("(2,3)의 새 좌표 =", coords)
```

실행 결과:

```
det = 2.0
(2,3)의 새 좌표 = [2.5 0.5]
```

$(2,3) = 2.5\cdot(1,1) + 0.5\cdot(-1,1)$ 로, 같은 벡터가 새 기저에서는 좌표 $(2.5, 0.5)$ 로 표현됩니다.

**4. 헷갈리기 쉬운 점**
기저는 유일하지 않지만(무수히 많음), 기저 벡터의 **개수(차원)** 는 유일하게 정해집니다. 또 표준기저 $e_1=(1,0), e_2=(0,1)$ 만 기저인 것이 아니라, 독립이면서 공간을 채우는 어떤 묶음도 기저가 됩니다.

**5. 한 줄 정리**
기저는 공간을 낭비 없이 생성하는 최소 벡터 묶음이고, 그 개수가 차원이다.

**차원 공식**: 두 부분공간 $W_1, W_2$ 에 대해 $\dim(W_1 + W_2) = \dim W_1 + \dim W_2 - \dim(W_1 \cap W_2)$ 가 성립합니다. 예를 들어 $R^3$ 에서 xy평면(2차원)과 xz평면(2차원)이 x축(1차원)에서 겹치면 $2 + 2 - 1 = 3$ 으로 $R^3$ 전체가 됩니다.

### 직교기저·정규직교기저와 Gram-Schmidt

**1. 정의**
기저 벡터들이 서로 수직(내적이 0)이면 **직교기저**, 여기에 각 벡터의 길이까지 1이면 **정규직교기저**입니다. **Gram-Schmidt** 과정은 임의의 기저를 받아 직교기저로 바꾸는 알고리즘입니다.

**2. 왜 필요한가?**
정규직교기저에서는 벡터의 좌표를 "내적 계산만으로" 바로 구할 수 있어 계산이 극적으로 간단해집니다. QR 분해, 최소제곱법(선형 회귀), SVD가 모두 직교기저 위에서 작동합니다.

**3. 예시** — Gram-Schmidt로 직교기저 만들기

```python
import numpy as np

u1 = np.array([1., 0., 0.])
u2 = np.array([2., 0., 3.])
u3 = np.array([4., 5., 6.])

v1 = u1
# v2 = u2에서 v1 방향 성분 제거
v2 = u2 - (np.dot(v1, u2) / np.dot(v1, v1)) * v1
# v3 = u3에서 v1, v2 방향 성분 제거
v3 = u3 - (np.dot(v1, u3) / np.dot(v1, v1)) * v1 \
        - (np.dot(v2, u3) / np.dot(v2, v2)) * v2

print("v1 =", v1)
print("v2 =", v2)
print("v3 =", v3)
print("직교 검증 <v1,v2>, <v1,v3>, <v2,v3> =",
      np.dot(v1, v2), np.dot(v1, v3), np.dot(v2, v3))
```

실행 결과:

```
v1 = [1. 0. 0.]
v2 = [0. 0. 3.]
v3 = [0. 5. 0.]
직교 검증 <v1,v2>, <v1,v3>, <v2,v3> = 0.0 0.0 0.0
```

세 결과 벡터가 서로 수직(모든 내적 0)임을 확인할 수 있습니다. 각 단계는 "새 벡터에서 이미 확보한 직교 방향 성분을 투영해 빼내는" 방식입니다.

**4. 헷갈리기 쉬운 점**
직교기저와 정규직교기저는 다릅니다. 직교기저는 "수직"만 만족하고, 정규직교기저는 여기에 "길이 1"까지 요구합니다. Gram-Schmidt만 하면 직교기저가 되고, 각 벡터를 자기 길이로 나눠 정규화해야 정규직교기저가 됩니다.

**5. 한 줄 정리**
Gram-Schmidt는 아무 기저나 받아 서로 수직인 축으로 다시 세워 주는 절차다.

> 🍞 **비유**: 방을 정리할 때 가구를 벽에 딱 맞춰 직각으로 배치하면(직교) 공간 계산이 쉬워집니다. Gram-Schmidt는 삐뚤빼뚤 놓인 가구를 하나씩 직각으로 정렬해 주는 정리 규칙입니다.

### 직교여공간 (Orthogonal Complement)

**1. 정의**
부분공간 $W$ 에 대해, $W$ 의 **모든** 벡터와 수직인 벡터들의 집합을 $W$ 의 **직교여공간** $W^\perp$ 이라 합니다. $W^\perp$ 도 부분공간이며, $R^n = W \oplus W^\perp$ (직합)이 성립합니다.

**2. 왜 필요한가?**
"이 부분공간에 담기지 않는 나머지 방향"을 정확히 집어내는 개념입니다. 최소제곱법에서 잔차(오차)는 항상 예측 공간의 직교여공간에 놓입니다. 신호에서 노이즈를 분리하는 관점의 기초이기도 합니다.

**3. 예시**
$R^3$ 에서 $W = \text{Span}\{(1,0,0), (1,1,0)\}$ (xy평면)일 때, 이와 수직인 방향은 z축뿐입니다. 즉 $W^\perp = \text{Span}\{(0,0,1)\}$.

**4. 헷갈리기 쉬운 점**
$W$ 의 "모든" 원소와 수직이어야 하지만, 실제로는 **기저 벡터들과의 수직만 확인하면 충분**합니다(기저의 조합이 전체를 만들므로). 확인해야 할 조건 수를 줄여 주는 실용적 성질입니다.

**5. 한 줄 정리**
직교여공간은 어떤 부분공간에 완전히 수직인 "나머지 방향" 전체다.

## 코드로 보기 — 직교여공간 원소 판별

```python
import numpy as np

# W = Span{(1, 0, 0), (1, 1, 0)}
w1 = np.array([1, 0, 0])
w2 = np.array([1, 1, 0])

candidates = {
    "(2,1,0)":  np.array([2, 1, 0]),
    "(0,1,0)":  np.array([0, 1, 0]),
    "(0,0,1)":  np.array([0, 0, 1]),
    "(-2,1,3)": np.array([-2, 1, 3]),
}

for label, v in candidates.items():
    dot1 = np.dot(v, w1)   # <v, w1>
    dot2 = np.dot(v, w2)   # <v, w2>
    is_perp = (dot1 == 0 and dot2 == 0)
    print(f"v = {label}: <v,w1>={dot1}, <v,w2>={dot2} → W⊥ 원소? {'YES' if is_perp else 'NO'}")
```

**코드목적**
후보 벡터들이 $W$ 의 직교여공간에 속하는지, 두 기저 벡터와의 내적이 모두 0인지로 판별합니다.

**해석**
실행 결과는 다음과 같습니다.

```
v = (2,1,0): <v,w1>=2, <v,w2>=3 → W⊥ 원소? NO
v = (0,1,0): <v,w1>=0, <v,w2>=1 → W⊥ 원소? NO
v = (0,0,1): <v,w1>=0, <v,w2>=0 → W⊥ 원소? YES
v = (-2,1,3): <v,w1>=-2, <v,w2>=-1 → W⊥ 원소? NO
```

두 내적이 **동시에** 0인 벡터는 $(0,0,1)$ 뿐입니다. 나머지는 최소 하나의 기저와 수직이 아니므로 탈락합니다. 즉 $W^\perp = \text{Span}\{(0,0,1)\}$ 임이 수치로 확인됩니다.

**실무 연결**
추천 시스템·차원 축소에서 "이미 설명된 성분"과 "남은 성분"을 분리할 때 이 판별 논리가 그대로 쓰입니다. 남은 성분(직교여공간 방향)이 곧 새로운 정보이거나 노이즈입니다.

## 헷갈리기 쉬운 포인트

- **부분공간 vs 아무 집합**: 부분공간은 원점 포함 + 두 연산에 닫혀 있어야 함. 원점 안 지나는 직선·곡선은 탈락.
- **Span의 차원 vs 벡터 개수**: 벡터가 여러 개여도 방향이 겹치면(종속) Span 차원은 그보다 작음.
- **직교기저 vs 정규직교기저**: 전자는 "수직"만, 후자는 "수직 + 길이 1". 정규화 한 단계 차이.
- **일차독립 판별**: 정사각행렬은 `det ≠ 0`, 직사각행렬은 `rank`로 판별.

## 셀프 체크

- [ ] 일차독립/종속을 rank 또는 행렬식으로 판별할 수 있다.

**복습 질문 및 답변**

*기본* — 부분공간이 되기 위한 두 조건은?
> 덧셈에 닫혀 있을 것, 스칼라 곱에 닫혀 있을 것. 이로부터 원점 포함이 따라온다.

*이해확인* — 벡터 3개가 있는데 rank가 2로 나왔다. 이 벡터들은 독립인가 종속인가?
> 종속이다. 벡터 개수(3)보다 rank(서로 다른 방향의 수, 2)가 작으므로, 하나가 나머지의 일차결합으로 표현된다.

*응용* — 데이터에서 어떤 변수가 다른 두 변수의 합으로 나타난다면, 선형대수적으로 어떤 상황이며 어떤 문제를 일으키는가?
> 일차종속(다중공선성) 상황이다. 그 변수는 새 정보를 주지 않아 rank가 낮아지고, 회귀에서 계수 추정이 불안정해진다. 차원 축소로 중복을 제거하는 것이 해법이다.

## 한 줄 정리

> 벡터공간·부분공간·기저·직교화는 "데이터가 어떤 공간에서 몇 개의 독립된 축으로 표현되는가"를 다루는 언어이며, PCA·SVD를 포함한 거의 모든 차원 축소 기법의 출발점이다.
