# 특이값 분해 (SVD) — 모든 행렬을 쪼개는 만능 열쇠

> 고윳값 분해는 편리하지만 정사각·대칭행렬에서만 깔끔하게 작동합니다. 그런데 현실의 데이터 행렬은 대부분 직사각형입니다(사용자 × 상품, 문서 × 단어). **특이값 분해(SVD)** 는 이 제약을 없앤 일반화로, 세상의 어떤 행렬이든 세 조각으로 쪼개 줍니다. 추천 시스템·이미지 압축·잠재의미분석이 모두 이 하나의 도구 위에 서 있습니다.

`특이값 분해` `SVD` `특이값` `좌특이벡터` `우특이벡터` `PSDM` `rank-k 근사` `저차원 근사` `이미지 압축` `차원 축소`

## 핵심요약

- **SVD**는 임의의 $m \times n$ 행렬을 $A = U \Lambda V^\top$ 세 조각으로 분해한다.
- $U$, $V$ 는 직교행렬(회전·반사), $\Lambda$ 는 대각행렬(늘림)이다 — "회전 → 늘림 → 회전"의 3단계.
- **특이값** $\sigma_i$ 는 $A^\top A$ 고윳값의 제곱근이며, 항상 0 이상이고 큰 순서로 정렬된다.
- $V$ 의 열은 $A^\top A$ 의 고유벡터, $U$ 의 열은 $AA^\top$ 의 고유벡터다.
- 임의의 $A$ 에 대해 $A^\top A$, $AA^\top$ 는 항상 양의 준정부호(PSDM)라 SVD가 늘 존재한다.
- **rank-k 근사**: 큰 특이값 몇 개만 남겨 행렬을 근사하면 손실을 최소화하며 압축된다.
- 이미지 압축·추천 시스템·LSA·노이즈 제거가 모두 rank-k 근사의 응용이다.

## 개념별 정리

### SVD의 정의

**1. 정의**
모든 $m \times n$ 행렬 $A$ 는 다음처럼 분해됩니다.

$$A = U \Lambda V^\top$$

| 기호 | 크기 | 성질 |
| --- | --- | --- |
| $U$ | $m \times m$ | 직교행렬 ($U^\top U = I$) — 좌특이벡터 |
| $\Lambda$ | $m \times n$ | 대각행렬 — 대각에 특이값 $\sigma_1 \geq \sigma_2 \geq \cdots \geq 0$ |
| $V$ | $n \times n$ | 직교행렬 ($V^\top V = I$) — 우특이벡터 |

**2. 왜 필요한가?**
고유분해는 정사각행렬에만 되지만, SVD는 **직사각행렬에도** 적용됩니다. 현실 데이터(사용자-상품 평점, 문서-단어 빈도)는 대부분 직사각형이라, SVD가 이들을 다루는 표준 도구가 됩니다.

**3. 예시**

```python
import numpy as np

A = np.array([[1., 1., 0.], [0., 0., 1.]])   # 2×3 직사각행렬
U, S, Vt = np.linalg.svd(A)
print("U =\n", np.round(U, 4))
print("특이값 S =", np.round(S, 4))
print("복원 U Λ Vt == A ?", np.allclose(U @ np.hstack([np.diag(S), np.zeros((2,1))]) @ Vt, A))
```

실행 결과:

```
U =
 [[1. 0.]
 [0. 1.]]
특이값 S = [1.4142 1.    ]
복원 U Λ Vt == A ? True
```

특이값은 $\sqrt{2} \approx 1.414$ 와 1이고, 세 조각을 다시 곱하면 원본 $A$ 가 정확히 복원됩니다.

**4. 헷갈리기 쉬운 점**
`np.linalg.svd`는 $V$ 가 아니라 이미 전치된 $V^\top$(코드의 `Vt`)를 반환합니다. 또 특이값 $S$ 는 정사각 대각행렬이 아니라 1차원 배열로 나오므로, 복원할 때는 $m \times n$ 크기의 $\Lambda$ 로 직접 배치해야 합니다.

**5. 한 줄 정리**
SVD는 어떤 행렬이든 "회전 → 축별 늘림 → 회전"의 세 단계로 분해한다.

> 🍞 **비유**: 어떤 변형이든 **몸을 돌리고(U) → 각 방향으로 잡아 늘린 뒤($\Lambda$) → 다시 돌리는(V)** 세 동작으로 나눌 수 있습니다. SVD는 복잡한 변환을 이 세 기본 동작의 조합으로 해체하는 것입니다.

### 특이값과 좌·우 특이벡터

**1. 정의**
특이값 $\sigma_i$ 는 $A^\top A$ (또는 $AA^\top$)의 고윳값의 제곱근입니다: $\sigma_i = \sqrt{\lambda_i(A^\top A)}$. $V$ 의 열은 $A^\top A$ 의 고유벡터(**우특이벡터**), $U$ 의 열은 $AA^\top$ 의 고유벡터(**좌특이벡터**)입니다.

**2. 왜 필요한가?**
특이값의 크기는 "그 방향이 데이터를 얼마나 많이 담고 있는가"를 나타냅니다. 큰 특이값 방향은 주요 패턴, 작은 특이값 방향은 세부·노이즈에 해당합니다. 이 순서 덕분에 "중요한 것부터" 골라 쓸 수 있습니다.

**3. 예시**
$A = \begin{pmatrix} 4 & 0 \\ 3 & -5 \end{pmatrix}$ 의 특이값을 구해 봅니다.

```python
import numpy as np

A = np.array([[4., 0.], [3., -5.]])
AtA = A.T @ A
print("A^T A =\n", AtA)
print("A^T A 고윳값:", np.linalg.eigvalsh(AtA))   # 10, 40
U, S, Vt = np.linalg.svd(A)
print("특이값 S =", np.round(S, 4))                # √40, √10
```

실행 결과:

```
A^T A =
 [[ 25. -15.]
 [-15.  25.]]
A^T A 고윳값: [10. 40.]
특이값 S = [6.3246 3.1623]
```

$A^\top A$ 의 고윳값 40, 10의 제곱근 $\sqrt{40} \approx 6.32$, $\sqrt{10} \approx 3.16$ 이 특이값과 정확히 일치합니다.

**4. 헷갈리기 쉬운 점**
고윳값은 음수일 수 있지만 **특이값은 항상 0 이상**입니다. $A^\top A$ 가 PSDM이라 고윳값이 음수가 아니고, 그 제곱근인 특이값도 음수가 될 수 없기 때문입니다. 또 $U$ 와 $V$ 의 고유벡터는 부호가 반대로 나올 수 있으나 방향(축)은 같습니다.

**5. 한 줄 정리**
특이값은 각 축이 데이터를 담는 양이고, 큰 것부터 정렬되어 중요도 순서를 준다.

### rank-1 분해와 rank-k 근사

**1. 정의**
SVD는 rank-1 조각들의 합으로 다시 쓸 수 있습니다.

$$A = \sigma_1 u_1 v_1^\top + \sigma_2 u_2 v_2^\top + \cdots + \sigma_k u_k v_k^\top$$

여기서 큰 특이값에 해당하는 상위 $k$ 개 항만 남긴 것이 **rank-k 근사**입니다.

**2. 왜 필요한가?**
작은 특이값 항은 원본에 거의 기여하지 않습니다. 이들을 버리면 저장 공간은 크게 줄면서 정보 손실은 적습니다. 이것이 이미지 압축·추천 시스템·노이즈 제거의 공통 원리입니다.

**3. 예시**

```python
import numpy as np
np.random.seed(0)

A = np.array([[3., 1., 4., 1.], [5., 9., 2., 6.],
              [5., 3., 5., 8.], [9., 9., 9., 3.]])
U, S, Vt = np.linalg.svd(A)
print("특이값 S =", np.round(S, 4))

for k in [1, 2, 3, 4]:
    Ak = U[:, :k] @ np.diag(S[:k]) @ Vt[:k, :]
    err = np.linalg.norm(A - Ak)
    keep = (1 - err / np.linalg.norm(A)) * 100
    print(f"rank-{k}: 오차={err:.4f}, 원본 보존률={keep:.1f}%")
```

실행 결과:

```
특이값 S = [21.9785  6.1108  5.2536  0.051 ]
rank-1: 오차=8.0589, 원본 보존률=65.6%
rank-2: 오차=5.2539, 원본 보존률=77.6%
rank-3: 오차=0.0510, 원본 보존률=99.8%
rank-4: 오차=0.0000, 원본 보존률=100.0%
```

네 번째 특이값(0.051)이 매우 작아서, rank-3 근사만으로도 원본의 99.8%를 보존합니다. 즉 마지막 조각은 거의 버려도 됩니다.

**4. 헷갈리기 쉬운 점**
"몇 개를 남길지($k$)"는 특이값이 얼마나 빨리 작아지는지에 달렸습니다. 특이값이 급격히 감소하면 적은 $k$ 로도 충분하지만, 완만하면 많은 항이 필요합니다. 무작정 절반을 남기는 것이 아니라 특이값 분포를 보고 결정합니다.

**5. 한 줄 정리**
rank-k 근사는 큰 특이값 몇 개만 남겨 정보 손실을 최소화하며 행렬을 압축한다.

## 코드로 보기 — SVD로 이미지 압축하기

```python
import numpy as np

# rank가 낮은 이미지 행렬 예시 (13×13, 실제 rank=6)
np.random.seed(1)
base = np.random.randn(13, 6)
A = base @ base.T[:6, :13]        # rank 6짜리 13×13 행렬
U, S, Vt = np.linalg.svd(A)

print("특이값 상위 6개:", np.round(S[:6], 4))
r = np.linalg.matrix_rank(A)
mn = A.shape[0] * A.shape[1]
compressed = r * (A.shape[0] + A.shape[1])
print(f"이미지 크기: {A.shape[0]} × {A.shape[1]} = {mn}")
print(f"실제 rank: {r}")
print(f"rank-{r} 압축 시 저장 원소 수: {compressed}")
print(f"압축률: {mn / compressed:.1f}배")
```

**코드목적**
이미지를 픽셀 행렬로 보고, SVD로 상위 특이값만 남겼을 때 저장 공간이 얼마나 줄어드는지를 계산합니다.

**해석**
개념적으로, $m \times n$ 이미지를 rank-$k$ 로 근사하면 원본 $m \times n$ 개 원소 대신 $k(m + n)$ 개 원소($u_i, v_i$ 벡터들과 특이값)만 저장하면 됩니다. 강의에서 다룬 실제 사례를 보면, $203 \times 233$ 흑백 이미지(원소 47,299개)가 rank(A)=5일 때 $5 \times (203 + 233) = 2{,}180$ 개로 줄어 **약 21.7배 압축**됩니다.

핵심은 특이값이 빠르게 작아질수록 적은 $k$ 로도 원본에 가깝게 복원된다는 점입니다. 큰 특이값이 이미지의 큰 윤곽을, 작은 특이값이 미세한 디테일을 담고 있어, 앞쪽 몇 개만으로도 형태가 살아납니다.

**실무 연결**
- **추천 시스템**: 사용자-상품 평점 행렬을 SVD로 분해해 "잠재 요인(latent factor)"을 뽑고, 평가하지 않은 항목을 예측합니다.
- **잠재의미분석(LSA)**: 문서-단어 행렬을 저차원으로 근사해 의미가 비슷한 단어·문서를 찾습니다.
- **노이즈 제거**: 작은 특이값은 대개 노이즈에 해당하므로, 이를 버리면 신호가 깨끗해집니다.
- **PCA와의 관계**: 데이터를 중심화한 뒤 SVD를 하면 우특이벡터가 곧 주성분이 됩니다.

## 직접 해보기

1. $2 \times 2$ 행렬 $A = \begin{pmatrix} 4 & 0 \\ 3 & -5 \end{pmatrix}$ 의 특이값을 손으로 구해 보세요. ($A^\top A$ 의 고윳값을 먼저 구하고 제곱근을 취합니다.)
2. 특이값이 $[10, 8, 0.3, 0.1]$ 인 어떤 행렬이 있습니다. rank-2 근사가 원본을 잘 대표할 수 있을지, 특이값 분포를 근거로 판단해 보세요.
3. $100 \times 100$ 이미지를 rank-5로 압축하면 저장 원소 수는 몇 개이고 압축률은 몇 배인지 계산해 보세요.

<details>
<summary>정답 및 해설</summary>

**1. 특이값 = $\sqrt{40} = 2\sqrt{10} \approx 6.32$, $\sqrt{10} \approx 3.16$**
$A^\top A = \begin{pmatrix} 25 & -15 \\ -15 & 25 \end{pmatrix}$, $\det(\lambda I - A^\top A) = (\lambda-25)^2 - 225 = (\lambda-40)(\lambda-10) = 0$ 이므로 고윳값은 40, 10. 특이값은 그 제곱근입니다.

**2. 잘 대표할 수 있다.**
상위 두 특이값(10, 8)이 나머지(0.3, 0.1)보다 압도적으로 큽니다. 작은 두 특이값이 담는 정보가 거의 없으므로, rank-2 근사만으로 원본의 대부분을 보존합니다. 특이값이 급격히 떨어지는 지점(여기서는 8 → 0.3)이 좋은 절단 기준입니다.

**3. 저장 원소 = 1,000개, 압축률 = 10배**
원본은 $100 \times 100 = 10{,}000$ 개. rank-5 근사는 $5 \times (100 + 100) = 1{,}000$ 개. 압축률 $10{,}000 / 1{,}000 = 10$ 배입니다.

## 헷갈리기 쉬운 포인트

- **SVD vs 고유분해**: 고유분해는 정사각·대칭행렬 전용, SVD는 모든 행렬에 적용.
- **특이값 vs 고윳값**: 특이값은 항상 ≥ 0, 고윳값은 음수 가능. 특이값 = $\sqrt{A^\top A\text{의 고윳값}}$.
- **`svd` 반환값**: $V$ 가 아니라 $V^\top$(`Vt`)를 반환, $S$ 는 1차원 배열.
- **$k$ 선택**: 특이값 감소 속도를 보고 결정 — 무작정 절반이 아님.

**복습 질문 및 답변**

*기본* — SVD는 행렬을 몇 조각으로, 무엇으로 분해하는가?
> 세 조각 $U \Lambda V^\top$. $U$·$V$ 는 직교행렬(회전·반사), $\Lambda$ 는 특이값을 담은 대각행렬(늘림)이다.

*이해확인* — 특이값이 음수가 될 수 없는 이유는?
> 특이값은 $A^\top A$ 고윳값의 제곱근인데, $A^\top A$ 는 항상 양의 준정부호(PSDM)라 고윳값이 음수가 아니다. 따라서 제곱근인 특이값도 0 이상이다.

*응용* — 사용자-상품 평점 행렬에 SVD를 적용하면 추천이 가능한 이유는?
> 큰 특이값 몇 개가 "취향의 주요 축(잠재 요인)"을 담는다. 이 저차원 구조로 행렬을 근사하면 평가하지 않은 칸의 값을 예측할 수 있어, 아직 보지 않은 상품에 대한 선호를 추정해 추천한다.

## 한 줄 정리

> SVD는 어떤 행렬이든 "회전-늘림-회전" 세 조각으로 쪼개고, 큰 특이값 몇 개만 남기는 rank-k 근사로 이미지 압축·추천·노이즈 제거를 가능하게 하는 선형대수의 만능 도구다.
