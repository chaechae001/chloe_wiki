# 선형변환과 행렬 — 행렬을 "공간을 잇는 함수"로 보기

> 행렬 곱셈을 그냥 "숫자 계산 규칙"으로만 외웠다면 절반만 아는 것입니다. 행렬은 사실 **한 공간을 다른 공간으로 옮기는 함수**이고, 이 관점을 얻으면 신경망의 레이어가 왜 "$Wx + b$"인지, PCA가 왜 행렬 분해인지가 자연스럽게 이해됩니다.

`선형변환` `행렬의 3가지 관점` `Frobenius Norm` `전치행렬` `대칭행렬` `직교행렬` `역행렬` `rank` `행렬식` `determinant`

## 핵심요약

- 행렬은 세 가지 관점으로 볼 수 있다: 벡터의 확장(표), 공간을 잇는 함수, 곱셈으로 변형되는 대상.
- **선형변환**은 덧셈과 스칼라 곱을 보존하는 함수이며, 모든 행렬 곱 $Ax$ 가 선형변환이다.
- 행렬도 벡터처럼 크기를 잰다 — 원소 제곱합의 제곱근인 **Frobenius Norm**.
- **직교행렬**($A^\top A = I$)은 길이·내적·각도를 모두 보존하는 특별한 변환(회전·반사)이다.
- **역행렬**은 변환을 되돌리는 역함수이며, `det ≠ 0`일 때만 존재한다.
- **rank**는 행렬이 담고 있는 "독립된 정보의 개수"이고, 낮은 rank는 다중공선성을 뜻한다.
- **행렬식(det)** 은 변환이 부피를 얼마나 늘리는지를 나타내며, 0이면 공간이 찌그러졌다는 신호다.
- 신경망 한 층의 계산 $u = Wx + b$ 는 그 자체로 선형변환 + 편향이다.

## 개념별 정리

### 행렬을 보는 3가지 관점

**1. 정의**
같은 행렬 $A$ 를 목적에 따라 세 가지로 볼 수 있습니다.
- **관점 1 (확장)**: 벡터를 2차원으로 늘린 숫자 표. 같은 형태끼리 덧셈·스칼라 곱이 가능.
- **관점 2 (함수)**: 벡터공간 $R^n$ 에서 $R^m$ 으로 보내는 함수. 곱 $AB$ 는 합성함수, 역행렬은 역함수.
- **관점 3 (변형)**: 곱셈으로 원하는 성질을 가진 행렬로 바꾸는 대상(대각화·분해 등).

**2. 왜 필요한가?**
문제에 따라 유리한 관점이 다릅니다. 데이터를 저장할 땐 관점 1(표), 변환을 설계할 땐 관점 2(함수), 알고리즘을 만들 땐 관점 3(변형)이 편합니다. 이 전환 능력이 선형대수 응용의 핵심입니다.

**3. 예시**

```python
import numpy as np

A = np.array([[1, 2, -1], [3, 2, -1]])
B = np.array([[3, 5, -7], [0, 4, 1]])
print("A + B =\n", A + B)   # 같은 형태끼리 덧셈 (관점 1)
print("3A =\n", 3 * A)      # 스칼라 곱 (관점 1)
```

실행 결과:

```
A + B =
 [[ 4  7 -8]
 [ 3  6  0]]
3A =
 [[ 3  6 -3]
 [ 9  6 -3]]
```

**4. 헷갈리기 쉬운 점**
관점 1(덧셈)은 같은 형태의 행렬끼리만 가능하지만, 관점 2(함수 합성 = 행렬 곱)는 "앞 행렬의 열 수 = 뒤 행렬의 행 수"만 맞으면 됩니다. 두 연산의 조건을 혼동하기 쉽습니다.

**5. 한 줄 정리**
행렬은 표이자 함수이자 변형 대상이며, 목적에 맞게 관점을 갈아 끼우는 것이 요령이다.

> 🍞 **비유**: 같은 지도라도 "지형 데이터"로 볼 수도, "A에서 B로 가는 경로 함수"로 볼 수도, "축척을 바꿔 다시 그리는 대상"으로 볼 수도 있습니다. 행렬도 마찬가지입니다.

### Frobenius Norm — 행렬의 크기

**1. 정의**
행렬의 모든 원소를 제곱해 더한 뒤 제곱근을 씌운 값입니다.

$$\|A\|_F = \left(\sum_{i,j} a_{ij}^2\right)^{1/2}$$

**2. 왜 필요한가?**
"두 행렬이 얼마나 다른가"를 하나의 숫자로 재는 도구입니다. 저차원 근사(SVD)에서 "원본과 근사본의 차이"를 측정하거나, 딥러닝에서 가중치 크기에 벌점을 주는 정규화에 쓰입니다.

**3. 예시**

```python
import numpy as np

A = np.array([[2., -1., 5.], [0., 2., 1.], [3., 1., 1.]])
print("원소 제곱합 =", np.sum(A**2))
print("||A||_F =", np.linalg.norm(A))   # sqrt(46)
```

실행 결과:

```
원소 제곱합 = 46.0
||A||_F = 6.782329983125268
```

$2^2 + (-1)^2 + 5^2 + \cdots + 1^2 = 46$, 그 제곱근 $\sqrt{46} \approx 6.78$ 이 행렬의 크기입니다.

**4. 헷갈리기 쉬운 점**
Frobenius Norm은 여러 행렬 노름 중 하나입니다. 나중에 나오는 특이값 기반 노름(spectral norm 등)과는 값이 다릅니다. "가장 직관적인 크기"가 Frobenius라고 기억하면 됩니다.

**5. 한 줄 정리**
Frobenius Norm은 행렬을 하나의 긴 벡터로 펴서 잰 길이다.

---

### 특수 행렬: 전치·대칭·직교

**1. 정의**
- **전치행렬** $A^\top$: 행과 열을 뒤바꾼 행렬. $(AB)^\top = B^\top A^\top$ (순서 반전 주의).
- **대칭행렬**: $A = A^\top$ 인 행렬.
- **직교행렬**: $A^\top A = I$ 를 만족하는 행렬. 즉 $A^\top = A^{-1}$.

**2. 왜 필요한가?**
대칭행렬은 공분산행렬처럼 데이터에서 자연스럽게 등장하고 항상 실수 고윳값과 직교 고유벡터를 가져 다루기 쉽습니다. 직교행렬은 회전·반사처럼 데이터의 형태를 왜곡하지 않는 변환이라 SVD·PCA의 핵심 부품이 됩니다.

**3. 예시** — 회전행렬은 직교행렬

```python
import numpy as np

theta = np.pi / 4   # 45도
R = np.array([[np.cos(theta), -np.sin(theta)],
              [np.sin(theta),  np.cos(theta)]])
print("RᵀR =\n", np.round(R.T @ R, 10))
```

실행 결과:

```
RᵀR =
 [[ 1. -0.]
 [-0.  1.]]
```

$R^\top R = I$ 이므로 회전행렬은 직교행렬입니다. 회전은 벡터의 길이를 바꾸지 않기 때문입니다.

**4. 헷갈리기 쉬운 점**
$(AB)^\top = B^\top A^\top$ 처럼 전치·역행렬은 곱의 순서가 뒤집힙니다($(AB)^{-1} = B^{-1}A^{-1}$ 도 동일). "겉옷을 나중에 입었으면 먼저 벗는다"로 기억하면 순서를 헷갈리지 않습니다.

**5. 한 줄 정리**
대칭행렬은 스스로 거울대칭, 직교행렬은 형태를 보존하는 회전·반사다.

> 🍞 **비유**: 직교행렬은 **사진을 회전만 시키는 편집**입니다. 각도는 돌아가도 인물의 비율·거리는 그대로 유지됩니다. 늘리거나 찌그러뜨리지 않습니다.

### 역행렬 (Inverse Matrix)

**1. 정의**
$AA^{-1} = A^{-1}A = I$ 를 만족하는 행렬 $A^{-1}$ 을 역행렬이라 합니다. **역함수**에 해당하며, `det(A) ≠ 0`일 때만 존재합니다.

**2. 왜 필요한가?**
연립방정식 $Ax = b$ 의 해를 $x = A^{-1}b$ 로 구하거나, 변환을 원래대로 되돌릴 때 씁니다. 최소제곱법의 정규방정식에도 등장합니다.

**3. 예시**

```python
import numpy as np

A = np.array([[3., 1., 0.], [1., 2., 1.], [-1., 2., 3.]])
A_inv = np.linalg.inv(A)
print("A @ A⁻¹ =\n", np.round(A @ A_inv, 10))
```

실행 결과:

```
A @ A⁻¹ =
 [[1. 0. 0.]
 [0. 1. 0.]
 [0. 0. 1.]]
```

$A$ 와 그 역행렬의 곱이 단위행렬이 되어 역행렬이 맞음을 확인합니다.

**4. 헷갈리기 쉬운 점**
`det = 0`인 행렬(특이행렬)은 역행렬이 없습니다. 이는 변환이 공간을 낮은 차원으로 찌그러뜨려 "정보를 잃었기" 때문에 되돌릴 수 없다는 뜻입니다. 수치적으로 `det`가 아주 작은 경우도 역행렬 계산이 불안정해집니다.

**5. 한 줄 정리**
역행렬은 변환을 되돌리는 역함수이며 `det ≠ 0`일 때만 존재한다.

---

### rank(계수)와 행렬식(determinant)

**1. 정의**
- **rank**: 행렬의 행(또는 열) 중 일차독립인 것의 최대 개수. 곧 "독립된 정보의 수".
- **행렬식(det)**: 정사각행렬에 대응하는 하나의 수. $\det A \neq 0 \iff$ 역행렬 존재.

핵심 관계식: $n = \dim N(A) + \text{rank}(A)$ (열 개수 = 영공간 차원 + rank).

**2. 왜 필요한가?**
rank는 데이터에 담긴 실질 정보량을 알려 줍니다. rank가 열 개수보다 작으면 **다중공선성**이 있다는 뜻입니다. 행렬식은 변환이 부피를 몇 배로 만드는지(부호는 방향 뒤집힘)를 나타내고, 0이면 차원이 붕괴했다는 경고입니다.

**3. 예시**

```python
import numpy as np

A = np.array([[-1., 2., -2.], [3., 4., -5.]])
print("rank(A) =", np.linalg.matrix_rank(A))

B = np.array([[2., 0., 0.], [-5., 1., 2.], [3., 8., -7.]])
print("det(B) =", round(np.linalg.det(B), 2))
print("rank(B) =", np.linalg.matrix_rank(B))
```

실행 결과:

```
rank(A) = 2
det(B) = -46.0
rank(B) = 3
```

$A$ 는 두 행이 독립이라 rank 2, $B$ 는 `det = -46 ≠ 0`이므로 세 행 모두 독립인 full rank(3)입니다.

**4. 헷갈리기 쉬운 점**
행렬식은 정사각행렬에만 정의됩니다. 직사각행렬에는 det가 없고 rank만 씁니다. 또 `det`의 부호는 "변환이 방향(뒤집힘)을 바꾸는가"를 뜻하며, 크기(절댓값)가 부피 배율입니다.

**5. 한 줄 정리**
rank는 독립 정보의 개수, 행렬식은 변환의 부피 배율(0이면 붕괴)이다.

> 🍞 **비유**: rank는 회의에서 나온 "서로 다른 진짜 의견의 수"이고, 행렬식은 반죽을 밀 때 "면적이 몇 배로 퍼졌는가"입니다. 면적이 0이 되면(det=0) 반죽이 한 줄로 눌린 것이라 원래 모양으로 못 되돌립니다.

## 코드로 보기 — 신경망의 한 층은 선형변환이다

```python
import numpy as np
np.random.seed(42)

def relu(x):    return np.maximum(0, x)
def sigmoid(x): return 1 / (1 + np.exp(-x))

# 2-레이어 신경망: R⁴ → R⁶ → R³
x  = np.array([1.0, -0.5, 0.8, -1.2])   # 입력
W1 = np.random.randn(6, 4) * 0.5         # 선형변환 R⁴→R⁶
W2 = np.random.randn(3, 6) * 0.5         # 선형변환 R⁶→R³
b1, b2 = np.zeros(6), np.zeros(3)

z1 = W1 @ x + b1;  a1 = relu(z1)         # 선형변환 + 활성화
z2 = W2 @ a1 + b2; a2 = sigmoid(z2)

print("z1 = W1x+b1:", np.round(z1, 3))
print("a1 = ReLU  :", np.round(a1, 3))
print("출력 = σ(z2):", np.round(a2, 3))
```

**코드목적**
신경망 한 층의 계산 $u = Wx + b$ 가 곧 선형변환(가중치 행렬 곱) 뒤에 편향을 더하는 과정임을 직접 보여 줍니다.

**해석**
실행 결과는 다음과 같습니다.

```
z1 = W1x+b1: [-0.372  0.113 -0.276  0.247 -0.101  1.671]
a1 = ReLU  : [0.    0.113 0.    0.247 0.    1.671]
출력 = σ(z2): [0.452 0.26  0.514]
```

입력 4차원 벡터가 $W_1$ 로 6차원으로 옮겨지고(선형변환), ReLU가 음수를 0으로 눌러 비선형성을 더합니다. 다시 $W_2$ 로 3차원으로 변환한 뒤 시그모이드로 0~1 사이 출력을 냅니다. **가중치 행렬이 곧 층 사이의 선형변환**이라는 것이 핵심입니다.

**실무 연결**
딥러닝의 모든 완전연결층은 이 구조의 반복입니다. 가중치 행렬의 rank가 낮으면 층이 표현할 수 있는 변환의 범위가 좁아지고, 직교행렬로 가중치를 초기화하면 신호 크기가 잘 보존되어 학습이 안정됩니다. 선형변환을 이해하면 이런 설계 선택의 이유가 보입니다.

**1. rank = 1**
$a^\top b = \begin{pmatrix} 2 & 4 & -2 \\ 4 & 8 & -4 \\ 6 & 12 & -6 \end{pmatrix}$ 인데, 모든 행이 $(1, 2, -1)$ 의 배수입니다. 서로 다른 방향이 하나뿐이므로 rank는 1입니다. 이는 세 변수 중 독립적인 정보가 1개뿐(강한 다중공선성)임을 뜻합니다.

import numpy as np
M = np.array([[1,2,3]]).T @ np.array([[2,4,-2]])

import numpy as np

## 헷갈리기 쉬운 포인트

- **전치·역의 곱 순서**: $(AB)^\top = B^\top A^\top$, $(AB)^{-1} = B^{-1}A^{-1}$ — 둘 다 순서 반전.
- **det가 있는 곳 vs rank가 있는 곳**: det는 정사각행렬만, rank는 모든 행렬.
- **직교행렬 $A^\top = A^{-1}$**: 전치가 곧 역행렬 — 계산이 매우 저렴해짐.
- **rank 낮음 = 정보 부족**: full rank가 아니면 다중공선성/차원 붕괴 신호.

## 셀프 체크

- [ ] 행렬을 보는 3가지 관점을 각각 설명할 수 있다.
- [ ] Frobenius Norm을 손으로 계산할 수 있다.
- [ ] 직교행렬의 정의와 "형태 보존" 성질을 안다.
- [ ] 역행렬 존재 조건(`det ≠ 0`)을 안다.
- [ ] rank가 다중공선성과 어떻게 연결되는지 설명할 수 있다.
- [ ] 신경망 층이 선형변환 + 편향임을 안다.

**복습 질문 및 답변**

*기본* — 직교행렬의 정의는?
> $A^\top A = I$ 를 만족하는 행렬. 이때 $A^\top = A^{-1}$ 이고 길이·내적·각도를 보존한다.

*이해확인* — `det(A) = 0`인 행렬의 역행렬이 없는 이유는?
> 변환이 공간을 낮은 차원으로 찌그러뜨려 정보를 잃기 때문. 여러 입력이 같은 출력으로 뭉개져 되돌릴 방법이 없다.

*응용* — 신경망 가중치 행렬의 rank가 층의 표현력에 어떤 영향을 주는가?
> rank가 낮으면 그 층이 만들 수 있는 서로 다른 출력 방향의 수가 줄어, 표현할 수 있는 변환의 범위가 좁아진다. 병목·정보 손실로 이어질 수 있다.

## 한 줄 정리

> 행렬은 "공간을 잇는 함수"이며, rank(정보량)·det(부피 배율)·직교성(형태 보존)이라는 세 지표로 그 변환의 성질을 읽을 수 있다.
