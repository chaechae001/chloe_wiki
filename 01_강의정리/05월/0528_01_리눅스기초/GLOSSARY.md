# 용어집 (Glossary)

리눅스 기초 강의에서 등장한 핵심 용어를 비전공자 눈높이로 정리했습니다.

| 용어 | 쉬운 설명 | 관련 강의명 | 함께 보면 좋은 개념 |
| --- | --- | --- | --- |
| 리눅스(Linux) | 무료로 쓰고 자유롭게 고칠 수 있는 운영체제. 서버·기기 대부분의 바탕이 됨 | 리눅스 입문 | 커널, 오픈소스, 배포판 |
| 배포판(Distribution) | 리눅스 커널을 바탕으로 만든 완성형 운영체제 묶음(우분투, CentOS 등) | 리눅스 입문 | 우분투, 데비안 계열, 레드햇 계열 |
| 우분투(Ubuntu) | 데비안 기반의 쉽고 사용자 많은 데스크탑용 리눅스 배포판 | 리눅스 입문 | 데비안, GNOME, apt |
| GUI | 아이콘·이미지를 마우스로 다루는 그래픽 인터페이스 | 리눅스 입문 | CLI, 바탕화면 |
| CLI | 문자 명령으로 컴퓨터와 상호작용하는 인터페이스(터미널) | 리눅스 입문 | GUI, 셸, 터미널 |
| 패키지 관리자 | 소프트웨어 설치·삭제·업데이트를 자동으로 처리해 주는 도구 | 리눅스 입문 | apt, yum, 의존성 |
| apt | 데비안 계열의 패키지 관리자. `apt install`처럼 사용 | 리눅스 입문 | apt-get, dpkg, sudo |
| root | 모든 권한을 가진 리눅스 최고 관리자 | 리눅스 입문 | sudo, 권한 |
| sudo | 일반 사용자가 명령 한 줄 동안 관리자 권한을 빌리는 키워드 | 리눅스 입문 | root, 권한 |
| 파일 시스템 | 저장 장치에 데이터를 저장·관리하는 약속(정책) | 파일 시스템과 권한 | 디렉토리, 트리 구조 |
| 디렉토리 | 파일과 하위 디렉토리를 묶는 이름 공간(폴더) | 파일 시스템과 권한 | 파일, 경로, 트리 구조 |
| 트리(tree) 구조 | 루트(`/`)를 정점으로 가지처럼 뻗는 계층 구조 | 파일 시스템과 권한 | 루트 디렉토리, 경로 |
| 루트 디렉토리(`/`) | 리눅스 파일 시스템의 최상위 출발점 | 파일 시스템과 권한 | 트리 구조, 경로 |
| pwd | 현재 작업 중인 경로를 출력하는 명령어 | 파일 시스템과 권한 | cd, whoami |
| ls / ls -al | 파일·폴더 목록 보기(`-al`은 숨김+상세 속성 포함) | 파일 시스템과 권한 | 파일 속성, 권한 |
| whoami | 현재 로그인한 계정 이름을 출력 | 파일 시스템과 권한 | pwd, 소유자 |
| mkdir / mkdir -p | 폴더 생성(`-p`는 중첩 폴더를 한 번에 생성) | 파일 시스템과 권한 | touch, 디렉토리 |
| touch | 비어 있는 파일을 생성하는 명령어 | 파일 시스템과 권한 | cat, mkdir |
| cat | 파일 내용을 출력하는 명령어 | 파일 시스템과 권한 | 리다이렉션, less |
| 파일 속성 | 파일의 유형·권한·소유자·크기·시간 등 정보(ls -al로 확인) | 파일 시스템과 권한 | 권한, 소유권 |
| 권한(Permission) | 읽기(4)·쓰기(2)·실행(1)을 대상별로 부여하는 통제 | 파일 시스템과 권한 | chmod, 소유권 |
| 소유권(Ownership) | 파일의 주인(소유자)과 소유 그룹 정보 | 파일 시스템과 권한 | 권한, chmod |
| chmod | 파일의 권한을 숫자(예: 777, 644)로 바꾸는 명령어 | 파일 시스템과 권한 | 권한, ls -al |
| nano | 가볍고 쉬운 터미널 텍스트 편집기 | 파일 시스템과 권한 | vi, 편집기 |
| vi | 강력하지만 모드 개념이 있는 터미널 편집기(`:q!`로 종료) | 파일 시스템과 권한 | nano, 입력 모드 |
| 표준 입출력 | 명령어의 기본 입력(키보드)과 출력(화면) 흐름 | 텍스트 흐름 다루기 | 리다이렉션, 파이프 |
| 리다이렉션 | 입출력 방향을 바꾸는 기능(`>` `>>` `<` `2>`) | 텍스트 흐름 다루기 | 파이프, 표준 입출력 |
| `>` / `>>` | 출력을 파일로 덮어쓰기(`>`) / 이어쓰기(`>>`) | 텍스트 흐름 다루기 | 리다이렉션, echo |
| 파이프(`\|`) | 앞 명령의 출력을 뒤 명령의 입력으로 잇는 기능 | 텍스트 흐름 다루기 | 리다이렉션, grep |
| grep | 특정 패턴이 든 줄만 골라 출력하는 검색 명령어 | 텍스트 흐름 다루기 | 정규표현식, 파이프 |
| 정규표현식 | 찾고 싶은 문자 패턴을 표현하는 규칙(예: `[0-9]`) | 텍스트 흐름 다루기 | grep, 패턴 매칭 |
| mount | 물리 저장 장치를 디렉토리에 연결해 쓰게 하는 작업 | 텍스트 흐름 다루기 | umount, df, PnP |
| umount | 마운트된 장치의 연결을 해제하는 명령어 | 텍스트 흐름 다루기 | mount, df |
| df | 현재 마운트된 디스크 정보를 출력 | 텍스트 흐름 다루기 | mount, 용량 |
| 프로세스(Process) | 메모리에 올라와 실행 중인 프로그램 | 프로세스와 네트워크 | PID, ps, 커널 |
| PID | 프로세스를 식별하는 고유 번호(1번=init) | 프로세스와 네트워크 | 프로세스, ps, kill |
| ps | 실행 중인 프로세스 목록·정보를 보는 명령어 | 프로세스와 네트워크 | PID, kill, 파이프 |
| job | 작업을 포그라운드/백그라운드로 실행·관리하는 개념 | 프로세스와 네트워크 | 백그라운드, kill, jobs |
| 백그라운드(`&`) | 터미널을 돌려받고 뒤에서 작업을 실행하는 방식 | 프로세스와 네트워크 | 포그라운드, jobs |
| kill | 작업 번호(`%1`) 또는 PID로 프로세스를 종료 | 프로세스와 네트워크 | job, PID, ps |
| cron / crontab | 명령을 정해진 시각에 자동·반복 실행하는 예약 도구 | 프로세스와 네트워크 | 스케줄러, 자동화 |
| ssh | 멀리 있는 컴퓨터에 암호화된 연결로 접속하는 방법 | 프로세스와 네트워크 | openssh, Telnet, 포트 |
| openssh | 우분투에서 ssh를 구동하는 패키지(client/server) | 프로세스와 네트워크 | ssh, apt, 포트 22 |
| Telnet | 데이터를 암호화하지 않는 옛 원격 접속 방식(보안 취약) | 프로세스와 네트워크 | ssh, 암호화 |
