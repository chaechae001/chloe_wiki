# 조건문 — 상황에 따라 다른 일 시키기

> "만약 ~라면 이걸 하고, 아니면 저걸 해라." 프로그램에 판단력을 부여하는 핵심 문법입니다.

`조건문` · `if` · `else` · `elif` · `들여쓰기` · `분기` · `콜론`

## 핵심요약

- 조건문은 특정 조건에 따라 실행되는 명령이 달라지는 구문이다.
- `if 조건:` 다음 줄을 들여써서 "조건이 참일 때 할 일"을 적는다.
- `if-else`는 참이면 `if` 블록, 거짓이면 `else` 블록을 실행한다.
- `if-elif-else`는 여러 조건을 순서대로 검사해 처음 참인 블록만 실행한다.
- 들여쓰기(보통 4칸)로 블록을 구분하며, `if`/`elif`/`else` 뒤엔 콜론(`:`)을 붙인다.

## 개념별 정리

### 왜 조건문이 필요한가

**1. 정의**
어떤 조건이 참인지 거짓인지에 따라 실행할 명령을 다르게 하는 구문입니다.

**2. 왜 필요한가?**
삶에는 "회원 정보가 맞으면 로그인, 틀리면 경고"처럼 조건에 따라 할 일이 갈리는 경우가 많습니다. 프로그램도 똑같이 상황을 판단해야 합니다.

**3. 예시 (개념)**
"점수가 90 이상이면 A, 아니면 다음 조건을 검사" — 갈림길에서 표지판을 보고 길을 정하는 것과 같습니다.

**4. 헷갈리기 쉬운 점**
조건문 학습의 핵심은 문법 암기보다 "**언제 조건문이 필요한지** 판단하는 능력"입니다. 조건을 먼저 한글로 적어 보고, 그 다음 코드로 옮기면 훨씬 수월합니다.

**5. 한 줄 정리**
조건문은 상황에 따라 실행 흐름을 가르는 갈림길입니다.

### if 문

**1. 정의**
조건이 참(`True`)일 때만 들여쓰기한 명령을 실행합니다.

**2. 왜 필요한가?**
"특정 조건을 만족할 때만 실행"이라는 가장 기본적인 분기를 만들 때 씁니다.

**3. 예시**

```python
i = 1
if i == 1:
    print(i)
```

실행 결과:

```
1
```

**4. 헷갈리기 쉬운 점**
`if` 뒤에는 반드시 콜론(`:`)이 오고, 실행할 명령은 같은 칸만큼 **들여써야** 합니다. 들여쓰기가 곧 "이 명령은 if에 속한다"는 표시입니다. 들여쓰기를 빼먹으면 오류가 납니다.

**5. 한 줄 정리**
`if`는 조건이 참일 때만 들여쓰기 블록을 실행합니다.

### if-else 문

**1. 정의**
조건이 참이면 `if` 블록, 거짓이면 `else` 블록을 실행합니다.

**2. 왜 필요한가?**
"맞을 때"와 "틀릴 때" 둘 다 처리해야 할 때 씁니다.

**3. 예시**

```python
i = 3
if i == 1:
    print("i는 1입니다.")
else:
    print("i는 1이 아닙니다.")   # i == 1 이 False → else 실행
```

실행 결과:

```
i는 1이 아닙니다.
```

**4. 헷갈리기 쉬운 점**
`else`에는 조건을 쓰지 않습니다. "위 조건이 거짓인 나머지 모든 경우"를 의미하기 때문입니다. `else` 뒤에도 콜론(`:`)이 필요합니다.

**5. 한 줄 정리**
`if-else`는 참이면 이쪽, 거짓이면 저쪽을 실행합니다.

### if-elif-else 문

**1. 정의**
여러 조건을 순서대로 검사해, 처음으로 참이 되는 블록 하나만 실행하고 나머지는 건너뜁니다.

**2. 왜 필요한가?**
성적 등급(A/B/C/F)처럼 갈래가 셋 이상일 때 씁니다. `elif`는 원하는 만큼 이어 붙일 수 있습니다.

**3. 예시**

```python
score = 78

if score >= 90:
    print("학점: A")
elif score >= 75:
    print("학점: B")    # 78 ≥ 75 → B 출력
elif score >= 60:
    print("학점: C")
else:
    print("학점: F")
```

실행 결과:

```
학점: B
```

**4. 헷갈리기 쉬운 점**
조건은 **위에서 아래로** 검사되며, 처음 참이 된 블록만 실행하고 멈춥니다. `78`은 `>= 90`은 거짓, `>= 75`는 참이므로 B에서 멈춥니다. 그 아래 조건들은 검사하지 않습니다. 그래서 조건의 **순서**가 중요합니다.

**5. 한 줄 정리**
`if-elif-else`는 위에서부터 검사해 처음 참인 한 갈래만 실행합니다.

## 코드로 보기 — BMI 계산기

```python
weight    = 70.0      # kg
height_cm = 175.0     # cm

height_m = height_cm / 100
bmi      = weight / (height_m ** 2)
print("BMI:", round(bmi, 2))

if bmi < 18.5:
    print("저체중입니다.")
elif bmi < 23:
    print("정상 체중입니다.")
elif bmi < 25:
    print("과체중입니다.")
else:
    print("비만입니다.")
```

실행 결과:

```
BMI: 22.86
정상 체중입니다.
```

**코드목적**
키·몸무게로 BMI를 계산하고, 그 값을 구간별 조건으로 분류합니다.

**해석**
1단계: 공식(`몸무게 / 키(m)²`)으로 BMI를 구합니다(제곱 연산 `**` 활용). 2단계: `if-elif-else`로 구간을 위에서부터 검사합니다. `22.86`은 `< 18.5` 거짓, `< 23` 참이므로 "정상 체중"에서 멈춥니다. 계산 → 분류로 이어지는 전형적인 흐름입니다.

**실무 연결**
입력값을 기준에 따라 분류·등급화하는 로직은 가격대 분류, 위험도 판정, 사용자 등급 산정 등 실무 전반에 등장합니다. 조건의 순서와 경계값(이상/미만) 설계가 정확성을 좌우합니다.

## 헷갈리기 쉬운 포인트

- **`=` vs `==`** — 조건에는 비교 연산자 `==`를 써야 한다.
- **들여쓰기** — `if`에 속한 명령은 반드시 들여쓰기로 구분.
- **`elif` vs 여러 개의 `if`** — `elif`는 앞 조건이 거짓일 때만 검사(하나만 실행), 별개의 `if`는 각각 독립적으로 검사(여러 개 실행 가능).

## 셀프 체크

- [ ] `if 조건:` + 들여쓰기로 분기를 만들 수 있다.
- [ ] `if-else`로 두 갈래를 처리할 수 있다.
- [ ] `if-elif-else`로 세 갈래 이상을 처리할 수 있다.
- [ ] 조건이 위에서부터 검사되어 처음 참에서 멈추는 것을 안다.
- [ ] 조건에는 `==`(비교)를 쓴다는 것을 안다.

**복습 질문 및 답변**

- (기본) 조건이 참일 때만 실행하는 구문은? → `if`
- (이해확인) `else` 뒤에 조건을 쓰지 않는 이유는? → "그 외 모든 경우"를 의미하기 때문.
- (응용) `score = 95`일 때 위 BMI식 대신 성적 분류 코드라면 어떤 학점이 출력될까? → A (`>= 90`이 처음으로 참)
