# 자료형의 연산 — 숫자 계산과 문자열 다루기

> 같은 `+` 기호라도 숫자에 쓰면 덧셈, 문자열에 쓰면 이어붙이기가 됩니다.

`사칙연산` · `몫` · `나머지` · `제곱` · `문자열연산` · `이어붙이기` · `반복`

## 핵심요약

- 숫자형은 `+ - * /`로 사칙연산을 한다.
- 나눗셈 `/`은 결과가 항상 실수(`float`)다. 예: `3 / 5 → 0.6`.
- 특수연산: 몫 `//`, 나머지 `%`, 제곱 `**`.
- 문자열은 `+`로 이어붙이고, `*`로 반복한다.
- 문자열과 숫자를 `+`로 직접 붙이면 오류(TypeError)가 난다. 형을 맞춰야 한다.

## 개념별 정리

### 숫자형 사칙연산

**1. 정의**
더하기 `+`, 빼기 `-`, 곱하기 `*`, 나누기 `/`로 숫자끼리 계산하는 기본 연산입니다.

**2. 왜 필요한가?**
합계, 평균, 단가 계산 등 거의 모든 데이터 처리의 기본이 됩니다.

**3. 예시**

```python
print(3 + 5)   # 8
print(3 - 5)   # -2
print(3 * 5)   # 15
print(3 / 5)   # 0.6  ← 항상 float 반환
```

실행 결과:

```
8
-2
15
0.6
```

**4. 헷갈리기 쉬운 점**
나눗셈 `/`은 나누어떨어져도 결과가 실수입니다. 예를 들어 `10 / 2`는 `5`가 아니라 `5.0`입니다. 정수끼리 나눠도 결과는 실수형이 됩니다.

**5. 한 줄 정리**
`+ - * /`로 계산하며, `/`의 결과는 항상 실수입니다.

### 특수연산: 몫, 나머지, 제곱

**1. 정의**
몫만 구하는 `//`, 나머지를 구하는 `%`, 거듭제곱을 구하는 `**`입니다.

**2. 왜 필요한가?**
"짝수/홀수 판별"(나머지), "몇 묶음으로 나뉘는지"(몫), "넓이·부피·복리 계산"(제곱) 등 실전에서 자주 쓰입니다.

**3. 예시**

```python
print(13 // 5)  # 2  (몫)
print(13 % 5)   # 3  (나머지)
print(2 ** 4)   # 16 (제곱)
```

실행 결과:

```
2
3
16
```

**4. 헷갈리기 쉬운 점**
`/`(나누기)와 `//`(몫)는 다릅니다. `13 / 5`는 `2.6`, `13 // 5`는 `2`입니다. 나머지 `%`는 "나누고 남은 값"을 의미합니다.

**5. 한 줄 정리**
`//`는 몫, `%`는 나머지, `**`는 제곱입니다.

### 문자열 연산

**1. 정의**
문자열끼리 `+`로 이어붙이고(연결), 문자열에 숫자를 `*`로 곱해 반복할 수 있습니다.

**2. 왜 필요한가?**
이름과 인사말을 합치거나, 구분선(`"-" * 20`)을 만드는 등 텍스트를 조립할 때 씁니다.

**3. 예시**

```python
print("안녕" + "하세요")  # 안녕하세요
print("안녕" * 3)         # 안녕안녕안녕
```

실행 결과:

```
안녕하세요
안녕안녕안녕
```

**4. 헷갈리기 쉬운 점**
같은 `+`라도 대상이 숫자면 덧셈, 문자열이면 이어붙이기입니다. `3 + 5`는 `8`, `"3" + "5"`는 `"35"`입니다.

**5. 한 줄 정리**
문자열에서 `+`는 이어붙이기, `*`는 반복입니다.

## 코드로 보기 — 숫자·문자열 연산 종합

```python
# 숫자형 사칙연산
print(3 + 5)   # 8
print(3 - 5)   # -2
print(3 * 5)   # 15
print(3 / 5)   # 0.6

# 특수연산
print(13 // 5) # 2
print(13 % 5)  # 3
print(2 ** 4)  # 16

# 문자열 연산
print("안녕" + "하세요")  # 안녕하세요
print("안녕" * 3)         # 안녕안녕안녕
```

실행 결과:

```
8
-2
15
0.6
2
3
16
안녕하세요
안녕안녕안녕
```

**코드목적**
숫자 연산과 문자열 연산을 한눈에 비교합니다.

**해석**
숫자는 "계산"되고, 문자열은 "조립"됩니다. 같은 기호라도 대상의 자료형에 따라 동작이 달라진다는 점이 핵심입니다.

**실무 연결**
가격 합계·할인율 계산은 숫자 연산, 메시지 문구 조립·로그 라인 생성은 문자열 연산으로 처리합니다.

## 헷갈리기 쉬운 포인트

- **`/` vs `//`** — `13 / 5`는 `2.6`(실수 나눗셈), `13 // 5`는 `2`(몫).
- **숫자 `+` vs 문자열 `+`** — `3 + 5 = 8` vs `"3" + "5" = "35"`.
- **`%`(나머지) vs `%`(서식)** — 여기서는 나머지 연산. 짝수 판별 `n % 2 == 0` 형태로 자주 쓰임.
