# 입력과 형 변환 — 사용자에게 값 받고 모양 바꾸기

> `input()`으로 받은 값은 무조건 문자열입니다. 숫자로 쓰려면 한 번 더 손질해야 합니다.

`input` · `형변환` · `타입캐스팅` · `int` · `float` · `str` · `list` · `TypeError`

## 핵심요약

- `input()`은 사용자가 입력한 값을 받아 온다.
- `input()`의 결과는 **무엇을 입력하든 항상 문자열(`str`)** 이다.
- 숫자로 계산하려면 `int()`나 `float()`로 형을 바꿔야 한다.
- 자료형을 바꾸는 것을 형 변환(Type Casting)이라 한다.
- 대표 변환: `int()`(정수), `float()`(실수), `str()`(문자열), `list()`(리스트).
- 문자열과 숫자를 섞어 연산하면 TypeError가 난다 — 형을 맞춰야 한다.

## 개념별 정리

### input()의 중요한 특징

**1. 정의**
`input()`은 사용자에게 값을 입력받아 변수에 담는 명령입니다. 안내 문구를 괄호 안에 넣을 수 있습니다.

**2. 왜 필요한가?**
프로그램이 사람과 대화하려면 값을 "받는" 통로가 필요합니다. `print()`가 출력 통로라면 `input()`은 입력 통로입니다.

**3. 예시 (개념 설명)**

```python
var = input("숫자를 입력하세요 : ")
print(var)
print(type(var))
```

가령 `10`을 입력하면 출력은 다음과 같습니다.

```
숫자를 입력하세요 : 10
10
<class 'str'>
```

**4. 헷갈리기 쉬운 점**
`10`을 입력했는데도 자료형이 `str`입니다. `input()`은 숫자처럼 보이는 입력도 전부 문자열로 받아 옵니다. 이걸 모르면 덧셈이 이상하게 동작합니다.

**5. 한 줄 정리**
`input()`의 결과는 항상 문자열입니다.

### 왜 가공이 필요한가 — 문자열 더하기 함정

**1. 정의**
문자열끼리 `+`는 덧셈이 아니라 이어붙이기이므로, 입력값을 그대로 더하면 숫자 합이 나오지 않습니다.

**2. 왜 필요한가?**
사용자가 입력한 두 숫자를 더하려면, 먼저 문자열을 숫자로 바꿔야 의도한 덧셈이 됩니다.

**3. 예시**

```python
var1 = "100"
var2 = "300"

print("문자열 더하기:", var1 + var2)            # "100300" (이어붙임!)
print("숫자로 더하기:", int(var1) + int(var2))  # 400 (덧셈)
```

실행 결과:

```
문자열 더하기: 100300
숫자로 더하기: 400
```

**4. 헷갈리기 쉬운 점**
`"100" + "300"`은 `400`이 아니라 `"100300"`입니다. 문자열에서 `+`는 글자를 이어붙이기 때문입니다. `int()`로 바꾼 뒤 더해야 `400`이 됩니다.

**5. 한 줄 정리**
입력값을 숫자로 쓰려면 `int()`나 `float()`로 형 변환을 먼저 해야 합니다.

### 형 변환 (Type Casting)

**1. 정의**
값의 자료형을 원하는 형태로 바꾸는 것입니다. `int()` `float()` `str()` `list()` 등을 사용합니다.

**2. 왜 필요한가?**
입력은 문자열로 들어오고, 계산은 숫자가 필요하고, 출력은 다시 문자열로 합치는 등 자료형을 상황에 맞게 바꿔야 할 때가 많기 때문입니다.

**3. 예시**

```python
a = "345"
b = int("345")
print("문자열 345:", a, type(a))   # <class 'str'>
print("정수  345:", b, type(b))   # <class 'int'>

c = float("3.14")
print("실수로 변환:", c, type(c))  # <class 'float'>

d = str(1000)
print("문자열로 변환:", d, type(d)) # <class 'str'>

e = list("1008")
print("리스트로 변환:", e)          # ['1', '0', '0', '8']
```

실행 결과:

```
문자열 345: 345 <class 'str'>
정수  345: 345 <class 'int'>
실수로 변환: 3.14 <class 'float'>
문자열로 변환: 1000 <class 'str'>
리스트로 변환: ['1', '0', '0', '8']
```

**4. 헷갈리기 쉬운 점**
`list("1008")`은 `[1008]`이 아니라 `['1','0','0','8']`입니다. 문자열을 리스트로 바꾸면 글자 하나하나가 원소가 됩니다. 또 `int("3.14")`처럼 소수점 문자열을 정수로 바꾸려 하면 오류가 납니다(이럴 땐 `float()`).

**5. 한 줄 정리**
형 변환은 값의 모양을 바꾸는 작업이며, 함수마다 결과 형태가 다릅니다.

### TypeError — 문자열과 숫자를 섞으면

**1. 정의**
서로 다른 자료형을 함께 연산할 수 없을 때 발생하는 오류입니다.

**2. 왜 필요한가?**
오류 메시지를 이해하면 "형을 맞춰야 한다"는 신호로 읽을 수 있습니다. 에러는 잘못이 아니라 정상적인 학습 과정입니다.

**3. 예시**

```python
age_num = 20
# print("나이: " + age_num)   # ← TypeError! 문자열 + 숫자
print("나이: " + str(age_num))           # str() 변환 후 이어붙이기
```

실행 결과:

```
나이: 20
```

**4. 헷갈리기 쉬운 점**
`"나이: " + 20`은 오류입니다. 문자열에 숫자를 직접 붙일 수 없기 때문입니다. 숫자를 `str()`로 바꿔야 합니다. (반대로 콤마로 출력하면 `print("나이:", 20)`처럼 자료형이 달라도 괜찮습니다.)

**5. 한 줄 정리**
형이 안 맞아 생긴 TypeError는 형 변환으로 해결합니다.

## 코드로 보기 — 입력값 덧셈 문제 해결

```python
var1 = "100"
var2 = "300"

print("문자열 더하기:", var1 + var2)            # 100300
print("숫자로 더하기:", int(var1) + int(var2))  # 400
```

실행 결과:

```
문자열 더하기: 100300
숫자로 더하기: 400
```

**코드목적**
입력값이 문자열이라 생기는 "엉뚱한 덧셈"을 형 변환으로 바로잡습니다.

**해석**
1단계: 두 값이 문자열이라 `+`가 이어붙이기로 동작 → `"100300"`. 2단계: `int()`로 숫자로 바꾸니 진짜 덧셈 → `400`. "받은 값의 자료형을 확인하고, 필요하면 변환한다"는 흐름이 핵심입니다.

**실무 연결**
설문 응답, 주문 수량, 결제 금액 등 사용자가 입력한 값을 계산에 쓰기 전에는 거의 항상 형 변환이 필요합니다. 형을 확인하지 않은 입력은 가장 흔한 버그의 원인입니다.

## 헷갈리기 쉬운 포인트

- **`list("ab")` vs `[ "ab" ]`** — `['a','b']` vs `['ab']`.

## 셀프 체크

- [ ] `input()`의 결과가 항상 문자열임을 안다.
- [ ] `int()` `float()` `str()` `list()`로 형을 바꿀 수 있다.
- [ ] 문자열 덧셈과 숫자 덧셈의 차이를 안다.
- [ ] TypeError가 형 불일치 신호임을 안다.
- [ ] `list("문자열")`이 글자 단위로 쪼개지는 것을 안다.

**복습 질문 및 답변**

- (기본) `input()`이 돌려주는 값의 자료형은? → 문자열(`str`)
- (이해확인) `"5" + "5"`의 결과는? → `"55"` (이어붙이기)
- (응용) 입력받은 두 숫자를 더하려면 무엇이 필요한가? → `int()`(또는 `float()`)로 형 변환
