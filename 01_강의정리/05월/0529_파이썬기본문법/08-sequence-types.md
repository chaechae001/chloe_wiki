# 시퀀스 자료형 — 문자열과 리스트의 공통 능력

> 문자열과 리스트는 겉모습이 달라도 "순서가 있는 자료"라는 공통점 덕분에 같은 기능을 많이 공유합니다.

`시퀀스` · `in연산자` · `len` · `이어붙이기` · `반복` · `str` · `list` · `AttributeError`

## 핵심요약

- 시퀀스 자료형은 순서가 있는 자료형이다. 문자열(`str`)과 리스트(`list`)가 대표적이다.
- 순서가 있어 인덱싱·슬라이싱이 가능하다.
- `in`으로 원소가 들어 있는지 확인한다.
- `len()`으로 길이(원소 개수)를 구한다.
- `+`로 같은 종류끼리 이어붙이고, `*`로 반복한다.
- 종류마다 차이도 있다. 리스트는 `append` 가능하지만 문자열은 불가능하다.

## 개념별 정리

### 시퀀스 자료형이란

**1. 정의**
원소들이 순서대로 나열된 자료형입니다. 순서가 있기 때문에 위치 기반 접근(인덱싱·슬라이싱)이 가능합니다.

**2. 왜 필요한가?**
문자열과 리스트를 따로 외우지 않고 "공통 규칙"으로 이해하면 학습량이 크게 줄어듭니다.

**3. 예시**

```python
a = "Hello"
b = ["e", "l", "i", "c", "e"]

print(a[1])      # e   (인덱싱)
print(b[2:4])    # ['i', 'c']  (슬라이싱)
```

실행 결과:

```
e
['i', 'c']
```

**4. 헷갈리기 쉬운 점**
"순서가 있다"는 곧 "위치 번호가 있다"는 뜻입니다. 그래서 문자열도 리스트처럼 `[1]`, `[2:4]` 같은 접근이 가능합니다.

**5. 한 줄 정리**
시퀀스 자료형은 순서가 있어 위치로 접근할 수 있는 자료형입니다.

### in 연산자

**1. 정의**
어떤 원소가 시퀀스 안에 들어 있는지 확인해 `True`/`False`로 답하는 연산자입니다.

**2. 왜 필요한가?**
"이 메뉴에 비빔밥이 있나?", "이 문장에 특정 글자가 있나?"를 판단할 때 씁니다.

**3. 예시**

```python
a = "Hello"
b = ["e", "l", "i", "c", "e"]

print("e" in a)     # True
print("E" in b)     # False (대소문자 구분)
print("z" not in a) # True
```

실행 결과:

```
True
False
True
```

**4. 헷갈리기 쉬운 점**
`in`은 대소문자를 구분합니다. `"E"`와 `"e"`는 다른 글자로 취급됩니다. `not in`을 쓰면 "없는지"를 확인할 수 있습니다.

**5. 한 줄 정리**
`in`은 원소의 포함 여부를 참/거짓으로 알려 줍니다.

### len() — 길이 구하기

**1. 정의**
시퀀스의 원소 개수(문자열은 글자 수)를 돌려주는 함수입니다.

**2. 왜 필요한가?**
"몇 개인지", "몇 글자인지"를 세는 일은 매우 자주 필요합니다. 반복 횟수를 정할 때도 쓰입니다.

**3. 예시**

```python
print(len("Hello World"))         # 11 (공백 포함)
print(len(["e","l","i","c","e"])) # 5
```

실행 결과:

```
11
5
```

**4. 헷갈리기 쉬운 점**
문자열 길이에는 공백도 한 글자로 포함됩니다. `"Hello World"`는 공백 1칸까지 합쳐 11입니다.

**5. 한 줄 정리**
`len()`은 시퀀스의 길이를 알려 줍니다.

### + 이어붙이기 / * 반복

**1. 정의**
같은 종류의 시퀀스를 `+`로 이어 붙이고, `*`와 숫자로 반복합니다.

**2. 왜 필요한가?**
두 목록을 합치거나, 같은 패턴을 여러 번 만들 때 씁니다.

**3. 예시**

```python
print("Good" + "Day")            # GoodDay
print(["H","e"] + ["l","l","o"]) # ['H','e','l','l','o']

print("Go!!" * 5)                # Go!!Go!!Go!!Go!!Go!!
print([13, 17, 19] * 3)          # [13,17,19,13,17,19,13,17,19]
```

실행 결과:

```
GoodDay
['H', 'e', 'l', 'l', 'o']
Go!!Go!!Go!!Go!!Go!!
[13, 17, 19, 13, 17, 19, 13, 17, 19]
```

**4. 헷갈리기 쉬운 점**
`+`는 같은 종류끼리만 됩니다. 문자열 + 리스트는 오류입니다. `*`는 시퀀스와 숫자를 함께 써야 합니다.

**5. 한 줄 정리**
`+`는 같은 종류 이어붙이기, `*`는 반복입니다.

### 종류별 차이 — AttributeError

**1. 정의**
공통 기능이 많지만, 자료형마다 고유한 기능도 있습니다. 없는 기능을 호출하면 AttributeError가 납니다.

**2. 왜 필요한가?**
"리스트엔 되는데 문자열엔 안 되는" 경우를 미리 알면 오류를 예방할 수 있습니다.

**3. 예시**

```python
my_list = ['P','y','t','h','o','n']
my_list.append('!')          # 리스트는 append 가능
print(my_list)               # ['P','y','t','h','o','n','!']

# my_str = "Python"
# my_str.append('!')         # ← 문자열엔 append 없음 → AttributeError
```

실행 결과:

```
['P', 'y', 't', 'h', 'o', 'n', '!']
```

**4. 헷갈리기 쉬운 점**
`AttributeError`는 "이 자료형에는 그런 기능(메서드)이 없다"는 신호입니다. 문자열에 `append`를 쓰거나, `append`를 `Append`(대문자)로 잘못 쓰면 같은 오류가 납니다. 사용하려는 자료형이 그 기능을 지원하는지 공식 문서로 확인하는 습관이 중요합니다.

**5. 한 줄 정리**
공통 기능은 많지만, 자료형 고유 기능은 다르므로 지원 여부를 확인해야 합니다.

## 코드로 보기 — str과 list 공통점과 차이점

```python
my_str  = "Python"
my_list = ['P','y','t','h','o','n']

print("문자열 첫 글자:", my_str[0])
print("리스트 첫 원소:", my_list[0])
print("문자열 길이:", len(my_str))
print("'y' in 문자열:", "y" in my_str)
print("'y' in 리스트:", "y" in my_list)

my_list.append('!')
print("리스트에 ! 추가:", my_list)
# my_str.append('!')  ← AttributeError 발생!
```

실행 결과:

```
문자열 첫 글자: P
리스트 첫 원소: P
문자열 길이: 6
'y' in 문자열: True
'y' in 리스트: True
리스트에 ! 추가: ['P', 'y', 't', 'h', 'o', 'n', '!']
```

**코드목적**
같은 데이터를 문자열과 리스트로 두고, 공통 기능(`[]`, `len`, `in`)은 동일하게, 고유 기능(`append`)은 차이 나게 동작함을 보여줍니다.

**해석**
인덱싱·길이·포함 확인은 두 자료형에서 똑같이 작동합니다. 그러나 원소 추가(`append`)는 리스트만 가능합니다. "공통 능력 + 고유 능력"이라는 구조를 이해하면 새로운 자료형도 빠르게 익힐 수 있습니다.

**실무 연결**
텍스트 검색(`in`), 데이터 개수 집계(`len`), 목록 합치기(`+`)는 데이터 처리에서 매일 쓰입니다. 자료형별 지원 기능을 정확히 아는 것이 오류 없는 코드의 바탕이 됩니다.
