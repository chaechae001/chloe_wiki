# 변수 — 값을 담는 그릇에 이름 붙이기

> 매번 값을 직접 쓰는 대신, 이름을 붙여 보관하면 코드가 훨씬 읽기 쉬워집니다.

`변수` · `네이밍` · `스네이크표기법` · `카멜표기법` · `덮어쓰기` · `예약어`

## 핵심요약

- 변수는 값을 담아 두고 이름으로 꺼내 쓰는 "그릇"이다.
- 선언 방법은 `변수명 = 값`. `=`는 "같다"가 아니라 "담는다"는 의미다.
- 변수 이름은 의미가 드러나게 짓는 것이 중요하다.
- 같은 변수에 새 값을 넣으면 기존 값은 덮어써진다.
- 대표 표기법: 스네이크(`prod_name`), 카멜(`prodName`). 파이썬은 스네이크를 권장한다.
- 이름 규칙: 숫자로 시작 금지, 숫자만으로 구성 금지, 예약어 금지, 공백·연산자 금지.

## 개념별 정리

### 변수란 무엇인가

**1. 정의**
변수(Variable)는 값을 담아 두는 그릇이고, 그 그릇에 붙인 이름입니다. 이름으로 언제든 값을 꺼내 쓸 수 있습니다.

**2. 왜 필요한가?**
같은 값을 여러 번 써야 할 때, 값에 의미 있는 이름을 붙여 두면 코드를 읽기 쉽고 고치기 쉽습니다. 값이 바뀌어도 한 곳만 고치면 됩니다.

**3. 예시**

```python
num   = 10
name  = "Michael"
grade = ['A+', 'B+', 'A0']

print(num)    # 10
print(name)   # Michael
print(grade)  # ['A+', 'B+', 'A0']
```

실행 결과:

```
10
Michael
['A+', 'B+', 'A0']
```

**4. 헷갈리기 쉬운 점**
`=`는 수학의 "같다"가 아니라 "오른쪽 값을 왼쪽 그릇에 담는다"는 뜻입니다. "같다"를 비교할 때는 `==`를 씁니다([논리형과 비교 연산](09-boolean-comparison.md) 참고).

**5. 한 줄 정리**
변수는 "값에 붙인 이름표가 달린 그릇"입니다. (비유: 내용물을 적어 둔 택배 상자)

### 변수 이름 짓는 법

**1. 정의**
변수 이름에는 알파벳, 숫자, 한글, 언더바(`_`) 등을 사용할 수 있습니다.

**2. 왜 필요한가?**
이름이 곧 설명이기 때문입니다. `a`, `b`보다 `num`, `name`, `grade_list`처럼 의미가 드러나면 코드를 읽는 사람이 바로 이해합니다.

**3. 예시**

```python
python = "파이썬"     # 알파벳 (권장)
파이썬 = "Python"      # 한글도 가능
carrot_123 = 1234     # 알파벳 + 언더바 + 숫자

print(python)
print(파이썬)
print(carrot_123)
```

실행 결과:

```
파이썬
Python
1234
```

**4. 헷갈리기 쉬운 점**
한글 변수명도 동작하지만, 협업과 호환성을 위해 영문 사용이 권장됩니다. 의미가 모호한 `a`, `b`, `c`는 코드가 길어질수록 무엇을 담았는지 추적하기 어려워집니다.

**5. 한 줄 정리**
좋은 변수 이름은 그 자체가 설명이 되도록 의미를 담습니다.

### 표기법: 스네이크 vs 카멜

**1. 정의**
여러 단어로 된 변수 이름을 쓰는 두 가지 대표 방식입니다. 스네이크는 단어를 `_`로 잇고(`prod_name`), 카멜은 두 번째 단어부터 첫 글자를 대문자로(`prodName`) 씁니다.

**2. 왜 필요한가?**
변수명에는 공백을 쓸 수 없어서, 여러 단어를 붙일 때 구분이 필요합니다. 일관된 표기법은 코드를 읽기 쉽게 만듭니다.

**3. 예시**

```python
# 스네이크 표기법 (파이썬 권장)
prod_name = "milk"
prod_date = "2024-10-08"
print(prod_name, prod_date)
```

실행 결과:

```
milk 2024-10-08
```

**4. 헷갈리기 쉬운 점**
두 표기법 모두 문법적으로는 동작합니다. 다만 파이썬 커뮤니티는 스네이크 표기법을 표준으로 권장하므로, 처음부터 스네이크에 익숙해지는 것이 좋습니다.

**5. 한 줄 정리**
파이썬에서는 여러 단어 변수명을 `under_bar`로 잇는 스네이크 표기법을 권장합니다.

### 변수 덮어쓰기 (재정의)

**1. 정의**
이미 값이 든 변수에 새 값을 대입하면, 기존 값은 사라지고 새 값으로 덮어써집니다.

**2. 왜 필요한가?**
프로그램이 진행되며 값이 바뀌는 경우(점수 갱신, 잔액 변경 등)가 많기 때문입니다.

**3. 예시**

```python
score = 50
print("처음 점수:", score)

score = 100          # 덮어쓰기
print("바뀐 점수:", score)
```

실행 결과:

```
처음 점수: 50
바뀐 점수: 100
```

**4. 헷갈리기 쉬운 점**
편리한 만큼 위험하기도 합니다. 중요한 값을 실수로 덮어쓰면 추적이 어려운 오류가 생깁니다. 그래서 `a`, `b` 같은 모호한 이름은 덮어쓰기 사고의 원인이 되기 쉽습니다.

**5. 한 줄 정리**
변수에 새 값을 넣으면 옛 값은 덮어써집니다.

## 코드로 보기 — 나만의 정보 저장하기

```python
my_name   = "홍길동"
my_age    = 20
my_hobby  = "코딩"
my_scores = [90, 85, 100]

print("이름:", my_name)
print("나이:", my_age)
print("취미:", my_hobby)
print("점수:", my_scores)
```

실행 결과:

```
이름: 홍길동
나이: 20
취미: 코딩
점수: [90, 85, 100]
```

**코드목적**
서로 다른 자료형(문자열, 정수, 리스트)을 의미 있는 이름의 변수에 담아 관리합니다.

**해석**
값마다 이름을 붙여 두니, 뒤에서 `my_name`만 적어도 "홍길동"을 꺼낼 수 있습니다. 정보가 늘어나도 이름으로 구분하므로 헷갈리지 않습니다.

**실무 연결**
사용자 정보, 설정 값, 중간 계산 결과 등 거의 모든 프로그램은 변수로 상태를 관리합니다. 의미 있는 변수명은 협업 시 코드 리뷰 속도를 크게 높입니다.

## 헷갈리기 쉬운 포인트

- **`=` vs `==`** — `=`는 값을 담기(대입), `==`는 같은지 비교.
- **스네이크 vs 카멜** — `prod_name`(파이썬 권장) vs `prodName`.
- **숫자로 시작하는 이름** — `1name`은 불가, `name1`은 가능.

## 셀프 체크

- [ ] `변수명 = 값`으로 변수를 선언할 수 있다.
- [ ] `=`와 `==`의 차이를 안다.
- [ ] 의미 있는 변수 이름을 지을 수 있다.
- [ ] 스네이크 표기법을 사용할 수 있다.
- [ ] 변수에 새 값을 넣으면 덮어써지는 것을 안다.

**복습 질문 및 답변**

- (기본) 값을 그릇에 담아 이름으로 부르는 것을 무엇이라 하나? → 변수
- (이해확인) `1name = "Coke"`가 오류인 이유는? → 변수 이름은 숫자로 시작할 수 없다.
- (응용) `x = 5` 다음 줄에 `x = 8`을 쓰고 `print(x)`하면? → `8` (덮어써짐)

## 한 줄 정리

> 변수는 값에 의미 있는 이름을 붙여 보관하는 그릇이며, 좋은 이름이 곧 좋은 코드의 시작입니다.
