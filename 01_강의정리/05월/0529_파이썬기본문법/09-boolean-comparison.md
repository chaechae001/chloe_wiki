# 논리형과 비교·논리 연산 — 참인가 거짓인가

> 컴퓨터의 모든 판단은 결국 "참이냐 거짓이냐"로 귀결됩니다. 조건문을 배우기 전 꼭 익혀야 할 토대입니다.

`논리형` · `bool` · `비교연산자` · `논리연산자` · `and` · `or` · `not` · `True` · `False`

## 핵심요약

- 논리형(`bool`)은 참(`True`)과 거짓(`False`) 두 값만 갖는다.
- 비교 연산자(`==` `!=` `<` `>` `<=` `>=`)의 결과는 논리형이다.
- `and`는 모두 참이어야 참이다.
- `or`는 하나라도 참이면 참이다.
- `not`은 논리값을 뒤집는다.
- 복잡한 조건을 논리 연산자로 묶어 한 문장으로 단순화할 수 있다.

## 개념별 정리

### 논리 자료형 (Boolean)

**1. 정의**
참(`True`)과 거짓(`False`)만 존재하는 자료형입니다.

**2. 왜 필요한가?**
"조건이 맞는가?"라는 질문의 답이 곧 참/거짓입니다. 모든 조건 판단의 결과가 논리형입니다.

**3. 예시**

```python
print(True)
print(False)
```

실행 결과:

```
True
False
```

**4. 헷갈리기 쉬운 점**
`True`/`False`는 첫 글자가 대문자이고 따옴표가 없습니다. `"True"`는 문자열, `true`는 오류입니다.

**5. 한 줄 정리**
논리형은 참·거짓 두 값만 갖는 자료형입니다.

### 비교 연산자

**1. 정의**
두 값을 비교해 참/거짓을 돌려주는 연산자입니다.

| 연산자 | 의미 | 예시 | 결과 |
| --- | --- | --- | --- |
| `==` | 같다 | `3 == 3` | `True` |
| `!=` | 다르다 | `3 != 5` | `True` |
| `>` | 왼쪽이 크다 | `3 > 5` | `False` |
| `<` | 오른쪽이 크다 | `3 < 5` | `True` |
| `>=` | 왼쪽이 크거나 같다 | `3 >= 5` | `False` |
| `<=` | 오른쪽이 크거나 같다 | `3 <= 5` | `True` |

**2. 왜 필요한가?**
"점수가 합격선 이상인가?", "입력값이 정답과 같은가?"처럼 값을 견주어 판단할 때 씁니다.

**3. 예시**

```python
print(3 < 5)    # True
print(7 == 5)   # False
print(2 >= 10)  # False
print(5 != 10)  # True
```

실행 결과:

```
True
False
False
True
```

**4. 헷갈리기 쉬운 점**
값을 비교하는 "같다"는 `==`(등호 두 개)입니다. 등호 하나 `=`는 값을 담는 대입입니다. 둘을 혼동하면 의도와 다른 결과가 나옵니다.

**5. 한 줄 정리**
비교 연산자는 두 값을 견주어 참/거짓을 돌려줍니다.

### and / or / not

**1. 정의**
여러 조건을 묶는 논리 연산자입니다. `and`(그리고), `or`(또는), `not`(반대)입니다.

**2. 왜 필요한가?**
"5보다 크고 9보다 작은가?"처럼 두 개 이상의 조건을 하나로 결합할 때 씁니다.

**3. 예시**

```python
# and: 모두 True여야 True
print(3==3 and 4<=5 and 6>2)   # True

# or: 하나라도 True면 True
print(3==4 or 4<=5 or 6<2)     # True

# not: 논리값 반전
print(not 3==4)   # True   (False → True)
```

실행 결과:

```
True
True
True
```

**4. 헷갈리기 쉬운 점**
- `and`는 하나라도 거짓이면 전체가 거짓입니다.
- `or`는 하나라도 참이면 전체가 참입니다.
- `not`은 `True`를 `False`로, `False`를 `True`로 뒤집습니다. `not 3==4`는 `3==4`(거짓)를 뒤집어 참이 됩니다.

**5. 한 줄 정리**
`and`는 모두 참, `or`는 하나라도 참, `not`은 반전입니다.

## 코드로 보기 — 실생활 조건을 논리식으로

```python
age        = 25
height     = 170
has_ticket = True

can_ride    = age >= 18 and height >= 150 and has_ticket
is_student  = False
is_senior   = False
get_discount = is_student or is_senior
is_closed   = False
is_open     = not is_closed

print("롤러코스터 탑승 가능?", can_ride)
print("할인 적용 가능?", get_discount)
print("가게 열려있나요?", is_open)
```

실행 결과:

```
롤러코스터 탑승 가능? True
할인 적용 가능? False
가게 열려있나요? True
```

**코드목적**
실생활 규칙("18세 이상 + 키 150 이상 + 티켓 보유")을 논리 연산자로 한 문장에 담습니다.

**해석**
- 탑승: 세 조건이 모두 참이라 `and` 결과가 참.
- 할인: 학생도 경로도 아니라 `or` 결과가 거짓.
- 영업: "닫혀 있지 않다"를 `not`으로 뒤집어 "열려 있다"가 참.

여러 조건을 사람의 말처럼 묶어 한눈에 읽히는 코드가 됩니다.

**실무 연결**
회원 자격 검증, 권한 확인, 필터 조건 등 거의 모든 분기 로직이 비교·논리 연산으로 표현됩니다. 조건을 한글로 먼저 적어 보고 논리 연산자로 옮기면 실수를 줄일 수 있습니다.

## 헷갈리기 쉬운 포인트

- **`=` vs `==`** — 대입 vs 비교(같다).
- **`and` vs `or`** — 모두 참이어야 vs 하나라도 참이면.
- **`not`의 적용 범위** — `not 3==4`는 `3==4`를 먼저 판단한 뒤 뒤집음.
