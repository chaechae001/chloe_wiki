# 기본 자료형 — 숫자, 문자열, 리스트, 논리형

> 컴퓨터가 다루는 값에는 "종류"가 있습니다. 종류를 알면 그 값으로 무엇을 할 수 있는지가 보입니다.

`자료형` · `int` · `float` · `str` · `list` · `bool` · `type` · `주석`

## 핵심요약

- 자료형이란 값의 "종류"다. 숫자, 글자, 여러 값의 묶음 등으로 나뉜다.
- 숫자형은 정수 `int`와 실수 `float`로 나뉜다.
- 문자열 `str`은 따옴표로 감싼 텍스트다.
- 리스트 `list`는 `[]` 안에 여러 값을 순서대로 담는다. 다른 종류를 섞어도 된다.
- 논리형 `bool`은 참(`True`)과 거짓(`False`) 두 값만 갖는다.
- `type()`으로 값이 어떤 자료형인지 확인할 수 있다.
- 주석(`#`, `"""..."""`)은 컴퓨터가 무시하는 메모다.

## 개념별 정리

### 숫자형 (Number)

**1. 정의**
숫자로 이루어진 자료형입니다. 소수점이 없으면 정수(`int`), 있으면 실수(`float`)입니다.

**2. 왜 필요한가?**
가격, 나이, 점수, 좌표 등 세상의 수많은 데이터가 숫자입니다. 숫자형끼리는 더하고 빼고 곱하는 계산이 가능합니다.

**3. 예시**

```python
print(type(3))      # <class 'int'>   정수
print(type(3.14))   # <class 'float'> 실수
```

실행 결과:

```
<class 'int'>
<class 'float'>
```

**4. 헷갈리기 쉬운 점**
`3`과 `3.0`은 사람 눈에는 같지만 컴퓨터에게는 다른 자료형(`int` vs `float`)입니다. 또 `"3"`처럼 따옴표로 감싸면 숫자가 아니라 문자열이 됩니다.

**5. 한 줄 정리**
숫자형은 계산할 수 있는 값이며, 정수와 실수로 나뉩니다.

### 문자열 (String)

**1. 정의**
문자들을 늘어놓은 자료형입니다. 작은따옴표(`' '`) 또는 큰따옴표(`" "`)로 감쌉니다.

**2. 왜 필요한가?**
이름, 메시지, 주소처럼 "글자로 된 정보"를 다룰 때 씁니다.

**3. 예시**

```python
print(type("Hello"))  # <class 'str'>
print('작은따옴표도 OK')
print("큰따옴표도 OK")
```

실행 결과:

```
<class 'str'>
작은따옴표도 OK
큰따옴표도 OK
```

**4. 헷갈리기 쉬운 점**
`"3.14"`는 숫자처럼 보여도 따옴표가 있으므로 문자열입니다. 문자열은 계산이 아니라 이어붙이기·반복만 가능합니다(자세히는 [자료형의 연산](04-operators.md)에서).

**5. 한 줄 정리**
문자열은 따옴표로 감싼 "글자 데이터"입니다.

### 리스트 (List)

**1. 정의**
`[]` 안에 여러 값을 순서대로 담는 자료형입니다. 서로 다른 종류의 값을 함께 담을 수도 있습니다.

**2. 왜 필요한가?**
점수 5개, 학생 명단처럼 "여러 값을 하나의 묶음"으로 관리할 때 씁니다. 값마다 변수를 따로 만들지 않아도 됩니다.

**3. 예시**

```python
print([])                    # 빈 리스트
print(['a', 'b', 'c'])       # 문자열 리스트
print(['a', 2, 3.14, True])  # 혼합 리스트
print(type([1, 2, 3]))       # <class 'list'>
```

실행 결과:

```
[]
['a', 'b', 'c']
['a', 2, 3.14, True]
<class 'list'>
```

**4. 헷갈리기 쉬운 점**
리스트는 순서가 있어서 `[1, 2, 3]`과 `[3, 2, 1]`은 **다른 리스트**입니다. 값의 종류가 같아도 배치 순서가 다르면 다른 데이터입니다.

**5. 한 줄 정리**
리스트는 여러 값을 순서대로 모아 담는 그릇입니다. (비유: 칸이 나뉜 서랍장)

### 논리형 (Boolean)

**1. 정의**
참(`True`)과 거짓(`False`) 두 가지 값만 갖는 자료형입니다. 첫 글자는 반드시 대문자입니다.

**2. 왜 필요한가?**
"조건이 맞나, 안 맞나?"를 판단하는 모든 곳에서 쓰입니다. 조건문([조건문](10-conditionals.md))의 기초가 됩니다.

**3. 예시**

```python
print(type(True))  # <class 'bool'>
```

실행 결과:

```
<class 'bool'>
```

**4. 헷갈리기 쉬운 점**
`True`, `False`는 따옴표 없이, 첫 글자 대문자로 써야 합니다. `"True"`는 문자열이고, `true`(소문자)는 오류입니다.

**5. 한 줄 정리**
논리형은 "예/아니오"를 나타내는 참·거짓 값입니다.

### 주석 (Comment)

**1. 정의**
컴퓨터가 실행하지 않고 무시하는 메모입니다. 한 줄은 `#`, 여러 줄은 따옴표 세 개(`"""..."""`)로 감쌉니다.

**2. 왜 필요한가?**
코드가 "무엇을 하는지" 사람에게 설명을 남기기 위해서입니다. 나중에 다시 봐도, 동료가 봐도 이해하기 쉬워집니다.

**3. 예시**

```python
# 이 줄은 설명용 메모입니다 (실행 안 됨)
print("실행되는 코드")
"""
여러 줄에 걸친
설명도 가능합니다
"""
```

**4. 헷갈리기 쉬운 점**
주석은 컴퓨터가 무시하지만, 사람에게는 매우 중요한 정보입니다. "무엇을"보다 "왜 이렇게 했는지"를 적으면 더 좋습니다.

**5. 한 줄 정리**
주석은 컴퓨터는 건너뛰고 사람만 읽는 설명입니다.

## 코드로 보기 — type()으로 자료형 확인

```python
print(type(42))        # <class 'int'>
print(type(3.14))      # <class 'float'>
print(type("Python"))  # <class 'str'>
print(type([1, 2, 3])) # <class 'list'>
print(type(True))      # <class 'bool'>
```

실행 결과:

```
<class 'int'>
<class 'float'>
<class 'str'>
<class 'list'>
<class 'bool'>
```

**코드목적**
같은 `print()` 안에 서로 다른 값을 넣고 `type()`으로 각각의 자료형을 확인합니다.

**해석**
`<class 'int'>`는 "이 값은 정수다"라는 뜻입니다. 값의 종류를 알면 그 값으로 어떤 연산이 가능한지 예측할 수 있습니다. 예를 들어 `str`끼리는 `+`로 이어붙이지만, `int`끼리는 `+`로 더해집니다.

**실무 연결**
데이터를 다루다 보면 "이 값이 숫자인 줄 알았는데 사실 문자열이었다"는 함정이 자주 생깁니다. `type()`은 그 함정을 찾는 가장 빠른 점검 도구입니다.

## 헷갈리기 쉬운 포인트

- **`int` vs `float`** — 소수점 유무. `3`은 정수, `3.0`은 실수.
- **`3` vs `"3"`** — 따옴표 유무. 앞은 숫자, 뒤는 문자열.
- **`True` vs `"True"`** — 따옴표 유무. 앞은 논리형, 뒤는 문자열.

## 셀프 체크

- [ ] 정수·실수·문자열·리스트·논리형을 구분할 수 있다.
- [ ] `type()`으로 자료형을 확인할 수 있다.

- (응용) `type(3.0)`의 결과는? → `<class 'float'>` (소수점이 있으므로 실수)
