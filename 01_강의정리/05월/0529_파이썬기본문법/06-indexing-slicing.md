# 인덱싱과 슬라이싱 — 원하는 위치·범위만 꺼내기

> 문자열과 리스트는 칸마다 번호가 매겨져 있습니다. 그 번호로 원하는 부분만 콕 집어 꺼낼 수 있습니다.

`인덱스` · `인덱싱` · `슬라이싱` · `음수인덱스` · `0부터시작` · `중첩리스트`

## 핵심요약

- 인덱스는 원소의 위치 번호이며, **0부터** 시작한다.
- 인덱싱 `자료[i]`는 특정 위치의 원소 하나를 꺼낸다.
- 음수 인덱스는 뒤에서부터 센다. `-1`이 마지막 원소다.
- 슬라이싱 `자료[시작:끝]`은 시작 이상, 끝 **미만** 범위를 꺼낸다.
- 시작이나 끝을 비우면 각각 처음부터/끝까지가 된다.
- 리스트 안에 리스트가 있으면 `자료[i][j]`로 두 번 접근한다.

## 개념별 정리

### 인덱스 (index)

**1. 정의**
문자열과 리스트의 각 원소에 매겨진 위치 번호입니다. 맨 앞이 0번입니다.

**2. 왜 필요한가?**
"세 번째 값"처럼 특정 위치의 데이터를 꺼내려면 위치를 가리키는 번호가 필요합니다.

**3. 예시**

```
"Ready"  →  R  e  a  d  y
인덱스   →  0  1  2  3  4   (양수)
            -5 -4 -3 -2 -1  (음수)
```

문자열에서는 공백 문자도 한 칸을 차지해 인덱스에 포함됩니다.

**4. 헷갈리기 쉬운 점**
사람은 보통 1부터 세지만 프로그래밍은 0부터 셉니다. 그래서 "첫 번째"는 인덱스 `0`, "다섯 번째"는 인덱스 `4`입니다.

**5. 한 줄 정리**
인덱스는 0부터 시작하는 위치 번호입니다.

### 인덱싱 (Indexing)

**1. 정의**
`자료[인덱스]` 형태로 특정 위치의 원소 하나를 꺼내는 방법입니다.

**2. 왜 필요한가?**
리스트에서 특정 학생의 점수, 문자열에서 특정 글자처럼 한 개의 값을 정확히 지목할 때 씁니다.

**3. 예시**

```python
word    = "Ready"
numbers = [2, 4, 6, 8, 10]

print(word[0])      # R   — 첫 번째
print(word[-1])     # y   — 뒤에서 첫 번째
print(numbers[2])   # 6
print(numbers[-1])  # 10
```

실행 결과:

```
R
y
6
10
```

**4. 헷갈리기 쉬운 점**
음수 인덱스를 활용하면 길이를 몰라도 마지막 원소를 `[-1]`로 바로 꺼낼 수 있습니다. `[-1]`은 "끝에서 한 칸"이라고 기억하면 쉽습니다.

**5. 한 줄 정리**
인덱싱은 위치 번호로 원소 하나를 꺼내는 것입니다.

### 슬라이싱 (Slicing)

**1. 정의**
`자료[시작:끝]` 형태로 일정 범위의 원소들을 잘라 가져오는 방법입니다.

**2. 왜 필요한가?**
"앞 3개", "중간 부분", "특정 구간"처럼 여러 원소를 한 번에 꺼낼 때 씁니다.

**3. 예시**

```python
beta = [2, 4, 6, 8, 10, 12, 14]

print(beta[2:5])    # [6, 8, 10]      인덱스 2 이상 5 미만
print(beta[:3])     # [2, 4, 6]       처음~3 미만
print(beta[4:])     # [10, 12, 14]    4 이상~끝
print(beta[:])      # 전체 복사
```

실행 결과:

```
[6, 8, 10]
[2, 4, 6]
[10, 12, 14]
[2, 4, 6, 8, 10, 12, 14]
```

**4. 헷갈리기 쉬운 점**
끝 인덱스는 **포함되지 않습니다(미만)**. `beta[2:5]`는 인덱스 2, 3, 4만 가져오고 5는 제외합니다. "시작은 포함, 끝은 제외"가 핵심입니다.

**5. 한 줄 정리**
슬라이싱은 시작 이상, 끝 미만의 범위를 잘라 가져옵니다.

### 중첩 리스트 접근

**1. 정의**
리스트 안에 리스트가 들어 있는 구조에서, `자료[i][j]`처럼 단계적으로 안쪽 값을 꺼내는 방법입니다.

**2. 왜 필요한가?**
"학생 한 명의 정보(이름·나이·점수 목록)"처럼 데이터가 계층 구조를 이룰 때 자주 나타납니다.

**3. 예시**

```python
student_info = ["홍길동", 20, "컴퓨터공학과", [90, 85, 100, 78, 92]]

student_scores = student_info[3]    # 내부 리스트
print(student_scores[0])            # 90  (첫 번째 점수)
print(student_scores[-1])           # 92  (마지막 점수)
print(student_scores[:3])           # [90, 85, 100]
```

실행 결과:

```
90
92
[90, 85, 100]
```

**4. 헷갈리기 쉬운 점**
`student_info[3]`은 점수 리스트 전체이고, `student_info[3][0]`이 그 안의 첫 점수입니다. 바깥에서 안쪽으로 한 칸씩 들어간다고 생각하면 됩니다.

**5. 한 줄 정리**
중첩 리스트는 `[i][j]`처럼 바깥→안쪽 순서로 접근합니다.

## 코드로 보기 — 학생 정보 꺼내기

```python
student_info = ["홍길동", 20, "컴퓨터공학과", [90, 85, 100, 78, 92]]

student_name   = student_info[0]
student_age    = student_info[1]
student_dept   = student_info[2]
student_scores = student_info[3]    # 내부 리스트

print("이름:", student_name)
print("나이:", student_age)
print("학과:", student_dept)
print("전체 점수:", student_scores)
print("첫 번째 점수:", student_scores[0])
print("마지막 점수:", student_scores[-1])
print("앞 3개 점수:", student_scores[:3])
```

실행 결과:

```
이름: 홍길동
나이: 20
학과: 컴퓨터공학과
전체 점수: [90, 85, 100, 78, 92]
첫 번째 점수: 90
마지막 점수: 92
앞 3개 점수: [90, 85, 100]
```

**코드목적**
하나의 리스트에 담긴 여러 정보를 인덱싱·슬라이싱으로 꺼내고, 중첩된 점수 리스트까지 접근합니다.

**해석**
1단계: 바깥 리스트에서 이름·나이·학과·점수목록을 인덱스로 꺼냅니다. 2단계: 점수목록(내부 리스트)에서 다시 인덱싱·슬라이싱으로 원하는 점수를 꺼냅니다. 계층을 한 단계씩 파고드는 흐름이 보입니다.

**실무 연결**
표 형태 데이터(행·열), JSON 응답, 여러 사용자 레코드 등 실무 데이터는 대부분 중첩 구조입니다. 인덱싱·슬라이싱은 그 안에서 필요한 값만 추출하는 기본기입니다.

## 헷갈리기 쉬운 포인트

- **0부터 vs 1부터** — 인덱스는 0부터. "첫 번째"는 `[0]`.
- **인덱싱 vs 슬라이싱** — `[i]`는 원소 하나, `[i:j]`는 범위(리스트/문자열).
- **끝 인덱스 포함 여부** — 슬라이싱의 끝은 미만(제외).

## 셀프 체크

- [ ] 인덱스가 0부터 시작함을 안다.
- [ ] 인덱싱으로 특정 원소를 꺼낼 수 있다.
- [ ] 음수 인덱스로 뒤에서부터 접근할 수 있다.
- [ ] 슬라이싱의 "끝 미만" 규칙을 안다.
- [ ] 중첩 리스트를 `[i][j]`로 접근할 수 있다.

**복습 질문 및 답변**

- (기본) 리스트 `[10, 20, 30]`에서 `[0]`의 값은? → `10`
- (이해확인) `[2, 4, 6, 8][1:3]`의 결과는? → `[4, 6]` (끝 인덱스 3은 제외)
- (응용) `x = [["a","b"], ["c","d"]]`에서 `"d"`를 꺼내려면? → `x[1][1]`
