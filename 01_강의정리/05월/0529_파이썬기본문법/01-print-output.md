# 출력 — print()로 컴퓨터에게 말 시키기

> 코딩을 시작하면 가장 먼저 만나는 명령, "내가 원하는 걸 화면에 보여줘!"

`print` · `출력` · `문자열` · `콤마구분` · `여러줄출력` · `계산식출력`

## 핵심요약

- `print()`는 괄호 안에 적은 내용을 화면(출력 창)에 보여주는 명령이다.
- 문자열은 따옴표로 감싼다. 숫자는 따옴표 없이 그대로 적는다.
- 콤마(`,`)로 여러 값을 한 줄에, 자동으로 공백을 넣어 출력할 수 있다.
- 여러 줄을 출력하고 싶으면 `print()`를 여러 번 쓰면 된다.
- 괄호 안에서 `100 + 200` 같은 계산식은 먼저 계산된 뒤 그 결과가 출력된다.

## 개념별 정리

### print()

**1. 정의**
`print()`는 괄호 안에 넣은 값을 사람이 볼 수 있게 화면에 표시해 주는 명령입니다.

**2. 왜 필요한가?**
컴퓨터가 내부에서 무슨 계산을 했는지 우리는 눈으로 볼 수 없습니다. `print()`는 "지금 이 값을 보여줘"라고 요청하는 통로입니다. 실무에서도 코드가 잘 돌아가는지 중간 값을 찍어 확인하는 가장 기본적인 도구입니다.

**3. 예시**

```python
print("나의 꿈은 파이썬 정복!")
```

실행 결과:

```
나의 꿈은 파이썬 정복!
```

**4. 헷갈리기 쉬운 점**
문자열은 반드시 따옴표로 감싸야 합니다. `print(안녕)`처럼 따옴표를 빼면 컴퓨터는 `안녕`을 "값을 담은 변수"로 착각해 오류를 냅니다. 시작 따옴표와 끝 따옴표 종류(작은따옴표/큰따옴표)는 똑같이 맞춰야 합니다.

**5. 한 줄 정리**
`print()`는 "이걸 보여줘"라고 컴퓨터에게 건네는 가장 기본 명령입니다.

### 콤마로 여러 값 출력하기

**1. 정의**
괄호 안에서 값과 값 사이를 콤마로 나누면, 한 번의 `print()`로 여러 값을 한 줄에 출력합니다.

**2. 왜 필요한가?**
"이름:"이라는 안내 문구와 실제 이름 값처럼, 서로 다른 종류의 정보를 한 줄에 묶어 보여줄 때 유용합니다.

**3. 예시**

```python
print(3, "Hello!")
print("이름:", "Alice", "나이:", 20)
```

실행 결과:

```
3 Hello!
이름: Alice 나이: 20
```

**4. 헷갈리기 쉬운 점**
콤마로 나눈 값들 사이에는 **자동으로 공백 한 칸**이 들어갑니다. 직접 띄어쓰기를 넣지 않아도 됩니다. 비유하자면 콤마는 "값 사이에 공백 한 칸씩 끼워주는 분리대"입니다.

**5. 한 줄 정리**
콤마는 여러 값을 공백으로 구분해 한 줄에 늘어놓는 도구입니다.

### 여러 줄 출력 / 계산식 출력

**1. 정의**
`print()`를 여러 번 쓰면 줄이 바뀌며 출력되고, 괄호 안에 계산식을 넣으면 결과가 먼저 계산됩니다.

**2. 왜 필요한가?**
삼행시처럼 줄을 나눠 보여줄 때, 또는 계산 결과를 바로 확인할 때 쓰입니다.

**3. 예시**

```python
print("비행기에 타신 승객 여러분")
print("행복한 여행 되십시오")
print("기내식은 바밤바")

print(100, "+", 200, "=", 100 + 200)
```

실행 결과:

```
비행기에 타신 승객 여러분
행복한 여행 되십시오
기내식은 바밤바
100 + 200 = 300
```

**4. 헷갈리기 쉬운 점**
`"100 + 200"`처럼 따옴표로 감싸면 글자 그대로 출력되지만, `100 + 200`처럼 따옴표 없이 적으면 계산되어 `300`이 나옵니다. 따옴표 하나로 의미가 완전히 달라집니다.

**5. 한 줄 정리**
줄바꿈은 `print()`를 여러 번, 계산은 따옴표 없이 적으면 됩니다.

## 코드로 보기 — 여러 출력 방식 한눈에

```python
# 기본 출력
print("나의 꿈은 파이썬 정복!")

# 콤마로 여러 값 한 줄 출력
print(3, "Hello!")
print("이름:", "Alice", "나이:", 20)

# print 여러 번 → 여러 줄
print("비행기에 타신 승객 여러분")
print("행복한 여행 되십시오")
print("기내식은 바밤바")
```

실행 결과:

```
나의 꿈은 파이썬 정복!
3 Hello!
이름: Alice 나이: 20
비행기에 타신 승객 여러분
행복한 여행 되십시오
기내식은 바밤바
```

**코드목적**
출력의 세 가지 기본 패턴(한 값, 여러 값 한 줄, 여러 줄)을 한 번에 보여줍니다.

**해석**
콤마로 나눈 값들은 공백으로 이어지고, `print()`를 나누면 줄이 바뀝니다. 즉 "무엇을 한 줄에 묶을지"와 "어디서 줄을 바꿀지"를 우리가 직접 정할 수 있습니다.

**실무 연결**
프로그램이 만든 결과를 사람에게 보고하는 모든 장면에서 쓰입니다. 데이터 분석 결과 요약, 자동화 스크립트의 진행 상황 출력, 서비스 로그 기록 등이 모두 출력의 응용입니다.

## 헷갈리기 쉬운 포인트

- **`print(3 + 5)` vs `print("3 + 5")`** — 앞은 계산 결과 `8`, 뒤는 글자 그대로 `3 + 5`.
- **콤마 vs 직접 띄어쓰기** — 콤마는 공백을 자동으로 넣어주므로 `print("a", "b")`만으로 `a b`가 됩니다.

- (응용) `print("정답:", 4 + 6)`의 출력은? → `정답: 10`
