# 리스트 메서드 — 추가·삽입·삭제·정렬하기

> 리스트는 한 번 만들고 끝이 아닙니다. 원소를 더하고, 끼우고, 빼고, 줄 세우며 자유롭게 다룹니다.

`리스트메서드` · `append` · `insert` · `remove` · `sort` · `reverse` · `정렬`

## 핵심요약

- `append(d)`는 리스트 맨 끝에 원소 하나를 추가한다.
- `insert(i, d)`는 인덱스 `i` 위치에 원소를 삽입하고, 기존 원소는 뒤로 밀린다.
- `remove(d)`는 처음 등장하는 `d`를 삭제한다. 중복이면 첫 번째만 지운다.
- `sort()`는 원본을 오름차순으로 정렬한다. `sort(reverse=True)`면 내림차순.
- 정렬·추가·삭제 메서드는 원본 리스트를 **직접 바꾼다**.

## 개념별 정리

### append(d) — 맨 끝에 추가

**1. 정의**
리스트의 마지막 원소 뒤에 자료 하나를 추가합니다. 한 번에 하나만 넣을 수 있습니다.

**2. 왜 필요한가?**
장바구니에 물건을 하나씩 담듯, 데이터를 점진적으로 쌓아 나갈 때 가장 많이 쓰는 메서드입니다.

**3. 예시**

```python
a = []
b = ["a", "b", "c"]

a.append(10)
b.append("d")

print("a:", a)   # [10]
print("b:", b)   # ['a', 'b', 'c', 'd']
```

실행 결과:

```
a: [10]
b: ['a', 'b', 'c', 'd']
```

**4. 헷갈리기 쉬운 점**
`append`는 한 번에 하나만 넣습니다. 여러 개를 넣으려면 `append`를 반복하거나 `extend()`를 씁니다. 또 `append`는 새 리스트를 돌려주지 않고 원본을 직접 바꿉니다.

**5. 한 줄 정리**
`append`는 리스트 끝에 원소 하나를 붙입니다.

### insert(i, d) — 원하는 위치에 삽입

**1. 정의**
인덱스 `i` 자리에 자료 `d`를 끼워 넣습니다. 그 자리에 있던 원소들은 한 칸씩 뒤로 밀립니다.

**2. 왜 필요한가?**
맨 끝이 아니라 "특정 위치"에 값을 넣어야 할 때 씁니다. `i=0`이면 맨 앞에 삽입됩니다.

**3. 예시**

```python
c = [1, 2, 4, 5]
c.insert(2, 3)           # 인덱스 2 자리에 3 삽입
print("삽입 후:", c)     # [1, 2, 3, 4, 5]

fruits = ["banana", "cherry"]
fruits.insert(0, "apple") # 맨 앞에 삽입
print("맨 앞 삽입:", fruits)
```

실행 결과:

```
삽입 후: [1, 2, 3, 4, 5]
맨 앞 삽입: ['apple', 'banana', 'cherry']
```

**4. 헷갈리기 쉬운 점**
`insert(2, 3)`은 "인덱스 2 자리에 3을 넣어라"는 뜻이지, "2번 자리에 2를 넣어라"가 아닙니다. 첫 번째 인자는 위치, 두 번째 인자는 값입니다.

**5. 한 줄 정리**
`insert(위치, 값)`은 원하는 자리에 값을 끼워 넣습니다.

### remove(d) — 첫 번째 d 삭제

**1. 정의**
리스트에서 처음으로 나오는 값 `d`를 삭제합니다.

**2. 왜 필요한가?**
"이 값을 목록에서 빼고 싶다"는 요구를 처리할 때 씁니다.

**3. 예시**

```python
my_list = [3, 1, 2, 3]
my_list.remove(3)
print("remove(3) 후:", my_list)    # [1, 2, 3] ← 뒤의 3은 유지

my_list.remove(3)
print("한 번 더 remove:", my_list) # [1, 2]
```

실행 결과:

```
remove(3) 후: [1, 2, 3]
한 번 더 remove: [1, 2]
```

**4. 헷갈리기 쉬운 점**
중복 값이 있으면 **첫 번째 하나만** 지웁니다. `[3, 1, 2, 3]`에서 `remove(3)`을 하면 앞의 3만 사라지고 뒤의 3은 남습니다. 또 리스트에 없는 값을 지우려 하면 오류가 납니다.

**5. 한 줄 정리**
`remove`는 처음 만나는 그 값 하나만 삭제합니다.

### sort() — 정렬

**1. 정의**
리스트의 원소들을 순서대로 정렬합니다. 숫자는 오름차순, 문자열은 사전순입니다. `sort(reverse=True)`면 내림차순입니다.

**2. 왜 필요한가?**
점수 순위, 가나다순 정렬 등 데이터를 보기 좋게 줄 세울 때 씁니다.

**3. 예시**

```python
e = [6, 2, 4, 1, 3, 5]
e.sort()
print("오름차순:", e)          # [1, 2, 3, 4, 5, 6]

f = ["carrot", "apple", "banana"]
f.sort()
print("사전순:", f)            # ['apple', 'banana', 'carrot']

g = [6, 2, 4, 1, 3, 5]
g.sort(reverse=True)
print("내림차순:", g)          # [6, 5, 4, 3, 2, 1]
```

실행 결과:

```
오름차순: [1, 2, 3, 4, 5, 6]
사전순: ['apple', 'banana', 'carrot']
내림차순: [6, 5, 4, 3, 2, 1]
```

**4. 헷갈리기 쉬운 점**
`sort()`는 원본 리스트를 직접 바꾸고, 돌려주는 값은 없습니다(`None`). 그래서 `new = e.sort()`처럼 쓰면 `new`에는 `None`이 담깁니다. 정렬된 리스트는 `e` 자신에 들어 있습니다. 내림차순은 매개변수 `reverse=True`로 지정합니다.

**5. 한 줄 정리**
`sort()`는 원본을 정렬하며, `reverse=True`로 내림차순이 됩니다.

## 코드로 보기 — 할 일(To-Do) 리스트 관리

```python
todo = ["운동하기", "책 읽기", "코딩 공부"]
print("초기:", todo)

todo.append("청소하기")
print("청소 추가:", todo)

todo.insert(0, "병원 예약")
print("병원 예약(맨 앞):", todo)

todo.remove("운동하기")
print("운동 완료 후:", todo)

todo.sort()
print("가나다순 정렬:", todo)
```

실행 결과:

```
초기: ['운동하기', '책 읽기', '코딩 공부']
청소 추가: ['운동하기', '책 읽기', '코딩 공부', '청소하기']
병원 예약(맨 앞): ['병원 예약', '운동하기', '책 읽기', '코딩 공부', '청소하기']
운동 완료 후: ['병원 예약', '책 읽기', '코딩 공부', '청소하기']
가나다순 정렬: ['병원 예약', '책 읽기', '청소하기', '코딩 공부']
```

**코드목적**
추가(`append`)→삽입(`insert`)→삭제(`remove`)→정렬(`sort`)의 흐름을 하나의 시나리오로 연결합니다.

**해석**
할 일을 끝에 추가하고, 급한 일을 맨 앞에 끼우고, 완료한 일을 빼고, 마지막에 가나다순으로 정리합니다. 각 메서드가 원본 리스트를 어떻게 바꾸는지 단계별 출력으로 확인할 수 있습니다.

**실무 연결**
장바구니, 알림 큐, 작업 목록 등 "동적으로 변하는 목록"은 모두 이 네 가지 메서드로 관리됩니다. 공식 문서에서 각 메서드의 매개변수를 확인하는 습관을 들이면 더 정확히 활용할 수 있습니다.

## 헷갈리기 쉬운 포인트

- **`append` vs `insert`** — `append`는 항상 끝, `insert`는 지정한 위치.
- **`remove(값)` vs `del 리스트[인덱스]`** — `remove`는 값으로 삭제(첫 번째), `del`은 위치로 삭제.
- **`sort()` vs `sorted()`** — `sort()`는 원본을 바꾸고 `None` 반환, `sorted()`는 정렬된 새 리스트 반환(원본 유지).

## 셀프 체크

- [ ] `append`로 끝에 원소를 추가할 수 있다.
- [ ] `insert`로 원하는 위치에 삽입할 수 있다.
- [ ] `remove`가 첫 번째 매칭만 지운다는 것을 안다.
- [ ] `sort()`로 오름·내림차순 정렬을 할 수 있다.
- [ ] `sort()`가 원본을 직접 바꾼다는 것을 안다.

**복습 질문 및 답변**

- (기본) 리스트 끝에 값을 추가하는 메서드는? → `append`
- (이해확인) `[3, 1, 3].remove(3)` 후의 리스트는? → `[1, 3]` (앞의 3만 삭제)
- (응용) 내림차순으로 정렬하려면? → `리스트.sort(reverse=True)`
