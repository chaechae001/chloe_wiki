# FastAPI 애플리케이션 컨테이너화

> 웹 애플리케이션을 컨테이너로 만들 때는 코드뿐 아니라 의존성, 시작 명령, 네트워크 수신 주소를 함께 정의해야 한다.

`FastAPI` · `uvicorn` · `requirements` · `0.0.0.0` · `container port`

## 핵심요약

- Python 웹 앱 이미지는 런타임, 의존성, 애플리케이션 코드, 실행 명령을 순서대로 정의한다.
- 컨테이너 안의 서버는 외부 요청을 받도록 적절한 호스트 주소와 포트를 사용해야 한다.
- 개발 편의와 운영 안정성을 위해 빌드 재현성, 작은 이미지, 비밀값 관리가 함께 필요하다.

## 1. 최소 Dockerfile 구조

```dockerfile
FROM python:3.11-slim
WORKDIR /app
COPY requirements.txt ./
RUN pip install --no-cache-dir -r requirements.txt
COPY . .
EXPOSE 8000
CMD ["uvicorn", "main:app", "--host", "0.0.0.0", "--port", "8000"]
```

의존성 목록을 먼저 복사한 뒤 설치하고, 앱 소스를 나중에 복사하면 코드 수정 때 의존성 설치 캐시를 재사용하기 쉽다.

## 2. 포트와 바인딩 주소

컨테이너 내부에서 앱이 특정 포트로 수신하더라도, 호스트에서 접근하려면 실행 시 매핑이 필요하다.

```bash
docker build -t sample-api:1.0 .
docker run -d --name sample-api -p 8000:8000 sample-api:1.0
```

`0.0.0.0` 바인딩은 컨테이너의 네트워크 인터페이스에서 요청을 받을 수 있게 한다. 실제 공개 범위는 호스트의 포트 매핑과 네트워크 정책으로 별도 제어한다.

## 3. 운영으로 연결되는 점검

| 항목 | 개발에서 확인할 내용 | 운영에서 확장할 내용 |
| --- | --- | --- |
| 의존성 | 고정 가능한 버전과 설치 성공 | 취약점 점검, 재현 가능한 빌드 |
| 설정 | 환경마다 달라지는 값 분리 | 비밀값 전용 저장소·권한 관리 |
| 실행 | 로그와 헬스 확인 | 모니터링, 재시작 정책 |
| 이미지 | 불필요한 파일 제외 | 작은 공격 표면, 배포 속도 |

2. `requirements.txt`를 앱 코드보다 먼저 복사하는 이유를 적어 보세요.
3. 비밀 API 키를 Dockerfile에 쓰지 않아야 하는 이유를 적어 보세요.

<details>
<summary>정답 보기</summary>

1. 앱이 컨테이너 포트에서 수신하도록 실행하고, `docker run -p 호스트:컨테이너`로 연결한다.
2. 의존성 목록이 변하지 않으면 설치 레이어를 재사용할 수 있어 빌드가 빨라질 수 있다.
3. 이미지 레이어와 배포 과정에서 값이 노출될 수 있으므로 안전한 런타임 설정 주입을 사용해야 한다.

</details>

## 헷갈리기 쉬운 포인트

| 비교 | 핵심 차이 |
| --- | --- |
| EXPOSE vs `-p` | 컨테이너 포트 의도 표현 vs 호스트-컨테이너 포트 연결 |
| build-time 설정 vs runtime 설정 | 이미지 생성 때 결정되는 값 vs 실행 환경에서 주입하는 값 |

### 복습 질문 및 답변

**Q1. 앱이 컨테이너 안에서는 열리는데 호스트에서 접속되지 않는 이유는 무엇일까요?**

<details>
<summary>답</summary>

앱의 바인딩 주소가 제한적이거나, 호스트 포트 매핑이 빠졌거나, 매핑 대상 포트가 앱의 실제 수신 포트와 다를 수 있다.

</details>

**Q2. 이미지에 소스 전체를 무조건 먼저 복사하면 어떤 불편이 있나요?**

<details>
<summary>답</summary>

작은 코드 수정에도 이후 레이어의 캐시가 무효화되어 의존성 설치를 다시 수행할 가능성이 커진다.

</details>

**Q3. 컨테이너화가 애플리케이션 품질을 자동으로 보장하나요?**

<details>
<summary>답</summary>

아니다. 컨테이너화는 실행 환경을 재현하기 쉽게 한다. 테스트, 로그, 보안, 설정 관리는 별도로 설계해야 한다.

</details>

## 한 줄 정리
