# 클라우드 컴퓨팅의 기본 개념

> 클라우드는 서버를 없애는 기술이 아니라, 서버·스토리지·네트워크를 필요한 순간에 서비스처럼 꺼내 쓰는 운영 방식입니다.

`on-demand` · `resource pooling` · `scalability` · `data center` · `shared responsibility`

## 핵심요약

- 클라우드 컴퓨팅은 원격 데이터 센터의 컴퓨팅 자원을 네트워크로 제공합니다.
- 사용자는 물리 장비 구매보다 필요한 용량과 사용 시간에 집중합니다.
- 가상화와 고속 네트워크가 여러 사용자의 자원을 안전하게 분리합니다.
- 확장 속도와 초기 비용은 줄일 수 있지만 보안·네트워크·비용 통제가 필요합니다.
- AI 서비스에서는 GPU, 저장 공간, API 서버를 수요에 맞게 조합할 수 있습니다.

## 1. 클라우드 컴퓨팅이란

클라우드 컴퓨팅은 CPU, 메모리, GPU, 저장 공간, 네트워크 같은 자원을 요청에 따라 제공하는 방식입니다. 사용자는 장비가 어느 랙에 있는지보다 어떤 성능을 얼마 동안 사용할지 지정합니다.

```text
사용자 기기 → 인터넷 → 클라우드 관리 계층 → 데이터 센터 자원
```

핵심은 **소유에서 사용으로의 전환**입니다. 직접 서버를 구매하면 최대 수요를 예상해 미리 준비하지만, 클라우드에서는 실제 수요에 맞춰 자원을 늘리거나 줄일 수 있습니다.

<details>
<summary>답</summary>

클라우드는 인터넷 자체가 아닙니다. 인터넷은 접근 경로이고, 클라우드는 원격 자원을 요청·할당·회수하는 서비스와 운영 체계입니다.

</details>

## 2. 필요한 이유

서비스 출시 전 모든 장비를 구매하면 조달과 설치에 시간이 들고, 예상보다 사용자가 적으면 자원이 남습니다. 반대로 사용자가 갑자기 늘면 서버 부족이 장애로 이어집니다. 클라우드는 이 간극을 줄입니다.

| 관점 | 기대 효과 | 함께 관리할 위험 |
|---|---|---|
| 속도 | 자원을 빠르게 생성 | 무분별한 생성 |
| 비용 | 초기 구매비 절감 | 방치 자원의 누적 과금 |
| 확장 | 수요에 맞춰 증감 | 잘못된 자동 확장 정책 |
| 안정성 | 여러 영역에 분산 가능 | 단일 구성의 오해 |
| 보안 | 표준 보안 기능 활용 | 권한·설정 오류 |

## 3. 클라우드가 자원을 제공하는 흐름

1. 사용자가 콘솔이나 API로 CPU·메모리·스토리지를 요청합니다.
2. 관리 계층이 남은 자원과 정책을 확인합니다.
3. 가상화 계층이 물리 자원의 일부를 논리 자원으로 분리합니다.
4. 네트워크와 운영체제 이미지가 연결됩니다.
5. 사용자는 주소와 자격 증명으로 생성된 환경에 접근합니다.

AI 추론 서버라면 일반 CPU 인스턴스 대신 GPU 인스턴스를 선택하고, 모델 파일은 별도 스토리지에 두며, 외부 요청은 API 계층에서 받도록 조합할 수 있습니다.

## 4. 클라우드를 판단하는 기준

클라우드가 항상 더 저렴하거나 더 안전한 것은 아닙니다. 워크로드의 사용 패턴과 운영 역량을 함께 봐야 합니다.

- 요청량이 변하는가?
- 중단 허용 시간이 얼마나 짧은가?
- 데이터 위치와 규제 조건이 있는가?
- 네트워크 지연이 사용자 경험에 영향을 주는가?
- 장기 고정 사용과 단기 탄력 사용 중 어느 쪽인가?

## 직접 해보기

1. 온라인 행사의 접속자가 평소보다 20배 증가하는 상황에서 클라우드의 장점을 설명하세요.
2. 24시간 고정 부하와 하루 2시간만 높은 부하인 시스템의 비용 전략을 비교하세요.
3. GPU 추론 API에 필요한 클라우드 자원을 컴퓨팅·스토리지·네트워크로 나누어 보세요.

<details>
<summary>정답 보기</summary>

1. 행사 시간에만 인스턴스를 늘리고 종료 후 줄여 최대 수요용 장비를 상시 보유하지 않아도 됩니다.
2. 고정 부하는 장기 약정이나 전용 자원이 유리할 수 있고, 짧은 피크는 사용량 기반 자원과 자동 확장이 적합합니다.
3. GPU 인스턴스, 모델·로그 저장 공간, 외부 요청을 받는 로드 밸런서와 네트워크가 필요합니다.

</details>

|---|---|
| 인터넷 vs 클라우드 | 연결망과 그 연결망으로 제공되는 컴퓨팅 서비스입니다. |

### 복습 질문 및 답변

**Q1. 온디맨드란 무엇인가요?**

<details>
<summary>답</summary>

필요한 시점에 사용자가 요청해 자원을 생성하고 사용할 수 있다는 뜻입니다.

</details>

**Q2. 클라우드에서 물리 서버를 몰라도 되는 이유는 무엇인가요?**

<details>
<summary>답</summary>

관리·가상화 계층이 물리 자원을 추상화해 CPU, 메모리, 스토리지 같은 논리 자원으로 제공하기 때문입니다.

</details>

**Q3. 클라우드 도입 후 비용이 오를 수 있는 이유는 무엇인가요?**

<details>
<summary>답</summary>

사용하지 않는 자원, 과도한 사양, 데이터 전송, 로그·백업 보관을 통제하지 않으면 사용량 기반 비용이 계속 누적됩니다.

</details>

## 한 줄 정리

> 클라우드 컴퓨팅은 원격 자원을 필요할 때 할당받아 빠르게 실험하고 수요에 맞춰 운영하는 방식입니다.
